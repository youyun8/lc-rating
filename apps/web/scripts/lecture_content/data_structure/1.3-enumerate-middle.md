## 這個技術解決什麼問題

三元組題（$i < j < k$）的暴力是 $O(n^3)$。1.1 的「列舉右、維護左」只消掉一層，還剩 $O(n^2)$。

本節再進一步：**固定中間那個下標 $j$，讓左右兩側各自獨立統計，再用乘法（或加法）合併。** 對每個 $j$，答案的貢獻寫成
$$\text{contrib}(j) = L(j) \times R(j),$$
其中 $L(j)$ 只看 $[0, j)$、$R(j)$ 只看 $(j, n)$。外層 $O(n)$ 枚舉 $j$，兩份摘要各自 $O(1)$ 增量維護，整體 $O(n)$——**三層迴圈一次消掉兩層**。

適用題目：447（迴旋鏢，$j$ 是頂點）、456（132 模式，$j$ 是那個 `3`）、1534（好三元組）、1930（長度 3 的迴文子序列，$j$ 是中心）、2909（山形三元組，$j$ 是山頂）、3128（直角三角形，$j$ 是直角頂點）、2242（圖上枚舉中間一條邊）。

## 狀態／資料結構定義

- **中間下標** $j$：由外層迴圈枚舉。
- **左側摘要** $L$：只依賴 $\{a_0, \dots, a_{j-1}\}$。
- **右側摘要** $R$：只依賴 $\{a_{j+1}, \dots, a_{n-1}\}$。

兩份摘要的內容視題目而定：

| 題目 | $j$ 的角色 | 左側摘要 | 右側摘要 |
| --- | --- | --- | --- |
| 1930 | 迴文中心 | 已出現的字元集合 | 尚未出現的字元集合 |
| 2909 | 山頂 | $\min_{i<j} a_i$ | $\min_{k>j} a_k$ |
| 3128 | 直角頂點 | 同列的 1 的個數 | 同行的 1 的個數 |
| 1534 | 中間元素 | 滿足 $|a_i - a_j| \le b$ 的個數 | 滿足 $|a_j - a_k| \le c$ 的個數 |
| 447 | 迴旋鏢頂點 | — | 到 $j$ 距離為 $d$ 的點數（左右不分） |

**注意 447 不分左右**：它要的是「無序對」，$j$ 以外的所有點放同一份摘要即可，配對數用 $c(c-1)$（有序對）。**要不要分左右，取決於題目的三元組是否要求下標有序。**

## 不變量或正確性證明

**主不變量。** 在第 $j$ 輪計算貢獻的那一瞬間：
$$L = f(a_0, \dots, a_{j-1}), \qquad R = g(a_{j+1}, \dots, a_{n-1}).$$
**$a_j$ 自己既不在 $L$ 也不在 $R$。** 這靠固定的三步節奏維持：

1. `R.remove(a[j])`——把 $a_j$ 從右側移出（初始化時所有元素都在 $R$）。
2. 計算 `contrib(j)`。
3. `L.insert(a[j])`——把 $a_j$ 併入左側，供下一輪使用。

歸納：$j = 0$ 時 $L$ 為空、$R$ 在步驟 1 後恰為 $\{a_1..a_{n-1}\}$；若第 $j$ 輪成立，步驟 3 使 $L = \{a_0..a_j\}$，第 $j+1$ 輪的步驟 1 使 $R = \{a_{j+2}..a_{n-1}\}$，正是所需。

**三步的順序不可交換。** 若步驟 1 放到步驟 2 之後，$a_j$ 會被算成自己右邊的元素，產生 $i < j = k$ 這種非法三元組。若步驟 3 放到步驟 2 之前，同樣會產生 $i = j < k$。**這兩個錯誤在「元素互異」的測資上看不出來**，只有出現重複值時才會多算——正是最難除錯的一類 bug。

**乘法合併的合法性（獨立性條件）。** 寫成 $L(j) \times R(j)$ 的前提是：
$$\text{三元組 } (i,j,k) \text{ 合法} \iff P(i,j) \wedge Q(j,k),$$
即條件可以**拆成「左–中」與「中–右」兩個獨立的謂詞，不含直接連結 $i$ 與 $k$ 的項**。

- 1534 好三元組：條件是 $|a_i - a_j| \le a$、$|a_j - a_k| \le b$、$|a_i - a_k| \le c$。**第三個條件直接連結 $i$ 與 $k$，不可拆！** 所以 1534 不能用純乘法，只能 $O(n^2)$（固定 $i, j$ 再用樹狀陣列數合法的 $k$）或直接 $O(n^3)$（$n \le 100$）。**這是本節最重要的反例：看起來像三元組就套乘法，是錯的。**
- 1930 長度 3 的迴文子序列 `xyx`：條件是 $a_i = a_k$（連結 $i$ 與 $k$！）。但因為值域只有 26，可以**枚舉外層字元 $x$**，把它從「連結」變成「常數」，再對每個 $x$ 取最左與最右出現位置，數中間的相異字元數。**把耦合的維度提到外層枚舉，是解開不可分解條件的標準手法。**
- 2909 山形三元組：$a_i > a_j < a_k$，兩個條件分別只連 $(i,j)$ 與 $(j,k)$。**可拆，成立。**
- 3128 直角三角形：三點分別在同列、同行，條件天然分解。**成立。**

**447 的計數公式。** 固定頂點 $j$，把其餘 $n-1$ 個點按到 $j$ 的距離分組，某距離有 $c$ 個點。題目要的是**有序**對 $(i, k)$ 且 $i \ne k$，故貢獻是 $c \times (c-1)$，不是 $\binom{c}{2}$。距離用**平方距離**比較，避免開根號的浮點誤差（$\mathrm{dx}^2 + \mathrm{dy}^2$，用 `long long` 防溢位）。

**2242（節點序列最大得分）的排除重複端點。** 枚舉中間的一條邊 $(u,v)$，左邊取 $u$ 的鄰居中分數最大者、右邊取 $v$ 的鄰居中分數最大者。但取到的可能就是 $v$ 或 $u$ 自己，或兩邊取到同一個點——**四個節點必須互異**。解法是每個節點只保留分數最大的前 3 個鄰居：因為要排除的最多是 2 個（另一端點 + 對面選中的點），第 3 名必定可用。**「保留前 $k+1$ 名」是處理這類排除的通用手法**，$k$ 是最多要排除的個數。

## C++17 模板

```cpp
// 長度為 3 的不同迴文子序列（LeetCode 1930）
// 中心 j 的角色是「中間那個字元」，但條件 a[i] == a[k] 耦合了左右，
// 因此把外層字元 x 提到最外層枚舉，讓條件退化成可分解的形式。
class Solution {
public:
    int countPalindromicSubsequence(std::string s) {
        int n = s.size(), ans = 0;
        for (char x = 'a'; x <= 'z'; ++x) {
            int lo = -1, hi = -1;
            for (int i = 0; i < n; ++i) {
                if (s[i] == x) {
                    if (lo < 0) {
                        lo = i;
                    }
                    hi = i;  // 最左與最右的 x
                }
            }
            if (hi - lo < 2) {
                continue;
            }  // 中間放不下任何字元
            std::array<bool, 26> mid{};
            for (int j = lo + 1; j < hi; ++j) {
                mid[s[j] - 'a'] = true;  // 中間出現過的相異字元
            }
            ans += std::count(mid.begin(), mid.end(), true);
        }
        return ans;
    }
};
```

```cpp
// 元素和最小的山形三元組 II（LeetCode 2909）
// j 是山頂的相反（谷底）：a[i] > a[j] < a[k]，兩個條件各只連一側，可分解。
class Solution {
public:
    int minimumSum(std::vector<int>& nums) {
        int n = nums.size();
        if (n < 3) {
            return -1;
        }
        std::vector<int> sufMin(n + 1, INT_MAX);
        for (int k = n - 1; k >= 0; --k) {
            sufMin[k] = std::min(sufMin[k + 1], nums[k]);  // 右側摘要，預先算好
        }
        long long ans = LLONG_MAX;
        int preMin = nums[0];  // 左側摘要，邊掃邊更新
        for (int j = 1; j + 1 < n; ++j) {
            if (preMin < nums[j] && sufMin[j + 1] < nums[j]) {
                ans =
                    std::min<long long>(ans, preMin + nums[j] + sufMin[j + 1]);
            }
            preMin = std::min(preMin, nums[j]);  // j 併入左側，供下一輪
        }
        return ans == LLONG_MAX ? -1 : static_cast<int>(ans);
    }
};
```

第二個模板示範了另一種常見寫法：**右側摘要用後綴陣列一次算好，左側摘要邊掃邊維護。** 這比「一開始全放右側、逐一移出」更省事，適用於摘要是極值或前綴和這類可預計算的量；當摘要是計數表（元素會被移出）時，就得用三步節奏。

## 時間與空間複雜度

**標準形（可分解 + 摘要 $O(1)$ 更新）**：$O(n)$ 時間、$O(n)$ 或 $O(|V|)$ 空間（2909、2874、3583）。

**外層再枚舉一維**（1930 枚舉 26 個字元、3128 枚舉列）：$O(n \cdot |\Sigma|)$ 或 $O(mn)$。

**447**：外層枚舉 $n$ 個頂點，內層 $O(n)$ 建距離表，$O(n^2)$ 時間、$O(n)$ 空間。$n \le 500$，可過。

**不可分解、需要第三個資料結構的**（2552 統計上升四元組、1534）：固定兩個下標 $O(n^2)$，內層用樹狀陣列或前綴計數 $O(1)$，整體 $O(n^2)$。**這已經不是本節的乘法合併，而是 9.1 的範疇。**

**與 $O(n^3)$ 的落差**：$n = 10^5$ 時 $O(n^3) = 10^{15}$（不可行）、$O(n^2) = 10^{10}$（不可行）、$O(n) = 10^5$（瞬間）。**三元組題只要 $n > 500$，就必須做到 $O(n)$ 或 $O(n \log n)$。**

## 常見錯誤與邊界條件

- 三步節奏順序寫錯，把 $a_j$ 算進自己的左側或右側（**只在有重複值的測資上出錯**）。
- 計數表移出後值變成 0 卻沒從 `unordered_map` 刪除，導致「相異值個數」多算（用 `if (--cnt[x] == 0) cnt.erase(x);`）。
- 乘法合併用在不可分解的條件上（1534 的第三個約束）。
- 447 用 $\binom{c}{2}$ 而非 $c(c-1)$（題目要有序對）。
- 447 用浮點距離（誤差）或 `int` 平方（$10^4$ 的座標差平方和達 $8\times10^8$，接近 `int` 上限，配對時務必 `long long`）。
- 2909 的 `sufMin` 開成長度 $n$ 而非 $n+1$（$j = n-2$ 時存取 `sufMin[n-1]` 沒問題，但寫成 `sufMin[j+1]` 且 $j$ 跑到 $n-1$ 就越界）。
- `preMin` 初始化成 `INT_MAX` 卻參與加法（溢位，本模板改成 `nums[0]` 並用 `long long` 比較）。
- $n < 3$ 未特判。
- 2242 忘記排除重複端點（只留前 1 名不夠，要前 3 名）。
- 乘積用 `int` 溢位（$L$ 與 $R$ 都到 $10^5$ 時乘積 $10^{10}$）。

## 與相似技巧的比較

- **與 1.1**：1.1 維護一側，本節維護兩側。**判準：三元組中「角色特殊」的元素在中間，就用本節；在右端就用 1.1。**
- **與前綴／後綴陣列（2.1）**：當摘要是可預計算的極值或和時，本節退化成「前綴陣列 + 後綴陣列 + 枚舉分界」，這是同一招的最常見形態（2909、3084、1653）。**看到「左邊最小、右邊最大」就往這裡想。**
- **與單調堆疊（4.7）**：456（132 模式）也是列舉中間，但它要的是「右邊比 $a_j$ 小的最大值」，這用單調堆疊從右往左掃更自然，$O(n)$。**當左右摘要需要的是「第一個滿足某序關係的元素」時，單調堆疊優於計數表。**
- **與樹狀陣列（9.1）**：條件不可分解、必須固定兩個下標時，內層的「有幾個小於 $x$」用樹狀陣列，$O(n^2 \log n) \to$ 常見的 2552、3257 都走這條。
- **與 1.4 遍歷對角線**：3128（直角三角形）的分組鍵是列與行，1.4 的分組鍵是 $i \pm j$。**都是「先分組再組合計數」，只是鍵不同。**
- **與 2867（統計樹中的合法路徑）**：那是把「列舉中間」搬到樹上——枚舉質數節點當中間點，左右換成各棵子樹，乘法合併時要扣掉「同一棵子樹內配對」的部分。**樹上版本的「不重不漏」比陣列版難，見 trees 3.13。**

## 本節重點速查

- 固定中間的 $j$，左右各一份摘要，貢獻寫成 $L(j) \times R(j)$：$O(n^3) \to O(n)$。
- 節奏固定三步：**移出右 → 算貢獻 → 加入左**。順序錯了只在重複值的測資上暴露。
- **乘法合併的前提是條件可分解**：$(i,j,k)$ 合法 $\iff P(i,j) \wedge Q(j,k)$，**不能有直接連結 $i$ 與 $k$ 的項**。1534 就是不可拆的反例。
- 條件耦合了 $i$ 與 $k$ 時，**把耦合的那一維提到最外層枚舉**（1930 枚舉 26 個字元）。
- 摘要是極值／前綴和 → 用後綴陣列預算，寫起來更短；摘要是計數表 → 必須用三步節奏。
- 447 要的是有序對，用 $c(c-1)$；距離用平方且開 `long long`。
- 排除重複端點時「保留前 $k+1$ 名」，$k$ 是最多要排除的個數（2242 保留前 3）。
