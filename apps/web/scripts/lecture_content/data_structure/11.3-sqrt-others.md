## 這個技術解決什麼問題

11.1 把**陣列**切成 $\sqrt n$ 塊，11.2 把**查詢**按 $\sqrt n$ 分組。但根號的用處遠不止「切塊」。

**這一節收集的是另一類根號**：不切任何東西，而是**證明「某個量本身就不超過 $\sqrt n$ 種」**，於是可以放心地枚舉它。

> **核心引理族**：若兩個非負量 $x$、$y$ 滿足 $x \cdot y \le n$（或 $x^2 \le n$），則**其中至少一個不超過 $\sqrt n$**。

這句廢話一樣的算術，撐起了一整族技巧：

| 場景 | 受限的量 | 上界 |
| --- | --- | --- |
| 子字串中 $\text{ones} \ge \text{zeros}^2$（3234） | 零的個數 | $\sqrt n$ |
| 出現次數 $> \sqrt n$ 的元素 | 這種元素的種類數 | $\sqrt n$ |
| $\lfloor n/i \rfloor$ 隨 $i$ 變化 | 不同值的個數 | $2\sqrt n$ |
| $\sum a_i = S$ 時 $a_i$ 的不同值 | 種類數 | $\sqrt{2S}$ |
| $n$ 的因數 | $\le\sqrt n$ 或配對的 $>\sqrt n$ | 各一半 |

**辨識訊號**：
- 問的是某段裡「符合某種條件的數量」，而這條件**沒有好用的區間合併公式**（3234 統計 1 顯著的子字串的數量）；
- 線段樹／樹狀陣列很難維護你要的摘要，但「每塊各自統計 + 零頭暴力」就能回答；
- $n$、$q$ 在十萬等級，$O((n+q)\sqrt n)$ 可過而 $O(nq)$ 會超時；
- **題目條件裡出現了平方、乘積或總和的限制**——這往往就是根號的入口。

**最後一條是最有用的辨識法**：**看到「$x^2 \le$ 某個線性量」或「總和 $\le S$」，先算一下它蘊含了什麼上界。** 很多題目的關鍵不是資料結構，而是這個上界。

## 狀態／資料結構定義

這一節沒有單一的資料結構，而是四個可以獨立使用的骨架。

**骨架一：受限量枚舉（3234 型）**

```cpp
// 對每個右端點 r，枚舉「零的個數」z = 0 .. sqrt(n)
// 對每個 z，合法的左端點 l 落在一個「連續區間」上，O(1) 計數
```

需要的輔助狀態只有：**零的位置陣列 `pos`**（`pos[j]` = 第 $j$ 個零的下標，$j$ 從 1 起算，`pos[0] = -1`）。

**骨架二：整除分塊（數論分塊）**

```cpp
for (int i = 1, j; i <= n; i = j + 1) {
    j = n / (n / i);  // [i, j] 內 n/i 的值都相同
    // 用 (j - i + 1) 個相同的 n/i 做事
}
```

**骨架三：重／輕元素分治**

```cpp
// 出現次數 > sqrt(n) 的元素稱為「重元素」，至多 sqrt(n) 種
// 重元素：每種各自 O(n) 掃一遍  ⇒ O(n sqrt n)
// 輕元素：出現次數 <= sqrt(n)，用另一套（通常是暴力枚舉出現位置對）
```

**骨架四：操作分塊（對時間軸分塊）**

```cpp
// 把 q 個操作按每 sqrt(q) 個分成一批
// 每批開始時：O(n) 重建一個「不含本批修改」的靜態結構
// 批內查詢：靜態結構的答案 + 本批 O(sqrt q) 個修改的暴力修正
```

**四個骨架的共同點**：**它們都把「一次做全部」拆成「大的少做、小的多做」，並讓兩側的代價相等。** 這就是 11.1 定理 1 的同一個平衡，只是套在不同的量上。

## 不變量或正確性證明

### 定理 1（平方受限引理）

*命題*：設子字串包含 $z$ 個 0 與 $o$ 個 1，且滿足 $o \ge z^2$。若字串總長為 $n$，則 $z \le \lfloor\sqrt n\rfloor$。

*證明*。$z^2 \le o \le z + o \le n$，故 $z \le \sqrt n$ ✔。$\square$

**看起來平凡，但它把「枚舉所有 $O(n^2)$ 個子字串」變成了「枚舉 $O(n\sqrt n)$ 個 $(r, z)$ 組合」——這是本節全部技巧的原型。**

**推論 1.1（同型的常用上界）**：
- $\sum_{i} a_i = S$ 且 $a_i$ 為相異正整數 ⇒ 至多 $O(\sqrt S)$ 個（因為 $1+2+\cdots+k = k(k+1)/2 \le S$）。**多重背包的「相同物品分組」與「不同重量至多 $\sqrt S$ 種」都靠這一條。**
- 陣列中出現次數 $> \sqrt n$ 的元素 ⇒ 至多 $\sqrt n$ 種（否則總長超過 $n$）。
- $n$ 的因數必定成對出現 $(d, n/d)$，其中至少一個 $\le \sqrt n$ ⇒ **枚舉因數只需 $O(\sqrt n)$。**

### 定理 2（3234 的完整解法與正確性）

*問題*：給定 01 字串 $s$（長度 $n$），求有多少子字串滿足「1 的個數 $\ge$ 0 的個數的平方」。

*記號*：設 $s$ 中零的位置由小到大為 $p_1 < p_2 < \cdots < p_m$，並約定 $p_0 = -1$。對右端點 $r$，令 $t = t(r)$ 為 $[0, r]$ 內零的個數。

**命題**：固定 $r$ 與 $z \ge 1$，子字串 $[l, r]$ 恰含 $z$ 個零，**當且僅當**

$$p_{t-z} + 1 \;\le\; l \;\le\; p_{t-z+1}\qquad(\text{需 } 1 \le z \le t).$$

*證明*。$[l, r]$ 內的零的個數 $= t - \#\{j : p_j < l\}$。此數等於 $z$ $\iff$ 恰有 $t-z$ 個零位置嚴格小於 $l$ $\iff$ $p_{t-z} < l \le p_{t-z+1}$ ✔（$p$ 嚴格遞增，故「前 $t-z$ 個在左、第 $t-z+1$ 個在右」等價於這個區間條件）。$\square$

**命題（1 的個數條件）**：$[l, r]$ 的長度為 $r-l+1$，其中 $z$ 個零 ⇒ 1 的個數 $o = r-l+1-z$。條件 $o \ge z^2$ 等價於

$$l \;\le\; r + 1 - z - z^2.$$

**兩個條件都是「$l$ 的區間限制」，交集仍是區間 ⇒ 合法 $l$ 的個數可以 $O(1)$ 算出**：

$$\mathrm{cnt}(r, z) \;=\; \max\Big(0,\; \min\big(p_{t-z+1},\; r+1-z-z^2\big) \;-\; \big(p_{t-z}+1\big) \;+\; 1\Big).$$

**$z = 0$ 的情形單獨處理**：$[l, r]$ 全為 1 $\iff$ $l > p_t$，且條件 $o \ge 0$ 恆成立 ⇒ 個數 $= r - p_t$（當 $t = 0$ 時 $p_0 = -1$，個數 $= r+1$ ✔）。

**總答案** $= \sum_{r=0}^{n-1}\sum_{z=0}^{\min(t(r),\,\lfloor\sqrt n\rfloor)} \mathrm{cnt}(r, z)$。

*不重不漏*：每個子字串 $[l, r]$ 有唯一的右端點 $r$ 與唯一的零個數 $z$，故恰好在 $(r, z)$ 這一項被計數一次 ✔。由定理 1，$z > \sqrt n$ 的項全部為 0，跳過它們不影響答案 ✔。

*複雜度*：$O(n\sqrt n)$。$n = 4\times10^4$ ⇒ 約 $8\times10^6$，輕鬆通過 ✔。$\square$

**這個證明的結構值得記住**：**「把條件逐一翻譯成 $l$ 的區間限制，取交集，$O(1)$ 計數。」** 只要每個條件都是 $l$ 的單調條件，這招就成立——**這也是 sliding_window 章「雙指標」與本節的共同祖先。**

**一個容易寫錯的地方**：$z$ 的上界要同時受 $t(r)$（真的有這麼多零）與 $\lfloor\sqrt n\rfloor$（定理 1）限制。**只寫其中一個，不是漏算就是越界讀 `pos`。**

### 定理 3（整除分塊：$\lfloor n/i \rfloor$ 只有 $O(\sqrt n)$ 種值）

*命題 (a)*：集合 $\{\lfloor n/i \rfloor : 1 \le i \le n\}$ 的大小不超過 $2\lfloor\sqrt n\rfloor$。

*證明*。分兩段：
- $i \le \sqrt n$：至多 $\lfloor\sqrt n\rfloor$ 個 $i$，故至多這麼多個值 ✔。
- $i > \sqrt n$：此時 $\lfloor n/i\rfloor < \sqrt n$，取值落在 $\{0, 1, \dots, \lfloor\sqrt n\rfloor\}$ 中，至多 $\lfloor\sqrt n\rfloor + 1$ 個 ✔。

合計 $\le 2\lfloor\sqrt n\rfloor + 1$ ✔。$\square$

*命題 (b)（塊的右端點公式）*：設 $q = \lfloor n/i\rfloor$，則使 $\lfloor n/j\rfloor = q$ 的最大 $j$ 為 $j = \lfloor n/q \rfloor$。

*證明*。
- **$\lfloor n/\lfloor n/q\rfloor\rfloor = q$**：令 $j = \lfloor n/q\rfloor$。由 $q = \lfloor n/i\rfloor$ 知 $q \le n/i$，故 $j = \lfloor n/q\rfloor \ge i$，於是 $\lfloor n/j\rfloor \le \lfloor n/i\rfloor = q$。另一方面 $j \le n/q$ 蘊含 $n/j \ge q$，故 $\lfloor n/j\rfloor \ge q$。兩者夾出 $\lfloor n/j\rfloor = q$ ✔。
- **$j$ 是最大的**：對 $j' > j = \lfloor n/q\rfloor$ 有 $j' \ge \lfloor n/q\rfloor + 1 > n/q$，故 $n/j' < q$，即 $\lfloor n/j'\rfloor < q$ ✔。$\square$

**於是 `for (i = 1; i <= n; i = j + 1) { j = n / (n / i); ... }` 恰好走過每一個「值相同的極大區間」，共 $O(\sqrt n)$ 次迭代。**

**典型用途**：$\sum_{i=1}^{n}\lfloor n/i\rfloor$、莫比烏斯反演的求和、「有多少個 $i$ 使得 $\lfloor n/i\rfloor = k$」。**LeetCode 上直接考的不多，但它是「值只有 $O(\sqrt n)$ 種」這個模式最乾淨的例子。**

### 定理 4（重／輕元素分治）

*命題*：陣列長度 $n$，稱出現次數 $> \sqrt n$ 的元素為**重元素**，則重元素至多 $\lfloor\sqrt n\rfloor$ 種。

*證明*。若有 $k$ 種重元素，總出現次數 $> k\sqrt n$，而總長為 $n$，故 $k < \sqrt n$ ✔。$\square$

**這條引理的價值在於它允許「對每種重元素各做一次 $O(n)$ 的處理」**，總計 $O(n\sqrt n)$。

*典型應用（區間眾數，無修改，離線或線上）*：
- **重元素**：至多 $\sqrt n$ 種。對每種 $v$ 預處理前綴出現次數 $c_v[i]$，查詢時 $O(1)$ 得到 $[l,r]$ 內 $v$ 的次數 ⇒ 每個查詢掃過所有重元素 $O(\sqrt n)$。
- **輕元素**：出現次數 $\le \sqrt n$。若答案是輕元素，則答案的出現次數 $\le \sqrt n$。**這一半通常需要別的技巧**（例如「答案要嘛是重元素，要嘛出現次數不超過 $\sqrt n$，可以用出現位置的列表二分」）。

**誠實的說明**：重／輕分治的「輕」那一半往往不像「重」那一半那麼乾淨，**很多題目只有重元素這一半是根號，輕元素得靠題目的額外性質。** 動手前先確認兩半都有辦法。

**空間代價**：對每種重元素存一份長度 $n$ 的前綴計數，是 $O(n\sqrt n)$ 的記憶體。$n = 10^5$ ⇒ $3\times10^7$ 個 `int` = **120 MB，通常不可行**。**實務上改成「重元素的出現位置列表 + 二分」，空間降到 $O(n)$，查詢多一個 $\log$。**

### 定理 5（操作分塊：把「難以增量維護」的結構定期重建）

*設定*：有一個結構 $D$，重建要 $O(n)$、查詢要 $O(1)$，但**單次修改無法增量維護**（只能重建）。共 $q$ 次操作混合修改與查詢。

*做法*：把操作序列按每 $b$ 個分成一批。**每批開始時重建 $D$（只反映本批之前的所有修改）**；批內的查詢 = $D$ 的答案 + 「本批已發生的 $\le b$ 個修改」的暴力修正。

*複雜度*：重建 $\frac{q}{b}\cdot O(n)$，批內修正 $q \cdot O(b)$ ⇒ 總 $O\big(\frac{qn}{b} + qb\big)$，取 $b = \sqrt n$ 得 $O(q\sqrt n)$ ✔。

*正確性的關鍵前提*：**「$D$ 的答案」與「本批修改的影響」必須能疊加。** 若修改之間會互相干擾（例如區間賦值的後蓋前），暴力修正就不是簡單相加，這招失效。**點名這個前提，才知道什麼時候不能用。**

**這與 11.1 定理 6（定期重建分塊）是同一個想法，只是這裡分塊的對象是「時間」而不是「空間」。** 兩者都屬於本章反覆出現的那個模式：**昂貴的整理工作被攤到 $\sqrt{\cdot}$ 次操作上。**

### 定理 6（為什麼分界點永遠在「兩側代價相等處」）

*命題*：設把某個參數 $k$ 分成「$k \le K$ 用方法 A、$k > K$ 用方法 B」，且方法 A 的代價隨 $K$ 遞增為 $f(K)$、方法 B 的代價隨 $K$ 遞減為 $g(K)$，兩者皆連續單調。則總代價 $\max\big(f(K), g(K)\big)$（或 $f+g$）在 $f(K^\star) = g(K^\star)$ 處達到最小。

*證明*。$\max(f,g)$ 在 $K < K^\star$ 時等於 $g$（遞減），在 $K > K^\star$ 時等於 $f$（遞增），故 $K^\star$ 是唯一極小點 ✔。對於 $f+g$，若兩者形如 $aK$ 與 $b/K$，AM–GM 給出同一個結論（11.1 定理 1）✔。$\square$

**這條「元定理」統一了本章所有的根號**：

| 技巧 | 方法 A（小） | 方法 B（大） | 平衡點 |
| --- | --- | --- | --- |
| 陣列分塊（11.1） | 零頭暴力 $O(s)$ | 整塊摘要 $O(n/s)$ | $s = \sqrt n$ |
| 1714 對參數分塊 | 預處理 $O(yn)$ | 暴力 $O(n/y)$ | $y = \sqrt n$ |
| 莫隊（11.2） | $l$ 移動 $O(qs)$ | $r$ 移動 $O(n^2/s)$ | $s = n/\sqrt q$ |
| 重／輕元素（定理 4） | 重元素各掃一次 | 輕元素次數有限 | $\sqrt n$ |
| 操作分塊（定理 5） | 批內修正 $O(qb)$ | 重建 $O(qn/b)$ | $b = \sqrt n$ |

**看到「一個參數，兩側代價一升一降」，就令它們相等解出分界點。$\sqrt n$ 只是最常見的解，不是唯一的答案。**

## C++17 模板

**模板一：3234 統計 1 顯著的子字串（定理 2）**

```cpp
class Solution {
public:
    int numberOfSubstrings(string s) {
        int n = int(s.size());
        int Z = int(sqrt(double(n))) + 1;  // 零的個數上界（定理 1）
        vector<int> pos;  // pos[0] = -1，之後是零的下標
        pos.push_back(-1);
        long long ans = 0;
        for (int r = 0; r < n; r++) {
            if (s[r] == '0') pos.push_back(r);
            int t = int(pos.size()) - 1;  // [0, r] 內零的個數
            // z = 0：全為 1 的子字串
            ans += r - pos[t];
            // z >= 1
            for (int z = 1; z <= min(t, Z); z++) {
                long long need = 1LL * z * z;
                long long hi = min<long long>(pos[t - z + 1], r + 1 - z - need);
                long long lo = pos[t - z] + 1;
                if (hi >= lo) ans += hi - lo + 1;
            }
        }
        return int(ans);
    }
};
```

**`z` 的上界是 `min(t, Z)`——兩個限制缺一不可**（真的有這麼多零 ∧ 定理 1 的上界）。**`hi` 用 `long long` 是因為 `r + 1 - z - z*z` 可能為負，而它要跟 `pos[...]` 比較。**

**模板二：整除分塊（定理 3）**

```cpp
long long sumOfFloorDiv(int n) {  // 計算 sum_{i=1}^{n} floor(n / i)
    long long res = 0;
    for (int i = 1, j; i <= n; i = j + 1) {
        int v = n / i;
        j = n / v;  // [i, j] 內 n/i 恆為 v（定理 3(b)）
        res += 1LL * v * (j - i + 1);
    }
    return res;
}
```

**`j = n / (n / i)` 這一行就是全部。** 迴圈次數 $O(\sqrt n)$。

**模板三：重元素預處理（定理 4，空間友善版）**

```cpp
struct HeavyLight {
    int n, TH;
    vector<int> heavyId;      // 值 -> 重元素編號，非重為 -1
    vector<vector<int>> occ;  // 每個重元素的出現位置（遞增）

    explicit HeavyLight(const vector<int>& a, int m) : n(int(a.size())) {
        TH = max(1, int(sqrt(double(n))));
        vector<int> cnt(m, 0);
        for (int x : a) cnt[x]++;
        heavyId.assign(m, -1);
        for (int v = 0; v < m; v++)
            if (cnt[v] > TH) {
                heavyId[v] = int(occ.size());
                occ.emplace_back();
            }
        for (int i = 0; i < n; i++)
            if (heavyId[a[i]] >= 0) occ[heavyId[a[i]]].push_back(i);
        // occ.size() <= sqrt(n)（定理 4），總空間 O(n)
    }
    // 重元素 v 在 [l, r] 內出現幾次：O(log n)
    int countIn(int v, int l, int r) const {
        int id = heavyId[v];
        if (id < 0) return -1;  // 不是重元素
        const auto& o = occ[id];
        return int(upper_bound(o.begin(), o.end(), r) -
                   lower_bound(o.begin(), o.end(), l));
    }
};
```

**用「出現位置 + 二分」而非「$\sqrt n$ 份前綴計數」，把空間從 $O(n\sqrt n)$ 降到 $O(n)$**（定理 4 的空間說明）。**這幾乎總是正確的取捨。**

**模板四：操作分塊骨架（定理 5）**

```cpp
const int B = max(1, int(sqrt(double(n))));
for (int st = 0; st < q; st += B) {
    int en = min(q, st + B);
    rebuild();           // O(n)，反映 [0, st) 的所有修改
    vector<Op> pending;  // 本批已發生的修改
    for (int i = st; i < en; i++) {
        if (ops[i].isUpdate) {
            pending.push_back(ops[i]);
            apply(ops[i]);
        } else {
            long long base = staticQuery(ops[i]);  // O(1) 或 O(log n)
            for (auto& u : pending) base += correct(u, ops[i]);  // O(|pending|)
            ans[ops[i].id] = base;
        }
    }
}
```

## 時間與空間複雜度

| 技巧 | 時間 | 空間 |
| --- | --- | --- |
| 3234（定理 2） | $O(n\sqrt n)$ | $O(n)$ |
| 整除分塊（定理 3） | $O(\sqrt n)$ 次迭代 | $O(1)$ |
| 重元素（前綴計數版） | 預處理 $O(n\sqrt n)$、查詢 $O(\sqrt n)$ | **$O(n\sqrt n)$，通常爆** |
| 重元素（位置 + 二分版） | 預處理 $O(n)$、查詢 $O(\sqrt n\log n)$ | $O(n)$ |
| 操作分塊（定理 5） | $O(q\sqrt n)$ | $O(n)$ |

**規模感**：
- $n = 4\times10^4$（3234）⇒ $n\sqrt n = 8\times10^6$，**極寬鬆**；
- $n = 10^5$ ⇒ $n\sqrt n = 3.2\times10^7$，**常數要小**；
- $n = 10^6$ ⇒ $10^9$，**根號全線失效，必須找 $O(n\log n)$**。

**「$n\sqrt n$ 的臨界點在 $n \approx 10^5$」值得記住**——看到 $n$ 超過這個量級，根號就不再是候選方案。

**空間永遠先算一遍**（定理 4 的教訓）：**「對 $\sqrt n$ 個東西各存一個長度 $n$ 的陣列」是 $O(n\sqrt n)$，$n = 10^5$ 時就是 120 MB。** 幾乎總要換成「位置列表 + 二分」。

## 常見錯誤與邊界條件

- **忘了受限量的上界要取兩個限制的最小值**（定理 2）。3234 的 `z` 上界是 `min(t, sqrt(n))`——只寫 `sqrt(n)` 會越界讀 `pos`，只寫 `t` 會退化成 $O(n^2)$。
- **`pos[0] = -1` 這個哨兵沒放**。$z = t$（子字串含全部零）時要用到 `pos[0]`，沒有哨兵就特判滿天飛。**與 8.4 的 `fa[n] = n+1`、10.1 的序列哨兵是同一個手法。**
- **負數與型別**。`r + 1 - z - z*z` 可能為負；`z*z` 在 `int` 下當 $z$ 大時也可能溢位（雖然 $z \le \sqrt n$ 時安全，但寫成 `1LL * z * z` 更保險）。
- **整除分塊寫成 `j = n / (n / i) + 1` 或忘了 `i = j + 1`**。前者跳過一個值，後者死迴圈。**照抄 `for (i = 1, j; i <= n; i = j + 1) { j = n / (n / i); }`。**
- **整除分塊在 `n / i == 0` 時除零**。只有 $i > n$ 才會發生，而迴圈條件是 `i <= n`，所以安全；**但若把上界改成 $m > n$ 就會炸，要寫成 `j = (v ? min(m, n / v) : m)`。**
- **重元素的空間**（定理 4）。$O(n\sqrt n)$ 的前綴計數表通常爆記憶體。**改用出現位置 + 二分。**
- **重／輕分治只想清楚一半**。「重」那半通常很順，**「輕」那半才是真正的難點**。動手前先確認兩半都有辦法。
- **操作分塊的疊加前提沒檢查**（定理 5）。修改之間互相干擾（區間賦值的後蓋前）時，「靜態答案 + 暴力修正」不成立。
- **分界點取錯**（定理 6）。$\sqrt n$ 不是萬用值——**兩側代價不對稱時要重新解方程。** 莫隊的 $n/\sqrt q$ 就是最好的反例。
- **在 $n \ge 10^6$ 時還想用根號**。$n\sqrt n = 10^9$，沒有救。

## 與相似技巧的比較

- **與 11.1 陣列分塊**：11.1 是「切資料」，本節是「證明某個量本身就 $\le\sqrt n$」。**後者不需要任何額外的資料結構，只需要一個算術論證，因此往往更快也更好寫。** 拿到題目先找有沒有這種上界，找不到再考慮切塊。
- **與 11.2 莫隊**：莫隊是「切查詢」。**三節合起來就是根號的三種對象：資料、查詢、以及「量本身」。**
- **與 9.7 ST 表的 gcd 性質**：「固定左端點，區間 gcd 至多 $O(\log V)$ 種值」與本節的「至多 $O(\sqrt n)$ 種」是同一類論證——**都是「找出被枚舉量的真實上界」**，只是一個是對數、一個是根號。**這類論證的通用問法：這個量每次變化至少付出多少代價？總代價的上界是多少？**
- **與 2 節前綴和**：3234 的解法本質上是「前綴計數 + 區間交集」，只是多了一層 $z$ 的枚舉。**如果你能把所有條件都翻譯成「$l$ 的區間限制」，剩下的就是 $O(1)$ 算交集。** 這是本節最可遷移的技能。
- **與 sliding_window 的雙指標**：雙指標處理「條件對 $l$ 單調」的情形，$O(n)$。**本節處理的是「條件對 $l$ 單調，但還有第二個參數 $z$ 要枚舉」的情形**，代價是多一個 $\sqrt n$。**先問：能不能只用雙指標？**
- **與 dynamic_programming 的多重背包**：「$\sum a_i = S$ ⇒ 不同重量至多 $O(\sqrt S)$」（推論 1.1）是多重背包能被優化的根據之一。**同一條引理，跨章出現。**
- **與位元壓縮（bitset）**：另一種常見的「常數優化到能過」的手段，$O(n^2/64)$。**與根號的定位相似（都是把不可行的暴力壓進時限），但 bitset 依賴的是機器字長而非數學上界。** $n \le 5\times10^4$ 時 $n^2/64 \approx 4\times10^7$，與 $n\sqrt n$ 是同一個量級——**兩者常常是同一題的兩種解法。**

## 本節重點速查

- **核心引理（定理 1）**：$x^2 \le n$ 或 $xy \le n$ ⇒ 至少一邊 $\le \sqrt n$。**看到題目條件裡的平方、乘積、總和限制，先算它蘊含什麼上界——那往往就是解法。**
- **四個常用上界（推論 1.1）**：$\sum a_i = S$ 的相異正整數至多 $O(\sqrt S)$ 種；出現次數 $>\sqrt n$ 的元素至多 $\sqrt n$ 種；因數成對出現故枚舉 $O(\sqrt n)$；$\lfloor n/i\rfloor$ 至多 $2\sqrt n$ 種值。
- **3234（定理 2）**：$o \ge z^2$ ⇒ $z \le \sqrt n$。固定 $(r, z)$，**兩個條件都是 $l$ 的區間限制**（恰含 $z$ 個零 ⇒ $l \in (p_{t-z},\, p_{t-z+1}]$；$o\ge z^2$ ⇒ $l \le r+1-z-z^2$），取交集 $O(1)$ 計數。**$z$ 上界 `min(t, sqrt(n))`，`pos[0] = -1` 哨兵，`long long`。**
- **整除分塊（定理 3）**：`for (i = 1, j; i <= n; i = j + 1) j = n / (n / i);`。塊右端 $= \lfloor n/\lfloor n/i\rfloor\rfloor$，$O(\sqrt n)$ 次迭代。
- **重／輕分治（定理 4）**：重元素至多 $\sqrt n$ 種 ⇒ 各掃一遍 $O(n\sqrt n)$。**空間務必用「出現位置 + 二分」（$O(n)$）而非「$\sqrt n$ 份前綴計數」（$O(n\sqrt n)$，會爆）。** 「輕」那一半通常才是難點。
- **操作分塊（定理 5）**：每 $\sqrt n$ 個操作重建一次靜態結構，批內查詢 = 靜態答案 + $O(\sqrt n)$ 個修改的暴力修正。**前提是兩者可疊加**（區間賦值不行）。
- **元定理（定理 6）**：**一個參數、兩側代價一升一降 ⇒ 令兩者相等解出分界點。** $\sqrt n$ 只是最常見的解；莫隊的 $n/\sqrt q$ 說明它不是唯一。
- **規模感**：$n\sqrt n$ 在 $n = 10^5$ 是 $3\times10^7$（要小常數）、$n = 10^6$ 是 $10^9$（**放棄根號**）。**空間永遠先算一遍。**
