## 這個技術解決什麼問題

2.1 把區間和變成 $O(1)$ 可取；2.2 用雜湊表回答「和恰為 $k$」。本節處理第三類問法：**在前綴和序列上做最佳化**——找最好的端點、最長的區間、最大的組合值。

三種常見形態：

1. **排序後前綴和單調 ⇒ 可二分**（2389 和有限的最長子序列、2300 咒語與藥水、1898）。子序列題允許打亂順序，排序後前綴和嚴格遞增，「最多能取幾個」就是一次 `upper_bound`。
2. **枚舉分界點，左右各取最佳**（1031 兩段不重疊子陣列、2555 兩條線段、1888、689）。這是 1.3「列舉中間」套在前綴和上。
3. **前綴和 + 排序 + 貪心／堆**（1788、2542、2813、1383）。先用前綴和把「取一段」的成本 $O(1)$ 化，再對另一維排序。

共同的槓桿是：**前綴和把「一段的量」壓成 $O(1)$，於是原本 $O(n)$ 的內層可以換成二分、單調維護或堆。**

## 狀態／資料結構定義

**形態一（排序 + 二分）**：
- 排序後的 $a$，前綴和 $s$（$s_0 = 0$，`long long`）。
- 因為 $a_i \ge 0$，$s$ **嚴格遞增**（有 0 時是非嚴格遞增，仍可二分）。
- 查詢「和不超過 $q$ 時最多取幾個」= `upper_bound(s.begin(), s.end(), q) - s.begin() - 1`。

**形態二（枚舉分界）**：
- $\mathrm{bestL}[i]$ = 在 $[0, i)$ 中，長度為 $k_1$ 的子陣列和的最大值（前綴最佳）。
- $\mathrm{bestR}[i]$ = 在 $[i, n)$ 中，長度為 $k_2$ 的子陣列和的最大值（後綴最佳）。
- 答案 $= \max_i (\mathrm{bestL}[i] + \mathrm{bestR}[i])$。

**形態三（前綴和 + 貪心）**：
- 通常先按某個鍵排序（1788 按位置、2542 按 `nums2` 降序），再用前綴和或堆維護「取 $k$ 個的最佳和」。

## 不變量或正確性證明

**形態一的正確性依賴「前綴和單調」。**

*引理。* 若所有 $a_i \ge 0$ 且已排序遞增，則 $s$ 非嚴格遞增，且**取前 $m$ 小的元素是所有大小為 $m$ 的子集中和最小者**。

*證明（交換論證）。* 設 $T$ 是任一大小為 $m$ 的下標集合，且 $T \ne \{0,1,\dots,m-1\}$。則存在 $j \in T$、$i \notin T$ 且 $i < j$（否則 $T$ 就是前 $m$ 個）。把 $j$ 換成 $i$，因 $a_i \le a_j$，總和不增。有限次交換後 $T$ 變成前 $m$ 個，故前 $m$ 個的和最小。$\square$

*推論*：「和 $\le q$ 時最多能取幾個」的答案是最大的 $m$ 使 $s_m \le q$，可二分。**這裡用了兩個前提：元素非負（保證 $s$ 單調，二分才有意義）、可任意選取（子序列題，不是子陣列題）。** 若題目要求**連續**子陣列，前 $m$ 小就不合法，這條論證失效——那要改用滑動視窗或 2.2。

**2300（咒語與藥水）的單調性。** 對每個 spell $x$，需要 potion $y$ 滿足 $x \cdot y \ge \mathrm{success}$，即 $y \ge \lceil \mathrm{success}/x \rceil$。排序 potions 後用 `lower_bound`。**除法向上取整必須寫成 `(success + x - 1) / x`**（在 `long long` 下），寫成 `success / x` 會少算邊界；用浮點 `ceil(success / (double)x)` 在 $10^{10}$ 量級會有精度誤差。**這是一個「整數運算的正確性細節」，與前綴和無關但同樣是失分點。**

**形態二的不重不漏（1031）。** 要選兩個**不重疊**的子陣列，長度分別為 $f$ 與 $s$。任兩個不重疊區間必有先後，故存在分界點 $i$ 使一個完全落在 $[0,i)$、另一個完全落在 $[i,n)$。

*不漏*：對任一組合法解，取「左邊那段的右端點 + 1」當 $i$，它會被枚舉到。
*不重*：可能同一組解對應多個 $i$，但因為取的是 $\max$，重複不影響答案。
*順序*：兩段的長度不同，**必須把 $(f,s)$ 與 $(s,f)$ 兩種順序都算一遍**——這是最常漏的一半。

**$\mathrm{bestL}$ 的遞推。** $\mathrm{bestL}[i] = \max(\mathrm{bestL}[i-1],\; s_i - s_{i-f})$（$i \ge f$）。這是「前綴最大值」的標準遞推，正確性來自 $\max$ 的結合律。**注意這裡不是前綴和相減，而是對「所有可能的定長區間和」取前綴 $\max$——$\max$ 沒有逆元，只能單向累積，不能相減。** 這正好呼應 2.1 提到的限制。

**2555（兩條線段獲得最多獎品）的變體。** 兩條長度為 $k$ 的線段，用雙指標算出「以 $i$ 為右端點的線段能覆蓋多少獎品」，再對它取前綴最大值，最後枚舉分界。**與 1031 同構，只是「長度」是座標長度而非元素個數，要用 `upper_bound` 找左端點。**

**1788（最大化花園的美觀值）的前綴和用法。** 要選同種花當首尾，中間可以砍掉負數。對每種花，取最左與最右出現位置 $l, r$，答案 = $2 \cdot a_l + (\text{區間 } (l, r) \text{ 內所有正數之和})$。「區間內正數之和」用**只累加正數的前綴和**：$p_i = \sum_{t<i} \max(a_t, 0)$。**把「取正部」寫進前綴和的定義，是本節最常用的一招——它讓「可以自由丟棄不利元素」這個自由度變成 $O(1)$ 可算。**

還要處理「首尾兩朵花本身是負數」的情形：它們必須保留（題目要求首尾同種且都算進去），所以 $2a_l$ 即使是負也要加。**別把「取正部」的優化誤套到強制保留的元素上。**

## C++17 模板

```cpp
// 和有限的最長子序列（LeetCode 2389）：排序 + 前綴和 + 二分。
class Solution {
public:
    std::vector<int> answerQueries(std::vector<int>& nums,
                                   std::vector<int>& queries) {
        std::sort(nums.begin(), nums.end());  // 前 m 小的和最小（交換論證）
        int n = nums.size();
        std::vector<long long> s(n + 1, 0);
        for (int i = 0; i < n; ++i) {
            s[i + 1] = s[i] + nums[i];
        }

        std::vector<int> ans;
        ans.reserve(queries.size());
        for (int q : queries) {
            // 最大的 m 使 s[m] <= q；s 遞增，可二分
            int m = std::upper_bound(s.begin(), s.end(),
                                     static_cast<long long>(q)) -
                    s.begin() - 1;
            ans.push_back(m);
        }
        return ans;
    }
};
```

```cpp
// 兩個無重疊子陣列的最大和（LeetCode 1031）：枚舉分界，左右各取最佳。
class Solution {
    // 固定「長度 f 的那段在左、長度 sLen 的那段在右」時的最大和
    static int solve(const std::vector<long long>& p, int f, int sLen) {
        int n = p.size() - 1;
        int best = 0;
        long long bestLeft = 0;  // [0, i) 中長度 f 的最大段和
        // i 是分界：左段結束於 i，右段從 i 開始
        for (int i = f; i + sLen <= n; ++i) {
            bestLeft = std::max(bestLeft, p[i] - p[i - f]);  // 前綴最大值遞推
            long long cur = bestLeft + (p[i + sLen] - p[i]);
            best = std::max<long long>(best, cur);
        }
        return best;
    }

public:
    int maxSumTwoNoOverlap(std::vector<int>& nums, int firstLen,
                           int secondLen) {
        int n = nums.size();
        std::vector<long long> p(n + 1, 0);
        for (int i = 0; i < n; ++i) {
            p[i + 1] = p[i] + nums[i];
        }
        // 兩種先後順序都要試，漏掉一半是最常見的錯誤
        return std::max(solve(p, firstLen, secondLen),
                        solve(p, secondLen, firstLen));
    }
};
```

## 時間與空間複雜度

**形態一**：排序 $O(n \log n)$ + 前綴和 $O(n)$ + 每個查詢 $O(\log n)$，總計 $O((n + q)\log n)$。空間 $O(n)$。

**形態二**：前綴和 $O(n)$，枚舉分界 $O(n)$（`bestLeft` 是滾動變數，$O(1)$ 空間），兩種順序各跑一次仍是 $O(n)$。**總計 $O(n)$ 時間、$O(n)$ 空間**（只有前綴和陣列）。

若推廣到「$k$ 段不重疊定長子陣列」（689 是 $k=3$），就變成 DP：$\mathrm{dp}[j][i]$ = 前 $i$ 個元素選 $j$ 段的最大和，$O(kn)$。**$k = 2$ 時手寫兩種順序還可以；$k \ge 3$ 一律轉 DP，否則排列數爆炸。**

**形態三**：排序主導，$O(n \log n)$。

與暴力的落差：2389 暴力是 $O(qn \log n)$（每個查詢重排），本節是 $O((n+q)\log n)$；1031 暴力枚舉兩段是 $O(n^2)$，本節 $O(n)$。

## 常見錯誤與邊界條件

- 1031 只算一種先後順序（漏掉一半的解）。
- `bestLeft` 初值設 0 但元素可能全負（本題約束 $\mathrm{nums}[i] \ge 0$ 所以安全，**換一題就要改成 `LLONG_MIN` 並小心加法溢位**）。
- 枚舉分界的迴圈範圍 `i >= f && i + sLen <= n` 寫錯導致越界或漏解。
- 2389 的 `upper_bound` 忘記減 1（回傳的是「第一個 $> q$ 的位置」，即「$\le q$ 的個數」，而 $s$ 有 $n+1$ 項含 $s_0$，所以減 1 才是元素個數）。
- 2389 把 `q` 隱式當 `int` 與 `long long` 比較（型別不一致時 `upper_bound` 的比較器會出錯，要顯式轉型）。
- 2300 的向上取整用浮點（精度）或寫成 `success / x`（少算）。
- 2300 的乘積 `x * y` 用 `int` 溢位。
- 對**連續**子陣列套用「取前 $m$ 小」的交換論證（前提是可任意選取）。
- 元素有負數時仍假設前綴和單調而去二分。
- 1788 把強制保留的首尾也套「取正部」。
- 1788 只考慮相鄰同種花而非最左最右（不是最優）。
- 前綴和一律 `long long`。

## 與相似技巧的比較

- **與 2.1／2.2**：本節不新增資料結構，只是把前綴和當成「$O(1)$ 取一段」的原語，接上二分、前綴最大值、堆。**先確認 2.1 的三個前提（不變、有逆元、不溢位）成立，再談本節。**
- **與 1.3 列舉中間**：形態二就是 1.3，只是左右摘要換成「定長區間和的前綴最大值」。
- **與 binary_search 主題**：形態一的二分是「在單調序列上找分界」，屬於最基本的二分；若題目要二分**答案**（如「最小化最大值」），那是另一回事，別混。
- **與滑動視窗**：「和不超過 $k$ 的最長**連續**子陣列」（元素非負）用滑動視窗 $O(n)$，比排序 + 二分快且不需額外空間。**連續 → 滑動視窗；可任選 → 排序 + 前綴和 + 二分。** 這是形態一最重要的判準。
- **與 DP**：$k \ge 3$ 段不重疊的問題必須轉 DP（689、1911）。**手寫排列組合只在 $k = 2$ 時划算。**
- **與 6.x 堆**：「取 $k$ 個使某量最大」若還帶另一維約束（2542 最大子序列的分數），前綴和不夠，要配上小根堆維護「當前選中的 $k$ 個中最小的」。

## 本節重點速查

- 前綴和在這一節的角色是**原語**：把「一段的量」壓成 $O(1)$，讓外層能換成二分／前綴最大值／堆。
- **形態一（排序 + 二分）**：非負 + 可任選 ⇒ 前 $m$ 小的和最小（交換論證），$s$ 單調，`upper_bound` 一步到位。**連續子陣列不適用，改滑動視窗。**
- **形態二（枚舉分界）**：兩段不重疊 ⇒ 必有先後 ⇒ 枚舉分界點，左右各取最佳。**兩種先後順序都要算**，$k \ge 3$ 轉 DP。
- $\mathrm{bestL}$ 用「前綴最大值遞推」而非相減——$\max$ 沒有逆元。
- 「可自由丟棄不利元素」→ 把 $\max(a_t, 0)$ 寫進前綴和的定義（1788）；但**強制保留的元素不適用**。
- 向上取整寫 `(a + b - 1) / b`，不要用浮點。
- 前綴和、乘積一律 `long long`。
