## 這個技術解決什麼問題

3.1.1 的一維差分把「區間加值」壓成兩次單點修改。二維差分做同一件事：**把「子矩形整體加 $v$」壓成四次單點修改**，最後做一次二維前綴和還原。

暴力是每筆操作逐格加：$q$ 筆操作、矩形面積 $A$，$O(qA)$。2536（子矩陣元素加 1）有 $n \le 500$、$q \le 10^4$，最壞 $10^4 \times 2.5\times10^5 = 2.5\times10^9$，超時。二維差分是 $O(q + mn)$。

它與 2.6 二維前綴和恰好對偶，而且**同一題常常兩個都要用**：2132（用郵票貼滿網格圖）用二維前綴和判斷「這個 $h\times w$ 視窗是不是全空」，用二維差分記錄「哪些格子被貼到」。**看到「先問能不能放、再記錄放了哪些」的雙層結構，就是這一對搭檔。**

## 狀態／資料結構定義

**定義。** 對 $m \times n$ 的目標矩陣 $a$（初始全 0），維護差分矩陣 $d$，大小 $(m+1) \times (n+1)$。

**子矩形加值** $[r_1, r_2] \times [c_1, c_2] \mathrel{+}= v$：
$$d[r_1][c_1] \mathrel{+}= v,\quad d[r_1][c_2{+}1] \mathrel{-}= v,\quad d[r_2{+}1][c_1] \mathrel{-}= v,\quad d[r_2{+}1][c_2{+}1] \mathrel{+}= v.$$

**還原**：對 $d$ 做一次二維前綴和（可原地）：
$$a[i][j] \;=\; \sum_{r \le i}\sum_{c \le j} d[r][c].$$

**四個角落的符號是 $+,-,-,+$**，與 2.6 的**查詢**公式（$-,-,+$ 加上主項）同形。這不是巧合，下一節會證明兩者是同一個張量積結構。

**尺寸必須是 $(m+1)\times(n+1)$**，因為 $r_2$ 可到 $m-1$、$c_2$ 可到 $n-1$，於是 $d[m][\cdot]$ 與 $d[\cdot][n]$ 要有地方放。**多開的那一列一行是垃圾桶，還原時不讀它們**——和一維一樣，這是為了省掉 `if (r2 + 1 < m)` 這種特判。

**座標很大時要離散化。** 850（矩形面積 II）與 LCP 74（最強祝福力場）的座標到 $10^9$，做法是：收集所有出現過的 $x$、$y$ 座標去重排序，在壓縮後的網格上做二維差分，最後把每個網格單元的面積 $(\Delta x)(\Delta y)$ 按「覆蓋次數是否 $> 0$」加總。LCP 74 的邊界會落在半整數（力場邊長是奇數時中心在格點，邊界在 $\pm 0.5$），**標準處理是把所有座標乘 2 化成整數，全程避免浮點比較。**

## 不變量或正確性證明

**主不變量。** 任意一串子矩形加值之後，恆有 $a[i][j] = \sum_{r\le i}\sum_{c\le j} d[r][c]$。

*證明。* 對操作次數歸納。基底顯然。歸納步：一筆 $[r_1,r_2]\times[c_1,c_2] \mathrel{+}= v$ 讓真實值改變 $v \cdot \big[\,r_1 \le i \le r_2\,\big]\cdot\big[\,c_1 \le j \le c_2\,\big]$。另一方面，四個脈衝對 $\sum_{r\le i}\sum_{c\le j}$ 的貢獻是
$$v\Big([\,r_1\le i\,] - [\,r_2{+}1\le i\,]\Big)\Big([\,c_1\le j\,] - [\,c_2{+}1\le j\,]\Big),$$
因為四項 $(+,-,-,+)$ 恰好是把上式展開。而 $[\,r_1\le i\,]-[\,r_2{+}1\le i\,] = [\,r_1\le i\le r_2\,]$（一維差分的恆等式，見 3.1.1），兩維各一次，乘起來正是矩形指示函數。$\square$

**這個證明說出了二維差分的真正身分：它是兩個一維差分的張量積。**

$$\underbrace{(\,+1 \text{ at } r_1,\ -1 \text{ at } r_2{+}1\,)}_{\text{列方向的一維差分}} \;\otimes\; \underbrace{(\,+1 \text{ at } c_1,\ -1 \text{ at } c_2{+}1\,)}_{\text{行方向的一維差分}}$$

四個角落 = $2 \times 2$ 個乘積項，符號 = 兩個符號相乘。**這也立刻給出 $d$ 維推廣：$2^d$ 個角落，符號是 $(-1)^{\text{取到 }+1\text{ 偏移的維度數}}$。** 不必再背公式。

**張量積結構點名了它依賴的前提：加值區域必須是「區間的直積」，也就是軸對齊矩形。**

若要對**對角帶狀區域**、**圓形**、或**任意多邊形**整體加值，區域不可分解成 $I \times J$，四角落法徹底失效。可行的替代：對角帶狀可以先做 1.4 的座標變換 $(r-c, r+c)$ 把它變回矩形；一般多邊形則要用掃描線逐列處理，退化成 $m$ 次一維差分（$O(m + q\cdot m)$）。**「能不能寫成直積」是使用二維差分的唯一入場券。**

**另外三個前提沿用 3.1.1，一字不改**：操作必須可疊加（**子矩形賦值不行**，要二維線段樹或 KD 樹）；值必須有逆元；操作與查詢必須分階段（中途要查就得用二維樹狀陣列，$O(\log m\log n)$）。

**還原可以原地做的理由。** 二維前綴和的遞推 $d[i][j] \mathrel{+}= d[i-1][j] + d[i][j-1] - d[i-1][j-1]$，在 $i$、$j$ 皆遞增的掃描順序下，讀到的三個鄰居**都已經是前綴和形式**，而寫入的 $d[i][j]$ 之後不會再被當成原始差分讀取。**順序正確性就是這條「只讀已完成、只寫未來不再需要原值的格子」的觀察**——與 DP 滾動陣列的更新順序論證同構。

**2132（用郵票貼滿網格圖）的貪心最優性。**

*宣稱*：把郵票貼在**每一個貼得下的位置**（該 $h\times w$ 視窗內全為空），若仍有空格未被覆蓋，則答案為否。

*證明。* 設存在一組合法貼法 $P$ 覆蓋了所有空格。$P$ 中每張郵票的位置都必然是「貼得下的位置」（否則會壓到障礙物，不合法），所以 $P \subseteq$ 全體可貼位置 $P^*$。覆蓋是單調的：$P \subseteq P^*$ ⇒ $P$ 覆蓋的格子 $\subseteq$ $P^*$ 覆蓋的格子。故若 $P$ 能全覆蓋，$P^*$ 必也能。反之若 $P^*$ 覆蓋不全，任何 $P$ 都不行。$\square$

**這條論證依賴兩個前提：郵票可以互相重疊、且郵票數量沒有上限。** 少了任一個，「多貼不會更差」就不成立——若限制最多貼 $k$ 張，這就變成集合覆蓋（NP-hard）；若不許重疊，就變成精確覆蓋。**題目那句不起眼的「郵票可以重疊」是整個貪心的地基。**

**850（矩形面積 II）為什麼不能直接把覆蓋次數當權重。** 離散化後每個網格單元 $[x_k, x_{k+1}) \times [y_l, y_{l+1})$ 的覆蓋次數 $c_{kl}$ 可能 $> 1$，但**聯集面積**只計一次。所以要加總的是
$$\sum_{k,l} [\,c_{kl} > 0\,]\cdot (x_{k+1}-x_k)(y_{l+1}-y_l),$$
不是 $\sum c_{kl}\cdot(\dots)$。**差分只負責高效算出 $c$，「聯集」這個語意要在最後那一步用 $[\,c>0\,]$ 表達。** 這是離散化 + 差分最常見的概念錯誤。

*離散化的閉開約定*：矩形 $[x_1,x_2)\times[y_1,y_2)$（面積題天然是半開）對應的網格單元下標範圍是 $[\,\mathrm{idx}(x_1),\ \mathrm{idx}(x_2)-1\,]$。**這裡不能再 $+1$**——半開區間的右端點本身不屬於區域。與 3.1.2 引理 2 是同一個「開閉語意決定端點」的問題，只是換到二維。

## C++17 模板

```cpp
// 二維差分的通用封裝：多次子矩形加值，最後一次還原。
class Diff2D {
    int m_, n_;
    std::vector<std::vector<long long>>
        d_;  // (m+1) x (n+1)，多開的一列一行是垃圾桶

public:
    Diff2D(int m, int n)
        : m_(m), n_(n), d_(m + 1, std::vector<long long>(n + 1, 0)) {}

    // 閉區間 [r1, r2] x [c1, c2] 整體加 v；四個角落符號 +,-,-,+
    void add(int r1, int c1, int r2, int c2, long long v) {
        d_[r1][c1] += v;
        d_[r1][c2 + 1] -= v;
        d_[r2 + 1][c1] -= v;
        d_[r2 + 1][c2 + 1] += v;
    }

    // 原地二維前綴和還原；回傳 m x n 的結果視圖（讀 d_[i][j], i < m, j < n）
    const std::vector<std::vector<long long>>& build() {
        for (int i = 0; i < m_; ++i) {
            for (int j = 0; j < n_; ++j) {
                long long up = i ? d_[i - 1][j] : 0;
                long long left = j ? d_[i][j - 1] : 0;
                long long ul = (i && j) ? d_[i - 1][j - 1] : 0;
                d_[i][j] += up + left - ul;  // 讀到的鄰居都已是前綴和，故可原地
            }
        }
        return d_;
    }
};

// 子矩陣元素加 1（LeetCode 2536）
class Solution {
public:
    std::vector<std::vector<int>> rangeAddQueries(
        int n, std::vector<std::vector<int>>& queries) {
        Diff2D diff(n, n);
        for (const auto& q : queries) {
            diff.add(q[0], q[1], q[2], q[3], 1);
        }
        const auto& g = diff.build();

        std::vector<std::vector<int>> ans(n, std::vector<int>(n));
        for (int i = 0; i < n; ++i) {
            for (int j = 0; j < n; ++j) {
                ans[i][j] = static_cast<int>(g[i][j]);
            }
        }
        return ans;
    }
};
```

```cpp
// 用郵票貼滿網格圖（LeetCode 2132）：二維前綴和判定 + 二維差分記錄。
class Solution {
public:
    bool possibleToStamp(std::vector<std::vector<int>>& grid, int h, int w) {
        int m = grid.size(), n = grid[0].size();

        // (1) 二維前綴和：O(1) 判斷 h x w 視窗是否全空
        std::vector<std::vector<int>> s(m + 1, std::vector<int>(n + 1, 0));
        for (int i = 0; i < m; ++i) {
            for (int j = 0; j < n; ++j) {
                s[i + 1][j + 1] =
                    s[i][j + 1] + s[i + 1][j] - s[i][j] + grid[i][j];
            }
        }

        // (2) 二維差分：貼得下就貼（重疊無害，見貪心證明）
        std::vector<std::vector<int>> d(m + 1, std::vector<int>(n + 1, 0));
        for (int i = 0; i + h <= m; ++i) {
            for (int j = 0; j + w <= n; ++j) {
                int r2 = i + h - 1, c2 = j + w - 1;
                int occupied =
                    s[r2 + 1][c2 + 1] - s[i][c2 + 1] - s[r2 + 1][j] + s[i][j];
                if (occupied == 0) {
                    d[i][j] += 1;
                    d[i][c2 + 1] -= 1;
                    d[r2 + 1][j] -= 1;
                    d[r2 + 1][c2 + 1] += 1;
                }
            }
        }

        // (3) 原地還原覆蓋次數，順便檢查每個空格是否被蓋到
        for (int i = 0; i < m; ++i) {
            for (int j = 0; j < n; ++j) {
                int up = i ? d[i - 1][j] : 0;
                int left = j ? d[i][j - 1] : 0;
                int ul = (i && j) ? d[i - 1][j - 1] : 0;
                d[i][j] += up + left - ul;
                if (grid[i][j] == 0 && d[i][j] == 0) {
                    return false;
                }
            }
        }
        return true;
    }
};
```

## 時間與空間複雜度

**建構**：$q$ 筆操作各 $O(1)$（四次寫入），共 $O(q)$。**還原**：一次二維前綴和 $O(mn)$。**總計 $O(mn + q)$ 時間、$O(mn)$ 空間。**

與暴力 $O(qA)$ 的落差：2536 從 $2.5\times10^9$ 降到 $2.6\times10^5$。

**2132**：前綴和 $O(mn)$ + 枚舉所有貼法 $O(mn)$（每個位置 $O(1)$ 判定）+ 還原 $O(mn)$ = $O(mn)$。

**850（離散化版）**：座標數 $O(n)$，網格 $O(n^2)$ 個單元，差分 $O(n)$ 次操作 + $O(n^2)$ 還原 = $O(n^2)$。$n \le 200$ 時 $4\times10^4$，輕鬆。**若 $n$ 到 $10^5$，$O(n^2)$ 就不行了，必須改「掃描線 + 線段樹」的 $O(n\log n)$**——那時第二維無法靠排序解決，只能上資料結構。

**$d$ 維推廣**：每次操作 $O(2^d)$，還原 $O(d \cdot N)$（逐維做一維前綴和），$N$ 是總格數。**$d \ge 4$ 時建議用「逐維前綴和」的寫法，不要手寫 $2^d$ 個角落——符號一定會抄錯。**

## 常見錯誤與邊界條件

- 四個角落的符號抄錯（正確是 $+,-,-,+$；**忘記最後那個 $+v$ 是最常見的**，症狀是右下方整片多加了 $v$）。
- 矩陣開成 $m\times n$ 而非 $(m+1)\times(n+1)$，`d[r2+1][c2+1]` 越界。
- 還原時把掃描順序寫成遞減（原地前綴和只在遞增順序下正確）。
- 還原時讀到未還原的邊界列行（迴圈範圍應是 $i<m,\ j<n$，垃圾桶那一列一行不參與）。
- 閉區間與半開區間混用——**離散化後的面積題是半開，右端點對應 `idx(x2) - 1`，不要再 $+1$**。
- 850 把覆蓋次數當權重累加（應該用 $[\,c>0\,]$）。
- 850 忘記座標去重（重複座標會產生寬度為 0 的單元，雖不影響面積但會浪費時間，且容易寫出 `idx` 錯位）。
- 850 的面積用 `int`（$10^9 \times 10^9$ 必爆，**且中途取模前要先用 `long long`**）。
- LCP 74 用浮點座標比較（應乘 2 化整數）。
- LCP 74 的力場邊界搞混（邊長 $s$、中心 $(x,y)$ 時範圍是 $[x - s/2,\ x + s/2]$，乘 2 後是 $[2x - s,\ 2x + s]$）。
- 2132 忘記「郵票不能壓到障礙物」而無條件貼。
- 2132 的視窗枚舉範圍寫成 `i < m` 而非 `i + h <= m`。
- 對非矩形區域套用四角落法（**張量積前提不成立**）。
- 子矩形**賦值**用差分（不成立，要線段樹）。

## 與相似技巧的比較

- **與 3.1.1 一維差分**：張量積關係。一維兩個端點、二維四個角落、$d$ 維 $2^d$ 個角落，符號是各維符號的乘積。**理解張量積就不必分別記憶。**
- **與 2.6 二維前綴和**：嚴格互逆。**二維前綴和 = 建好不動、多次查矩形和；二維差分 = 多次改矩形、最後查一次。** 2132 同時用到兩者，因為它既要查詢（能不能貼）又要修改（貼了哪裡）。
- **與二維樹狀陣列**：支援「矩形加、單點查」（對差分矩陣建二維 BIT）或「單點加、矩形和查」，$O(\log m\log n)$。**只有在修改與查詢真的交錯時才值得。**
- **與掃描線 + 線段樹（850 的進階解）**：當一個維度的規模大到不能離散化成 $O(n^2)$ 網格時，把 $x$ 軸當時間掃描、$y$ 軸用線段樹維護「當前被覆蓋的總長度」。**二維差分的稀疏化不像一維那麼便宜——一維的稀疏版只要排序，二維的稀疏版需要一棵樹。這是維度的真實代價。**
- **與 1.4 遍歷對角線**：若加值區域是對角帶狀，先用 $(r-c,\ r+c)$ 變換把它轉成矩形，再套本節。**變換的前提是矩陣為矩形（凸），與 1.4 那條引理相同。**

## 本節重點速查

- 子矩形 $[r_1,r_2]\times[c_1,c_2]$ 加 $v$ ⇒ 四個角落 `d[r1][c1] += v; d[r1][c2+1] -= v; d[r2+1][c1] -= v; d[r2+1][c2+1] += v;`（$+,-,-,+$）。
- **二維差分 = 兩個一維差分的張量積**；$d$ 維就是 $2^d$ 個角落，符號 = 各維符號相乘。
- 矩陣開 $(m+1)\times(n+1)$；還原用**原地二維前綴和**，$i,j$ 皆遞增。
- 入場券是「加值區域可寫成區間直積（軸對齊矩形）」——對角帶狀先做 $(r-c, r+c)$ 變換，一般多邊形只能逐列一維差分。
- 沿用 3.1.1 的三個前提：**可疊加**（賦值不行）、**有逆元**、**修改與查詢分階段**。
- 2132 = 二維前綴和判定 + 二維差分記錄；貪心「貼滿所有可貼位置」的前提是**郵票可重疊且數量無限**。
- 850 離散化後要用 $[\,c>0\,]$ 而非 $c$ 當權重；半開區間的右端是 `idx(x2) - 1`；面積用 `long long`。
- LCP 74 的半整數邊界一律**乘 2 化整數**。
- 二維的稀疏化要靠掃描線 + 線段樹，不像一維只要排序。
