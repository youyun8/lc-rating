## 這個技術解決什麼問題

題目只要**某一個排名的值**（第 $K$ 小 / 第 $K$ 大 / 前 $K$ 個），而候選總數遠大於 $K$——甚至是指數級（2386 的所有子序列和有 $2^n$ 個）。**全部生成再排序既慢又放不下。**

兩條主線：

- **按需生成 + 堆**：候選之間有「下一個」的關係，彈出一個就推入它的後繼。適用於 23、264（醜數 II）、373（查詢和最小的 K 對數字）、378（有序矩陣中第 K 小）、1439、2386。複雜度 $O(K\log K)$ 級，**與候選總數無關**。
- **對「值」二分 + 計數**：若能快速算出「$\le x$ 的候選有幾個」，就對答案二分。適用於 378、786、1439、2386。複雜度 $O(n\log C)$ 級，**與 $K$ 無關**。

**選型判準**：**$K$ 小用堆，$K$ 大（接近候選總數）用二分。** 兩者在 378 上分別是 $O(K\log n)$ 與 $O(n\log C)$，$K$ 可到 $n^2$ 時二分完勝。

**另有第三條路**：靜態陣列、單次查詢第 $K$ 小 ⇒ `nth_element`（期望 $O(n)$）。**別在該用 `nth_element` 的地方堆一個堆。**

## 狀態／資料結構定義

### (A) 前緣堆（frontier heap）

把候選集合看成一個**偏序集**，堆中存的是「已彈出集合的邊界」。

**373（查詢和最小的 K 對數字）**：候選是下標對 $(i,j)$，值 $= \textit{nums1}[i] + \textit{nums2}[j]$，兩陣列皆升冪。
$$(i,j) \preceq (i',j') \iff i \le i' \ \wedge\ j \le j' .$$
**值沿 $\preceq$ 單調不減**——這是全部推理的基礎。

```cpp
priority_queue<array<long long, 3>, vector<array<long long, 3>>, greater<>>
    pq;  // (sum, i, j)
pq.push({(long long)nums1[0] + nums2[0], 0, 0});
// 彈出 (i,j) 時：一律 push (i, j+1)；只有 j == 0 時才 push (i+1, j)
```

**「$j = 0$ 才往下走」這條規則不是效率技巧，是去重機制**（定理 2）。另一種寫法是無條件推入兩個後繼並用 `unordered_set` 去重——**能用結構去重就別用雜湊表，省一個常數大的容器**。

**378（有序矩陣中第 K 小）**：把每一列當成一條升冪串列，初始推入前 $\min(k, n)$ 列的第 0 個元素，彈出 $(i,j)$ 後推入 $(i, j+1)$。**初始只需 $\min(k,n)$ 列**——第 $k$ 小不可能來自第 $k+1$ 列以後（每列的首元素已經佔掉一個名額）。

### (B) 二分 + 計數

```cpp
long long lo = 最小可能值, hi = 最大可能值;
while (lo < hi) {
    long long mid = lo + (hi - lo) / 2;  // 注意負數時用 floor_div
    if (count_le(mid) >= k)
        hi = mid;
    else
        lo = mid + 1;
}
return lo;
```
**狀態只有 `lo`／`hi`，難點全在 `count_le` 怎麼寫成 $O(n)$。**

**378 的 `count_le(x)` 走階梯**：從左下角 $(n-1, 0)$ 出發，`matrix[r][c] <= x` 就 `cnt += r+1; ++c;`，否則 `--r`。**不變量：任一時刻，第 $c$ 欄以左、第 $r$ 列以下的元素都已計入，且沒有重複計入。** 每步 $r$ 減或 $c$ 增，總步數 $\le 2n$。

## 不變量或正確性證明

### 定理 1（前緣堆的主不變量）

令 $P$ 為候選的偏序集，值函數 $f$ 沿 $\preceq$ 單調不減。令 $D$ 為已彈出的元素集合。

*不變量 (I)*：
1. **$D$ 是一個下閉集（down-set）**：若 $y \in D$ 且 $x \preceq y$，則 $x \in D$。
2. **$P \setminus D$ 的每個極小元都在堆中**，且堆 $\subseteq P\setminus D$。

*定理*：在 (I) 之下，**第 $t$ 次彈出的元素就是 $f$ 的第 $t$ 小值**（重複值按任意固定順序）。

*證明*。只需證每次彈出的都是 $P\setminus D$ 中 $f$ 最小者。
- $\min_{x \in P\setminus D} f(x)$ 必在某個**極小元**上取到：設 $x$ 達到最小值，若 $x$ 不極小，存在 $x' \prec x$ 且 $x' \in P \setminus D$（由 (I).1，$D$ 下閉，$x \notin D$ 不保證 $x' \notin D$⋯ 反過來：若 $x' \in D$ 也無妨，我們沿 $\prec$ 往下走，最終會停在一個 $P\setminus D$ 的極小元 $x''$，且由單調性 $f(x'') \le f(x)$）。
- 由 (I).2，該極小元在堆中；由堆 $\subseteq P\setminus D$，堆頂 $\ge \min_{P\setminus D} f$。兩者夾擠得堆頂 $= \min_{P\setminus D} f$。$\square$

**這個證明點名了唯一的前提：$f$ 沿偏序單調不減。** 373 靠「兩陣列皆升冪」，378 靠「每列升冪」，2386 靠「取絕對值後升冪排序」。**任何一題若值不單調，前緣堆立刻失效。**

### 定理 2（373 的去重規則：每個候選恰生成一次）

推入規則：初始 $(0,0)$；彈出 $(i,j)$ 時推入 $(i, j+1)$（若合法），並在 $j = 0$ 時推入 $(i+1, 0)$（若合法）。

*宣稱*：每個 $(i,j)$ 恰被推入一次。
*證明*：
- $(0,0)$：只在初始化時推入。
- $(i, j)$ 且 $j > 0$：只可能由 $(i, j-1)$ 的第一條規則產生（第二條規則只產生 $j=0$ 的元素）。而 $(i,j-1)$ 只被彈出一次。
- $(i, 0)$ 且 $i > 0$：只可能由 $(i-1, 0)$ 的第二條規則產生。$\square$

*宣稱（覆蓋性，即 (I).2）*：若 $(i,j)$ 是 $P\setminus D$ 的極小元，則它在堆中。
*證明*：極小表示它的所有直接前驅（$(i-1,j)$、$(i,j-1)$，存在者）都在 $D$ 中。
- $j > 0$：$(i, j-1) \in D$ 已被彈出 ⇒ 已推入 $(i,j)$ ✔。
- $j = 0,\ i > 0$：$(i-1, 0) \in D$ ⇒ 已推入 $(i, 0)$ ✔。
- $(0,0)$：初始已推入 ✔。$\square$

**堆的大小上界**：任一時刻堆中至多 $O(\min(K, n))$ 個元素（每彈出一個最多推入兩個，但推入 $(i+1,0)$ 只在 $j=0$ 時發生，故第一欄最多貢獻 $n$ 個）。**所以複雜度是 $O(K\log \min(K,n))$，不是 $O(K \log K)$。**

### 定理 3（二分答案：單調性與「答案必為實際元素」）

令 $C(x) = |\{\text{候選} \le x\}|$。

*引理 1（單調）*：$C$ 對 $x$ 單調不減。故 $\{x : C(x) \ge k\}$ 是一個上閉的射線，**可以二分**。

*引理 2*：令 $x^{*} = \min\{x \in \mathbb{Z} : C(x) \ge k\}$，則 **$x^{*}$ 一定是某個實際存在的候選值**，且就是第 $k$ 小。
*證明*：若 $x^{*}$ 不是任何候選的值，則沒有候選落在 $(x^{*}-1, x^{*}]$，故 $C(x^{*}-1) = C(x^{*}) \ge k$，與 $x^{*}$ 的最小性矛盾。$\square$

**引理 2 用到的前提是「候選取值為整數」**（或更一般地：在一個可枚舉的離散集合上）。**若候選是實數（例如 786 的分數），就不能對整數二分**——要嘛對分數的實數值做固定輪數的浮點二分（有精度風險），要嘛改用「對分數 $p/q$ 二分」的 Stern–Brocot 式做法，或直接用前緣堆。**786 的推薦寫法是二分 + 雙指標計數，同時記錄達到計數上界的那一對分數本身**，這樣回傳的一定是實際存在的分數，避開精度問題。

*引理 3（786 的計數）*：對固定 $x$，計算 $|\{(i,j) : i<j,\ p_i/p_j \le x\}|$。因 $p$ 升冪，對每個 $j$，滿足 $p_i \le x\, p_j$ 的 $i$ 構成前綴，且該前綴長度隨 $j$ **單調不減**（$x p_j$ 遞增）⇒ 雙指標一次掃描 $O(n)$。**「單調不減」正是雙指標成立的條件，必須明確驗證。**

### 定理 4（2386 第 K 大子序列和：化歸為「非負子集和的第 K 小」）

令 $S = \sum_{a_i > 0} a_i$（所有正數之和，也就是最大子序列和）。

*引理（雙射）*：對任意子集 $A \subseteq [n]$，
$$\mathrm{sum}(A) \;=\; S \;-\; \sum_{i \in B} |a_i|, \qquad B \;=\; \{i : a_i > 0,\ i \notin A\} \;\cup\; \{i : a_i < 0,\ i \in A\} .$$
*證明*：$\mathrm{sum}(A) = \sum_{i\in A, a_i>0} a_i + \sum_{i \in A, a_i<0} a_i = \left(S - \sum_{i\notin A, a_i>0} a_i\right) - \sum_{i\in A, a_i<0}|a_i|$。$\square$

*映射 $A \mapsto B$ 是雙射*（對每個下標，$A$ 是否含它與 $B$ 是否含它一一對應：正數取反、負數同步）。

*推論*：**第 $k$ 大的 $\mathrm{sum}(A)$ $= S - $（第 $k$ 小的 $\sum_{i\in B}|a_i|$，取遍所有 $2^n$ 個子集 $B$）。**

於是問題變成：給定非負陣列 $b_i = |a_i|$，求所有子集和中第 $k$ 小者。**這個新問題的候選值域是非負的、且空集合的和 $0$ 是最小者**——結構好得多。

*前緣堆生成*：把 $b$ 升冪排序。堆中存 $(\text{和}, \text{最後選用的下標})$。初始 $(b_0, 0)$；彈出 $(s, i)$ 後推入 $(s + b_{i+1},\ i+1)$（加一個）與 $(s - b_i + b_{i+1},\ i+1)$（換掉最後一個）。**這兩條規則恰好把「以 $i$ 結尾的子集」擴展成「以 $i+1$ 結尾的子集」，且每個非空子集只由它的「去掉最大下標」或「把最大下標往前換」唯一產生。** 彈出 $k-1$ 次即得（第 1 小是空集的 $0$，不在堆中，要另外計入）。

**這一題把「指數級候選」壓成 $O(k\log k)$，靠的完全是定理 1 的單調性 + 一個巧妙的雙射。** 沒有雙射，負數會破壞單調性，前緣堆用不了。

### 定理 5（264 醜數 II：三指標的去重）

$\mathrm{dp}[0]=1$，$\mathrm{dp}[i] = \min(2\,\mathrm{dp}[p_2],\ 3\,\mathrm{dp}[p_3],\ 5\,\mathrm{dp}[p_5])$。

*不變量*：$p_c$ 指向「下一個尚未被乘以 $c$ 的醜數」，故 $c \cdot \mathrm{dp}[p_c]$ 是「因子 $c$ 這條鏈上，尚未產生的最小醜數」。三條鏈的並集恰為全部醜數（每個醜數 $u > 1$ 至少有一個質因子 $\in \{2,3,5\}$，故至少由一條鏈產生）。

*去重*：因為一個醜數可能由多條鏈產生（例如 $6 = 2\times 3 = 3 \times 2$），**取到最小值後，所有達到該最小值的指標都要前進**：
```cpp
if (v == 2 * dp[p2]) ++p2;
if (v == 3 * dp[p3]) ++p3;  // 是 if，不是 else if
if (v == 5 * dp[p5]) ++p5;
```
**寫成 `else if` 就會產生重複的醜數**——這是本題唯一的坑，也是「多鏈合流必須處理重複」的最小示例。

*與堆解的對比*：用 `priority_queue` + `unordered_set` 去重是 $O(n\log n)$；三指標是 $O(n)$、無額外容器。**當「下一個候選」可以用固定數量的指標表示時，指標永遠優於堆。**

## 時間與空間複雜度

| 題目 | 前緣堆 | 二分 + 計數 | 其他 |
| --- | --- | --- | --- |
| 373 K 對數字 | $O(K\log\min(K,n))$，空間 $O(\min(K,n))$ | — | |
| 378 矩陣第 K 小 | $O(K\log n)$，空間 $O(n)$ | $O(n\log\frac{\max-\min}{1})$，空間 $O(1)$ | **$K$ 可達 $n^2$，二分通常更好** |
| 786 第 K 小質數分數 | $O(K\log n)$ | $O(n\log C)$ 雙指標計數 | |
| 1439 第 K 小陣列和 | $O(mK\log K)$（逐列合併，每列只留前 $K$ 小） | $O(mn\log C)$ | |
| 2386 第 K 大子序列和 | $O(n\log n + k\log k)$ | $O(n\log n + n\log C)$ | 候選總數 $2^n$ |
| 264 醜數 II | $O(n\log n)$（堆） | — | **三指標 $O(n)$、空間 $O(n)$** |

**378 的兩解量化對比**（$n = 300$，$K$ 最大 $= 90000$）：
- 前緣堆：$90000 \times \log 300 \approx 7\times 10^5$ 次堆操作。
- 二分：$\log(2\times10^9) \approx 31$ 輪 $\times\ 600$ 步 $\approx 1.9 \times 10^4$ 步，**且空間 $O(1)$**。
**二分快一個數量級以上。$K$ 大時務必選二分。**

**1439 的「逐列合併只留前 K」為什麼正確**：最終的第 $K$ 小和，其在前 $t$ 列上的部分和必定也在「前 $t$ 列的前 $K$ 小和」之中（否則已有 $K$ 個更小的部分和，補上後面各列的最小值後仍全部更小，矛盾）。**這是「前綴最優性」的一個實例，也是所有「只留前 K」剪枝的共同理由。**

## 與相似技巧的比較

- **與 6.1 的「大小為 K 的堆」**：那是**已知全部候選、逐個掃過去**（$O(n\log K)$）；本節是**候選按需生成、總數可能無限或指數級**。**候選數 $n$ 有限且能全掃 ⇒ 6.1；不能全掃 ⇒ 本節。**
- **與 `nth_element`**：靜態陣列、單次查詢 ⇒ `nth_element` 期望 $O(n)$，比任何堆解都快。**但它會重排陣列、最壞 $O(n^2)$、且不能用於「按需生成」的候選。**
- **與 6.2 的 K 路合流**：定理 1 的前緣堆是 K 路合流的推廣——**K 路合流是「偏序 = $k$ 條互不相交的鏈」的特例**。認識到這一點，373／378 就只是換了一種偏序。
- **與二分答案（一般）**：本節的二分是「對答案的值二分」，成敗全在 `count_le` 能否做到 $O(n)$。**若 `count_le` 只能 $O(n\log n)$，總複雜度 $O(n\log n\log C)$ 可能就不如堆了。**
- **與 5.4 雙指標**：786 的計數靠雙指標，前提是「前綴長度隨 $j$ 單調不減」。**幾乎每個 $O(n)$ 的 `count_le` 背後都是一個單調性論證**，寫之前先把它說清楚。
- **與 DP**：1439 的逐列合併其實是 DP（狀態 = 前 $t$ 列的前 $K$ 小和集合）。**「只保留前 $K$ 個狀態」是有界 DP 的通用剪枝**，正確性靠前綴最優性。

## 本節重點速查

- **$K$ 小用堆（$O(K\log\cdot)$），$K$ 大用對值二分（$O(n\log C)$）。** 378 在 $K = n^2$ 時二分快一個數量級以上，且空間 $O(1)$。
- **前緣堆的唯一前提：值沿偏序單調不減**（定理 1）。已彈出集合恆為下閉集，補集的極小元恆在堆中，故堆頂即下一個最小值。
- **373 的去重靠結構而非雜湊表**：一律推 $(i, j+1)$，只有 $j=0$ 時才推 $(i+1, 0)$——每個候選恰生成一次（定理 2）。
- **264 的三指標必須用 `if` 不是 `else if`**，否則產生重複醜數。**能用固定數量的指標表示「下一個候選」時，指標永遠優於堆。**
- **二分的答案一定是實際存在的候選值**（定理 3 引理 2），前提是候選取整數；實數（786）要改成「記錄達標時的那一對」以避開精度。
- **每個 $O(n)$ 的 `count_le` 背後都有一個單調性論證**（378 的階梯走法、786 的雙指標），寫之前先講清楚。
- **2386**：用雙射 $\mathrm{sum}(A) = S - \sum_{B}|a_i|$ 把「第 $K$ 大子序列和」化成「非負值的第 $K$ 小子集和」，$2^n$ 個候選壓到 $O(k\log k)$。**沒有這個雙射，負數會破壞單調性。**
- **「只留前 $K$ 個」的剪枝**（1439）靠前綴最優性：全域第 $K$ 小的前綴部分必在前綴的前 $K$ 小之中。
- 靜態、單次、只要一個排名 ⇒ `nth_element`，別堆一個堆。
