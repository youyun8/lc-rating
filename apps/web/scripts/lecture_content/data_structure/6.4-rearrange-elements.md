## 這個技術解決什麼問題

一堆帶重複次數的元素要排成一列，限制是「**相同的元素不能靠太近**」：

- **相鄰不同**（間隔 $\ge 2$）：767（重構字串）、1054（距離相等的條形碼）、984（字串的另一種表示）。
- **間隔 $\ge k$**：358（K 距離重排字串）、1405（最長快樂字串，額外限制「同一字元不能連續三次」）。
- **有冷卻時間、允許閒置，問最短總長**：621（任務排程器）。

**共同骨架**：*每一步都選「剩餘次數最多、且目前不在冷卻中」的元素。* 直覺是「先處理最難安排的」——次數最多的元素最容易在末尾擠成一團，必須優先攤開。

**兩個要分清楚的問法**：
- **「能不能排出來」**（767、358）：答案是充要條件 + 構造，見定理 1、4。
- **「最短要多長」**（621）：答案是一個閉式公式，見定理 3。**這題其實不需要堆**，用計數陣列直接套公式即可。

**暴力是枚舉全排列（$n!$）**；貪心 + 堆是 $O(n\log \Sigma)$，$\Sigma$ 為字元種類數。

## 狀態／資料結構定義

**基本狀態**：`cnt[c]` = 元素 $c$ 的剩餘次數。

**(A) 相鄰不同（間隔 2）**——大頂堆 + 一個「上一步用過的」暫存：
```cpp
priority_queue<pair<int, char>> pq;  // (剩餘次數, 字元)；預設大頂堆，first 優先
pair<int, char> prev = {0, 0};  // 上一步放的元素，冷卻一步後放回
while (!pq.empty()) {
    auto [c, ch] = pq.top();
    pq.pop();
    res += ch;
    if (prev.first > 0) pq.push(prev);  // 上一步的元素現在解除冷卻
    prev = {c - 1, ch};
}
```
**`prev` 就是長度為 1 的冷卻佇列。** 這個寫法的關鍵是**先取、再把上一步的放回**——順序反了就會把剛用過的元素立刻再取一次。

**(B) 間隔 $k$**——大頂堆 + 長度 $k-1$ 的冷卻佇列：
```cpp
priority_queue<pair<int, char>> pq;
queue<pair<int, char>> cool;  // 冷卻中的元素，長度恆 <= k-1
while (!pq.empty() || !cool.empty()) {
    if (pq.empty()) return "";  // 有元素還沒排完卻全在冷卻中 → 無解
    auto [c, ch] = pq.top();
    pq.pop();
    res += ch;
    cool.push({c - 1, ch});
    if ((int)cool.size() == k) {  // 最早進冷卻的已滿 k-1 步
        auto p = cool.front();
        cool.pop();
        if (p.first > 0) pq.push(p);
    }
}
```
**冷卻佇列的長度恆為 $\min(k-1, \text{已放置數})$**，這條不變量保證「距離 $< k$ 的元素都在佇列裡、不在堆裡」。**$k \le 1$ 要特判直接回傳原字串**（`cool.size() == k` 永遠不成立會死迴圈）。

**(C) 621 不需要堆**——只要 `cnt[26]`、`maxCount`、`cntMax`（達到最大次數的任務種類數），套定理 3 的公式。

## 不變量或正確性證明

以下令 $n$ 為總元素數、$m = \max_c \mathrm{cnt}(c)$、$p = |\{c : \mathrm{cnt}(c) = m\}|$。

### 定理 1（相鄰不同的充要條件）

**存在一個相鄰皆不同的排列 $\iff m \le \lceil n/2 \rceil$。**

*必要性*。設某元素 $x$ 出現 $m$ 次。在任何合法排列中，$x$ 的任兩次出現之間至少要夾一個非 $x$ 元素，故需要至少 $m - 1$ 個非 $x$ 元素，即 $n - m \ge m - 1$，得 $m \le (n+1)/2$，即 $m \le \lceil n/2\rceil$。$\square$

*充分性（構造）*。把元素按次數降冪展開成一個序列 $s_0, s_1, \dots, s_{n-1}$（同一元素的所有份連續）。把它們依序填入位置
$$0,\ 2,\ 4,\ \dots,\ 1,\ 3,\ 5,\ \dots$$
（先填所有偶數位，再填所有奇數位）。

*宣稱*：任兩個相鄰位置的元素不同。
*證明*。相鄰位置 $i, i+1$ 在填入順序中的距離是 $\lceil n/2\rceil$（偶數位 $i$ 是第 $i/2$ 個填的，奇數位 $i+1$ 是第 $\lceil n/2\rceil + i/2$ 個填的）。而同一元素在展開序列中佔連續的 $\mathrm{cnt}(c) \le m \le \lceil n/2\rceil$ 個位置。**兩個填入順序相差 $\lceil n/2 \rceil$ 的槽位，不可能同屬一段長度 $\le \lceil n/2\rceil$ 的連續區間**——除非恰好是該區間的兩端，此時 $\mathrm{cnt}(c) = \lceil n/2\rceil + 1 > m$，矛盾。$\square$

**這個構造比堆貪心更好證，也更快（$O(n + \Sigma\log\Sigma)$，且無堆的常數）。** 1054（距離相等的條形碼）用它是最短的寫法。**「按次數降冪展開後隔位填入」值得當成一個獨立的招式記住。**

### 定理 2（貪心「取剩餘最多者」在間隔 2 時的安全性）

*引理*：若當前狀態（剩餘計數 $\mathrm{cnt}$、上一步放的元素 $\textit{prev}$）存在可行完成，則存在一個**在這一步選擇剩餘次數最大的可用元素 $a$** 的可行完成。

*證明（交換）*。設某可行完成在這一步放 $b \ne a$，其中 $a$ 可用（$a \ne \textit{prev}$）且 $\mathrm{cnt}(a) \ge \mathrm{cnt}(b)$。

因 $\mathrm{cnt}(a) \ge 1$，該完成在後續某位置放了 $a$；取**最早**的那個位置 $q$。把位置 $t$（放 $b$）與 $q$（放 $a$）互換：
- *位置 $t$ 放 $a$*：$a \ne \textit{prev}$ ✔；位置 $t+1$ 原本放的元素 $\ne a$（因為 $q$ 是 $t$ 之後最早的 $a$，若 $q = t+1$ 則互換後 $t$ 放 $a$、$t+1$ 放 $b$，仍合法；若 $q > t+1$ 則 $t+1$ 上不是 $a$）✔。
- *位置 $q$ 放 $b$*：需 $q-1$ 與 $q+1$ 上不是 $b$。$q - 1$ 上若是 $b$，則原本 $q-1$ 放 $b$、$q$ 放 $a$；互換後 $q$ 放 $b$ 與 $q-1$ 的 $b$ 相鄰 ✗ —— 此時改用另一個交換：把 $t$ 的 $b$ 與 $q-1$ 的 $b$ 視為同一元素，直接令互換對象為 $(t, q)$ 之外⋯

  更簡潔的處理：**若 $q-1$ 或 $q+1$ 上是 $b$，則把該處的 $b$ 與 $t$ 的 $b$ 互換（同元素，序列不變），再對新的 $q$ 重做上述論證。** 由於 $b$ 的出現位置兩兩不相鄰（原解合法），$q$ 的左右至多一側是 $b$，重做一次即可脫離。

因此總能得到一個在位置 $t$ 放 $a$ 的可行解。$\square$

**這條引理點名的前提是「元素之間除了自身的間隔限制外沒有其他約束」**——也就是元素是可互換的。若題目給每個元素額外的位置限制（例如某些位置只能放特定元素），交換論證立刻失效，就得改用二分圖匹配或流。

### 定理 3（621 任務排程器的閉式公式）

**答案 $= \max\big((m-1)(k+1) + p,\ \ n\big)$**，其中 $k$ 是冷卻時間、$n$ 是任務總數。

*下界 1*：總長度至少要放得下所有任務，故 $\ge n$。

*下界 2*：取任一出現 $m$ 次的任務 $x$。它的第 $i$ 次與第 $i+1$ 次出現之間至少隔 $k$ 個時間單位，故前 $m-1$ 次出現各自「佔據」一段長度恰為 $k+1$ 的區塊（從該次出現算起）。這 $m-1$ 段互不重疊，共 $(m-1)(k+1)$。在最後一段（第 $m$ 次出現所在的位置及其後）中，**所有 $p$ 個出現 $m$ 次的任務都必須各出現一次**（它們的最後一次出現都落在最後一個區塊裡，且彼此不能同時），故最後至少再加 $p$。合計 $\ge (m-1)(k+1) + p$。$\square$

*達成性（構造）*。把時間軸切成 $m-1$ 個長度 $k+1$ 的列，加上最後一列。**按次數降冪，把每個任務的 $\mathrm{cnt}(c)$ 份分別放進前 $\mathrm{cnt}(c)$ 列的同一欄。** 同一任務的兩份分屬相鄰兩列的同一欄，間隔恰為 $k+1 > k$ ✔。
- 若不同任務數 $\le k+1$：所有任務都放得進 $k+1 個欄位$，空白處填閒置，總長 $= (m-1)(k+1) + p$。
- 若不同任務數 $> k+1$：欄位不夠，多出來的任務插進原本的閒置格。**每插入一格，所有後續格子右移，同任務的間隔只會變大不會變小**，故仍合法；插到沒有閒置格為止，總長 $= n$。$\square$

**公式的兩項分別對應「被最頻繁任務撐開的骨架」與「任務多到不需要閒置」兩種情形。** 這也是為什麼答案是兩者取 $\max$。

**621 不需要堆**：$O(n + 26)$ 即可。**看到「求最短長度」而不是「求具體排列」，先想公式。** 若題目要求輸出具體排列（621 的變體「任務排程器 II」），才需要模擬。

### 定理 4（358 間隔 $k$ 的必要條件）

**若存在間隔 $\ge k$ 的合法排列，則 $(m-1)\cdot k + p \le n$。**

*證明*：與定理 3 下界 2 相同——前 $m-1$ 次出現各佔一段長度 $\ge k$ 的不重疊區塊，最後一段至少要容納 $p$ 個達到最大次數的元素。$\square$

**注意 358 與 621 的差別：621 允許閒置（可以拉長總長度），358 不允許（總長固定為 $n$）。** 所以 621 的公式是「答案」，358 的同一個式子只是「可行性判準」。**這條差異是這兩題最容易混淆的地方。**

*$k = 2$ 時*，條件化為 $(m-1)\cdot 2 + p \le n$。當 $p = 1$ 得 $m \le (n+1)/2 = \lceil n/2\rceil$，與定理 1 一致 ✔。

### 定理 5（為什麼是「剩餘次數最多」：唯一不消耗餘裕的選擇）

定義**餘裕**
$$\mathrm{slack} \;=\; (\text{剩餘位置數}) \;-\; \big[(m-1)k + p\big] ,$$
由定理 4，$\mathrm{slack} < 0$ 時必定無解。看每放一個元素後 slack 怎麼變（剩餘位置數固定減 1）：

- **放一個剩餘次數為 $m$ 的元素**：
  - 若 $p > 1$：新的 $m$ 不變、$p$ 減 1 ⇒ 界限減 1 ⇒ **slack 不變**。
  - 若 $p = 1$：新的最大次數變成 $m-1$，界限從 $(m-1)k + 1$ 變成 $(m-2)k + p'$ ⇒ **界限至少減 $k - p' + 1$，slack 通常增加**。
- **放一個剩餘次數 $< m$ 的元素**：$m$ 與 $p$ 都不變 ⇒ 界限不變，而剩餘位置數減 1 ⇒ **slack 減 1**。

**結論：只有「取剩餘次數最大者」不會消耗餘裕；取其他元素每次都白白損失 1 單位。** 這就是貪心的精確意義——它是**唯一一個對「必要條件的緊繃程度」沒有負面影響的選擇**。

**這個位能論證點名了它依賴的前提**：(i) 定理 4 的界限確實是必要條件；(ii) 元素之間可互換（定理 2 的前提）。**在間隔 $k \ge 3$ 的一般情形，把「不消耗餘裕」升級成完整的最優性證明，還需要一個位置重指派的引理**（給定兩組各自 $k$-分散的位置集合、其中一組較大，可以重新指派使當前位置歸給次數較多的元素）；本節不展開，但這一步是唯一的缺口，其餘推理都是完整的。

### 定理 6（1405 最長快樂字串的額外限制）

限制是「同一字元不能連續出現 3 次」，不是固定間隔。**因此冷卻佇列長度不是常數，而是取決於「上一步是否已經連放兩個相同的」。**

*貪心*：每次取剩餘最多者；**若它與已輸出的最後兩個字元相同，就改取剩餘次數第二多者**（若不存在則結束）。

*正確性（交換）*：與定理 2 同構——設此步應放 $a$（剩餘最多且合法）而某最優解放 $b$。因 $\mathrm{cnt}(a) \ge \mathrm{cnt}(b)$，最優解後續必有 $a$，交換之。**額外要檢查的是「連續三次」這個局部條件，而它只涉及相鄰三格，交換後逐一驗證即可。**

**「取最多者、被擋住就取次多者」是這一族的通用退化寫法**——堆頂被冷卻擋住時，退而取次頂，而不是等待。

## 時間與空間複雜度

| 題目 | 做法 | 時間 | 空間 |
| --- | --- | --- | --- |
| 767 重構字串 | 隔位填入（定理 1） | $O(n + \Sigma\log\Sigma)$ | $O(n)$ |
| 767 / 1054 | 大頂堆貪心 | $O(n\log\Sigma)$ | $O(\Sigma)$ |
| 358 K 距離重排 | 堆 + 冷卻佇列 | $O(n\log\Sigma)$ | $O(\Sigma)$ |
| 621 任務排程器 | **公式** | $O(n + 26)$ | $O(26)$ |
| 621 | 堆模擬（若要輸出排列） | $O(n\log 26)$ | $O(26)$ |
| 1405 最長快樂字串 | 堆貪心（只有 3 種字元） | $O(n)$ | $O(1)$ |

**$\Sigma$ 通常是 26 或 100，所以 $\log\Sigma \le 7$——堆的成本其實是常數。** 但在 $\Sigma$ 小的時候，**直接用 `cnt[26]` 每次線性掃找最大值（$O(\Sigma)$）往往比堆更快**，因為省掉了堆的節點搬移與快取失效。**$\Sigma \le 26$ 時，$O(n\Sigma) = 26n$ 完全可接受。**

**621 用公式是 $O(n)$、用模擬是 $O(n\log 26)$，且模擬還要處理「時間跳躍」的細節。** 只問長度時務必用公式。

**空間**：所有做法都是 $O(\Sigma)$（不計輸出）。**注意堆裡放的是「(剩餘次數, 字元)」而不是逐份元素**，否則空間會退化成 $O(n)$、時間退化成 $O(n\log n)$。

## 與相似技巧的比較

- **與 6.1 的貪心 + 堆**：本節是它的一個特化——**多了「冷卻」這個時間維度的約束**，所以堆之外還要一個佇列。**「堆管價值、佇列管時間」與 5.4 單調佇列的「尾端管價值、頭端管時間」是同一種分工。**
- **與 3.1.2 差分／掃描線**：621 的公式解本質是「算最頻繁元素撐出的骨架長度」，屬於計數論證而非資料結構。**很多「重排」題的最優值有閉式解，先花五分鐘找公式，找不到再上資料結構。**
- **與二分圖匹配**：若元素有「只能放在某些位置」的額外限制，交換論證失效（定理 2 的前提被破壞），要改用匹配或網路流。**判準：元素之間是否可互換。**
- **與 6.5 反悔堆**：本節的貪心**不反悔**——因為定理 5 保證每一步都不消耗餘裕。**一旦某步的選擇可能在未來被推翻，才需要反悔堆。**
- **與計數排序**：$\Sigma$ 小時用 `cnt[]` 陣列取代堆更快。**堆的優勢在 $\Sigma$ 大（例如元素是任意整數）時才顯現。**
- **與 4.3 鄰項消除**：兩者都在處理「相鄰元素的關係」，但方向相反：4.3 是**移除**相鄰的相同項，本節是**安排**使相鄰不同。**4.3 的答案唯一（合流性），本節的答案通常不唯一。**

## 本節重點速查

- **共同骨架：每步取「剩餘次數最多且不在冷卻中」的元素。** 堆管價值、冷卻佇列管時間。
- **相鄰不同的充要條件：$m \le \lceil n/2\rceil$**（定理 1）。**構造用「按次數降冪展開後先填偶數位再填奇數位」——比堆貪心更快也更好證。**
- **621 的公式：$\max\big((m-1)(k+1)+p,\ n\big)$**（定理 3）。兩項分別是「最頻繁任務撐開的骨架」與「任務多到不必閒置」。**只問長度就別模擬。**
- **621 允許閒置、358 不允許**——同一個式子在 621 是答案、在 358 只是可行性判準（定理 4）。這是兩題最常混淆之處。
- **貪心的精確意義（定理 5）**：定義 $\mathrm{slack} = \text{剩餘位置} - [(m-1)k + p]$，**只有取最大次數者不會消耗 slack**，取其他元素每次白白損失 1。
- 交換論證的前提是**元素可互換**；一旦有「某位置只能放某元素」的限制，就要改用匹配／流。
- 實作：`prev`／冷卻佇列的元素**要在放置之後才推回堆**；`k <= 1` 要特判否則死迴圈；堆裡放 `(次數, 字元)` 而非逐份元素。
- $\Sigma \le 26$ 時，直接掃 `cnt[26]` 找最大值往往比堆更快。
