## 這個技術解決什麼問題

有一類題長這樣：**沿著某個固定順序掃描，邊走邊做取捨，受一個累積型的限制約束**（油量、時間、磚塊、前綴和非負、預算）。

純貪心會錯，因為「現在看起來該選的」到後面才知道不該選；但**枚舉所有取捨是指數級**。

**反悔貪心的解法**：*先無條件地把每一項都拿下來；一旦違反約束，就從已拿的當中退掉最糟的一個。* 堆負責 $O(\log n)$ 找出「最糟的已選項」。

典型題：
- **871 最低加油次數**：路過就先把油「記在帳上」，油不夠時才回頭「補加」最大的那桶。
- **630 課程表 III**：先把課排進去，超過期限就退掉**耗時最長**的一門。
- **1642 可以到達的最遠建築**：磚塊不夠時，把**最大的那次爬升**改用梯子。
- **2599 / LCP 30**：前綴和變負時，退掉**最負的**那個元素。
- **2813 子序列最大優雅度**：先取利潤最大的 $k$ 個，再用後面的項替換掉「重複類別中利潤最小」的已選項。

**辨識訊號**：
1. 有一個**單向掃描的順序**（位置、期限、時間）；
2. 有一個**累積量**必須滿足不等式；
3. 「已選集合」的大小或代價是目標；
4. 而且**「撤銷一個已選項」是合法且可計算的**。

第 4 點是關鍵前提：**必須能算出撤銷的效果，且撤銷不會讓已經走過的路變得不合法。**

## 狀態／資料結構定義

**通用骨架**：
```cpp
priority_queue<int> regret;  // 已選項中「最糟者」在堆頂（方向依題目而定）
long long acc = 初始值;  // 受約束的累積量
int count = 0;           // 已選 / 已用次數
for (每個項目 x，按掃描順序) {
    無條件選入 x;
    acc += 貢獻(x);
    regret.push(代價(x));
    while (acc 違反約束) {
        if (regret.empty()) return 無解;
        acc -= 撤銷(regret.top());
        regret.pop();
        ++count;
    }
}
```

**堆的方向要對應「最糟」的定義，這是唯一需要逐題判斷的地方**：

| 題目 | 堆中存什麼 | 堆頂是 | 撤銷的意義 |
| --- | --- | --- | --- |
| 871 加油 | 路過但未加的油量 | **最大** | 「補加」這桶油（次數 +1） |
| 630 課程表 III | 已選課程的耗時 | **最大** | 退掉最耗時的課 |
| 1642 建築 | 已走過的正爬升 | **最小**（大小為 `ladders` 的小頂堆） | 把最小的那次改回用磚塊 |
| 2599 前綴和非負 | 已選的負元素 | **最小（最負）** | 把最負的搬到最後 |
| 2813 優雅度 | 已選中「類別重複」者的利潤 | **最小** | 換成一個新類別的項 |

**871 的方向最反直覺**：堆裡放的不是「已加的油」而是「路過的加油站」，撤銷的動作是**追加**而不是移除。**這是「反悔」的另一種面貌——把『當時沒做的事』事後補做。** 它成立的前提見定理 1。

**1642 的兩種等價寫法**：
- **大頂堆存所有爬升，磚塊不夠就把最大的改用梯子**（要維護已用梯子數）；
- **小頂堆恆保持大小 $\le$ `ladders`，代表「分配給梯子的爬升」，被擠出來的用磚塊**。
後者更簡潔，且與 6.1 定理 4「大小為 $K$ 的堆」是同一個不變量。

## 不變量或正確性證明

### 定理 1（871 最低加油次數：時機無關性）

*關鍵前提（時機無關）*：**在加油站 $i$ 加油，與「先開過去、事後再宣稱在 $i$ 加了油」是等價的**——只要車在到達 $i$ 之後的任何時刻回頭把這桶油計入，路徑上的每一點油量都不會變成負值嗎？

嚴格地說：設實際策略是「在站 $i_1 < i_2 < \dots < i_j$ 加油」。車能開到位置 $x$ 的充要條件是：對**每一個前綴位置** $y \le x$，都有
$$\text{起始油量} + \sum_{i_s \le y} \text{fuel}(i_s) \;\ge\; y .$$
**演算法的做法是「先假設不加油地開，卡住時才從已路過的站中取最大的補上」。** 這樣做出來的加油集合是否滿足上式？

*引理*：貪心在到達位置 $x$ 時所用的加油次數 $j(x)$，等於「能開到 $x$ 所需的最少次數」，且此時的油量是「用 $j(x)$ 次加油能達到的最大值」。

*證明（歸納）*。設到達站 $i$ 前不變量成立：已用 $j$ 次，且油量 $= \text{start} + (\text{已路過站中最大的 } j \text{ 桶之和}) - (\text{已走距離})$。
- 若油夠開到下一站，$j$ 不變，不變量保持（新路過的站進堆，不影響「最大 $j$ 桶」是否改變？會改變——若新站的油量比已選的某桶大，「最大 $j$ 桶」應該換人）。

  這正是**堆的寫法自動處理的事**：把所有路過的站都放進大頂堆，只在需要時彈出最大者。彈出的一定是「所有已路過站中最大的、尚未使用的那桶」，所以任何時刻「已使用的 $j$ 桶」恆為**已路過站中最大的 $j$ 桶**。$\square$
- 若油不夠：必須增加加油次數。由上述性質，用 $j+1$ 次能達到的最大油量就是「最大 $j+1$ 桶之和」，貪心正是取出第 $j+1$ 大的那桶。若堆已空仍不夠 ⇒ 用任何次數都不夠 ⇒ 無解。$\square$

*最少性*：由引理，對每個 $j$，貪心給出「用 $j$ 次能到達的最遠距離」；因此第一次到達終點時的 $j$ 就是最小值。$\square$

**這個證明點名的前提是「油可以無限儲存、加油不花時間」**——即**資源是可累積且無上限的**。若油箱有容量上限，「事後補加」就不再等價（可能溢出），反悔堆立刻失效，得改用 DP。**這是 871 與其變體的分界線。**

### 定理 2（630 課程表 III：兩層最優的強不變量）

課程 $(d_i, e_i)$ = (耗時, 截止日)；同時只能上一門課；求最多能修幾門。

*引理 A（排序）*：**對任一可行的課程子集，按截止日升冪安排一定可行。**
*證明（交換）*：若某可行安排中存在相鄰兩門 $u, v$ 順序為 $u$ 先、$v$ 後但 $e_u > e_v$，交換之。交換後 $v$ 的結束時間變早（不會違規），$u$ 的結束時間等於原本 $v$ 的結束時間 $\le e_v < e_u$（不會違規）。反覆消除逆序即得。$\square$

*推論*：子集 $S$ 可行 $\iff$ 按截止日升冪排列後，每個前綴的耗時總和 $\le$ 該前綴最後一門的截止日。

*演算法*：把課程按 $e_i$ 升冪處理。維護一個**大頂堆**（存已選課程的耗時）與 `total`（已選總耗時）。
```
total += d_i;  heap.push(d_i);
if (total > e_i) { total -= heap.top(); heap.pop(); }
```

*強不變量 (S)*：處理完前 $i$ 門課後，堆中的集合 $S_i$ 滿足
1. $S_i$ 可行；
2. $|S_i|$ 是「前 $i$ 門課的可行子集」中的**最大值**；
3. 在所有大小為 $|S_i|$ 的可行子集中，$S_i$ 的**總耗時最小**。

**條件 3 是這個證明的靈魂**——只有「同樣門數之下總耗時最小」，才能保證後續的課有最大的空間可以插入。**只證條件 2 是證不下去的。**

*證明（對 $i$ 歸納）*。$i=0$ 顯然。設 (S) 對 $i-1$ 成立，處理第 $i$ 門課 $(d_i, e_i)$。
- *情形 A：$\mathrm{total}(S_{i-1}) + d_i \le e_i$*。取 $S_i = S_{i-1}\cup\{i\}$。
  - 可行：由引理 A 的推論，把 $i$ 接在最後（它的截止日最大），前綴和條件正是 $\mathrm{total} + d_i \le e_i$ ✔。
  - 最大：任一前 $i$ 門的可行子集 $T$，若 $|T| > |S_{i-1}| + 1$，則 $T \setminus \{i\}$ 是前 $i-1$ 門的可行子集且大小 $> |S_{i-1}|$，違反歸納假設 2 ✔。
  - 最小耗時：設 $T$ 可行、$|T| = |S_{i-1}|+1$。若 $i \in T$，則 $T\setminus\{i\}$ 大小為 $|S_{i-1}|$、可行，由假設 3 其耗時 $\ge \mathrm{total}(S_{i-1})$，故 $\mathrm{total}(T) \ge \mathrm{total}(S_i)$ ✔。若 $i \notin T$，則 $T$ 是前 $i-1$ 門中大小 $|S_{i-1}|+1$ 的可行子集，與假設 2 矛盾 ✔。
- *情形 B：$\mathrm{total}(S_{i-1}) + d_i > e_i$*。令 $M = \max(S_{i-1} \cup \{i\})$（最大耗時），$S_i = (S_{i-1}\cup\{i\})\setminus\{M\}$，故 $|S_i| = |S_{i-1}|$。
  - 可行：$\mathrm{total}(S_i) = \mathrm{total}(S_{i-1}) + d_i - M \le \mathrm{total}(S_{i-1})$（因 $M \ge d_i$），而 $S_{i-1}$ 可行且新加入的課截止日最大，故所有前綴條件仍成立 ✔。
  - 最大：若存在大小 $|S_{i-1}|+1$ 的可行子集 $T \subseteq [i]$，則 $\mathrm{total}(T) \le e_i$（$T$ 的總耗時不超過最大截止日）。$T\setminus\{i\}$（或 $T$ 本身若 $i\notin T$）是前 $i-1$ 門中大小 $\ge |S_{i-1}|$ 的可行子集，由假設 3，$\mathrm{total}(S_{i-1}) \le \mathrm{total}(T \setminus \{i\})$，於是 $\mathrm{total}(S_{i-1}) + d_i \le \mathrm{total}(T) \le e_i$，與情形 B 的前提矛盾 ✔。
  - 最小耗時：$S_i$ 是在「$S_{i-1} \cup \{i\}$」中去掉最大者，故是該多重集合中大小為 $|S_{i-1}|$ 的最小耗時子集；再結合假設 3 可得全域最小 ✔。$\square$

**這個「主目標最大 + 次要目標最小」的雙層不變量，是所有反悔堆題的證明範式。** 630 是它最乾淨的示例，值得完整讀一遍。

### 定理 3（1642 可以到達的最遠建築）

*引理*：**若已經走到建築 $i$，則所需磚塊的最小值 $=$（前 $i$ 段正爬升之和）$-$（其中最大的 `ladders` 個之和）。**
*證明*：每段正爬升必須用磚塊或梯子；梯子最多 `ladders` 個，且一段爬升用梯子省下的磚塊恰等於該段高度。要最小化磚塊，就把梯子用在最大的 `ladders` 段上（這是「選 $k$ 個使和最大」的平凡貪心）。$\square$

*推論（單調性）*：可到達的建築編號構成一個前綴——若能到 $i$，用同樣的分配也能到 $i-1$。**所以「走到不能走為止」是正確的終止條件，不需要二分。**

*實作*：小頂堆恆保持大小 $\le$ `ladders`，內容是「目前分配給梯子的爬升」。新爬升推入後若超量，彈出最小者並從磚塊扣除。**堆的不變量與 6.1 定理 4 完全相同：大小為 $K$ 的小頂堆恆為「目前為止最大的 $K$ 個」。**

### 定理 4（2599 / LCP 30：搬走最負的元素）

要求每個前綴和 $\ge 0$（LCP 30 是 $\ge 1$，且可把元素搬到最後）；求最少搬動次數。

*觀察*：**把元素搬到最後，等價於在掃描階段把它移除**（因為搬到最後的元素不影響任何中間前綴；LCP 30 需另外確認總和足夠，題目已保證或需先判斷）。

*貪心*：從左到右累加；一旦 $\mathrm{acc} < 0$，從已加入的元素中取出**最小（最負）**的一個移除，`acc -= that`（減去負數即增加），次數 +1。

*不變量*：處理完前 $i$ 個元素後，
1. 移除次數是「使前 $i$ 個的所有前綴和非負」所需的**最小值**；
2. 在所有達到該最小次數的移除方案中，當前的 $\mathrm{acc}$ **最大**。

*證明概要*。條件 2 是關鍵：移除 $r$ 個元素能達到的最大 $\mathrm{acc}$，就是「總和減去最小的 $r$ 個」，貪心正是這麼做的。條件 1 由條件 2 推得：若貪心在第 $i$ 步不得不移除第 $r+1$ 個，表示用 $r$ 次移除能達到的最大 $\mathrm{acc}$ 仍為負，故任何方案都至少要 $r+1$ 次。$\square$

**又是「主目標最小 + 次要目標最大」的雙層不變量**，與定理 2 同構。**寫任何反悔堆題時，先把這兩層寫下來，證明就自己浮現了。**

### 定理 5（什麼時候「反悔」是合法的）

反悔堆能用，需要三個前提，缺一不可：

1. **撤銷可計算**：能 $O(1)$ 算出移除某已選項對累積量的影響（通常是「減掉它的貢獻」）。
2. **撤銷不破壞歷史**：移除一個已選項後，**先前所有已檢查過的約束仍然成立**。871、630、1642、2599 都滿足——因為移除只會讓累積量朝「更寬鬆」的方向走。**若移除某項會讓早先的某個約束反而變緊，就不能反悔。**
3. **順序固定**：掃描順序由題目結構決定（位置、截止日、時間），**不是我們可以選的**。若順序也要優化，那是排程問題，通常需要 DP 或流。

**檢查這三點只要一分鐘，卻能避免把一個 DP 題硬套成貪心。**

## 時間與空間複雜度

| 題目 | 時間 | 空間 | 說明 |
| --- | --- | --- | --- |
| 871 最低加油次數 | $O(n\log n)$ | $O(n)$ | 每站入堆出堆各一次 |
| 630 課程表 III | $O(n\log n)$ | $O(n)$ | 排序主導 |
| 1642 最遠建築 | $O(n\log L)$，$L$ = 梯子數 | $O(L)$ | **堆大小是 $L$ 不是 $n$** |
| 2599 / LCP 30 | $O(n\log n)$ | $O(n)$ | |
| 2813 優雅度 | $O(n\log n)$ | $O(n)$ | 排序 + 堆 |

**攤還論證**：每一項最多入堆一次、出堆一次，故堆操作總數 $\le 2n$，總時間 $O(n\log n)$。**這與 4.7、5.4 的位能論證是同一件事——反悔堆的 `while` 迴圈同樣不會讓複雜度變成 $O(n^2)$。**

**1642 的空間 $O(L)$ 值得強調**：用「小頂堆恆保持大小 $\le$ `ladders`」的寫法，堆最多 $L$ 個元素；用「大頂堆存全部爬升」的寫法則是 $O(n)$。**兩者時間同級，但前者常數與空間都更好。**

**溢位**：871 的距離與油量、630 的總耗時、2599 的前綴和都要用 `long long`。**$n \le 10^5$、單值 $\le 10^9$ ⇒ 總和可達 $10^{14}$，`int` 必爆。**

## 與相似技巧的比較

- **與 6.2 的純貪心（502 IPO）**：502 **不需要反悔**，因為「資本只增不減 ⇒ 可行集單調」（6.2 定理 3）。**一旦某個選擇會讓未來的可行集縮小，就要升級成反悔堆。這是兩節的精確分界。**
- **與 6.4 的重排貪心**：6.4 定理 5 證明了「取最大者不消耗餘裕」，所以不必反悔。**反悔堆處理的是「不得不先做決定，但決定會被後續資訊推翻」的情形。**
- **與 DP**：反悔堆能解的題，通常都有一個 $O(n \cdot C)$ 的 DP 解（$C$ 為資源上限）。**當資源上限很大（$10^9$）時 DP 不可行，反悔堆的 $O(n\log n)$ 是唯一出路；反之若資源上限小、或約束之間互相耦合（例如油箱有容量上限，破壞了定理 1 的前提），就得回頭用 DP。**
- **與反悔自動機**：另一種反悔形式是「**選一個項時，同時把一個『撤銷券』放回堆裡**」。經典例子是「低買高賣」型的股票題：賣出時把賣價再推入一次，代表「這筆交易可以事後改成中轉」。**反悔堆撤銷已做的決定，反悔自動機則預先為撤銷保留機會。** 兩者證明思路相同，都是雙層不變量。
- **與交換論證（一般貪心）**：本節的證明都是「雙層不變量 + 歸納」而非單純的交換。**差別在於：反悔堆的解在每個前綴上都最優，這比『存在一個最優解與貪心一致』更強，也更好用歸納推下去。**
- **與 8.x 並查集**：某些「反悔」題（例如「每個時刻只能用一個資源，找最晚可用的空位」）用並查集做「找 $\le t$ 的最大空閒位置」更快，$O(n\,\alpha)$。**若撤銷的對象是「時間槽」而非「已選項」，先想並查集。**

## 本節重點速查

- **骨架：先無條件全拿，違反約束就退掉最糟的一個。** 堆負責 $O(\log n)$ 找出「最糟的已選項」。
- **證明範式：雙層不變量——「主目標最優」＋「同分時次要指標最優」。** 630 是「門數最多 + 同門數下總耗時最小」，2599 是「移除最少 + 同次數下累積和最大」。**只證第一層一定推不下去。**
- **能用反悔堆的三個前提（定理 5）**：撤銷可計算、撤銷不破壞已檢查過的約束、掃描順序由題目固定。
- **871 的反悔方向是「事後補加」而非「移除」**；它依賴「資源可累積且無上限」——**油箱有容量上限就得改 DP。**
- **1642 用「小頂堆恆保持大小 $\le$ ladders」**：時間 $O(n\log L)$、空間 $O(L)$，比大頂堆存全部好。
- **2599 的「搬到最後」等價於「掃描時移除」**——認出這個等價是解題的第一步。
- **與 502（6.2）的分界**：可行集單調 ⇒ 純貪心；某個選擇會讓未來變差 ⇒ 反悔堆。
- 攤還 $O(n\log n)$：每項最多入堆出堆各一次，`while` 不會退化。
- 累積量一律 `long long`。
