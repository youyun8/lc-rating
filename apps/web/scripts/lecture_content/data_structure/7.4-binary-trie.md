## 這個技術解決什麼問題

一組整數 $S$，反覆問「給定 $x$，在 $S$ 裡挑一個 $y$，使 $x \oplus y$ 最大／最小」，或「$S$ 中有多少對的異或值落在某範圍內」。

暴力是每次查詢掃全部 $O(|S|)$，$n$ 與查詢數都到 $10^5$ 時就是 $10^{10}$。

**核心想法**：*把每個整數看成固定長度的二進位字串（高位在前），插進一棵 $\Sigma = 2$ 的 trie。* 於是：

- **異或的「逐位」性質**與 trie 的「逐層」結構完全對齊——第 $b$ 層的分支恰好對應第 $b$ 位的取值；
- 「最大化 $x \oplus y$」變成「從最高位開始，每層都盡量走與 $x$ 當前位**相反**的孩子」，$O(\text{位數})$；
- 節點上掛 `cnt`（子樹中的數字個數），就能做**前綴計數**——「異或值 $<$ 某個界」的對數，$O(\text{位數})$。

**與 7.1 的關係**：**0-1 trie 就是 $\Sigma=2$ 的 trie，沒有任何新結構。** 但因為所有「字串」等長，它有兩個特殊性質，直接簡化了寫法：

1. **每次查詢必定恰好走滿 $B$ 層，不會中途走不動**（只要 trie 非空——見定理 2 的前提）；
2. **不需要 `isEnd`**——終點深度固定，`isEnd` 沒有資訊量。用 `cnt` 取代它。

**辨識訊號**：題面出現「XOR / 異或」＋「最大／最小／計數」＋「從一堆數裡挑」。看到這三件事湊齊，先想 0-1 trie。**只有單一固定的 $x$、沒有反覆查詢的話，排序或雜湊可能更簡單**（見「與相似技巧的比較」）。

## 狀態／資料結構定義

```cpp
constexpr int B = 30;  // 最高位下標；值域 < 2^(B+1)
constexpr int MAXN = 200005 * (B + 1) + 5;  // 節點數上界 = 插入個數 × (B+1) + 1

int ch[MAXN][2];
int cnt[MAXN];  // 子樹中的數字個數（含重複）
int tot = 0;    // 節點 0 是根，已配置 tot+1 個節點
```

**`B` 怎麼定**：$B = \lceil \log_2(\max\text{值}+1)\rceil - 1$。
- 421：$\text{nums}[i] \le 2^{31}-1$ ⇒ $B = 30$。
- 1803：$\text{nums}[i] \le 2\times10^4$、$\text{high} \le 2\times10^4$ ⇒ $2^{15} = 32768 > 2\times10^4$ ⇒ $B = 14$。
- 1707：$\le 10^9 < 2^{30}$ ⇒ $B = 29$。

**$B$ 取太小會漏掉高位，答案偏小且極難除錯；取太大只是慢一點、耗記憶體多一點。** 不確定就取大的，但要重算 `MAXN`。

**`cnt` 的三個用途，缺一不可：**

| 用途 | 題目 |
| --- | --- |
| 判斷子樹是否非空（貪心時能不能往這邊走） | 421、1707 |
| 子樹計數（「異或值 $<L$ 的個數」一次加一整棵子樹） | 1803 |
| 支援刪除（`--cnt` 而非真的刪節點） | 1938、滑動視窗類變形 |

**不要用 `ch[u][b] != 0` 判斷子樹非空**——一旦支援刪除，節點還在但已無數字。**一律用 `cnt[ch[u][b]] > 0`。** 這是本節最容易埋下的隱形錯誤。

**節點 0 同時當作根與「空指標」**：`ch` 初值全 0，而根就是 0。這在只插入的場景可行（因為根永遠不是任何節點的孩子），**但 `cnt[0]` 會被根的計數污染**——所以判空要用 `ch[u][b] && cnt[ch[u][b]]`，或者把根改成節點 1、保留 0 當空。**本節模板採後者更安全的寫法：`tot` 從 0 開始，根是 0，判空同時檢查指標與 `cnt`。**

## 不變量或正確性證明

### 定理 1（高位優先貪心的正確性：位權的支配性）

**命題**：設 $u, v$ 是兩個 $B+1$ 位的非負整數，$b$ 是它們**最高的相異位**。若 $u$ 在第 $b$ 位是 1、$v$ 是 0，則 $u > v$。

*證明*：$u$ 與 $v$ 在 $> b$ 的位完全相同，設該部分的共同值為 $H$。則
$$u \ge H + 2^b, \qquad v \le H + \sum_{i=0}^{b-1} 2^i = H + 2^b - 1 < H + 2^b \le u. \qquad\square$$

**推論（貪心的合法性）**：要在候選集合中最大化一個 $B+1$ 位的值，**可以從最高位往低位逐位決定：每一位都優先取 1，只要「取 1 之後仍有候選存活」**。這樣得到的值是最大的。

*證明*：設貪心在第 $b$ 位取了 1，而某個「更優解」在該位取 0。由於兩者在 $>b$ 的位相同（貪心的前綴是可行的，且該解也在同一候選集內），由本定理該解嚴格小於任何在第 $b$ 位取 1 的可行值——矛盾 ✔。$\square$

**這是整節的地基，而它依賴一個常被忽略的前提：所有數字必須被視為等長的位串。** 若你用「有效位數」（去掉前導零）來走 trie，不同數字的深度就不同，位權對齊就壞了，定理 1 完全失效。**這是 0-1 trie 必須補足前導零的根本原因。**

### 定理 2（trie 上的貪心走訪實現了定理 1 的策略）

**不變量 (X)**：在查詢 $\max_{y \in S}(x \oplus y)$ 的過程中，走到第 $b$ 層的節點 $u$ 時，**$u$ 的子樹中的數字集合，恰好等於「所有與已作決策一致的 $y$」**——也就是那些能讓 $x\oplus y$ 的高位部分等於已經決定的那些位的 $y$。

*證明*：由 7.1 的不變量 (T)，$u$ 的子樹恰為「以 $u$ 對應的位串為前綴」的所有數字。而每一步我們選的孩子 $c$ 決定了 $y$ 的第 $b$ 位，從而決定了 $(x\oplus y)$ 的第 $b$ 位 $= x_b \oplus c$ ✔。$\square$

**貪心步**：在第 $b$ 層，想讓 $(x\oplus y)_b = 1$，需要 $y_b = x_b \oplus 1$。故
```cpp
int want = (x >> b & 1) ^ 1;
if (ch[u][want] && cnt[ch[u][want]]) {
    ans |= 1 << b;
    u = ch[u][want];
} else
    u = ch[u][want ^ 1];
```

由 (X)，`cnt[ch[u][want]] > 0` $\iff$ 「第 $b$ 位取 1 之後仍有候選存活」。**這正是定理 1 推論所要求的判斷**，故走訪結果最大 ✔。

**前提是 trie 非空**：若 $S = \emptyset$，`else` 分支會走到空節點。**所有 0-1 trie 題都要先確認「查詢時集合非空」**——421 的作法是「先插入 `nums[0]`，再從 $i=1$ 開始邊查邊插」，1707 的作法是「集合為空就回答 $-1$」。

**求最小值**：把 `want` 改成 `x >> b & 1`（走**相同**的位）即可，證明對偶。**注意「最小異或對」有更簡單的解法**：排序後只需檢查相鄰對（因為最小異或的兩個數在排序後必相鄰——它們的最高相異位最低，故數值最接近）。**不要為了用 trie 而用 trie。**

### 定理 3（1803 計數：「異或值 $< L$」的集合可以分解成 $O(B)$ 棵完整子樹）

**命題**：固定 $x$ 與界 $L$，令 $v = x \oplus y$。則
$$\{\, y : v < L \,\} \;=\; \biguplus_{\substack{b\,:\,L_b = 1}} \Big\{\, y : v_{i} = L_{i} \ \forall i > b,\ \ v_b = 0 \,\Big\}$$
且右側各集合**兩兩不交**（$\uplus$ 表示不交併）。

*證明*。
- **($\subseteq$)** 設 $v < L$。則 $v \ne L$，令 $b$ 為 $v$ 與 $L$ 的最高相異位。由定理 1，$v < L$ 迫使 $L_b = 1$、$v_b = 0$；且依定義 $v_i = L_i$ 對所有 $i > b$ ✔。
- **($\supseteq$)** 設 $v$ 屬於某個 $b$ 對應的集合。則 $v$ 與 $L$ 在 $>b$ 位相同、在第 $b$ 位 $L$ 為 1 而 $v$ 為 0，由定理 1 得 $v < L$ ✔。
- **不交**：每個 $v$ 的「與 $L$ 的最高相異位」唯一，故它只屬於該 $b$ 對應的集合 ✔。$\square$

**這個分解為什麼有用**：每一個 $b$ 對應的集合，在 trie 上**恰好是一整棵子樹**——「$v$ 在 $>b$ 位等於 $L$」把路徑唯一確定到第 $b$ 層的某個節點 $u$，而「$v_b = 0$」指定了 $u$ 的一個孩子，該孩子的**整棵子樹**都滿足條件。**所以計數不需要遞迴，只要沿一條路徑走下去，順路把若干個 `cnt` 加起來。**

```cpp
// 回傳 S 中滿足 (x ^ y) < L 的 y 的個數
int countLess(int x, int L) {
    int u = 0, res = 0;
    for (int b = B; b >= 0; --b) {
        if (u < 0) break;
        int xb = x >> b & 1, Lb = L >> b & 1;
        if (Lb == 1) {
            // v_b = 0 分支（y_b == x_b）整棵子樹都滿足 v < L
            int c = ch[u][xb];
            if (c) res += cnt[c];
            // 繼續沿 v_b = 1（= L_b）走
            u = ch[u][xb ^ 1];
        } else {
            // L_b = 0 ⇒ 必須 v_b = 0 才能維持「高位相等」
            u = ch[u][xb];
        }
        if (!u) break;
    }
    return res;
}
```

**「$\le L$」用 `countLess(x, L+1)`；「落在 $[\text{low}, \text{high}]$」用 `countLess(x, high+1) - countLess(x, low)`。** 1803 就是後者，對每個 $i$ 查詢 $[0, i)$ 中的數（**邊查邊插，天然避免重複計數與自己配自己**）。

**注意迴圈結束時 $u$ 對應的是 $v = L$ 本身，不計入**——這正是嚴格小於所要求的。

### 定理 4（1707 離線排序：單側約束 ⇒ 只需插入，不需刪除）

*問題*：查詢 $(x_i, m_i)$，要在 $\{\,y \in \text{nums} : y \le m_i\,\}$ 中最大化 $x_i \oplus y$。

**命題**：把 `nums` 升序排序、查詢按 $m$ 升序排序，用一個指標邊插邊答，結果正確。

*證明*：令 $S(m) = \{y \in \text{nums} : y \le m\}$。約束是**單側**的，故 $m \le m' \Rightarrow S(m) \subseteq S(m')$——**$S$ 對 $m$ 單調遞增。** 按 $m$ 升序處理時，從 $S(m_{k})$ 到 $S(m_{k+1})$ 只需**插入**新增的元素，永不需要刪除 ✔。$\square$

**前提是「單側」。** 若約束變成 $l_i \le y \le r_i$（雙側），單調性就沒了，這時有三條路：
1. **可持久化 trie**：對每個前綴版本建一棵樹，查詢時用 `cnt[版本r] - cnt[版本l-1]` 做差分——**這是通解，也是競賽中「區間內最大異或」的標準答案**；
2. **離線 + 差分**（把 $[l,r]$ 拆成 $[1,r] - [1,l-1]$，需要答案可差分——最大值不可差分，計數可以）；
3. **支援刪除的 trie**（`--cnt`），適用於雙指標／滑動視窗的場景。

**「約束是否單側」決定了要不要可持久化，這是這一族題的分水嶺。**

### 定理 5（1938 樹上查詢：DFS 進出即為集合的插入與刪除）

*問題*：一棵樹，每個查詢 $(node_i, val_i)$ 問：$node_i$ 到根的路徑上，$val_i \oplus \text{parentVal}$ 的最大值。

**不變量 (D)**：在 DFS 到達節點 $p$ 時，若進入節點就插入其值、離開節點就刪除（`--cnt` 沿路），則**0-1 trie 中的元素恰為根到 $p$ 的路徑上的所有值**。

*證明*（對 DFS 的執行歸納）：DFS 的呼叫堆疊恰為根到當前節點的路徑；插入與刪除與進入／離開嚴格配對，故 trie 中的元素集合恆等於堆疊中的節點值 ✔。$\square$

**所以只要把每個查詢掛在對應節點上，DFS 到那裡時查一次即可**，總複雜度 $O((n+q)B)$。

*刪除的實作*：沿 $val$ 的位路徑走下去，每個節點 `--cnt`。**節點不回收**（回收會破壞 `ch` 的結構且無必要）——這就是為什麼判空必須用 `cnt` 而非指標。

**這個「DFS 進出 = 集合維護」的套路不限於 0-1 trie**，任何支援插入／刪除的結構都適用（可撤銷並查集、`multiset`、值域 BIT）。**看到「路徑上的某種查詢」，先想這個套路，再想樹上倍增或樹鏈剖分。**

### 定理 6（2479：把「兩棵不相交子樹的異或和」化歸為「兩組數的最大異或對」）

*問題*：一棵樹，每個節點有值。選兩棵**不相交**的子樹，最大化兩者子樹和的異或。

*化歸鏈*：
1. 一次 DFS 求出每個節點的子樹和 $s_u$；
2. **兩棵子樹不相交 $\iff$ 兩個根互不為祖先**（樹的子樹要嘛包含要嘛不交）；
3. 對每個節點 $u$，「與 $u$ 不相交的子樹」= 全部子樹 $-$ ($u$ 的祖先鏈) $-$ ($u$ 的子樹)。用 DFS 序處理：**在 DFS 中，離開 $u$ 的子樹時再把 $u$ 的子樹內所有節點插入 trie，就保證 trie 中只有「已完成且不含 $u$、也非 $u$ 祖先」的節點**。

*細節*：標準寫法是「DFS 時先遞迴所有孩子，處理完一個孩子子樹就把它整棵插入 trie 並用 $u$ 的其他孩子去查」——這會在同一個父節點下配對不同孩子的子樹。**加上「$u$ 自己與已完成的兄弟子樹」的配對即可覆蓋所有不相交對**：任兩棵不相交子樹的根，其 LCA 是某個節點 $w$，且它們分別位於 $w$ 的不同孩子子樹中（或其中一個就是 $w$——但 $w$ 的子樹包含另一個，矛盾）✔。

**這題的價值在於化歸，不在 trie。** trie 只是最後一步的工具。**大部分 0-1 trie 的難題都長這樣：真正的難點是把題目化成「兩組數的最大異或對」，化成之後套模板。**

## C++17 模板

**模板一：421 陣列中兩個數的最大異或值（邊插邊查）**

```cpp
class Solution {
    static constexpr int B = 30;
    vector<array<int, 2>> ch;
    vector<int> cnt;
    int newNode() {
        ch.push_back({0, 0});
        cnt.push_back(0);
        return (int)ch.size() - 1;
    }
    void insert(int x) {
        int u = 0;
        for (int b = B; b >= 0; --b) {
            int d = x >> b & 1;
            if (!ch[u][d]) ch[u][d] = newNode();
            u = ch[u][d];
            ++cnt[u];
        }
    }
    int queryMax(int x) {
        int u = 0, res = 0;
        for (int b = B; b >= 0; --b) {
            int want = (x >> b & 1) ^ 1;
            int c = ch[u][want];
            if (c && cnt[c]) {
                res |= 1 << b;
                u = c;
            } else {
                u = ch[u][want ^ 1];
            }
        }
        return res;
    }

public:
    int findMaximumXOR(vector<int>& nums) {
        ch.assign(1, {0, 0});
        cnt.assign(1, 0);
        insert(nums[0]);
        int ans = 0;
        for (size_t i = 1; i < nums.size(); ++i) {
            ans = max(ans, queryMax(nums[i]));  // 只跟前面的配對，不重不漏
            insert(nums[i]);
        }
        return ans;
    }
};
```

**模板二：1803 統計異或值在範圍內的數對（定理 3 的計數）**

```cpp
class Solution {
    static constexpr int B = 14;  // nums[i], high <= 2e4 < 2^15
    vector<array<int, 2>> ch;
    vector<int> cnt;
    int newNode() {
        ch.push_back({0, 0});
        cnt.push_back(0);
        return (int)ch.size() - 1;
    }
    void insert(int x) {
        int u = 0;
        for (int b = B; b >= 0; --b) {
            int d = x >> b & 1;
            if (!ch[u][d]) ch[u][d] = newNode();
            u = ch[u][d];
            ++cnt[u];
        }
    }
    int countLess(int x, int L) {  // #{ y in trie : (x ^ y) < L }
        int u = 0, res = 0;
        for (int b = B; b >= 0 && u; --b) {
            int xb = x >> b & 1, Lb = L >> b & 1;
            if (Lb) {
                int c = ch[u][xb];
                if (c) res += cnt[c];
                u = ch[u][xb ^ 1];
            } else {
                u = ch[u][xb];
            }
        }
        return res;
    }

public:
    int countPairs(vector<int>& nums, int low, int high) {
        ch.assign(1, {0, 0});
        cnt.assign(1, 0);
        int ans = 0;
        for (int x : nums) {
            ans += countLess(x, high + 1) - countLess(x, low);
            insert(x);  // 邊查邊插：每對只算一次
        }
        return ans;
    }
};
```

**模板三：1707 與陣列中元素的最大異或值（離線 + 單調插入）**

```cpp
class Solution {
    static constexpr int B = 29;  // <= 1e9 < 2^30
    vector<array<int, 2>> ch;
    void insert(int x) {
        int u = 0;
        for (int b = B; b >= 0; --b) {
            int d = x >> b & 1;
            if (!ch[u][d]) {
                ch.push_back({0, 0});
                ch[u][d] = (int)ch.size() - 1;
            }
            u = ch[u][d];
        }
    }
    int queryMax(int x) {
        int u = 0, res = 0;
        for (int b = B; b >= 0; --b) {
            int want = (x >> b & 1) ^ 1;
            if (ch[u][want]) {
                res |= 1 << b;
                u = ch[u][want];
            } else {
                u = ch[u][want ^ 1];
            }
        }
        return res;
    }

public:
    vector<int> maximizeXor(vector<int>& nums, vector<vector<int>>& queries) {
        sort(nums.begin(), nums.end());
        int q = queries.size();
        vector<int> ord(q);
        iota(ord.begin(), ord.end(), 0);
        sort(ord.begin(), ord.end(),
             [&](int a, int b) { return queries[a][1] < queries[b][1]; });
        ch.assign(1, {0, 0});
        vector<int> ans(q, -1);
        size_t p = 0;
        for (int id : ord) {
            int x = queries[id][0], m = queries[id][1];
            while (p < nums.size() && nums[p] <= m) insert(nums[p++]);
            if (p > 0) ans[id] = queryMax(x);  // p == 0 表示集合為空
        }
        return ans;
    }
};
```

（模板三沒有 `cnt`，因為它**只插不刪**——這時「指標非空」與「子樹非空」等價。**一旦需要刪除就必須加回 `cnt`。**）

## 時間與空間複雜度

設 $n$ 為插入個數、$q$ 為查詢數、$B+1$ 為位數。

| 操作 | 時間 | 說明 |
| --- | --- | --- |
| `insert` | $O(B)$ | 恰好走 $B+1$ 層，沒有提前終止 |
| `queryMax` / `queryMin` | $O(B)$ | 同上 |
| `countLess` | $O(B)$ | 定理 3：一條路徑 + 沿路加 `cnt` |
| 刪除（`--cnt`） | $O(B)$ | 不回收節點 |

| 題目 | 時間 | 空間 |
| --- | --- | --- |
| 421 | $O(nB)$ | $O(nB)$ |
| 1707 | $O\!\big((n + q)\log + (n+q)B\big)$ | $O(nB)$ |
| 1803 | $O(nB)$ | $O(nB)$ |
| 1938 | $O\!\big((n+q)B\big)$ | $O(nB)$ |
| 2479 | $O(nB)$ | $O(nB)$ |

**空間才是 0-1 trie 的真實限制。** $n = 2\times10^5$、$B = 30$ ⇒ 最多 $6.2\times10^6$ 個節點，每節點兩個 `int` 孩子加一個 `int` 計數 = 12 bytes ⇒ **約 75 MB**。這已經逼近多數判題系統的 256 MB（含其他開銷）。三個對策：

1. **把 $B$ 壓到真正需要的位數**（1803 從 30 降到 14，空間直接砍一半以上）；
2. **用 `vector` 動態增長而非開滿靜態陣列**——實際節點數通常遠小於上界（共用前綴越多，節點越少）；
3. **改用「逐位雜湊」解法**（見下節），空間 $O(n)$。

**與暴力的對比**：421 暴力是 $O(n^2)$，$n = 2\times10^5$ 時是 $4\times10^{10}$；trie 是 $6\times10^6$。**這是 $10^4$ 倍的差距，而不是常數級的改善**——這種時候別猶豫，直接寫 trie。

## 常見錯誤與邊界條件

- **`B` 取太小**。最高位被截斷，答案系統性偏小。**由值域算，不要憑印象。** 例如「$\le 10^9$」需要 $B = 29$（$2^{30} > 10^9$），寫成 $B=20$ 就錯。
- **沒有補足前導零 / 用「有效位數」建樹**。這直接摧毀定理 1 的位權對齊前提。**所有數字必須從同一個最高位 $B$ 開始插入**，小的數字自然走出一串 `0` 邊。
- **支援刪除後仍用 `ch[u][b] != 0` 判空**。節點還在但 `cnt` 已經是 0，貪心會走進一棵空子樹，回傳一個不存在的 $y$。**一律用 `cnt[ch[u][b]] > 0`。**
- **查詢時 trie 為空**。`else` 分支走到節點 0（根）或未初始化的節點，結果是垃圾值而非崩潰。**421 要先插一個；1707 要判 `p > 0` 回傳 $-1$。**
- **自己跟自己配對**。421 若先把全部插入再逐一查詢，$x \oplus x = 0$ 不影響最大值（其他配對只會更大或相等），**所以 421 這麼寫剛好沒事**；但 **1803 這麼寫就會多算**（$x\oplus x = 0$ 可能落在 $[low, high]$ 內），而且每對會算兩次。**「邊查邊插」是這一族題的標準寫法，同時解決兩個問題。**
- **`countLess` 忘記處理 $u$ 變成 0（走到不存在的節點）**。要在迴圈條件或迴圈內 `break`，否則會讀到 `ch[0]`（根）的孩子，計數暴增。
- **`res |= 1 << b` 當 $b = 31$ 時溢位**。`1 << 31` 對 `int` 是 UB。**$B \le 30$ 時安全；要用到第 31 位就寫 `1LL << b` 並用 `long long`。**
- **負數**。0-1 trie 假設非負。有負數時先整體加上偏移量——**但要注意加偏移會改變異或的結果**，所以只有在題目本身是「比較大小 / 求第 K 小」時才能這樣做。**純異或題若含負數，正確做法是用補碼的完整 32 位（$B = 31$，配 `unsigned`）。**
- **`MAXN` 算錯**。靜態陣列版本的節點上界是 $n \times (B+1) + 1$，**不是 $n$，也不是 $n \times B$**。少算一層在極端測資上會越界。
- **1707 的答案要按原始查詢順序輸出**。排序時排的是索引，不是查詢本身；忘了這點會拿到亂序答案。
- **1803 的 `countLess(x, low)` 不是 `countLess(x, low - 1)`**。`countLess` 是嚴格小於，所以 $[low, high]$ 的計數是 `countLess(high+1) - countLess(low)`。**這一格差錯是這題的頭號 WA。**

## 與相似技巧的比較

- **與 7.1 一般 trie**：**同一個資料結構，$\Sigma = 2$。** 差別只有三點：等長 ⇒ 不需 `isEnd`、必定走滿、位權對齊使貪心成立。**7.1 的推論 1.1（前綴 ⟺ 祖先）在這裡就是「高位相同 ⟺ 同一棵子樹」。**
- **與「逐位雜湊」解法（421 的另一解）**：從高位往低位維護 `ans`，每一位試探 `ans | (1<<b)` 是否可達——把所有數的前 $b$ 位放進 `unordered_set`，檢查是否存在 $a, b$ 使 $a \oplus b = \text{候選}$。$O(nB)$ 時間、$O(n)$ 空間。**時間相同、空間好得多、程式短，但只適用「單一全域最大值」，無法處理帶約束的查詢（1707）或計數（1803）。** 421 單題建議用雜湊解，其餘用 trie。
- **與排序 + 相鄰比較（最小異或對）**：最小異或的兩個數在排序後必定相鄰。$O(n\log n)$、$O(1)$ 額外空間。**求最小用排序，求最大用 trie**——這個不對稱來自「最大異或的兩數在數值上通常相距很遠」。
- **與值域樹狀陣列 / 動態開點線段樹**：**0-1 trie 本質上就是值域上的動態開點線段樹**（`cnt` 就是區間計數）。兩者可互換，選擇看你要做什麼：**逐位貪心用 trie 直觀**（每一層直接對應一個位元決策），**區間求和、區間第 K 小用線段樹直觀**。「線段樹上二分找第 K 小」與「0-1 trie 上走訪」是同一個演算法的兩種寫法。
- **與可持久化 trie**：處理「任意區間 $[l,r]$ 內的最大異或」。對每個前綴建一個版本（共用未修改的節點，每版本新增 $O(B)$ 個節點），查詢用 `cnt[版本r] - cnt[版本l-1]` 判斷子樹是否非空。**空間 $O(nB)$，時間仍 $O(B)$。這是「約束雙側」時的通解**（定理 4 的討論）。
- **與線性基（XOR 基底）**：處理的是「**任意子集**的異或最大值」，是完全不同的問題——線性基做的是線性代數（$\mathbb{F}_2$ 上的高斯消去），0-1 trie 做的是集合查詢。**「選一個數配對」⇒ trie；「選任意多個數異或起來」⇒ 線性基。** 這兩者常被混淆，因為題面都寫「最大異或」。
- **與分治按位遞迴**：1803 也可以用「按最高位把數組分成兩半，遞迴統計跨組對」的分治法，$O(nB)$、$O(n)$ 空間、無需建樹。**本質上就是把 trie 的遞迴展開，不顯式存節點。** 空間敏感時值得考慮。

## 本節重點速查

- **0-1 trie = $\Sigma=2$ 的 trie，把整數看成定長位串。** 等長帶來三個簡化：不需 `isEnd`、必定走滿 $B+1$ 層、位權對齊使貪心成立。
- **定理 1（位權支配）**：最高相異位為 1 者較大，因為 $2^b > \sum_{i<b}2^i$。**這是高位優先貪心的唯一依據，前提是所有數字等長**——用「有效位數」建樹就全錯了。
- **求最大走相反位（`want = xb ^ 1`），求最小走相同位。** 但**最小異或對用排序後檢查相鄰對更簡單**，不要為了用 trie 而用 trie。
- **定理 3（計數分解）**：$\{v < L\}$ 可分解成 $O(B)$ 棵不交的完整子樹——沿一條路徑走，`L_b == 1` 時加上 `cnt[ch[u][xb]]` 再往 `xb^1` 走。**區間計數是 `countLess(high+1) - countLess(low)`，別寫成 `low-1`。**
- **「邊查邊插」是標準寫法**：同時解決「自己配自己」與「每對算兩次」。
- **約束單側（$y \le m$）⇒ 離線排序、只插不刪（定理 4）；約束雙側 ⇒ 可持久化 trie。** 這是分水嶺。
- **支援刪除就必須用 `cnt` 判空，不能用指標判空。** 節點不回收。
- **「路徑上的查詢」用 DFS 進出維護集合（定理 5）**，不必樹上倍增。
- **難題的難點通常在化歸**（2479 的「不相交子樹 ⟺ 互不為祖先」），trie 只是最後一步。
- **空間是真實限制**：$n=2\times10^5$、$B=30$ 約 75 MB。**先把 $B$ 壓到值域真正需要的位數。**
- **別跟線性基搞混**：「選一個數配對」⇒ trie；「選任意子集異或」⇒ 線性基。
