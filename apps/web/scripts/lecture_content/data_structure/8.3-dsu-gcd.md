## 這個技術解決什麼問題

一組數字，兩個數「有公因數」（或「$\gcd > $ 某個門檻」「$\mathrm{lcm} \le$ 某個門檻」）就連一條邊，問連通塊個數、最大連通塊、能否全連通、能否透過交換排序。

**直接兩兩配對是 $O(n^2\log V)$**（每對算一次 $\gcd$）。$n = 2\times10^4$ 就是 $4\times10^8$ 次 $\gcd$，過不了。

**核心想法**：*不要在數字之間直接連邊，改成「數字 — 質因數 — 數字」的兩層結構。* 把每個質數也當成並查集裡的一個節點，把每個數字與它的所有質因數合併。於是：

$$\gcd(a,b) > 1 \iff a \text{ 與 } b \text{ 有共同的質因數 } p \iff a \text{ 與 } b \text{ 都連到節點 } p.$$

**邊數從 $O(n^2)$ 降到 $O(n\log V)$**——因為一個 $\le 10^9$ 的數最多只有 9 個相異質因數（定理 2）。

**這是一個非常一般的手法，值得抽象記住：**

> **當「兩兩之間有邊」的條件可以寫成「共享某個屬性」時，就把屬性本身當成節點，把 $O(n^2)$ 的完全圖壓成 $O(n\cdot k)$ 的二分圖。**

同一個手法在其他地方也用：**947 移除石頭**（共享行號或列號 ⇒ 把行、列當節點）、**721 帳號合併**（共享 email ⇒ 把 email 當節點）、**1998／2709**（共享質因數）。**「共享屬性 ⇒ 屬性當橋樑」是本節真正要學的東西，質因數只是它最常見的實例。**

**辨識訊號**：連通條件裡出現 $\gcd$、$\mathrm{lcm}$、「有公因數」「互質」「共用因數」，而且 $n$ 大到不能兩兩枚舉。

## 狀態／資料結構定義

**節點集合 = 數字（或索引）$\cup$ 質數。** 兩種編號方式：

**（一）值域小（$V \le 10^5$ 左右）：直接開陣列，質數用它的值當編號**
```cpp
DSU dsu(V + 1);  // 節點 v 同時代表「值 v」與「質數 v」——它們本來就該是同一個
for (int x : nums)
    for (int p : primeFactors(x)) dsu.unite(x, p);  // 值 x 與質數 p 合併
```
**這裡有一個漂亮的巧合：質數 $p$ 自己也是一個可能出現的值，而「值 $p$」與「質數 $p$」本來就該同組**（$\gcd(p,p)=p>1$）。**所以共用同一個編號不但不衝突，還是正確的。**

**（二）值域大（$\le 10^9$）：質數用 `unordered_map<int,int>` 分配編號**
```cpp
DSU dsu(n + MAXPRIMES);  // 前 n 個是索引，之後是質數
unordered_map<int, int> pid;
auto getPid = [&](int p) {
    auto it = pid.find(p);
    if (it != pid.end()) return it->second;
    return pid[p] = n + (int)pid.size();
};
```
**此時節點要用「索引」而非「值」**——因為值可能重複，而題目通常問的是索引的連通性（1998 最大公因數排序、2709 最大公因數遍歷）。

**質因數分解的兩種方式，依值域選：**

```cpp
// (A) 試除，O(sqrt(x))：值域大時用
vector<int> primeFactors(int x) {
    vector<int> res;
    for (int p = 2; (long long)p * p <= x; ++p) {
        if (x % p) continue;
        res.push_back(p);
        while (x % p == 0) x /= p;
    }
    if (x > 1) res.push_back(x);  // 剩下的大質數，絕對不能漏
    return res;
}

// (B) 最小質因數篩（SPF），預處理 O(V log log V)，單次分解 O(log x)
vector<int> spf(V + 1);
void sieve() {
    iota(spf.begin(), spf.end(), 0);
    for (int i = 2; (long long)i * i <= V; ++i)
        if (spf[i] == i)
            for (int j = i * i; j <= V; j += i)
                if (spf[j] == j) spf[j] = i;
}
// 分解：while (x > 1) {
//     int p = spf[x]; res.push_back(p);
//     while (x % p == 0) x /= p;
// }
```

**選哪個**：$n$ 個數各做一次試除是 $O(n\sqrt V)$；SPF 篩是 $O(V\log\log V + n\log V)$。**$n\sqrt V$ vs $V$：$n$ 小值域大 ⇒ 試除；$n$ 大值域小 ⇒ 篩。** 952（$V \le 10^5$、$n \le 2\times10^4$）：$2\times10^4 \times 316 = 6\times10^6$ 試除也很快，兩者皆可。

**（三）「因數當橋樑」的變體（1627）**：條件是 $\gcd > T$ 而不是 $\gcd > 1$，此時**質數不夠用**（$\gcd$ 可能是合數），要枚舉所有 $> T$ 的因數當橋樑——見定理 3。

## 不變量或正確性證明

### 定理 1（質因數橋接的等價性）

設 $A$ 是給定的數字集合。定義兩個圖：

- $G_1$：頂點 $A$，$a$ 與 $b$ 相連 $\iff \gcd(a,b) > 1$。
- $G_2$：**二分圖**，頂點 $A \cup P$（$P$ = 出現過的所有質數），$a$ 與 $p$ 相連 $\iff p \mid a$。

**命題**：對任意 $a, b \in A$，**$a$ 與 $b$ 在 $G_1$ 中連通 $\iff$ 在 $G_2$ 中連通。**

*證明*。

- **($\Rightarrow$)** 只需證單條邊。設 $\gcd(a,b) = g > 1$，取 $g$ 的任一質因數 $p$，則 $p \mid a$ 且 $p \mid b$，故 $a - p - b$ 是 $G_2$ 中的路徑 ✔。連通性由路徑的串接得到。
- **($\Leftarrow$)** 設 $G_2$ 中有路徑 $a = a_0 - p_1 - a_1 - p_2 - \cdots - p_k - a_k = b$（二分圖的路徑必定數字與質數交錯）。對每個 $i$，$p_i$ 同時整除 $a_{i-1}$ 與 $a_i$，故 $\gcd(a_{i-1}, a_i) \ge p_i > 1$，即 $a_{i-1}$ 與 $a_i$ 在 $G_1$ 中直接相連 ✔。串起來得 $a$ 與 $b$ 在 $G_1$ 中連通。$\square$

**注意證明用到「二分圖的路徑必定交錯」**——這保證了路徑上的相鄰數字對都真的共享一個質數。**若你把「合數因數」也加進去當節點，這個性質仍然成立**（$d \mid a$ 且 $d \mid b$ $\Rightarrow \gcd \ge d > 1$），只是節點變多、白費工。**所以只用質因數，不是為了正確性，是為了效率。**

**兩個前提要點名：**

1. **$1$ 沒有質因數，所以它在 $G_2$ 中是孤立點。** 這與 $G_1$ 一致（$\gcd(1,x) = 1$），所以**不需要特判**——但很多人會下意識想「1 跟誰都能連」而寫錯。**2709 最大公因數遍歷的標準測資就是 `nums = [1]`（回傳 `true`，因為只有一個節點）與 `nums = [1,2]`（回傳 `false`）。**
2. **答案要的是「數字的連通性」，質數節點只是橋樑。** 統計連通塊大小時**不能把質數節點算進去**——要嘛只統計數字節點，要嘛在 `sz` 之外另開一個 `cntNum[root]` 只累加真實數字。**這是本節的頭號 bug。**

### 定理 2（每個數的相異質因數個數是 $O(\log V)$）

**命題**：$v \le 10^9$ 的相異質因數不超過 **9** 個。

*證明*：設 $v$ 有 $k$ 個相異質因數，則 $v \ge$ 最小的 $k$ 個質數之積。而
$$2\cdot3\cdot5\cdot7\cdot11\cdot13\cdot17\cdot19\cdot23 = 223\,092\,870 < 10^9,$$
$$2\cdot3\cdot5\cdot7\cdot11\cdot13\cdot17\cdot19\cdot23\cdot29 = 6\,469\,693\,230 > 10^9.$$
故 $k \le 9$ ✔。$\square$

**一般地，$v$ 的相異質因數個數是 $O(\log v / \log\log v)$**，上界 $\log_2 v$ 也夠用。**這就是為什麼「每個數連到它的所有質因數」只產生 $O(n\log V)$ 條邊，而不是更多。**

**實用的數字**（背下來，估複雜度時直接用）：

| 值域 | 相異質因數上限 |
| --- | --- |
| $10^5$ | 6 |
| $10^6$ | 7 |
| $10^9$ | 9 |
| $10^{18}$ | 15 |

### 定理 3（1627 帶閾值的圖連通性：因數當橋樑 + 調和級數）

*問題*：城市編號 $1..n$，$x$ 與 $y$ 相連 $\iff \gcd(x,y) > T$。回答若干組連通性查詢。

**關鍵等價**：
$$\gcd(x,y) > T \iff \exists\, d > T \text{ 使 } d \mid x \text{ 且 } d \mid y.$$
*證明*：($\Rightarrow$) 取 $d = \gcd(x,y)$ ✔。($\Leftarrow$) $d$ 是公因數 ⇒ $\gcd(x,y) \ge d > T$ ✔。$\square$

**所以橋樑不是質數，是「所有 $> T$ 的整數」。** 演算法：

```cpp
for (int d = T + 1; d <= n; ++d)
    for (int m = 2 * d; m <= n; m += d)
        dsu.unite(d, m);  // d 的所有倍數彼此相連
```

*正確性*：對每個 $d > T$，把 $d$ 的所有倍數合併成一組——這正好表達了「共享因數 $d$」。由上面的等價，並查集的連通性恰為題目的連通性 ✔。**這裡把 $d$ 自己當橋樑節點（$d$ 也是一個城市），與定理 1 的巧合同理。**

*複雜度*：內層迴圈執行 $\lfloor n/d \rfloor - 1$ 次，總計
$$\sum_{d=T+1}^{n} \left(\frac{n}{d} - 1\right) < n\sum_{d=T+1}^{n}\frac1d \approx n\ln\frac{n}{T} = O\!\left(n\log\frac{n}{T}\right).$$
**$T$ 越大越快；$T = 0$ 時退化成 $O(n\log n)$，仍完全可接受。** $\square$

**這個「枚舉 $d$ 及其倍數，總和是調和級數」的模式在數論題中反覆出現**（篩法、莫比烏斯、求所有數的因數和）。**看到「對每個 $d$ 掃它的倍數」，直接寫 $O(n\log n)$，不要以為是 $O(n^2)$。**

### 定理 4（1998 最大公因數排序：連通塊內可任意重排）

*問題*：可以任意次交換 $\text{nums}[i]$ 與 $\text{nums}[j]$，只要 $\gcd(\text{nums}[i], \text{nums}[j]) > 1$。問能否排成非遞減。

**引理（連通圖的邊生成整個對稱群）**：設 $G$ 是頂點集 $S$（$|S| = k$）上的連通圖。則由 $G$ 的邊所對應的對換 $\{(u\ v) : (u,v) \in E(G)\}$ 生成的置換群，就是 $S$ 上的**完整對稱群** $\mathfrak{S}_k$。

*證明*（對 $k$ 歸納）。$k=1$ 顯然。設 $k \ge 2$，取 $G$ 的一棵生成樹 $T$ 與其一個葉節點 $\ell$，設 $\ell$ 的唯一鄰居為 $u$。由歸納假設，$T - \ell$ 上的對換生成 $\mathfrak{S}_{S\setminus\{\ell\}}$。而任一對換 $(\ell\ v)$（$v \ne u$）可寫成
$$(\ell\ v) = (u\ v)\,(\ell\ u)\,(u\ v),$$
右側三個因子都已在生成集中（$(u\ v)$ 來自歸納假設，$(\ell\ u)$ 是樹邊）✔。故所有對換都能生成，而對換生成 $\mathfrak{S}_k$ ✔。$\square$

**推論**：**在同一個連通塊內，元素可以任意重排。**

*所以演算法是*：
1. 用質因數橋接建並查集（節點用**索引**，因為值可能重複）；
2. 把 `nums` 排序得到 `sorted`；
3. 檢查每個位置 $i$：`sorted[i]` 與 `nums[i]` 是否屬於同一個連通塊。全部符合則 `true`。

*步驟 3 的正確性*：
- **($\Leftarrow$ 全符合則可排序)**：連通塊 $C$ 佔據的位置集合固定（交換不會把元素移出連通塊——**因為連通性是定義在值上的，而交換不改變值的集合**）。由推論，塊內可任意重排，所以只要「排序後每個位置該放的值仍在原塊內」，就能達成 ✔。
- **($\Rightarrow$ 可排序則全符合)**：任何交換序列都不會把值移出它所屬的連通塊，故排序後位置 $i$ 上的值必與原本 $\text{nums}[i]$ 同塊 ✔。$\square$

**實作細節**：值有重複時，`sorted[i]` 與 `nums[i]` 可能是同一個值的不同出現。**用「值 → 代表根」的映射**（`root_of_value[v]`）比用索引更好寫，因為相同的值必定在同一個連通塊（$\gcd(v,v) = v > 1$，只要 $v > 1$）。**$v = 1$ 是例外：兩個 1 之間 $\gcd = 1$，不能交換——但它們也不需要交換（相同的值換了等於沒換），所以不影響結論。**

### 定理 5（952 與 2709：同一個並查集，兩種讀法）

**952 按公因數計算最大組件大小**：答案 = **數字節點**的最大連通塊大小。

由定理 1，連通塊就是「$\gcd > 1$ 關係的等價閉包」。**統計時要用 `cntNum[root]`（只算真實數字），不能用 `sz[root]`（含質數節點）。**

**2709 最大公因數遍歷**：問「任兩個索引之間是否都能到達」，即**是否只有一個連通塊**。

三個邊界：
- $n = 1$ ⇒ 直接 `true`；
- 有任何一個 $\text{nums}[i] = 1$ 且 $n > 1$ ⇒ `false`（1 是孤立點，定理 1 的前提 1）；
- 否則檢查所有索引是否同根。

**3378 統計最小公倍數圖中的連通塊數目**（見定理 6）與這兩題共用同一個框架，只是橋樑的選法不同。**認出「橋樑是什麼」是本節每一題的唯一難點。**

### 定理 6（3378 lcm 圖：用「最小倍數」當橋樑）

*問題*：$\text{nums}$ 互不相同，$a$ 與 $b$ 相連 $\iff \mathrm{lcm}(a,b) \le T$。求連通塊數。

**先砍掉不可能的**：$\mathrm{lcm}(a,b) \ge \max(a,b)$，故**任何 $> T$ 的元素都是孤立點**，直接各算一塊。以下只看 $\le T$ 的元素。

**演算法**：對每個 $g = 1, 2, \dots, T$：
- 令 $S_g = \{x \in \text{nums} : g \mid x\}$，若 $|S_g| \le 1$ 則跳過；
- 令 $m_g = \min S_g$；
- 對每個 $x \in S_g$，若 $\dfrac{x \cdot m_g}{g} \le T$，則 `unite(x, m_g)`。

**命題**：這樣得到的連通性，恰為題目定義的連通性。

*證明*。

- **（不多連）** 若演算法 `unite(x, m_g)`，則 $g \mid x$、$g \mid m_g$，故 $\gcd(x,m_g) \ge g$，於是
  $$\mathrm{lcm}(x, m_g) = \frac{x\,m_g}{\gcd(x,m_g)} \le \frac{x\,m_g}{g} \le T,$$
  即 $(x, m_g)$ 真的是一條邊 ✔。
- **（不漏連）** 設 $\mathrm{lcm}(a,b) \le T$，令 $g = \gcd(a,b)$。則 $a, b \in S_g$，且 $m_g \le \min(a,b)$。於是
  $$\frac{a\cdot m_g}{g} \le \frac{a\cdot b}{g} = \mathrm{lcm}(a,b) \le T,$$
  故演算法會 `unite(a, m_g)`；同理 `unite(b, m_g)`。**所以 $a$ 與 $b$ 透過 $m_g$ 連通** ✔。$\square$

**這個證明的漂亮之處在於第二部分**：不需要 $a$ 與 $b$ 直接相連，只要它們都連到 $m_g$ 就夠了——**用一個「代表元」把 $S_g$ 內部的星狀連接壓成 $O(|S_g|)$ 條邊，而不是 $O(|S_g|^2)$ 條。**「取最小者當中心」是這裡的關鍵，因為 $m_g$ 最小 ⇒ 與它做 lcm 最容易滿足門檻。

*複雜度*：外層 $g$ 從 1 到 $T$，內層掃 $g$ 的倍數 ⇒ $\sum_{g\le T} T/g = O(T\log T)$，與定理 3 同一個調和級數 ✔。

## C++17 模板

**模板一：952 按公因數計算最大組件大小（SPF 篩 + 質因數橋接）**

```cpp
class Solution {
    vector<int> fa;
    int find(int x) {
        while (fa[x] != x) {
            fa[x] = fa[fa[x]];
            x = fa[x];
        }
        return x;
    }
    void unite(int x, int y) {
        x = find(x);
        y = find(y);
        if (x != y) fa[x] = y;
    }

public:
    int largestComponentSize(vector<int>& nums) {
        int V = *max_element(nums.begin(), nums.end());
        vector<int> spf(V + 1);
        iota(spf.begin(), spf.end(), 0);
        for (int i = 2; (long long)i * i <= V; ++i)
            if (spf[i] == i)
                for (int j = i * i; j <= V; j += i)
                    if (spf[j] == j) spf[j] = i;

        fa.resize(V + 1);
        iota(fa.begin(), fa.end(), 0);
        for (int x : nums) {
            int t = x;
            while (t > 1) {
                int p = spf[t];
                unite(x, p);  // 值 x 與質數 p 同組
                while (t % p == 0) t /= p;
            }
        }
        unordered_map<int, int> cntNum;  // 只統計真實數字，不含質數節點
        int ans = 0;
        for (int x : nums) ans = max(ans, ++cntNum[find(x)]);
        return ans;
    }
};
```

**模板二：2709 最大公因數遍歷（值域大 ⇒ 試除 + 質數雜湊編號）**

```cpp
class Solution {
    vector<int> fa;
    int find(int x) {
        while (fa[x] != x) {
            fa[x] = fa[fa[x]];
            x = fa[x];
        }
        return x;
    }
    void unite(int x, int y) {
        x = find(x);
        y = find(y);
        if (x != y) fa[x] = y;
    }

public:
    bool canTraverseAllPairs(vector<int>& nums) {
        int n = nums.size();
        if (n == 1) return true;
        for (int x : nums)
            if (x == 1) return false;  // 1 是孤立點（定理 1 前提 1）

        fa.resize(n);
        iota(fa.begin(), fa.end(), 0);
        unordered_map<int, int> firstIdx;  // 質數 p -> 第一個含有 p 的索引
        for (int i = 0; i < n; ++i) {
            int t = nums[i];
            for (int p = 2; (long long)p * p <= t; ++p) {
                if (t % p) continue;
                auto [it, inserted] = firstIdx.try_emplace(p, i);
                if (!inserted) unite(i, it->second);
                while (t % p == 0) t /= p;
            }
            if (t > 1) {  // 剩下的大質數，絕對不能漏
                auto [it, inserted] = firstIdx.try_emplace(t, i);
                if (!inserted) unite(i, it->second);
            }
        }
        int r = find(0);
        for (int i = 1; i < n; ++i)
            if (find(i) != r) return false;
        return true;
    }
};
```

（**這裡不另外配置質數節點，改用「第一個擁有該質數的索引」當代表**——效果等價，省掉一半節點。**兩種寫法都對，選一種寫熟即可。**）

**模板三：1627 帶閾值的圖連通性（因數當橋樑 + 調和枚舉）**

```cpp
class Solution {
    vector<int> fa;
    int find(int x) {
        while (fa[x] != x) {
            fa[x] = fa[fa[x]];
            x = fa[x];
        }
        return x;
    }

public:
    vector<bool> areConnected(int n, int threshold,
                              vector<vector<int>>& queries) {
        fa.resize(n + 1);
        iota(fa.begin(), fa.end(), 0);
        for (int d = threshold + 1; d <= n; ++d) {
            for (int m = 2 * d; m <= n; m += d) {
                int a = find(d), b = find(m);
                if (a != b) fa[a] = b;
            }
        }
        vector<bool> ans;
        ans.reserve(queries.size());
        for (auto& q : queries) ans.push_back(find(q[0]) == find(q[1]));
        return ans;
    }
};
```

（`threshold == 0` 時所有城市都連通，上面的迴圈從 $d=1$ 開始會自動處理——**不需要特判**，但值得在腦中驗證一次。）

## 時間與空間複雜度

設 $n$ 為數字個數、$V$ 為值域上界、$T$ 為閾值、$q$ 為查詢數。

| 題目 | 時間 | 空間 |
| --- | --- | --- |
| 952 | $O(V\log\log V + n\log V \cdot \alpha)$ | $O(V)$ |
| 2709 | $O(n\sqrt{V}\,\alpha)$ | $O(n + \lvert P\rvert)$ |
| 1998 | $O(n\log n + n\sqrt{V}\,\alpha)$ | $O(n + V)$ |
| 1627 | $O\!\left(n\log\frac{n}{T}\cdot\alpha + q\,\alpha\right)$ | $O(n)$ |
| 3378 | $O(T\log T\cdot\alpha + n)$ | $O(T)$ |

**分解方式的選擇（這是本節唯一的效率決策）：**

| | 預處理 | 單次分解 | 何時用 |
| --- | --- | --- | --- |
| 試除 $O(\sqrt x)$ | 無 | $\sqrt{V}$ | $V$ 大（$10^9$）、$n$ 小 |
| SPF 篩 | $O(V\log\log V)$ | $O(\log x)$ | $V$ 小（$\le 10^6$）、$n$ 大 |

**乘出來比較**：$V = 10^5$、$n = 2\times10^4$ ⇒ 試除 $2\times10^4 \times 316 = 6.3\times10^6$；篩 $10^5 \times 3 + 2\times10^4\times17 = 6.4\times10^5$。**篩快 10 倍，但要多 $O(V)$ 空間。** $V = 10^9$ 時篩不可能，只能試除。

**並查集本身從來不是瓶頸**——$O(n\log V \cdot \alpha)$ 相對於分解成本可以忽略。**優化這類題要從「分解」與「枚舉方式」下手，不要去調並查集。**

**調和級數的實際數值**（估 1627、3378 這類枚舉時直接代）：$\sum_{d\le n} n/d \approx n\ln n$。$n = 10^4$ ⇒ $9.2\times10^4$；$n = 10^5$ ⇒ $1.2\times10^6$；$n = 10^6$ ⇒ $1.4\times10^7$。**全都很小，不用怕。**

## 常見錯誤與邊界條件

- **統計連通塊大小時把質數節點算進去**。`sz[root]` 包含橋樑節點，必須另外用 `cntNum[find(x)]` 只累加真實數字。**這是本節的頭號 bug，症狀是答案偏大。**
- **試除分解漏掉最後的大質數**。`for (p = 2; p*p <= x; ++p)` 結束後若 `x > 1`，剩下的 `x` 本身是質數，**必須加進去**。漏掉會讓「兩個大質數相同」的數字無法連通。
- **`p * p` 溢位**。$x \le 10^9$ 時 `p` 可達 $31623$，`p*p` 約 $10^9$ 仍在 `int` 範圍；**但 $x \le 10^{18}$ 時必須寫 `(long long)p * p`。** 養成一律加轉型的習慣。
- **忘記處理 1**。1 沒有質因數，是孤立點。**2709 的 `[1]` 回傳 `true`、`[1,2]` 回傳 `false`；952 中的 1 自成一塊（大小 1）。**
- **值重複時用「值」當節點卻要回答「索引」的問題**。1998 中 `nums` 可以有重複值，若用值當節點就分不清是哪一個索引。**解法：要嘛用索引當節點，要嘛（更簡單）用「值 → 根」的映射，因為相同的值必定同根。**
- **並查集陣列開得不夠大**。用值當節點時要開 `max(nums) + 1`；混用索引與質數時要開 `n + 質數個數`。**用 `unordered_map` 動態分配質數編號時，別忘了預留空間或改用 `vector` 動態擴容。**
- **1627 的 `threshold` 可能為 0**。迴圈從 `threshold + 1 = 1` 開始，$d=1$ 會把所有城市連起來——**這是正確的**（$\gcd \ge 1 > 0$），但要確認自己的迴圈邊界沒寫成 `d = max(2, threshold+1)`。
- **3378 忘記把 $> T$ 的元素各算一塊**。它們是孤立點，不能漏計。
- **`unordered_map` 在大量插入時退化**。質數個數可達 $O(n\log V)$；若 TLE，改用 `reserve` 或把質數離散化後用 `vector`。
- **以為「共用因數」要枚舉所有因數**。只需質因數（定理 1 的說明）。枚舉所有因數在 $\gcd > 1$ 的題目中是白費工，**但在 $\gcd > T$ 的題目中（1627）則是必要的**——兩者別搞混。

## 與相似技巧的比較

- **與 8.1／8.2**：本節不改變並查集本身，只是換了「節點是什麼」。**8.2 的建模是幾何／時間上的，本節的建模是數論上的。** 共同的抽象是「把 $O(n^2)$ 的完全圖用共享屬性壓成二分圖」。
- **與 947 移除石頭、721 帳號合併**：**完全同一個手法**——947 把「行號」「列號」當橋樑節點，721 把「email」當橋樑節點。**如果你會 721，本節你已經會了一半；剩下的一半是數論（怎麼分解、怎麼枚舉倍數）。**
- **與直接建圖 + BFS**：邊數 $O(n\log V)$，BFS 也是 $O(n\log V)$，**複雜度相同**。並查集的優勢是**不用顯式存邊**（省記憶體）、以及支援「邊加邊查」。**只問一次連通塊數的話，BFS 完全可行且更直觀。**
- **與莫比烏斯反演／狄利克雷前綴和**：那些解決的是「有多少對數的 $\gcd$ 恰為 $d$」這類**計數**問題，本節解決的是**連通性**問題。**兩者常出現在同一題的不同小問中，枚舉倍數的調和級數技巧是共通的。**
- **與線性篩（歐拉篩）**：SPF 篩是 $O(V\log\log V)$，線性篩是 $O(V)$。**在 $V \le 10^6$ 的規模下兩者實測差距不到 2 倍**，SPF 篩程式短、不易寫錯，**優先用 SPF。**
- **與 8.4／8.5**：那兩節的 `fa` 表達的是「下一個可用位置」，與連通性無關。**本節的 `fa` 仍是正統的等價類**——不要把 8.4 的直覺帶進來。

## 本節重點速查

- **核心手法**：「兩兩有邊」的條件若能寫成「共享某個屬性」，就**把屬性當成節點**，$O(n^2)$ 完全圖 ⇒ $O(nk)$ 二分圖。質因數只是最常見的屬性；947 是行列，721 是 email。
- **定理 1**：$\gcd(a,b)>1 \iff$ 共享質因數 $\iff$ 在「數字—質數」二分圖中相連。**只用質因數就夠**（合數因數不增加連通性）。
- **兩個前提**：**1 沒有質因數 ⇒ 孤立點**（2709 的 `[1,2]` 是 `false`）；**質數節點不能算進連通塊大小**（頭號 bug，要另開 `cntNum`）。
- **值域小時「值 $v$」與「質數 $v$」可以共用同一個編號**——它們本來就該同組。
- **定理 2**：$v\le10^9$ 最多 9 個相異質因數（$2\cdots23 = 2.2\times10^8$，再乘 29 就超過 $10^9$）。所以邊數是 $O(n\log V)$。
- **$\gcd > T$（1627）不能只用質數**——要枚舉所有 $d > T$ 當橋樑，因為 $\gcd(x,y)>T \iff \exists d>T$ 同時整除兩者。複雜度是調和級數 $O(n\log\frac{n}{T})$。
- **定理 4（1998）**：連通圖的邊對換生成完整對稱群 ⇒ **連通塊內可任意重排**。判斷方式：排序後每個位置的值是否仍與原值同塊。
- **定理 6（3378）**：$\mathrm{lcm}(a,b)\le T$ 用 **$S_g$ 中的最小元素當中心**做星狀連接——因為 $\frac{a\,m_g}{g}\le\frac{ab}{g}=\mathrm{lcm}(a,b)$，$m_g$ 最小最容易過門檻。$>T$ 的元素各自孤立。
- **分解方式**：$V$ 大 $n$ 小 ⇒ 試除 $O(\sqrt V)$（**別漏掉最後的大質數**）；$V$ 小 $n$ 大 ⇒ SPF 篩。
- **並查集從來不是瓶頸**，優化要從分解與枚舉下手。
- **「對每個 $d$ 掃它的倍數」是 $O(n\log n)$，不是 $O(n^2)$。**
