## 這個技術解決什麼問題

爬樓梯是**整個動態規劃章的第一課**，但它要教的不是那條 $f(n) = f(n-1) + f(n-2)$ 的式子——那個誰都背得起來。它要教的是**寫下遞推式時，你到底在主張什麼**。

一條 DP 轉移式其實是一個數學命題：

> **「所有可行方案的集合，被這幾個分支不重不漏地劃分了。」**

**寫錯 DP 的人，幾乎都是這句話沒成立**：要嘛漏了一種情況（少算），要嘛兩個分支數到了同一個方案（重複計數）。**本節把這句話講清楚，後面 60 節都會反覆用到它。**

**辨識訊號**：
- 問「總共有幾種方法」或「最少／最多多少」，而且每一步的選擇有限（爬 1 或 2 階、選或不選）；
- 當前答案只跟「前面固定幾個位置」有關；
- 暴力遞迴會把同一個子問題重算很多次。

## 狀態／資料結構定義

**線性遞推 DP 的狀態就是一個下標**：

$$f(i) \;=\; \text{「以 } i \text{ 為終點」的方案數（或最優值）}.$$

**「以 $i$ 為終點」這五個字是關鍵**——不是「前 $i$ 個裡面的答案」。兩者的差別在後面 1.3（Kadane）會炸開來。

```cpp
// 骨架 A：完整陣列（初學、除錯、需要回溯方案時用）
vector<long long> f(n + 1);
f[0] = 1;
f[1] = 1;  // 邊界：走 0 階有 1 種「什麼都不做」的方法
for (int i = 2; i <= n; i++) f[i] = f[i - 1] + f[i - 2];

// 骨架 B：滾動變數（定理 3 說明為什麼安全）
long long a = 1, b = 1;  // a = f(i-2), b = f(i-1)
for (int i = 2; i <= n; i++) {
    long long c = a + b;  // 先算，再搬
    a = b;
    b = c;
}
// C++17 也可以寫成 tie(a, b) = pair{b, a + b};
```

**邊界值 `f[0] = 1` 常被寫成 0。** 判準：**$f(0)$ 是「湊出總和 0 的方案數」，空集合本身就是一種方案** ⇒ 應為 1。**寫成 0 會讓所有計數整體歸零。**

**多維推廣（377、2466 這類「每步有多種選擇」）**：

```cpp
vector<int> f(target + 1);
f[0] = 1;
for (int c = 1; c <= target; c++)  // 外層：容量
    for (int x : nums)             // 內層：選項
        if (x <= c) f[c] = (f[c] + f[c - x]) % MOD;
// 這個迴圈順序算的是「排列數」，不是「組合數」——定理 2
```

## 不變量或正確性證明

### 定理 1（加法原理的前提：不重不漏的劃分）

*命題*：設 $S_n$ 為「爬到第 $n$ 階的所有方案」之集合。令

$$A = \{\, \sigma \in S_n : \sigma \text{ 的最後一步是 1 階} \,\},\qquad
B = \{\, \sigma \in S_n : \sigma \text{ 的最後一步是 2 階} \,\}.$$

則 $S_n = A \sqcup B$，且 $|A| = |S_{n-1}|$、$|B| = |S_{n-2}|$，故 $f(n) = f(n-1) + f(n-2)$。

*證明*。
- **(不漏)** 每個非空方案都有一個最後一步，而題目規定每步只能是 1 或 2 ⇒ 必屬 $A$ 或 $B$ ✔。
- **(不重)** 同一個方案的最後一步大小是唯一確定的 ⇒ $A \cap B = \varnothing$ ✔。
- **(雙射)** 把 $\sigma \in A$ 的最後一步砍掉，得到一個爬到 $n-1$ 階的方案；反過來在任一 $S_{n-1}$ 的方案末端接一個 1 階，得到 $A$ 的元素。**兩個映射互為反函數 ⇒ 是雙射** ⇒ $|A| = |S_{n-1}|$ ✔。$B$ 同理。$\square$

**這三步（不漏／不重／雙射）就是所有計數 DP 的證明格式。** 往後每寫一條計數轉移式，都應該能填出這三格：

| 檢查 | 問題 |
| --- | --- |
| **不漏** | 有沒有哪個方案不屬於任何分支？ |
| **不重** | 有沒有哪個方案同時屬於兩個分支？ |
| **雙射** | 分支 $k$ 的元素，砍掉最後一段之後，恰好是某個子問題的方案嗎？ |

**「不重」最常被跳過，而它正是最容易錯的一格**——定理 2 就是一個例子。

### 定理 2（377 組合總和 Ⅳ：迴圈順序決定你在數什麼）

*命題*：設 `nums` 中元素互異。

$$\underbrace{\texttt{for c: for x:}}_{\text{外容量、內選項}} \;\Longrightarrow\; \text{數的是「有序的排列數」},$$
$$\underbrace{\texttt{for x: for c:}}_{\text{外選項、內容量}} \;\Longrightarrow\; \text{數的是「無序的組合數」}.$$

*證明*。兩者用的是**不同的劃分依據**。
- **外容量內選項**：對每個 $c$，按「**最後一個**被加入的元素是 $x$」劃分。不同的 $x$ 給出不同的分支 ⇒ 不重 ✔；每個非空序列都有唯一的最後一個元素 ⇒ 不漏 ✔。**因為「最後一個是誰」是有序資訊，數出來的是排列** ✔。
- **外選項內容量**：對每個前綴物品集 $\{x_1,\dots,x_k\}$ 與容量 $c$，$f_k(c)$ 表示「只用前 $k$ 種元素湊出 $c$」的方案數，按「**$x_k$ 用了幾個**」劃分。用量不同 ⇒ 不重 ✔；用量必為某個非負整數 ⇒ 不漏 ✔。**這裡完全沒有「順序」的資訊，數出來的是多重集合，也就是組合** ✔。$\square$

**這是初學者最痛的一個坑**：兩份程式碼只差兩行迴圈的順序，答案卻是完全不同的東西。**判斷方法不是背，而是問自己「我的劃分依據是什麼」**——「最後一個是誰」有序，「這種用了幾個」無序。

**377 要的是排列**（題目明說順序不同視為不同組合），**518 零錢兌換 II 要的是組合**。**看到「湊總和的方法數」，先確認題目在不在意順序。**

### 定理 3（滾動變數的更新順序為什麼安全）

*命題*：把 $f(i) = f(i-1) + f(i-2)$ 壓成兩個變數 $(a, b) = (f(i-2), f(i-1))$，執行

$$c \leftarrow a + b;\qquad a \leftarrow b;\qquad b \leftarrow c$$

之後 $(a, b) = (f(i-1), f(i))$，不變量得以維持。

*證明*。**關鍵在於「先把所有要讀的值讀完，再開始寫」。** 第一行讀 $a, b$ 並把結果存進**新變數** $c$；後兩行的寫入只覆蓋已經不再需要的 $a$，以及已被 $c$ 保存的 $b$ ✔。$\square$

**反例（把三行壓成兩行）**：`a = b; b = a + b;` ✘——第二行的 `a` 已經被改成舊的 `b`，算出來是 $2f(i-1)$。

**這條看起來瑣碎的定理，是整章「滾動陣列」的原型。** 3.1 0-1 背包倒序、3.2 完全背包正序，本質都是同一個問題：**「我讀到的，是這一輪的值還是上一輪的值？」** 每次壓縮維度時，都要重新回答一次。

### 定理 4（無後效性：這條遞推式依賴的隱含前提）

*命題*：$f(n) = f(n-1) + f(n-2)$ 成立，依賴一個沒有寫出來的前提——

> **從第 $i$ 階往上爬的可行方案集合，只取決於 $i$，與「你是怎麼走到 $i$ 的」完全無關。**

**這就是「無後效性」，也是狀態定義完備的形式化條件**（見 13.1 定理 1 的同一個判準）。

*為什麼要點名它*。把題目改成「**不能連續爬兩次 2 階**」，前提立刻失效：站在第 $i$ 階時，能不能爬 2 階取決於上一步是什麼。**此時 $f(i)$ 這個狀態不完備，必須拆成 $f(i, 0)$（上一步爬 1 階）與 $f(i, 1)$（上一步爬 2 階）** ✔。

**檢查無後效性的標準動作**：**構造兩條走到 $i$ 的不同路徑，看它們的後續選擇是否相同。** 不同 ⇒ 狀態不完備，加維度。

**這個檢查會貫穿整章**：6 節狀態機 DP 加的是「持股狀態」、9 節狀壓 DP 加的是「已用集合」、10 節數位 DP 加的是「是否貼上限」——**每一個都是同一個檢查失敗後補上的維度。**

### 定理 5（2266 統計打字方案數：乘法原理的前提）

*問題*：一串按鍵記錄按相同字元分成若干段，每段長度 $L$ 對應若干種可能的原文。求總方案數。

*命題*：總方案數 $= \prod_{\text{段}} g(L_j)$，其中 $g$ 是單段的方案數。

*證明*。**乘法原理成立的前提是「各段的選擇彼此獨立」。** 這裡成立，因為相鄰兩段的按鍵字元不同 ⇒ 段的邊界是強制的，任何一段怎麼拆都不會影響另一段的可拆法 ✔。$\square$

**段內的 $g$ 又是本節的遞推**：一個字母最多連打 3 次（`7`、`9` 是 4 次）⇒

$$g(L) = g(L-1) + g(L-2) + g(L-3) \quad (\text{Tribonacci}),$$

劃分依據是「**最後一組用了幾個相同按鍵**」——**不漏（1、2 或 3 個）、不重（個數唯一）、雙射（砍掉最後一組）** ✔ 完全套用定理 1 的三格檢查。

**要點名的前提**：「段邊界是強制的」依賴**相鄰段字元必不相同**（否則它們本來就是同一段）。**若題目允許同字元的段被人為切開，乘法原理立刻失效、會嚴重重複計數。**

### 定理 6（746 最小花費爬樓梯：邊界在哪裡）

*命題*：設 $\mathit{cost}$ 長度為 $n$，定義 $f(i)$ 為「到達下標 $i$」的最小花費，則

$$f(0) = f(1) = 0,\qquad f(i) = \min\big(f(i-1) + \mathit{cost}[i-1],\; f(i-2) + \mathit{cost}[i-2]\big),$$

答案為 $f(n)$。

*為什麼答案是 $f(n)$ 而不是 $f(n-1)$*。題目的「樓頂」在最後一階**之外** ⇒ 下標 $n$ ✔。**這是本題最主要的 WA 來源。**

*為什麼 $f(0) = f(1) = 0$*。可以從下標 0 或 1 起步，**起步本身不花錢，花的是「離開」某階的費用** ✔。

**這裡展示的是一個通用習慣**：

> **把「花費記在進入時」還是「記在離開時」想清楚，並寫進註解。**

**最優化型 DP 的定理 1 對應版本**是「**最優子結構**」：$f(i)$ 的最優解，其「砍掉最後一步」的部分必定是 $f(i-1)$ 或 $f(i-2)$ 的最優解。*證明*用**剪貼論證**：若不是，把子問題換成更優的解，總花費會更小，與 $f(i)$ 最優矛盾 ✔。**計數型用「不重不漏」，最優化型用「剪貼論證」——兩種證明格式，往後交替出現。**

## 時間與空間複雜度

| 寫法 | 時間 | 空間 | 適用 |
| --- | --- | --- | --- |
| 完整 `dp` 陣列 | $O(n)$ | $O(n)$ | 需要回溯方案、除錯 |
| 滾動變數（定理 3） | $O(n)$ | $O(1)$ | 一般情況 |
| 每步有 $k$ 種選擇（377、2466） | $O(nk)$ | $O(n)$ | 選項集合大小為 $k$ |
| 分段獨立 + 乘法原理（2266） | $O(n)$ | $O(1)$ | 段內遞推 + 段間相乘 |
| 矩陣快速冪（見 11.6） | $O(k^3 \log n)$ | $O(k^2)$ | $n$ 大到 $10^{18}$ |

**溢位是本節第一大死因**：$f(45)$ 已超過 $10^9$，$f(90)$ 超過 `long long`。**計數題幾乎都會給模數，忘了取模就是 WA；沒給模數的（如 70，$n \le 45$）要確認 `int` 夠不夠。**

**空間的實務建議**：$n \le 10^6$ 時 $O(n)$ 的 `long long` 陣列是 8 MB，完全可接受。**先寫完整陣列（好除錯），確定對了再壓成滾動變數。** 反過來做，錯了會很難查。

## 與相似技巧的比較

- **與遞迴 + 記憶化**：兩者等價，複雜度相同。**遞推（自底向上）的優勢是沒有遞迴開銷、可以壓空間；記憶化（自頂向下）的優勢是不必想清楚填表順序**，而且**只會計算真正到得了的狀態**。2.2 網格 DP 的 329 就是「填表順序想不出來 ⇒ 用記憶化」的典型。
- **與 1.2 打家劫舍**：1.1 是「方案數／最小花費」，1.2 是「選或不選且相鄰互斥」。**結構完全相同（都只看前一兩格），差別只在轉移式裡是 `+` 還是 `max`。** 把 1.1 的 `+` 換成 `max` 就是 1.2。
- **與 1.3 Kadane**：1.1 的 $f(i)$ 是「到達 $i$」，1.3 的 $f(i)$ 是「以 $i$ 結尾」，而**答案在 1.1 是 $f(n)$、在 1.3 是 $\max_i f(i)$**。**這個差別是 1.3 的全部難點所在。**
- **與 3 節背包**：377 的「外容量內選項」其實就是**完全背包的排列版**。**背包章的所有迴圈順序討論，源頭都在定理 2。**
- **與 11.6 矩陣快速冪**：當 $n$ 大到 $10^{18}$，$O(n)$ 也不夠。**線性常係數遞推都可以寫成矩陣冪**，複雜度變 $O(k^3\log n)$。**判準：轉移是固定的線性組合，且 $n$ 極大。**
- **與 15 節機率／期望 DP**：把「方案數」換成「機率」，加法原理變成全機率公式，**不重不漏的要求一模一樣**（機率的可加性同樣需要互斥事件）。

## 本節重點速查

- **DP 轉移式 = 一個數學命題**：「所有方案被這些分支**不重不漏**地劃分」。
- **定理 1（計數 DP 的證明格式）**：**不漏**（每個方案都屬於某分支）／**不重**（沒有方案屬於兩個分支）／**雙射**（砍掉最後一段恰得子問題的方案）。**三格填不出來，轉移式就有問題。**
- **定理 2（迴圈順序）**：**外容量內選項 ⇒ 排列**（劃分依據「最後一個是誰」，有序）；**外選項內容量 ⇒ 組合**（劃分依據「這種用了幾個」，無序）。**377 要排列、518 要組合。**
- **定理 3（滾動更新）**：**先讀完再寫。** `c = a+b; a = b; b = c;` ✔；`a = b; b = a+b;` ✘。**整章「滾動陣列」都是這條的推廣——每次壓維度都要重問「我讀到的是這輪還是上輪的值」。**
- **定理 4（無後效性）**：$f(i)$ 完備 $\iff$ 從 $i$ 出發的後續只取決於 $i$。**檢查法：構造兩條到 $i$ 的路徑，後續選擇不同 ⇒ 加維度。** 狀態機／狀壓／數位 DP 的額外維度全是這個檢查失敗的產物。
- **定理 5（乘法原理）**：分段相乘的前提是**段間選擇獨立**（2266 靠「相鄰段字元不同」保證）。段內 Tribonacci 的劃分依據是「最後一組用了幾個」。
- **定理 6（邊界與最優子結構）**：$f(0)=1$（空方案也是方案，計數型）；746 的答案是 $f(n)$ 不是 $f(n-1)$；**花費記在「進入」還是「離開」要寫進註解。** 最優化型用**剪貼論證**取代不重不漏。
- **溢位**：$f(45) > 10^9$、$f(90) >$ `long long`。**有模數就每步取模。**
