## 這個技術解決什麼問題

打家劫舍是**「選或不選」型 DP 的原型**，也是整章最常被偽裝的模型。它的數學本體是：

> **在一條路徑圖上求最大權獨立集。**

「相鄰兩個不能同時選」就是獨立集的定義。**一旦認出這件事，一整批看起來毫無關聯的題目就會塌縮成同一題**——刪除並獲得點數（值域排成一排）、解決智力問題（帶跳躍的間隔）、統計放置房子的方式數（把 `max` 換成 `+`）。**而 12.2 樹上最大獨立集，不過是把「路徑」換成「樹」。**

**辨識訊號**：
- 沿一排元素做選擇，且「選了某個就不能選它旁邊的」；
- 限制可以**轉成**「相鄰互斥」（740 是「選 $x$ 就不能選 $x\pm1$」，2140 是「解了某題就跳過後面幾題」）；
- 每個位置只有有限幾種狀態，且只依賴前面一兩格。

**本節真正要教的**：**如何驗證一個「歸約」是對的**（定理 3），以及**最優化型 DP 為什麼可以容忍「重疊覆蓋」而計數型不行**（定理 2）——後者是很多人把 213 的技巧錯誤地套到計數題上的原因。

## 狀態／資料結構定義

**兩種等價的狀態定義，選一種貫徹到底：**

```cpp
// 定義甲（前綴型）：f[i] = 只考慮前 i 間房子的最大金額
//   f[i] = max(f[i-1], f[i-2] + nums[i-1]);        // 注意下標偏移
// 定義乙（狀態機型）：g[i][0/1] = 考慮到第 i 間、第 i 間「未選/已選」的最大金額
//   g[i][0] = max(g[i-1][0], g[i-1][1]);
//   g[i][1] = g[i-1][0] + nums[i];
```

**定義甲短，定義乙好推廣。** 判準：

| 情況 | 選哪個 |
| --- | --- |
| 純相鄰互斥、只求一個值 | **甲**（滾動成兩個變數） |
| 要計數（2320）、要輸出方案、間隔規則變複雜 | **乙**（顯式狀態機，見 6 節） |

**滾動版本（定理 5 說明順序為什麼安全）**：

```cpp
int rob(const vector<int>& nums) {
    int pre2 = 0, pre1 = 0;  // pre2 = f[i-2], pre1 = f[i-1]
    for (int x : nums) {
        int cur = max(pre1, pre2 + x);  // 先算
        pre2 = pre1;
        pre1 = cur;  // 再搬
    }
    return pre1;
}
```

**`pre2 = pre1 = 0` 同時處理了「空陣列」與「只有一間房」**——不需要特判 ✔。**這是「邊界值選得好，特判就消失」的典型例子。**

**從記憶化搜尋 1:1 翻譯成 DP 陣列時，大小由遞迴參數的完整可達範圍決定。** 若參數 `i`（包含邊界狀態）的範圍是閉區間 `[L, R]`，就需要 `R - L + 1` 格，並用 `i - L` 當陣列下標。例：`i ∈ [-1, n-1]` 需要 `n + 1` 格；`i ∈ [-2, n-1]` 需要 `n + 2` 格。也可以把狀態改寫成「前 `i` 個」來消除負下標，但必須同步重推初值與轉移。

## 不變量或正確性證明

### 定理 1（選或不選：最優子結構）

*命題*：設 $f(i)$ 為「只考慮前 $i$ 間房子、滿足相鄰互斥」的最大金額，則

$$f(i) = \max\big(\, f(i-1),\;\; f(i-2) + \mathit{nums}[i-1] \,\big),\qquad f(0) = 0,\; f(1) = \mathit{nums}[0].$$

*證明*。設 $O$ 為前 $i$ 間的一個最優方案。按「第 $i$ 間選不選」分兩種情況——**不漏**（一定是其中之一）、**不重**（互斥）✔。

- **(未選第 $i$ 間)** $O$ 也是前 $i-1$ 間的一個合法方案 ⇒ $\mathrm{val}(O) \le f(i-1)$。
- **(選了第 $i$ 間)** 由相鄰互斥，$O$ 不含第 $i-1$ 間 ⇒ $O \setminus \{i\}$ 是前 $i-2$ 間的合法方案 ⇒ $\mathrm{val}(O) \le f(i-2) + \mathit{nums}[i-1]$。

故 $f(i) \le \max(\cdot,\cdot)$。反向不等式：右側兩項各自都對應一個**合法**的前 $i$ 間方案（第二項合法，因為 $f(i-2)$ 的方案不含第 $i-1$ 間，接上第 $i$ 間仍互斥 ✔），故 $f(i) \ge \max(\cdot,\cdot)$。兩邊夾擠 ⇒ 等號成立 $\square$

**「反向不等式」這半段常被跳過，但它才是真正會出錯的地方**——它要求「**由子問題的解拼出來的東西必須仍然合法**」。若題目改成「不能選相鄰**兩格以內**」，$f(i-2)$ 的方案可能含第 $i-2$ 間，接上第 $i$ 間就違規 ⇒ **必須改成 $f(i-3)$** ✔。**每次改規則，都要重跑這半段。**

**要點名的前提**：定理 1 沒有用到 $\mathit{nums}[i] \ge 0$。**即使有負數，`max` 也會自動選擇不拿** ✔——**這是「取 max」比「取和」穩健的地方。**

### 定理 2（213 環形：為什麼「取兩次 max」是對的，而計數題不能這樣做）

*命題*：環形版本的答案 $= \max\big(\mathrm{rob}(\mathit{nums}[0..n-2]),\; \mathrm{rob}(\mathit{nums}[1..n-1])\big)$（$n \ge 2$）。

*證明*。
- **($\ge$，兩個子問題都合法)** 去掉最後一間後，首尾不再相鄰 ⇒ 線性問題的任一合法解也是環形問題的合法解 ✔。另一半同理。
- **($\le$，覆蓋性)** 環形的最優解 $O$ **不可能同時包含第 0 間與第 $n-1$ 間**（它們相鄰）⇒ $O$ 至少缺少其中一個 ⇒ $O$ 落在兩個子問題的至少一個裡 ✔。$\square$

**注意這裡用的是「覆蓋」而不是「劃分」**：兩個子問題**有交集**（既不選 0 也不選 $n-1$ 的方案被數了兩次）。

> **最優化型 DP 可以容忍重疊覆蓋，因為 $\max(a, a) = a$；計數型絕對不行，因為 $a + a \ne a$。**

**這是本節最容易被誤用的一條。** 若把 213 的技巧原封不動套到 2320（計數版）上，**會把「首尾都不選」的方案數重複計算一次**。**計數的環形問題必須用「劃分」而非「覆蓋」**：按「第 0 間選 / 不選」嚴格二分，兩支分別做線性計數 ✔。

**推論 2.1**：$n = 1$ 時要特判（`nums[0..-1]` 是空區間）。**把 $n=1$ 丟進上式會回傳 $\max(0, \mathit{nums}[0])$——恰好也對，但那是巧合，寫特判比較誠實。**

### 定理 3（740 刪除並獲得點數：歸約的驗證）

*問題*：選一個數 $x$ 可得 $x$ 分，但會刪光所有 $x-1$ 與 $x+1$。求最大總分。

**歸約**：令 $\mathit{cnt}[v]$ 為值 $v$ 的出現次數，$w[v] = v \cdot \mathit{cnt}[v]$。**在值域 $0,1,2,\dots,V$ 這條路徑上跑打家劫舍。**

*要證明兩件事*：

**(a) 最優解中，若選了值 $v$ 的某個實例，則選光所有值為 $v$ 的實例不劣。**
*證明*。選第一個 $v$ 之後，$v\pm1$ 已全被刪除；再選其餘的 $v$ **不會產生任何新的刪除**（$v$ 的鄰居已經沒了），而每個都額外貢獻 $v \ge 0$ 分 ✔。故存在一個最優解，其選取的值集合可以用「哪些 $v$ 被完整選取」來描述 ✔。

**(b) 值集合 $S$ 合法 $\iff$ $S$ 中沒有兩個相鄰整數。**
*證明*。若 $v, v+1 \in S$，選了 $v$ 就刪光 $v+1$，矛盾 ✔；反之若 $S$ 無相鄰整數，按任意順序選取，刪除操作只會刪到不在 $S$ 中的值 ✔。$\square$

**於是原題 $\equiv$ 在值域路徑上的最大權獨立集，權重 $w[v]$** ✔。

**這兩步就是「歸約」的標準驗收**：
1. **證明最優解可以被限制成某種標準形**（(a)，這裡是「同值全取」）；
2. **證明標準形與新問題的可行解一一對應**（(b)）。

**跳過第 1 步是歸約類題目最常見的漏洞。** 注意 (a) 依賴 $v \ge 0$——**若分數可能為負，「全取」就不再不劣，歸約失效。**

**實作陷阱**：**值域是 $[1, 10^4]$，要按值域建陣列而不是按下標。** 排序後直接對原陣列做打家劫舍是錯的（相同的值會被當成相鄰而互斥）✘。

### 定理 4（2140 解決智力問題：為什麼必須倒著推）

*問題*：解第 $i$ 題得 $\mathit{score}[i]$ 分，但接下來 $\mathit{brainpower}[i]$ 題都不能解。求最大總分。

*命題*：正確的遞推是**倒序**的：

$$f(i) = \max\big(\, f(i+1),\;\; \mathit{score}[i] + f\big(\min(n,\; i + \mathit{brainpower}[i] + 1)\big) \,\big),\qquad f(n) = 0.$$

*為什麼不能正序*。「跳過」這個動作是**向後**作用的：選了第 $i$ 題會影響 $i+1, \dots, i+b_i$。若定義 $g(i)$ 為前綴最優值，則要算 $g(i)$ 必須知道「前面有沒有哪一題的跳躍範圍蓋到 $i$」——**這個資訊不在 $g$ 的狀態裡，無後效性不成立** ✘。

倒序定義 $f(i) = $「從第 $i$ 題開始往後」的最優值，則約束「選了 $i$ 就從 $i+b_i+1$ 繼續」**完全落在子問題內部** ✔ 無後效性成立。$\square$

**通用判準（往後 60 節都適用）**：

> **約束是「向前看」的（依賴之前的選擇）⇒ 正序 DP。
> 約束是「向後推」的（影響之後的選擇）⇒ 倒序 DP，狀態定義成「從 $i$ 開始的後綴」。**

**前提**：$\mathit{brainpower}[i] \ge 0$，跳躍不會往回 ⇒ 遞推無環 ✔。**若跳躍可能為負，狀態圖有環，DP 失效，要改用最短路或 13.1 定理 3 的逆向推理。**

**別忘了 `min(n, ...)` 夾住上界**——$i + b_i + 1$ 可能超出陣列 ✘。

### 定理 5（2320 計數版：`max` 換成 `+`，但兩件事要重新驗）

*問題*：街道兩側各 $n$ 個地塊，同側相鄰不能都放房子。求方案總數。

**(a) 兩側獨立 ⇒ 答案 $= h(n)^2$。**
*證明*。乘法原理，前提是「同側的約束不跨越街道」✔（題目明說只有同側相鄰受限）。$\square$

**(b) 單側方案數 $h(n)$ 滿足 $h(n) = h(n-1) + h(n-2)$。**
*證明*。按「第 $n$ 個地塊放不放」劃分——**不漏**（必是其一）、**不重**（互斥）、**雙射**（放 ⇒ 第 $n-1$ 必空，砍掉這兩格得 $h(n-2)$；不放 ⇒ 砍掉一格得 $h(n-1)$）✔。$\square$

**與定理 1 的差別只有一個字**：`max` 變成 `+`。**但驗證從「剪貼論證」變成「不重不漏」**——**定理 2 的教訓在這裡兌現：不能再用「覆蓋」了。**

**滾動更新的順序仍要遵守定理 3 of 1.1（先讀後寫）**，且**每一步都要取模**（$n$ 可達 $10^4$，$h(n)$ 是 Fibonacci 級別，早就爆 `long long`）✔。

### 定理 6（狀態不需要記錄「選了哪些」）

*命題*：$f(i)$ 只記一個數字就夠，不需要記錄具體選了哪些房子。

*證明*。由定理 1 的最優子結構，**後續的可行選擇只取決於「第 $i$ 間有沒有被選」，與更早的選擇無關** ✔——而定義甲透過「$f(i-1)$ 對比 $f(i-2)+\mathit{nums}[i-1]$」隱含地區分了這件事：$f(i-2)$ 的方案保證不含第 $i-1$ 間。$\square$

**若題目要求輸出具體方案**，有兩種做法：
1. **回溯**：從 $f(n)$ 反推，比較 $f(i-1)$ 與 $f(i-2)+\mathit{nums}[i-1]$ 哪個等於 $f(i)$；
2. **記錄決策**：額外開一個 `choose[i]` 陣列。

**兩者都需要保留完整的 `f` 陣列，不能滾動** ✘。**這是「壓空間」的代價，16 節（輸出具體方案）會專門處理。**

## 時間與空間複雜度

| 題目 | 時間 | 空間 | 備註 |
| --- | --- | --- | --- |
| 198 打家劫舍 | $O(n)$ | $O(1)$ | 兩個滾動變數 |
| 213 環形（定理 2） | $O(n)$ | $O(1)$ | 跑兩次線性版 |
| 740 刪除並獲得點數（定理 3） | $O(n + V)$ | $O(V)$ | $V = \max(\mathit{nums}) \le 10^4$ |
| 2140 解決智力問題（定理 4） | $O(n)$ | $O(n)$ | 倒序，**不能滾動**（跳躍距離不固定） |
| 2320 放置房子（定理 5） | $O(n)$ | $O(1)$ | 單側遞推後平方 |
| 12.2 樹上最大獨立集 | $O(n)$ | $O(n)$ | 同一個模型，路徑換成樹 |

**2140 為什麼不能滾動**：跳躍目標 $i + b_i + 1$ 可能跨很遠，$O(1)$ 個變數存不下 ⇒ **必須保留整個 $f$ 陣列** ✔。**「只依賴前面固定幾格」是滾動的前提，跳躍型 DP 不滿足。**

**740 為什麼是 $O(V)$ 而不是 $O(n)$**：值域路徑的長度是 $V$，即使 $n$ 很小也要掃完整個值域。**若 $V$ 極大（如 $10^9$），要改成「先排序去重，只在相鄰值差為 1 時才套互斥」——那時複雜度回到 $O(n\log n)$。**

## 與相似技巧的比較

- **與 1.1 爬樓梯**：**結構完全相同，`+` 換成 `max`。** 但驗證方式不同：計數用不重不漏，最優化用剪貼論證。**定理 2 揭示了它們的關鍵分歧——`max` 容許重疊覆蓋，`+` 不容許。**
- **與 1.3 Kadane**：兩者都是 $O(1)$ 空間的線性掃描，但 **1.3 的狀態是「以 $i$ 結尾」而 1.2 是「前 $i$ 個」**。**1.2 的答案就是 $f(n)$，1.3 的答案要另外取 $\max$。** 混用這兩種定義是初學者最常見的錯。
- **與 6 節狀態機 DP**：定義乙（$g[i][0/1]$）就是最小的狀態機。**當「相鄰互斥」變成更複雜的規則（冷凍期、交易次數上限），前綴型定義甲會撐不住，必須升級成狀態機。** 6.1 買賣股票就是這個升級的完整示範。
- **與 12.2 樹上最大獨立集**：**同一個問題，圖從路徑變成樹。** 狀態從 $f(i)$ 變成 $f(u, 0/1)$，轉移從「看前一格」變成「合併所有子樹」。**定理 1 的證明結構原封不動搬過去。**
- **與貪心**：路徑圖上的最大權獨立集**沒有正確的貪心解**。「每次選最大的，刪掉左右鄰居」在 `[2, 3, 2]` 上會選 3（得 3），但最優是 $2+2=4$ ✘。**這是「看起來像貪心其實是 DP」的標準反例，值得記住。**
- **與一般圖的最大獨立集**：一般圖上是 NP-hard。**路徑與樹之所以有多項式解，靠的是「移除一個點就把圖切成獨立的部分」這個結構性質**——這也是 12 節樹形 DP 全章成立的根基。

## 本節重點速查

- **本體**：打家劫舍 = **路徑圖上的最大權獨立集**。認出這件事，740／2140／2320／12.2 就是同一題。
- **定理 1（最優子結構）**：$f(i) = \max(f(i-1),\, f(i-2)+\mathit{nums}[i-1])$。**兩個方向都要證**：$\le$ 用分情況，$\ge$ 要驗「子問題的解接上去仍合法」。**改規則（如互斥距離變 2）就要重跑 $\ge$ 這半段** ⇒ 改成 $f(i-3)$。
- **定理 2（環形 213）**：$\max(\mathrm{rob}[0..n-2],\,\mathrm{rob}[1..n-1])$，靠的是**覆蓋**（$O$ 不能同時含首尾）而非劃分。**最優化可以重疊覆蓋（$\max(a,a)=a$），計數不行（$a+a\ne a$）——計數的環形要嚴格二分。**
- **定理 3（740 歸約驗收）**：**(a) 證明最優解可限制成標準形**（同值全取，依賴 $v\ge0$）；**(b) 證明標準形 $\iff$ 新問題的可行解**。**跳過 (a) 是歸約題最常見的漏洞。** 實作要按**值域**建陣列。
- **定理 4（2140 方向）**：**約束向後推 ⇒ 倒序 DP，狀態定義成後綴。** 正序時「有沒有被前面的跳躍蓋到」不在狀態裡 ⇒ 無後效性失敗。前提：跳躍非負（否則有環）。`min(n, i+b+1)` 夾上界。
- **定理 5（2320 計數）**：兩側獨立 ⇒ 平方（前提：約束不跨街）。單側 Fibonacci。**`max` 變 `+` 之後，驗證方式要從剪貼論證換回不重不漏。** 每步取模。
- **定理 6（狀態不記方案）**：後續選擇只取決於「第 $i$ 間選沒選」。**要輸出方案就得留完整陣列，不能滾動。**
- **沒有正確的貪心解**：`[2, 3, 2]` 是反例（貪心 3、最優 4）。
- **陣列大小規則**：遞迴參數若走過 `[L,R]`（邊界狀態也算），DP 需 `R-L+1` 格並以 `i-L` 索引； `[-1,n-1]`／`[-2,n-1]` 分別是 `n+1`／`n+2` 格。
