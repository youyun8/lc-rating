## 這個技術解決什麼問題

最大子陣列和（Kadane）表面上是一條三行的迴圈，實際上它教的是**一個決定整章成敗的狀態設計選擇**：

> **狀態要定義成「以 $i$ 結尾」，而不是「前 $i$ 個之中」。**

**為什麼？** 因為「連續」這個約束**只能靠「結尾在哪裡」來表達**。若定義成「前 $i$ 個之中的最大子陣列和」，你會發現無法寫出轉移——**你不知道前面那個最優段是不是恰好停在 $i-1$，也就沒辦法決定能不能把 $\mathit{nums}[i]$ 接上去。無後效性直接失敗。**

代價是：**答案不再是 $f(n)$，而是 $\max_i f(i)$。** 這個「多取一次 max」是「以 $i$ 結尾」定義的固定配套，**忘了它就是 1.3 最經典的 WA。**

**辨識訊號**：
- 求「**連續**」子陣列／子字串的最大或最小總和、乘積；
- 暴力是枚舉所有區間端點（雙層迴圈試遍 $(i,j)$）；
- 題目在基本款上加轉折（環形、可刪一次、重複拼接），但核心仍是「**接續 or 重啟**」。

## 狀態／資料結構定義

```cpp
// 定義：f[i] = 以下標 i 結尾的、非空連續子陣列的最大和
// 轉移：f[i] = max(nums[i], f[i-1] + nums[i]) = nums[i] + max(0, f[i-1])
// 答案：max(f[0..n-1])       <-- 不是 f[n-1]！
int maxSubArray(const vector<int>& nums) {
    int f = nums[0], ans = nums[0];
    for (size_t i = 1; i < nums.size(); i++) {
        f = max(nums[i], f + nums[i]);  // 重啟 or 接續
        ans = max(ans, f);              // 每一步都要收集
    }
    return ans;
}
```

**`ans` 的初值必須是 `nums[0]` 而不是 `0`** ✘——**若全為負數，初值 0 會回傳 0（空子陣列），而題目要求非空** ✔。**這是本節第一大坑。**

**另一種完全等價的觀點（定理 2），處理變形時往往更順手**：

```cpp
// 前綴和觀點：max_{l<=r} (S[r+1] - S[l]) = max_r (S[r+1] - min_{l<=r} S[l])
long long S = 0, mn = 0, ans = LLONG_MIN;
for (int x : nums) {
    S += x;
    ans = max(ans, S - mn);  // 先用舊的 mn（保證 l <= r），再更新
    mn = min(mn, S);
}
```

**這裡的 `ans` 與 `mn` 順序不能顛倒**——先更新 `mn` 會允許 $l = r+1$（空區間）✘。**這是「先讀後寫」（1.1 定理 3）在另一個場景的化身。**

**狀態機化（1186 這類「有一次特權」的變形）**：

```cpp
// g[0] = 以 i 結尾、還沒用掉刪除機會；g[1] = 以 i 結尾、已用掉
long long g0 = nums[0], g1 = LLONG_MIN / 4;
```

## 不變量或正確性證明

### 定理 1（Kadane 的正確性：兩層劃分）

*命題*：令 $f(i)$ 為「以下標 $i$ 結尾的**非空**連續子陣列的最大和」，則

$$f(i) = \max\big(\mathit{nums}[i],\;\; f(i-1) + \mathit{nums}[i]\big),\qquad f(0) = \mathit{nums}[0],$$

且答案 $= \max_{0 \le i < n} f(i)$。

*證明*。

**(第一層：轉移)** 以 $i$ 結尾的非空子陣列，按**長度是否為 1** 劃分——不漏（長度 $\ge 1$）、不重（長度唯一）✔。
- 長度 $= 1$：和為 $\mathit{nums}[i]$。
- 長度 $> 1$：砍掉最後一個元素後，剩下的是**以 $i-1$ 結尾的非空子陣列** ⇒ 和 $\le f(i-1) + \mathit{nums}[i]$（剪貼論證）。反過來，$f(i-1)$ 對應的段接上 $\mathit{nums}[i]$ 仍是以 $i$ 結尾的合法段 ⇒ 可達 ✔。

**(第二層：答案的收集)** 每個非空子陣列**恰有一個右端點** ⇒ 全體非空子陣列按右端點劃分，不重不漏 ✔ ⇒ 全域最大 $= \max_i f(i)$。$\square$

**「第二層」是很多人漏掉的一半證明。** 它說明了為什麼「以 $i$ 結尾」的定義**必須**搭配外層取 max：$f$ 本身不是答案，$f$ 只是**按右端點分類後的組內最優值**。

**與 1.2 的對照值得寫在筆記上**：

| | 1.2 打家劫舍 | 1.3 Kadane |
| --- | --- | --- |
| 狀態 | 前 $i$ 個之中 | **以 $i$ 結尾** |
| 答案 | $f(n)$ | $\max_i f(i)$ |
| 為什麼 | 「不相鄰」可以只看前綴 | **「連續」必須釘住端點** |

**判準：約束是「全域的」（不相鄰、總數限制）⇒ 前綴型；約束是「局部連續的」⇒ 釘端點型。**

### 定理 2（前綴和觀點：Kadane $\equiv$ 掃描最小前綴和）

*命題*：設 $S_0 = 0$、$S_{k} = \sum_{t<k}\mathit{nums}[t]$，則

$$\max_{0 \le l \le r < n} \sum_{t=l}^{r}\mathit{nums}[t] \;=\; \max_{0 \le r < n}\Big( S_{r+1} - \min_{0 \le l \le r} S_l \Big).$$

*證明*。子陣列 $[l, r]$ 的和 $= S_{r+1} - S_l$。固定 $r$ 後，最大化即最小化 $S_l$，而 $l$ 的合法範圍是 $[0, r]$（保證非空）✔。對 $r$ 取 max 即得。$\square$

**兩種觀點完全等價，但適用場合不同**：

| 觀點 | 什麼時候用 |
| --- | --- |
| **Kadane（接續 or 重啟）** | 純線性掃描、要壓成 $O(1)$ 空間 |
| **前綴和 + 維護歷史最小值** | **有額外約束**：長度下限（$l \le r - k + 1$，配單調佇列）、模數（$S_l \equiv$ 某值）、下標關係（2321） |

**「維護歷史最小值」這個框架的可擴充性遠高於 Kadane**：把 `min` 換成「窗口內的 min」就是 11.3 單調佇列優化 DP；換成「某個集合裡的 min」就是 11.4 線段樹優化 DP。**Kadane 是它的 $O(1)$ 特例。**

**推論 2.1（1749 絕對值最大）**：$\max_{l,r}\big|\sum\big| = \max\big(\text{最大子段和},\; -\text{最小子段和}\big)$——**跑兩次 Kadane（一次求 max、一次求 min）即可** ✔。

### 定理 3（918 環形：補集論證，以及那個必須排除的退化情況）

*命題*：設 $\mathrm{best}^+$ 為普通最大子陣列和、$\mathrm{best}^-$ 為普通**最小**子陣列和（皆要求非空）、$T = \sum \mathit{nums}$。則環形最大子陣列和為

$$\begin{cases}
\mathrm{best}^+ & \text{若 } \mathrm{best}^- = T \ \text{（即全部元素為負）},\\[2pt]
\max\big(\mathrm{best}^+,\; T - \mathrm{best}^-\big) & \text{否則}.
\end{cases}$$

*證明*。環形子陣列分兩類——**不漏、不重**（是否跨越首尾邊界）✔：
- **(不跨界)** 就是普通子陣列 ⇒ 最優值 $\mathrm{best}^+$。
- **(跨界)** 設該段為 $[l, n-1] \cup [0, r]$（$r < l$）。**它在整個陣列中的補集恰為 $[r+1, l-1]$，是一個不跨界的連續段** ✔，且該段的和 $= T - (\text{補集的和})$。**要最大化它，就要最小化補集的和** ⇒ 值為 $T - \mathrm{best}^-$。

**退化情況**：跨界段必須**非空**，也就是它的補集**不能是整個陣列**。若 $\mathrm{best}^-$ 恰好由「整個陣列」達成（等價於**所有元素皆為負**），則 $T - \mathrm{best}^- = 0$ 對應空段，**非法** ✘ ⇒ 必須退回 $\mathrm{best}^+$。$\square$

**判別條件寫成 `best- == T` 比「檢查是否全負」更直接，也更不容易寫錯。** 另一種等價寫法是求「最小子段和時強制長度 $< n$」，但那要多開一組狀態，不如前者乾淨。

**這個「補集論證」是環形問題的通用手法**：**「環上的區間」的補集仍是「環上的區間」，而其中至少一個不跨界。** 213 打家劫舍 II 用的是同一個直覺的另一種形式（1.2 定理 2）。

### 定理 4（152 乘積最大：為什麼「同時維護 max 與 min」是充分的）

*命題*：令 $P_i$ 為「以 $i$ 結尾的所有非空子陣列之乘積」構成的集合，$M_i = \max P_i$、$m_i = \min P_i$。則

$$M_i = \max\big(\mathit{nums}[i],\; M_{i-1}\cdot \mathit{nums}[i],\; m_{i-1}\cdot \mathit{nums}[i]\big),$$
$$m_i = \min\big(\mathit{nums}[i],\; M_{i-1}\cdot \mathit{nums}[i],\; m_{i-1}\cdot \mathit{nums}[i]\big).$$

*證明*。由定義，$P_i = \{\mathit{nums}[i]\} \cup \{\, p \cdot \mathit{nums}[i] : p \in P_{i-1} \,\}$（同定理 1 的長度劃分）✔。

**關鍵在於映射 $\varphi(x) = x \cdot \mathit{nums}[i]$ 是單調函數**：$\mathit{nums}[i] > 0$ 時遞增、$< 0$ 時遞減、$= 0$ 時常數。**單調函數把一個有限集合的最大值送到「原集合的 max 或 min 的像」上**：

$$\max_{p \in P_{i-1}} \varphi(p) = \max\big(\varphi(M_{i-1}),\; \varphi(m_{i-1})\big),$$

（遞增時取前者、遞減時取後者、常數時兩者相等）✔。$m_i$ 同理。$\square$

**這條定理真正的價值是它的一般形式**：

> **若轉移函數對「上一輪的值」是單調的，則只需維護該集合的兩個端點（max 與 min）。**

**點名前提**：**單調性**。若轉移是 $x \mapsto x^2 - x$（非單調），端點就不夠了——最優可能出現在集合內部 ✘。**遇到新的「以 $i$ 結尾」型變形時，先檢查轉移單調不單調，再決定要維護幾個量。**

**溢位提醒**：152 保證任何前綴乘積落在 32 位範圍內，**但中間量仍建議用 `long long`**；改成一般情況（無此保證）時，乘積會指數爆炸，**必須改成取對數或直接判 0／負號個數。**

### 定理 5（1186 刪除一次：加一維「特權用掉沒」）

*問題*：可以最多刪除子陣列中的一個元素（刪完後仍須非空），求最大和。

*命題*：令 $g(i, 0)$ 為「以 $i$ 結尾、尚未使用刪除機會」的最大和、$g(i, 1)$ 為「以 $i$ 結尾、已使用刪除機會」的最大和，則

$$g(i,0) = \max\big(\mathit{nums}[i],\; g(i-1,0) + \mathit{nums}[i]\big),$$
$$g(i,1) = \max\big(\underbrace{g(i-1,0)}_{\text{刪掉第 } i \text{ 個}},\;\; \underbrace{g(i-1,1) + \mathit{nums}[i]}_{\text{之前刪過，保留第 } i \text{ 個}}\big).$$

答案 $= \max_i \max(g(i,0), g(i,1))$。

*為什麼需要這一維*。**無後效性檢查（1.1 定理 4）**：只知道「以 $i$ 結尾的最大和」不足以決定後續——**能不能再刪一個，取決於歷史** ✘ ⇒ 狀態不完備，必須補上這一維 ✔。

*轉移的兩個分支*。以 $i$ 結尾且已刪過一個，按「**被刪的是不是第 $i$ 個**」劃分——不漏、不重 ✔。若刪的是第 $i$ 個，則剩下的是以 $i-1$ 結尾且未刪過的段 ⇒ $g(i-1, 0)$；否則第 $i$ 個保留，前段是以 $i-1$ 結尾且已刪過 ⇒ $g(i-1,1) + \mathit{nums}[i]$ ✔。$\square$

**兩個邊界**：
- **$g(0,1)$ 必須是 $-\infty$ 而不是 0**——「刪掉唯一的元素」會得到空段，非法 ✘。用 `LLONG_MIN / 4` 避免加法溢位。
- **$g(i,1)$ 的第一個分支沒有加 $\mathit{nums}[i]$**（因為它被刪了）——**寫成 `g0 + nums[i]` 是最常見的手誤。**

**這個「加一維記錄特權」的模式會在 6 節（狀態機 DP，交易次數）與 10 節（數位 DP，是否貼上限）反覆出現。** 判準永遠是同一句：**構造兩條到 $i$ 的路徑，後續選擇不同 ⇒ 加維度。**

### 定理 6（1191 K 次串聯：為什麼只需要考慮「頭 + 中間整份 + 尾」）

*問題*：把陣列重複 $k$ 次拼接，求最大子陣列和（可為空，答案下界 0）。

*命題*：設單份的總和為 $T$、最大子陣列和為 $B$、最大前綴和為 $\mathrm{pre}$、最大後綴和為 $\mathrm{suf}$（前綴／後綴皆允許為空，故 $\ge 0$）。則

$$\mathrm{ans} = \begin{cases}
\max(0,\; B) & k = 1,\\[2pt]
\max\big(0,\; B,\; \mathrm{suf} + \mathrm{pre} + (k-2)\cdot\max(0, T)\big) & k \ge 2.
\end{cases}$$

*證明*。設最優段跨越了 $c$ 個完整副本的邊界。
- **$c \le 1$**：整段落在連續兩份之內 ⇒ 被 $k=2$ 的情形涵蓋，即 $\max(B, \mathrm{suf}+\mathrm{pre})$ ✔。
- **$c \ge 2$**：該段形如「第一份的一個後綴 + 若干個完整副本 + 最後一份的一個前綴」。**中間每個完整副本貢獻恰好 $T$。** 若 $T \le 0$，把中間的副本全部刪掉不劣（且刪掉後仍是合法段）⇒ 退回前一種情形；若 $T > 0$，中間副本自然是愈多愈好 ⇒ 取滿 $k-2$ 個 ✔。

兩種情形取 max 即得。$\square$

**這個論證的骨架值得抽出來**：

> **當「重複結構」的每一份貢獻是固定值 $T$ 時，最優解只會在「$T > 0$ 就全要、$T \le 0$ 就一個都不要」之間二選一** ⇒ **$k$ 只以一個乘法因子出現，$k$ 有多大都不影響複雜度。**

**兩個實作細節**：
- **$\mathrm{pre}$ 與 $\mathrm{suf}$ 必須允許為空**（取 $\max$ 與 0），否則 $T > 0$ 但兩端都是負數時會低估 ✘；
- **必須用 `long long`**：$k \le 10^5$、$T \le 10^9$ ⇒ 乘積達 $10^{14}$ ✘ `int` 必爆。

## 時間與空間複雜度

| 題目 | 時間 | 空間 | 備註 |
| --- | --- | --- | --- |
| 53 最大子陣列和 | $O(n)$ | $O(1)$ | 標準 Kadane |
| 152 乘積最大（定理 4） | $O(n)$ | $O(1)$ | 同時維護 max 與 min |
| 918 環形（定理 3） | $O(n)$ | $O(1)$ | 兩次 Kadane + 一次總和 |
| 1186 刪一次（定理 5） | $O(n)$ | $O(1)$ | 兩個滾動狀態 |
| 1191 K 次串聯（定理 6） | $O(n)$ | $O(1)$ | **與 $k$ 無關** |
| 1749 絕對值最大 | $O(n)$ | $O(1)$ | 最大子段和與最小子段和取 max |
| 2606 最大開銷子字串 | $O(n + 26)$ | $O(26)$ | 先建映射表，再 Kadane |
| 前綴和 + 單調佇列（長度下限） | $O(n)$ | $O(n)$ | 見 11.3 |

**暴力對照**：枚舉所有 $(l, r)$ 是 $O(n^2)$，再加上逐項求和是 $O(n^3)$。**$n = 10^5$ 時 $O(n^2) = 10^{10}$ 必 TLE**——Kadane 把它降到 $10^5$。

**溢位速查**：$n = 10^5$、$|\mathit{nums}[i]| \le 10^4$ ⇒ 和的量級 $10^9$，**貼著 `int` 上限**；1191 加上 $k$ 之後直接爆。**這一節的所有累加量一律用 `long long`，沒有例外。**

## 與相似技巧的比較

- **與 1.2 打家劫舍**：**狀態定義的分野**——1.2 是「前 $i$ 個之中」（答案 $f(n)$），1.3 是「以 $i$ 結尾」（答案 $\max_i f(i)$）。**判準：約束是全域的用前綴型，約束要求連續就釘端點。**
- **與滑動窗口（sliding_window 章）**：兩者都處理「連續子陣列」，但**滑動窗口要求某種單調性**（窗口擴大時指標值單調變化），**Kadane 不要求**。**有負數時滑動窗口幾乎必壞（和不單調），Kadane 照常運作**——這是選擇的第一判準。
- **與 2 節字首和（data_structure 章）**：定理 2 顯示 Kadane 就是「前綴和 + 維護歷史最小值」。**把「歷史最小值」換成更強的查詢結構，就得到 11.3／11.4 的優化 DP**——**Kadane 是那整個家族的 $O(1)$ 起點。**
- **與 7.3 子陣列 DP**：7.3 是本節的一般化（狀態不只一個標量）。**本節的兩個要點——釘住右端點、每步收集答案——在 7.3 原封不動使用。**
- **與 8 節區間 DP**：區間 DP 的狀態是 $f(l, r)$（兩個端點都自由），複雜度 $O(n^2)$ 起跳。**Kadane 之所以能到 $O(n)$，正是因為它只釘一個端點、另一端靠遞推遞延。** 遇到「連續段」問題時**先試釘一端**，實在不行才上區間 DP。
- **與分治**：最大子陣列和有經典的 $O(n\log n)$ 分治解（左半 / 右半 / 跨中點）。**Kadane 更快也更短，分治的價值在於它能推廣到「線段樹維護區間最大子段和」**（見 data_structure 9.3 的合併資訊），從而支援修改與區間查詢。**單次查詢用 Kadane，帶修改用線段樹。**

## 本節重點速查

- **核心選擇**：**狀態定義成「以 $i$ 結尾」**，因為「連續」只能靠釘住端點表達。**代價是答案要 $\max_i f(i)$，不是 $f(n-1)$。**
- **定理 1（兩層劃分）**：轉移層按「長度是否為 1」劃分；答案層按「右端點是誰」劃分。**兩層都要不重不漏。**
- **定理 2（前綴和觀點）**：$\max_r (S_{r+1} - \min_{l\le r} S_l)$。**先用舊的 min 再更新**，否則會允許空區間。**這個框架比 Kadane 更能擴充**（長度下限 ⇒ 單調佇列；一般約束 ⇒ 線段樹）。
- **定理 3（918 環形）**：**補集論證**——跨界段的補集是不跨界段 ⇒ $\max(\mathrm{best}^+,\, T - \mathrm{best}^-)$。**退化情況：$\mathrm{best}^- = T$（全負）時 $T-\mathrm{best}^-$ 對應空段，非法，要退回 $\mathrm{best}^+$。**
- **定理 4（152 乘積）**：同時維護 max 與 min 之所以充分，是因為 $x \mapsto x\cdot\mathit{nums}[i]$ **單調** ⇒ 極值必在端點的像上。**一般原則：轉移單調 ⇒ 維護兩個端點就夠；轉移不單調 ⇒ 端點不夠。**
- **定理 5（1186 刪一次）**：無後效性檢查失敗 ⇒ 加一維「特權用掉沒」。**$g(0,1) = -\infty$（刪光會變空段）**；$g(i,1)$ 的「刪掉第 $i$ 個」分支**不加 $\mathit{nums}[i]$**。
- **定理 6（1191 K 次串聯）**：**中間整份的貢獻固定為 $T$ ⇒ $T>0$ 全要、$T\le0$ 全不要** ⇒ 複雜度與 $k$ 無關。$\mathrm{pre}$、$\mathrm{suf}$ 要允許為空。**必用 `long long`。**
- **兩個必踩的坑**：`ans` 初值要用 `nums[0]` 不能用 0（全負時）；累加量一律 `long long`。
