## 這個技術解決什麼問題

**線性 DP 的轉移是「枚舉最後一段，而那一段必須是字典裡的某個字串」：**

$$\mathit{dp}[i]=\operatorname*{opt}_{\substack{j<i\\ s[j..i-1]\ \in\ D}}\ \big(\mathit{dp}[j]\ \square\ w(s[j..i-1])\big).$$

樸素做法是「對每個 $i$ 枚舉每個 $j$，再判斷 $s[j..i-1]$ 是否在字典裡」：

| 判斷方式 | 單次 | 總計 |
| --- | --- | --- |
| 逐字元比對整個字典 | $O(|D|\cdot L)$ | $O(n^2|D|L)$ ✘ |
| `unordered_set<string>` | $O(L)$（要建子字串！） | $O(n^2L)$ |
| 滾動雜湊 | $O(1)$ | $O(n^2)$，但有碰撞風險 |
| **字典樹（Trie）** | — | $\boxed{O(n\cdot L_{\max})}$，**且會提早剪枝** ✔ |

**字典樹贏在哪裡**——它把「枚舉 $j$ 再查表」換成**一次沿樹下走**：從位置 $i$ 出發，每讀一個字元就往下走一步，

- 走到的節點若是某個字典詞的結尾 ⇒ **就地做一次轉移**；
- **一旦下一個字元沒有分支，立刻 `break`** ⇒ 後面所有更長的 $j$ 都不必試（定理 2）。

這個 `break` 才是重點：字典裡沒有以 `"xq"` 開頭的詞，就不必再看 `"xqa"`、`"xqab"`……**剪枝的正確性來自「Trie 的路徑集合對前綴封閉」**，不是靠運氣。

**四個典型信號**：

- 題目給一個**字典／單詞表**，問「能否切分」「最少剩幾個字元」「最少切幾刀」「有幾種切法」（139、面試題 17.13、2707）；
- 要判斷「某個詞能否由**其他詞**拼成」（472）；
- 要在字串上做 DP，而**轉移的每一段都必須匹配某個模式串**（2977）；
- 字典很大（$|D|$ 上萬）但**共用前綴很多** ⇒ Trie 的空間與時間都被前綴共享攤掉。

## 狀態／資料結構定義

### DP 部分

**狀態一律定義在「位置」上，而不是「切了幾段」上**：

| 題型 | 狀態 | 邊界 | 答案 |
| --- | --- | --- | --- |
| 139 能否切分 | $\mathit{dp}[i]\in\{0,1\}$：$s[0..i-1]$ 可否切完 | $\mathit{dp}[0]=1$ | $\mathit{dp}[n]$ |
| 2707 最少額外字元 | $\mathit{dp}[i]$：$s[i..n-1]$ 的最少剩餘字元 | $\mathit{dp}[n]=0$ | $\mathit{dp}[0]$ |
| 面試題 17.13 恢復空格 | 同上 | 同上 | 同上 |
| 切法計數 | $\mathit{dp}[i]$：切法數 | $\mathit{dp}[0]=1$ | $\mathit{dp}[n]$ |

**兩種等價的推法**：

- **拉（pull）**：$\mathit{dp}[i]$ 從所有 $\mathit{dp}[j]$（$j<i$）取值 ⇒ 需要「所有**以 $i-1$ 結尾**的字典詞」⇒ **Trie 要存反轉後的詞**，從 $i-1$ 往左走。
- **推（push）／後綴狀態**：$\mathit{dp}[i]$ 定義成「後綴 $s[i..]$ 的答案」，從 $i$ 往右走 ⇒ **Trie 存原詞** ✔。

**推薦後者**（定理 3）：不用反轉字典、不用反轉字串、索引不易錯。本節模板一律用它。

### Trie 部分

```
節點 = { ch[26] : 子節點編號（-1 表示不存在）, end : bool 或 id : int }
```

**用 `std::vector<Node>` 的陣列版**，不要 `new` 或 `unordered_map`：

| 實作 | 單步 | 備註 |
| --- | --- | --- |
| `std::array<int,26>` $+$ `vector` | $O(1)$，常數極小 | **首選** ✔ |
| `unordered_map<char,int>` | $O(1)$ 但常數大 3–10 倍 | 字元集大（Unicode）才用 |
| 指標 $+$ `new` | 同上 | 記憶體碎片、難釋放，不推薦 |

**節點上要存什麼，取決於題目要什麼**：

| 需要 | 節點欄位 |
| --- | --- |
| 只問「是不是一個詞」 | `bool end` |
| 需要那個詞的權重／編號 | `int id`（$-1$ 表示不是詞尾） |
| 需要「以此為前綴的詞數」 | `int cnt` |

## 不變量或正確性證明

### 定理 1（**DP 的不重不漏：最後一段的唯一性**）

*命題*：令 $\mathcal{S}(i)$ 為「$s[i..n-1]$ 的所有合法切分」。則

$$\mathcal{S}(i)=\biguplus_{\substack{j\ \ge\ i\\ s[i..j]\in D}}\big\{\,s[i..j]\ \text{接上}\ \sigma\ :\ \sigma\in\mathcal{S}(j+1)\,\big\}\ \uplus\ \big\{\,\text{把 }s[i]\text{ 丟棄}\ \cdots\big\},$$

且右邊各項**兩兩不交**（$\uplus$ 表示不交併）。

*證明*。任一切分 $\sigma\in\mathcal{S}(i)$ 有唯一的**第一段**；第一段的右端 $j$ 唯一決定它落在哪一項 ⇒ 不重 ✔。反之，對每個合法的 $j$ 與每個 $\sigma'\in\mathcal{S}(j+1)$，拼起來都是合法切分 ⇒ 不漏 ✔。**無後效性**：後段 $\mathcal{S}(j+1)$ 只依賴 $j+1$，與前段怎麼切無關 ✔。$\square$

*⚠ 這條看似廢話，但它點名了一個前提*：**「第一段」必須被唯一確定**。若題目允許段與段重疊（例如「覆蓋」而非「切分」），這條就不成立，DP 會重複計數 ✘。**2707 是切分（不重疊），所以成立。**

### 定理 2（**Trie 剪枝的安全性：前綴封閉**）

這是本節唯一真正需要證明的東西。

*記號*：Trie 中從根走出的所有路徑構成集合 $P(D)=\{\,u\ :\ u\ \text{是某個}\ w\in D\ \text{的前綴}\,\}$。

*引理（前綴封閉）*：$P(D)$ **對取前綴封閉**——若 $u\in P(D)$ 且 $u'$ 是 $u$ 的前綴，則 $u'\in P(D)$。等價地取逆否：

$$u\notin P(D)\ \Longrightarrow\ \text{任何以 }u\text{ 為前綴的 }u''\notin P(D).$$

*證明*。$u\in P(D)$ ⇒ 存在 $w\in D$ 以 $u$ 為前綴 ⇒ 該 $w$ 也以 $u'$ 為前綴 ⇒ $u'\in P(D)$ ✔。$\square$

*定理（走訪的兩個不變量）*：對固定的 $i$，令內層迴圈在讀完 $s[i..j]$ 後停在節點 $u_j$。則

- **(I1) 對應**：只要迴圈還沒 `break`，$u_j$ 恰好代表字串 $s[i..j]$；
- **(I2) 完備**：迴圈走過的所有 $j$ 中，「$u_j$ 是詞尾」的那些，**恰好就是全部滿足 $s[i..j]\in D$ 的 $j$**。

*證明*。**(I1)** 對 $j$ 歸納：$u_{i-1}=$ 根 $=\varepsilon$ ✔；每步沿 $s[j]$ 這條邊走 ⇒ 由 Trie 的定義，$u_j$ 代表 $u_{j-1}$ 接上 $s[j]$ ✔。

**(I2)** 分兩半。
**不多**：由 (I1)，$u_j$ 是詞尾 $\iff s[i..j]\in D$ ✔。
**不漏**：設 $s[i..j^{*}]\in D$ 但迴圈在 $j_0<j^{*}$ 處 `break` 了。`break` 的條件是 $s[i..j_0]\notin P(D)$。但 $s[i..j_0]$ 是 $s[i..j^{*}]$ 的前綴，而 $s[i..j^{*}]\in D\subseteq P(D)$ ⇒ 由引理，$s[i..j_0]\in P(D)$ ⇒ 矛盾 ✘。故不會提早 `break` ✔。$\square$

*推論 2.1（剪枝是免費的）*：`break` 只在「後面不可能再有任何字典詞」時發生 ⇒ **剪枝不損失任何轉移**，是嚴格的加速。

*推論 2.2（真實複雜度）*：內層迴圈的步數 $\le\min(n-i,\ L_{\max})$，其中 $L_{\max}=\max_{w\in D}|w|$。**更緊的界是「$s$ 從 $i$ 起的最長字典前綴」**——實測上常遠小於 $L_{\max}$。總時間 $O(n\cdot L_{\max})$，與 $|D|$ **無關** ✔。這就是 Trie 打敗雜湊表的地方：雜湊表得試遍所有長度，Trie 走不通就停。

### 定理 3（**正向 Trie 與反向 Trie 等價，但正向的索引更不容易錯**）

*命題*：以下兩者計算相同的答案：

- **(A) 反向**：$\mathit{dp}[i]=$「前綴 $s[0..i-1]$ 的答案」，Trie 存 $\{\,\mathrm{rev}(w):w\in D\,\}$，對每個 $i$ 從 $s[i-1]$ 往左走；
- **(B) 正向**：$\mathit{dp}[i]=$「後綴 $s[i..n-1]$ 的答案」，Trie 存 $D$，對每個 $i$ 從 $s[i]$ 往右走。

*證明*。(A) 中「從 $i-1$ 往左讀出的字串」$=\mathrm{rev}(s[j..i-1])$，而 $\mathrm{rev}(s[j..i-1])\in \mathrm{rev}(D)\iff s[j..i-1]\in D$ ⇒ 兩者枚舉的 $(j,i)$ 對完全相同 ✔；兩個 DP 都由定理 1 的分解導出，只是把「最後一段」換成「第一段」，而定理 1 對兩端都成立（切分的第一段同樣唯一）✔。$\square$

*⚠ 選 (B) 的三個理由*：(1) 不必反轉字典（少一次 $O(\sum|w|)$ 與一組 bug）；(2) 不必反轉答案（面試題 17.13 若要輸出切分方案，(A) 會得到反的）；(3) `for (int j = i; j < n; ++j)` 比 `for (int j = i - 1; j >= 0; --j)` 少一組邊界推敲 ✔。

*⚠ 只有一種情況必須用 (A)*：題目本身要求「以某位置**結尾**」的統計，且外層迴圈的順序被其他約束綁死。

### 定理 4（**472 的自我排除：「先查後插」加上「按長度排序」**）

*設定*：找出所有「能由陣列中**其他**（至少兩個）單詞拼成」的單詞。

*演算法*：把 `words` 依**長度非遞減**排序；依序對每個 $w$ 先用當前 Trie 跑一次「能否完整切分」的 DP，再把 $w$ 插入 Trie。

*命題*：這樣得到的結果正確。

*證明*。要證兩件事。

**(a) 不會誤判（$w$ 不會被自己拼出來）**：查詢發生在插入 $w$ **之前** ⇒ Trie 中不含 $w$ 自己 ✔。（**這與 11.4 定理 1 是同一個「先查後插」不變量。**）

**(b) 不會漏判（所有能用的詞都已在 Trie 中）**：設 $w=w_1w_2\cdots w_k$，$k\ge2$，每個 $w_t\in D$ 非空。則 $|w_t|\le|w|-(k-1)<|w|$，即**每個組成部分嚴格更短** ⇒ 排序後 $w_t$ 一定排在 $w$ 前面 ⇒ 已插入 ✔。$\square$

*⚠ 論證依賴的兩個前提，缺一不可*：

1. **組成部分非空**（否則 $|w_t|<|w|$ 不成立）⇒ **空字串必須先過濾掉** ⚠。輸入含 `""` 時，不過濾會讓每個詞都被判定成「$w=w+\varepsilon$」的拼接 ✘。
2. **單詞互不相同**。若允許重複，等長的重複詞會先被插入，然後把 $w$ 誤判成「單獨一段」的拼接（$k=1$）✘。**LC 472 保證互異；自己造測資時要注意。**

*⚠ 排序只要求「非遞減」，等長之間任意順序都可以*——因為等長的詞不可能是 $w$ 的真組成部分（由 (b) 的嚴格不等式）✔。

### 定理 5（**多模式 $+$ 圖上最短路：2977 的兩層結構**）

*設定（2977 轉換字串的最小成本 II）*：可以把 `source` 的一段子字串 `original[k]` 整段換成 `changed[k]`，花費 `cost[k]`；問把 `source` 變成 `target` 的最小總成本，**且被替換的區間不得重疊**。

*命題*：正確解 $=$ 兩個獨立部分的組合。

**第一層（字串 $\to$ 圖）**：把出現過的每個模式串映一個編號 $0..m-1$（$m\le|\mathit{cost}|\cdot2$）。令

$$d[a][b]=\text{把字串 }a\text{ 變成字串 }b\text{ 的最小成本}.$$

以 $d[a][b]\gets\min(d[a][b],\ \mathit{cost}[k])$（當 $a=\mathrm{original}[k],b=\mathrm{changed}[k]$）為邊、跑 **Floyd** 得到全對最短路。

*為什麼可以 Floyd*：一次替換是圖上一條邊，多次替換**同一段**是路徑的串接，成本相加 ⇒ 這正是最短路的定義 ✔。**前提：替換可以在同一段上反覆進行，且成本非負**（非負 ⇒ 最短路存在、不會有負環）✔。

**第二層（圖 $\to$ DP）**：

$$\mathit{dp}[i]=\min\Big(\underbrace{[\,s_i=t_i\,]\cdot\mathit{dp}[i+1]}_{\text{不替換}},\quad \min_{\substack{j\ \ge\ i\\ s[i..j]=a,\ t[i..j]=b}}\big(d[a][b]+\mathit{dp}[j+1]\big)\Big).$$

*為什麼 Trie*：需要同時找出「`source` 從 $i$ 起匹配哪些模式」與「`target` 從 $i$ 起匹配哪些模式」。**建兩棵 Trie，從 $i$ 起同步往右走一步**——只有**兩邊都停在詞尾節點**時才產生一條轉移 ✔。任一邊走不動就 `break`（定理 2 的剪枝對兩棵樹同時成立，因為兩個條件是**合取**）✔。

*正確性的關鍵前提*：**區間不重疊**。若允許重疊，定理 1 的「第一段唯一」就失效，DP 分解不成立 ✘。

*推論 5.1（複雜度）*：Floyd $O(m^3)$；DP $O(n\cdot L_{\max})$。$m\le200$ ⇒ $8\times10^6$ ✔。

*⚠ 三個實作陷阱*：`dist` 要用 `long long`（$n\cdot\mathit{cost}_{\max}$ 會爆 `int`）；`d[a][a]=0` 要初始化；**無解要回傳 $-1$**，所以 $\infty$ 必須是「加得動也不會溢位」的哨兵（同 11.4 的 $-(1\ll60)$ 慣例，這裡取 $+(1\ll60)$）⚠。

### 定理 6（**什麼時候 Trie 是必要的，什麼時候是多餘的**）

*命題（Trie 沒有優勢的三種情形）*：

1. **所有字典詞等長 $L$** ⇒ 每個 $i$ 只需查一個子字串 ⇒ 雜湊集合 $O(n)$，Trie 沒有剪枝可做 ✔。
2. **$n$ 很小**（139 的 $n\le300$、面試題 17.13 的 $n\le1000$）⇒ $O(n^2)$ 的雜湊做法 $\le10^6$，**直接寫，別建樹**。
3. **只需要「是否存在」而字典極小**（$|D|\le10$）⇒ 直接對每個詞做 `compare`。

*命題（Trie 明顯獲勝）*：$n\ge10^4$ **且** 詞長分佈廣（有很多長詞但實際能匹配的很短）⇒ 剪枝讓內層平均步數遠小於 $L_{\max}$ ✔。

*命題（該換 AC 自動機的信號）*：需要「**字串中所有模式串的所有出現位置**」而不只是「從某個 $i$ 開始的匹配」——例如「模式可以在任意位置出現、要統計總次數」。Trie 對每個起點各走一遍是 $O(n L_{\max})$；**AC 自動機（Trie $+$ fail 鏈）把它降到 $O(n+\text{匹配數})$** ✔。

*⚠ 本節列的題目都是「從某個位置開始的匹配」，因此純 Trie 就夠，不需要 fail 鏈。* 誤上 AC 自動機只是徒增複雜度。

*推論 6.1（決策表）*：

| 情形 | 用 |
| --- | --- |
| 詞等長 | 雜湊集合 |
| $n\le2000$ | 雜湊 $+$ $O(n^2)$ |
| 詞長分佈廣、$n$ 大 | **Trie（本節）** |
| 要所有位置的所有匹配 | AC 自動機 |
| 要「任意子字串是否出現過」 | 後綴自動機／後綴陣列 |
| 只比較固定的兩個字串 | 別繞路，直接 4.1 LCS |

## C++17 模板

**模板 1｜陣列版字典樹（小寫字母）**

```cpp
struct Trie {
    // ch[u][c] = -1 表示沒有這條邊；id >= 0 表示 u 是第 id 個字典詞的結尾
    std::vector<std::array<int, 26>> ch;
    std::vector<int> id;

    Trie() { newNode(); }

    int newNode() {
        ch.push_back({});
        ch.back().fill(-1);
        id.push_back(-1);
        return int(ch.size()) - 1;
    }

    void insert(const std::string& w, int wordId) {
        int u = 0;
        for (char c : w) {
            int k = c - 'a';
            if (ch[u][k] < 0) {
                ch[u][k] = newNode();
            }
            u = ch[u][k];
        }
        id[u] = wordId;
    }
};
```

**模板 2｜2707 字串中的額外字元（正向 Trie $+$ 後綴狀態，定理 3 的寫法 (B)）**

```cpp
int minExtraChar(std::string s, std::vector<std::string>& dictionary) {
    Trie tr;
    for (int k = 0; k < int(dictionary.size()); ++k) {
        tr.insert(dictionary[k], k);
    }
    int n = s.size();
    const int INF = 0x3f3f3f3f;
    std::vector<int> dp(n + 1, INF);
    dp[n] = 0;  // 空後綴沒有額外字元
    for (int i = n - 1; i >= 0; --i) {
        dp[i] = dp[i + 1] + 1;  // s[i] 當成額外字元（一定要有這條）
        int u = 0;
        for (int j = i; j < n; ++j) {
            int k = s[j] - 'a';
            if (tr.ch[u][k] < 0) break;  // 定理 2：前綴封閉 ⇒ 剪枝安全
            u = tr.ch[u][k];
            if (tr.id[u] >= 0) {  // s[i..j] 是字典詞
                dp[i] = std::min(dp[i], dp[j + 1]);
            }
        }
    }
    return dp[0];
}
```

把 `dp[i] = dp[i + 1] + 1` 拿掉、初值改成布林，就是 **139 單詞拆分**；把 `min` 換成 `+=` 就是**切法計數**；在轉移時記下最佳的 $j$，就能還原**面試題 17.13** 的切分方案。

**模板 3｜472 連接詞（按長度排序 $+$ 先查後插，定理 4）**

```cpp
std::vector<std::string> findAllConcatenatedWordsInADict(
    std::vector<std::string>& words) {
    std::sort(words.begin(), words.end(),
              [](const std::string& a, const std::string& b) {
                  return a.size() < b.size();
              });
    Trie tr;
    std::vector<std::string> ans;
    for (const std::string& w : words) {
        if (w.empty()) continue;  // ⚠ 定理 4 前提 1：空字串必須排除
        int n = w.size();
        std::vector<char> ok(n + 1, 0);
        ok[0] = 1;
        for (int i = 0; i < n; ++i) {
            if (!ok[i]) continue;
            int u = 0;
            for (int j = i; j < n; ++j) {
                int k = w[j] - 'a';
                if (tr.ch[u][k] < 0) break;
                u = tr.ch[u][k];
                if (tr.id[u] >= 0) ok[j + 1] = 1;
            }
        }
        if (ok[n]) ans.push_back(w);
        tr.insert(w, 0);  // 先查、後插（同 11.4 定理 1）
    }
    return ans;
}
```

因為 $w$ 自己不在樹裡，`ok[n] == 1` 就保證用了 $\ge2$ 段 ✔，不必另外數段數。

**模板 4｜2977 型：雙 Trie 同步走 $+$ Floyd（定理 5）**

```cpp
long long minimumCost(std::string source, std::string target,
                      std::vector<std::string>& original,
                      std::vector<std::string>& changed,
                      std::vector<int>& cost) {
    const long long INF = 1LL << 60;

    // 第一層：字串 -> 編號 -> Floyd 全對最短路
    std::map<std::string, int> sid;
    auto getId = [&](const std::string& w) {
        auto it = sid.find(w);
        if (it != sid.end()) return it->second;
        int v = int(sid.size());
        sid.emplace(w, v);
        return v;
    };
    for (const auto& w : original) getId(w);
    for (const auto& w : changed) getId(w);

    int m = int(sid.size());
    std::vector<std::vector<long long>> d(m, std::vector<long long>(m, INF));
    for (int i = 0; i < m; ++i) d[i][i] = 0;
    for (int k = 0; k < int(cost.size()); ++k) {
        int a = sid[original[k]];
        int b = sid[changed[k]];
        d[a][b] = std::min(d[a][b], (long long)cost[k]);
    }
    for (int k = 0; k < m; ++k) {
        for (int i = 0; i < m; ++i) {
            if (d[i][k] == INF) continue;
            for (int j = 0; j < m; ++j) {
                d[i][j] = std::min(d[i][j], d[i][k] + d[k][j]);
            }
        }
    }

    // 第二層：兩棵 Trie 同步往右走
    Trie ta, tb;
    for (const auto& [w, v] : sid) {
        ta.insert(w, v);
        tb.insert(w, v);
    }
    int n = source.size();
    std::vector<long long> dp(n + 1, INF);
    dp[n] = 0;
    for (int i = n - 1; i >= 0; --i) {
        if (source[i] == target[i]) {
            dp[i] = dp[i + 1];  // 不替換
        }
        int u = 0;
        int v = 0;
        for (int j = i; j < n; ++j) {
            int ca = source[j] - 'a';
            int cb = target[j] - 'a';
            if (ta.ch[u][ca] < 0 || tb.ch[v][cb] < 0)
                break;  // 合取條件，任一邊斷就停
            u = ta.ch[u][ca];
            v = tb.ch[v][cb];
            if (ta.id[u] >= 0 && tb.id[v] >= 0 && d[ta.id[u]][tb.id[v]] < INF &&
                dp[j + 1] < INF) {
                dp[i] = std::min(dp[i], d[ta.id[u]][tb.id[v]] + dp[j + 1]);
            }
        }
    }
    return dp[0] >= INF ? -1 : dp[0];
}
```

## 時間與空間複雜度

記 $n=|s|$、$|D|$ 為字典大小、$L_{\max}$ 為最長詞長、$T=\sum_{w\in D}|w|$ 為字典總長度、$\Sigma$ 為字元集大小。

| 階段 | 時間 | 空間 |
| --- | --- | --- |
| 建 Trie | $O(T)$ | $O(T\cdot\Sigma)$（陣列版）／$O(T)$（map 版） |
| DP | $O(n\cdot L_{\max})$，**與 $|D|$ 無關** | $O(n)$ |
| 472（每個詞各跑一次） | $O\!\big(\sum_w |w|^2\big)$ | 同上 |
| 2977 | $O(m^3+n\cdot L_{\max})$ | $O(m^2+T\Sigma)$ |

**與樸素做法對照**：

| 題 | 規模 | 樸素 | Trie |
| --- | --- | --- | --- |
| 139 單詞拆分 | $n\le300$ | $O(n^2L)$ ✔ **本來就過** | $O(nL_{\max})$ |
| 面試題 17.13 恢復空格 | $n\le10^6$、$T\le15\times10^4$ | $O(n^2)$ ✘ | $O(nL_{\max})$ ✔ |
| 2707 額外字元 | $n\le50$ | 隨便寫都過 | — |
| 472 連接詞 | $T\le6\times10^5$ | $O(T\cdot L_{\max})$ | ✔ |
| 2977 | $n\le1000$、$m\le200$ | — | $O(m^3)$ 主導 |

**⚠ 陣列版 Trie 的空間要算一下**：$T=15\times10^4$、$\Sigma=26$、每格 4 bytes ⇒ $15\times10^4\times26\times4\approx15.6$ MB ✔ 還行；但 $T=10^6$ 就是 104 MB ✘ **會 MLE**。此時改用 `unordered_map` 版或雙陣列 Trie（son/bro 表示法）。

**四個常數層面的實務要點**：

1. **`ch` 用 `std::vector<std::array<int,26>>` 而非 `vector<vector<int>>`** ⇒ 連續記憶體，快 2–3 倍。
2. **`reserve`**：已知 $T$ 就 `ch.reserve(T + 1)`，避免多次擴容搬移。
3. **內層迴圈加 `if (j - i >= maxLen) break;`** 在字典詞普遍很短時比 Trie 的分支判斷更快（但通常沒必要，剪枝已經夠了）。
4. **多測資時重建 Trie**，不要清空 26 萬個 `-1`；直接換一個新物件更快。

## 常見錯誤與邊界條件

1. **⚠ 忘了「不匹配」的那條轉移**（2707 的 `dp[i] = dp[i+1] + 1`）⇒ 沒有任何字典詞從 $i$ 開始時 $\mathit{dp}[i]$ 停在 $\infty$，整個 DP 崩掉。**只要題目允許「跳過字元」，這條就是必需的。**
2. **⚠ 472 沒過濾空字串**（定理 4 前提 1）⇒ 每個詞都被誤判成連接詞。
3. **⚠ 472 把 $w$ 先插入再查詢**（定理 4 (a)）⇒ 每個詞都被自己拼出來。**先查、後插。**
4. **⚠ 472 忘了「至少兩段」**：把 $w$ 排除在樹外之後就自動滿足了；但若改成「一次插入全部再查」，就必須額外記段數 ⚠。
5. **⚠ `break` 寫成 `continue`** ⇒ 剪枝失效還會走到錯誤的節點（$u$ 沒更新，下一步從舊節點繼續走）⇒ **答案錯，不只是變慢** ✘。這是本節最陰險的錯誤。
6. **⚠ 反向 Trie 忘了反轉字典或忘了反轉輸出**（定理 3）。**用正向寫法就沒這問題。**
7. **⚠ 節點用 `bool end` 但題目需要詞的權重** ⇒ 得回頭改結構。**一開始就存 `int id`，代價只是 4 bytes。**
8. **⚠ 大寫字母、數字或空白**：`c - 'a'` 會得到負數 ⇒ 越界 UB。**先確認字元集**，必要時把 `ch` 開成 `128` 或做一次映射。
9. **⚠ 2977 的 `INF` 相加溢位**（定理 5 的 ⚠）⇒ Floyd 裡要先 `if (d[i][k] == INF) continue;`，轉移前要檢查 `dp[j+1] < INF`。
10. **⚠ 2977 忘了初始化 `d[a][a] = 0`** ⇒ 「一段不變」的情形算不出來。
11. **⚠ 空字串輸入**：$n=0$ 時 $\mathit{dp}[0]=\mathit{dp}[n]=0$，模板自然正確 ✔，但布林版要確認 $\mathit{dp}[0]=1$（空串可切分）。
12. **⚠ 在 $n\le2000$ 的題硬寫 Trie**（定理 6）⇒ 多花時間又多 bug。**先估 $n^2$。**

## 與相似技巧的比較

- **與雜湊集合（`unordered_set<string>`）**：兩者都在回答「這個子字串在字典裡嗎」。雜湊要**先建出子字串**（$O(L)$ 的複製）再雜湊，且**必須試遍所有長度**；Trie 邊走邊判、走不通就停（定理 2）。**詞等長時雜湊反而更簡單，別為了用 Trie 而用 Trie。**
- **與滾動雜湊**：$O(1)$ 判斷、$O(n^2)$ 總時間，但有碰撞風險（要雙模數），而且**得不到「哪個詞」**——需要詞的權重時就不夠用。
- **與 AC 自動機**：Trie 加上 fail 鏈。**分界線是「從指定起點匹配」還是「找出所有出現位置」**（定理 6）。本節都是前者。
- **與 11.4 樹狀陣列優化**：兩者都是「把 $O(n^2)$ 的候選枚舉換成資料結構」。11.4 的候選由**數值區間**界定、用區間查詢；本節的候選由**字串匹配**界定、用前綴剪枝。**共通的不變量是「先查、後插」**（11.4 定理 1、本節定理 4）。
- **與 4.1 LCS／4.2 LIS**：那些是「兩個固定字串」或「單一序列」的 DP，狀態是二維下標；本節是「一個字串對一整個字典」，字典被壓進 Trie 後**完全不進入狀態**——狀態仍是一維的位置 ✔。**這是本節最省事的地方。**
- **與 8 章區間 DP**：若「段」可以任意重排或巢狀，就不再是線性切分，定理 1 的分解失效 ⇒ 要上區間 DP。**判準：段是否嚴格由左到右不重疊。**
- **與 11.6 矩陣快速冪**：若字典是**固定的正則語言**且只問「長度 $n$ 的合法字串有幾個」，Trie 可以退化成有限自動機、再用轉移矩陣做快速冪 ⇒ $O(|S|^3\log n)$。**這是 10.1 定理 4「條件必須是有限自動機語言」的同一個觀念。**

## 本節重點速查

- **適用形態**：$\mathit{dp}[i]=\operatorname{opt}_{s[i..j]\in D}(\mathit{dp}[j+1]\ \square\ w)$，字典大、詞長分佈廣。
- **寫法（定理 3）**：**用後綴狀態 $+$ 正向 Trie**——$\mathit{dp}[i]$ 是 $s[i..]$ 的答案，從 $i$ 往右走。不用反轉字典、不用反轉答案。
- **定理 1**：切分的「第一段」唯一 ⇒ 不重不漏。**前提：段不重疊**；允許重疊就會重複計數。
- **定理 2（本節核心）**：Trie 的路徑集合**對前綴封閉** ⇒ 走不動就 `break` 是**安全的**（不漏任何轉移），因此複雜度 $O(n\cdot L_{\max})$ 且**與 $|D|$ 無關**。
- **定理 4（472）**：**按長度非遞減排序 $+$ 先查後插**。兩個前提：**空字串要過濾**、**單詞互異**。組成部分嚴格更短 ⇒ 必已在樹中。
- **定理 5（2977）**：兩層——字串編號 $+$ Floyd 求 $d[a][b]$；再雙 Trie 同步走做 DP。前提：**成本非負**、**區間不重疊**。$\infty$ 用 $1\ll60$ 並在相加前檢查。
- **定理 6**：詞等長 ⇒ 雜湊；$n\le2000$ ⇒ $O(n^2)$；要所有出現位置 ⇒ AC 自動機。**別為了用 Trie 而用 Trie。**
- **最陰險的 bug**：`break` 寫成 `continue`（節點沒更新，答案直接錯）。
- **次陰險的 bug**：忘了 `dp[i] = dp[i+1] + 1` 這條「跳過字元」的轉移。
- **空間**：陣列版 $O(T\cdot26\cdot4)$ bytes；$T=10^6$ 會 MLE ⇒ 改 map 版。
