## 這個技術解決什麼問題

**題目多加了一個「恰好 $k$ 個／最多 $k$ 段」的計數限制，害得狀態多出一維。**

| 版本 | 狀態 | 複雜度 |
| --- | --- | --- |
| 無限制（愛切幾段就切幾段） | $\mathit{dp}[i]$ | $O(n)$ 或 $O(n\log n)$ ✔ |
| **加上「恰好 $k$ 段」** | $\mathit{dp}[i][t]$ | $O(nk)$ ✘（$n,k\le10^5$ 時 $10^{10}$） |

**WQS 二分（又稱 Alien Trick、帶權二分、Lagrangian relaxation）的想法**：

> **把「硬性的段數限制」換成「每開一段就罰 $\lambda$ 元」的軟性代價，再去調 $\lambda$，使得最優解自己剛好用 $k$ 段。**

新的問題**沒有段數維度** ⇒ 回到 $O(n)$；外面套一層對 $\lambda$ 的二分 ⇒ 總共 $O(n\log V)$。**一整個維度換成一個 $\log$。**

**三個典型信號**：

1. **「恰好」／「最多」$k$ 個**（$k$ 段、$k$ 次交易、$k$ 條地毯、選 $k$ 個物品）；
2. **去掉那個 $k$ 之後，問題立刻變簡單**（這是最重要的信號——**先問自己「沒有 $k$ 我會做嗎？」**）；
3. $n$ 與 $k$ **同時**很大（$nk>10^7$）。

**⚠ WQS 有一個硬前提，而且它不成立時會錯得非常隱蔽**：

$$g(k):=\text{「恰好 }k\text{ 段」的最優值}\quad\text{必須是}\quad\boxed{\text{凸的}}.$$

**沒有凸性就沒有 WQS。** 定理 1 說明為什麼，並給出檢查方法。

**⚠ 再次先估樸素法**：188 買賣股票的最佳時機 IV 的 $k\le100$、$n\le1000$ ⇒ $O(nk)=10^5$；2209 用地毯覆蓋後的最少白色磚塊的 $n\le1000$、$\mathit{numCarpets}\le1000$ ⇒ $10^6$。**這兩題直接寫二維 DP 就好**，它們是拿來練 WQS 的，不是非用不可。

## 狀態／資料結構定義

### 三層結構

| 層 | 內容 |
| --- | --- |
| **最外層** | 對懲罰值 $\lambda$ 二分 |
| **中間層** | 一次「帶懲罰的無限制 DP」，回傳 $\big(h(\lambda),\ \mathrm{cnt}(\lambda)\big)$ |
| **最內層** | 原本那個沒有 $k$ 的 DP（$O(n)$、$O(n\log n)$，甚至可以是 11.7 的斜率優化） |

### 記號（本節全程使用，以**最大化**為例）

$$g(k)=\text{恰好用 }k\text{ 段的最優值};\qquad h(\lambda)=\max_{t}\big(g(t)-\lambda t\big).$$

$h(\lambda)$ 正是「每段罰 $\lambda$」之後的無限制最優值——**因為無限制 DP 會自動在所有 $t$ 之間選最好的那個** ✔。

### 中間層必須回傳兩個東西

```
check(λ)  ->  { value = h(λ),  cnt = 達到 h(λ) 的「最少」段數 }
```

**⚠ `cnt` 不是可有可無的附加資訊，而是整個演算法的核心**（定理 4）。它有兩種取法（最少段數 / 最多段數），**必須固定一種並貫徹到底**：

| 取法 | 二分找 | 答案 |
| --- | --- | --- |
| **最少段數**（本節採用） | 最小的 $\lambda$ 使 $\mathrm{cnt}(\lambda)\le k$ | $h(\lambda)+\lambda k$ |
| 最多段數 | 最大的 $\lambda$ 使 $\mathrm{cnt}(\lambda)\ge k$ | $h(\lambda)+\lambda k$ |

### 實作 `cnt` 的統一寫法

每個 DP 狀態存一對 $(\text{值},\ \text{段數})$，轉移時**先比值、值相同再比段數**：

```
若 (v > best) 或 (v == best 且 c < bestCnt)  ->  更新
```

**⚠ 這個 tie-break 必須寫對**，否則 `cnt` 回傳的不是真正的最小段數，定理 4 的論證就垮了。

## 不變量或正確性證明

### 定理 1（**凸性是唯一也是全部的前提**）

*定義*：$g$ **上凸（concave）** $\iff$ 其一階差分 $\Delta(k)=g(k)-g(k-1)$ **非遞增**：

$$\Delta(1)\ \ge\ \Delta(2)\ \ge\ \cdots\ \ge\ \Delta(K).$$

（直觀：**每多切一段，邊際收益遞減。**）

*命題*：WQS 二分正確 $\iff$ $g$ 上凸（最大化問題；最小化則要求下凸，差分非遞減）。

*證明（必要性——不凸就會錯）*。設 $g(0)=0,g(1)=1,g(2)=5,g(3)=6$（$\Delta=1,4,1$，**不凸**）。考慮 $k=1$：對任何 $\lambda$，

$$g(1)-\lambda\cdot1=1-\lambda,\qquad g(2)-\lambda\cdot2=5-2\lambda.$$

要讓 $t=1$ 成為 $\arg\max$，需要 $1-\lambda\ge5-2\lambda$ ⇒ $\lambda\ge4$；但同時要贏過 $t=0$：$1-\lambda\ge0$ ⇒ $\lambda\le1$。**兩者矛盾** ⇒ **沒有任何 $\lambda$ 能讓 $t=1$ 被選中** ✘。二分無論怎麼跑都得不到 $g(1)$。$\square$

*⚠ 錯誤的表現形式*：不會 RE、不會 TLE，就是**答案偏大**（回傳了凸包上的插值而非真值）。**小測資通常正常，大測資才錯。**

*推論 1.1（凸性的驗證方法——寫完 WQS 一定要做）*：

```
對 n <= 12 的隨機測資，用 O(n^2 k) 的樸素二維 DP 算出 g(0..K)，
檢查 g(k+1) - g(k) <= g(k) - g(k-1) 對所有 k 成立。
```

**這是唯一可靠的驗證法。** 憑感覺說「應該是凸的」是本節最大的風險來源。

*推論 1.2（凸性的常見來源：交換論證）*：多數「分段／選取」問題的凸性可以這樣證——

設 $A$ 是 $k-1$ 段的最優解、$B$ 是 $k+1$ 段的最優解。把 $A\cup B$ 重新組合成兩個各 $k$ 段的解 $A',B'$，且 $\mathrm{val}(A')+\mathrm{val}(B')\ge\mathrm{val}(A)+\mathrm{val}(B)$。則

$$2g(k)\ \ge\ \mathrm{val}(A')+\mathrm{val}(B')\ \ge\ g(k-1)+g(k+1)\ \Longrightarrow\ \Delta(k)\ge\Delta(k+1)\ \checkmark.$$

**難的一步永遠是「重新組合」**——它依賴問題的具體結構（區間可交換、交易可拆分等），**不是通用的**。

*⚠ 一個經典的凸性失效情形*：段數有**額外的結構限制**（例如「每段長度必須是偶數」「相鄰兩段不能同色」）⇒ $g$ 可能在某些 $k$ 上無定義或跳躍 ⇒ 不凸 ✘。

### 定理 2（**勒讓德變換：$\lambda$ 是切線斜率**）

*命題*：設 $g$ 上凸，則對每個 $k$，取任意

$$\lambda\ \in\ \big[\ \Delta(k+1),\ \ \Delta(k)\ \big]\qquad(\text{即 }g(k+1)-g(k)\ \le\ \lambda\ \le\ g(k)-g(k-1)),$$

都有 $k\in\arg\max_t\big(g(t)-\lambda t\big)$，且

$$\boxed{g(k)=h(\lambda)+\lambda k}.$$

*證明*。要證 $g(k)-\lambda k\ \ge\ g(t)-\lambda t$ 對所有 $t$ 成立。

**情形 $t>k$**：

$$g(t)-g(k)=\sum_{s=k+1}^{t}\Delta(s)\ \le\ (t-k)\,\Delta(k+1)\ \le\ (t-k)\lambda,$$

第一個不等號用了 $\Delta$ 非遞增（$s\ge k+1\Rightarrow\Delta(s)\le\Delta(k+1)$）✔，第二個用了 $\lambda\ge\Delta(k+1)$ ✔。移項即得 ✔。

**情形 $t<k$**：

$$g(k)-g(t)=\sum_{s=t+1}^{k}\Delta(s)\ \ge\ (k-t)\,\Delta(k)\ \ge\ (k-t)\lambda,$$

用 $\Delta$ 非遞增（$s\le k\Rightarrow\Delta(s)\ge\Delta(k)$）與 $\lambda\le\Delta(k)$ ✔。移項即得 ✔。

**情形 $t=k$**：顯然 ✔。

於是 $h(\lambda)=g(k)-\lambda k$ ⇒ $g(k)=h(\lambda)+\lambda k$ ✔。$\square$

*幾何解讀*：$h(\lambda)$ 是把斜率 $\lambda$ 的直線從上往下壓，第一次碰到 $g$ 的圖形時的 $y$ 截距。**$\lambda$ 就是切線斜率，$k$ 就是切點的橫座標。** 這與 11.7 定理 2 是同一件事（那裡的 $k_i$ 是斜率、$X_j$ 是橫座標），只是**這裡我們反過來用：已知想要的切點，去找對應的斜率** ✔。

*⚠ 定理 2 依賴的唯一前提就是 $\Delta$ 非遞增*，證明的兩個不等號各用了它一次。**這就是為什麼凸性不可協商。**

### 定理 3（**$\mathrm{cnt}(\lambda)$ 對 $\lambda$ 單調 ⇒ 可以二分**）

*命題*：令 $\mathrm{cnt}_{\min}(\lambda)=\min\arg\max_t(g(t)-\lambda t)$。則 $\lambda_1<\lambda_2\Rightarrow\mathrm{cnt}_{\min}(\lambda_1)\ge\mathrm{cnt}_{\min}(\lambda_2)$。

*證明*。記 $k_1=\mathrm{cnt}_{\min}(\lambda_1)$、$k_2=\mathrm{cnt}_{\min}(\lambda_2)$，反設 $k_1<k_2$。由最優性：

$$g(k_1)-\lambda_1k_1\ \ge\ g(k_2)-\lambda_1k_2,\qquad g(k_2)-\lambda_2k_2\ \ge\ g(k_1)-\lambda_2k_1.$$

兩式相加並消去 $g$：

$$-\lambda_1k_1-\lambda_2k_2\ \ge\ -\lambda_1k_2-\lambda_2k_1\ \Longrightarrow\ (\lambda_2-\lambda_1)(k_2-k_1)\ \le\ 0.$$

但 $\lambda_2>\lambda_1$ 且 $k_2>k_1$ ⇒ 左式 $>0$，矛盾 ✘。故 $k_1\ge k_2$ ✔。$\square$

*⚠ 注意這個證明沒有用到凸性*——單調性是**交換不等式**的直接結果，對任何 $g$ 都成立。**凸性是用在定理 2（存在合適的 $\lambda$），不是用在定理 3（單調性）。分清楚這兩件事，才知道出錯時該懷疑哪一邊。**

*推論 3.1（二分的目標）*：既然 $\mathrm{cnt}_{\min}$ 對 $\lambda$ 非遞增，就可以二分

$$\lambda^{*}=\min\{\ \lambda\ :\ \mathrm{cnt}_{\min}(\lambda)\ \le\ k\ \}.$$

**判定式是 `cnt <= k`，區間是「單調的布林序列」** ⇒ 標準的「找第一個 true」二分 ✔。

### 定理 4（**平臺問題：找不到「恰好 $k$」也沒關係**）

這是 WQS 的精髓，也是初學者最容易卡住的地方。

*問題*：$g$ 上若有連續三點**共線**（$\Delta(k)=\Delta(k+1)$），則在 $\lambda=\Delta(k)$ 這一點，$t=k-1,k,k+1$ **同時最優** ⇒ DP 回傳的 $\mathrm{cnt}$ 只會是其中一個（我們取最小的），**可能永遠取不到我們要的 $k$** ⚠。

*命題*：令 $\lambda^{*}$ 如推論 3.1。則**即使 $\mathrm{cnt}_{\min}(\lambda^{*})<k$**，仍有

$$g(k)=h(\lambda^{*})+\lambda^{*}k.$$

*證明*。記 $c_-=\mathrm{cnt}_{\min}(\lambda^{*})\le k$。

**第一步：$k\le\mathrm{cnt}_{\max}(\lambda^{*})$。** 若 $\lambda^{*}$ 是二分區間的下界（$\lambda^{*}=\lambda_{\text{lo}}$，代表連最小的懲罰都已經讓段數 $\le k$），則無限制最優解本身就用不到 $k$ 段，**「最多 $k$ 段」的題目直接回傳 $h(\lambda^{*})$ 即可**（此時 $\lambda^{*}=0$，公式仍成立）✔。否則由 $\lambda^{*}$ 的最小性，$\mathrm{cnt}_{\min}(\lambda^{*}-1)>k$（整數 $\lambda$ 的情形）。而 $\lambda^{*}-1$ 與 $\lambda^{*}$ 相鄰 ⇒ 在 $[\lambda^{*}-1,\lambda^{*}]$ 之間 $\arg\max$ 從 $>k$ 掉到 $c_-\le k$ ⇒ **$k$ 落在 $\lambda^{*}$ 對應的最優段數區間 $[c_-,\ c_+]$ 內** ✔。

**第二步：區間內全部共線。** 設 $c_-\le t_1<t_2\le c_+$ 都是 $\arg\max$ ⇒

$$g(t_1)-\lambda^{*}t_1=g(t_2)-\lambda^{*}t_2=h(\lambda^{*})\ \Longrightarrow\ \frac{g(t_2)-g(t_1)}{t_2-t_1}=\lambda^{*}.$$

由凸性，介於其間的每個 $t$ 也必須落在這條直線上（否則會凹進去或凸出去，與 $\Delta$ 非遞增矛盾）⇒ **對 $[c_-,c_+]$ 內的每個 $t$，$g(t)=h(\lambda^{*})+\lambda^{*}t$** ✔。

**第三步**：$k\in[c_-,c_+]$（第一步）⇒ 代入即得 ✔。$\square$

*⚠ 這條定理的實務意義非常大*：

> **不需要（也往往做不到）真的讓 DP 湊出 $k$ 段。只要 $k$ 落在最優段數區間裡，公式 $h(\lambda^{*})+\lambda^{*}k$ 就給出正確答案。**

*⚠ 相對地，兩個常見的錯誤寫法*：

1. **二分到「$\mathrm{cnt}$ 恰好 $=k$」才停** ⇒ 有平臺時**永遠找不到，死迴圈或回傳錯誤** ✘。**判定式一定要寫成 $\le$（或 $\ge$），不能寫 $=$。**
2. **`cnt` 取的不是嚴格的最小（或最大）段數** ⇒ 第一步的區間論證失效 ⇒ 偶發性錯誤 ✘。**tie-break 必須寫對。**

*推論 4.1（「最多 $k$ 段」比「恰好 $k$ 段」更好處理）*：若題目是「**最多** $k$ 段」且 $g$ 非遞減，則 $\lambda$ 只需在 $[0,+\infty)$ 上二分，且 $\lambda^{*}=0$ 時直接回傳 $h(0)$ ✔。**188 就是這種。**

### 定理 5（**整數 $\lambda$：把精度問題徹底消滅**）

*命題*：若所有代價都是整數，則 $g(k)$ 皆為整數 ⇒ $\Delta(k)$ 皆為整數 ⇒ **只需在整數 $\lambda$ 上二分**，且定理 2 的區間 $[\Delta(k+1),\Delta(k)]$ 必含整數（因為兩端都是整數）✔。

*證明*。$g$ 是有限多個整數值的 $\max$／$\min$ ⇒ 整數 ✔。區間端點為整數且 $\Delta(k+1)\le\Delta(k)$ ⇒ 區間非空且含整數 ✔。$\square$

*⚠ 這條的重要性被嚴重低估*。實數二分的三個坑：

| 坑 | 後果 |
| --- | --- |
| 迭代次數不夠 | 答案差一點點 |
| 迭代次數太多 | TLE |
| 浮點比較 `cnt(λ) <= k` 在平臺邊界抖動 | **答案隨機錯** |

**整數二分全部沒有。** $\lambda$ 的範圍取 $[0,\ V]$，$V=$ 單段收益的上界（例如所有正差之和），$O(\log V)\approx30\sim60$ 次 DP ✔。

*⚠ 若代價含 $0.5$ 之類的半整數*：**全部乘 2 化成整數**，最後再除回去 ✔。

*推論 5.1（$\lambda$ 的搜尋範圍）*：下界取 $0$（或 $-V$，若「多開一段」可能有害）；上界取「一段最多能賺多少」。**範圍設太小會讓二分停在邊界、答案錯；設太大只多幾次迭代。寧可設大。**

### 定理 6（**該不該用**）

*命題（不該用的四種情形）*：

1. **$nk\le10^7$** ⇒ 直接二維 DP。188（$nk\le10^5$）、2209（$\le10^6$）都是。**先估。**
2. **$g$ 不凸**（定理 1）⇒ **完全不能用**，沒有補救。
3. **需要輸出具體方案** ⇒ WQS 只給最優**值**；要方案得在 $\lambda^{*}$ 下重跑一次 DP 並回溯，**而且回溯出來的段數可能不是 $k$**（定理 4 的平臺）⇒ 還要額外把某些段拆開／合併。**很麻煩，能避則避。**
4. **$k$ 很小**（$k\le100$）⇒ 二維 DP 的 $O(nk)$ 通常比 $O(n\log V)$ 還快（$\log V\approx60$）。

*命題（該用）*：$n,k$ 同時 $\ge10^4$，且凸性已驗證。

*推論 6.1（與 11.7 疊加，本章的天花板）*：內層那個「無限制 DP」本身可以是 $O(n^2)$ 的交叉項轉移 ⇒ 用 11.7 的斜率優化壓成 $O(n)$ ⇒ **總複雜度 $O(n\log V)$**。

$$\underbrace{\text{WQS 二分}}_{\log V\ \text{層}}\ \times\ \underbrace{\text{斜率優化 DP}}_{O(n)\ \text{每層}}.$$

**⚠ 疊加時的兩個額外難點**：(a) 每層都要重建凸包（清空 `X`、`Y`、`head`）；(b) `cnt` 的 tie-break 要一路傳進凸包的比較裡——**這會讓「彈出共線點」變得不安全**（11.7 定理 5 的 ⚠：共線點的最優值相同但段數不同）⇒ **此時凸包彈出條件要改成嚴格 $<0$，並在取等時比段數** ⚠。

*推論 6.2（其他名字）*：WQS 二分 $=$ Alien Trick $=$ 帶權二分 $=$ 拉格朗日鬆弛（Lagrangian relaxation）的離散版。**知道「拉格朗日鬆弛」這個名字的好處是**：它提醒你 $\lambda$ 是**對偶變數**，而「對偶間隙為零」正好對應「$g$ 是凸的」——**這就是定理 1 的另一種說法。**

## C++17 模板

**模板 1｜通用框架（整數二分，最大化，`cnt` 取最少段數）**

```cpp
// check(lambda) 回傳 {h(lambda), 達到 h(lambda) 的最少段數}
// 前提：g(k) 上凸（推論 1.1 驗過）
template <class Check>
long long wqs(long long lo, long long hi, int k, Check check) {
    // 二分「最小的 lambda 使得 cnt <= k」（推論 3.1）
    while (lo < hi) {
        long long mid = lo + (hi - lo) / 2;  // 注意負數時的向下取整
        if (check(mid).second <= k) {
            hi = mid;
        } else {
            lo = mid + 1;
        }
    }
    auto [value, cnt] = check(lo);
    return value + lo * k;  // 定理 4：不必 cnt == k
}
```

**模板 2｜188 買賣股票的最佳時機 IV（最多 $k$ 筆交易）**

```cpp
// 每賣出一次（完成一筆交易）罰 lambda
// 回傳 {扣掉懲罰後的最大利潤, 最少交易次數}
std::pair<long long, int> stockCheck(const std::vector<int>& prices,
                                     long long lambda) {
    const long long NEG = -(1LL << 60);
    long long hold = NEG;  // 手上有股票時的最大值
    int holdCnt = 0;
    long long empty = 0;  // 手上沒股票時的最大值
    int emptyCnt = 0;

    for (int x : prices) {
        long long nh = hold;
        int nhc = holdCnt;
        long long ne = empty;
        int nec = emptyCnt;

        // 買入（不計交易次數）
        long long buy = empty - x;
        if (buy > nh || (buy == nh && emptyCnt < nhc)) {
            nh = buy;
            nhc = emptyCnt;
        }
        // 賣出（計一次交易，扣 lambda）
        if (hold > NEG) {
            long long sell = hold + x - lambda;
            int sc = holdCnt + 1;
            if (sell > ne || (sell == ne && sc < nec)) {
                ne = sell;
                nec = sc;
            }
        }
        hold = nh;
        holdCnt = nhc;
        empty = ne;
        emptyCnt = nec;
    }
    return {empty, emptyCnt};
}

int maxProfit(int k, std::vector<int>& prices) {
    long long hi = 0;
    for (size_t i = 1; i < prices.size(); ++i) {
        hi += std::max(0,
                       prices[i] - prices[i - 1]);  // lambda 的上界（推論 5.1）
    }
    long long ans =
        wqs(0, hi, k, [&](long long lam) { return stockCheck(prices, lam); });
    return int(ans);
}
```

| --- | --- | --- |
| 0 | 0 | — |
| 1 | 1 | 1 |
| 2 | 2 | 1 |
| 3 | 3 | 1 |

$\Delta$ 全等於 1 ⇒ **整條線共線，是最極端的平臺** ✔ 也確實上凸。

- $\lambda=0$：$h=3$、$\mathrm{cnt}_{\min}=3>1$ ⇒ 往上；
- $\lambda=1$：每筆交易淨賺 $1-1=0$ ⇒ $h=0$、$\mathrm{cnt}_{\min}=\boxed{0}\le1$ ⇒ 可行。

二分得 $\lambda^{*}=1$，答案 $=h(1)+1\cdot k=0+1=\boxed{1}$ ✔。

**注意 $\mathrm{cnt}_{\min}(\lambda^{*})=0\ne k=1$——定理 4 說這完全沒關係。** 若把判定式寫成 `cnt == k`，這組就會掛掉。

另一組（無平臺）：`prices = [3,2,6,5,0,3]`、`k = 2` ⇒ $\lambda^{*}=0$、$h(0)=7$、$\mathrm{cnt}=2\le2$ ⇒ 答案 $7+0=7$ ✔。

**模板 3｜凸性驗證（推論 1.1，寫完 WQS 一定要跑）**

```cpp
// 對小 n 用樸素二維 DP 算出 g(0..K)，檢查二階差分 <= 0
bool verifyConcave(const std::vector<long long>& g) {
    for (size_t t = 2; t + 1 <= g.size(); ++t) {
        // g[t] - g[t-1] <= g[t-1] - g[t-2]
        if (g[t] - g[t - 1] > g[t - 1] - g[t - 2]) {
            return false;  // 不凸 -> WQS 不適用（定理 1）
        }
    }
    return true;
}
```

**用法**：對 $n\le12$ 的隨機測資各跑一次；**只要有一組回傳 `false`，立刻放棄 WQS**，改回二維 DP 或另尋他法。

## 時間與空間複雜度

記 $V$ 為 $\lambda$ 的搜尋範圍寬度，$T(n)$ 為一次「無限制 DP」的成本。

| 做法 | 時間 | 空間 |
| --- | --- | --- |
| 二維 DP | $O(nk)$ | $O(n)$（滾動） |
| **WQS $+$ 線性 DP** | $O(T(n)\log V)=O(n\log V)$ | $O(n)$ 或 $O(1)$ |
| **WQS $+$ 斜率優化**（推論 6.1） | $O(n\log V)$ | $O(n)$ |
| WQS $+$ 樹狀陣列 DP | $O(n\log n\log V)$ | $O(n)$ |

**具體對照**：

| 題／情境 | $n$ | $k$ | 二維 DP | WQS |
| --- | --- | --- | --- | --- |
| 188 買賣股票 IV | $10^3$ | $10^2$ | $10^5$ ✔ **直接寫** | $6\times10^4$ |
| 2209 地毯覆蓋 | $10^3$ | $10^3$ | $10^6$ ✔ **直接寫** | $10^5$ |
| 一般競賽題 | $10^5$ | $10^5$ | $10^{10}$ ✘ | $6\times10^6$ ✔ |

**⚠ $\log V$ 不小**：$V=10^{18}$ 時是 60 次完整 DP。若 $T(n)=O(n\log n)$，總量是 $60n\log n$——**在 $n=10^5$ 時約 $10^8$，會很緊**。此時要 (a) 縮小 $\lambda$ 範圍（用問題的上下界估計）或 (b) 把內層 DP 優化到 $O(n)$。

**三個常數層面的實務要點**：

1. **內層 DP 用滾動變數，不要每次配置 `vector`** ⇒ 60 次配置很傷。
2. **`cnt` 用 `int`**，值用 `long long`；把兩者塞進 `std::pair` 沒有效能問題。
3. **$\lambda$ 為負的可能性**：若「多開一段」可能讓答案變差（最小化問題常見），下界要設負數；此時 `mid = lo + (hi - lo) / 2` 才是正確的向下取整寫法（`(lo + hi) / 2` 對負數會往零取整 ⇒ **可能死迴圈**）⚠。

## 常見錯誤與邊界條件

1. **⚠ 沒驗證凸性就用**（定理 1）⇒ 答案偏大／偏小，且小測資看不出來。**推論 1.1 的對拍是必做項，不是可選項。**
2. **⚠ 二分判定式寫成 `cnt == k`**（定理 4 的 ⚠1）⇒ 有平臺時永遠找不到。**必須是 `<=`（或 `>=`）。**
3. **⚠ `cnt` 的 tie-break 寫錯**（定理 4 的 ⚠2）⇒ 回傳的不是最小段數 ⇒ 區間論證失效。**「值相同時取段數較小者」這行不能漏。**
4. **⚠ 最後忘了把懲罰加回去** ⇒ 答案應該是 `h(λ*) + λ* * k`，不是 `h(λ*)`。**這是打完收工前最常忘的一行。**
5. **⚠ 加回去用的是 `cnt` 而不是 `k`** ⇒ `h + λ*cnt` 在平臺時會算出**別的 $g(t)$**，不是 $g(k)$ ✘。**一定要乘 $k$。**
6. **⚠ 用浮點 $\lambda$**（定理 5）⇒ 精度抖動、迭代次數難調。**代價是整數就用整數二分。**
7. **⚠ $\lambda$ 的範圍設太窄**（推論 5.1）⇒ 二分卡在邊界。**寧可設大，只多幾次迭代。**
8. **⚠ $\lambda$ 可為負時用 `(lo + hi) / 2`** ⇒ C++ 的整數除法往零取整 ⇒ 二分可能不收斂。**用 `lo + (hi - lo) / 2`。**
9. **⚠ 內層 DP 的初值沒重設** ⇒ 上一次二分的殘留狀態污染這一次。
10. **⚠ 「恰好 $k$」與「最多 $k$」搞混**：「最多」時 $g$ 非遞減 ⇒ $\lambda\ge0$ 即可（推論 4.1）；「恰好」時 $g$ 可能先升後降 ⇒ **$\lambda$ 必須允許負數** ⚠。
11. **⚠ 要輸出方案**（定理 6 情形 3）⇒ WQS 只給值。**先問清楚題目要什麼再決定用不用。**
12. **⚠ 與 11.7 疊加時彈掉共線點**（推論 6.1 的 ⚠b）⇒ 段數資訊被破壞。**改成嚴格 $<0$ 並在取等時比段數。**
13. **⚠ $k=0$ 或 $k>$ 可能的最大段數** ⇒ 邊界要特判或確認公式仍成立。

## 與相似技巧的比較

- **與二維 DP（直接多開一維）**：**這永遠是正確的參照組。** WQS 唯一的好處是砍掉 $k$ 這一維；代價是多一個 $\log V$、加上凸性前提、加上難以輸出方案。**$nk\le10^7$ 時二維 DP 全面勝出。**
- **與 11.7 斜率優化**：兩者都在用凸性，但**用的方向相反**。11.7 是「已知斜率 $k_i$，找最優切點」；WQS 是「已知想要的切點 $k$，找對應斜率 $\lambda$」。**它們是同一個勒讓德變換的兩個方向**（定理 2 的幾何解讀），也因此可以完美疊加（推論 6.1）。
- **與 11.6 矩陣快速冪**：11.6 砍**步數**（要線性常係數），WQS 砍**計數維度**（要凸性）。前提互不相干，理論上可疊但實務罕見。
- **與費用流／模擬費用流**：「恰好 $k$ 單位流量」的最小費用流，其費用關於流量**天然是凸的**（連續最短路的費用遞增）⇒ WQS 在網路流上同樣適用。**反過來說，若你能把問題建成費用流，凸性就免證了** ✔——這是證凸性最省力的路徑之一。
- **與貪心 $+$ 反悔堆**：許多「選 $k$ 個」的問題可以用「先貪心選最好的，再用堆做反悔」在 $O(n\log n)$ 內解，**而且不需要凸性**。**若題目結構允許反悔貪心，它通常比 WQS 更好寫、更好證。**
- **與拉格朗日鬆弛的一般理論**：WQS 是離散版的拉格朗日鬆弛。**一般的拉格朗日鬆弛只保證得到「對偶界」（可能有間隙）；WQS 之所以能得到精確解，正是因為凸性讓對偶間隙為零**（推論 6.2）。**「不凸 ⇒ 有間隙 ⇒ 答案偏大」——這就是定理 1 反例的本質。**

## 本節重點速查

- **適用形態**：「恰好／最多 $k$ 段」的限制讓 $O(n)$ 變成 $O(nk)$，且 $n,k$ 都很大。
- **核心變換**：每段罰 $\lambda$ ⇒ 無限制 DP 得 $h(\lambda)=\max_t(g(t)-\lambda t)$ ⇒ 調 $\lambda$ 讓最優段數落到 $k$。
- **定理 1（唯一前提）**：$g(k)$ 必須**凸**（最大化 ⇒ 差分非遞增）。**不凸 ⇒ 答案偏大，且小測資測不出來。** 必做：小 $n$ 樸素 DP 打表驗二階差分（模板 3）。
- **定理 2（為什麼對）**：$\lambda\in[\Delta(k+1),\Delta(k)]$ ⇒ $k$ 是 $\arg\max$ ⇒ $g(k)=h(\lambda)+\lambda k$。證明的兩個不等號各用一次凸性。
- **定理 3（可以二分）**：$\mathrm{cnt}_{\min}(\lambda)$ 對 $\lambda$ 非遞增（**這條不需要凸性**，是交換不等式）。二分目標：**最小的 $\lambda$ 使 $\mathrm{cnt}\le k$**。
- **定理 4（平臺，最關鍵）**：$g$ 上有共線段時，$\mathrm{cnt}(\lambda^{*})$ **可能不等於 $k$，這完全沒關係**——只要 $k$ 落在最優段數區間內，$h(\lambda^{*})+\lambda^{*}k$ 仍是正解。**判定式絕不能寫 `cnt == k`。**
- **定理 5（整數化）**：代價是整數 ⇒ $\lambda$ 只在整數上二分 ⇒ 沒有精度問題。半整數就全部乘 2。
- **定理 6（別亂用）**：$nk\le10^7$ ⇒ 二維 DP；$k\le100$ ⇒ 二維 DP 通常還更快；要輸出方案 ⇒ 很麻煩。**188、2209 都屬於「直接寫二維」的範圍。**
- **最常忘的一行**：最後要 `+ λ* * k`（**乘 $k$，不是乘 `cnt`**）。
- **驗證組**：`prices=[1,2,1,2,1,2]`、`k=1` ⇒ $\lambda^{*}=1$、$h=0$、$\mathrm{cnt}=0$、答案 $=1$。**這組專測平臺。**
- **天花板組合**：WQS（外層 $\log V$）$\times$ 斜率優化（內層 $O(n)$）$=O(n\log V)$。⚠ 疊加時凸包不能彈共線點。
