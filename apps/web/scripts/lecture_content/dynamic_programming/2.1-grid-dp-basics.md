## 這個技術解決什麼問題

網格 DP 是**第一個「填表順序不是理所當然」的場景**。在 1 節裡狀態只有一個下標，從小到大掃就對了；到了二維，你得回答一個新問題：

> **我怎麼知道，算 $(i,j)$ 的時候它依賴的格子都已經算好了？**

答案很短，但值得寫下來：**DP 的填表順序，就是狀態依賴圖的一個拓撲序**（定理 1）。**網格 DP 之所以能用「兩層 for 迴圈由上到下、由左到右」，是因為「只能往右／往下」這個限制恰好讓行列下標遞增的順序成為合法拓撲序。** 一旦題目允許四個方向移動（2.2 的 329），這個順序就不成立，得換記憶化搜尋。

**本節同時是「滾動陣列」的真正起點**（定理 2）：一維就地更新為什麼能同時讀到「上一行」與「這一行」的值——**這條規則直接決定了 3 節背包的正序／倒序**，值得在這裡一次講透。

**辨識訊號**：
- 在二維方格上移動，方向固定（只能右／下，或類似限制），問路徑數或路徑最佳值；
- 每個格子的答案只由「相鄰的前驅格子」決定（120 由正上方與斜上方、931 由上一列三個鄰格）；
- 暴力會把同一個格子的子路徑重算很多次。

## 狀態／資料結構定義

```cpp
// 定義：f[i][j] = 從起點走到 (i,j) 的方案數 / 最優值
// 依賴：f[i][j] <- f[i-1][j], f[i][j-1]     （只能右/下）
vector<vector<long long>> f(m, vector<long long>(n, 0));
f[0][0] = 1;  // 計數型的邊界
for (int i = 0; i < m; i++)
    for (int j = 0; j < n; j++) {
        if (i) f[i][j] += f[i - 1][j];
        if (j) f[i][j] += f[i][j - 1];
    }
```

**壓成一維（定理 2 說明為什麼安全）**：

```cpp
vector<long long> f(n, 0);
f[0] = 1;
for (int i = 0; i < m; i++)
    for (int j = 1; j < n; j++)
        f[j] += f[j - 1];  // 正序！讀到的 f[j] 是上一行、f[j-1] 是這一行
```

**單位元要選對（定理 3）**：

| 合併運算 | 不可達格的初值 | 為什麼 |
| --- | --- | --- |
| `+`（計數） | `0` | 加法單位元，貢獻 0 種方案 |
| `min`（最小路徑和） | **`INF`** | 取 min 的單位元；設 0 會被誤選為最優 ✘ |
| `max`（最大得分） | **`-INF`** | 同理 |

**哨兵邊界的寫法（省掉所有 `if (i)` 判斷）**：

```cpp
// 多開一圈，下標整體 +1；f[0][*] 與 f[*][0] 設成單位元
vector f(m + 1, vector<long long>(n + 1, INF));
f[0][1] = 0;  // 讓 (1,1) 能從「虛擬前驅」拿到 0
for (int i = 1; i <= m; i++)
    for (int j = 1; j <= n; j++)
        f[i][j] = min(f[i - 1][j], f[i][j - 1]) + grid[i - 1][j - 1];
```

**哨兵法讓「第一行第一列」不必特判**——**但只有在單位元選對時才成立**（這裡 `INF` 與 `f[0][1] = 0` 缺一不可）。

## 不變量或正確性證明

### 定理 1（填表順序 = 依賴圖的拓撲序）

*設定*：把每個狀態看成一個節點，若計算狀態 $u$ 需要用到狀態 $v$，就連一條邊 $v \to u$。稱這張圖為**依賴圖**。

*命題*：**DP 可行 $\iff$ 依賴圖是 DAG（無環）**；而**任何一個拓撲序都是合法的填表順序**。

*證明*。
- **(必要性)** 若有環 $u_1 \to u_2 \to \cdots \to u_1$，則計算 $u_1$ 需要 $u_1$ 自己 ⇒ 遞迴式不良定義 ✘（此時要改用最短路演算法或 13.1 定理 3 的逆向推理）。
- **(充分性)** 按拓撲序處理，處理到 $u$ 時它的所有前驅都排在前面、已被計算 ✔。$\square$

*推論 1.1（網格的具體拓撲序）*：只能右／下時，$(i,j)$ 的前驅是 $(i-1,j)$ 與 $(i,j-1)$，**兩者的 $i+j$ 都嚴格小於 $(i,j)$ 的 $i+j$** ⇒ 按 $i+j$ 遞增是拓撲序；而「行優先由上到下、由左到右」是它的一個加細 ✔。**「列優先」也一樣合法**——這解釋了為什麼有些題解的兩層迴圈順序看起來相反卻都對。

*推論 1.2（什麼時候不能用雙層迴圈）*：允許四方向移動時，$(i,j)$ 可能依賴 $(i+1,j)$，**下標不再單調** ⇒ 必須另找拓撲序（329 靠「值嚴格遞增」提供，見 2.2），或直接用記憶化搜尋讓遞迴自己找 ✔。

**這條定理是整章「填表順序」討論的總綱。** 每當你不確定迴圈該正著跑還是倒著跑，就回到這一句：**畫出依賴箭頭，找一個讓所有箭頭都指向「後面」的順序。**

### 定理 2（一維就地更新為什麼同時讀得到兩行）

*命題*：執行 `for (j = 1; j < n; j++) f[j] += f[j-1];` 時，在處理下標 $j$ 的那一刻，

$$f[j] \ \text{的舊值} = f_{\text{上一行}}[j], \qquad f[j-1] \ \text{的現值} = f_{\text{這一行}}[j-1].$$

*證明（對 $j$ 歸納）*。

- **基底 $j = 1$**：$f[0]$ 在本行尚未被寫入，但**它的正確值本來就等於上一行的 $f[0]$**（第一列只能從上方來）⇒ 兩者一致 ✔；$f[1]$ 尚未被本行寫過 ⇒ 仍是上一行的值 ✔。
- **歸納步**：處理 $j$ 之前，迴圈已經寫過 $f[0..j-1]$、尚未碰過 $f[j..n-1]$。故 $f[j-1]$ 是本行的新值、$f[j]$ 是上一行的舊值 ✔。$\square$

**這正是我們要的**：$(i,j)$ 需要上方的 $(i-1,j)$ 與左方的 $(i,j-1)$，**正序就地更新恰好一次提供這兩者** ✔。

**若把迴圈改成倒序 `for (j = n-1; j >= 1; j--)`，$f[j-1]$ 會是上一行的值 ⇒ 算出來的是完全不同的東西** ✘。

> **判準：「就地更新」的迴圈方向，取決於你要讀到的是**本輪**還是**上一輪**的值。同向（要本輪）就順著寫入方向掃，反向（要上一輪）就逆著掃。**

**這一句是 3.1 0-1 背包必須倒序、3.2 完全背包必須正序的完整解釋**——那兩節只是把「上一行 / 這一行」換成「不用第 $i$ 個物品 / 可以重複用第 $i$ 個物品」。**在這裡把它想通，背包章就不用再背了。**

### 定理 3（障礙與不可達：單位元的選擇）

*命題*：把不可達格（障礙、越界）的值設成**合併運算的單位元**，可以讓轉移式不必特判。

*證明*。設合併運算為 $\oplus$、單位元為 $e$（$x \oplus e = x$）。不可達格對應的方案集合為空，其「彙總值」依定義就是空集合上的 $\oplus$，即 $e$ ✔。於是 $f[i][j] = f[i-1][j] \oplus f[i][j-1]$ 在任何情況下都成立 ✔。$\square$

**具體對照**：
- **63 不同路徑 II（計數，$\oplus = +$）**：障礙格設 0 ✔。**注意第一行／第一列不能無腦填 1**——障礙之後的格子全都不可達，必須靠遞推自然傳播 0，或在初始化時遇到障礙就 `break` ✔。
- **64 最小路徑和（$\oplus = \min$）**：越界格設 `INF`，**不能設 0** ✘（會讓 `min` 誤取 0）。
- **931 下降路徑最小和（$\oplus = \min$，三個前驅）**：左右越界設 `INF`，或用「多開兩列哨兵」把邊界判斷消掉 ✔。

**`INF` 的數值要留餘裕**：若寫成 `INT_MAX`，`INF + grid[i][j]` 會溢位 ✘。**慣例是 `const int INF = 0x3f3f3f3f;`（約 $10^9$，兩個相加仍不溢位）**，或直接用 `long long`。

**這條「單位元」觀點在 9 節線段樹式合併、11 節優化 DP 都會再出現**：**任何「彙總子問題」的地方，空集合的值就是單位元。**

### 定理 4（62 不同路徑：什麼時候根本不需要 DP）

*命題*：無障礙的 $m \times n$ 網格，只能右／下，路徑數為

$$\binom{m+n-2}{\,m-1\,}.$$

*證明（雙射）*。一條路徑恰由 $m-1$ 次「下」與 $n-1$ 次「右」組成，總步數 $m+n-2$。

- **(路徑 $\to$ 序列)** 把路徑的移動依序記成一個由 `D`、`R` 組成的字串，長度 $m+n-2$、恰含 $m-1$ 個 `D` ✔。
- **(序列 $\to$ 路徑)** 任一這樣的字串，從 $(0,0)$ 依序執行，**永遠不會越界**（`D` 恰好用 $m-1$ 次 ⇒ 行下標最多到 $m-1$；`R` 同理）✔，得到一條合法路徑。
- 兩個映射互為反函數 ⇒ 雙射 ✔。

故路徑數 $=$ 這種字串的個數 $= \binom{m+n-2}{m-1}$。$\square$

**為什麼要講這個**：**它劃出了 DP 的適用邊界。** 有封閉解時，$O(m+n)$ 就能算完（且 $m, n$ 可以極大）；**但只要加上一個障礙，這個雙射就壞了**（有些字串對應的路徑會撞到障礙），**封閉解不復存在，只能 DP 或容斥。**

**通用判準**：**看到「無限制的格路計數」先想組合數；看到任何形式的障礙或代價，回到 DP。**

**實作提醒**：$\binom{m+n-2}{m-1}$ 在 $m = n = 100$ 時遠遠超過 `long long`。**62 保證答案在 $2^{31}$ 內，但直接算階乘會中途溢位** ⇒ 要用「邊乘邊除」的遞推 $\binom{k}{i} = \binom{k}{i-1}\cdot\frac{k-i+1}{i}$（每步整除必然成立）✔，或乾脆用 DP。

### 定理 5（1289 下降路徑最小和 II：最小值 + 次小值）

*問題*：$n \times n$ 網格，每一行選一個數，**相鄰兩行不能選同一列**，求最小總和。

*樸素轉移*：$f[i][j] = \mathit{grid}[i][j] + \min_{j' \ne j} f[i-1][j']$，複雜度 $O(n^3)$（$n$ 行 $\times$ $n$ 列 $\times$ $n$ 次比較）。

*命題*：設上一行的最小值為 $f[i-1][p]$（位置 $p$）、**次小值**為 $s$（允許與最小值相等，只要位置不同），則

$$\min_{j' \ne j} f[i-1][j'] = \begin{cases} s & j = p,\\ f[i-1][p] & j \ne p.\end{cases}$$

*證明*。$j \ne p$ 時，$p$ 本身就在可選範圍內，而它是全域最小 ⇒ 即為所求 ✔。$j = p$ 時，可選範圍是「去掉位置 $p$」的集合，其最小值依定義就是次小值 $s$ ✔。$\square$

**於是複雜度降到 $O(n^2)$。**

**這個「最小值 + 次小值」技巧的一般形式**：

> **要對「排除某一個元素後的集合」反覆取最小值，只需要維護（最小值, 其位置, 次小值）三元組。**

**點名前提**：**只排除一個元素。** 若題目改成「相鄰兩行不能選相鄰的列」（排除 3 個位置），三元組就不夠 ⇒ 要改成前後綴最小值陣列，或用滑動窗口最小值（11.3）✔。

**次小值的定義要小心**：**是「去掉最小值所在的那一個位置之後的最小值」，不是「嚴格大於最小值的最小值」。** 若有兩個相等的最小值，次小值應等於最小值 ✔——**寫成「嚴格大於」會 WA。**

### 定理 6（推廣：從網格到一般 DAG）

*命題*：定理 1 完全不依賴「網格」這個結構。**任何無環的狀態轉移都可以 DP，網格只是拓撲序特別好寫的一個特例。**

**三種常見的「非標準網格」與它們的拓撲序**：

| 情境 | 依賴 | 拓撲序 |
| --- | --- | --- |
| 只能右／下 | $(i-1,j), (i,j-1)$ | 行優先遞增（或按 $i+j$ 遞增） |
| **只能下／左下／右下**（931、120） | 上一列的三格 | **按行遞增**（列的順序無所謂） |
| **多層／多狀態**（1824 最少側跳） | 同層前一格 + 異層同一格 | **按列遞增，列內把同格的層間轉移做到收斂** |
| **四方向 + 嚴格遞增**（329） | 值更小的鄰格 | **按格子的值遞增**（或記憶化搜尋） |

**1824 這類「同一列內層與層之間也能轉移」的題目要特別小心**：**同一列內的層間轉移構成了列內的依賴，不能只掃一遍。** 標準做法是**先算完「不側跳」的轉移，再在列內做一次（或兩次）鬆弛把側跳的代價傳開** ✔——**本質是在一個小圈上跑最短路。**

**當列內依賴形成環時，DP 就失效了，要改用 Dijkstra**（把網格當圖、格子當節點）。**判準：轉移代價非負且依賴有環 ⇒ Dijkstra；依賴無環 ⇒ DP。** 2304 網格中的最小路徑代價若改成「可以往任意方向移動」就屬於前者。

## 時間與空間複雜度

| 題目 | 時間 | 空間 | 備註 |
| --- | --- | --- | --- |
| 62 不同路徑 | $O(mn)$ 或 $O(m+n)$ | $O(n)$ 或 $O(1)$ | 有組合數封閉解（定理 4） |
| 63 不同路徑 II | $O(mn)$ | $O(n)$ | 障礙破壞封閉解 |
| 64 最小路徑和 | $O(mn)$ | $O(n)$ | `INF` 單位元 |
| 120 三角形 | $O(n^2)$ | $O(n)$ | 倒推可原地做 |
| 931 下降路徑最小和 | $O(n^2)$ | $O(n)$ | 三前驅 |
| 1289 下降路徑 II（定理 5） | $O(n^2)$ | $O(n)$ | 樸素是 $O(n^3)$ |
| 1824 最少側跳 | $O(n \cdot k)$ | $O(k)$ | $k$ = 層數（此題為 3） |

**空間壓縮的通則**：$f[i][\cdot]$ 只依賴 $f[i-1][\cdot]$ ⇒ **只需兩行，甚至一行就地更新**（定理 2）✔。$O(mn) \to O(n)$。

**壓縮的代價**：**壓完就無法回溯路徑。** 若題目要輸出具體路徑（見 16 節），必須保留完整表格，或另存 $O(mn)$ 的決策陣列。**先確認題目要不要方案，再決定壓不壓。**

**什麼時候 $O(mn)$ 也不夠**：$m, n \le 10^3$ 時 $10^6$ ✔ 沒問題；$m,n \le 10^5$ 時 $10^{10}$ ✘——**那種題目一定有特殊結構**（例如無障礙 ⇒ 組合數，或障礙數量很少 ⇒ 只對障礙做容斥）。

## 與相似技巧的比較

- **與 1 節線性 DP**：**唯一的新東西是「填表順序需要論證」**（定理 1）。狀態定義、不重不漏、剪貼論證全部照搬。
- **與記憶化搜尋**：**遞推需要你自己找出拓撲序，記憶化讓遞迴替你找。** 網格只能右／下時遞推更快（無函式呼叫開銷）；**方向自由時（329）遞推幾乎寫不出來，記憶化是唯一實際選擇** ✔。
- **與最短路（graph 章）**：網格 DP $\equiv$ **DAG 上的最短路**。**依賴有環（可以往回走）時 DP 失效，必須換 Dijkstra／BFS**——這是 2.2 與本節的分界線之一。**代價全為 1 時用 BFS，非負時用 Dijkstra，可為負且無環時仍可 DP。**
- **與組合數學**：定理 4 顯示無障礙格路有封閉解。**「有沒有障礙／代價」是選 DP 還是選公式的判準。** 障礙很少時還有第三條路——**對障礙做容斥**（枚舉「第一個碰到的障礙」），複雜度 $O(k^2)$ 與網格大小無關。
- **與 3 節背包**：定理 2（就地更新的方向）在背包章直接兌現。**背包的「倒序防止重複使用」與網格的「正序讀到本行」是同一條規則的兩面。**
- **與 2.2 進階**：2.2 的三個新挑戰是——**倒推**（174 地下城，需求由未來決定）、**方向自由**（329，靠嚴格遞增保證無環）、**多主體**（741／1463，狀態要加維度）。**三者都是本節定理 1 的直接後果：拓撲序不好找時，換一種找法。**

## 本節重點速查

- **定理 1（總綱）**：**填表順序 = 依賴圖的拓撲序。** DP 可行 $\iff$ 依賴圖無環。網格「只能右／下」⇒ $i+j$ 嚴格遞增 ⇒ 雙層遞增迴圈合法（行優先、列優先都行）。**不確定迴圈方向時，畫依賴箭頭。**
- **定理 2（就地更新）**：正序 `f[j] += f[j-1]` 時，$f[j]$ 是**上一行**的舊值、$f[j-1]$ 是**這一行**的新值。**判準：要讀本輪的值就順著寫入方向掃，要讀上一輪的值就逆著掃。** ← **這一句就是 0-1 背包倒序、完全背包正序的全部原因。**
- **定理 3（單位元）**：不可達格填**合併運算的單位元**——`+` 用 0、`min` 用 `INF`、`max` 用 `-INF`。**`INF` 用 `0x3f3f3f3f` 避免相加溢位。** 63 的第一行第一列遇障礙後要全 0，不能無腦填 1。
- **定理 4（62 封閉解）**：無障礙格路數 $=\binom{m+n-2}{m-1}$，用「路徑 $\leftrightarrow$ `D`/`R` 字串」的雙射證明。**有障礙就沒有封閉解。** 算組合數要邊乘邊除防溢位。
- **定理 5（1289）**：**維護（最小值, 位置, 次小值）**即可 $O(1)$ 取得「排除一列後的最小值」，$O(n^3) \to O(n^2)$。**前提：只排除一個元素**（排除多個 ⇒ 前後綴最小值或單調佇列）。**次小值是「去掉那個位置後的最小值」，相等時仍算次小值。**
- **定理 6（推廣）**：網格只是拓撲序好寫的特例。**列內有層間轉移（1824）要在列內鬆弛到收斂；依賴成環就改用 Dijkstra。**
- **空間**：$O(mn) \to O(n)$ 幾乎免費，**但壓完就不能回溯路徑**——要輸出方案先別壓。
