## 這個技術解決什麼問題

2.1 建立的規則是「填表順序 = 拓撲序」。本節處理**這條規則不好用的四種情況**，每一種都對應一個真正的技術：

| 症狀 | 技術 | 代表題 |
| --- | --- | --- |
| **順推的狀態不完備**（需要兩個目標同時最優） | **倒推**，把狀態改成「從 $(i,j)$ 出發還需要多少」 | 174 地下城遊戲 |
| **方向自由，下標不單調** | 找**另一個**單調量當拓撲序（值、時間） | 329 最長遞增路徑 |
| **兩個以上移動體要協調** | **用「步數」把它們同步**，狀態加維度 | 741／1463 摘櫻桃 |
| **答案不只一個標量**（最優值 + 方案數、餘數、括號深度） | 狀態**加一維**或**值變成元組** | 1301／2435／2267 |

**這四件事沒有一件是「更難的網格 DP」，它們全都是同一個問題的變形：狀態不完備時該怎麼補。** 本節把補的方法講清楚，後面 9／10 節（狀壓、數位）補的維度只是更花俏而已。

**辨識訊號**：
- **答案取決於「後面」而非「前面」，需要倒著推**（地下城遊戲：現在的需求由未來決定）；
- **可往多個方向移動、難以排出填表順序**（329 上下左右都能走，靠「嚴格遞增」保證無環）；
- **同時有兩個（或多個）移動體要協調**（741／1463 兩條路徑一起走；1301 同時記路徑數與最佳值）。

## 狀態／資料結構定義

**骨架 A：倒推（174）**

```cpp
// f[i][j] = 從 (i,j) 出發、活著走到終點所需的「最小初始血量」（至少 1）
vector f(m + 1, vector<int>(n + 1, INT_MAX));
f[m][n - 1] = f[m - 1][n] = 1;  // 走出終點後只需 1 點血
for (int i = m - 1; i >= 0; i--)
    for (int j = n - 1; j >= 0; j--)
        f[i][j] = max(1, min(f[i + 1][j], f[i][j + 1]) - dungeon[i][j]);
```

**骨架 B：記憶化搜尋（329，方向自由）**

```cpp
int dfs(int i, int j) {
    int& res = memo[i][j];
    if (res) return res;  // 0 代表未算（合法答案 >= 1）
    res = 1;
    for (auto [di, dj] : DIRS) {
        int x = i + di, y = j + dj;
        if (x < 0 || x >= m || y < 0 || y >= n) continue;
        if (grid[x][y] <= grid[i][j]) continue;  // 嚴格遞增：定理 2 的關鍵前提
        res = max(res, dfs(x, y) + 1);
    }
    return res;
}
```

**骨架 C：兩個移動體用步數同步（741）**

```cpp
// t = 步數；第一個人在 (i1, t - i1)、第二個人在 (i2, t - i2)
// 只需兩個「行下標」，列下標由 t 推出來 —— 這是定理 3 的直接後果
vector f(n, vector<int>(n, -1));  // f[i1][i2]，-1 = 不可達
```

**骨架 D：值是元組（1301，最優值 + 方案數）**

```cpp
struct Node {

```

## 不變量或正確性證明

### 定理 1（174 地下城遊戲：順推的狀態為什麼不完備）

*問題*：騎士從左上走到右下（只能右／下），每格加減血量，全程血量必須 $\ge 1$。求最小初始血量。

**命題（順推失敗）**：狀態「走到 $(i,j)$ 時的最大剩餘血量」**不完備**；狀態「走到 $(i,j)$ 所需的最小初始血量」**也不完備**。

*證明（構造反例）*。考慮兩條走到同一格 $(i,j)$ 的路徑：

| 路徑 | 所需初始血量 | 到達時的剩餘血量 |
| --- | --- | --- |
| $A$ | $1$ | $5$ |
| $B$ | $3$ | $10$ |

- **若後續是一連串大量扣血**（例如接下來要一口氣掉 8 點），$B$ 更好（剩餘 10 撐得住，剩餘 5 撐不住）；
- **若後續平坦**（不再扣血），$A$ 更好（初始只要 1）。

**所以「同一個格子」的兩條路徑，優劣取決於後續——單一標量無法排序，無後效性失敗** ✘。$\square$

**根本原因**：順推時有**兩個目標**（初始血量要小、剩餘血量要大），它們構成一個二維的 Pareto 前沿，**沒有一個標量能代表它**。

**倒推為什麼有效**：定義

$$f(i,j) = \text{「從 }(i,j)\text{ 出發、走到終點且全程血量} \ge 1\text{，進入 }(i,j)\text{ 前所需的最小血量」},$$

**這只有一個目標** ⇒ 標量足夠 ✔。轉移為

$$f(i,j) = \max\Big(1,\; \min\big(f(i+1,j),\, f(i,j+1)\big) - \mathit{dungeon}[i][j]\Big).$$

*轉移的正確性*。進入 $(i,j)$ 後血量變成 $h + \mathit{dungeon}[i][j]$，要能繼續走下去需 $h + \mathit{dungeon}[i][j] \ge \min(f(i+1,j), f(i,j+1))$；同時**在 $(i,j)$ 這一格本身也必須存活**，即 $h + \mathit{dungeon}[i][j] \ge 1$。兩個條件取較嚴者，並解出最小的 $h$ ⇒ 上式 ✔。$\square$

**外層的 `max(1, ...)` 是本題最常漏的一項**——它保證了「這一格本身不會被打死」，**在遇到大血包（$\mathit{dungeon}$ 很正）時尤其關鍵，否則會算出 $\le 0$ 的血量。**

**這條定理的一般教訓**：

> **當「最優」需要同時滿足兩個彼此拉扯的目標時，先問：換個方向推，是不是就只剩一個目標了？**

**判準（與 1.2 定理 4 的判準是同一條）**：**約束向後傳（現在的決定限制未來）⇒ 倒推。** 174 的血量下限就是典型的向後傳約束。

### 定理 2（329 最長遞增路徑：嚴格遞增提供了拓撲序）

*命題*：把每個格子當節點、從 $(i,j)$ 向**值嚴格更大**的鄰格連邊，所得的圖是 DAG。

*證明*。沿任一條邊，格子的值嚴格遞增 ⇒ 沿任一條路徑值嚴格遞增 ⇒ **不可能回到起點**（否則起點的值嚴格大於自己）✔。$\square$

**由定理 1 of 2.1，DAG ⇒ 記憶化搜尋合法，且每個狀態只算一次** ⇒ $O(mn)$ ✔。

**要點名的前提：「嚴格」。** 若題目改成「非遞減路徑」，兩個相等的鄰格之間會有雙向邊 ⇒ **有環 ⇒ DP 立刻失效** ✘。**此時要先把相等的連通塊縮成一個點（並查集或 BFS 染色），在縮點後的 DAG 上再做 DP** ✔。**這是一個很值得記住的補救手法。**

**等價的遞推寫法**：把所有格子按值排序後由小到大處理，或用「拓撲排序剝離入度為 0 的層」。**兩者都 $O(mn\log(mn))$ 或 $O(mn)$，但都比記憶化難寫。** 本題記憶化是明顯的首選——**這正是 2.1 推論 1.2 說的「拓撲序不好寫時讓遞迴自己找」。**

**記憶化的哨兵值**：本題答案 $\ge 1$，所以 `memo` 用 0 表示「未計算」很安全 ✔。**若答案可能是 0，必須另外用 $-1$ 或獨立的 `visited` 陣列**——**用錯哨兵會讓記憶化退化成沒有記憶（重複計算）甚至無限遞迴。**

### 定理 3（741 摘櫻桃：一來一回 $\equiv$ 兩條同向路徑，且「同格必同時」）

*問題*：從 $(0,0)$ 走到 $(n-1,n-1)$（只能右／下）再走回 $(0,0)$（只能左／上），撿到的櫻桃只算一次，求最多櫻桃數。

**(a) 一來一回 $\equiv$ 兩條從 $(0,0)$ 到 $(n-1,n-1)$ 的同向路徑。**
*證明*。把回程反轉：回程是從 $(n-1,n-1)$ 只能左／上走到 $(0,0)$；反轉後就是從 $(0,0)$ 只能右／下走到 $(n-1,n-1)$ ✔。反轉是一個雙射，且經過的格子集合不變 ⇒ 目標函數不變 ✔。$\square$

**(b)（關鍵）兩條路徑若經過同一格，必定在同一步數。**
*證明*。只能右／下移動 ⇒ 走了 $t$ 步之後恰好位於滿足 $i + j = t$ 的格子上 ✔。故格子 $(i,j)$ **只可能在第 $i+j$ 步被經過**——與走法無關 ✔。$\square$

**(b) 是整個解法能成立的支點。** 有了它，「同一格只算一次」的判斷變成**只需比較兩人當前是否在同一格**：

$$f(t, i_1, i_2) = \max_{\text{四種上一步組合}} f(t-1, \cdot, \cdot) \;+\; \mathit{grid}[i_1][t-i_1] \;+\; \big(i_1 \ne i_2\big)\cdot \mathit{grid}[i_2][t-i_2].$$

**如果沒有 (b)，就得記錄「已經撿過哪些格子」——狀態爆炸成 $2^{n^2}$，題目直接不可解。**

**維度的節省**：由 $j = t - i$，列下標不必存 ⇒ 狀態從 $(i_1,j_1,i_2,j_2)$ 的 $O(n^4)$ 降到 $(t, i_1, i_2)$ 的 $O(n^3)$ ✔，再滾動掉 $t$ ⇒ 空間 $O(n^2)$。

**邊界**：$j = t - i$ 必須落在 $[0, n-1]$ ⇒ $i \in [\max(0, t-n+1), \min(t, n-1)]$ ✔。**不夾這個範圍會讀到界外。** 障礙格（$-1$）要標成不可達（用 `-INF`，不是 0 ✘ ——見 2.1 定理 3）。

**不用擔心「兩條路徑必須真的不相交」**：題目允許相交，而 (b) 保證相交時我們只算一次 ✔。**反過來，若題目要求兩條路徑不得相交，就要在轉移時排除 $i_1 = i_2$——那是另一道題。**

### 定理 4（1463 摘櫻桃 II：行天然同步）

*問題*：兩個機器人從第一行的兩端出發，**每步都往下移動一行**（列可以 $-1/0/+1$），撿櫻桃，同格只算一次。求最多。

*命題*：狀態 $f(i, j_1, j_2)$ 就夠，**不需要額外的「步數」維度**。

*證明*。兩個機器人**每步都恰好下降一行** ⇒ 任何時刻它們必在同一行 ✔——**同步是題目直接保證的，不需要像 741 那樣自己構造。** $\square$

**於是相交判斷同樣退化成 $j_1 = j_2$** ✔，轉移枚舉 $3 \times 3 = 9$ 種列移動組合。

**741 與 1463 的對照值得記下來**：

| | 741 | 1463 |
| --- | --- | --- |
| 同步機制 | **自己構造**（$t = i+j$，定理 3(b)） | **題目自帶**（每步下降一行） |
| 狀態 | $(t, i_1, i_2)$ | $(i, j_1, j_2)$ |
| 為什麼能同步 | 只能右／下 ⇒ 步數決定 $i+j$ | 移動規則強制同行 |

**通用手法**：**多主體問題的第一步永遠是「找一個所有主體共享的單調量」**（步數、行號、時間），**用它當外層維度，其餘維度描述各主體的位置。** 找不到這樣的量（例如兩人移動速度不同），就得引入時間軸並允許「原地等待」✔。

### 定理 5（加一維：餘數、深度、剩餘次數）

**當「後續是否合法／最優」取決於某個累積量時，那個累積量必須進入狀態。** 三個代表：

**(a) 2435 路徑和能被 $k$ 整除的路徑數**：狀態 $f(i,j,r)$，$r$ 為當前路徑和模 $k$。
*為什麼需要*。兩條走到 $(i,j)$ 的路徑，其和模 $k$ 不同時，後續能否湊成 $0$ 也不同 ⇒ 無後效性失敗 ✘ ⇒ 加維度 ✔。
*為什麼模 $k$ 就夠（而不需要記錄真實和）*。**後續只用到「和 $\bmod k$」這一件事，而模運算與加法相容：$(a+b)\bmod k$ 只取決於 $a \bmod k$** ✔。**這是「加維度時要壓到最小」的示範**——記錄真實和會讓狀態數變成 $O(mn \cdot \text{和的範圍})$，記錄餘數只要 $O(mnk)$。

**(b) 2267 檢查是否有合法括號路徑**：狀態 $f(i,j,d)$，$d$ 為「未匹配的左括號數」。
*為什麼是 $d$ 而不是整個括號串*。**合法性只取決於「當前未匹配左括號數」與「它從未變成負數」** ✔——這是括號序列的標準刻畫。
*兩個剪枝*：$d > (m-1-i) + (n-1-j) + 1$ 時剩下的步數不夠關掉 ⇒ 剪 ✔；**路徑總長 $m+n-1$ 為奇數時直接無解**（合法括號串長度必為偶數）✔。

**(c) 剩餘次數型**（可以打破 $k$ 面牆、可以傳送 $k$ 次）：狀態加一維 $k$，**注意 $k$ 要夾在 $[0, K]$ 內**，且**「不使用」的分支不要漏掉**。

**共通的檢查流程**（1.1 定理 4 的機械化版本）：

> 1. 構造兩條到達同一格的路徑；
> 2. 找出它們後續行為不同的原因；
> 3. **把那個「原因」壓成最小的形式**（真實和 ⇒ 餘數；括號串 ⇒ 深度），加進狀態。

**第 3 步是關鍵，也是最常被忽略的一步**——不壓縮就會 MLE。

### 定理 6（1301：同時維護最優值與方案數的合併規則）

*命題*：設狀態值為二元組 $(v, c)$（最優值、達到該最優值的方案數）。從多個前驅 $(v_1,c_1),\dots,(v_k,c_k)$ 合併時，正確的規則是

$$v = \max_t v_t, \qquad c = \sum_{t\,:\,v_t = v} c_t.$$

*證明*。把「達到最優值 $v$ 的方案」按「最後一步從哪個前驅來」劃分——**不漏**（每個方案有唯一的最後一步）、**不重**（前驅不同則方案不同）✔。而**只有 $v_t = v$ 的前驅才可能延伸出總值為 $v$ 的方案**（$v_t < v$ 的前驅延伸出來的總值嚴格更小）✔。故方案數是那些 $c_t$ 之和。$\square$

**實作上必須寫成三分支，不能只寫 `best = max(best, v)`**：

```cpp
void merge(Node& acc, const Node& x) {
    if (x.best > acc.best)
        acc = x;  // 更優：整組取代
    else if (x.best == acc.best)
        acc.cnt = (acc.cnt + x.cnt) % MOD;  // 相等：方案數相加
    // 更差：忽略
}
```

**三個常見錯誤**：
- **只更新 `best` 忘了 `cnt`** ⇒ 方案數全錯；
- **`best` 相等時用 `max` 而不是 `+` 更新 `cnt`** ⇒ 嚴重少算；
- **不可達狀態的初值寫成 `{0, 1}`** ✘ ——應為 `{-INF, 0}`，否則不可達的路徑會被算成一種方案（**又是 2.1 定理 3 的單位元問題：$\max$-$+$ 半環的單位元是 $(-\infty, 0)$**）。

**這個 $(\max, +)$ 與 $(+)$ 疊在一起的結構是一個半環**，同樣的合併規則會在 12 節樹形 DP、graph 章的「最短路計數」原封不動出現。**寫成一個 `merge` 函式，一次寫對，處處可用。**

**推論 6.1（1594 路徑最大乘積）**：值是「乘積」時，**要同時維護 max 與 min**（理由與 1.3 定理 4 完全相同：乘負數翻轉序關係）✔。**元組從 $(v,c)$ 變成 $(v_{\max}, v_{\min})$，但合併時仍要注意單位元。**

**規模感**：741 的 $n \le 50$ ⇒ $n^3 = 1.25\times10^5$ ✔ 綽綽有餘；**若 $n$ 到 $500$ 就是 $1.25\times10^8$，需要壓常數。** 1463 的 $\mathit{cols} \le 70$ ⇒ $mn^2 \times 9 \approx 4\times10^6$ ✔。

**記憶化的空間不能滾動**（329）：遞迴的訪問順序無法預測，**整張表都要留著** ⇒ $O(mn)$ 是硬下限。

**遞迴深度**：329 最壞情況（整個網格構成一條遞增鏈）遞迴深度達 $mn$。$m = n = 200$ ⇒ 深度 $4\times10^4$，**在預設堆疊上通常還撐得住，但要有意識**。**若題目規模再大一級，必須改成拓撲排序的迭代版本。**

## 與相似技巧的比較

- **與 2.1 基礎**：**唯一的新東西是「拓撲序不好找時怎麼辦」。** 三條出路——倒推（換方向）、記憶化（讓遞迴找）、換一個單調量（值、步數）。
- **與最短路（graph 章）**：**移動可以往回走且代價非負 ⇒ Dijkstra；無環 ⇒ DP。** 329 之所以能用 DP，全靠「嚴格遞增」提供的無環性（定理 2）——**這個前提一鬆，就得換演算法。**
- **與 6 節狀態機 DP**：定理 5 加的那些維度（餘數、深度、剩餘次數）**就是狀態機的狀態**。**網格 DP 加一維 $\equiv$ 在每個格子上放一台小狀態機。**
- **與 9 節狀壓 DP**：定理 3(b) 的價值正是**避免了狀壓**。**若「同格只算一次」無法用「同時刻」判斷，就得記錄已訪問集合 ⇒ $2^{n^2}$ ⇒ 不可解。** 遇到「不能重複計算」的題目，**先找有沒有像 $t = i+j$ 這樣的結構性巧合。**
- **與 12 節樹形 DP**：定理 6 的 $(\max, +)$ 合併規則在樹形 DP 合併子樹時一字不改地使用。**先在這裡寫對一個 `merge`，之後都能重用。**
- **與 16 節輸出方案**：本節所有滾動壓縮都會摧毀回溯能力。**要輸出具體路徑就保留完整表格，或另存決策陣列。**

## 本節重點速查

- **定理 1（174 倒推）**：順推的狀態不完備——**「初始血量小」與「剩餘血量大」是兩個互相拉扯的目標，標量排不了序**（反例：$(1,5)$ vs $(3,10)$）。倒推只剩一個目標 ⇒ 標量足夠。**轉移外層的 `max(1, ...)` 保證這一格本身不會被打死，最常漏。** 判準：**約束向後傳 ⇒ 倒推。**
- **定理 2（329 嚴格遞增）**：嚴格遞增 ⇒ 沿路徑值嚴格單調 ⇒ **無環 ⇒ 記憶化合法**，$O(mn)$。**前提是「嚴格」**：改成非遞減就有環，得先把相等的連通塊縮點。**memo 的哨兵值要選一個合法答案取不到的數。**
- **定理 3（741）**：(a) 回程反轉 ⇒ 兩條同向路徑；**(b) 只能右／下 ⇒ 格子 $(i,j)$ 只可能在第 $i+j$ 步被經過 ⇒ 「同格」等價於「同時刻同格」**。**(b) 是支點——沒有它就得記錄已訪問集合，狀態爆炸成 $2^{n^2}$。** 列下標由 $j = t-i$ 推出，記得夾範圍。
- **定理 4（1463）**：**同步是題目自帶的**（每步下降一行）⇒ 狀態 $(i,j_1,j_2)$。**通用手法：多主體問題先找一個所有主體共享的單調量當外層維度。**
- **定理 5（加一維）**：餘數（2435）、括號深度（2267）、剩餘次數。**三步流程：構造兩條路徑 → 找出後續不同的原因 → 把原因壓到最小形式再加進狀態。** 第三步不做就 MLE。2267 記得奇偶剪枝與「剩餘步數夠不夠關括號」。
- **定理 6（最優值 + 方案數）**：合併要寫**三分支**——更優則整組取代、相等則 `cnt` 相加、更差則忽略。**不可達的單位元是 $(-\infty, 0)$ 不是 $(0,1)$。** 這是 $(\max,+)$ 半環，樹形 DP 與最短路計數共用。**乘積型（1594）則同時維護 max 與 min（同 1.3 定理 4）。**
