## 這個技術解決什麼問題

完全背包與 0-1 背包只差一個字：**每個物品可以用無限次**。

$$\text{0-1：每種至多 1 個} \qquad\longrightarrow\qquad \text{完全：每種任意多個}$$

**但這個差別在程式碼上只體現為「內層迴圈由倒序改成正序」**——一個字元的差距。**本節要說清楚的，正是那一個字元背後的兩層論證**：

1. **為什麼「用了幾個」的 $O(C/w)$ 枚舉可以壓成 $O(1)$ 的二分**（定理 1）——這是模型層面的化簡；
2. **為什麼正序就地更新恰好實現了那個化簡**（定理 2）——這是實作層面的對應。

**兩層都懂，你才算真的會了背包**；只記住「完全背包正序」，遇到多重背包（3.3）或「恰好用 $k$ 個」的變形就會卡住。

**辨識訊號**：
- 物品／面額／數字可以**重複使用無限次**，在容量或目標下求最佳或計數；
- 像 0-1 背包，但少了「每個只能拿一次」的限制；
- **計數題要分清「組合」還是「排列」**（518 數的是組合、377 數的是排列）——定理 3。

## 狀態／資料結構定義

```cpp
// 二維：注意第二項是 f[i][...] 而不是 f[i-1][...]  —— 定理 1
vector f(n + 1, vector<int>(C + 1, 0));
for (int i = 1; i <= n; i++)
    for (int c = 0; c <= C; c++) {
        f[i][c] = f[i - 1][c];  // 一個都不用
        if (c >= w[i - 1])
            f[i][c] = max(f[i][c], f[i][c - w[i - 1]] + v[i - 1]);
    }

// 一維：容量正序 —— 定理 2
vector<int> g(C + 1, 0);
for (int i = 0; i < n; i++)
    for (int c = w[i]; c <= C; c++)  // 正序！
        g[c] = max(g[c], g[c - w[i]] + v[i]);
```

**與 3.1 對照，只有兩處不同**：

| | 0-1 背包 | 完全背包 |
| --- | --- | --- |
| 二維轉移的第二項 | $f(\mathbf{i-1},\, c-w_i) + v_i$ | $f(\mathbf{i},\, c-w_i) + v_i$ |
| 一維內層迴圈 | `for (c = C; c >= w; c--)` | `for (c = w; c <= C; c++)` |

**初值規則與 3.1 定理 3 完全相同**（至多 ⇒ 全 0；恰好 ⇒ `g[0]=0` 其餘 `±INF`；計數 ⇒ `g[0]=1` 其餘 0）。

**計數型的迴圈順序決定答案的語意（定理 3）**：

```cpp
// 518 零錢兌換 II：數「組合」（不計順序）—— 外層物品、內層容量
for (int coin : coins)
    for (int c = coin; c <= amount; c++) f[c] += f[c - coin];

// 377 組合總和 IV：數「排列」（計順序）—— 外層容量、內層物品
for (int c = 1; c <= target; c++)
    for (int x : nums)
        if (x <= c) f[c] += f[c - x];
```

**這兩段只差迴圈嵌套順序，算的卻是完全不同的東西。**

## 不變量或正確性證明

### 定理 1（把 $O(C/w)$ 的枚舉壓成 $O(1)$）

**樸素轉移**：按「物品 $i$ 用了 $k$ 個」劃分（不漏、不重 ✔），

$$f(i, c) = \max_{0 \le k \le \lfloor c/w_i \rfloor} \big( f(i-1,\; c - k w_i) + k v_i \big),$$

複雜度 $O(nC \cdot \frac{C}{w})$——**在 $w$ 小、$C$ 大時非常慢。**

*命題*：上式等價於

$$f(i, c) = \max\big(\, \underbrace{f(i-1, c)}_{k = 0},\;\; \underbrace{f(i,\; c - w_i) + v_i}_{k \ge 1} \,\big).$$

*證明*。改用**二分劃分**：「一個都不用」與「至少用一個」——不漏、不重 ✔。

- **($k = 0$)** 即 $f(i-1, c)$ ✔。
- **($k \ge 1$)** 從最優解中拿掉**一個**物品 $i$，剩下的仍是「容量 $\le c - w_i$、允許使用物品 $1..i$（**含 $i$**，因為還可以再用）」的合法方案 ⇒ 其值 $\le f(i, c - w_i)$ ⇒ 原值 $\le f(i, c-w_i) + v_i$ ✔。
- **(反向)** $f(i, c-w_i)$ 對應的方案再加一個物品 $i$，總重 $\le c$、仍只用物品 $1..i$ ⇒ 合法 ⇒ $f(i,c) \ge f(i,c-w_i)+v_i$ ✔。$\square$

**這一步是完全背包的全部技術含量。** 對照 0-1 背包（3.1 定理 1）：那裡「選了物品 $i$」之後**不能再選它**，所以只能退回 $f(i-1, \cdot)$；**這裡因為可以再選，所以停在 $f(i, \cdot)$——遞推在同一層內部自我引用。**

**要點名的前提**：$w_i > 0$（**嚴格大於 0**）。若某個物品 $w_i = 0$ 而 $v_i > 0$，「用無限個」會讓答案無界 ⇒ $f(i,c) = f(i,c) + v_i$ 自我引用成環 ✘。**同層自我引用之所以合法，全靠 $c - w_i < c$ 這個嚴格遞減。**

**這條前提在 3.1 是「$w_i \ge 0$ 即可」，在這裡收緊成「$w_i > 0$」——一個容易漏掉的差別。**

### 定理 2（正序就地更新恰好實現了定理 1）

*命題*：一維陣列 `for (c = w; c <= C; c++) g[c] = max(g[c], g[c-w] + v);` 正確實現了完全背包。

*證明*。由定理 1，計算 $f(i,c)$ 時右側需要的是 $f(i, c - w_i)$——**「本輪」的值**。

由 2.1 定理 2 的判準——**要讀本輪的值，就順著寫入方向掃**——而 $c - w_i < c$ 位於左側，**正序時左側已經被本輪寫過** ⇒ 讀到的正是 $f(i, c-w_i)$ ✔。$\square$

**於是 3.1 定理 2 的反例，在這裡變成了正確行為**。重跑那個例子（$w=2, v=3, C=4$，物品可無限用）：

| $c$ | 讀 `g[c-2]` | 寫入 `g[c]` |
| --- | --- | --- |
| 2 | `g[0] = 0` | $3$（用 1 個） |
| 4 | `g[2] = 3`（本輪值） | $6$（用 2 個）✔ |

**同一段程式碼、同一個反例，在 0-1 背包裡是 bug，在完全背包裡是 feature。** 這正說明了為什麼要理解而不是背誦。

**推論 2.1（整章的迴圈方向表）**：

| 每種物品的可用次數 | 轉移讀的是 | 一維迴圈方向 |
| --- | --- | --- |
| 至多 1 次（3.1） | 上一輪 $f(i-1,\cdot)$ | **倒序** |
| 無限次（3.2） | 本輪 $f(i,\cdot)$ | **正序** |
| 至多 $k_i$ 次（3.3） | 都不是（需要枚舉或拆分） | **見 3.3** |

### 定理 3（518 組合 vs 377 排列：迴圈順序決定語意）

*命題*（1.1 定理 2 的完全背包版本）：

$$\texttt{for 物品: for 容量:} \;\Longrightarrow\; \text{組合數（多重集合）},$$
$$\texttt{for 容量: for 物品:} \;\Longrightarrow\; \text{排列數（序列）}.$$

*證明*。兩者用的是不同的劃分依據。

- **(外物品內容量)** 定義 $f_i(c)$ 為「只用前 $i$ 種物品湊出 $c$」的方案數，劃分依據是「**第 $i$ 種用了幾個**」。用量是一個非負整數，**不含順序資訊** ⇒ 數出來的是「每種各用幾個」這個多重集合 ⇒ 組合 ✔。由定理 1，這個劃分被壓成了「$0$ 個 / $\ge 1$ 個」的二分，但語意不變。
- **(外容量內物品)** 劃分依據是「**最後一個加入的元素是哪一種**」。「最後一個是誰」是有序資訊 ⇒ 同一個多重集合會依不同的排出順序被數多次 ⇒ 排列 ✔。$\square$

**具體感受一下**：`coins = [1,2]`, `amount = 3`。
- **組合**：$\{1,1,1\}$、$\{1,2\}$ ⇒ **2 種**（518 的答案）；
- **排列**：$1{+}1{+}1$、$1{+}2$、$2{+}1$ ⇒ **3 種**（377 的答案）。

**判準（背下這一句）**：

> **問「有幾種湊法」而題目說「$1+2$ 與 $2+1$ 算同一種」⇒ 組合 ⇒ 外物品內容量。
> 說「算不同種」⇒ 排列 ⇒ 外容量內物品。**

**最大／最小值型不受影響**：$\max$ 與 $\min$ 是冪等的（$\max(a,a)=a$），**重複計算同一個方案不改變結果** ⇒ 兩種順序都對 ✔。**只有計數型才必須小心**——這與 1.2 定理 2 的「覆蓋 vs 劃分」是同一個道理。

### 定理 4（322 零錢兌換：「恰好」型與貪心的失敗）

*問題*：面額 `coins` 可無限使用，求湊出 `amount` 的**最少硬幣數**（湊不出回傳 $-1$）。

**這是「恰好」型**（3.1 定理 3）⇒ 初值 $f[0] = 0$、其餘 $f[c] = \mathrm{INF}$，轉移 $f[c] = \min(f[c],\, f[c-\mathit{coin}] + 1)$，最後 `f[amount] >= INF ? -1 : f[amount]` ✔。

**`INF` 的選擇**：用 `INT_MAX` 時 `f[c-coin] + 1` 會溢位 ✘。**用 `amount + 1` 當 `INF` 最乾淨**——因為任何真實答案都 $\le$ `amount`（面額至少為 1），且 `amount + 1 + 1` 不會溢位 ✔。

*命題（貪心是錯的）*：「每次拿最大的、拿不動再換小的」不保證最優。

*反例*：`coins = [1, 3, 4]`, `amount = 6`。
- **貪心**：$4 + 1 + 1$ ⇒ **3 枚**；
- **最優**：$3 + 3$ ⇒ **2 枚** ✘。$\square$

**為什麼真實貨幣系統可以貪心**：美元、人民幣、歐元的面額都是**「正則的」（canonical）幣制**，它們滿足「貪心即最優」的性質。**這是幣制的特殊性質，不是普遍真理**——而且「判斷一個幣制是否正則」本身是一個不平凡的問題。**題目給任意面額 ⇒ 一律 DP。**

**這個反例值得記住**：它與 3.1 的分數背包反例（`w=[3,4,5], v=[3,5,6], C=8`）是同一類——**「局部最優 $\ne$ 全域最優」的最短證明。**

### 定理 5（279 完全平方數：DP 之外還有 $O(\sqrt n)$ 的數論解）

**DP 解**：完全背包，物品是 $1^2, 2^2, \dots, \lfloor\sqrt n\rfloor^2$，求恰好湊出 $n$ 的最少個數 ⇒ $O(n\sqrt n)$ ✔。

**但這題有封閉解。** 引用兩個經典定理：

- **Lagrange 四平方和定理**：**每個正整數都可以表示成至多 4 個平方數之和** ⇒ 答案 $\in \{1,2,3,4\}$ ✔。
- **Legendre 三平方和定理**：$n$ **不能**表示成 3 個平方數之和 $\iff n = 4^a(8b+7)$（$a, b$ 為非負整數）。

*由這兩條可得 $O(\sqrt n)$ 演算法*：
1. $n$ 是完全平方數 ⇒ 答案 1；
2. 否則，把 $n$ 反覆除以 4，若餘下的數模 8 等於 7 ⇒ 答案 4（由 Legendre）；
3. 否則枚舉 $i \le \sqrt n$，若 $n - i^2$ 是完全平方數 ⇒ 答案 2；
4. 否則答案 3 ✔。

**誠實的說明**：**這兩個定理本節不證明**（Lagrange 的證明用到 Minkowski 幾何或 Jacobi 恆等式，Legendre 的更深），我們是**引用**它們。**知道有這條路很有價值——它示範了「有些 DP 題其實有數論封閉解」——但在面試裡寫 DP 才是穩妥的選擇，因為你需要能證明自己寫的東西。**

**這也回應了 2.1 定理 4 的同一個主題**：**先問有沒有封閉解，再決定要不要 DP。**

### 定理 6（1449 數位成本和為目標值的最大數字：DP + 貪心構造）

*問題*：數字 $1..9$ 各有成本 $\mathit{cost}[d]$，總成本必須**恰好**為 `target`，求能拼出的最大整數（字串，無前導零，湊不出回傳 `"0"`）。

**兩步。**

**(a) 先用完全背包求「恰好花費 $t$ 時的最多位數」** $f[t]$（初值 $f[0]=0$，其餘 $-\infty$）✔。

**(b) 再從高位往低位貪心構造**：對每一位，從 $d = 9$ 試到 $1$，**若 $f[\,t - \mathit{cost}[d]\,] = f[t] - 1$ 就選 $d$** 並把 $t$ 減掉 $\mathit{cost}[d]$。

*為什麼「先最大化位數」是對的*。**在十進位下，位數多的正整數一定比位數少的大** ✔——這是嚴格的偏序，不需要比較內容。

*為什麼「同位數時從 9 往下貪心」是對的*。**兩個位數相同的數，比較大小等同於字典序比較** ✔。故從最高位開始，**在「剩餘成本仍能填滿剩餘位數」的前提下取最大的數字**，得到的就是字典序最大者 ⇒ 也是數值最大者 ✔。

*為什麼判斷式是 $f[t - \mathit{cost}[d]] = f[t] - 1$*。**它精確地表達了「選了 $d$ 之後，剩下的成本仍能湊出恰好 $f[t]-1$ 位」** ⇒ 總位數不損失 ✔。**寫成 $\ge$ 或 $>$ 都是錯的**（$f$ 的定義已是最大值，不可能 $>$；寫 $\ge$ 在 $f[t-\mathit{cost}[d]] = -\infty$ 時也會出問題）。$\square$

**點名前提**：$\mathit{cost}[d] \ge 1$。**若某個成本為 0，「位數」會無界 ⇒ $f$ 不存在** ✘（同定理 1 的前提）。

**這個「DP 求最優值 + 貪心逐位還原」的模式在 16 節（輸出具體方案）是通用手法**：**先用 DP 建表，再用「表值是否吻合」來檢驗每一個候選決策。** 它比「在 DP 過程中記錄決策」更省空間，也更不容易寫錯。

## 時間與空間複雜度

| 題目 | 時間 | 空間 | 備註 |
| --- | --- | --- | --- |
| 標準完全背包 | $O(nC)$ | $O(C)$ | 定理 1 把 $O(nC^2/w)$ 壓到 $O(nC)$ |
| 322 零錢兌換 | $O(n \cdot \mathit{amount})$ | $O(\mathit{amount})$ | `INF` 取 `amount+1` |
| 518 零錢兌換 II | $O(n \cdot \mathit{amount})$ | $O(\mathit{amount})$ | **外物品內容量** |
| 377 組合總和 IV | $O(n \cdot \mathit{target})$ | $O(\mathit{target})$ | **外容量內物品**；用 `unsigned` 或題目保證不溢位 |
| 279 完全平方數 | $O(n\sqrt n)$ 或 **$O(\sqrt n)$**（定理 5） | $O(n)$ 或 $O(1)$ | 數論解需引用兩個定理 |
| 1449 最大數字（定理 6） | $O(9 \cdot \mathit{target})$ | $O(\mathit{target})$ | DP + 逐位貪心 |

**規模速查**：$\mathit{amount} \le 10^4$、$n \le 12$ ⇒ $1.2\times10^5$ ✔ 毫無壓力。**完全背包很少成為瓶頸**，因為題目的容量通常不大。

**溢位**：377 的答案保證在 32 位內，**但中間值可能超過**——官方測資裡有需要用 `unsigned int` 或 `long long` 的情況。**計數型完全背包一律用 `long long` 或按題目取模。**

**空間**：一維陣列 $O(C)$。**完全背包同樣可以壓成 `bitset` 做可行性判斷**（`f |= f << w` 重複執行到不動點，或注意到單次位移即可覆蓋——因為完全背包允許重複，需要 $\lfloor C/w \rfloor$ 次位移或用倍增），**但不如直接跑 $O(nC)$ 來得簡單。**

## 與相似技巧的比較

- **與 3.1 0-1 背包**：**只差內層迴圈方向**，而那個差別由定理 1（模型）與定理 2（實作）兩層解釋。**兩節必須一起讀。**
- **與 3.3 多重背包**：完全背包是「上限 $\infty$」的特例。**當 $k_i \ge \lfloor C/w_i \rfloor$ 時，多重背包退化成完全背包**——**這是多重背包實作中一個常用的快速路徑判斷** ✔。
- **與 1.1 爬樓梯**：377 的遞推 $f[c] = \sum_x f[c-x]$ **就是廣義的爬樓梯**（每步可以爬 `nums` 中任一個數）。**1.1 定理 2 與本節定理 3 是同一條定理的兩次出現。**
- **與最短路（graph 章）**：322 零錢兌換 $\equiv$ **在「金額」節點上、以面額為邊權 1 的無權圖上求最短路** ⇒ **BFS 也能解**，複雜度相同。**當面額很少而金額很大時，BFS 因為只訪問可達狀態，實際上可能更快。**
- **與 11.6 矩陣快速冪**：計數型完全背包在 $C$ 極大（$10^{18}$）而面額固定時，遞推是常係數線性的 ⇒ **可以用矩陣快速冪 $O(w^3\log C)$**，其中 $w$ 是最大面額。
- **與數論（math 章）**：定理 5 顯示 279 有 $O(\sqrt n)$ 的封閉解。**另一個著名例子是「Chicken McNugget / Frobenius 數」**：兩個互質面額 $a, b$ 湊不出的最大金額是 $ab - a - b$。**遇到「面額固定且很小」的題目，先想想有沒有數論結論。**

## 本節重點速查

- **模型**：每種物品**可用無限次**。與 0-1 只差一個字，程式碼只差迴圈方向。
- **定理 1（$O(C/w) \to O(1)$）**：把「用了 $k$ 個」的枚舉改成「**$0$ 個 / 至少 1 個**」二分。「至少 1 個」拿掉一個之後**仍可再用物品 $i$** ⇒ 停在 $f(\mathbf{i},\, c-w_i)$ 而不是 $f(i-1,\cdot)$。**前提收緊為 $w_i > 0$**（$w_i=0$ 會自我引用成環）。
- **定理 2（正序）**：轉移要讀「**本輪**」的 $g[c-w]$，它在左側 ⇒ **正序**。**3.1 那個「同一物品用兩次」的反例，在這裡正是我們要的行為。**
- **迴圈方向總表**：至多 1 次 ⇒ 倒序；無限次 ⇒ 正序；至多 $k_i$ 次 ⇒ 見 3.3。
- **定理 3（組合 vs 排列）**：**外物品內容量 ⇒ 組合**（劃分依據「這種用幾個」，無序）；**外容量內物品 ⇒ 排列**（劃分依據「最後一個是誰」，有序）。`coins=[1,2], amount=3` ⇒ 組合 2 種、排列 3 種。**$\max/\min$ 型冪等，兩種順序都對；只有計數型必須小心。**
- **定理 4（322）**：「恰好」型，`INF` 用 `amount+1`。**貪心是錯的**：`coins=[1,3,4], amount=6` ⇒ 貪心 3 枚、最優 2 枚。**真實幣制能貪心是那些幣制的特殊性質。**
- **定理 5（279）**：DP 是 $O(n\sqrt n)$；**引用 Lagrange 四平方和定理與 Legendre 三平方和定理**（$n=4^a(8b+7)\iff$ 答案為 4）可做到 $O(\sqrt n)$。**兩個定理本節不證明，只引用。**
- **定理 6（1449）**：**先 DP 求「恰好花 $t$ 的最多位數」，再從高位貪心試 $9\to1$，判斷式是 $f[t-\mathit{cost}[d]] = f[t]-1$（等號，不是 $\ge$）。** 正確性：位數多必定更大；同位數時字典序 = 數值序。前提 $\mathit{cost}[d]\ge1$。**這個「DP 建表 + 逐位驗證還原」是 16 節的通用手法。**
