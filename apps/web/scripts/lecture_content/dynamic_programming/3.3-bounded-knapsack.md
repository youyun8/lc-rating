## 這個技術解決什麼問題

多重背包是 0-1 與完全背包之間那一格：

$$\text{0-1（上限 }1\text{）} \;\longrightarrow\; \text{多重（上限 } k_i\text{）} \;\longrightarrow\; \text{完全（上限 }\infty\text{）}$$

**它的樸素解法很直接**——按「第 $i$ 種用了幾個」枚舉——**但複雜度多了一個因子 $\bar k$，在 $k_i$ 大時會爆。** 本節的三個加速手段，難度與適用範圍各不相同：

| 手段 | 複雜度 | 適用 | 難度 |
| --- | --- | --- | --- |
| **二進位拆分**（定理 2） | $O(nC\log k)$ | **最優化型**（`max`/`min`） | 容易 |
| **單調佇列**（定理 3） | $O(nC)$ | **最優化型** | 中等 |
| **同餘類前綴和**（定理 4、5） | $O(nC)$ | **計數型** | 中等 |

**最重要的一件事，也是本節唯一真正的陷阱**：**二進位拆分在計數型題目上是錯的**（定理 4）。**很多人把它當萬用工具，然後在 2902 這類題目上默默地重複計數。** 這條定理值得單獨記住。

**辨識訊號**：
- 每種物品有**數量上限**，介於「只能拿一次」和「無限拿」之間；
- 要在一個總和／容量限制下求最大值或方案數；
- **暴力枚舉每種拿幾個會爆炸**——用背包把它壓成 `dp[c]` 沿容量推進。

## 狀態／資料結構定義

```cpp
// 樸素：O(n * C * k)，正確但慢；小資料直接用它，別過早優化
for (int i = 0; i < n; i++)
    for (int c = C; c >= 0; c--)  // 倒序（本質是 0-1）
        for (int j = 1; j <= k[i] && j * w[i] <= c; j++)
            g[c] = max(g[c], g[c - j * w[i]] + j * v[i]);
```

```cpp
// 二進位拆分：把「k 個相同物品」拆成 O(log k) 個 0-1 物品 —— 定理 2
vector<pair<int, int>> items;  // (weight, value)
for (int i = 0; i < n; i++) {
    int rest = k[i];
    for (int b = 1; b <= rest; b <<= 1) {  // 1, 2, 4, ...
        items.push_back({b * w[i], b * v[i]});
        rest -= b;
    }
    if (rest > 0) items.push_back({rest * w[i], rest * v[i]});
}
// 之後就是標準 0-1 背包（倒序）
```

```cpp
// 計數型：同餘類前綴和 —— 定理 5（絕不能用二進位拆分）
// f_new[c] = sum_{j=0..k} f_old[c - j*w]
//          = S[c] - S[c - (k+1)*w]，其中 S[c] = f_new[c-w] + f_old[c]
for (int c = w; c <= C; c++) {       // 正序
    f[c] = (f[c] + f[c - w]) % MOD;  // 先做「無限次」的前綴和
    if (c >= (k + 1) * w)            // 再扣掉「用超過 k 個」的部分
        f[c] = (f[c] - old[c - (k + 1) * w] % MOD + MOD) % MOD;
}
```

**三個實作前提**：
- **`old` 必須是本輪開始前的快照**（`f` 在本輪會被就地改寫）；
- **減法取模一定要 `+ MOD` 再取模**，否則會得到負數 ✘；
- **$w = 0$ 的物品要單獨處理**（見定理 5）。

## 不變量或正確性證明

### 定理 1（樸素轉移的正確性）

*命題*：$\displaystyle f(i, c) = \max_{0 \le j \le \min(k_i,\; \lfloor c/w_i\rfloor)} \big( f(i-1,\; c - j w_i) + j v_i \big)$。

*證明*。按「第 $i$ 種用了 $j$ 個」劃分——**不漏**（$j$ 必為 $[0, k_i]$ 中某個整數）、**不重**（$j$ 唯一確定）✔；剩下的部分是「只用前 $i-1$ 種、容量 $\le c - jw_i$」的合法方案，剪貼論證得等號 ✔。$\square$

**為什麼不能像完全背包那樣壓成二分**（3.2 定理 1）。那裡「拿掉一個之後還可以再拿」，所以能停在同一層 $f(i, \cdot)$；**這裡拿掉一個之後，剩餘可用數量從 $k_i$ 變成 $k_i - 1$——「還能用幾個」是一個新的狀態分量，不在 $f(i,c)$ 裡** ✘。

**要把它補進狀態就得寫成 $f(i, c, j)$，狀態數乘上 $k_i$——那還不如直接枚舉。** 這正是多重背包比另外兩者麻煩的根本原因：**它的「剩餘次數」既非 0 也非無窮，無法被吸收掉。**

### 定理 2（二進位拆分：$\{1, 2, 4, \dots, 2^{t-1}, r\}$ 恰好覆蓋 $[0, k]$）

*設定*：給定 $k \ge 1$，取最大的 $t \ge 0$ 使得 $2^t - 1 \le k$，令 $r = k - (2^t - 1)$。考慮多重集合

$$B = \{\,1, 2, 4, \dots, 2^{t-1}\,\} \cup \{\,r\,\}\quad(\text{若 } r > 0).$$

*命題*：$B$ 的子集和**恰好**構成 $\{0, 1, 2, \dots, k\}$——**每個值至少可達一次，且沒有任何子集和超過 $k$。**

*證明*。
- **(不超過 $k$)** $B$ 的全部元素之和 $= (2^t - 1) + r = k$ ✔。
- **(覆蓋 $[0, 2^t - 1]$)** $\{1,2,\dots,2^{t-1}\}$ 的子集和就是所有二進位表示，恰為 $\{0,1,\dots,2^t-1\}$ ✔。
- **(覆蓋 $[2^t, k]$)** 由 $t$ 的最大性，$2^{t+1} - 1 > k$ ⇒ $r = k - 2^t + 1 < 2^t$。對任一 $m \in [2^t, k]$，取 $m' = m - r$。則 $m' \ge 2^t - r > 0$ 且 $m' \le k - r = 2^t - 1$ ⇒ $m'$ 可由前半部覆蓋 ⇒ $m = m' + r$ 可達 ✔。$\square$

**於是「$k_i$ 個相同物品」可以換成 $O(\log k_i)$ 個 0-1 物品，直接套 3.1** ⇒ $O(nC\log k)$ ✔。

**為什麼這在最優化型是對的**：定理 2 只保證「每個用量都**至少**有一種表示」。**最優化型只需要「可達」，重複表示無害（$\max(a,a)=a$）** ✔——**這與 1.2 定理 2 的「覆蓋 vs 劃分」是同一個道理。**

**實作提醒**：迴圈條件寫 `for (int b = 1; b <= rest; b <<= 1) { push(b); rest -= b; }`，**這樣寫出來的 `rest` 自動就是定理 2 的 $r$** ✔，不需要另外算 $t$。**別忘了迴圈結束後再 push 一次 `rest`（若 $>0$）。**

### 定理 3（單調佇列優化：$O(nC\log k) \to O(nC)$）

*命題*：定理 1 的轉移可以在 $O(1)$ 均攤時間內完成。

*證明*。固定物品 $i$（記 $w = w_i$、$v = v_i$、$k = k_i$）。**按 $c \bmod w$ 把容量分成 $w$ 個同餘類**，每一類獨立處理。設 $c = qw + r$（$0 \le r < w$），並記 $F(q) = f(i-1,\, qw + r)$、$G(q) = f(i,\, qw+r)$。轉移變成

$$G(q) = \max_{\max(0,\,q-k) \le p \le q} \big( F(p) + (q - p)v \big) = qv + \max_{\max(0,q-k) \le p \le q}\big( F(p) - pv \big).$$

**關鍵在於把 $qv$ 提到 max 外面**——這一步之所以可行，是因為 $qv$ 與被最大化的變數 $p$ 無關 ✔。

於是令 $H(p) = F(p) - pv$，問題化成「**對 $H$ 求長度為 $k+1$ 的滑動窗口最大值**」⇒ 單調佇列 $O(1)$ 均攤 ✔。$\square$

**每個同餘類的長度是 $O(C/w)$，共 $w$ 個類 ⇒ 每個物品 $O(C)$ ⇒ 總計 $O(nC)$** ✔。

**這條定理的一般形式極為重要**，它是 11.3（單調佇列優化 DP）的原型：

> **轉移形如 $\mathit{dp}[c] = \max_{c - L \le c' \le c}\big(\mathit{dp}[c'] + (\text{只依賴 } c \text{ 的項}) + (\text{只依賴 } c' \text{ 的項})\big)$ 時，把「只依賴 $c$」的部分提出 max，剩下的就是滑動窗口最大值。**

**「能不能把兩個變數分離」是判斷能否用單調佇列的唯一標準。** 若代價項是 $c \cdot c'$ 這種**耦合**的形式，分離失敗 ⇒ 要改用斜率優化（11.7）✔。

**實作上的三個坑**：
- **窗口長度是 $k+1$ 不是 $k$**（$j$ 可以取 0）；
- **同餘類要從小到大處理**，且**每個類要重新清空佇列**；
- **佇列裡存的是下標 $p$，比較時用 $H(p)$**——存值會導致無法判斷是否過期。

**實務建議**：$O(nC\log k)$ 與 $O(nC)$ 差的只是一個 $\log k$（通常 $\le 20$）。**先寫二進位拆分（20 行、不容易錯），確定 TLE 了再換單調佇列。**

### 定理 4（**計數型不能用二進位拆分**）

*命題*：把「$k$ 個相同物品」二進位拆分後做計數型背包，**會重複計數**。

*證明（反例）*。取 $k = 4$，拆分為 $\{1, 2, 1\}$（因為 $1+2 = 3$，餘數 $r = 4 - 3 = 1$）。列出所有子集和：

| 子集 | 和 |
| --- | --- |
| $\varnothing$ | 0 |
| $\{1\}$ | 1 |
| $\{1'\}$ | **1** |
| $\{2\}$ | **2** |
| $\{1, 1'\}$ | **2** |
| $\{1, 2\}$ | **3** |
| $\{2, 1'\}$ | **3** |
| $\{1,2,1'\}$ | 4 |

**用量 1、2、3 各有兩種表示** ⇒ 計數型會把「用 2 個」數成兩次 ✘。$\square$

**定理 2 保證的是「覆蓋」（每個用量至少一種表示），不是「劃分」（恰好一種表示）。** 最優化型靠 $\max$ 的冪等性免疫，計數型的 `+` 沒有這個性質。

> **這是 1.2 定理 2 那句話的第三次出現：**
> **最優化可以重疊覆蓋（$\max(a,a)=a$），計數不行（$a+a \ne a$）。**

**計數型的正確做法是同餘類前綴和（定理 5）**，複雜度 $O(nC)$，比拆分還快。

### 定理 5（計數型的同餘類前綴和，以及 $w=0$ 的陷阱）

*命題*：計數型轉移 $\displaystyle f_i(c) = \sum_{j=0}^{k_i} f_{i-1}(c - j w_i)$ 可以在 $O(1)$ 均攤時間完成。

*證明*。固定物品 $i$（記 $w, k$）。在同餘類 $c \equiv r \pmod w$ 內，定義**無限次前綴和**

$$S(c) = \sum_{j \ge 0} f_{i-1}(c - jw) \qquad\Longleftrightarrow\qquad S(c) = f_{i-1}(c) + S(c - w),$$

則所求的**有限和**為

$$f_i(c) = \sum_{j=0}^{k} f_{i-1}(c - jw) = S(c) - S\big(c - (k+1)w\big) \qquad (\text{當 } c \ge (k+1)w).$$

**兩個無限和相減，多出來的尾巴恰好抵銷** ✔。$\square$

**就地實作的技巧**：正序掃描時 `f[c] += f[c-w]` 恰好在原地算出 $S(c)$（這正是完全背包的正序，3.2 定理 2）✔；**接著再減去 $(k+1)w$ 處「上一輪的」$S$ 值**。**所以必須先把上一輪的陣列存成 `old` 快照**——直接讀 `f[c-(k+1)w]` 會讀到本輪已改寫的值 ✘。

**取模的兩個坑**：
- **減法後可能為負** ⇒ 寫 `(a - b % MOD + MOD) % MOD` ✔；
- **前綴和會不斷累加** ⇒ 每步都要取模，否則 `long long` 也會爆。

**$w = 0$ 的陷阱（2902 真的會遇到）**：若某個值為 0，它對「和」沒有貢獻，**但選或不選會影響方案數** ⇒ 上面的同餘類推導在 $w = 0$ 時除以零、完全失效 ✘。

*正確處理*：設值 0 出現了 $c_0$ 次，**每個 0 可選可不選，共 $2^{c_0}$ 種**（若題目數的是「子多重集合」且相同的 0 不可區分，則是 $c_0 + 1$ 種）。**先算出非零部分的答案，最後整體乘上這個因子** ✔。

**務必先確認題目的「相同元素可否區分」**——這決定了因子是 $2^{c_0}$ 還是 $c_0+1$。**2902 數的是子多重集合，相同的數不可區分 ⇒ 因子是 $c_0 + 1$。**

### 定理 6（兩個退化情形：先判斷再選路徑）

*命題*：
- **(a)** 若 $k_i \ge \lfloor C / w_i \rfloor$，物品 $i$ 可以當作**完全背包**處理（正序，$O(C)$）；
- **(b)** 若 $k_i = 1$，物品 $i$ 就是**0-1 背包**（倒序，$O(C)$）。

*證明*。
- **(a)** 容量上限 $C$ 使得物品 $i$ 最多也只能放 $\lfloor C/w_i\rfloor$ 個 ⇒ 數量上限 $k_i$ **從未被觸及** ⇒ 與「無限」等價 ✔。
- **(b)** 定義直接一致 ✔。$\square$

**實作建議：在物品迴圈裡先做這兩個判斷。**

```cpp
for (int i = 0; i < n; i++) {
    if (w[i] == 0) { /* 單獨處理，見定理 5 */
        continue;
    }
    if (k[i] == 1) {                          /* 0-1：倒序   */
    } else if ((long long)k[i] * w[i] >= C) { /* 完全：正序 */
    } else { /* 二進位拆分 或 單調佇列 */
    }
}
```

**這個快速路徑在實務上很有價值**：**很多題目的 $k_i$ 名義上很大（例如 $10^9$），但一經 (a) 判斷就全部退化成完全背包**，複雜度從「看起來要 $\log k$」變成 $O(nC)$ ✔。**先判斷退化，再談優化。**

**注意 (a) 的判斷要防溢位**：`k[i] * w[i]` 在兩者都是 $10^9$ 時會爆 `int` ⇒ 用 `long long` 或改寫成 `k[i] >= C / w[i]` ✔。

## 時間與空間複雜度

| 方法 | 時間 | 空間 | 適用 |
| --- | --- | --- | --- |
| 樸素枚舉（定理 1） | $O(nC\bar k)$ | $O(C)$ | $\bar k$ 很小時 |
| 二進位拆分（定理 2） | $O(nC\log k)$ | $O(C)$ | **最優化型**，首選 |
| 單調佇列（定理 3） | $O(nC)$ | $O(C)$ | 最優化型，$\log k$ 也嫌慢時 |
| 同餘類前綴和（定理 5） | $O(nC)$ | $O(C)$ | **計數型，唯一正確的優化** |
| 退化為完全／0-1（定理 6） | $O(nC)$ | $O(C)$ | 先判斷，常常直接省掉優化 |

**規模速查**：$n = 10^3$、$C = 10^4$、$k = 10^3$

| 方法 | 運算量 |
| --- | --- |
| 樸素 | $10^{10}$ ✘ |
| 二進位拆分 | $10^8$ ⚠️ 邊緣 |
| 單調佇列 / 前綴和 | $10^7$ ✔ |

**溢位**：計數型的中間值必須取模；最優化型若 $v_i$ 與 $k_i$ 都大，$\sum k_i v_i$ 可能超過 `int` ⇒ **一律 `long long`。**

**空間**：一維 $O(C)$。**計數型需要一份 `old` 快照 ⇒ $O(C)$ 額外空間**，這是同餘類前綴和唯一的空間代價 ✔。

## 與相似技巧的比較

- **與 3.1 / 3.2**：三者是同一個模型的三個參數值（上限 $1$、$k$、$\infty$）。**多重背包最麻煩，因為「剩餘次數」既無法忽略也無法吸收**（定理 1 的說明）。**遇到多重背包，第一件事是檢查會不會退化（定理 6）。**
- **與 11.3 單調佇列優化 DP**：定理 3 就是那一節的原型。**判準是「能不能把兩個變數分離」**——能分離就是滑動窗口，不能就要看 11.7 斜率優化。
- **與 11.1 字首和優化 DP**：定理 5 就是那一節的原型。**判準是「轉移是不是一段連續區間的和」**——是的話就用前綴和；**注意減法取模。**
- **與 3.4 分組背包**：分組背包是「每組**恰選一個**」，多重背包是「每種選 $0..k_i$ 個」。**多重背包可以看成一種特殊的分組背包**（第 $i$ 組的選項是「用 0 個 / 1 個 / … / $k_i$ 個」）⇒ **兩者的樸素解法一模一樣**，差別只在多重背包有額外結構（用量是等差的）可以優化 ✔。
- **與生成函數（math 章）**：多重背包的計數型 $\equiv$ 計算 $\prod_i \frac{1 - x^{(k_i+1)w_i}}{1 - x^{w_i}}$ 的係數。**定理 5 的「無限和相減」正是這個分子分母的組合意義**——$\frac{1}{1-x^w}$ 是完全背包（無限次），乘上 $(1 - x^{(k+1)w})$ 就是扣掉「用超過 $k$ 個」的部分 ✔。**知道這個對應，前綴和公式就不必背了。**

## 本節重點速查

- **模型**：每種物品上限 $k_i$ 個。**「剩餘次數」既非 0 也非無窮，無法像完全背包那樣被吸收**（定理 1）。
- **定理 2（二進位拆分）**：$\{1,2,4,\dots,2^{t-1}, r\}$（$r = k - 2^t + 1$）的子集和**恰好覆蓋 $[0,k]$ 且不超過 $k$**。⇒ $O(nC\log k)$。**寫法：`for (b=1; b<=rest; b<<=1) { push(b); rest-=b; }` 之後再 push 剩下的 `rest`。**
- **定理 3（單調佇列）**：按 $c \bmod w$ 分組，令 $H(p) = F(p) - pv$，轉移變成長度 $k+1$ 的**滑動窗口最大值** ⇒ $O(nC)$。**關鍵是把 $qv$ 提到 max 外面——「兩個變數能否分離」是能否用單調佇列的唯一標準。** 窗口長度是 $k+1$、每個同餘類要清空佇列。
- **定理 4（最大的坑）**：**計數型不能用二進位拆分。** $k=4$ 拆成 $\{1,2,1\}$ 時，用量 2 有兩種表示 ⇒ 重複計數 ✘。**定理 2 保證的是覆蓋不是劃分；$\max$ 冪等所以免疫，`+` 不冪等所以中招。**
- **定理 5（計數型的正解）**：同餘類前綴和 $f_i(c) = S(c) - S(c-(k+1)w)$。**必須存 `old` 快照**（就地正序已改寫）、**減法取模要 `+MOD`**、**$w=0$ 要單獨處理**（2902 的因子是 $c_0+1$，因為子多重集合裡相同元素不可區分）。
- **定理 6（先看退化）**：$k_i \ge \lfloor C/w_i\rfloor$ ⇒ 當完全背包（正序）；$k_i = 1$ ⇒ 當 0-1（倒序）。**判斷要防溢位，寫成 `k >= C / w`。** 很多「$k$ 很大」的題目一判就退化，根本不必優化。
- **生成函數視角**：計數型 $=\prod_i \frac{1-x^{(k_i+1)w_i}}{1-x^{w_i}}$，**分母是完全背包、分子是扣掉超額**——定理 5 的公式就是它。
