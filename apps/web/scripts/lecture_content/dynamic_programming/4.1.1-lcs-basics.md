## 這個技術解決什麼問題

LCS 這一族處理的是**兩個序列之間的對齊**：

> **在兩個序列上各挑一個子序列，使它們「對得上」，並最佳化某個目標。**

**「對得上」的含義隨題目變化，但骨架永遠是同一個 $O(mn)$ 的二維表格**：

| 題 | 對齊的目標 | 本質 |
| --- | --- | --- |
| 1143 最長公共子序列 | 最大化匹配數 | 模板 |
| 1035 不相交的線 | 最大化不交叉的連線數 | **就是 LCS**（定理 5） |
| 583 兩字串的刪除操作 | 最小化刪除次數 | $m + n - 2\cdot\mathrm{LCS}$（定理 4） |
| 712 兩個字串的最小 ASCII 刪除和 | 最小化刪除字元的權重和 | **加權版，不能套長度公式**（定理 4） |
| 72 編輯距離 | 最小化增／刪／改次數 | 三分支對齊（定理 3） |
| 718 最長重複子陣列 | 最大化**連續**匹配長度 | **狀態要釘住結尾**（定理 6） |

**這一節真正要學會的是三件事**：

1. **「相等就一定匹配」需要證明**（定理 1）——這是全節唯一一個「看起來顯然、其實要交換論證」的地方，而且它的證明格式在很多對齊題裡會重複用到。
2. **「不重不漏」在最小化問題裡可以放寬成「不漏」**（定理 3）——編輯距離的三個分支其實是**重疊的**，但因為取 `min` 所以無害。
3. **「子序列」與「子陣列」的狀態定義完全不同**（定理 6）——連續性一旦出現，狀態必須釘住結尾。

**辨識訊號**：
- **兩個序列**（而不是一個）；
- 要在兩者之間建立**保序**的對應關係（$i$ 遞增時 $j$ 也遞增）；
- 答案只跟「兩個前綴」有關 ⇒ 二維表格。

## 狀態／資料結構定義

**通用狀態**：

$$f(i, j) = \text{只考慮 } s\text{ 的前 } i \text{ 個字元與 } t \text{ 的前 } j \text{ 個字元時的最優值}$$

**注意下標約定**：$f$ 的下標是**長度**（$0..m$、$0..n$），字元是 $s[i-1]$、$t[j-1]$。**多開一行一列存空前綴的邊界，比在轉移裡處理 $i=0$ 乾淨得多。**

| 題型 | 轉移 | 邊界 |
| --- | --- | --- |
| **LCS**（1143、1035） | 相等：$f(i-1,j-1)+1$；否則 $\max\big(f(i-1,j),\, f(i,j-1)\big)$ | $f(0,\cdot)=f(\cdot,0)=0$ |
| **編輯距離**（72） | 相等：$f(i-1,j-1)$；否則 $1+\min\big(f(i-1,j-1),\, f(i-1,j),\, f(i,j-1)\big)$ | $f(i,0)=i$、$f(0,j)=j$ |
| **加權刪除**（712） | 相等：$f(i-1,j-1)$；否則 $\min\big(f(i-1,j)+s_i,\ f(i,j-1)+t_j\big)$ | $f(i,0)=\sum_{k<i}s_k$ |
| **最長重複子陣列**（718） | 相等：$f(i-1,j-1)+1$；**否則 $0$** | $f(0,\cdot)=f(\cdot,0)=0$ |

**718 那一列的粗體是全表最重要的差異**：**它的 $f(i,j)$ 語意是「以 $s[i-1]$ 與 $t[j-1]$ 為結尾的最長公共後綴」，答案是 $\max_{i,j} f(i,j)$ 而不是 $f(m,n)$**（定理 6）。

**編輯距離三個分支的意義**（記住這個對應，符號就不會抄錯）：

| 分支 | 操作 | 直覺 |
| --- | --- | --- |
| $f(i-1,j-1)+1$ | **替換** $s_i \to t_j$ | 兩邊各消耗一個 |
| $f(i-1,j)+1$ | **刪除** $s_i$ | 只消耗 $s$ |
| $f(i,j-1)+1$ | **插入** $t_j$ | 只消耗 $t$ |

## 不變量或正確性證明

### 定理 1（**「相等就一定匹配」的交換論證**）

*命題*：若 $s[i-1] = t[j-1]$，則 $f(i,j) = f(i-1,j-1) + 1$，其中 $f$ 是 LCS 長度。

**這一步經常被當成顯然而跳過，但它其實是一個交換論證**：$s[i-1] = t[j-1]$ 只說明「**可以**匹配」，不說明「**最優解裡一定匹配**」。要排除「不匹配這一對反而更好」的可能性，必須證明。

*證明*。

- **($\ge$)** 任何 $s[0..i-2]$ 與 $t[0..j-2]$ 的公共子序列後面接上 $s[i-1]$，仍是 $s[0..i-1]$ 與 $t[0..j-1]$ 的公共子序列 ⇒ $f(i,j) \ge f(i-1,j-1)+1$ ✔。

- **($\le$)** 取一個長度為 $f(i,j)$ 的最優公共子序列 $L$，設它在 $s$ 上的匹配位置為 $a_1 < \cdots < a_k$、在 $t$ 上為 $b_1 < \cdots < b_k$（$k = f(i,j)$，且 $a_k \le i-1$、$b_k \le j-1$）。

  **把最後一對匹配 $(a_k, b_k)$ 換成 $(i-1, j-1)$。** 這仍是合法的公共子序列，因為：
  - $s[i-1] = t[j-1]$ ⇒ 新的這一對字元相同 ✔；
  - 前 $k-1$ 對的下標滿足 $a_{k-1} < a_k \le i-1$、$b_{k-1} < b_k \le j-1$ ⇒ **嚴格遞增性保持** ✔。

  於是**存在一個長度同為 $k$ 的最優解，其最後一對匹配恰是 $(i-1,j-1)$**。去掉這一對，剩下的是 $s[0..i-2]$ 與 $t[0..j-2]$ 的公共子序列 ⇒ $k - 1 \le f(i-1,j-1)$ ⇒ $f(i,j) \le f(i-1,j-1)+1$ ✔。$\square$

**這個「把最後一對匹配往右下角推」的手法是對齊型 DP 的通用工具**，之後在 4.1.2 的通配符匹配、正則匹配裡還會再見到。**它依賴的前提是「匹配必須保序」**——若題目允許交叉匹配（例如「兩個多重集合的交集大小」），這個論證立刻失效 ✘，那類題目要用計數而非 DP。

### 定理 2（不相等時為什麼不必看左上角）

*命題*：若 $s[i-1] \ne t[j-1]$，則 $f(i,j) = \max\big(f(i-1,j),\, f(i,j-1)\big)$——**不需要再取 $f(i-1,j-1)$**。

*證明*。先證**單調性**：對固定的 $j$，$f(i,j)$ 對 $i$ 單調不減（前綴變長，可選的子序列只多不少）✔；對 $j$ 同理。

於是 $f(i-1,j-1) \le f(i-1,j)$ ⇒ **把 $f(i-1,j-1)$ 加進 $\max$ 不會改變結果** ⇒ 省略它是安全的 ✔。

至於等號本身：最優解 $L$ 中，$s[i-1]$ 與 $t[j-1]$ **不可能同時被匹配**（否則它們必須互相匹配，但兩者不等 ✘）。
- 若 $s[i-1]$ 未被用到 ⇒ $L$ 是 $s[0..i-2]$ 與 $t[0..j-1]$ 的公共子序列 ⇒ $|L| \le f(i-1,j)$；
- 若 $t[j-1]$ 未被用到 ⇒ 同理 $|L| \le f(i,j-1)$。

兩種情形**覆蓋所有可能**（可能重疊，但取 max 無害）⇒ $f(i,j) \le \max(\cdot,\cdot)$；反向不等式顯然 ✔。$\square$

**這裡出現了本節第二個重要觀念**：**兩個分支是「覆蓋」而非「劃分」**（$s[i-1]$ 與 $t[j-1]$ 可能都沒被用到，此時兩個分支都成立）。**最優化型免疫，計數型會出錯**——這是 1.2 定理 2、3.3 定理 4 之後的第三次應用。

> **若題目改成「數有多少個不同的最長公共子序列」，上面的轉移會重複計數 ✘**，必須改成嚴格劃分（用容斥減去 $f(i-1,j-1)$ 的重疊部分）。

### 定理 3（編輯距離：三個分支是**重疊覆蓋**，取 `min` 才安全）

*命題*：$s[i-1] \ne t[j-1]$ 時 $f(i,j) = 1 + \min\big(f(i-1,j-1),\ f(i-1,j),\ f(i,j-1)\big)$。

*證明（$\le$）*。三個分支各給出一個合法的編輯方案（替換／刪除／插入），故 $f(i,j)$ 不超過三者 $+1$ 的最小值 ✔。

*證明（$\ge$，即「不漏」）*。取一個最優編輯序列，把它整理成一個**對齊**（alignment）：一列一列地把 $s$ 與 $t$ 的字元配對，允許某一側為空。考慮**最後一列**，只有三種可能：
- $(s[i-1],\, t[j-1])$ 配成一列 ⇒ 代價 $\ge 1 + f(i-1,j-1)$（不等因為兩字元不同，必須替換）；
- $(s[i-1],\, \varnothing)$ ⇒ 代價 $\ge 1 + f(i-1,j)$；
- $(\varnothing,\, t[j-1])$ ⇒ 代價 $\ge 1 + f(i,j-1)$。

**這三種情形窮盡了「最後一列」的所有形狀**（不可能兩側都為空）✔ ⇒ 最優值 $\ge$ 三者最小 ✔。$\square$

**注意證明裡刻意說的是「窮盡」而不是「劃分」**：**同一個編輯距離值可能由多種對齊達成**（例如「刪一個再插一個」與「替換一次」在某些串上代價相同），三個分支**確實重疊**。**因為目標是 `min`，重疊只會讓同一個值被算兩次，不影響結果** ✔。

**這一點在改題時會咬人**：若要**數有多少種最少編輯方案**，直接把 `min` 換成計數是錯的 ✘——**要先定義「什麼算同一種方案」（編輯序列？對齊？），再重新設計不重的劃分。** 這是把最優化 DP 改成計數 DP 時最常見的失誤。

### 定理 4（583 = $m+n-2\cdot\mathrm{LCS}$，而 712 **不能**套這個公式）

*命題 (a)*：只允許刪除時，把 $s$、$t$ 變成相同所需的最少刪除次數為 $m + n - 2\,\mathrm{LCS}(s,t)$。

*證明*。
- **($\le$)** 保留一個長度為 $\mathrm{LCS}$ 的公共子序列，其餘全刪 ⇒ 刪除次數 $= (m - \mathrm{LCS}) + (n - \mathrm{LCS})$ ✔。
- **($\ge$)** 任一合法方案刪完後剩下的公共串 $R$，**同時是 $s$ 與 $t$ 的子序列** ⇒ $|R| \le \mathrm{LCS}$ ⇒ 刪除次數 $= (m - |R|) + (n - |R|) \ge m + n - 2\,\mathrm{LCS}$ ✔。$\square$

*命題 (b)*：712 的加權版**不能**寫成「總權重 $-$ 2 × (LCS 的權重)」，除非重新定義 LCS 為「**權重和最大**的公共子序列」。

*理由*。長度最長的公共子序列未必權重和最大。**反例**：$s = \texttt{"az"}$、$t = \texttt{"za"}$。最長公共子序列長度為 1，可以是 `a`（ASCII 97）或 `z`（122）。**若只求長度，兩者無差別；但保留 `z` 才能讓刪除和最小** ✔。

⇒ **正確做法是把目標直接改成「最大化保留的公共子序列權重和」$W$，答案 $=\mathrm{total} - 2W$**；或者如「狀態定義」表所列，直接寫最小化版本的轉移 ✔。$\square$

**這條定理的教訓比公式本身重要**：

> **「把最優化目標換一個等價的形式」之前，必須驗證兩個目標的最優解集合真的重合。** 長度與權重在無權情形下重合，在加權情形下不重合 ✘。

### 定理 5（1035 不相交的線 $\equiv$ LCS）

*命題*：在兩排數字之間連線，要求連線兩端數值相等且**任兩條線不相交**，最大連線數 $=\mathrm{LCS}$。

*證明*。設連線集合為 $\{(a_1,b_1), \dots, (a_k,b_k)\}$，其中 $a$ 是上排下標、$b$ 是下排下標，且 $s[a_t] = t[b_t]$。

**關鍵引理：兩條線 $(a,b)$、$(a',b')$ 不相交 $\iff$ ($a<a'$ 且 $b<b'$) 或 ($a>a'$ 且 $b>b'$)**，即**兩個下標的大小關係一致**。（$a<a'$ 但 $b>b'$ 時兩線必然交叉，這是平面上兩條線段端點交錯的幾何事實。）

於是「兩兩不相交的連線集合」$\iff$「可以排成 $a_1<\cdots<a_k$ 且 $b_1<\cdots<b_k$ 的匹配」$\iff$「一個公共子序列」✔。雙射且保長 ⇒ 兩問題最大值相等 ✔。$\square$

**這是一個典型的「偽裝題」**——**題面完全不提子序列，但約束「不相交」等價於「保序」。** 看到「不交叉」「保持相對順序」「一一對應且遞增」這類措辭，**先試著往 LCS 或 LIS（4.2）翻譯。**

### 定理 6（718 連續 ⇒ 狀態必須釘住結尾）

*命題*：最長公共**子陣列**（連續）不能用 LCS 的狀態定義。

*證明*。若沿用「$f(i,j) = s$ 前 $i$ 個與 $t$ 前 $j$ 個的最長公共連續段」，則轉移無法寫出：**當 $s[i-1] = t[j-1]$ 時，$f(i-1,j-1)$ 記錄的那一段未必以 $s[i-2]$、$t[j-2]$ 結尾**，因此不能直接接上 ✘。

*修法*（與 1.3 定理 1 完全相同的模式）：把狀態改成「**必須以 $s[i-1]$ 與 $t[j-1]$ 結尾**的最長公共段」：

$$f(i,j) = \begin{cases} f(i-1,j-1) + 1 & s[i-1] = t[j-1] \\ 0 & \text{否則} \end{cases}$$

此時 $f(i-1,j-1)$ 的語意保證了「前一個字元也匹配且連續」✔，轉移成立。**答案是 $\max_{i,j} f(i,j)$，不是 $f(m,n)$** ✔。$\square$

> **通用判準：目標要求「連續」時，狀態必須釘住一個端點（通常是右端點），答案再對所有端點取最優。**
> **這條規則在 1.3（最大子陣列和）、718、以及後面的所有「最長合法子串」題目裡是同一件事。**

**另一個推論**：**釘住結尾的狀態天然滿足「不相等就歸零」**——這也是為什麼 718 的轉移看起來比 LCS 還簡單。

### 定理 7（一維滾動：為什麼需要一個 `prev` 變數）

*命題*：把 $f$ 壓成一維 `g[0..n]` 並正序掃 $j$ 時，`g[j-1]` 已是**本行**（第 $i$ 行）的值、`g[j]` 仍是**上一行**的值，而 LCS 的轉移需要**上一行的 `g[j-1]`** ⇒ 必須額外用變數保存。

*證明*。這是 2.1 定理 2 的直接應用：正序掃描時，下標小於 $j$ 的位置已被本輪覆寫，下標 $\ge j$ 的還是上一輪 ✔。LCS 相等分支要的 $f(i-1,j-1)$ 恰好落在「已被覆寫」的區域 ✘ ⇒ 在覆寫前先存起來 ✔。$\square$

```cpp
vector<int> g(n + 1, 0);
for (int i = 1; i <= m; i++) {
    int prev = 0;  // prev = f(i-1, j-1)
    for (int j = 1; j <= n; j++) {
        int tmp = g[j];  // 覆寫前先存下 f(i-1, j)
        g[j] = (s[i - 1] == t[j - 1]) ? prev + 1 : max(g[j], g[j - 1]);
        prev = tmp;  // 下一輪的左上角
    }
}
```

**這三行的順序不能動**：`tmp = g[j]` 必須在賦值前、`prev = tmp` 必須在賦值後。**這正是 1.1 定理 3「讀完再寫」的又一次體現。**

**編輯距離的一維版同理**，而且**別忘了每行開頭要設 `g[0] = i`**（邊界）✘ 忘記這行是最常見的錯。

## 時間與空間複雜度

| 題 | 時間 | 空間（二維） | 空間（滾動） |
| --- | --- | --- | --- |
| 1143 / 1035 LCS | $O(mn)$ | $O(mn)$ | $O(\min(m,n))$ |
| 72 編輯距離 | $O(mn)$ | $O(mn)$ | $O(n)$ |
| 583 / 712 | $O(mn)$ | $O(mn)$ | $O(n)$ |
| 718 最長重複子陣列 | $O(mn)$ | $O(mn)$ | $O(n)$（**須倒序**，見下） |
| 1458 最大點積 | $O(mn)$ | $O(mn)$ | $O(n)$ |

**718 的滾動要倒序**：它的轉移只依賴左上角 $f(i-1,j-1)$，**倒序掃 $j$ 時 `g[j-1]` 還是上一行的值** ⇒ 可以直接寫 `g[j] = (eq ? g[j-1] + 1 : 0)`，連 `prev` 變數都不用 ✔。**這是「依賴左上角」與「依賴左上角＋左邊」的差別造成的**——LCS 因為還要讀本行的 `g[j-1]`，倒序反而不行。

**要輸出方案時空間降不下來**：回溯需要完整的 $O(mn)$ 表。**若 $mn$ 太大而仍需輸出方案，用 Hirschberg 分治可做到 $O(\min(m,n))$ 空間、$O(mn)$ 時間**（分治點取中間行的最優切分），此處只提及不展開。

**常數優化**：字元集小時可用 bitset 把 LCS 做到 $O(mn/64)$（Hunt–Szymanski / 位元平行 LCS），**競賽場合偶爾用得上，面試不需要。**

## 與相似技巧的比較

- **與 4.1.2 LCS 進階**：本節是「兩個序列、無萬用字元、無額外維度」的基本盤。**進階節加入的是：萬用字元（10、44）、交錯合併（97）、計數（115）——狀態定義相同，但轉移的分支劃分要重新論證。**
- **與 4.2 LIS**：LIS 是「一個序列」，LCS 是「兩個序列」。**兩者有一個經典聯繫：當其中一個序列元素互異時，$\mathrm{LCS}(s,t)$ 可以轉成 $t$ 在 $s$ 中位置序列的 LIS，複雜度從 $O(mn)$ 降到 $O(n\log n)$** ✔。**前提是「元素互異」——有重複時位置不唯一，轉換失效。**
- **與 718 / 1.3**：**「連續」把問題從 LCS 拉回「釘住結尾」的模式**（定理 6）。**這是判斷用哪種狀態定義的第一個問題：目標要不要求連續？**
- **與字串演算法（KMP / 後綴自動機）**：718 也可以用二分 + 雜湊做到 $O((m+n)\log)$，或用後綴自動機做到線性。**DP 的優勢是好寫、好改（加權、加約束都只是改轉移）；字串演算法的優勢是複雜度。**
- **與 8 章區間 DP**：區間 DP 也是二維表，但**下標是「同一個序列的左右端點」，遞推方向是「按區間長度」**；LCS 的兩維來自**兩個不同序列**，遞推方向是「按前綴長度」。**看到 $f(i,j)$ 先問「$i$ 和 $j$ 是不是同一個序列的下標」，這決定了填表順序。**
- **與 1458 最大點積**：它套 LCS 的框架，但**目標是最大化 $\sum a_{i_k} b_{j_k}$ 且「至少要選一對」**。**這個「至少一對」讓初始化不能是 0** ✘——`f(0,·) = f(·,0) = -INF`，否則負數測資會回傳 0 ✘。**這是本族題目最常見的邊界陷阱。**

## 本節重點速查

- **狀態**：$f(i,j)$ = 前 $i$ 個與前 $j$ 個的最優值。**多開第 0 行第 0 列處理空前綴。**
- **定理 1（要證，不要跳）**：$s[i-1]=t[j-1]$ ⇒ **一定存在最優解匹配這一對**。證法是把最優解的**最後一對匹配往右下角推**——保序性保證推完仍合法。**這個手法在 4.1.2 還會反覆用。**
- **定理 2**：不等時 $\max(f(i-1,j),f(i,j-1))$，**不必看左上角**（單調性）。**兩分支是覆蓋不是劃分 ⇒ 最優化安全、計數會錯。**
- **定理 3（編輯距離）**：三分支對應替換／刪除／插入，**它們重疊但窮盡**——取 `min` 所以無害。**要數方案數就必須重做劃分。**
- **定理 4**：583 $= m+n-2\,\mathrm{LCS}$；**712 不能套，因為「最長」與「權重最大」的最優解不重合**（反例 `"az"` vs `"za"`）。**換目標前先驗證最優解集合重合。**
- **定理 5**：1035「不相交」$\iff$「保序」$\iff$ LCS。**看到不交叉／保持相對順序，先往 LCS 或 LIS 翻譯。**
- **定理 6**：**要求連續 ⇒ 狀態必須釘住結尾**，不等就歸零，答案取全域 max。與 1.3 同一個模式。
- **定理 7（滾動）**：LCS 一維正序時要用 `prev` 保存左上角，順序是「先存 `tmp = g[j]`、賦值、再 `prev = tmp`」。**718 只依賴左上角 ⇒ 倒序即可，不用 `prev`。** 編輯距離每行別忘 `g[0] = i`。
- **邊界陷阱**：**1458 要求「至少選一對」⇒ 初始化必須是 `-INF` 不是 0。**
