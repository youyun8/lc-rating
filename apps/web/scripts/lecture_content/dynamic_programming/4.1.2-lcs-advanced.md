## 這個技術解決什麼問題

進階 LCS 保留 4.1.1 的二維表格骨架，但把「什麼算對得上」換成更複雜的規則：

| 題 | 新增的東西 | 要重新論證的是 |
| --- | --- | --- |
| 44 萬用字元匹配 | `?`、`*` | **`*` 的無限枚舉如何摺疊成兩個分支**（定理 1） |
| 10 正則表達式匹配 | `x*` 是不可分割的單元 | **「用 0 次 / 用 $\ge1$ 次」的二分**（定理 2） |
| 97 交錯字串 | 三個序列 | **第三維是冗餘的**（定理 3） |
| 115 不同的子序列 | **計數** | **劃分必須嚴格**（定理 4） |
| 1092 最短公共超序列 | 要輸出方案 | **回溯需要完整表格**（定理 5） |
| 1639 依詞典構造字串 | 每列多個候選 | **同構狀態合併**（定理 6） |

**這一節的價值不在題目本身，而在六種「改造二維 DP」的手法。** 它們各自對應一個獨立的技巧：

- **摺疊自我引用**（定理 1、2）——與 3.2 完全背包用的是同一招；
- **消除冗餘維度**（定理 3）——與 2.2 摘櫻桃的 $step = i+j$ 是同一件事；
- **從最優化改計數時重做劃分**（定理 4）——4.1.1 定理 2、3 都預告過這個坑；
- **回溯輸出方案**（定理 5）；
- **合併同構的轉移來源**（定理 6）。

**辨識訊號**：仍然是「兩個（或多個）序列的保序對應」，但**其中一側帶有『一個符號可以吃掉任意多個字元』或『同一位置有多個候選』的自由度。**

## 狀態／資料結構定義

| 題 | 狀態 | 型別 | 邊界 |
| --- | --- | --- | --- |
| 44 | $f(i,j)$：`s[0..i)` 能否被 `p[0..j)` 匹配 | `bool` | $f(0,0)=$ true；$f(0,j)$ 僅當 `p[0..j)` 全是 `*` |
| 10 | 同上 | `bool` | $f(0,0)=$ true；$f(0,j) = f(0,j-2)$ 當 `p[j-1]=='*'` |
| 97 | $f(i,j)$：`s1[0..i)` 與 `s2[0..j)` 能否交錯成 `s3[0..i+j)` | `bool` | $f(0,0)=$ true |
| 115 | $f(i,j)$：`t[0..j)` 在 `s[0..i)` 中作為子序列出現的次數 | `long long` | $f(i,0)=1$、$f(0,j>0)=0$ |
| 1092 | LCS 表 + 回溯 | `int` | 同 4.1.1 |
| 1639 | $f(i,j)$：用前 $i$ 列拼出 `target[0..j)` 的方案數 | `long long`（取模） | $f(i,0)=1$ |

**115 的邊界 $f(i,0)=1$ 值得單獨說**：空字串作為子序列出現的次數是 **1**（取空的匹配），不是 0 ✘。**這一格設錯，整張表全錯。**

**10 與 44 的關鍵差異**：

- **44 的 `*` 自己就是一個單元**，可以匹配任意長度（含空）的任意字元；
- **10 的 `*` 必須跟前面那個字元綁在一起看**（`a*` 是一個單元），單獨的 `*` 沒有意義。

⇒ **44 掃 `p` 時一次走一格；10 遇到 `*` 時一次退兩格（`j-2`）。** 這個「一格 vs 兩格」是兩題所有差異的根源。

## 不變量或正確性證明

### 定理 1（44 的 `*`：把 $O(n)$ 個分支摺疊成 2 個）

*命題*：當 `p[j-1] == '*'` 時，$f(i,j) = f(i-1,j) \ \lor\ f(i,j-1)$。

*證明*。按「這個 `*` 吃掉了幾個字元」展開，得到樸素轉移

$$f(i,j) \;=\; \bigvee_{k=0}^{i} f(i-k,\; j-1).$$

（**不漏**：`*` 必吃掉 $0..i$ 個中的某個數量；**不重**：$k$ 唯一 ✔。）

現在把 $k=0$ 的項單獨拿出來：

$$f(i,j) \;=\; \underbrace{f(i,\,j-1)}_{k=0} \ \lor\ \bigvee_{k=1}^{i} f(i-k,\; j-1).$$

而對 $i-1$ 套同一個樸素式：

$$f(i-1,\,j) \;=\; \bigvee_{k'=0}^{i-1} f(i-1-k',\; j-1) \;=\; \bigvee_{k=1}^{i} f(i-k,\; j-1),$$

（換元 $k = k'+1$）——**恰好就是剩下的那一堆** ✔。代回即得 $f(i,j) = f(i,j-1) \lor f(i-1,j)$ $\square$

**這與 3.2 定理 1（完全背包）是字面上同一個手法**：

> **當「某個東西可以用任意多次」時，把「用 0 次」與「用 $\ge 1$ 次」分開；後者因為『用掉一個之後還可以再用』而能引用同一層的狀態，於是 $O(n)$ 個分支塌縮成 2 個。**

**兩個分支的直覺讀法**：$f(i,j-1)$ = **`*` 匹配空串**；$f(i-1,j)$ = **`*` 再多吃一個字元 `s[i-1]`**。

**前提**：`*` 可以匹配**任意**字元。若題目限制 `*` 只能匹配某個字元集，$f(i-1,j)$ 分支要加上 `s[i-1]` 是否在該集合內的判斷 ✔。

### 定理 2（10 的 `x*`：「用 0 次 / 用 $\ge1$ 次」的嚴格二分）

*命題*：當 `p[j-1] == '*'`（於是 `p[j-2]` 是它修飾的字元）時，

$$f(i,j) \;=\; \underbrace{f(i,\,j-2)}_{\text{`x*` 用 0 次}} \ \lor\ \underbrace{\big(\mathrm{match}(s[i-1],\, p[j-2]) \ \land\ f(i-1,\,j)\big)}_{\text{`x*` 用 } \ge 1 \text{ 次}},$$

其中 $\mathrm{match}(c, q) = (q = \texttt{'.'} \lor q = c)$。

*證明*。按「`x*` 這個單元吃掉幾個字元」劃分成 $0$ 與 $\ge 1$ 兩類——**不漏**（窮盡）、**不重**（互斥）✔。

- **用 0 次**：`x*` 整個跳過 ⇒ 模式退回 $j-2$，字串不動 ⇒ $f(i,j-2)$ ✔。
- **用 $\ge 1$ 次**：最後被吃掉的字元是 `s[i-1]`，它必須符合 `p[j-2]`；吃掉它之後 **`x*` 仍然可用**（可以繼續吃）⇒ 狀態變成 $f(i-1, j)$，**模式下標不變** ✔。

自我引用 $f(i-1,j)$ 合法，因為第一維嚴格遞減 ⇒ 依賴圖無環（2.1 定理 1）✔。$\square$

**與定理 1 的對照很有啟發性**：44 的兩個分支是**覆蓋**（`*` 匹配空 與 `*` 多吃一個，在某些情形同時成立）；10 的兩個分支是**劃分**（用 0 次 與 用 $\ge1$ 次互斥）。**兩者都取 `||` 所以都對**——**但如果哪天要數方案數，只有定理 2 的形式可以直接改成加法** ✔。

**邊界是 10 最常見的 bug**：$f(0, j)$ 必須支援 `"a*b*c*"` 這種能匹配空串的模式。

```cpp
f[0][0] = true;
for (int j = 2; j <= n; j++)  // 從 2 開始：'*' 不可能是第一個字元
    if (p[j - 1] == '*') f[0][j] = f[0][j - 2];
```

**忘記這個迴圈，`isMatch("", "a*")` 就會回傳 false** ✘。

**另一個前提要點名**：轉移假設 **`*` 前面一定有一個可修飾的字元**（即 `j >= 2`）。**這由題目的「模式合法」保證**；若不保證，要先做格式檢查，否則 `p[j-2]` 會越界 ✘。

### 定理 3（97 交錯字串：**第三維是冗餘的**）

*命題*：判斷 `s1`、`s2` 能否交錯成 `s3`，狀態只需二維 $f(i,j)$，不需要記錄「已用掉 `s3` 的多少字元」。

*證明*。**交錯的定義要求 `s1` 與 `s2` 的字元恰好用完、且順序保持** ⇒ 用掉 `s1` 的前 $i$ 個與 `s2` 的前 $j$ 個時，**恰好對應 `s3` 的前 $i+j$ 個，沒有其他可能** ✔。

即：第三維 $k$ 滿足恆等式 $k = i + j$——**它是其他兩維的函數，因此不攜帶任何資訊** ⇒ 可以刪掉 ✔。$\square$

於是轉移為

$$f(i,j) = \big(f(i-1,j) \land s_1[i-1] = s_3[i+j-1]\big) \ \lor\ \big(f(i,j-1) \land s_2[j-1] = s_3[i+j-1]\big),$$

按「`s3` 的第 $i+j$ 個字元來自哪一邊」劃分——**不漏**（必來自其一）✔。**注意這是覆蓋不是劃分**（兩邊字元相同時兩個分支都可能成立），取 `||` 無害 ✔。

**這與 2.2 定理 3（741 摘櫻桃）是同一個發現**：

> **只能往固定方向走 ⇒「走了幾步」由座標決定 ⇒ 那一維可以刪掉。**
> **一般判準：若某個狀態分量恆等於其他分量的函數，刪掉它。** 這往往是把指數狀態降成多項式的關鍵一步。

**檢查方法**：寫下狀態的定義後，**問自己「有沒有兩個分量永遠同步變化」**。有的話就寫出它們的關係式並消去 ✔。

**前置檢查**：`s1.size() + s2.size() != s3.size()` 時直接回傳 false ✔——**不判會讓 `s3[i+j-1]` 越界。**

### 定理 4（115 計數：**劃分依據要換成「位置用不用」而非「字元等不等」**）

*命題*：設 $f(i,j)$ = `t[0..j)` 在 `s[0..i)` 中作為子序列出現的次數，則

$$f(i,j) = f(i-1,\,j) \;+\; \big[\,s[i-1] = t[j-1]\,\big]\cdot f(i-1,\,j-1).$$

*證明*。**劃分依據：`s` 的第 $i$ 個字元（下標 $i-1$）在這次匹配中有沒有被用到。**

- **沒被用到**：整個匹配落在 `s[0..i-1)` 內 ⇒ 恰有 $f(i-1,j)$ 種 ✔。
- **被用到**：它必須匹配 `t` 的最後一個字元（保序 ⇒ `s` 的最後一個被用字元只能對應 `t` 的最後一個）⇒ 要求 $s[i-1]=t[j-1]$，剩下的是 `t[0..j-1)` 在 `s[0..i-1)` 中的匹配 ⇒ $f(i-1,j-1)$ 種 ✔。

兩類**互斥**（用到／沒用到）且**窮盡** ⇒ 嚴格劃分 ⇒ 可以相加 ✔。$\square$

**這條定理是 4.1.1 定理 2 那個警告的正面示範。** 對比一下：

| | 劃分依據 | 互斥？ | 可否用於計數 |
| --- | --- | --- | --- |
| 4.1.1 定理 2（LCS） | 「$s[i-1]$ 沒被用」或「$t[j-1]$ 沒被用」 | **否**（可能都沒用） | ✘ |
| 本定理（115） | 「$s[i-1]$ 被用」或「沒被用」 | **是** | ✔ |

> **把最優化 DP 改成計數 DP 時，不是把 `max` 換成 `+` 就好——要先找到一個「互斥且窮盡」的劃分依據。**
> **好用的依據通常是「某個具體位置的二值決策」，而不是「兩個位置的比較結果」。**

**重複字元不會出錯**：劃分依據是**位置**而非**字元值**，所以 `s = "bbb"`、`t = "bb"` 會正確得到 3（$\binom{3}{2}$）✔——**三個 `b` 是三個不同的位置。**

**溢位**：LeetCode 115 保證答案落在 32 位範圍內，**但中間值不保證** ⇒ 用 `long long`（或 `unsigned`／取模，依題目）✔。

**滾動**：只依賴上一行 ⇒ 一維 + **倒序**掃 $j$（要讀上一行的 `g[j-1]`，2.1 定理 2）✔。

### 定理 5（1092 最短公共超序列：長度公式 + 回溯構造）

*命題 (a)*：最短公共超序列（SCS）的長度為 $m + n - \mathrm{LCS}(s,t)$。

*證明*。
- **($\le$)** 依 LCS 對齊，把公共部分寫一次、其餘各自插入 ⇒ 長度 $= \mathrm{LCS} + (m-\mathrm{LCS}) + (n-\mathrm{LCS}) = m+n-\mathrm{LCS}$ ✔。
- **($\ge$)** 設 $U$ 是任一公共超序列，固定 $s$、$t$ 在 $U$ 中的一組嵌入（各自的下標遞增序列 $A$、$B$）。$|U| \ge |A \cup B| = m + n - |A \cap B|$；而 **$A\cap B$ 對應的字元同時是 $s$ 與 $t$ 的子序列**（保序）⇒ $|A\cap B| \le \mathrm{LCS}$ ⇒ $|U| \ge m+n-\mathrm{LCS}$ ✔。$\square$

**這與 4.1.1 定理 4（583 刪除距離）是對偶的一組**：一個是「刪到相同」，一個是「補到相同」，**兩者都以 LCS 為樞紐。**

*命題 (b)*：要輸出方案，必須保留完整的 $O(mn)$ LCS 表。

*理由*。回溯的每一步都要比較 $f(i-1,j)$ 與 $f(i,j-1)$ 以決定往哪走 ⇒ **滾動陣列丟掉的正是這些歷史值** ✘。

**回溯的標準寫法**（從右下角往左上角走，結果反轉）：

```cpp
string scs(const string& s, const string& t, const vector<vector<int>>& f) {
    string res;
    int i = (int)s.size(), j = (int)t.size();
    while (i > 0 && j > 0) {
        if (s[i - 1] == t[j - 1]) {
            res += s[--i];
            --j;
        }  // 公共字元寫一次
        else if (f[i - 1][j] >= f[i][j - 1])
            res += s[--i];  // 走 s 這邊
        else
            res += t[--j];
    }
    while (i > 0) res += s[--i];
    while (j > 0) res += t[--j];
    reverse(res.begin(), res.end());
    return res;
}
```

**回溯時的判斷必須與建表時的取捨一致**——`>=` 換成 `>` 會得到另一個同樣合法的答案，**但如果建表用 `max` 而回溯用了不相容的比較，就會走到非最優路徑** ✘。**保險做法是回溯時直接檢查「這一步是否還原了 $f(i,j)$ 的值」。**

**空間下不去時**：Hirschberg 分治可在 $O(\min(m,n))$ 空間內輸出方案，代價是常數翻倍（4.1.1 已提及）。

### 定理 6（1639：把「選哪個單詞」摺疊成「該列有幾個字元 $c$」）

*設定*：`words` 中所有單詞等長（記長度 $L$）；從左到右挑選字元，**每次選的列下標必須嚴格遞增**，且**同一列只能貢獻一個字元**，問拼出 `target` 的方案數。

*命題*：不需要枚舉「用了哪個單詞」，只需預處理

$$\mathit{cnt}[i][c] = \#\{\,w \in \mathit{words} : w[i] = c\,\},$$

轉移為

$$f(i+1,\, j+1) \mathrel{+}= f(i,j)\cdot \mathit{cnt}[i][\mathit{target}[j]], \qquad f(i+1,\,j) \mathrel{+}= f(i,j).$$

*證明*。**兩個單詞若在第 $i$ 列的字元相同，則它們對「從第 $i$ 列取一個字元」這件事的貢獻完全相同**——**因為題目允許不同位置取自不同單詞，各次選擇之間沒有任何約束把它們綁在一起** ✔。

於是「選 $w$ 的第 $i$ 個字元」這些方案彼此**同構**，只需按字元值歸類、乘上該類的大小 ⇒ 從 $O(|\mathit{words}|)$ 個分支降成 $O(1)$ ✔。

劃分依據是「第 $i$ 列有沒有被使用」——**互斥且窮盡** ⇒ 相加合法（定理 4 的判準）✔。$\square$

**這條定理依賴的前提必須點名**：**不同位置的選擇互相獨立。** 若題目改成「所有字元必須取自同一個單詞」，同構性立刻消失 ✘——那時 $\mathit{cnt}$ 丟掉的「來自哪個單詞」資訊變得關鍵。

**複雜度**：預處理 $O(|\mathit{words}| \cdot L)$，DP $O(L \cdot |\mathit{target}|)$——**與單詞數量無關** ✔。這是本題從 TLE 變 AC 的全部原因。

> **通用手法：當多個轉移來源在「未來」看來完全等價時，把它們合併成一個帶權的轉移。**
> **檢驗方法：問「交換這兩個來源，後續的可行集與收益會不會改變」**——不變就能合併（這正是無後效性檢查的另一種用法，1.1 定理 4）。

## 時間與空間複雜度

| 題 | 時間 | 空間 | 備註 |
| --- | --- | --- | --- |
| 44 萬用字元 | $O(mn)$ | $O(n)$ 滾動 | 貪心雙指標可做到 $O(m+n)$ 時間、$O(1)$ 空間 |
| 10 正則 | $O(mn)$ | $O(n)$ 滾動 | `*` 分支要讀 $f(i-1,j)$ ⇒ 滾動時注意順序 |
| 97 交錯字串 | $O(mn)$ | $O(n)$ 滾動 | 先判長度和 |
| 115 不同子序列 | $O(mn)$ | $O(n)$ 滾動（**倒序**） | 中間值用 `long long` |
| 1092 SCS | $O(mn)$ | $O(mn)$ | **要輸出方案 ⇒ 不能滾動** |
| 1639 | $O(L\cdot|\mathit{target}| + |\mathit{words}|\cdot L)$ | $O(L\cdot 26)$ | **與單詞數無關** |

**44 的線性解法值得一提**：用雙指標 + 記錄「最後一個 `*` 的位置」做回溯式匹配，$O(m+n)$ 平均、最壞 $O(mn)$。**它比 DP 快但難證明；面試若被追問，DP 版本的正確性好說明得多。**

**滾動時的方向再整理一次**（全部由 2.1 定理 2 推出）：

| 轉移依賴 | 滾動方向 |
| --- | --- |
| 只依賴上一行同列 / 左上角 | 倒序（115、718） |
| 依賴上一行 + 本行左邊 | 正序 + `prev` 變數（LCS、97） |
| 依賴上一行同列（自我引用 $f(i-1,j)$，10 的 `*`） | **正序**，因為要讀「本行已算好的左邊」與「上一行同列」——**寫之前先確認每個來源屬於哪一輪** |

**與其背表，不如每次動手標註**：在轉移式的每個 $f(\cdot,\cdot)$ 旁邊寫上「上一輪／本輪」，方向自然就定了 ✔。

## 與相似技巧的比較

- **與 4.1.1**：骨架相同（二維前綴表、$O(mn)$）。**進階題改的是「分支怎麼劃分」，不是狀態怎麼定義。** 每遇到一個新規則，先問：**分支窮盡嗎？互斥嗎？** 前者決定正確性，後者決定能不能拿來計數。
- **與 3.2 完全背包**：定理 1 的摺疊與完全背包的「$0$ / $\ge1$ 二分」是同一個定理的兩個外衣。**看到「某物可用任意多次」，就找這個摺疊。**
- **與 2.2 摘櫻桃**：定理 3 的維度消除與那裡的 $step = i+j$ 是同一個發現。
- **與 5 章劃分型 DP**：1639 的「從左到右、列下標遞增」也可以看成劃分型；**但劃分型的分段是連續的，這裡是可跳過的** ⇒ 轉移形狀不同（劃分型枚舉段長 $O(n)$ 分支，這裡只有 2 個分支）。
- **與自動機（KMP / AC 自動機）**：10 與 44 本質上是「把模式編譯成 NFA，再對輸入做子集構造」。**DP 表格 $f(i,j)$ 就是「讀完 `s` 的前 $i$ 個字元後，NFA 是否可能停在狀態 $j$」** ✔。這個視角讓 `*` 的兩個分支變得顯然（$\varepsilon$-轉移 + 自環）。**多模式匹配時值得改用 AC 自動機。**
- **與計數 DP 的一般原則**：115 與 1639 都是計數型，**它們的共同點是「劃分依據都選在某個具體位置的二值決策上」**。**這是設計計數 DP 時第一個該試的角度。**

## 本節重點速查

- **定理 1（44）**：`*` 的 $O(n)$ 枚舉摺疊成 $f(i,j) = f(i,j-1) \lor f(i-1,j)$（匹配空 / 再多吃一個）。**與 3.2 完全背包同一招。**
- **定理 2（10）**：`x*` 是一個單元 ⇒ **「用 0 次」退兩格 $f(i,j-2)$，「用 $\ge1$ 次」自我引用 $f(i-1,j)$**。**這是嚴格劃分（44 的則是覆蓋）。邊界 $f(0,j)=f(0,j-2)$ 的迴圈千萬別漏，否則 `isMatch("", "a*")` 就錯。**
- **定理 3（97）**：**$k = i+j$ 恆成立 ⇒ 第三維冗餘，刪掉。** 通用判準：**某分量是其他分量的函數就消去它。** 先判長度和，否則越界。
- **定理 4（115）**：計數型的劃分依據要選「**`s` 的最後一個位置用不用**」（互斥窮盡），**不能用 LCS 那種「誰沒被用」的覆蓋式分支**。$f(i,0)=1$（空串出現 1 次）。位置而非字元值當依據 ⇒ 重複字元自動正確。
- **定理 5（1092）**：$|\mathrm{SCS}| = m+n-\mathrm{LCS}$，與 583 對偶。**要輸出方案就不能滾動**；回溯的比較方向必須與建表一致。
- **定理 6（1639）**：**同一列中字元相同的單詞對未來完全等價 ⇒ 合併成 $\mathit{cnt}[i][c]$**，複雜度與單詞數脫鉤。**前提是不同位置的選擇互相獨立**——改成「必須同一個單詞」就失效。
- **貫穿全節的一句話**：**分支要窮盡（正確性），且若要計數則必須互斥（可加性）。** 每寫一個新轉移，就把這兩句話對照一遍。
