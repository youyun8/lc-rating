## 這個技術解決什麼問題

LIS 處理「**單一序列**上的保序選取」：

> **從一個序列中挑出一個子序列，使它滿足某種單調性，並最佳化長度或其他目標。**

**它與 4.1 LCS 的分工很清楚**：LCS 是兩個序列的對齊，LIS 是一個序列的內部結構。

| 題 | 要求 | 化歸 |
| --- | --- | --- |
| 300 最長遞增子序列 | 嚴格遞增、最長 | 模板 |
| 334 遞增的三元子序列 | 存在長度 $\ge 3$ 的遞增子序列 | **LIS 的前兩格**（定理 4） |
| 1964 找出到每個位置為止最長的有效障礙賽跑路線 | 每個前綴的最長**非遞減**子序列 | **貪心陣列的即時長度**（推論 2.2） |
| 1671 得到山形陣列的最少刪除次數 | 最長「先增後減」 | 前綴 LIS + 後綴 LDS（定理 5） |
| 2111 使陣列 K 遞增的最少操作次數 | 每個同餘類非遞減 | **$k$ 組獨立，每組 $\mathrm{len} - \mathrm{LNDS}$**（定理 6） |
| 2826 將三個組排序 | 整體非遞減的最少刪除 | $n - \mathrm{LNDS}$（定理 6 的推論） |

**本節真正要理解的只有一件事：$O(n\log n)$ 的貪心陣列為什麼對。**

**這個演算法幾乎人人會寫，但能說清楚 `tails` 陣列語意的人不多**——而且有一個非常常見的誤解（`tails` 本身**不是**一個合法的子序列，定理 2）。**把不變量寫清楚，這一節就通了。**

**辨識訊號**：
- 單一序列 + 「遞增／遞減／非遞減」；
- **「最少刪除幾個使其單調」** ⇒ $n - \mathrm{LIS}$（定理 6）；
- **「最少修改幾個使其單調」** ⇒ 也是 $n - \mathrm{LIS}$，但要驗證值域夠寬（定理 6）。

## 狀態／資料結構定義

**寫法 A：$O(n^2)$ DP**

$$f(i) = \text{以 } a_i \text{ 結尾的最長遞增子序列長度},\qquad f(i) = 1 + \max_{\substack{j < i \\ a_j < a_i}} f(j),$$

答案為 $\max_i f(i)$。**「釘住結尾」的理由與 1.3、4.1.1 定理 6 相同：只有固定右端點，「能不能接上去」才判斷得了。**

**寫法 B：$O(n\log n)$ 貪心 + 二分**

維護陣列 `tails`，語意是：

$$\mathit{tails}[k] = \text{所有長度為 } k+1 \text{ 的遞增子序列中，\textbf{最小的結尾值}}$$

```cpp
// 嚴格遞增（LIS）
vector<int> tails;
for (int x : a) {
    auto it = lower_bound(tails.begin(), tails.end(), x);  // 第一個 >= x
    if (it == tails.end())
        tails.push_back(x);
    else
        *it = x;
}
int lis = (int)tails.size();
```

**嚴格與非嚴格只差一個函式**（定理 3）：

| 目標 | 二分函式 | 找的是 |
| --- | --- | --- |
| 嚴格遞增（LIS） | `lower_bound` | 第一個 $\ge x$ 的位置 |
| **非遞減**（LNDS） | `upper_bound` | 第一個 $> x$ 的位置 |
| 嚴格遞減 | 對 `-a[i]` 求 LIS | — |
| 非遞增 | 對 `-a[i]` 求 LNDS | — |

**把遞減轉成遞增時取相反數（而不是反轉陣列），可以少寫一份程式碼、也不會弄錯嚴格性** ✔。

## 不變量或正確性證明

### 定理 1（$O(n^2)$ 版本的正確性）

*命題*：$f(i) = 1 + \max\{f(j) : j < i,\ a_j < a_i\}$（空集時取 0）。

*證明*。按「以 $a_i$ 結尾的最優子序列中，$a_i$ 的前一個元素是誰」劃分：**不漏**（要嘛沒有前驅，要嘛是某個唯一的 $j$）、**不重**（$j$ 唯一）✔。前驅為 $j$ 時，前面那一段必是「以 $a_j$ 結尾的遞增子序列」，剪貼論證得等號 ✔。$\square$

**注意 $f(i)$ 的定義要求「以 $a_i$ 結尾」，所以答案是 $\max_i f(i)$ 而不是 $f(n-1)$** ✔——**這是釘住端點的狀態定義的標準代價。**

### 定理 2（**貪心陣列的兩個不變量**）

*命題*：上述迴圈執行完任意前綴 $a_0..a_{i-1}$ 後，`tails` 滿足

- **(I1)** `tails` 嚴格遞增；
- **(I2)** 對每個 $k$，$\mathit{tails}[k]$ **等於**「$a_0..a_{i-1}$ 中所有長度為 $k+1$ 的遞增子序列的最小結尾值」；且長度 $> |\mathit{tails}|$ 的遞增子序列不存在。

*證明*。對 $i$ 做歸納。$i=0$ 時 `tails` 為空，兩者平凡成立 ✔。

設處理 $a_i = x$ 之前 (I1)(I2) 成立，令 $p$ = 第一個滿足 $\mathit{tails}[p] \ge x$ 的下標（`lower_bound`）。

**先證 (I2) 對 $k=p$ 成立（即賦值 $\mathit{tails}[p] \leftarrow x$ 正確）。**

- **(可達性)** 若 $p = 0$，$x$ 自己就是長度 1 的遞增子序列 ✔。若 $p > 0$，由 $p$ 的定義 $\mathit{tails}[p-1] < x$；由歸納假設存在一個長度為 $p$、結尾為 $\mathit{tails}[p-1]$ 的遞增子序列，**它整個落在 $a_0..a_{i-1}$ 中（下標都 $< i$）** ⇒ 接上 $x$ 得到長度 $p+1$、結尾 $x$ 的遞增子序列 ✔。
- **(最小性)** 新加入的元素只有 $x$，所以「長度 $p+1$ 的子序列」要嘛是舊的（最小結尾為舊的 $\mathit{tails}[p] \ge x$），要嘛以 $x$ 結尾 ⇒ 新的最小值就是 $x$ ✔。

**再證其他位置不變。** 對 $k < p$：$\mathit{tails}[k] < x$，加入 $x$ 不會產生更小的長度 $k+1$ 結尾 ✔。對 $k > p$：以 $x$ 結尾的子序列最長只有 $p+1$（否則 $p$ 的定義矛盾）⇒ 不影響 ✔。

**(I1) 的維持**：賦值後 $\mathit{tails}[p-1] < x \le$ 舊的 $\mathit{tails}[p] < \mathit{tails}[p+1]$ ⇒ 嚴格遞增保持 ✔。（$p = |\mathit{tails}|$ 時是 `push_back`，由 $\mathit{tails}[p-1] < x$ 得證 ✔。）

**最後**：由 (I2)，$|\mathit{tails}|$ 就是最大可達長度 = LIS ✔。$\square$

**（I1）其實是（I2）的推論**：長度越長，最小結尾越大——因為長度 $k+1$ 的子序列去掉最後一個就是長度 $k$ 的，結尾更小 ✔。**但把它單獨列出來很有用，因為二分搜尋的正確性依賴它。**

**最重要的一句話——`tails` 本身通常不是原序列的子序列**：

> **反例**：$a = [3, 4, 1]$。過程：`[3]` → `[3,4]` → `[1,4]`。
> 最終 `tails = [1,4]`，但原序列中 `1` 出現在 `4` **之後** ⇒ `[1,4]` 根本不是 $a$ 的子序列 ✘。
> **`tails` 只保證「長度正確」，不保證「內容是一個合法解」。**

**⇒ 要輸出方案就不能只靠 `tails`**：必須額外記錄每個元素被放進的下標 $p_i$（= 以它結尾的 LIS 長度 $-1$）與前驅指標，最後回溯 ✔。

**推論 2.1（每個元素的貢獻）**：處理 $a_i$ 時得到的下標 $p$ 滿足 $p + 1 = $「以 $a_i$ 結尾的 LIS 長度」——**這正是 $O(n^2)$ 版本的 $f(i)$，只是用 $O(\log n)$ 算出來** ✔。

**推論 2.2（1964）**：因為 `tails` 是**線上**維護的（處理到第 $i$ 個時，它反映的就是前綴 $a_0..a_i$ 的狀態），**每一步直接輸出 $p+1$ 就是該位置的答案**，不需要重跑 ✔。**1964 求的是非遞減 ⇒ 用 `upper_bound`。**

### 定理 3（嚴格 vs 非嚴格：為什麼只差一個 `lower`/`upper`）

*命題*：把 `lower_bound` 換成 `upper_bound`，演算法求的就是最長**非遞減**子序列（LNDS）。

*證明*。重跑定理 2 的歸納，唯一改變的是「$x$ 能接在哪些結尾之後」：

- 嚴格遞增要求前驅 $< x$ ⇒ 要找**最後一個 $< x$ 的位置**，其後一格就是第一個 $\ge x$ ⇒ `lower_bound` ✔。
- 非遞減允許前驅 $\le x$ ⇒ 要找**最後一個 $\le x$ 的位置**，其後一格就是第一個 $> x$ ⇒ `upper_bound` ✔。

其餘論證（可達性、最小性、不變量維持）逐字相同 ✔。$\square$

**注意此時 (I1) 弱化為「非嚴格遞增」**：`tails` 中可以出現相同的值（例如 $a = [1,1,1]$ ⇒ `tails = [1,1,1]`）✔。**二分仍然正確，因為 `upper_bound` 對有重複的非遞減序列一樣有定義。**

**檢驗方法**：拿 $a = [2,2,2]$ 跑一遍。**嚴格版應得 1，非嚴格版應得 3。** 這個三元素測資能立刻抓出用錯函式 ✔。

### 定理 4（334 = LIS 的前兩格）

*命題*：以下 $O(1)$ 空間演算法正確判斷「是否存在長度 $\ge 3$ 的嚴格遞增子序列」：

```cpp
int first = INT_MAX, second = INT_MAX;
for (int x : nums) {
    if (x <= first)
        first = x;  // 更新 tails[0]
    else if (x <= second)
        second = x;  // 更新 tails[1]
    else
        return true;  // 要 push 到 tails[2] 了
}
return false;
```

*證明*。把它與定理 2 的迴圈逐行對照：`first` = $\mathit{tails}[0]$、`second` = $\mathit{tails}[1]$（未填時為 $+\infty$）。

`lower_bound` 在只有兩格時的結果只有三種：$p=0$（$x \le \mathit{tails}[0]$）、$p=1$（$\mathit{tails}[0] < x \le \mathit{tails}[1]$）、$p=2$（$x > \mathit{tails}[1]$）——**恰好對應三個分支** ✔。而 $p = 2$ 意味著 `tails` 將成長到長度 3 ⇒ LIS $\ge 3$ ✔。$\square$

**這個對照有兩個好處**：
- **不用另外記憶 334 的解法**——它就是 LIS 截斷到兩格；
- **解釋了那個令人困惑的 `second` 已被更新但 `first` 更小的情形**（例如 $[3,4,1,5]$，處理完 `1` 後 `first=1, second=4`，`[1,4]` 不是子序列——**但這不影響答案**，理由完全同定理 2 的反例討論：**只有長度是可信的** ✔）。

**這正是初學者對 334 最大的疑惑點**，而它在 LIS 的框架下是一句話的推論。

### 定理 5（1671 山形：兩側都必須 $\ge 2$）

*命題*：設 $\mathrm{pre}(i)$ = 以 $a_i$ 結尾的最長嚴格遞增子序列長度，$\mathrm{suf}(i)$ = 以 $a_i$ 開頭的最長嚴格遞減子序列長度，則最長山形子序列長度為

$$\max_{\substack{i:\ \mathrm{pre}(i)\ \ge\ 2 \ \land\ \mathrm{suf}(i)\ \ge\ 2}} \big(\mathrm{pre}(i) + \mathrm{suf}(i) - 1\big),$$

答案（最少刪除數）為 $n$ 減去它。

*證明*。
- **($\ge$)** 給定滿足條件的 $i$，把「以 $a_i$ 結尾的最長遞增」與「以 $a_i$ 開頭的最長遞減」拼起來，$a_i$ 被算了兩次故減 1；兩段的下標分別 $\le i$ 與 $\ge i$ ⇒ 拼接後仍是子序列 ✔；由 $\mathrm{pre},\mathrm{suf}\ge2$ 知峰左右各至少一個元素 ⇒ 是合法山形 ✔。
- **($\le$)** 任一山形子序列有唯一峰值位置 $i$（**唯一因為嚴格單調**）⇒ 其左半是「以 $a_i$ 結尾的遞增」、右半是「以 $a_i$ 開頭的遞減」⇒ 長度不超過 $\mathrm{pre}(i)+\mathrm{suf}(i)-1$ ✔。$\square$

**兩個 $\ge 2$ 的條件是本題唯一的陷阱**：題目定義的山形陣列**必須有嚴格上升段和嚴格下降段**，峰不能在端點。**漏掉這個條件，$[1,2,3]$ 會被誤判成合法山形（長度 3），答案就錯了** ✘。

**「嚴格」在證明的 ($\le$) 方向被用到**：若允許非嚴格，峰值可能是一段平台 ⇒ 峰位置不唯一 ⇒ 上述劃分不再是良定義的 ✘（雖然取 max 仍是覆蓋，不會算錯，但論證要改寫）。

**實作**：正著跑一遍 LIS 記 $\mathrm{pre}$，倒著跑一遍 LIS（對反轉後的序列）記 $\mathrm{suf}$，$O(n\log n)$ ✔。

### 定理 6（「最少刪除／修改使其單調」= $n - \mathrm{LIS}$）

*命題 (a)（刪除版，2826）*：使序列非遞減所需的**最少刪除數**為 $n - \mathrm{LNDS}$。

*證明*。刪除後剩下的元素構成一個非遞減子序列 ⇒ 剩下的個數 $\le \mathrm{LNDS}$ ⇒ 刪除數 $\ge n - \mathrm{LNDS}$ ✔；反之保留一個最長非遞減子序列即可達到 ✔。$\square$

*命題 (b)（修改版，2111 的單組情形）*：把序列改成非遞減所需的**最少修改數**也是 $n - \mathrm{LNDS}$，**前提是值域足夠寬**。

*證明*。
- **($\ge$)** 任一修改方案中，**未被修改的元素必須構成一個非遞減子序列**（它們的相對順序與值都沒變，而最終序列非遞減）⇒ 未修改數 $\le \mathrm{LNDS}$ ⇒ 修改數 $\ge n - \mathrm{LNDS}$ ✔。
- **($\le$)** 保留一個最長非遞減子序列，**其餘位置各自改成「左邊最近的保留元素的值」**（最左段改成第一個保留元素的值）⇒ 整體非遞減 ✔。$\square$

**($\le$) 方向依賴的前提必須點名**：
- **允許相等**（因為填的是重複值）⇒ **對「嚴格遞增」的版本這個構造失效** ✘，那時要檢查值域是否夠塞下嚴格遞增的間隔；
- **填入的值在合法值域內**——這裡填的是原本就存在的值，所以自動合法 ✔。

> **「最少修改使嚴格遞增」的正確做法**：令 $b_i = a_i - i$，則「$a$ 嚴格遞增」$\iff$「$b$ 非遞減」⇒ 答案 $= n - \mathrm{LNDS}(b)$ ✔。**這個 $-i$ 的位移是嚴格／非嚴格轉換的標準技巧**，但它同樣依賴值域無下界限制（若要求 $a_i \ge 1$，還要額外檢查）。

*命題 (c)（2111 的分組）*：K 遞增的約束「$\forall i,\ a_i \le a_{i+k}$」把下標按 $i \bmod k$ 分成 $k$ 組，**組與組之間沒有任何約束** ⇒ 各組獨立求命題 (b)，答案相加 ✔。

*證明*。約束只出現在下標差為 $k$ 的配對之間 ⇒ 同餘類內部封閉 ⇒ 修改一組不影響另一組的可行性 ✔。各組取最少修改數，總和即為全域最少 ✔。$\square$

**複雜度**：$k$ 組的總長度是 $n$，每組 $O(\mathrm{len}\log \mathrm{len})$ ⇒ **總計 $O(n\log n)$，與 $k$ 無關** ✔。

## 時間與空間複雜度

| 題 | 時間 | 空間 |
| --- | --- | --- |
| 300（$O(n^2)$ / 貪心） | $O(n^2)$ / $O(n\log n)$ | $O(n)$ |
| 334 | $O(n)$ | $O(1)$ |
| 1964 | $O(n\log n)$ | $O(n)$ |
| 1671 | $O(n\log n)$ | $O(n)$ |
| 2111 | $O(n\log n)$ | $O(n)$ |
| 2826 | $O(n\log n)$ | $O(n)$ |

**$O(n^2)$ 何時反而該用**：
- $n \le 1000$ 且要**輸出方案**（$O(n^2)$ 版本回溯很直觀）；
- 轉移條件不只是「$a_j < a_i$」（例如 354 俄羅斯套娃要二維偏序）⇒ **貪心陣列的不變量 (I2) 依賴全序，偏序時要改用樹狀陣列**（4.2.2）。

**輸出方案的做法（貪心版）**：記錄每個元素的 $p_i$ 與「當時 $\mathit{tails}[p_i-1]$ 對應的元素下標」作為前驅，最後從最大的 $p_i$ 回溯 ✔。**不要試圖直接輸出 `tails`**（定理 2 的反例）。

**二分的常數**：`lower_bound` 在 `vector<int>` 上是連續記憶體、快取友善，實測比手寫二分還快。**$n \le 10^5$ 時 $O(n\log n)$ 幾乎瞬間完成。**

**2826 / 2111 的特例**：2826 的值只有 1、2、3 ⇒ **可以用 $O(1)$ 個狀態的線性 DP**（$f[v]$ = 結尾值為 $v$ 的最長非遞減長度），$O(n)$ 時間 ✔。**值域極小時，「按值域開狀態」通常比通用 LIS 更快也更好寫。**

## 與相似技巧的比較

- **與 4.1 LCS**：LCS 是兩序列對齊、$O(mn)$；LIS 是單序列、$O(n\log n)$。**橋樑：當一個序列元素互異時，$\mathrm{LCS}(s,t) = \mathrm{LIS}$（把 $t$ 的每個元素換成它在 $s$ 中的位置）** ✔。**前提「互異」不能少**——有重複時位置不唯一，需改成「位置列表倒序展開」的技巧。
- **與 4.2.2 LIS 進階**：進階節處理**二維偏序**（354）、**計數**（673）、**帶權**（2407 等）。**共同點是貪心陣列的不變量 (I2) 不再夠用**，要換成樹狀陣列或線段樹上的 DP。
- **與貪心**：LIS 的 $O(n\log n)$ 演算法**是貪心 + DP 的混合**——貪心地讓每個長度的結尾盡量小，正確性由 (I2) 這個交換論證式的不變量保證。**它是「用貪心維護 DP 值」這一類演算法的最佳入門例子。**
- **與樹狀陣列**：$f(i) = 1 + \max_{j<i,\,a_j<a_i} f(j)$ 是一個「前綴最大值查詢」⇒ **值域離散化後用樹狀陣列維護前綴 max，也是 $O(n\log n)$** ✔。**這個寫法比貪心陣列慢一點，但它能自然推廣到帶權、計數、二維的版本**（4.2.2）⇒ **值得優先掌握，因為它的適用面更廣。**
- **與 Dilworth 定理**：「最少用幾個非遞增序列覆蓋整個序列」= LIS 長度（Dilworth 定理在此偏序上的形式）。**這在「最少發射系統攔截導彈」一類題目裡是直接的化歸**；本節只引用，不證明。
- **與耐心排序（patience sorting）**：貪心陣列就是耐心排序的牌堆頂集合。**這個牌堆的物理意義正好解釋了 (I2)：每堆頂端是該長度下最小的結尾。**

## 例題與分級練習

**延伸閱讀**：[最長遞增子序列影片講解](https://www.bilibili.com/video/BV1ub411Q7sB/)，重點是 `tails[len]` 的不變量，而不是把 `tails` 誤認成實際子序列。

## 本節重點速查

- **兩種寫法**：$O(n^2)$ 的 $f(i)$（釘住結尾，答案取全域 max）；$O(n\log n)$ 的貪心陣列。
- **定理 2（核心）**：$\mathit{tails}[k]$ = **長度 $k+1$ 的遞增子序列中最小的結尾值**。歸納證明可達性 + 最小性，(I1) 嚴格遞增是 (I2) 的推論。
- **最大誤解**：**`tails` 本身通常不是原序列的子序列。** 反例 $[3,4,1] \Rightarrow$ `[1,4]` ✘。**它只保證長度正確；要輸出方案必須另記前驅。**
- **推論 2.1 / 2.2**：處理 $a_i$ 得到的下標 $p$ 就是「以 $a_i$ 結尾的 LIS 長度 $-1$」⇒ **1964 每步直接輸出即可，不必重跑。**
- **定理 3**：嚴格用 `lower_bound`、非遞減用 `upper_bound`。**測資 $[2,2,2]$：嚴格得 1、非嚴格得 3。** 遞減版對 $-a_i$ 求解。
- **定理 4（334）**：就是 `tails` 只留兩格。**`first`/`second` 可能不構成真子序列，但不影響答案**——理由與定理 2 的反例相同。
- **定理 5（1671）**：$\max_i(\mathrm{pre}(i)+\mathrm{suf}(i)-1)$，**必須加上 $\mathrm{pre}(i)\ge2$ 且 $\mathrm{suf}(i)\ge2$**（峰不能在端點）。
- **定理 6**：最少刪除 = 最少修改 = $n - \mathrm{LNDS}$。**修改版的 ($\le$) 方向靠「填成左邊最近保留元素的值」，因此依賴「允許相等」；要嚴格遞增就先做 $b_i = a_i - i$ 的位移。** 2111 按 $i \bmod k$ 分組獨立求解，總複雜度與 $k$ 無關。
- **值域極小時**（2826 只有 1/2/3）**直接按值域開狀態，$O(n)$ 解決。**
