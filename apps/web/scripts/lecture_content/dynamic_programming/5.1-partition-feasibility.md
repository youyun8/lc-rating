## 這個技術解決什麼問題

劃分型 DP 處理這種問題：

> **把一個序列切成若干**連續**的段，每段各自要滿足某個條件，問「能不能切」「最少切幾段」「有幾種切法」。**

**本節只做最單純的「能不能」（布林版），但它的骨架就是整個第 5 章的骨架**：

$$f(i) = \bigvee_{\substack{j\ <\ i \\ \mathrm{valid}(j,\,i)}} f(j), \qquad f(0) = \text{true}.$$

**這個式子的三個要素，決定了後面所有變化**：

| 要素 | 5.1（本節） | 5.2 最優劃分 | 5.3 約束劃分個數 |
| --- | --- | --- | --- |
| 合併運算 | $\lor$ | $\min$ / $\max$ | $\min$ / $\max$ |
| 每段的貢獻 | （無） | $\mathrm{cost}(j,i)$ | $\mathrm{cost}(j,i)$ |
| 額外維度 | 無 | 無 | **段數 $k$** |

**看穿這一點，第 5 章就只有一個模型**（定理 6 把它講成半環的語言）。

**本節真正的技術重點只有兩個**：

1. **轉移的分支數 = 「最後一段的可能長度數」**（定理 2）。段長有界 ⇒ $O(n)$；無界 ⇒ $O(n^2)$。
2. **記憶化不是常數優化，是把指數降成多項式**（定理 4，有具體的 Fibonacci 論證）。

**辨識訊號**：
- 「能否**拆分**／**劃分**成若干部分」；
- **每段獨立地判斷合法性**，段與段之間沒有耦合；
- **最後一段的長度有明確上界**（2369 是 2 或 3、139 是字典中最長單詞的長度）⇒ 線性時間。

## 狀態／資料結構定義

$$f(i) = \big[\ s[0..i)\ \text{可以被合法劃分}\ \big],\qquad f(0) = \text{true}.$$

**下標約定**：$f$ 的下標是**長度**（$0..n$），$f(0)$ 表示空前綴，恆為 true。**「空前綴合法」不是慣例而是必需**——它是所有轉移的起點 ✔。

| 題 | $\mathrm{valid}(j, i)$ | 最後一段的可能長度 |
| --- | --- | --- |
| 139 單詞拆分 | `s.substr(j, i-j)` 在字典中 | $1 \dots L_{\max}$ |
| 2369 有效劃分 | 長度 2 且兩數相等；或長度 3 且三數相等；或長度 3 且連續遞增（差 1） | $\{2, 3\}$ |

**139 的字典要存成 `unordered_set<string>`，並額外記錄最長單詞長度 $L_{\max}$**：轉移時只回看 $L_{\max}$ 格，而不是整個前綴 ✔（定理 2）。

**2369 的三個合法段判斷**（直接寫成小函式，避免在轉移裡塞一長串條件）：

```cpp
auto ok2 = [&](int j) { return a[j] == a[j + 1]; };
auto ok3 = [&](int j) {
    bool same = (a[j] == a[j + 1] && a[j + 1] == a[j + 2]);
    bool inc = (a[j + 1] == a[j] + 1 && a[j + 2] == a[j + 1] + 1);
    return same || inc;
};
```

## 不變量或正確性證明

### 定理 1（劃分型轉移的正確性）

*命題*：$f(i) = \bigvee_{j<i,\ \mathrm{valid}(j,i)} f(j)$，其中 $f(0) = \text{true}$。

*證明*。按「**最後一段的起點 $j$**」劃分所有合法劃分方案：
- **不漏**：任一合法劃分至少有一段（$i>0$ 時），最後一段的起點是唯一確定的 $j$ ✔；
- **不重**：不同的 $j$ 對應不同的劃分 ✔。

給定 $j$，這個劃分合法 $\iff$ 最後一段 $s[j..i)$ 合法（即 $\mathrm{valid}(j,i)$）**且**前綴 $s[0..j)$ 可劃分（即 $f(j)$）——**兩個條件互相獨立**，因為**段與段之間沒有耦合** ✔。$\square$

**「段間無耦合」這個前提必須點名**，它是整章的基石：

> **若某段的合法性取決於前一段的內容**（例如「相鄰兩段的和必須遞增」）**，$f(i)$ 這個一維狀態就不完整了** ✘——必須把「上一段的特徵」加進狀態（這正是 5.2 的部分題目與 6 章狀態機 DP 在做的事）。

**檢查方法**（1.1 定理 4 的無後效性檢查）：**構造兩種到達「前 $i$ 個都合法劃分」的方式，看它們對「第 $i$ 個位置之後」的可行性有沒有差別。** 沒有差別 ⇒ 一維狀態夠用 ✔。

### 定理 2（**分支數 = 最後一段的可能長度數**）

*命題*：轉移的時間複雜度為 $O\big(\sum_i |\{\text{最後一段的合法長度}\}| \cdot \mathrm{cost}(\mathrm{valid})\big)$。

*證明*。定理 1 的 $\bigvee$ 對每個可能的最後段長各展開一項 ✔。$\square$

**這條看似平凡的觀察，是本節唯一的優化槓桿**：

| 題 | 段長範圍 | 複雜度 |
| --- | --- | --- |
| 2369 | $\{2,3\}$ ⇒ **2 個分支** | $O(n)$ |
| 139 | $1..L_{\max}$ ⇒ $L_{\max}$ 個分支 | $O(n L_{\max} \cdot \mathrm{cost})$ |
| 一般（無界） | $1..i$ | $O(n^2 \cdot \mathrm{cost})$ |

**139 的兩個常見寫法及其複雜度差異**：

```cpp
// 寫法 A：回看整個前綴 —— O(n^2) 個 substr，每個 O(len) ⇒ O(n^3) ✘
for (int i = 1; i <= n; i++)
    for (int j = 0; j < i; j++)
        if (f[j] && dict.count(s.substr(j, i - j))) {
            f[i] = true;
            break;
        }

// 寫法 B：只回看 Lmax 格 —— O(n * Lmax) 個 substr ⇒ O(n * Lmax^2) ✔
for (int i = 1; i <= n; i++)
    for (int j = max(0, i - Lmax); j < i; j++)
        if (f[j] && dict.count(s.substr(j, i - j))) {
            f[i] = true;
            break;
        }
```

**$L_{\max}$ 在 LeetCode 139 的資料範圍下通常很小（$\le 20$）⇒ 寫法 B 實質上是線性的** ✔。

**再進一步：用 Trie 消掉 `substr` 的建構成本。** 從位置 $i$ 出發**往後**沿 Trie 走，每走一步就檢查是否為單詞結尾：

```cpp
for (int j = 0; j < n; j++) {
    if (!f[j]) continue;
    Node* p = root;
    for (int i = j; i < n && p; i++) {
        p = p->ch[s[i] - 'a'];
        if (p && p->isEnd) f[i + 1] = true;
    }
}
```

**這個版本的複雜度是 $O(n L_{\max})$ 且沒有任何字串複製** ✔，**同時自動享受了「字典中沒有這個前綴就提早停止」的剪枝**（`p` 變成 `nullptr` 即斷）。

> **通用判準：「最後一段」的枚舉範圍能不能被題目條件限制住？**
> **能 ⇒ 線性；不能 ⇒ 平方，然後考慮用資料結構（Trie、雜湊、單調隊列）把 $\mathrm{cost}(\mathrm{valid})$ 或分支數壓下來。**

### 定理 3（劃分方案數是指數的 ⇒ **記憶化是必需而非優化**）

*命題*：對 $s = \underbrace{\texttt{"aaa}\cdots\texttt{a"}}_{n}$、字典 $= \{\texttt{"a"}, \texttt{"aa"}\}$，合法劃分的**數量**為第 $n$ 個 Fibonacci 數，因此無記憶化的 DFS 是**指數時間**。

*證明*。設 $P(n)$ 為長度 $n$ 的劃分數。按最後一段長度（1 或 2）劃分：$P(n) = P(n-1) + P(n-2)$，$P(0)=P(1)=1$ ⇒ $P(n) = F_{n+1} = \Theta(\varphi^n)$，$\varphi = \tfrac{1+\sqrt5}{2} \approx 1.618$ ✔。

一個枚舉所有劃分的 DFS 至少要走訪 $P(n)$ 個葉節點 ⇒ $\Omega(\varphi^n)$ ✔。$\square$

**這與「加剪枝就好了」的直覺相反**：**剪枝在最壞情況下無效**——上述例子中**每一條分支都合法**，沒有任何東西可剪 ✘。

**記憶化為什麼能救**：狀態只有 $n+1$ 個（$f(0..n)$），每個狀態只算一次 ⇒ $O(n L_{\max})$ ✔。**它把「枚舉方案」換成了「枚舉狀態」，而狀態數是多項式的。**

> **這是動態規劃相對於暴力搜尋的全部價值所在，也是判斷一題「該不該用 DP」的核心問題：**
> **方案數是指數的，但「有意義的中間狀態」只有多項式個嗎？**

**139 的經典 TLE 測資**就是這個構造的變體（`"aaaa...aab"` + 字典 `["a","aa","aaa",...]`），**它的答案是 false，所以 DFS 必須窮盡整棵指數大小的搜尋樹才能回答** ✘。**「無解的測資」是暴力解最致命的情形**，因為連提早回傳都做不到。

### 定理 4（2369：貪心失敗，必須 DP）

*命題*：「從左到右優先取最短的合法段」的貪心策略對 2369 是錯的。

*證明（反例）*。$a = [3, 3, 3, 4, 4]$。
- **貪心（優先取長度 2）**：取 $[3,3]$ ✔，剩下 $[3,4,4]$——既非全等、也非連續遞增 ✘ ⇒ 判定為 false。
- **正解**：取 $[3,3,3]$（三個相等 ✔）+ $[4,4]$（兩個相等 ✔）⇒ true ✔。$\square$

**同理「優先取最長」也會錯**（把上例左右鏡像即可構造）。**沒有任何固定的取段順序是安全的，因為「這一段怎麼切」會影響「後面還能不能切」——這正是需要 DP 的訊號。**

**2369 的轉移只有兩個分支**（定理 2）：

$$f(i) = \big(f(i-2) \land \mathrm{ok}_2(i-2)\big) \ \lor\ \big(f(i-3) \land \mathrm{ok}_3(i-3)\big),$$

**不漏**（最後一段長度只能是 2 或 3）、**不重**（長度不同）✔ ⇒ $O(n)$ 時間、$O(1)$ 空間（只需保留 $f(i-1), f(i-2), f(i-3)$）✔。

**邊界**：$i < 2$ 時只有 $f(0) = $ true；$i = 2$ 時只有長度 2 的分支可用。**用「先判 $i \ge 2$ / $i \ge 3$ 再取值」而不是靠陣列負下標** ✘。

### 定理 5（合法段判斷的獨立性前提，以及它何時失效）

*命題*：定理 1 的分解要求 $\mathrm{valid}(j,i)$ **只依賴 $s[j..i)$ 本身**。

*證明*。定理 1 的推導中，「前綴可劃分」與「最後一段合法」被當成兩個獨立的合取項。若 $\mathrm{valid}$ 還依賴前面怎麼切，這兩項就不獨立，乘積分解失效 ✘。$\square$

**失效的三種常見形式與對策**：

| 耦合形式 | 對策 |
| --- | --- |
| 段的合法性依賴**上一段的某個特徵**（如上一段的和、最後一個字元） | 把該特徵加進狀態：$f(i, \text{特徵})$（6 章狀態機 DP） |
| 段的合法性依賴**已用過的段數** | 加一維段數（5.3） |
| 段的合法性依賴**全局統計量**（如「所有段的和相等」） | 通常要枚舉那個統計量，或改用二分／搜尋 |

**這張表是遇到變形題時的第一份檢查清單**：**先問「$\mathrm{valid}$ 依賴什麼」，依賴的東西就是要加進狀態的東西** ✔。

### 定理 6（同一骨架，換半環就換題型）

*命題*：劃分型 DP 的三種常見問法對應同一個轉移骨架，只是把 $(\lor, \land)$ 換成別的半環運算：

$$f(i) = \bigoplus_{j<i,\ \mathrm{valid}(j,i)} \Big( f(j) \otimes \mathrm{cost}(j,i) \Big)$$

| 問法 | $\oplus$ | $\otimes$ | 單位元 $f(0)$ | 章節 |
| --- | --- | --- | --- | --- |
| 能否劃分 | $\lor$ | $\land$ | true | **5.1** |
| 有幾種劃分 | $+$ | $\times$ | 1 | 5.2 的計數變形 |
| 最少段數 | $\min$ | $+$（$\mathrm{cost}=1$） | 0 | 5.2 |
| 最小總代價 | $\min$ | $+$ | 0 | 5.2 |
| 最小化「最大段代價」 | $\min$ | $\max$ | $-\infty$ | 5.3 |

*證明*。定理 1 的劃分論證（按最後一段起點分類、不重不漏）**與合併運算完全無關**，只用到「分類窮盡且互斥」✔。因此任何滿足結合律與分配律的 $(\oplus,\otimes)$ 都能套 ✔。$\square$

**這個統一觀點有兩個實際用途**：

1. **改題時只改運算，不用重推轉移** ✔——例如把 139 改成「有幾種拆分方法」（LC 140 的計數版），只要把 `bool` 換成 `long long`、`||` 換成 `+` ✔。
2. **它警告你哪裡會出錯**：**$\lor$ 和 $\min$ 對「重複覆蓋」免疫，$+$ 不免疫**（1.2 定理 2 那句話的第四次應用）⇒ **改成計數版之前，先確認定理 1 的劃分真的互斥。** 這裡是互斥的（最後一段起點唯一），所以安全 ✔。

**但要小心 LC 140（輸出所有拆分方案）不屬於這個框架**：**它的輸出規模本身就是指數的**（定理 3），**任何演算法都逃不掉** ⇒ 那題該做的是「用 $f$ 陣列剪掉無解分支的 DFS」，複雜度為 $O(\text{答案總長})$ ✔。**先跑一遍 5.1 的可行性 DP，再只沿著 `f[j] == true` 的路徑搜尋——這是「可行性 DP + 回溯輸出」的標準組合。**

## 時間與空間複雜度

| 題 | 時間 | 空間 |
| --- | --- | --- |
| 2369 | $O(n)$ | $O(1)$（滾動 3 格） |
| 139（回看 $L_{\max}$ + `unordered_set`） | $O(n L_{\max}^2)$ | $O(\sum |w_i|)$ |
| 139（Trie 版） | $O(n L_{\max})$ | $O(\sum |w_i| \cdot \Sigma)$ |
| 140（輸出所有方案） | $O(\text{答案總長} + n L_{\max})$ | 同上 |

**$L_{\max}^2$ 是怎麼來的**：每個 $(i,j)$ 對要建一個長度 $O(L_{\max})$ 的 `substr` 並雜湊 ⇒ 每個 $i$ 有 $L_{\max}$ 個 $j$ ⇒ $O(L_{\max}^2)$ 每格 ✔。**Trie 版把它壓成 $O(L_{\max})$，因為沿 Trie 走時字元只讀一次。**

**字串雜湊的替代方案**：預處理整串的滾動雜湊 ⇒ 每次 $O(1)$ 取子串雜湊 ⇒ $O(nL_{\max})$，與 Trie 同階。**但雜湊有碰撞風險，字典題用 Trie 更穩妥。**

**空間優化**：2369 的 $f$ 只依賴最近 3 格 ⇒ 三個 `bool` 變數即可 ✔。139 的 $f$ 依賴最近 $L_{\max}$ 格 ⇒ 可壓成 $O(L_{\max})$ 的環形緩衝，**但通常沒必要**（$n$ 本來就不大）。

**布林版的 `bitset` 加速**：若 $\mathrm{valid}(j,i)$ 只依賴 $i-j$（段長）而非內容，$f$ 的轉移可寫成 `bitset` 的位移或 ⇒ $O(n^2/64)$ ✔。**這在段長集合較大時有用，但本節兩題都不需要。**

## 與相似技巧的比較

- **與 5.2 最優劃分**：**同一個骨架，把 $\lor$ 換成 $\min$、加上 $\mathrm{cost}(j,i)$**（定理 6）。**5.2 的難點轉移到「$\mathrm{cost}$ 怎麼 $O(1)$ 算出來」**（通常靠前綴和或增量維護）。
- **與 5.3 約束劃分個數**：多一維段數 $k$ ⇒ $O(n^2 k)$。**5.3 還會出現「最小化最大段和」這種可以改用二分答案的題型**——那時 DP 只用來做可行性判斷，反而回到本節的布林形式 ✔。
- **與 3 章背包**：劃分型可以看成「每段是一個物品」的分組背包（3.4），**但差別在於劃分型的段必須連續且恰好覆蓋整個序列**，而背包的物品可以任選、可以留空。**這個差別讓劃分型的狀態只需一維（前綴長度），比背包簡單。**
- **與 8 章區間 DP**：兩者都在切割序列，**但劃分型只切「前綴 | 剩餘」（一維狀態），區間 DP 要處理「任意區間 $[l,r]$」（二維狀態）**。**判準：合併的代價只跟「這一段」有關 ⇒ 劃分型；跟「左右兩塊各自的內部結構」有關 ⇒ 區間 DP。**
- **與貪心**：定理 4 給了明確的反例。**「這一段怎麼切影響後面能不能切」就是貪心失效的訊號** ✔。
- **與 BFS**：可行性劃分也可以建圖後跑 BFS（點 = 位置，邊 = 合法段）⇒ 同樣 $O(n L_{\max})$，而且**天然給出「最少段數」**。**兩者是同一件事的不同外衣；DP 的寫法更短，BFS 的寫法在要求最短路徑時更直觀。**

## 本節重點速查

- **骨架**：$f(i) = \bigvee_{j<i,\ \mathrm{valid}(j,i)} f(j)$，$f(0)=$ **true**（空前綴合法，是所有轉移的起點）。
- **定理 1**：劃分依據是「**最後一段的起點**」——不重不漏。**前提：段與段之間無耦合，$\mathrm{valid}(j,i)$ 只依賴 $s[j..i)$ 本身。**
- **定理 2（唯一的優化槓桿）**：**分支數 = 最後一段的可能長度數。** 2369 是 $\{2,3\}$ ⇒ $O(n)$；139 回看 $L_{\max}$ 格而非整個前綴 ⇒ 實質線性。**Trie 版 $O(nL_{\max})$ 且無字串複製、自帶前綴剪枝。**
- **定理 3（為什麼一定要記憶化）**：`"aaa...a"` + 字典 `{a, aa}` 的劃分數是 **Fibonacci $\Theta(\varphi^n)$** ⇒ 純 DFS 指數。**剪枝救不了「全部合法但整體無解」的測資。** DP 的價值 = 方案數指數但狀態數多項式。
- **定理 4（2369）**：**貪心錯，反例 $[3,3,3,4,4]$**（優先取 2 會失敗，正解是 3+2）。轉移只有兩個分支，$O(n)$ 時間 $O(1)$ 空間。
- **定理 5（何時一維狀態不夠）**：$\mathrm{valid}$ 依賴上一段特徵 ⇒ 加特徵維（6 章）；依賴段數 ⇒ 加段數維（5.3）；依賴全局量 ⇒ 枚舉或二分。**依賴什麼就把什麼加進狀態。**
- **定理 6（半環視角）**：換 $(\oplus,\otimes)$ 就換題型——$(\lor,\land)$ 可行性、$(+,\times)$ 計數、$(\min,+)$ 最優、$(\min,\max)$ 最小化最大段。**改計數前先確認劃分互斥（這裡互斥 ✔）。**
- **輸出所有方案（LC 140）**：**先跑可行性 DP，再只沿 `f[j]==true` 的路徑 DFS** ⇒ 複雜度與答案規模同階。
