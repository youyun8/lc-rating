## 這個技術解決什麼問題

最優劃分在 5.1 的骨架上加了一個東西：**每段有代價**。

$$f(i) \;=\; \min_{\substack{j\ <\ i \\ \mathrm{valid}(j,\,i)}} \Big( f(j) + \mathrm{cost}(j,\,i) \Big), \qquad f(0) = 0.$$

**結構完全沒變（定理 6 of 5.1 的半環視角），所以本節的難點不在 DP，而在兩件事**：

1. **$\mathrm{cost}(j,i)$ 怎麼在 $O(1)$ 內算出來**（定理 2 的增量維護）——這是把 $O(n^3)$ 壓成 $O(n^2)$ 的關鍵；
2. **$\mathrm{valid}(j,i)$ 怎麼在 $O(1)$ 內判斷**（定理 3 的回文預處理、定理 6 的頻率判準）。

**這一節的題目量很大，但它們的差別幾乎都在這兩個函式上**：

| 題 | $\mathrm{cost}$ / $\mathrm{valid}$ | 加速手法 |
| --- | --- | --- |
| 132 分割回文串 II | 段必須是回文，代價 1 | 預處理回文表 / 中心擴展（定理 3） |
| 91、639 解碼方法 | 段長 1 或 2，計數 | 常數分支（定理 4） |
| 1043 分隔陣列以得到最大和 | 段長 $\le k$，代價 $= \max \times \mathrm{len}$ | 增量維護 $\max$（定理 5） |
| 2464 有效分割的最少子陣列數目 | 段內相鄰元素 $\gcd > 1$ | 增量維護 $\gcd$（定理 2） |
| 2767 將字串分割為最少的美麗子字串 | 段是 5 的冪的二進位、無前導零 | 預處理合法段集合 |
| 3144 分割字元頻率相等的最少子字串 | 段內所有出現字元的頻率相同 | **$O(1)$ 判準**（定理 6） |
| 2707 字串中的額外字元 | 允許字元不屬於任何段 | **多加一個「丟棄」分支**（定理 6） |
| 1105 填充書架、2052 分隔句子 | 段長受寬度限制，代價 = 段內最大高度 / 剩餘平方 | 增量維護 |

**辨識訊號**：連續分段 + 每段有代價 + 求總代價最優。**與 5.1 的差別只是「能不能」變成「最好是多少」。**

## 狀態／資料結構定義

$$f(i) = \text{把前 } i \text{ 個元素劃分完畢的最優總代價},\qquad f(0) = 0.$$

**$f(0) = 0$ 是 $(\min,+)$ 半環的單位元**（5.1 定理 6）；計數型則是 $f(0) = 1$。**寫錯這一格，全表偏移。**

**無解的表示**：`INF = 0x3f3f3f3f`（可安全相加而不溢位）。**判斷用 `f[i] >= INF/2` 而不是 `== INF`**，因為 `INF + cost` 已經不等於 `INF` ✔。

**標準的雙層迴圈骨架**（注意內層是**遞減**的，理由見定理 2）：

```cpp
vector<int> f(n + 1, INF);
f[0] = 0;
for (int i = 1; i <= n; i++) {
    Agg agg{};                          // 段 [j, i) 的聚合資訊
    for (int j = i - 1; j >= 0; j--) {  // 遞減：段的左端往外擴
        agg.push_front(a[j]);           // O(1) 增量更新
        if (agg.valid()) f[i] = min(f[i], f[j] + agg.cost());
    }
}
```

**各題的 `Agg` 是什麼**：

| 題 | `Agg` 維護的量 | 增量更新 |
| --- | --- | --- |
| 1043 | 段內最大值 | `mx = max(mx, a[j])` |
| 2464 | 段的前綴 $\gcd$ | `g = gcd(g, a[j])` |
| 3144 | 各字元頻率、`distinct`、`maxFreq` | 三個量各 $O(1)$ 更新（定理 6） |
| 1105 | 段內最大高度、寬度和 | 兩個累加 |
| 2052 | 段內字元數 | 累加，超過寬度就 `break` |

## 不變量或正確性證明

### 定理 1（最優劃分轉移的正確性）

*命題*：$f(i) = \min_{j<i,\ \mathrm{valid}(j,i)} \big(f(j) + \mathrm{cost}(j,i)\big)$。

*證明*。按「最後一段的起點 $j$」劃分（5.1 定理 1）：不重不漏 ✔。

給定 $j$，該類方案的最小代價 $= \mathrm{cost}(j,i) + \big(\text{前綴 } [0,j) \text{ 的最小劃分代價}\big)$——**剪貼論證**：若前綴部分不是最優，換成最優的會得到更小的總代價，矛盾 ✔。$\square$

**這裡用到的前提有兩個，都要點名**：
- **$\mathrm{cost}(j,i)$ 只依賴這一段本身**（與前面怎麼切無關）——否則不能拆成兩項相加；
- **總代價是各段代價之和**（可加性）——若目標是「最大段代價的最小值」，$+$ 要換成 $\max$（5.3），骨架不變但單位元變成 $-\infty$ ✔。

### 定理 2（**增量維護 $\mathrm{cost}$：內層迴圈必須遞減**）

*命題*：若 $\mathrm{cost}$ 與 $\mathrm{valid}$ 可由「段的聚合量」$O(1)$ 決定，且該聚合量在**左端外擴**時可 $O(1)$ 更新，則整個 DP 是 $O(n^2)$。

*證明*。固定 $i$，內層 $j$ 從 $i-1$ 遞減到 $0$ 時，段 $[j, i)$ 恰好每次在**左邊**多一個元素 ⇒ 聚合量做一次 `push_front` 即可 ✔。每個 $(i,j)$ 對 $O(1)$ ⇒ 總計 $O(n^2)$ ✔。$\square$

**方向為什麼重要**：若內層寫成 $j$ 從 $0$ 遞增到 $i-1$，段 $[j,i)$ 是**左端內縮**——**縮小一個聚合量通常做不到 $O(1)$**（$\max$、$\gcd$、頻率的「移除」都不是 $O(1)$ 可逆的）✘ ⇒ 只能每次重算，退化成 $O(n^3)$。

> **判準：聚合量在「加入元素」時 $O(1)$，在「移除元素」時通常不是。**
> **所以劃分型 DP 的內層一律寫成遞減（左端外擴）。** 這是一條可以無腦遵守的規則。

**三個具體例子**：

- **1043**：`mx = max(mx, a[j])` ✔；反過來「從段中移除最大值」需要單調隊列或 multiset ✘。
- **2464**：`g = gcd(g, a[j])` ✔；$\gcd$ 沒有除法逆運算 ✘。**注意 2464 的合法條件是「段的第一個與最後一個元素 $\gcd > 1$」還是「整段 $\gcd>1$」，讀題時要確認**——兩者的聚合量不同。
- **3144**：頻率表加一 ✔；同時維護 `distinct` 與 `maxFreq`（定理 6）。

**能提早 `break` 的情形要善用**：1043 的段長上限 $k$ ⇒ `j >= i-k`；2052 的寬度上限 ⇒ 超過就 `break`。**這常常把 $O(n^2)$ 實際壓成 $O(nk)$** ✔。

### 定理 3（132：回文預處理的兩種寫法）

**寫法 A（回文表 + 遞迴定義）**：

$$\mathrm{pal}[j][i] = \big(s[j] = s[i]\big) \ \land\ \big(i - j < 2 \ \lor\ \mathrm{pal}[j+1][i-1]\big).$$

*正確性*：對區間長度做歸納。長度 $\le 2$ 的情形直接由 $s[j]=s[i]$ 判定 ✔；長度 $\ge 3$ 時，$s[j..i]$ 是回文 $\iff$ 首尾相同且去掉首尾後仍是回文（回文的定義）✔。

**填表順序必須讓 $\mathrm{pal}[j+1][i-1]$ 先算好** ⇒ **$j$ 遞減、$i$ 遞增**（或按區間長度由小到大）✔。

```cpp
vector<vector<bool>> pal(n, vector<bool>(n, false));
for (int j = n - 1; j >= 0; j--)  // j 遞減
    for (int i = j; i < n; i++)   // i 遞增
        pal[j][i] = (s[j] == s[i]) && (i - j < 2 || pal[j + 1][i - 1]);
```

**寫錯順序不會 RE，只會讀到尚未填的 `false`** ✘——**這是回文表最常見的 bug，而且測資小的時候可能剛好過。**

**寫法 B（中心擴展，省掉 $O(n^2)$ 的 bool 表）**：

```cpp
vector<int> f(n + 1, INF);
f[0] = 0;
for (int i = 1; i <= n; i++) f[i] = f[i - 1] + 1;  // 上界：每個字元自成一段
auto expand = [&](int l, int r) {
    while (l >= 0 && r < n && s[l] == s[r]) {
        f[r + 1] = min(f[r + 1], f[l] + 1);  // s[l..r] 是回文
        l--;
        r++;
    }
};
for (int c = 0; c < n; c++) {
    expand(c, c);
    expand(c, c + 1);
}
return f[n] - 1;  // 切割次數 = 段數 - 1
```

*正確性*：中心擴展**窮舉了所有回文子串**（每個回文有唯一的中心，奇偶各一種）✔，而每找到一個回文 $s[l..r]$ 就做一次鬆弛 ⇒ 所有轉移都被執行到 ✔。

**但這個寫法有一個微妙之處必須說清楚**：**鬆弛 `f[r+1]` 時用到的 `f[l]` 是否已經是最終值？**

**是的**——因為 $l < r+1$，而中心擴展的過程中，**所有以 $r+1$ 為右端的鬆弛都用到嚴格更小的下標**；只要保證「處理完所有中心後才讀 `f[n]`」，且 `f` 是單調鬆弛（只變小），最終每個 `f[i]` 都會收斂到正確值 ✔。**更嚴謹的說法**：這是在 DAG（下標從小到大）上做鬆弛，**所有邊都從小指向大，任意順序的完整鬆弛都會得到正確結果** ✔。

**答案是 `f[n] - 1`**：$f$ 算的是**段數**，題目要的是**切割次數** ✘ 忘記減 1 是本題第二常見的錯。

### 定理 4（91 / 639：計數型的嚴格劃分，以及 `0` 與 `*` 的陷阱）

*命題（91）*：$f(i) = f(i-1)\cdot[\,s[i-1] \ne \texttt{'0'}\,] + f(i-2)\cdot[\,10 \le \overline{s[i-2]s[i-1]} \le 26\,]$。

*證明*。按「最後一段長度」劃分（1 或 2）——**互斥且窮盡** ⇒ 可加 ✔（5.1 定理 6 的警告在此被滿足）。$\square$

**`0` 的三條規則，每一條都是一個測資**：

| 情形 | 合法？ | 例子 |
| --- | --- | --- |
| 單獨的 `'0'` | ✘ | `"0"` ⇒ 0 種 |
| 前導零的兩位數 | ✘ | `"06"` ⇒ 0 種 |
| `'0'` 作為 `10` / `20` 的個位 | ✔ | `"10"` ⇒ 1 種 |

⇒ **`"100"` 應該回傳 0**（`1|00` ✘、`10|0` ✘）。**這個測資能一次抓出上面三條規則有沒有寫全** ✔。

*命題（639）*：加入 `'*'`（代表 `1`–`9`，**不含 `0`**）後，兩個係數變成：

- **單字元**：`'*'` ⇒ **9** 種；數字 `d` ⇒ $[d \ne 0]$ 種。
- **雙字元** $c_1 c_2$：

| $c_1$ | $c_2$ | 合法組合數 | 說明 |
| --- | --- | --- | --- |
| `'1'` | `'*'` | 9 | `11`–`19` |
| `'2'` | `'*'` | 6 | `21`–`26` |
| `'*'` | 數字 $d \le 6$ | 2 | `1d`、`2d` |
| `'*'` | 數字 $d \ge 7$ | 1 | 只有 `1d` |
| `'*'` | `'*'` | **15** | `11`–`19`（9 個）+ `21`–`26`（6 個） |
| 數字 $c_1$ | 數字 $c_2$ | $[10 \le \overline{c_1c_2} \le 26]$ | 同 91 |

**那個 15 值得自己算一遍**：兩位都是 `*` 時，十位只能是 1 或 2（否則超過 26），個位是 1–9 ⇒ 十位為 1 給 9 個、十位為 2 給 `21`–`26` 共 6 個 ⇒ 15 ✔。**這裡最容易漏掉的是「`*` 不能是 0」，若誤以為可以，`2*` 會多算 `20`** ✘。

**取模**：639 要對 $10^9+7$ 取模，**乘法前先轉 `long long`** ✔。

### 定理 5（1043：段長上界 + $\mathrm{cost} = \max \times \mathrm{len}$）

*命題*：$f(i) = \max_{i-k \le j < i} \big( f(j) + \max(a_j..a_{i-1}) \times (i-j) \big)$，複雜度 $O(nk)$。

*證明*。按最後一段起點劃分 ✔；段長上界 $k$ 把分支數限制為 $k$ ✔；$\max$ 由定理 2 的遞減迴圈增量維護 ✔。$\square$

**注意 $\mathrm{cost} = \max \times \mathrm{len}$ 是題目的規則（每段的元素都被改成該段最大值），不是某種優化選擇** ✔——**讀題時把「代價函式」寫下來再開始寫程式，可以省掉大量 debug。**

**這一題常被誤以為可以貪心**（「盡量讓大數自成一段」之類）。**反例容易構造**：$[1, 100, 1, 1]$，$k=2$。
- 貪心「大數獨立」：$[1] + [100] + [1,1] = 1 + 100 + 2 = 103$；
- 更優：$[1,100] + [1,1] = 200 + 2 = 202$ ✔。

**「把大數和小數放一起反而更好」正是這題與直覺相反之處**——因為代價是 $\max \times \mathrm{len}$，**把小數併進大數的段裡能把小數也「提升」成大數** ✔。

**1105 填充書架**結構相同（段內取最大厚度，段寬受限），**但它的段長不是固定上界而是由累積寬度決定** ⇒ 迴圈條件改成 `while (寬度和 <= shelfWidth)` ✔。

### 定理 6（兩個實用擴展：$O(1)$ 合法判準 與「允許丟棄」的分支）

**(a) 3144 的 $O(1)$ 判準**

*命題*：一個段內「所有出現過的字元頻率都相等」$\iff$ $\mathit{maxFreq} \times \mathit{distinct} = \mathit{segLen}$。

*證明*。
- **($\Rightarrow$)** 所有頻率都等於 $\mathit{maxFreq}$，共 $\mathit{distinct}$ 種 ⇒ 總和 $= \mathit{maxFreq}\times\mathit{distinct} = \mathit{segLen}$ ✔。
- **($\Leftarrow$)** 每個出現過的字元頻率 $\le \mathit{maxFreq}$，共 $\mathit{distinct}$ 個，總和為 $\mathit{segLen} = \mathit{maxFreq}\times\mathit{distinct}$ ⇒ **每一項都必須取到上界**（否則總和嚴格小於）⇒ 全部相等 ✔。$\square$

**這條判準把「掃過 26 個字母檢查是否全等」的 $O(\Sigma)$ 降到 $O(1)$**，總複雜度從 $O(n^2\Sigma)$ 變成 $O(n^2)$ ✔。而 $\mathit{maxFreq}$ 與 $\mathit{distinct}$ 在左端外擴時都是 $O(1)$ 更新的：

```cpp
cnt[c]++;
if (cnt[c] == 1) distinct++;
maxFreq = max(maxFreq, cnt[c]);  // 只增不減 ⇒ 外擴時安全
```

**`maxFreq` 只增不減，這正好配合定理 2 的「只加不減」原則** ✔。

**(b) 2707 的「丟棄」分支**

*設定*：把字串切成字典中的單詞，**未被覆蓋的字元算作額外字元**，最小化額外字元數。

*命題*：$f(i) = \min\Big( f(i-1) + 1,\ \min_{\substack{j<i \\ s[j..i)\ \in\ \mathrm{dict}}} f(j) \Big)$。

*證明*。按「第 $i$ 個字元（下標 $i-1$）是否屬於某個匹配的單詞」劃分——**互斥且窮盡** ✔。
- 不屬於 ⇒ 它是額外字元，代價 $+1$，前綴獨立 ⇒ $f(i-1)+1$ ✔；
- 屬於 ⇒ 它是某個單詞的最後一個字元，該單詞起點為 $j$ ⇒ $f(j)$ ✔。$\square$

> **通用手法：問題允許「有些元素不屬於任何段」時，在轉移裡加一個 $f(i-1) + \mathit{penalty}$ 的分支即可。**
> **這個小改動把「必須完全劃分」放寬成「盡量劃分」，而骨架完全不用動** ✔。

**它也解釋了為什麼 2707 不需要 `valid` 判斷**：**丟棄分支保證 $f(i)$ 永遠有解**（最差就是全部丟棄）⇒ 不會出現 `INF` ✔。

## 時間與空間複雜度

| 題 | 時間 | 空間 |
| --- | --- | --- |
| 132（回文表） | $O(n^2)$ | $O(n^2)$ |
| 132（中心擴展） | $O(n^2)$ | $O(n)$ |
| 91 / 639 | $O(n)$ | $O(1)$ |
| 1043 | $O(nk)$ | $O(n)$ |
| 2464 / 3144 / 2547 等通用型 | $O(n^2)$ | $O(n)$ |
| 2707（Trie） | $O(n L_{\max})$ | 字典大小 |
| 2767 | $O(n^2)$（合法段可預處理） | $O(n)$ |

**$O(n^2)$ 在 $n \le 5000$ 時穩過**；$n \ge 10^5$ 就必須找到「分支數有界」或「可用資料結構優化」的結構（11 章）。

**中心擴展比回文表好在哪**：省掉 $O(n^2)$ 的 `vector<vector<bool>>`（後者雖然是位壓縮，但存取有額外開銷），**而且程式碼更短、不會寫錯填表順序** ✔。**代價是它不能回答「任意 $(j,i)$ 是不是回文」的隨機查詢**——若後續還需要這個查詢（例如 2472），還是要建表。

**溢位**：1043 的 $\max \times \mathrm{len}$ 在 $n=500$、值 $10^4$ 時最大 $5\times10^6$，`int` 足夠；**但若題目值域更大就要 `long long`。** 計數型（91、639、1416）一律取模。

**空間優化**：$f$ 只有一維 $O(n)$，通常不需要再壓。**段長有界時（1043）可壓成 $O(k)$，但意義不大。**

## 與相似技巧的比較

- **與 5.1**：**同一骨架，$\lor$ 換成 $\min$、加上 $\mathrm{cost}$。** 5.1 的所有觀察（分支數 = 最後一段長度數、記憶化的必要性、段間無耦合的前提）在此原封不動成立。
- **與 5.3**：多一維「段數 $k$」。**注意 5.3 有些題目（「最小化最大段和」）可以改用二分答案 + 貪心檢查，複雜度 $O(n\log V)$ 遠優於 $O(n^2k)$** ⇒ **看到「最小化最大值」先想二分。**
- **與 3.4 分組背包**：把「最後一段長度」當成組內選項，兩者的複雜度分析一致（3.4 定理 6）。**差別是劃分型的段必須連續且覆蓋整個序列。**
- **與 8 章區間 DP**：**判準（重複一次）：代價只跟「這一段」有關 ⇒ 劃分型（一維狀態）；跟「左右兩塊各自的內部結構」有關 ⇒ 區間 DP（二維狀態）。** 例如「合併石子」的代價依賴兩堆各自的和 ⇒ 區間 DP。
- **與 11 章優化 DP**：本節的 $O(n^2)$ 在 $\mathrm{cost}$ 具有特殊結構時可以再降：
  - $\mathrm{cost}$ 是**區間和** ⇒ 前綴和 + 單調隊列 / 斜率優化（11.3、11.7）；
  - $\mathrm{cost}$ 滿足**四邊形不等式** ⇒ 決策單調性，$O(n\log n)$（11.8）。
  **本節先把 $O(n^2)$ 寫熟，11 章再談怎麼再快。**
- **與貪心**：定理 5 的 $[1,100,1,1]$ 反例、5.1 定理 4 的 $[3,3,3,4,4]$ 反例都說明**劃分型幾乎沒有貪心解**。**唯一的例外是「最小化最大段和」的二分答案版本，那裡的貪心（盡量塞滿）是有正確性證明的**（5.3）。

## 本節重點速查

- **骨架**：$f(i) = \min_{j<i,\ \mathrm{valid}} \big(f(j) + \mathrm{cost}(j,i)\big)$，$f(0)=0$。**無解用 `0x3f3f3f3f`，判斷寫 `>= INF/2`。**
- **定理 2（最重要的實作規則）**：**內層迴圈一律遞減**（段的左端外擴）⇒ 聚合量 $O(1)$ 增量更新。**理由：$\max$、$\gcd$、頻率都是「只能加、不能減」的量。** 遞增寫法會退化成 $O(n^3)$。
- **定理 3（132）**：回文表 $\mathrm{pal}[j][i] = (s_j = s_i) \land (i-j<2 \lor \mathrm{pal}[j+1][i-1])$，**填表順序必須 $j$ 遞減 $i$ 遞增**（寫錯只會靜默讀到 false）。**中心擴展版省 $O(n^2)$ 空間，正確性靠「所有邊都從小下標指向大下標」的鬆弛論證。答案要 $-1$（段數 → 切割次數）。**
- **定理 4（91/639）**：最後一段長 1 或 2 ⇒ 嚴格劃分 ⇒ 可加。**`0` 的三條規則用 `"100"` 測（答案 0）。`*` 代表 1–9 不含 0；`**` 是 15 種（`11`–`19` 九個 + `21`–`26` 六個）。**
- **定理 5（1043）**：$\mathrm{cost} = \max \times \mathrm{len}$，段長 $\le k$ ⇒ $O(nk)$。**貪心錯，反例 $[1,100,1,1]$、$k=2$：把小數併進大數的段反而更好（202 > 103）。**
