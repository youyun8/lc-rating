## 這個技術解決什麼問題

6.2 的模式集合都很自然（升 / 降、正 / 負、奇 / 偶）。**進階題的難點在於：模式集合要自己設計出來，而且往往不只一維。**

本節收集四種「模式從哪裡來」的典型來源：

| 來源 | 模式的形式 | 代表題 |
| --- | --- | --- |
| **階段順序**：答案必須依序經過若干階段 | 「目前在第 $j$ 階段」 | LCP 19 秋葉收藏集、1955 統計特殊子序列 |
| **一次性操作**：最多用一次某種特權 | 布林值「用了沒」 | 1186 刪除一次得到子陣列最大和、2036 |
| **相鄰約束**：合法性取決於相鄰兩項的關係 | 「與前一項相同 / 不同」 | 276 柵欄塗色、801 使序列遞增 |
| **鄰接圖**：移動受限於一張固定的圖 | 「目前在圖上哪個節點」 | 935 騎士撥號器、1594 |

**四種來源共用同一條式子**（6.2 定理 1 的框架），**難的從來不是轉移，而是「模式集合有沒有設完備」** ✘。

**還有一個 6.2 沒有的新工具**：當模式數 $|S|$ 很小、轉移矩陣**不隨 $i$ 變化**、而步數 $n$ 大到 $10^9$ 時，可以用**矩陣快速冪**把 $O(n|S|^2)$ 壓到 $O(|S|^3\log n)$（定理 5）。

## 狀態／資料結構定義

### (a) 階段型

$$f(i,\,j) = \text{處理完前 } i \text{ 個元素、目前處於第 } j \text{ 階段時的最優值（或方案數）},\qquad j \in \{0,1,\dots,K-1\}.$$

轉移只有兩條：**留在原階段**（$j \to j$）或**推進一階段**（$j-1 \to j$）——**階段不能跳、不能退**。

**「每個階段非空」的處理**：階段 $j$ 至少需要 $j+1$ 個元素 ⇒ **只讓 $i \ge j$ 的狀態有效**，其餘設為 $\infty$ / $-\infty$。**這比在轉移裡加一堆 `if` 乾淨得多** ✔（定理 1）。

### (b) 一次性操作型

$$f(i,\,u) = \text{以 } i \text{ 結尾、且特權「已用 / 未用」為 } u \in\{0,1\} \text{ 的最優值}.$$

**$u$ 只能從 0 變 1，不能回頭** ⇒ 這是一張只有兩層、單向的 DAG ✔。

### (c) 相鄰約束型

$$f(i,\,r) = \text{前 } i \text{ 項合法、且第 } i \text{ 項與第 } i-1 \text{ 項的關係為 } r \text{ 的值}.$$

**$r$ 要記多少，取決於約束往回看幾步**：「相鄰不同色」看一步 ⇒ $r$ 是布林；「不能連續三根同色」看兩步 ⇒ **仍然只要布林**，因為「與前一根同色」這一個位元已經足以判斷「再同色就違規」✔（定理 3）。

### (d) 鄰接圖型

$$f(i,\,v) = \text{走了 } i \text{ 步、目前在節點 } v \text{ 的方案數（或最優值）},\qquad f(i,v)=\sum_{(u\to v)\in E} f(i-1,\,u).$$

**這其實就是「在時間展開圖上做 DP」**，也等價於**鄰接矩陣的 $n$ 次冪**（定理 5）。

## 不變量或正確性證明

### 定理 1（**階段型：非空約束由狀態的有效範圍自動保證**）

*設定*（LCP 19）：把字串切成「紅、黃、紅」三段、**每段非空**，最小化需要調整的葉子數。

*命題*：令 $f(i,j)$ 為「前 $i+1$ 片葉子、第 $i$ 片處於第 $j$ 段」的最小調整數（$j=0,1,2$ 依序代表紅、黃、紅），轉移

$$f(i,j) = \min\big(f(i-1,j),\ f(i-1,j-1)\big) + \mathrm{cost}(i,j),$$

並**只在 $i \ge j$ 時視為有效**，則答案 $f(n-1,2)$ 自動滿足三段皆非空。

*證明*。
**(⇐ 有效狀態都合法)** 對 $j$ 歸納：$f(i,j)$ 有效需要 $f(i-1,j-1)$ 或 $f(i-1,j)$ 有效，即 $i-1 \ge j-1$，恆成立。而狀態 $(i,j)$ 的語意是「第 $i$ 片在第 $j$ 段」，要走到第 $j$ 段必須先經過第 $0..j-1$ 段，**每段至少貢獻一片葉子** ⇒ 至少用掉 $j$ 片 ⇒ $i \ge j$ ✔。

**(⇒ 所有合法方案都被涵蓋)** 任一「紅黃紅」三段皆非空的方案，其最後一片葉子必在第 2 段 ⇒ 對應到某個 $f(n-1,2)$ 的路徑 ✔。

**關鍵在於「階段不能跳」**：轉移只允許 $j-1\to j$，**不允許 $j-2 \to j$** ⇒ **中間段不可能被跳過** ⇒ 非空自動成立 ✔。$\square$

> **這條的價值在於它把「非空」這個看似需要額外檢查的約束，變成了轉移圖的結構性質。**
> **反過來說：若題目允許某些階段為空，就要顯式加上 $j-2\to j$ 的邊——而那時 $i \ge j$ 的界也要跟著鬆綁。**

**$\mathrm{cost}(i,j)$ 的定義**：第 $j$ 段要求葉子是紅（$j=0,2$）或黃（$j=1$），$\mathrm{cost}$ 就是「當前葉子不符合時要調整」的 $0/1$ ✔。

### 定理 2（**1186：一次性操作的布林維，以及「刪除後非空」的初始化**）

*設定*：求「至多刪除一個元素」後的最大子陣列和，**且刪除後子陣列非空**。

*命題*：令 $f(i,0)$ / $f(i,1)$ 為「以 $a_i$ 結尾、未刪 / 已刪一個元素」的最大和，

$$f(i,0) = \max\big(f(i-1,0),\ 0\big) + a_i, \qquad f(i,1) = \max\big(\underbrace{f(i-1,0)}_{\text{刪掉 } a_i},\ \underbrace{f(i-1,1) + a_i}_{\text{早就刪過了}}\big),$$

初始化 $f(0,0) = a_0$、$f(0,1) = -\infty$，答案 $\max_i \max\big(f(i,0),\ f(i,1)\big)$。

*證明*。
**劃分的互斥窮盡性**：考慮任一以 $a_i$ 結尾、恰刪一個元素的子陣列。**被刪的位置只有兩種可能**：
- **就是 $i$ 本身** ⇒ 剩下的是「以 $a_{i-1}$ 結尾、未刪任何元素」的子陣列 ⇒ 值為 $f(i-1,0)$；
- **在 $i$ 之前** ⇒ 剩下的是「以 $a_{i-1}$ 結尾、已刪一個」的子陣列再接上 $a_i$ ⇒ 值為 $f(i-1,1)+a_i$。

兩者互斥（刪的位置不同）且窮盡 ✔。$\square$

**⚠ 三個初始化細節，每一個都能讓你 WA**：

1. **$f(0,1) = -\infty$ 而非 0** ✘——「刪掉唯一的元素」會得到空陣列，題目不允許 ✔。**這是 6.2 定理 3「0 不能兼任不可達」的同一個坑。**
2. **$f(i,1)$ 的第一條分支寫 $f(i-1,0)$ 而不是 $\max(f(i-1,0),0)$** ✘——寫成 $\max(\cdot,0)$ 等於允許「刪掉 $a_i$ 後前面是空的」，那結果是空陣列 ✔。
3. **$f(i,0)$ 的 $\max(f(i-1,0),0)$ 才是對的**（Kadane 的「要不要帶上前面」），**因為它後面還會加 $a_i$，不會產生空陣列** ✔。

**這兩條分支一個要 $\max(\cdot,0)$、一個不要——差別完全來自「加不加 $a_i$」。** 想清楚這一點，這題就通了。

**推廣**：「至多用 $t$ 次特權」就把布林維換成 $0..t$；**只要 $t$ 是小常數，複雜度仍是 $O(nt)$** ✔（2036 最大交替子陣列和、1546 等同理）。

### 定理 3（**276：「不能連續三根同色」只需要一個布林位元**）

*設定*：$n$ 根柵欄、$k$ 種顏色，**不允許連續三根同色**，求塗色方案數。

*命題*：令 $\mathit{same}_i$ / $\mathit{diff}_i$ 為「第 $i$ 根與第 $i-1$ 根同色 / 不同色」的方案數，則

$$\mathit{same}_i = \mathit{diff}_{i-1}, \qquad \mathit{diff}_i = (\mathit{same}_{i-1} + \mathit{diff}_{i-1})\cdot(k-1).$$

*證明*。
**$\mathit{same}_i = \mathit{diff}_{i-1}$**：第 $i$ 根與第 $i-1$ 根同色時，若第 $i-1$ 根又與第 $i-2$ 根同色就形成連續三根 ✘ ⇒ **必須 $\mathit{diff}_{i-1}$** ✔。而顏色被第 $i-1$ 根唯一決定 ⇒ 係數為 1 ✔。

**$\mathit{diff}_i = (\mathit{same}_{i-1}+\mathit{diff}_{i-1})(k-1)$**：不同色時無論前面是什麼狀態都合法 ✔，且有 $k-1$ 種顏色可選 ✔。

**互斥窮盡**：「同色 / 不同色」顯然是對第 $i$ 根的一個二分劃分 ✔。$\square$

> **為什麼「看兩步的約束」只需要一個位元？**
> 因為約束是「連續三根同色」，而**「第 $i$ 根與第 $i-1$ 根同色」這一個位元，加上第 $i+1$ 根的選擇，就足以判斷會不會違規**——**不需要知道第 $i-2$ 根到底是什麼顏色。**
>
> **通則：狀態要記的不是「歷史」，而是「判斷未來合法性所需的最小資訊」。** 這句話是整個第 6 章的靈魂。

**推論 3.1**：改成「不能連續 $m$ 根同色」時，狀態變成「目前已連續同色 $t$ 根」，$t \in \{1,\dots,m-1\}$ ⇒ $O(nm)$ ✔。**位元數隨約束長度線性增長，不是指數增長。**

**⚠ 邊界**：$n=1$ 答案是 $k$；$n=2$ 答案是 $k^2$（兩根同色也合法）。**遞推要從 $i=2$ 開始，$\mathit{same}_1 = k$、$\mathit{diff}_1 = k(k-1)$** ✔。

### 定理 4（**801：兩個相容性條件可以同時成立，寫 `else if` 就錯**）

*設定*：兩個等長陣列 $a,b$，每個位置可以選擇交換 $a_i \leftrightarrow b_i$，求使**兩個陣列都嚴格遞增**的最小交換次數。

*命題*：令

$$A_i \equiv (a_i > a_{i-1}) \land (b_i > b_{i-1}), \qquad B_i \equiv (a_i > b_{i-1}) \land (b_i > a_{i-1}),$$

則 $f(i,0)$（不交換 $i$）與 $f(i,1)$（交換 $i$）的轉移為

$$f(i,0) = \min\big(\ [A_i]\ f(i-1,0),\ \ [B_i]\ f(i-1,1)\ \big), \qquad f(i,1) = 1 + \min\big(\ [B_i]\ f(i-1,0),\ \ [A_i]\ f(i-1,1)\ \big),$$

其中 $[\,\cdot\,]$ 表示條件不成立時該分支為 $+\infty$。**這四條分支必須獨立判斷。**

*證明的關鍵*：$A_i$ 與 $B_i$ **不互斥**。

> **反例**：$a = [1,3]$、$b = [2,4]$。
> $A_1$：$3>1$ ✔ 且 $4>2$ ✔ ⇒ 成立。
> $B_1$：$3>2$ ✔ 且 $4>1$ ✔ ⇒ **也成立。**

若寫成 `if (A) {...} else if (B) {...}`，**$B$ 分支永遠不會被檢查**，於是「前一位交換、這一位不交換」這條合法路徑被整個丟掉 ✘ ⇒ 答案偏大或變成無解。$\square$

**為什麼四條分支的劃分是互斥窮盡的**：按「$(i-1$ 交換與否$,\ i$ 交換與否$)$」劃分，恰好四種組合 ✔；每種組合的合法性由 $A_i$ 或 $B_i$ 判定：

| $i-1$ | $i$ | 需要比較 | 條件 |
| --- | --- | --- | --- |
| 不換 | 不換 | $a_i$ vs $a_{i-1}$、$b_i$ vs $b_{i-1}$ | $A_i$ |
| 換 | 換 | $b_i$ vs $b_{i-1}$、$a_i$ vs $a_{i-1}$ | $A_i$ |
| 不換 | 換 | $b_i$ vs $a_{i-1}$、$a_i$ vs $b_{i-1}$ | $B_i$ |
| 換 | 不換 | $a_i$ vs $b_{i-1}$、$b_i$ vs $a_{i-1}$ | $B_i$ |

**（注意「換換」用的是 $A_i$、「換不換」用的是 $B_i$——因為兩邊同時換等於沒換相對關係。這張表值得自己推一遍。）**

> **通則：轉移條件不互斥時，一律用四條獨立的 `if`（或全部走 $\min$），不要用 `else`。**
> **這是狀態機 DP 排名第一的實作錯誤**——**因為 `else if` 在多數測資下剛好也對。**

**⚠ 題目保證有解**，所以不必處理全 $\infty$ 的情形；**但若題目不保證，記得檢查答案是否為 $\infty$** ✔。

### 定理 5（**鄰接圖型 + 矩陣快速冪：適用前提**）

*命題*：若轉移可以寫成 $f_i = M \cdot f_{i-1}$，其中 **$M$ 不依賴 $i$**，則 $f_n = M^n f_0$，可用快速冪在 $O(|S|^3\log n)$ 求出。

*證明*。矩陣乘法結合律 ⇒ $M^n$ 可用二進位分解 $M^n = \prod_{b:\,n_b=1} M^{2^b}$ 求得，共 $O(\log n)$ 次矩陣乘法 ✔。$\square$

**適用前提（三個，缺一不可）**：

1. **轉移是線性的**——每個新狀態是舊狀態的加權和。**計數型（935 騎士撥號器）天生滿足** ✔。
2. **係數與時刻 $i$ 無關**。**6.1 的股票題不滿足**（邊權是 $\pm p_i$，逐日變化）✘——**這就是為什麼股票題不能用矩陣快速冪。**
3. **$|S|$ 夠小**：$|S|^3\log n$ 要能算完。$|S| \le 100$、$n \le 10^9$ ⇒ $10^6 \times 30 = 3\times10^7$ ✔。

**半環推廣**：把矩陣乘法的 $(+,\times)$ 換成 $(\min,+)$，同一套快速冪就變成「**恰好 $n$ 條邊的最短路**」✔——**這是 5.1 定理 6 半環表的第二次應用。** $(\max,+)$ 同理。

**⚠ 實務判斷**：**935 的 $n \le 5000$，直接 $O(n\cdot|S|)$ 就好，寫矩陣快速冪是殺雞用牛刀。** 只有在 $n$ 大到 $10^9$、而狀態數是常數時才值得 ✔。**看到「步數 $\le 10^9$、狀態數很小」才啟動這個工具。**

### 定理 6（**階段型計數：$f_j \leftarrow 2f_j + f_{j-1}$ 的意義**）

*設定*（1955）：統計形如 $\texttt{0}^{+}\texttt{1}^{+}\texttt{2}^{+}$ 的子序列個數。

*命題*：維護 $f_0,f_1,f_2$ = 「已匹配到第 $0/1/2$ 段」的子序列個數，掃到元素 $d$ 時**只更新 $f_d$**：

$$f_0 \leftarrow 2f_0 + 1 \ (d=0), \qquad f_1 \leftarrow 2f_1 + f_0 \ (d=1), \qquad f_2 \leftarrow 2f_2 + f_1 \ (d=2).$$

*證明*。固定 $d$，對「已匹配到第 $d$ 段」的子序列按**當前元素的用法**劃分：

- **不選它** ⇒ 沿用舊的 $f_d$ 個；
- **選它、延長第 $d$ 段** ⇒ 舊的 $f_d$ 個各延長一次；
- **選它、開啟第 $d$ 段**（即它是第 $d$ 段的第一個元素）⇒ 前面必須已匹配到第 $d-1$ 段，共 $f_{d-1}$ 個（$d=0$ 時是「空前綴」，恰 1 種）。

三類**互斥**（第一類沒選它；第二、三類都選了它，但它在第 $d$ 段的位置不同：非首 / 首）**且窮盡** ✔ ⇒ 總數 $2f_d + f_{d-1}$ ✔。$\square$

**⚠ 為什麼不會有更新順序問題**：因為**每個元素只有一個 $d$，所以每輪只改一個 $f_d$，而它讀的 $f_{d-1}$ 這輪必定沒被改** ✔。**這是「只更新一格」帶來的免費午餐——換成 6.2 定理 5 的 2222（每輪要改多格）就得小心順序了。**

**與 LCP 19 的對照**：**同一個階段型狀態機，一個在 $(\min,+)$ 半環上（求最優），一個在 $(+,\times)$ 半環上（計數）** ✔。**骨架一字不變，只換運算。**

## C++17 模板

```cpp
// ---- 1. 階段型：LCP 19 秋葉收藏集（紅-黃-紅，每段非空）----
int minimumOperations(const string& leaves) {
    int n = (int)leaves.size();
    const int INF = 0x3f3f3f3f;
    // f[j]：目前在第 j 段（0 紅 / 1 黃 / 2 紅）
    vector<int> f(3, INF), g(3, INF);
    for (int i = 0; i < n; i++) {
        int isY = (leaves[i] == 'y');
        int costR = isY, costY = 1 - isY;  // 要調整就 +1
        g[0] = (i == 0 ? 0 : f[0]) + costR;
        g[1] = (i >= 1 ? min(f[0], f[1]) : INF);
        if (g[1] < INF) g[1] += costY;
        g[2] = (i >= 2 ? min(f[1], f[2]) : INF);
        if (g[2] < INF) g[2] += costR;
        f = g;  // 整批換，避免自我污染
    }
    return f[2];
}

// ---- 2. 一次性操作：LC 1186 刪除一次得到子陣列最大和 ----
int maximumSum(const vector<int>& a) {
    const int NEG = INT_MIN / 2;  // 除以 2 避免加法溢位
    int keep = a[0], del = NEG, ans = a[0];
    for (size_t i = 1; i < a.size(); i++) {
        int nd = max(keep, del + a[i]);  // 刪 a[i] ／ 早就刪過
        int nk = max(keep, 0) + a[i];    // Kadane
        keep = nk;
        del = nd;  // 一起更新
        ans = max({ans, keep, del});
    }
    return ans;
}

// ---- 3. 相鄰約束：LC 276 柵欄塗色（不可連續三根同色）----
int numWays(int n, int k) {
    if (n == 0) return 0;
    if (n == 1) return k;
    long long same = k, diff = 1LL * k * (k - 1);  // i = 1（0-based）
    for (int i = 2; i < n; i++) {
        long long ns = diff;  // 同色只能接在「不同色」之後
        long long nd = (same + diff) * (k - 1);
        same = ns;
        diff = nd;
    }
    return (int)(same + diff);
}

// ---- 4. 條件不互斥：LC 801 使序列遞增的最小交換次數 ----
int minSwap(const vector<int>& a, const vector<int>& b) {
    int n = (int)a.size();
    const int INF = 0x3f3f3f3f;
    int keep = 0, swp = 1;  // f[0][0], f[0][1]
    for (int i = 1; i < n; i++) {
        bool A = (a[i] > a[i - 1]) && (b[i] > b[i - 1]);
        bool B = (a[i] > b[i - 1]) && (b[i] > a[i - 1]);
        int nk = INF, ns = INF;
        if (A) {
            nk = min(nk, keep);
            ns = min(ns, swp + 1);
        }  // 兩邊同動作
        if (B) {
            nk = min(nk, swp);
            ns = min(ns, keep + 1);
        }  // 兩邊異動作
        keep = nk;
        swp = ns;  // 注意：A、B 各自獨立判斷
    }
    return min(keep, swp);
}

// ---- 5. 鄰接圖：LC 935 騎士撥號器（O(n * |S|)，n 不大時的正解）----
int knightDialer(int n) {
    const int MOD = 1'000'000'007;
    static const vector<vector<int>> from = {
        // from[v] = 能跳到 v 的鍵
        {4, 6}, {6, 8},    {7, 9}, {4, 8}, {0, 3, 9},
        {},     {0, 1, 7}, {2, 6}, {1, 3}, {2, 4}};
    vector<long long> f(10, 1), g(10, 0);  // n = 1：每鍵各 1 種
    for (int step = 2; step <= n; step++) {
        for (int v = 0; v < 10; v++) {
            long long s = 0;
            for (int u : from[v]) s += f[u];
            g[v] = s % MOD;
        }
        f.swap(g);
    }
    long long ans = 0;
    for (long long x : f) ans += x;
    return (int)(ans % MOD);
}

// ---- 6. 階段型計數：LC 1955 統計特殊子序列的數目 ----
int countSpecialSubsequences(const vector<int>& nums) {
    const int MOD = 1'000'000'007;
    long long f0 = 0, f1 = 0, f2 = 0;
    for (int d : nums) {
        if (d == 0)
            f0 = (2 * f0 + 1) % MOD;  // 不選／延長／開啟
        else if (d == 1)
            f1 = (2 * f1 + f0) % MOD;
        else
            f2 = (2 * f2 + f1) % MOD;
    }
    return (int)f2;
}

// ---- 7. 矩陣快速冪骨架：n 大到 1e9 且轉移矩陣固定時才用 ----
using Mat = vector<vector<long long>>;
Mat mul(const Mat& A, const Mat& B, long long MOD) {
    int n = (int)A.size(), m = (int)B[0].size(), K = (int)B.size();
    Mat C(n, vector<long long>(m, 0));
    for (int i = 0; i < n; i++)
        for (int k = 0; k < K; k++) {
            if (!A[i][k]) continue;
            for (int j = 0; j < m; j++)
                C[i][j] = (C[i][j] + A[i][k] * B[k][j]) % MOD;
        }
    return C;
}
Mat matPow(Mat A, long long e, long long MOD) {
    int n = (int)A.size();
    Mat R(n, vector<long long>(n, 0));
    for (int i = 0; i < n; i++) R[i][i] = 1;  // 單位矩陣
    while (e > 0) {
        if (e & 1) R = mul(R, A, MOD);
        A = mul(A, A, MOD);
        e >>= 1;
    }
    return R;
}
```

## 時間與空間複雜度

| 型別 | 時間 | 空間 |
| --- | --- | --- |
| 階段型（LCP 19、1955） | $O(nK)$，$K$ = 階段數 | $O(K)$ |
| 一次性操作（1186、2036） | $O(nt)$，$t$ = 特權次數 | $O(t)$ |
| 相鄰約束（276、801） | $O(n)$ | $O(1)$ |
| 鄰接圖（935） | $O(n\,|E|)$ | $O(|S|)$ |
| 鄰接圖 + 矩陣快速冪 | $O(|S|^3\log n)$ | $O(|S|^2)$ |

**何時該切換到矩陣快速冪**：把兩式相等解出來，$n|E| \approx |S|^3\log n$。$|S|=10$、$|E|=20$ 時交叉點在 $n \approx 1500$ 左右，**但常數差很多，實務上 $n \le 10^6$ 都建議直接 DP** ✔。**只有 $n \ge 10^8$ 才非用不可。**

**溢位速查**：

- 276 的 $\mathit{diff}$ 有 $k(k-1)$ ⇒ **`long long`**（$k$ 可能到 $10^4$ 以上）✘；
- 1186 用 `INT_MIN` 當 $-\infty$ **會在 `del + a[i]` 溢位** ✘ ⇒ **用 `INT_MIN / 2`** ✔；
- 935、1955 取模。

**滾動的「整批更新」**：階段型有 $K$ 個值同時變 ⇒ **必須寫進暫存陣列再整批換**（模板 1 的 `f = g`）✔，**不能就地寫**（6.2 的同一條規則）。

## 常見錯誤與邊界條件

- **✘ 條件不互斥卻寫 `else if`（801）。** $A_i$ 與 $B_i$ 可以同時成立（反例 $a=[1,3]$、$b=[2,4]$）⇒ **四條分支各自獨立判斷**（定理 4）。**這是本節第一名的錯。**
- **✘ 模式集合不完備。** 少一個模式 ⇒ 靜默少算。**自檢：小輸入手動列舉所有合法方案，看能不能唯一歸類。**
- **✘ 就地更新導致同一輪互相污染。** 階段型、相鄰約束型都有多個值同時變 ⇒ **先算進暫存、再整批換** ✔。**唯一的例外是 1955（每輪只改一格）**，理由見定理 6。
- **✘ $-\infty$ 用 `INT_MIN`。** 後面的加法立刻溢位 ⇒ **用 `INT_MIN/2` 或 `0x3f3f3f3f` 系列** ✔。
- **✘ 階段型忘記非空約束。** 靠「$i \ge j$ 才有效」自動處理（定理 1）；**若手寫 `if` 逐條檢查，很容易漏掉某條邊。**
- **✘ 1186 把 $f(i,1)$ 的第一條分支寫成 $\max(f(i-1,0),\,0)$。** 那會允許刪除後變成空陣列 ✘。
- **✘ 276 從 $i=0$ 開始遞推。** 必須從 $i=2$ 起步，且 $\mathit{same}_1=k$、$\mathit{diff}_1=k(k-1)$ ✔。**$n=1$、$n=2$ 要特判。**
- **✘ 矩陣快速冪的單位矩陣沒初始化，或半環的單位元寫錯。** $(\min,+)$ 半環的單位矩陣是「對角線 0、其餘 $+\infty$」，**不是全 0** ✘。
- **✘ 鄰接表寫反方向。** $f(i,v)=\sum_{u\to v}f(i-1,u)$ 需要的是**入邊**；935 的騎士跳法對稱所以寫反也對，**但一般圖會錯** ✘。
- **邊界**：$n=0$、$n=1$、$K > n$（階段數多於元素數 ⇒ 無解）、$k=1$（276 只有 $n\le2$ 有解）、所有元素相同、答案為 $\infty$（無解）時的回傳值。

## 與相似技巧的比較

- **與 6.1 / 6.2**：**同一框架，本節只是模式更難設計。** 6.1 的股票次數維 $=$ 本節的階段維；6.1 的「持有 / 未持有」$=$ 本節的相鄰約束維。
- **與 5.3 定理 4（1473 粉刷房子 III）**：那題的「街區數」就是本節的階段維，**而「街區數 = 顏色變化次數 + 1」正是定理 3「只記判斷未來所需的最小資訊」的實例** ✔。
- **與 9 章狀壓 DP**：**分界線是「模式的資訊量」。** 本節的模式是 $O(1)$ 個標籤；狀壓的模式是一個 $n$ 位元的集合。**推論 3.1 的「連續同色 $t$ 根」是中間地帶：$O(m)$ 個標籤。**
- **與最短路**：定理 5 的 $(\min,+)$ 矩陣冪就是「恰好 $k$ 條邊的最短路」，**而 Bellman-Ford 的每一輪鬆弛正是一次 $(\min,+)$ 矩陣向量乘法** ✔。**787 K 站中轉內最便宜的航班就是這個模型。**
- **與 11 章優化 DP**：本節的優化手段是「**壓縮狀態**」（把歷史編碼成少數位元）；11 章的優化手段是「**加速轉移**」（單調隊列、斜率、四邊形）。**兩者正交，可以疊加。**
- **與遞推 / 找規律**：276 這類題的答案常有閉式（如 $k$ 種顏色的柵欄方案數滿足類 Fibonacci 遞推），**但先寫狀態機再觀察，比直接猜規律可靠得多。**

## 本節重點速查

- **模式的四個來源**：**階段順序**（LCP 19、1955）、**一次性操作**（1186）、**相鄰約束**（276、801）、**鄰接圖**（935）。
- **核心心法（整章的靈魂）**：**狀態要記的不是「歷史」，而是「判斷未來合法性所需的最小資訊」。** 276 的「不能連續三根同色」只需一個布林位元，就是這句話的證明。
- **定理 1（LCP 19）**：**階段不能跳** ⇒ 「每段非空」由「$i \ge j$ 才有效」自動保證，不必逐條加 `if`。
- **定理 2（1186）**：布林維編碼「用了沒」；$f(i,1)$ 的兩條分支一個**不能**加 $\max(\cdot,0)$、一個**必須**加——差別在於有沒有再加上 $a_i$。$f(0,1)=-\infty$。
- **定理 3（276）**：$\mathit{same}_i = \mathit{diff}_{i-1}$、$\mathit{diff}_i=(\mathit{same}_{i-1}+\mathit{diff}_{i-1})(k-1)$。推廣到「連續 $m$ 根」是 $O(nm)$，**位元數線性增長而非指數**。
- **定理 4（801，最容易錯）**：$A_i$ 與 $B_i$ **不互斥**（反例 $a=[1,3],b=[2,4]$）⇒ **四條分支獨立判斷，禁用 `else if`。**
- **定理 5**：矩陣快速冪需要**線性轉移 + 係數與 $i$ 無關 + $|S|$ 小**。**股票題不合格（邊權隨日變）。** $(\min,+)$ 半環版 = 恰好 $k$ 條邊的最短路。**$n \le 10^6$ 都不必用。**
- **定理 6（1955）**：$f_d \leftarrow 2f_d + f_{d-1}$ = 不選／延長／開啟三類互斥窮盡；**每輪只改一格，所以不必擔心更新順序。**
- **實作通則**：多個狀態同時變 ⇒ **先算進暫存再整批換**；$-\infty$ 用 `INT_MIN/2`。
