## 這個技術解決什麼問題

輸入是一堆**帶權區間** $(s_i,\ e_i,\ w_i)$，要在「**被選的區間兩兩不重疊**」的前提下最大化總權重。

**暴力枚舉子集是 $2^n$**；本節把它壓到 $O(n\log n)$，靠的是一個關鍵結構性質：

> **按「結束時間」排序之後，「與區間 $i$ 相容的前面區間」恰好構成一個前綴。**

有了這條，「選 $i$」就只需要一個下標 $p(i)$ 就能描述全部歷史 ⇒ **一維 DP 成立**（7.1 定理 1 的替換性質）✔。

**這個模型的覆蓋面比看起來廣**：

| 題 | 區間是什麼 | 權重是什麼 |
| --- | --- | --- |
| 1235 規劃兼職工作 | $[\mathit{start}_i,\ \mathit{end}_i]$ | $\mathit{profit}_i$ |
| 2008 出租車的最大盈利 | $[\mathit{start}_i,\ \mathit{end}_i]$ | $\mathit{end}_i - \mathit{start}_i + \mathit{tip}_i$ |
| 1751 最多可以參加的會議數目 II | $[\mathit{start}_i,\ \mathit{end}_i]$ | $\mathit{value}_i$，**且最多選 $k$ 個** |
| 2054 兩個最好的不重疊活動 | $[\mathit{start}_i,\ \mathit{end}_i]$ | $\mathit{value}_i$，**恰好選至多 2 個** |
| 2830 銷售利潤最大化 | $[\mathit{start}_i,\ \mathit{end}_i]$ | $\mathit{gold}_i$ |
| 435 無重疊區間 | 同上 | **全為 1（無權版）** |

**無權版與有權版的分水嶺**（定理 3）：**無權版有 $O(n\log n)$ 的貪心，有權版沒有——必須 DP。** 這是本節最值得帶走的判斷。

## 狀態／資料結構定義

**預處理**：把所有區間**按結束時間 $e_i$ 遞增排序**（相同則任意）。排序後下標 $1..n$。

**核心輔助量**：

$$p(i) \;=\; \max\{\,j : e_j \le s_i\,\} \quad(\text{不存在則 } 0),$$

即「**最後一個與 $i$ 相容的區間下標**」。**因為排序後 $e$ 單調不減，$p(i)$ 可用二分查找在 $O(\log n)$ 求得** ✔。

**狀態（基本版）**：

$$f(i) = \text{只考慮前 } i \text{ 個區間時的最大總權重} \qquad(\textbf{前綴型，不釘住結尾}),$$
$$f(i) = \max\big(\underbrace{f(i-1)}_{\text{不選 } i},\ \ \underbrace{f(p(i)) + w_i}_{\text{選 } i}\big), \qquad f(0)=0,\quad \text{答案 } f(n).$$

**狀態（限制個數版，1751 / 2054）**：

$$f(i,\,t) = \text{前 } i \text{ 個區間、最多選 } t \text{ 個的最大權重}, \qquad f(i,t)=\max\big(f(i-1,t),\ f(p(i),\,t-1)+w_i\big).$$

**對偶建模（按時刻，2008）**：當**時刻的值域** $T$ 不大時，改用

$$g(t) = \text{到時刻 } t \text{ 為止的最大權重} = \max\Big(g(t-1),\ \max_{\substack{i:\ e_i = t}} \big(g(s_i) + w_i\big)\Big).$$

**兩種建模等價，選哪個看值域**（定理 4）：$T \le 10^5$ ⇒ 按時刻，$O(n+T)$；$T$ 很大而 $n$ 小 ⇒ 按區間 + 二分，$O(n\log n)$。

**⚠ 「相鄰」算不算重疊，題目之間不一致**：

| 題 | $e_i = s_j$ 時 | $p(i)$ 的定義 |
| --- | --- | --- |
| 1235、2008 | **不算重疊**（可以接續） | $\max\{j : e_j \le s_i\}$ |
| 2054 | **算重疊**（要求 $e_i < s_j$） | $\max\{j : e_j < s_i\}$ |

**寫成 `upper_bound` 還是 `lower_bound` 全看這一行** ✘——**這是本節第一名的 WA 來源。**

## 不變量或正確性證明

### 定理 1（**排序 + 選／不選：為什麼一個下標就夠**）

*不變量*：$f(i)$ 恰為「只用前 $i$ 個區間、兩兩不重疊」的最大總權重。

*證明*（對 $i$ 歸納）。

**劃分**：任一最優方案 $A$（只用前 $i$ 個區間）按「**是否選了區間 $i$**」二分——互斥且窮盡 ✔。

- **沒選 $i$** ⇒ $A$ 只用前 $i-1$ 個 ⇒ 權重 $\le f(i-1)$ ✔。
- **選了 $i$** ⇒ $A$ 中其他區間 $j$ 都與 $i$ 不重疊，且 $j < i$（只用前 $i$ 個）。

  **關鍵引理**：$j$ 與 $i$ 不重疊且 $e_j \le e_i$ $\Rightarrow$ $e_j \le s_i$ $\Rightarrow$ $j \le p(i)$。

  *引理的證明*：$j$ 與 $i$ 不重疊表示兩者一前一後。若 $j$ 在 $i$ 之後（$s_j \ge e_i$），則 $e_j \ge s_j \ge e_i$，配合排序 $e_j \le e_i$ 得 $e_j = e_i$，此時 $s_j \ge e_i = e_j \ge s_j$ ⇒ 區間 $j$ 退化成一個點且與 $i$ 的端點重合（**在「端點相接不算重疊」的約定下這是允許的邊界情形，並入下一種處理**）。否則 $j$ 在 $i$ 之前，即 $e_j \le s_i$ ✔。由 $e$ 的單調性，$e_j \le s_i \iff j \le p(i)$ ✔ $\square$

  於是 $A \setminus \{i\}$ 是「只用前 $p(i)$ 個」的合法方案 ⇒ 權重 $\le f(p(i))$ ⇒ $A$ 的權重 $\le f(p(i)) + w_i$ ✔。

反向：兩個候選都對應真實可行的方案（歸納假設）⇒ 取等 ✔。$\square$

> **這條證明真正依賴的前提只有一個：「按結束時間排序」。**
> **它讓「與 $i$ 相容的前面區間」從一個任意集合，變成一個前綴 $[1, p(i)]$**——**而前綴才能用一個下標描述，一維 DP 才成立。**

### 定理 2（**排序鍵必須是結束時間；按開始時間排序會壞掉**）

*命題*：若改按**開始時間**遞增排序，則「與 $i$ 相容的前面區間」不再是前綴，$p(i)$ 也無法二分。

*證明*（反例）。三個區間

$$I_1 = [0,\ 100],\qquad I_2 = [1,\ 2],\qquad I_3 = [3,\ 4].$$

按開始時間排序即 $I_1, I_2, I_3$。與 $I_3$ 相容的前面區間只有 $I_2$（$e_2 = 2 \le 3$），**但 $I_1$ 不相容**（$e_1 = 100 > 3$）⇒ 相容集合 $\{2\}$ **不是前綴** ✘。

而且結束時間序列 $100, 2, 4$ **不單調** ⇒ 無法二分 ✘。$\square$

**若按結束時間排序**，同樣三個區間變成 $I_2(e=2),\ I_3(e=4),\ I_1(e=100)$，與 $I_1$ 相容的是空集（前綴長度 0）、與 $I_3$ 相容的是 $\{I_2\}$（前綴長度 1）✔——**都是前綴。**

> **「按結束時間排序」不是慣例，而是這整套方法的地基。** 記住理由，就不會排錯鍵。

### 定理 3（**無權版可以貪心，有權版不行**）

**(a) 無權版（435 / 最多選幾個不重疊區間）的貪心正確**：按結束時間排序，**能選就選**。

*證明*（交換論證）。設貪心先選的是 $I_1$（結束最早），$A$ 是任一最優解。

- 若 $I_1 \in A$，遞迴處理剩下的區間即可 ✔。
- 若 $I_1 \notin A$，設 $A$ 中結束最早的區間為 $J$。因為 $I_1$ 是全體中結束最早的，$e_1 \le e_J$。**把 $A$ 中的 $J$ 換成 $I_1$**：$A' = A\setminus\{J\}\cup\{I_1\}$。$A'$ 仍兩兩不重疊——因為 $A$ 中其他區間都滿足 $s \ge e_J \ge e_1$ ✔。而 $|A'| = |A|$ ⇒ $A'$ 也是最優解且含 $I_1$ ✔。

反覆施行 ⇒ 存在含貪心選擇的最優解 ⇒ 貪心正確 ✔。$\square$

**(b) 有權版的貪心錯誤**（三種常見貪心全部有反例）：

| 貪心策略 | 反例 | 貪心得到 | 最優 |
| --- | --- | --- | --- |
| 按結束時間，能選就選 | $[0,1]$ 權 1；$[0,10]$ 權 100 | 1 | **100** |
| 按權重遞減，能選就選 | $[0,10]$ 權 10；$[0,4]$ 權 6；$[5,10]$ 權 6 | 10 | **12** |
| 按單位時間權重 | $[0,1]$ 權 5；$[0,10]$ 權 40 | 5 | **40** |

*為什麼交換論證在有權版失效*：(a) 的論證只用到「$|A'| = |A|$」——**個數守恆**。有權版換掉 $J$ 換成 $I_1$ 後 $w_1$ 可能遠小於 $w_J$ ⇒ **總權重會下降** ✘。$\square$

> **判準（可以套到任何「選不重疊物件」的題）**：
> **目標是「個數」⇒ 貪心（按結束時間）；目標是「加權和」⇒ DP。**
> **這與 5.3 定理 3「min-max 可二分、min-sum 只能 DP」是同一種思考：問你的目標函式能不能被拆成逐項獨立的局部條件。**

### 定理 4（**按時刻 DP 與按區間 DP 等價**）

*命題*：$g(t) = \max\big(g(t-1),\ \max_{i:\,e_i=t}(g(s_i)+w_i)\big)$（$g(0)=0$）與定理 1 的 $f$ 給出相同答案。

*證明*。建立雙射：一個「兩兩不重疊的區間集合」對應時間軸上一條從 0 走到 $T$ 的路徑，每一步要麼「原地待一個時刻」（$t-1 \to t$，權重 0），要麼「跳過一個區間」（$s_i \to e_i$，權重 $w_i$）✔。

**不重疊 ⟺ 這些跳躍在時間軸上互不交疊 ⟺ 它們能串成一條路徑** ✔。於是兩種 DP 都在同一張 DAG 上求最長路 ⇒ 答案相同 $\square$

**選哪一種**：

| | 按區間 | 按時刻 |
| --- | --- | --- |
| 複雜度 | $O(n\log n)$ | $O(n + T)$ |
| 適用 | $T$ 巨大（$10^9$） | $T$ 小（$\le 10^6$） |
| 需要 | 排序 + 二分 | **按 $e_i$ 分桶**（`vector<vector<...>> byEnd`） |
| 2008 | ✔ 可用 | ✔ **更簡單，推薦** |

**⚠ 按時刻版必須「先繼承 $g(t-1)$，再處理結束於 $t$ 的區間」**，否則會漏掉「這一刻什麼都不做」的選項 ✘。

**⚠ 值域大但區間少 ⇒ 離散化**：把所有端點收集起來排序去重，時刻 DP 就退化成區間 DP ✔——**兩種建模因此可以互相轉換。**

### 定理 5（**2054「至多兩個」：前綴最大值就夠，不必開維**）

*設定*：選至多兩個不重疊活動（要求 $e_i < s_j$，**嚴格**），最大化權重和。

*命題*：按結束時間排序後，維護前綴最大值 $\mathit{best}(i) = \max_{j\le i} w_j$，答案為

$$\max\Big(\ \max_i w_i,\ \ \max_i \big(w_i + \mathit{best}(p(i))\big)\ \Big), \qquad p(i)=\max\{j : e_j < s_i\}.$$

*證明*。任一「恰好兩個」的最優解 $\{J_1, J_2\}$（設 $e_{J_1} < s_{J_2}$）——**枚舉「後面那個」$J_2 = i$**。此時 $J_1$ 必須滿足 $e_{J_1} < s_i$ ⇒ $J_1 \le p(i)$ ⇒ $w_{J_1} \le \mathit{best}(p(i))$ ✔。

**每個二元組恰被枚舉一次**（由「哪個在後面」唯一決定）⇒ 互斥窮盡 ✔。另外加上「只選一個」的情形 ✔。$\square$

> **這是「$t$ 維度只有 2 時的特例化」**：一般的 $f(i,t)$ 在 $t\le2$ 時退化成「**前綴最大值 + 枚舉最後一個**」，程式碼短得多 ✔。
> **同樣的簡化在 4.2.1 定理 5（1671，前後綴 LIS）出現過。**

**⚠ 這題是嚴格不重疊**（$e_i < s_j$）⇒ 二分要找 $e_j < s_i$ 的最後一個，**用 `lower_bound(s_i) - 1`；而 1235 的非嚴格版用 `upper_bound(s_i) - 1`** ✔。**這一個字元的差別就是 AC 與 WA。**

### 定理 6（**1751「至多 $k$ 個」：加一維，且「至多」= 直接讀**）

*命題*：$f(i,t)=\max\big(f(i-1,t),\ f(p(i),t-1)+w_i\big)$，$f(\cdot,0)=0$、$f(0,\cdot)=0$，答案 $f(n,k)$。

*證明*。
**轉移**：同定理 1，多記「已選幾個」✔。

**為什麼答案直接讀 $f(n,k)$ 而不必取 $\max_{t\le k}$**：$f(i,t)$ **對 $t$ 單調不減**——「至多 $t$ 個」的方案集合包含「至多 $t-1$ 個」的方案集合 ✔（形式上：轉移的第一條分支 $f(i-1,t)$ 與初始化 $f(\cdot,0)=0$ 保證了「什麼都不選」永遠可行）$\square$

**與 5.3 定理 1 的對照**：那裡的「至多 vs 恰好」需要額外論證（「多切一刀會不會變差」），**這裡因為「不選」永遠是合法且權重為 0 的選項，單調性是免費的** ✔——**前提是 $w_i \ge 0$。若允許負權重，「至多 $k$」與「恰好 $k$」就會分家。**

**複雜度** $O(nk + n\log n)$；**$p(i)$ 只需算一次**（與 $t$ 無關）⇒ **先預處理成陣列，別在雙層迴圈裡重複二分** ✔。

## C++17 模板

```cpp
// ---- 0. 共用：排序 + 預處理 p(i)（1-based，f[0] 為虛擬起點）----
struct Interval {
    int s, e;
    long long w;
};

// touching = true  表示 e_j == s_i 算相容（1235、2008）
// touching = false 表示要求 e_j <  s_i（2054）
vector<int> buildPrev(vector<Interval>& a, bool touching) {
    sort(a.begin(), a.end(),
         [](const Interval& x, const Interval& y) { return x.e < y.e; });
    int n = (int)a.size();
    vector<int> ends(n);
    for (int i = 0; i < n; i++) ends[i] = a[i].e;
    vector<int> p(n + 1, 0);
    for (int i = 1; i <= n; i++) {
        // 在 ends[0..i-2] 中找最後一個 <= s（或 < s）的位置
        int lim = a[i - 1].s;
        auto it = touching
                      ? upper_bound(ends.begin(), ends.begin() + i - 1, lim)
                      : lower_bound(ends.begin(), ends.begin() + i - 1, lim);
        p[i] = (int)(it - ends.begin());  // 已經是 1-based 的個數
    }
    return p;
}

// ---- 1. 基本版：LC 1235 規劃兼職工作，O(n log n) ----
long long maxProfit(vector<Interval> a) {
    vector<int> p = buildPrev(a, /*touching=*/true);
    int n = (int)a.size();
    vector<long long> f(n + 1, 0);
    for (int i = 1; i <= n; i++) f[i] = max(f[i - 1], f[p[i]] + a[i - 1].w);
    return f[n];
}

// ---- 2. 至多 k 個：LC 1751，O(n k + n log n) ----
long long maxValueAtMostK(vector<Interval> a, int k) {
    vector<int> p = buildPrev(a, /*touching=*/false);  // 1751 要求嚴格不重疊
    int n = (int)a.size();
    vector f(n + 1, vector<long long>(k + 1, 0));
    for (int i = 1; i <= n; i++)
        for (int t = 1; t <= k; t++)
            f[i][t] = max(f[i - 1][t], f[p[i]][t - 1] + a[i - 1].w);
    return f[n][k];
}

// ---- 3. 至多兩個：LC 2054，前綴最大值即可，O(n log n) ----
long long maxTwoEvents(vector<Interval> a) {
    vector<int> p = buildPrev(a, /*touching=*/false);  // 要求 e_i < s_j
    int n = (int)a.size();
    vector<long long> best(n + 1, 0);  // best[i] = max w over 前 i 個
    long long ans = 0;
    for (int i = 1; i <= n; i++) {
        long long w = a[i - 1].w;
        ans = max(ans, w + best[p[i]]);  // 含「只選一個」（best[0] = 0）
        best[i] = max(best[i - 1], w);
    }
    return ans;
}

// ---- 4. 按時刻 DP：LC 2008 出租車的最大盈利，O(n + T) ----
long long maxTaxiEarnings(int T, vector<vector<int>>& rides) {
    vector<vector<pair<int, long long>>> byEnd(T +
                                               1);  // byEnd[e] = {start, earn}
    for (auto& r : rides) {
        int s = r[0], e = r[1];
        byEnd[e].push_back({s, (long long)(e - s + r[2])});
    }
    vector<long long> g(T + 1, 0);
    for (int t = 1; t <= T; t++) {
        g[t] = g[t - 1];  // 先繼承：這一刻什麼都不做
        for (auto& [s, earn] : byEnd[t]) g[t] = max(g[t], g[s] + earn);
    }
    return g[T];
}

// ---- 5. 無權版貪心：最多能選幾個不重疊區間（435 的對偶）----
int maxNonOverlapping(vector<Interval> a) {
    sort(a.begin(), a.end(),
         [](const Interval& x, const Interval& y) { return x.e < y.e; });
    int cnt = 0, last = INT_MIN;
    for (auto& iv : a)
        if (iv.s >= last) {
            cnt++;
            last = iv.e;
        }  // 能選就選
    return cnt;
}
```

## 時間與空間複雜度

| 做法 | 時間 | 空間 |
| --- | --- | --- |
| 基本版（排序 + 二分 + DP） | $O(n\log n)$ | $O(n)$ |
| 至多 $k$ 個 | $O(n\log n + nk)$ | $O(nk)$，滾動後 $O(n)$ 或 $O(k)$ |
| 至多 2 個（前綴最大值） | $O(n\log n)$ | $O(n)$ |
| 按時刻 DP | $O(n + T)$ | $O(n + T)$ |
| 無權貪心 | $O(n\log n)$ | $O(1)$ |

**排序是複雜度下界的來源**——即使 $p(i)$ 能 $O(1)$ 算出，仍需 $O(n\log n)$ 排序 ✔。

**$p(i)$ 要預先算好**：在 $k$ 維迴圈裡重複二分會變成 $O(nk\log n)$ ✘。

**滾動（1751）**：$f(i,t)$ 依賴 $f(p(i),t-1)$，**而 $p(i) < i$ 但不一定是 $i-1$** ⇒ **$i$ 這一維不能滾動掉**（要隨機存取 $f(p(i),\cdot)$）✘；**$t$ 這一維可以**（用兩層 `prev`/`cur`，$t$ 遞減也行）✔。**這與 3.1 背包能滾掉容量維不同——差別在於「依賴的下標是否固定偏移」。**

**溢位**：1235 的 $\mathit{profit} \le 10^4$、$n \le 5\times10^4$ ⇒ 總和 $\le 5\times10^8$，`int` 勉強夠但**建議 `long long`**；2008 的 $\mathit{tip}$ 加上距離，$T \le 10^5$ ⇒ **必須 `long long`** ✘。

## 常見錯誤與邊界條件

- **✘ 按開始時間排序。** 相容集合不是前綴、結束時間不單調 ⇒ 二分與 DP 都垮（定理 2）。**永遠按結束時間排序。**
- **✘ `upper_bound` / `lower_bound` 選錯。** 端點相接算不算重疊，每題不同：1235、2008 **算相容**（用 `upper_bound`）；2054、1751 **要求嚴格**（用 `lower_bound`）。**先讀清楚題目再寫這一行。**
- **✘ 二分的搜尋範圍寫成整個 `ends`。** 必須限制在 `ends.begin() + i - 1`，否則會找到自己或後面的區間 ✘。
- **✘ 有權版用貪心。** 三個反例都在定理 3(b)。**個數 ⇒ 貪心，權重 ⇒ DP。**
- **✘ 按時刻 DP 忘記先繼承 $g(t-1)$。** 那等於強迫每一刻都要有區間結束 ✘。
- **✘ 在 $k$ 維迴圈裡重複二分。** 預處理 $p(i)$。
- **✘ 忘記「一個都不選」。** $f(0)=0$、$\mathit{best}(0)=0$；**若權重可能為負，答案還要與 0 取 $\max$**（或依題目是否允許空集合）✔。
- **✘ 1751 的 $k > n$。** 直接取 $k=\min(k,n)$，否則多開一堆無用狀態（同 6.1 定理 4 的 `k = min(k, n/2)` 精神）。
- **✘ 溢位。** 2008 必須 `long long`。
- **邊界**：$n=0$、$n=1$、所有區間互相重疊（答案 = 單一最大權重）、所有區間都不重疊（答案 = 全選）、零長度區間 $s_i = e_i$（**在「端點相接算相容」的題目裡，兩個同位置的零長度區間可以都選**——確認題目是否允許）。

## 與相似技巧的比較

- **與 7.1 一維 DP**：**本節就是 7.1 的一個實例，只是 $\mathrm{pred}(i) = \{i-1,\ p(i)\}$ 需要二分才求得出來。** 定理 1 的引理正是 7.1 定理 1「替換性質」的驗證。
- **與 4.2 LIS**：兩者都是「排序後在偏序上找最優鏈」。**差別：LIS 的相容關係是 $a_j < a_i$（要逐個比較），本節的相容關係因為排序而變成前綴（只需一個下標）** ⇒ 本節更快。
- **與 3.1 0-1 背包**：「選 / 不選」的骨架相同；**差別在於背包的資源是容量（一個數字），本節的資源是時間軸上的佔用（一個區間）**——**而「按結束時間排序」正是把後者化約成前者的關鍵。**
- **與 5.3 加段數維**：1751 的 $k$ 維與 5.3 的段數維是同一手法；**但本節的「至多 $k$」單調性是免費的**（定理 6），5.3 則需要額外論證。
- **與貪心（區間排程）**：定理 3 給出了完整的分界。**無權 ⇒ 貪心；有權 ⇒ DP。** 435 無重疊區間、452 引爆氣球都屬於無權版。
- **與掃描線 / 線段樹**：若權重會動態改變，或要支援「查詢某時刻前的最大值」，可以把 $f$ 存進線段樹按端點掃描 ⇒ **同樣 $O(n\log n)$，但能處理更複雜的查詢**。**本節的靜態版用二分就夠。**
- **與 2.1 / 3.1 的滾動**：本節的 $i$ 維**不能滾動**（依賴 $p(i)$ 這個非固定偏移的下標）——**這是判斷「能不能滾」的好例子：能滾的前提是依賴的下標與當前下標差固定。**

## 本節重點速查

- **地基**：**按結束時間排序** ⇒ 「與 $i$ 相容的前面區間」變成前綴 $[1,p(i)]$ ⇒ 一維 DP 成立。
- **骨架**：$f(i)=\max\big(f(i-1),\ f(p(i))+w_i\big)$，$p(i)=\max\{j: e_j \le s_i\}$，二分求得，$O(n\log n)$。
- **定理 2**：**按開始時間排序會壞掉**（反例 $[0,100],[1,2],[3,4]$：相容集合不是前綴，結束時間不單調）。
- **定理 3（最實用的判準）**：**目標是個數 ⇒ 貪心（按結束時間，能選就選，交換論證）；目標是加權和 ⇒ 必須 DP**（三個貪心反例）。差別在交換論證只保個數守恆、不保權重。
- **定理 4**：**按時刻 DP** $g(t)=\max(g(t-1),\max_{e_i=t}(g(s_i)+w_i))$ 與按區間 DP 等價；$T$ 小用時刻版（2008），$T$ 大用區間版或離散化。**必須先繼承 $g(t-1)$。**
- **定理 5（2054）**：至多兩個 ⇒ **前綴最大值 + 枚舉後面那個**，不必開 $t$ 維。
- **定理 6（1751）**：至多 $k$ 個 ⇒ 加一維，**「至多」直接讀 $f(n,k)$**（單調性免費，前提 $w_i\ge0$）。**$p(i)$ 要預處理，別在雙層迴圈裡二分。**
- **第一名的 WA**：**端點相接算不算重疊** ⇒ `upper_bound`（1235、2008 相容）vs `lower_bound`（2054、1751 嚴格）。
- **不能滾動 $i$ 維**：依賴的 $p(i)$ 不是固定偏移。
