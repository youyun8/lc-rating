## 這個技術解決什麼問題

答案必須是一段**連續**的元素。「連續」這兩個字帶來一條鐵律（4.1.1 定理 6 已經說過，這裡是它的主場）：

> **狀態必須釘住結尾**：$f(i)$ = 「**以第 $i$ 個元素結尾**的最優值」，答案取 $\max_i f(i)$。

**為什麼一定要釘住結尾？** 因為「連續」是一個**局部約束**——新元素 $a_i$ 能不能加進來，只取決於「目前這段的結尾是不是 $a_{i-1}$」。若狀態寫成「前 $i$ 個元素的最優值」，**你就不知道那個最優解的右端點在哪，也就無法判斷 $a_i$ 能不能接上** ✘。

$$f(i) = g\big(f(i-1),\ a_i\big), \qquad \text{答案} = \max_i f(i).$$

**這一節收的是「$g$ 長什麼樣」的各種變體**：

| 題 | $f(i)$ 的語意 | 轉移 |
| --- | --- | --- |
| 53 最大子陣列和 | 以 $i$ 結尾的最大和 | $\max(f(i-1),0)+a_i$（Kadane） |
| 152 乘積最大子陣列 | 以 $i$ 結尾的最大 / 最小乘積 | 三個候選取極值 |
| 467 環繞字串中唯一的子字串 | 以 $s_i$ 結尾的最長環繞段 | $f(i-1)+1$ 或 1 |
| 2262 字串的總引力 | 以 $i$ 結尾的所有子字串的引力和 | $f(i-1) + (i - \mathrm{prev})$ |
| 828 統計子串中的唯一字元 | （用**貢獻法**更直接） | 每個位置獨立計數 |
| 1186 刪除一次得到子陣列最大和 | 釘住結尾 × 布林維 | 見 6.3 定理 2 |

**本節有兩套互補的思路，都要會**：

1. **釘住結尾的 DP**（定理 1–4）：適合「求某個最優子陣列」；
2. **貢獻法 / 前綴和**（定理 5）：適合「對所有子陣列求和」——**這時 DP 反而不是最自然的語言。**

## 狀態／資料結構定義

**基本形**：

$$f(i) = \text{以下標 } i \text{ 結尾的最優值}, \qquad f(i) = g(f(i-1),\ a_i), \qquad \text{答案} = \max_i f(i).$$

**三個必須先確認的設計問題**：

| 問題 | 影響 |
| --- | --- |
| **允不允許空子陣列？** | 53 要求非空 ⇒ 初始 $f(0)=a_0$、答案不能與 0 取 $\max$ ✘ |
| **需不需要一對狀態？** | 乘積、含負號的量 ⇒ 同時維護 $(\max,\min)$（定理 3） |
| **有沒有「重置點」？** | 152 遇到 0、467 遇到不連續字元 ⇒ $f(i)$ 直接重來 |

**「重置」與「不帶上前面」是不同的兩件事**：

- **不帶上前面**（Kadane 的 $\max(f(i-1),0)$）：前面那段沒用，但**我仍然從 $a_i$ 開始一段新的** ✔；
- **重置為不可用**（$f(i) = -\infty$ 或 0 且不計入答案）：**這個位置根本不能當結尾**。

**混淆這兩者是本節最常見的 WA** ✘。

**前綴和視角**（定理 2）：令 $P_0=0$、$P_i = a_1+\cdots+a_i$，則

$$\text{子陣列 } (j,i] \text{ 的和} = P_i - P_j \quad\Rightarrow\quad \max_{\text{子陣列}} = \max_i \Big(P_i - \min_{j<i} P_j\Big).$$

**這個視角是所有「和的變形題」的通用入口**——**加上長度限制、上下界限制時，DP 版本很難改，前綴和版本只要換掉「$\min_{j<i}$」的求法。**

## 不變量或正確性證明

### 定理 1（**Kadane 的正確性**）

*不變量*：$f(i) = \max\{\,\mathrm{sum}(a[j..i]) : 0\le j\le i\,\}$，即「以 $i$ 結尾的所有非空子陣列」的最大和。

*命題*：$f(i) = \max\big(f(i-1),\ 0\big) + a_i$，$f(0)=a_0$。

*證明*（對 $i$ 歸納）。**按「這段子陣列的長度是不是 1」劃分**——互斥且窮盡 ✔：

- **長度為 1** ⇒ 和為 $a_i$；
- **長度 $\ge 2$** ⇒ 它等於「某個以 $i-1$ 結尾的非空子陣列」再接上 $a_i$ ⇒ 最大值為 $f(i-1)+a_i$（歸納假設）✔。

故 $f(i) = \max\big(a_i,\ f(i-1)+a_i\big) = \max\big(0,\ f(i-1)\big) + a_i$ ✔。$\square$

**⚠ 「非空」這個限定不可省**：

- 若允許空子陣列，$f(i)$ 的定義會變成 $\max(f(i-1),0)+a_i$ **與 $0$ 再取 $\max$**，答案在全負陣列時是 0；
- **53 要求非空** ⇒ **答案是 $\max_i f(i)$，不能寫成 $\max(0,\max_i f(i))$** ✘。全負陣列 $[-3,-1,-2]$ 的答案是 $-1$，不是 0。

**推論 1.1（為什麼可以 $O(1)$ 空間）**：$f(i)$ 只依賴 $f(i-1)$ ⇒ 一個變數 + 一個全域答案 ✔。

**推論 1.2（回溯出區間）**：在 $f(i-1) < 0$ 時記錄「新段起點 = $i$」，並在更新全域答案時把當前起點與 $i$ 一起記下 ✔。

### 定理 2（**前綴和視角，以及它為什麼更好推廣**）

*命題*：$\displaystyle\max_{\text{非空子陣列}} \mathrm{sum} \;=\; \max_{1\le i\le n}\Big(P_i - \min_{0\le j<i} P_j\Big)$。

*證明*。子陣列與「一對下標 $(j,i)$，$0\le j<i\le n$」一一對應（$j$ 是開區間左端、$i$ 是閉區間右端）✔，其和為 $P_i-P_j$。固定 $i$ 取 $P_j$ 最小 ⇒ 內層最優；再對 $i$ 取 $\max$ ⇒ 全域最優 ✔。$\square$

**與 Kadane 的等價**：$f(i) = P_i - \min_{j<i}P_j$，兩式逐項相同 ✔——**Kadane 只是把 $\min_{j<i}P_j$ 用一個變數增量維護。**

> **這個視角的價值全在推廣。** 加上不同的限制時，DP 幾乎改不動，前綴和版只要換掉「怎麼找最小的 $P_j$」：

| 變形 | $\min_{j<i}P_j$ 換成什麼 | 工具 | 題 |
| --- | --- | --- | --- |
| 子陣列**長度 $\ge k$** | $\min_{j \le i-k} P_j$ | 前綴最小值 | 152 型 |
| 子陣列**長度 $\le k$** | $\min_{i-k\le j<i}P_j$ | **單調隊列**（11.3 的原型） | 918 環形、862 |
| 和 $\ge k$ 的**最短**子陣列 | 找最大的 $j$ 使 $P_j \le P_i-k$ | 單調隊列 | 862 |
| 和 $= k$ 的**個數** | 統計 $P_j = P_i - k$ 的個數 | 雜湊表 | 560 |
| 和 $\le k$ 的最大和 | 找 $P_i - k$ 的後繼 | 有序集合 | 363 |

**⚠ 「元素全為正」時前綴和單調 ⇒ 可用滑動窗口（雙指標）；有負數時前綴和不單調 ⇒ 滑動窗口失效，必須用上表的工具** ✘。**這是「什麼時候能用雙指標」最可靠的判準。**

### 定理 3（**152：連續型的 $(\max,\min)$ 對，與 2708 的關鍵差異**）

*命題*：$\mathit{mx}_i$ / $\mathit{mn}_i$ = 以 $i$ 結尾的最大 / 最小乘積，則

$$\mathit{mx}_i = \max\big(a_i,\ \ \mathit{mx}_{i-1}\cdot a_i,\ \ \mathit{mn}_{i-1}\cdot a_i\big), \qquad \mathit{mn}_i = \min\big(a_i,\ \ \mathit{mx}_{i-1}\cdot a_i,\ \ \mathit{mn}_{i-1}\cdot a_i\big).$$

*證明*。**為什麼要同時記最小值**：轉移 $x\mapsto x\cdot a_i$ 在 $a_i<0$ 時**單調遞減** ⇒ 最大值來自上一步的**最小值** ✔。而單調函數把區間端點映到端點 ⇒ 只保留兩個端點就足夠（1.3 定理 4、6.2 定理 6 的同一條）$\square$

**⚠ 與 6.2 定理 6（2708 子序列版）的差異——只差一項，但意義完全不同**：

| | 2708（子序列） | 152（連續子陣列） |
| --- | --- | --- |
| 候選項 | $\mathit{mx}_{i-1}$、$\mathit{mx}_{i-1}a_i$、$\mathit{mn}_{i-1}a_i$、$a_i$ | $\mathit{mx}_{i-1}a_i$、$\mathit{mn}_{i-1}a_i$、$a_i$ |
| 多出的 $\mathit{mx}_{i-1}$ | **「不選 $a_i$」** ✔ | **不存在**——連續型必須以 $a_i$ 結尾 ✘ |
| $a_i$ 那一項的意義 | 「從 $a_i$ 重新開始」 | 「從 $a_i$ 重新開始」（相同） |

**把「不選」那一項誤加進 152，會讓答案變成子序列的最大乘積** ✘——**這是「釘住結尾」在程式碼上的具體體現。**

**⚠ $a_i = 0$**：$\mathit{mx}_i = \mathit{mn}_i = 0$（三個候選都是 0）✔——**0 自動起到「重置」的作用，不需要特判** ✔。**下一步 $\mathit{mx}\cdot a_{i+1}=0$，等於重新開始，正確。**

**⚠ 溢位**：152 保證任意前綴乘積落在 32 位元內，**但中間量 $\mathit{mn}_{i-1}\cdot a_i$ 仍建議用 `long long`** ✔。

### 定理 4（**467：「以某字元結尾、長度固定 ⇒ 內容唯一」的去重論證**）

*設定*：求 $s$ 中有多少個**不同的**子字串出現在無限環繞字串 `"...abcdefghijklmnopqrstuvwxyzabcd..."` 中。

*命題*：令 $\mathit{len}[c]$ = 「以字元 $c$ 結尾的、最長的環繞子串長度」，則答案 $=\sum_{c} \mathit{len}[c]$。

*證明*。分兩步。

**(a) 以字元 $c$ 結尾、長度為 $L$ 的環繞子串，內容唯一。**
環繞子串的定義是「字元依字母序循環遞增」⇒ 給定結尾字元 $c$ 與長度 $L$，往前每個位置的字元都被唯一決定（$c-1, c-2, \dots$ 循環）✔。

**(b) 以 $c$ 結尾、長度 $\le \mathit{len}[c]$ 的環繞子串都在 $s$ 中出現。**
取達到 $\mathit{len}[c]$ 的那一段，**它的任意後綴都是更短的、以 $c$ 結尾的環繞子串，且都出現在 $s$ 中** ✔。反之長度 $> \mathit{len}[c]$ 的不出現（否則與最大性矛盾）✔。

由 (a)，以 $c$ 結尾的不同子串個數 $=$ 合法長度的個數 $=\mathit{len}[c]$；由 (b)，這些長度恰是 $1..\mathit{len}[c]$ ✔。不同結尾字元的子串必不相同 ⇒ 求和不重複 ✔。$\square$

**$\mathit{len}[c]$ 的計算**：掃描時維護「當前連續環繞段的長度」$k$（$s_i = s_{i-1}+1 \pmod{26}$ 則 $k{+}{+}$，否則 $k=1$），然後 $\mathit{len}[s_i] \leftarrow \max(\mathit{len}[s_i],\ k)$ ✔。

> **這條的可遷移之處：計數不同子串時，「按結尾字元（或結尾位置）分類 + 證明同類內長度決定內容」是一個標準的去重框架。**
> **同樣的思路可以用來數「不同的等差子串」「不同的全 1 子矩陣」。**

### 定理 5（**貢獻法：對所有子陣列求和時，換一個求和順序**）

*命題*：對任何形如 $\displaystyle\mathrm{Ans} = \sum_{\text{子陣列 } I} F(I)$ 且 $F(I)=\sum_{x \in I} \phi(x, I)$ 的問題，可以交換求和順序：

$$\mathrm{Ans} = \sum_{x} \sum_{I \ni x} \phi(x,I) = \sum_x \big(\text{位置 } x \text{ 的總貢獻}\big).$$

**這不是 DP，而是「把答案沿著另一個軸切開」**——**而切開之後，每個位置的貢獻常常有 $O(1)$ 的閉式。**

**(a) 828 統計子串中的唯一字元**：$F(I)$ = $I$ 中恰好出現一次的字元個數。

固定位置 $i$（字元 $c$），令 $p$ = 前一個 $c$ 的位置（無則 $-1$）、$q$ = 後一個 $c$ 的位置（無則 $n$）。

> **$c$ 在子串 $I$ 中唯一出現且該次出現是位置 $i$** $\iff$ $I$ 包含 $i$、但**不包含 $p$ 與 $q$** $\iff$ $I$ 的左端在 $(p,\ i]$、右端在 $[i,\ q)$。

*證明*：($\Rightarrow$) 若 $I$ 含 $p$ 或 $q$，則 $c$ 出現至少兩次 ✘。($\Leftarrow$) 若左端 $>p$ 且右端 $<q$，$I$ 中除了 $i$ 沒有其他 $c$（$p,q$ 是最近的兩個）✔。

⇒ 貢獻為 $(i-p)\times(q-i)$，答案 $=\sum_i (i-p_i)(q_i-i)$ ✔。**每個 $(i, I)$ 對恰被算一次 ⇒ 嚴格劃分**（1.2 定理 2 的又一次應用）$\square$

**(b) 2262 字串的總引力**：$F(I)$ = $I$ 中不同字元的個數。

**用「每個字元在 $I$ 中的第一次出現」代表它**（**這是關鍵的去重手法：把「不同字元數」寫成「首次出現的位置數」**）✔：

> 位置 $i$（字元 $c$）是 $I$ 中 $c$ 的首次出現 $\iff$ $I$ 的左端在 $(\mathrm{prev}[c],\ i]$、右端在 $[i,\ n)$

⇒ 貢獻 $(i - \mathrm{prev}[c])\times(n-i)$ ✔。

**等價的 DP 寫法**：令 $f(i)$ = 「所有以 $i$ 結尾的子字串的引力總和」，則

$$f(i) = f(i-1) + \big(i - \mathrm{prev}[c]\big), \qquad \mathrm{Ans} = \sum_i f(i).$$

*證明*：把 $a_i$ 接到每個以 $i-1$ 結尾的子字串後面。**新字元 $c$ 讓引力 $+1$ 的，恰是那些不含 $c$ 的子字串**，即左端在 $(\mathrm{prev}[c],\ i]$ 的那 $i-\mathrm{prev}[c]$ 個（含長度為 1 的 $[i,i]$）✔。$\square$

> **兩種寫法完全等價，選哪個看習慣。**
> **判準：看到「對所有子陣列 / 子字串求某個統計量的總和」，先想貢獻法，不要硬套 DP。**
> **DP 適合「求一個最優子陣列」，貢獻法適合「對所有子陣列求和」。**

### 定理 6（**什麼時候「以 $i$ 結尾」不夠用**）

*命題*：釘住結尾的一維 DP 成立的充要條件是——**$f(i)$ 能由 $f(i-1)$ 與 $a_i$ 在 $O(1)$ 時間算出**，也就是「以 $i$ 結尾的最優解」與「以 $i-1$ 結尾的最優解」之間有直接的遞推關係。

**三種常見的失效情形與對應工具**：

| 失效原因 | 例 | 該用什麼 |
| --- | --- | --- |
| **合法性是「整段的性質」，加一個元素可能讓段從合法變不合法，且需要縮左端** | 3 最長無重複字元子串、1004 最大連續 1 的個數 III | **滑動窗口**（左端單調右移） |
| **需要查詢「前面所有 $j$ 中滿足某條件的最優 $P_j$」** | 560 和為 $k$、862 和至少為 $k$ 的最短 | **前綴和 + 雜湊表 / 單調隊列**（定理 2 的表） |
| **需要「左邊第一個比我小的位置」** | 84 柱狀圖最大矩形、907 子陣列的最小值之和 | **單調棧 + 貢獻法** |

**為什麼滑動窗口不是 DP**：滑動窗口維護的是「以 $i$ 結尾的**最長合法**段的左端」，它依賴一個**單調性前提**：

> **左端隨右端單調不減**——即「若 $[l,r]$ 不合法，則 $[l,r']$ 對所有 $r'>r$ 也不合法」。

**這個性質對「無重複字元」成立**（加元素只會讓重複更多）✔，**但對「和為 $k$」在有負數時不成立** ✘ ⇒ 那時必須回到前綴和 + 雜湊。

> **判準三連問**：
> 1. 加一個元素會不會讓合法變不合法？**會 ⇒ 想滑動窗口**（並檢查上面的單調性）。
> 2. 我需要的資訊是不是「前面某個 $j$ 的值」？**是 ⇒ 前綴和 + 資料結構。**
> 3. 我要對所有子陣列求和？**是 ⇒ 貢獻法 + 單調棧。**
> **三個都否，才是本節的純 DP。**

```cpp
// ---- 1. Kadane：LC 53 最大子陣列和（非空），O(n) / O(1) ----
int maxSubArray(const vector<int>& a) {
    int cur = a[0], ans = a[0];
    for (size_t i = 1; i < a.size(); i++) {
        cur = max(cur, 0) + a[i];  // 帶不帶上前面那段
        ans = max(ans, cur);  // 注意：不能與 0 取 max（要求非空）
    }
    return ans;
}

// ---- 1b. 同時回傳區間 [l, r] ----
tuple<int, int, int> maxSubArrayRange(const vector<int>& a) {
    int cur = a[0], ans = a[0], start = 0, bl = 0, br = 0;
    for (int i = 1; i < (int)a.size(); i++) {
        if (cur < 0) {
            cur = a[i];
            start = i;
        }  // 前面是負擔，重開一段
        else
            cur += a[i];
        if (cur > ans) {
            ans = cur;
            bl = start;
            br = i;
        }
    }
    return {ans, bl, br};
}

// ---- 2. 前綴和視角：長度至少 k 的最大子陣列和 ----
long long maxSumAtLeastK(const vector<int>& a, int k) {
    int n = (int)a.size();
    vector<long long> P(n + 1, 0);
    for (int i = 0; i < n; i++) P[i + 1] = P[i] + a[i];
    long long ans = LLONG_MIN, mn = LLONG_MAX;
    for (int i = k; i <= n; i++) {
        mn = min(mn, P[i - k]);  // 只有 j <= i-k 才合法
        ans = max(ans, P[i] - mn);
    }
    return ans;
}

// ---- 3. LC 152 乘積最大子陣列：連續型的 (max, min) 對 ----
int maxProduct(const vector<int>& a) {
    long long mx = a[0], mn = a[0], ans = a[0];
    for (size_t i = 1; i < a.size(); i++) {
        long long v = a[i];
        long long nmx = max({v, mx * v, mn * v});  // 沒有「不選」那一項
        long long nmn = min({v, mx * v, mn * v});
        mx = nmx;
        mn = nmn;  // 一起更新，避免污染
        ans = max(ans, mx);
    }
    return (int)ans;
}

// ---- 4. LC 467 環繞字串中唯一的子字串 ----
int findSubstringInWraproundString(const string& s) {
    vector<int> len(26, 0);
    int k = 0;
    for (size_t i = 0; i < s.size(); i++) {
        if (i > 0 && (s[i] - s[i - 1] + 26) % 26 == 1)
            k++;
        else
            k = 1;  // 環繞中斷，重置
        int c = s[i] - 'a';
        len[c] = max(len[c], k);
    }
    return accumulate(len.begin(), len.end(), 0);
}

// ---- 5a. 貢獻法：LC 828 統計子串中的唯一字元 ----
int uniqueLetterString(const string& s) {
    int n = (int)s.size();
    vector<vector<int>> pos(26);  // 每個字元出現的位置
    for (int i = 0; i < n; i++) pos[s[i] - 'a'].push_back(i);
    long long ans = 0;
    for (int c = 0; c < 26; c++) {
        const auto& v = pos[c];
        for (size_t t = 0; t < v.size(); t++) {
            long long p = (t == 0 ? -1 : v[t - 1]);
            long long q = (t + 1 == v.size() ? n : v[t + 1]);
            ans += (v[t] - p) * (q - v[t]);  // 左端選法 × 右端選法
        }
    }
    return (int)ans;
}

// ---- 5b. DP 版貢獻法：LC 2262 字串的總引力 ----
long long appealSum(const string& s) {
    vector<int> prev(26, -1);
    long long f = 0, ans = 0;  // f = 以 i 結尾的子字串引力和
    for (int i = 0; i < (int)s.size(); i++) {
        int c = s[i] - 'a';
        f += i - prev[c];  // 不含 c 的那些子字串各 +1
        prev[c] = i;
        ans += f;
    }
    return ans;
}
```

## 時間與空間複雜度

| 題 | 時間 | 空間 |
| --- | --- | --- |
| 53 Kadane | $O(n)$ | $O(1)$ |
| 53 + 回傳區間 | $O(n)$ | $O(1)$ |
| 152 | $O(n)$ | $O(1)$ |
| 467 | $O(n)$ | $O(26)$ |
| 828（貢獻法） | $O(n)$ | $O(n)$（或 $O(26)$ 邊掃邊做） |
| 2262（DP 版貢獻法） | $O(n)$ | $O(26)$ |
| 前綴和 + 單調隊列變形 | $O(n)$ | $O(n)$ |
| 前綴和 + 有序集合變形（363） | $O(n\log n)$ | $O(n)$ |

**$O(1)$ 空間是本節的常態**——**只要 $f(i)$ 只依賴 $f(i-1)$，就用變數而非陣列** ✔。

**⚠ 一起更新**：152 的 $\mathit{mx}$ 與 $\mathit{mn}$ **必須先算完再一起賦值**，否則第二式會讀到本輪的新 $\mathit{mx}$ ✘（6.2 的同一條規則）。

**溢位速查**：828 的答案可達 $O(n^2)\cdot 26$；2262 的答案可達 $O(n^2)$ ⇒ **都要 `long long`** ✘。152 的中間乘積也建議 `long long`。

**貢獻法的常數優勢**：$O(n)$ 且只掃一遍，**比「枚舉所有子陣列」的 $O(n^2)$ 快得多，而且往往比 DP 更好寫。**

## 常見錯誤與邊界條件

- **✘ 53 把答案與 0 取 $\max$。** 題目要求**非空**子陣列 ⇒ 全負陣列 $[-3,-1,-2]$ 的答案是 $-1$，不是 0。
- **✘ 152 誤加「不選 $a_i$」那一項。** 那會變成求子序列的最大乘積（6.2 定理 6 才有那一項）。**連續型必須以 $a_i$ 結尾。**
- **✘ 152 的 $\mathit{mx}$、$\mathit{mn}$ 沒有一起更新。**
- **✘ 混淆「不帶上前面」與「重置為不可用」。** Kadane 的 $\max(f(i-1),0)$ 是前者（仍以 $a_i$ 開一段新的）；467 的字母不連續是後者（$k$ 直接歸 1）。
- **✘ 467 的環繞判斷寫成 `s[i] - s[i-1] == 1`。** 漏掉 `'z' -> 'a'` ⇒ 要寫 `(s[i] - s[i-1] + 26) % 26 == 1` ✔。
- **✘ 828 的 $p$、$q$ 邊界寫成 0 與 $n-1$。** 必須是 $-1$ 與 $n$（虛擬哨兵），否則首尾字元的貢獻會少算 ✘。
- **✘ 有負數時用滑動窗口找「和 $\ge k$ 的最短子陣列」。** 單調性不成立（定理 6）⇒ 必須用單調隊列 + 前綴和 ✘。
- **✘ 溢位。** 828、2262 的答案是 $O(n^2)$ 量級。
- **✘ 忘記釘住結尾 ⇒ 答案取成 $f(n)$。** 釘住結尾型的答案永遠是 $\max_i f(i)$（7.1 也強調過）。
- **邊界**：$n=1$、全部相同元素、全負、含 0（152 的 0 自動重置，不必特判）、空字串（467、2262 回傳 0）。

## 與相似技巧的比較

- **與 4.1.1 定理 6（718 最長重複子陣列）**：**同一條鐵律的兩個實例**——「連續」⇒ 狀態釘住結尾、答案取全域 $\max$。718 是二維版。
- **與 6.2 基礎狀態機**：本節的多數題目就是「單模式」或「雙模式」的狀態機（53 單模式、152 雙模式）。**6.2 是它的一般化。**
- **與 6.2 定理 6 / 2708**：**差一項「不選」，就從連續變成子序列。** 這是本節最值得記住的對照。
- **與滑動窗口**：**判準見定理 6**——「加元素只會讓合法變不合法」且「左端單調」才能用窗口。**兩者不是替代關係，是互補關係。**
- **與單調棧（10 章 / data_structure）**：907 子陣列最小值之和、84 柱狀圖最大矩形都是「貢獻法 + 單調棧」，**與定理 5 的 828 是同一個思路：對每個元素算它「主導」的子陣列個數。**
- **與 11.3 單調隊列優化 DP**：定理 2 表中的「長度 $\le k$」變形就是單調隊列的原型。**本節先看到它的具體形態，11.3 再給一般框架。**
- **與前綴和 + 雜湊（560）**：**那不是 DP。** 判準：需要的是「前面所有 $j$ 中符合某等式的個數」而非「最優值」時，DP 的 $\max$ 結構用不上 ✘。

## 本節重點速查

- **鐵律**：連續 ⇒ **狀態釘住結尾**，$f(i)$ = 以 $i$ 結尾的最優值，**答案取 $\max_i f(i)$**（不是 $f(n)$）。
- **定理 1（Kadane）**：$f(i)=\max(f(i-1),0)+a_i$，按「長度是不是 1」劃分。**53 要求非空 ⇒ 答案不與 0 取 $\max$**，全負陣列答案是最大的那個負數。
- **定理 2（前綴和視角，最能推廣）**：$\max_i(P_i-\min_{j<i}P_j)$。**加限制時換掉「怎麼找 $P_j$」即可**：長度下界 ⇒ 前綴最小；長度上界 ⇒ 單調隊列；和為 $k$ ⇒ 雜湊；和 $\le k$ ⇒ 有序集合。**元素全正 ⇒ 前綴和單調 ⇒ 可用雙指標；有負數則不行。**
- **定理 3（152）**：$(\max,\min)$ 三候選；**沒有「不選」那一項**（與 2708 的唯一差別）。0 自動重置。一起更新。
- **定理 4（467）**：**「以某字元結尾 + 長度固定 ⇒ 內容唯一」** ⇒ 答案 $=\sum_c\mathit{len}[c]$。這是計數不同子串的標準去重框架。
- **定理 5（貢獻法）**：**對所有子陣列求和 ⇒ 交換求和順序，逐元素算貢獻。** 828：$(i-p)(q-i)$；2262：用「首次出現」代表每個不同字元，$(i-\mathrm{prev}[c])(n-i)$，或等價的 DP $f(i)=f(i-1)+(i-\mathrm{prev}[c])$。
- **定理 6（判準三連問）**：加元素會讓合法變不合法 ⇒ 滑動窗口；需要「前面某個 $j$ 的值」⇒ 前綴和 + 資料結構；對所有子陣列求和 ⇒ 貢獻法 + 單調棧。**三否才是純 DP。**
- **溢位**：828、2262 用 `long long`。
