## 這個技術解決什麼問題

題目問的不是「最好能到多少」，而是「**有幾種**」。這一字之差改變了三件事：

| | 最值型 DP | **計數型 DP** |
| --- | --- | --- |
| 合併運算 | $\max$ / $\min$ | **$+$** |
| 分類要求 | **覆蓋即可**（重複算不影響 $\max$） | **必須嚴格劃分：不漏、不重** |
| 不可達的值 | $-\infty$ / $+\infty$ | **$0$** |
| 「空方案」 | 常常是 0 或非法 | **通常是 $1$（乘法單位元）** |
| 剪枝 | 可以丟掉次優解 | **不能丟任何合法方案** |
| 溢位 | 少見 | **幾乎必然，要對 $10^9+7$ 取模** |

**核心紀律只有一句話（1.2 定理 2 的計數版）**：

> **每一個合法方案，必須恰好被某一條轉移數到一次。**
> 少數一次 ⇒ 漏；多數一次 ⇒ 重。**最值型可以容忍重複覆蓋，計數型不行。**

實作上這句話幾乎總是靠**「按最後一步分類」**來保證：**最後一步的取值互斥且窮盡** ⇒ 自動成為嚴格劃分 ✔。

**本節的錨題 LC 3317（安排活動的方案數）** 把計數 DP 的三個要素一次湊齊：**組合計數的乘法分解、第二類 Stirling 數的遞推、模冪與模逆元**。

## 狀態／資料結構定義

**通式**：

$$f(i,\ \theta) = \text{「前 } i \text{ 個元素、附加狀態為 }\theta\text{」的合法方案「個數」（已對 } M=10^9+7 \text{ 取模）}.$$

**三個必須在寫程式之前想清楚的定義問題**：

1. **邊界 $f(0,\cdot)$ 是 0 還是 1？**
   「什麼都不選」本身若是一個合法方案 ⇒ **$f(0,\text{初始}) = 1$** ✔（空方案，乘法單位元）；其餘 $\theta$ 為 0 ✔。
2. **「不可達」與「有 0 種方法」是同一件事嗎？**
   **在計數 DP 裡是同一件事，都寫 0** ✔——這比最值型單純（最值型必須區分 $-\infty$ 與真的是 0，見 6.2 定理 3）。
3. **元素有沒有標號？** ⇒ **這是本節第一名的錯誤源，見定理 4。**

**LC 3317 的狀態設計**（$n$ 個表演者、$x$ 個舞台、評分範圍 $[1,y]$）：

$$S(i,\ j) = \text{把 } i \text{ 個「有標號」的表演者劃分成 } j \text{ 個「無標號、非空」群的方法數（第二類 Stirling 數）}.$$

$$\mathrm{Ans} = \sum_{j=1}^{\min(n,x)} S(n,j)\ \cdot\ \underbrace{\frac{x!}{(x-j)!}}_{\text{把 } j \text{ 個群放到 } j \text{ 個相異舞台}}\ \cdot\ \underbrace{y^{\,j}}_{\text{每個樂團一個評分}}.$$

**等價的一步到位寫法**（省掉 Stirling，直接把舞台的標號吃進 DP）：

$$g(i,\ j) = \text{前 } i \text{ 個表演者恰好用滿 } j \text{ 個「指定的、相異的」舞台的方法數} = j!\,S(i,j).$$

**兩種寫法都要 $O(nx)$ 的表**，選哪個看你比較習慣哪一種語意。**推薦先寫 Stirling 版**，因為它把「無標號」這件事顯式寫出來，比較不會出錯。

## 不變量或正確性證明

### 定理 1（**計數 DP 的正確性條件：最後一步分類必須互斥且窮盡**）

*設定*：設 $\mathcal{A}(i,\theta)$ 是狀態 $(i,\theta)$ 對應的方案集合，轉移為 $f(i,\theta)=\sum_{e\in E} f(\mathrm{pre}(e))$，其中 $E$ 是「最後一步」的候選集合。

*命題*：$f(i,\theta)=|\mathcal{A}(i,\theta)|$ **當且僅當**映射「方案 $\mapsto$ 它的最後一步 $e$」滿足

- **（窮盡）** 每個方案至少對應到一個 $e\in E$；
- **（互斥）** 每個方案至多對應到一個 $e\in E$；
- **（子問題雙射）** 對固定的 $e$，「以 $e$ 結尾的 $\mathcal{A}(i,\theta)$ 方案」與「$\mathcal{A}(\mathrm{pre}(e))$ 的方案」一一對應。

*證明*。三條合起來說的正是「$\mathcal{A}(i,\theta)=\biguplus_{e\in E}\phi_e\big(\mathcal{A}(\mathrm{pre}(e))\big)$ 是不交聯集，且每個 $\phi_e$ 是雙射」⇒ 基數相加 ✔。反之若任一條不成立，就能構造出被算兩次或零次的方案 ✔。$\square$

**⚠ 實務上最容易破功的是「互斥」。** 三個典型破功情形：

| 破功情形 | 症狀 | 修法 |
| --- | --- | --- |
| 同一方案有多種「最後一步」的讀法 | 答案偏大 | **改用「唯一可辨識」的最後一步**（例如「最後一段的起點」而非「任一斷點」） |
| 元素有重複值，交換後是同一方案 | 答案偏大 | **按位置分類而非按值分類**（7.4 定理 4 的 446 就是這樣自動去重） |
| 用「至多」型狀態卻又累加 | 答案偏大 | **改成「恰好」型**，或最後只讀一格 |

**（窮盡）破功較少見**，通常是漏了「這一步什麼都不做」的自環。

### 定理 2（**第二類 Stirling 數的遞推**）

*命題*：對 $i\ge1,\ j\ge1$，

$$S(i,j) = j\cdot S(i-1,\,j) \;+\; S(i-1,\,j-1),\qquad S(0,0)=1,\quad S(i,0)=0\ (i\ge1),\quad S(0,j)=0\ (j\ge1).$$

*證明（按第 $i$ 個元素的去向分類）*。把有標號元素 $\{1,\dots,i\}$ 劃分成 $j$ 個無標號非空群，考慮元素 $i$：

- **情形 A：元素 $i$ 自己獨佔一群。** 剩下 $i-1$ 個元素必須恰好填滿另外 $j-1$ 群 ⇒ $S(i-1,j-1)$ 種 ✔。
- **情形 B：元素 $i$ 與別人同群。** 拿掉 $i$ 之後，剩下 $i-1$ 個元素仍佔滿 $j$ 個非空群（因為 $i$ 的群還有別人）⇒ 先有 $S(i-1,j)$ 種劃分，再選 $i$ 加入哪一群 ⇒ $j$ 種 ⇒ $j\cdot S(i-1,j)$ ✔。

**互斥**：A 與 B 由「$i$ 的群是否只有它自己」區分，二者必居其一且不能同時 ✔。
**窮盡**：任何劃分都落入其中之一 ✔。
**雙射**：情形 B 中，「$(i-1$ 元素的劃分, 選中的群編號$)$」$\mapsto$「$i$ 元素的劃分」是雙射——**這裡用到群「無標號」但在一個給定劃分中群是可區分的**（群由其成員決定）⇒ 「選哪一群」有明確的 $j$ 種選擇，且不同選擇給出不同結果 ✔。$\square$

*依賴的前提*：**元素有標號、群無標號、群非空**。三者改任一個，遞推就變了：

| 變體 | 公式 |
| --- | --- |
| 群**有**標號、允許空 | $j^i$ |
| 群**有**標號、非空（滿射） | $j!\,S(i,j)$ |
| 群無標號、**允許空** | $\sum_{t\le j} S(i,t)$ |
| 元素**無**標號、群無標號 | 整數劃分（不是 Stirling） |

**⚠ 讀題時務必先把自己的問題對到這張表的哪一列。**

### 定理 3（**3317 的乘法分解**）

*命題*：

$$\mathrm{Ans} = \sum_{j=1}^{\min(n,x)} S(n,j)\cdot \frac{x!}{(x-j)!}\cdot y^{\,j}.$$

*證明*。定義「一次活動」為三元組（表演者到舞台的指派, 每個樂團的評分）。**按「有人的舞台數量 $j$」分類**——$j$ 由方案唯一決定 ⇒ **互斥且窮盡** ✔（$j\ge1$ 因為 $n\ge1$）。

固定 $j$，建立雙射：

$$\Big\{\text{恰用 } j \text{ 個舞台的活動}\Big\} \;\longleftrightarrow\; \Big\{\text{劃分}\Big\}\times\Big\{\text{把群射到相異舞台}\Big\}\times\Big\{\text{評分}\Big\}.$$

- **劃分**：同舞台的表演者組成一個樂團 ⇒ 誘導出 $\{1..n\}$ 的一個 $j$ 群非空劃分。表演者有標號、樂團本身無標號（樂團的身分只由成員決定）⇒ $S(n,j)$ ✔。
- **配到舞台**：把 $j$ 個群單射到 $x$ 個相異舞台 ⇒ 排列數 $P(x,j)=x!/(x-j)!$ ✔。**（先選 $\binom{x}{j}$ 個舞台再排 $j!$，兩者相乘正是 $P(x,j)$。）**
- **評分**：每個樂團獨立取 $[1,y]$ ⇒ $y^j$ ✔。

三個選擇**互相獨立**（任一組合都對應一次合法活動，且不同組合給出不同活動）⇒ 乘法原理 ✔。

**「不同活動」的判準與題目一致**：兩次活動不同 $\iff$ 某位表演者的舞台不同（⟺ 劃分或配置不同）或某個樂團評分不同 ✔。$\square$

*常見的兩個錯誤分解*：

- **✘ 寫成 $\sum_j \binom{x}{j}S(n,j)y^j$**（漏掉 $j!$）：這等於把 $j$ 個群「無序地」丟給選中的舞台，但**舞台是有標號的** ✘。
- **✘ 寫成 $x^n\cdot y^{(\text{非空舞台數})}$ 之類**：非空舞台數不是常數，不能提出來 ✘。

### 定理 4（**有標號 / 無標號：計數 DP 的第一名錯誤源**）

*命題*：兩個計數問題若只差在「某類物件是否可區分」，答案可以差 $j!$ 倍。因此**每一個計數量都必須先回答：這類物件有沒有標號？**

*3317 的三類物件*：

| 物件 | 有無標號 | 依據 |
| --- | --- | --- |
| **表演者** | **有** | 題目說「任一表演者被指派到不同舞台」就算不同活動 ✔ |
| **舞台** | **有** | 同上——換舞台就是不同活動 ✔ |
| **樂團（群）** | **無** | 樂團沒有獨立身分，它只是「同台的人的集合」✔ |

**判別法（可以直接套用到任何計數題）**：

> **問「把這兩個物件互換，題目認不認為是同一個方案？」**
> **認為相同 ⇒ 無標號；認為不同 ⇒ 有標號。**

*為什麼「樂團無標號 + 舞台有標號」不會互相矛盾*：樂團在**配到舞台之前**無標號（$S(n,j)$ 不區分群），**配到舞台之後**因為舞台有標號而變得可區分（乘上 $P(x,j)$）✔。**這正是「先劃分、再配置」這種兩段式分解的意義——把無標號與有標號的部分分開處理，避免重複計數。**

**檢查用的小例子**：$n=2,\ x=2,\ y=1$。
手算：兩位表演者，2 個舞台 ⇒ $2^2=4$ 種指派，評分只有 1 種 ⇒ 答案 4。
公式：$j=1$: $S(2,1)\cdot P(2,1)\cdot1 = 1\cdot2\cdot1=2$；$j=2$: $S(2,2)\cdot P(2,2)\cdot 1 = 1\cdot2\cdot1=2$ ⇒ 共 4 ✔。
**漏掉 $j!$ 的錯版**會得到 $1\cdot\binom21 + 1\cdot\binom22 = 3$ ✘ ——**一個 $n=x=2$ 的例子就能抓出來，這種手算自檢一定要做。**

### 定理 5（**模運算的三條規則，以及為什麼取模不影響 DP 的正確性**）

*命題*：設 $M=10^9+7$。對加法與乘法，「每一步取模」與「最後才取模」結果相同。

*證明*。$\mathbb{Z}_M$ 是環，自然映射 $\mathbb{Z}\to\mathbb{Z}_M$ 是環同態 ⇒ 保持 $+$ 與 $\times$ ⇒ 任何只用 $+,\times$ 組成的算式，先取模與後取模同餘 ✔。$\square$

*三條實作規則*：

1. **加法**：`f = (f + g) % M;` ——**兩個 $<M$ 的數相加 $<2^{31}$，`int` 剛好不溢位，但乘法一定要 `long long`** ✔。
2. **減法（容斥時會用到）**：`f = (f - g % M + M) % M;` ——**忘記 `+ M` 會得到負數** ✘（7.4 定理 5 的 940 減法版同一個坑）。
3. **除法**：**沒有除法**。要除以 $a$ 就乘以 $a^{M-2}\bmod M$（費馬小定理，**前提 $M$ 是質數且 $a\not\equiv0$**）✔。

*3317 需要除法嗎*：$P(x,j)=x!/(x-j)!$ 看起來要除。**兩種做法**：

- **(a) 預處理階乘與階乘逆元** ⇒ $O(x)$ 預處理、$O(1)$ 查詢 ✔；
- **(b) 遞推 $P(x,j) = P(x,j-1)\cdot(x-j+1)$** ⇒ **完全不需要逆元**，更不易錯 ✔ **（推薦）**。

**一般教訓**：**能用遞推避開逆元就避開**——逆元只在「同一個分母要被反覆使用、且無法遞推」時才划算。

### 定理 6（**計數型的四種去重框架**）

計數 DP 的難點幾乎都在「不重」。**已經在前幾節出現過的四種框架，在此整理成判準表**：

| 框架 | 做法 | 出處 |
| --- | --- | --- |
| **① 按最後一步分類** | 讓「最後一步」由方案唯一決定 | 定理 1、定理 2、定理 3 |
| **② 按第一次出現分類** | 每個對象由「它第一次出現的位置」代表 | 7.3 定理 5（2262）、7.4 定理 5（940） |
| **③ 規範形式（canonical form）** | 強制一種標準表示（如「群內下標遞增」「段長不遞增」） | 整數劃分、組合枚舉 |
| **④ 容斥** | 先多算、再減掉不合法的 | 「至少」型條件、錯排 |

**選擇判準**：

- 方案天然有「順序」（序列、路徑、分段）⇒ **①**；
- 方案是「集合 / 字串」且會因為重複元素撞號 ⇒ **②**（**位置比值更能區分**）；
- 方案的元素之間**沒有天然順序**（劃分、多重集）⇒ **③**，用「非遞減 / 遞增」的規範化來打破對稱；
- 條件是「**至少滿足一個**」或「**都不滿足**」⇒ **④**。

**3317 用的是 ①（按 $j$ 分類）+ ①（Stirling 內按第 $i$ 個元素分類）的兩層套用** ✔。

> **最後提醒一條與最值型的關鍵差異**：
> **最值型可以在轉移中隨手加剪枝（丟掉一定不是最優的分支），計數型不行——丟掉任何一個合法方案，答案就直接錯了。**
> **計數 DP 的「優化」只能是等價變形（合併同類項、前綴和、矩陣快速冪），不能是剪枝。**

## C++17 模板

```cpp
static constexpr long long MOD = 1'000'000'007LL;

// ---- 0. 快速冪（模冪；也用來求逆元）----
long long qpow(long long a, long long e, long long m = MOD) {
    a %= m;
    if (a < 0) a += m;
    long long r = 1;
    while (e > 0) {
        if (e & 1) r = r * a % m;
        a = a * a % m;
        e >>= 1;
    }
    return r;
}
long long inv(long long a) {
    return qpow(a, MOD - 2);
}  // 前提：MOD 為質數

// ---- 1. 第二類 Stirling 數：S[i][j]，O(n*k) ----
vector<vector<long long>> stirling2(int n, int k) {
    vector S(n + 1, vector<long long>(k + 1, 0LL));
    S[0][0] = 1;  // 空集合劃分成 0 群：恰 1 種
    for (int i = 1; i <= n; i++)
        for (int j = 1; j <= min(i, k); j++)
            S[i][j] = (1LL * j * S[i - 1][j] + S[i - 1][j - 1]) % MOD;
    return S;
}

// ---- 2. LC 3317 安排活動的方案數 ----
int numberOfWays(int n, int x, int y) {
    int K = min(n, x);
    auto S = stirling2(n, K);
    long long ans = 0, perm = 1;  // perm = P(x, j)
    for (int j = 1; j <= K; j++) {
        perm =
            perm % MOD * ((x - j + 1) % MOD) % MOD;  // 遞推，避開逆元（定理 5）
        ans = (ans + S[n][j] % MOD * perm % MOD * qpow(y, j)) % MOD;
    }
    return (int)ans;
}

// ---- 2'. 等價的一步到位版：g[i][j] = 前 i 人恰好填滿 j 個「相異」舞台 ----
int numberOfWaysDirect(int n, int x, int y) {
    int K = min(n, x);
    vector g(n + 1, vector<long long>(K + 1, 0LL));
    g[0][0] = 1;
    for (int i = 1; i <= n; i++)
        for (int j = 1; j <= min(i, K); j++)
            // 第 i 人：放進已有的 j 個舞台之一，或開一個新舞台（j 個相異舞台中選誰是新的）
            g[i][j] = (1LL * j * g[i - 1][j] + 1LL * j * g[i - 1][j - 1]) % MOD;
    long long ans = 0, comb = 1;  // comb = C(x, j)
    for (int j = 1; j <= K; j++) {
        comb = comb % MOD * ((x - j + 1) % MOD) % MOD * inv(j) % MOD;
        ans = (ans + g[n][j] * comb % MOD * qpow(y, j)) % MOD;
    }
    return (int)ans;
}

// ---- 3. 組合數預處理（階乘 + 階乘逆元），需要反覆查 C(n,k) 時用 ----
struct Binom {
    vector<long long> f, g;  // f[i]=i!, g[i]=(i!)^{-1}
    explicit Binom(int n) : f(n + 1), g(n + 1) {
        f[0] = 1;
        for (int i = 1; i <= n; i++) f[i] = f[i - 1] * i % MOD;
        g[n] = inv(f[n]);
        for (int i = n; i >= 1; i--)
            g[i - 1] = g[i] * i % MOD;  // 反向遞推，只需一次逆元
    }
    long long C(int n, int k) const {
        if (k < 0 || k > n) return 0;
        return f[n] * g[k] % MOD * g[n - k] % MOD;
    }
    long long P(int n, int k) const {  // 排列數 n!/(n-k)!
        if (k < 0 || k > n) return 0;
        return f[n] * g[n - k] % MOD;
    }
};

// ---- 4. 計數 DP 的通用骨架：按「最後一步」分類 ----
long long countSkeleton(int n, const vector<vector<int>>& lastStepFrom) {
    vector<long long> f(n + 1, 0);
    f[0] = 1;  // 空方案算 1（乘法單位元）
    for (int i = 1; i <= n; i++)
        for (int j : lastStepFrom[i])  // 這些「最後一步」必須互斥且窮盡
            f[i] = (f[i] + f[j]) % MOD;
    return f[n];
}
```

## 時間與空間複雜度

| 步驟 | 時間 | 空間 |
| --- | --- | --- |
| Stirling 表 $S(n,j)$ | $O(n\cdot\min(n,x))$ | $O(n\cdot\min(n,x))$，**滾動後 $O(\min(n,x))$** |
| 累加答案（含 $y^j$ 的快速冪） | $O(\min(n,x)\log y)$ | $O(1)$ |
| **3317 總計** | $O(nx + x\log y)$ | $O(x)$（滾動） |
| `Binom` 預處理 | $O(n)$（**只呼叫一次逆元**） | $O(n)$ |

**兩個可以再省的地方**：

1. **$y^j$ 不必每次快速冪**：遞推 `py = py * y % MOD` ⇒ 去掉 $\log y$ ⇒ $O(nx)$ ✔。
2. **Stirling 表可以滾動**：$S(i,\cdot)$ 只依賴 $S(i-1,\cdot)$，且轉移 $j\cdot S(i-1,j)+S(i-1,j-1)$ 依賴 $j-1$ ⇒ **就地更新時 $j$ 必須遞減**（2.1 定理 2）✔：

```cpp
vector<long long> S(K + 1, 0);
S[0] = 1;
for (int i = 1; i <= n; i++)
    for (int j = min(i, K); j >= 1; j--)  // j 遞減，否則讀到本層的 S[j-1]
        S[j] = (1LL * j * S[j] + S[j - 1]) % MOD;
```

**⚠ 這個 $j$ 遞減與 3.1 的 0-1 背包同一條理由**：**要讀的是「上一層」的 $S[j-1]$。**

**常數項**：取模是整數除法，在內層迴圈裡不便宜。若 $n,x\le1000$（$10^6$ 次）完全不必擔心；若到 $10^8$ 級，可改用「延遲取模」（累加到接近 $2^{63}$ 才取一次模）✔。

## 常見錯誤與邊界條件

- **✘ 重複計數。** 最常見的死法。**每寫一條轉移，就問「這個方案會不會被另一條轉移也數到」**（定理 1 的互斥性）。
- **✘ 邊界寫成 0 而不是 1。** $f(0)=1$（空方案）——**寫成 0 會讓整張表全是 0**，症狀非常明顯，是最好抓的一種錯。
- **✘ 有標號 / 無標號搞混。** 3317 漏掉 $j!$ 就是這個病。**用 $n=x=2$ 這種小例子手算對照**（定理 4）。
- **✘ 忘記取模，或只在最後取模。** 中間值早就溢位 ✘。
- **✘ 乘法沒轉成 `long long`。** `int * int` 在 $10^9$ 級一定溢位 ⇒ **寫 `1LL * a * b % MOD`** ✔。
- **✘ 減法後沒 `+ MOD`。** 容斥、去重時必踩 ✘。
- **✘ 對非質數模數用費馬小定理求逆元。** 只有 $M$ 質數才成立 ✘（$10^9+7$ 是質數 ✔）。
- **✘ 對 $y$ 沒先取模。** 若 $y$ 也很大，`qpow(y, j)` 內部已經 `a %= m` ✔，但自己遞推時要記得 ✘。
- **✘ Stirling 滾動時 $j$ 遞增。** 會讀到本層的 $S[j-1]$ ✘。
- **✘ $j$ 的上界寫成 $x$ 而非 $\min(n,x)$。** $j>n$ 時 $S(n,j)=0$，不會算錯，但白跑；**反過來若 $j$ 只跑到 $n$ 而 $x<n$，就會用到不存在的舞台** ✘。
- **邊界**：$n=1$（答案 $x\cdot y$，可自檢）、$x=1$（答案 $y$）、$y=1$（答案 = 所有指派數 $=x^n$，**這是最好的自檢式**：$\sum_j S(n,j)P(x,j)=x^n$ ✔）、$n>x$（仍合法，$j\le x$）。

## 與相似技巧的比較

- **與最值型 DP（1.2 定理 2）**：**同一個 DP 骨架，換成 $+$ 與嚴格劃分。** 「$\max$ 可以重複覆蓋、計數不行」這句話值得背下來——**本章前六節每一節的計數版都受它約束**。
- **與 7.3 / 7.4 的去重手法**：7.3 定理 4（467 的「結尾字元 + 長度唯一」）、7.3 定理 5（2262 的「首次出現代表」）、7.4 定理 5（940 的「賦值而非累加」）**都是本節定理 6 表中的 ① 與 ②**。**本節只是把它們抽象成判準。**
- **與 3 章背包計數**（3.2 的完全背包求方案數）：**「組合 vs 排列」的差別就是迴圈順序**——物品在外層數組合、容量在外層數排列。**那也是定理 1 的互斥性問題**：物品在外層時，每個方案由「物品的固定順序」唯一表示 ⇒ 不重 ✔。
- **與容斥 / 組合恆等式**：計數 DP 與純組合公式常常互為驗算工具。**3317 在 $y=1$ 時退化成 $\sum_j S(n,j)P(x,j)=x^n$，是絕佳的單元測試** ✔。
- **與 10 章數位 DP**：那是「在數字的十進位表示上做計數 DP」，**同樣受定理 1 約束**，而且「是否貼上界」正是為了保證互斥窮盡而加的維度。
- **與 15 章機率／期望 DP**：把「個數」換成「機率」，加法原理變全機率公式 ⇒ **轉移形狀相同，但係數要乘機率而非計數**，且不能取模（用 `double`）。

## 本節重點速查

- **黃金律（定理 1）**：**每個方案恰被數到一次。** 按「最後一步」分類，並逐一檢查**互斥 / 窮盡 / 子問題雙射**。**最值型可以重複覆蓋，計數型不行。**
- **邊界**：$f(0)=1$（空方案），不可達寫 0。**全表是 0 通常就是邊界寫成 0 了。**
- **定理 2（Stirling）**：$S(i,j)=j\,S(i-1,j)+S(i-1,j-1)$，$S(0,0)=1$。分類依據：**第 $i$ 個元素是否獨佔一群**。前提：**元素有標號、群無標號、群非空。**
- **定理 3（3317）**：$\mathrm{Ans}=\sum_{j=1}^{\min(n,x)}S(n,j)\cdot P(x,j)\cdot y^{\,j}$。**漏掉 $j!$（即用 $\binom{x}{j}$ 而非 $P(x,j)$）是標準錯法。**
- **定理 4（有標號嗎？）**：問「互換這兩個物件，題目認不認為是同一方案」。3317：表演者有標號、舞台有標號、樂團無標號。**先劃分（無標號）再配置（有標號）** 是分離這兩者的標準兩段式。
- **定理 5（模運算）**：加法直接取模；**減法要 `+ MOD`**；除法用費馬小定理逆元（**前提 $M$ 質數**）；**能用遞推避開逆元就避開**（$P(x,j)=P(x,j-1)(x-j+1)$）。乘法一律 `1LL *`。
- **定理 6（四種去重）**：① 按最後一步 ② 按首次出現 ③ 規範形式 ④ 容斥。**序列用 ①、重複元素用 ②、無序集合用 ③、「至少」型用 ④。**
- **優化只能是等價變形，不能剪枝。**
- **自檢式**：$y=1$ 時 3317 的答案必為 $x^n$；$n=x=2,y=1$ 時必為 4。
- **滾動**：Stirling 就地更新時 **$j$ 必須遞減**（同 0-1 背包）。
