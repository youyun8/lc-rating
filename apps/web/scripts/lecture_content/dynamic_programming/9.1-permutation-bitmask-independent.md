## 這個技術解決什麼問題

題目要在 $n$ 個元素上**排出一個順序**或**做一對一配對**，而 $n$ 小得反常（大約 $\le20$）。暴力枚舉是 $n!$——$n=20$ 時 $2.4\times10^{18}$，完全不可行。

**狀壓 DP 的觀察只有一句話**：

> **兩個「已經放好前 $k$ 個」的排列前綴，若用掉的元素集合相同，則它們對後續完全等價。**
> **⇒ 只需要記住「用了哪些」，不必記住「以什麼順序用的」⇒ $n!$ 壓成 $2^n$。**

$2^{20}\approx10^6$，配上 $O(n)$ 的轉移就是 $2\times10^7$——**輕鬆過。這就是「$n\le20$」這個小到反常的資料範圍在暗示的事。**

**⚠ 但上面那句話不是永遠成立的。** 它成立的條件正是本節標題裡的**「相鄰無關」**：

$$\text{放入新元素 } j \text{ 的代價，只依賴「}j\text{ 是誰」與「它被放在第幾個位置」，不依賴「上一個放的是誰」}.$$

**滿足 ⇒ 本節（狀態只要 `mask`）；不滿足 ⇒ 9.2（要多記一維「上一個是誰」）。** 這條分界是第 9 章前兩節唯一的差別，**讀題時第一件事就是判它**。

| 題 | 「第 $k$ 個位置放元素 $j$」的代價 | 相鄰無關？ |
| --- | --- | --- |
| 526 優美的排列 | 合法性：$j \bmod k=0$ 或 $k\bmod j=0$ | ✔ 只看 $(j,k)$ |
| 1947 最大相容性評分和 | 學生 $j$ 配給導師 $k$ 的相容分 | ✔ |
| 1066 校園自行車分配 II | 工人 $k$ 騎車 $j$ 的曼哈頓距離 | ✔ |
| 1879 兩個陣列最小的異或值之和 | $\mathit{nums1}[k]\oplus \mathit{nums2}[j]$ | ✔ |
| 2403 殺死所有怪物的最短時間 | $\lceil \mathit{power}[j]/k\rceil$（$k$ = 當前每日法力） | ✔ **只看已殺幾隻，不看殺的順序** |
| 2172 陣列的最大與和 | $\mathit{nums}[k]\ \&\ (\text{槽位編號})$ | ✔（槽位容量 2，見定理 5） |
| **996 平方陣列的數目** | 需要「上一個是誰」才知道和是不是完全平方數 | **✘ ⇒ 9.2** |

## 狀態／資料結構定義

**標準狀態**：

$$f(\mathit{mask}) = \text{已經把 } \mathit{mask} \text{ 這個集合的元素放進前 } |\mathit{mask}| \text{ 個位置時的最優值}.$$

其中 $\mathit{mask}$ 是 $n$ 位元的整數，第 $j$ 位為 1 表示元素 $j$ 已被使用。

**關鍵設計（定理 2）**：**「目前填到第幾個位置」不需要額外一維——它就是 $\mathrm{popcount}(\mathit{mask})$。**

**邊界**：$f(0)=$ 單位元（求最小值用 0 或 $+\infty$ 視語意、求最大值用 0、計數用 1）。
**答案**：$f\big((1\ll n)-1\big)$。

**兩種等價寫法**：

| 寫法 | 迴圈 | 語意 |
| --- | --- | --- |
| **填表（拉）** | 對每個 `mask`，枚舉「**最後**放的那個 $j\in\mathit{mask}$」，從 `mask ^ (1<<j)` 轉移過來 | $f(\mathit{mask})=\operatorname{opt}_{j\in \mathit{mask}} \big(f(\mathit{mask}\setminus j) + w(j,\ |\mathit{mask}|)\big)$ |
| **刷表（推）** | 對每個 `mask`，枚舉「**下一個**放誰」$j\notin\mathit{mask}$，更新 `mask | (1<<j)` | $f(\mathit{mask}\cup j)\mathrel{\operatorname{opt}=} f(\mathit{mask}) + w(j,\ |\mathit{mask}|+1)$ |

**兩者完全等價**（同一張圖，只是邊的遍歷方向不同）。**推薦刷表**：位置編號直接是 $\mathrm{popcount}(\mathit{mask})+1$，比填表少一次減法，也比較不會把位置算錯 ✔。

**位元運算備忘**：

| 操作 | 寫法 |
| --- | --- |
| 元素 $j$ 是否已用 | `mask >> j & 1` |
| 加入 $j$ | `mask \| (1 << j)` |
| 移除 $j$ | `mask ^ (1 << j)`（**已知 $j\in mask$ 時**）或 `mask & ~(1 << j)` |
| 集合大小 | `__builtin_popcount(mask)` |
| 最低位的 1 | `mask & -mask`；其下標 `__builtin_ctz(mask)` |
| 全集 | `(1 << n) - 1`（**$n=32$ 時要寫 `1u << n` 或用 `long long`**） |

**⚠ $n$ 的上界**：$2^{20}\cdot20=2\times10^7$ ✔；$2^{22}\cdot22=9\times10^7$ 勉強；$2^{24}$ 的陣列光是 `int` 就 64 MB ✘。**看到 $n\le20$ 就放心用，$n\ge24$ 就要另找結構。**

## 不變量或正確性證明

### 定理 1（**合併定理：為什麼 $n!$ 可以壓成 $2^n$**）

*設定*：一個排列方案是雙射 $\sigma:\{1..n\}\to\{1..n\}$（第 $k$ 個位置放元素 $\sigma(k)$），總代價

$$\mathrm{cost}(\sigma) = \sum_{k=1}^{n} w\big(\sigma(k),\ k\big).$$

**注意這個式子的形狀：每一項只依賴「元素」與「位置」，不依賴其他項。這就是「相鄰無關」的精確定義。**

*命題*：定義 $f(\mathit{mask}) = \min\Big\{\sum_{k=1}^{|\mathit{mask}|} w(\sigma(k),k)\ :\ \sigma \text{ 是 } \{1..|\mathit{mask}|\}\to \mathit{mask} \text{ 的雙射}\Big\}$，則

$$f(\mathit{mask}) = \min_{j\in \mathit{mask}} \Big( f\big(\mathit{mask}\setminus\{j\}\big) + w\big(j,\ |\mathit{mask}|\big) \Big),\qquad f(\varnothing)=0.$$

*證明*。
**(i)（分類完備且互斥）** 每個部分排列 $\sigma$ 有唯一的「最後一個元素」$j=\sigma(|\mathit{mask}|)$ ✔ ⇒ 按 $j$ 分類是嚴格劃分（1.2 定理 2）✔。

**(ii)（最優子結構）** 固定 $j$。$\sigma$ 去掉最後一項後是 $\{1..|\mathit{mask}|-1\}\to \mathit{mask}\setminus\{j\}$ 的雙射，代價為 $\mathrm{cost}(\sigma)-w(j,|\mathit{mask}|)$。**因為 $w(j,|\mathit{mask}|)$ 這一項與前面怎麼排完全無關**（相鄰無關！）⇒ 要讓 $\mathrm{cost}(\sigma)$ 最小，前綴部分必須最小 ⇒ 取 $f(\mathit{mask}\setminus\{j\})$ ✔。

**(iii)（可達性）** 反之，任何 $\mathit{mask}\setminus\{j\}$ 的部分排列後面接上 $j$ 都合法（**雙射的定義只要求元素不重複**）✔。$\square$

**壓縮率**：原本 $|\mathit{mask}|!$ 個部分排列，壓成 1 個狀態。總狀態從 $\sum_k \binom{n}{k}k! $ 降到 $2^n$ ✔。

*⚠ (ii) 是唯一會失敗的一條*。**失敗的例子**：若代價寫成 $\sum_k w'\big(\sigma(k-1),\sigma(k)\big)$（相鄰項乘積 / 相鄰和是平方數 / 相鄰整除），則「前綴的最優」不保證能接上後面 ⇒ **必須把 $\sigma(|\mathit{mask}|)$ 記進狀態 ⇒ 9.2** ✔。

> **判斷方法（三秒鐘）**：**把代價寫成一個總和，看每一項的自變數。**
> **只有 $(\text{元素},\ \text{位置})$ ⇒ 本節；出現 $(\text{元素},\ \text{前一個元素})$ ⇒ 9.2。**

### 定理 2（**位置 $=\mathrm{popcount}(\mathit{mask})$，所以不必多一維**）

*命題*：在定理 1 的狀態定義下，「目前要填第幾個位置」由 $\mathit{mask}$ **唯一決定**，等於 $\mathrm{popcount}(\mathit{mask})$（0-indexed 時為下一個位置的下標）。

*證明*。狀態的定義是「把 $\mathit{mask}$ 的元素放進**前 $|\mathit{mask}|$ 個位置**」——位置是連續填滿的，沒有跳過 ✔ ⇒ 已填位置數 $=|\mathit{mask}|=\mathrm{popcount}(\mathit{mask})$ ✔。$\square$

> **這是 7.6 定理 6「加維度前的三個檢查」第 1 條（能不能由其他維度推出來）最漂亮的一次應用。**
> **多開一維 $f(\mathit{mask},k)$ 不會錯，但狀態數乘上 $n$，而且其中只有 $k=\mathrm{popcount}(\mathit{mask})$ 的格子有意義——$O(n2^n)$ 的空間有 $1-1/n$ 是浪費的。**

*⚠ 什麼時候真的要多一維*：**位置不是連續填滿的時候。** 例如 1066 校園自行車分配 II 中「車比人多」——若把 `mask` 定義成「哪些**車**被騎走」，則已服務的工人數仍等於 $\mathrm{popcount}$ ✔（每個工人恰騎一台）；但若允許某些工人不配車，$\mathrm{popcount}$ 就推不出工人數 ⇒ 要多一維 ✘。**設計狀態時務必確認這一點。**

### 定理 3（**mask 遞增就是合法的拓撲序**）

*命題*：所有轉移都形如 $\mathit{mask}\to \mathit{mask}\ |\ (1\ll j)$（$j\notin\mathit{mask}$），而這使得**目標的整數值嚴格大於來源**。因此 `for (int mask = 0; mask < (1<<n); mask++)` 就是合法的填表順序。

*證明*。$j\notin \mathit{mask}$ ⇒ 加入第 $j$ 位使整數值增加 $2^j>0$ ⇒ 嚴格遞增 ✔。DP 圖的所有邊都從小整數指向大整數 ⇒ 依整數遞增遍歷即拓撲序（1.1 定理 4）✔。$\square$

> **這條定理讓狀壓 DP 的實作出奇地簡單**：**不必像區間 DP 那樣煩惱填表順序（8.1 定理 4 的坑），一個從 0 數到 $2^n-1$ 的迴圈就對了。**
> **⚠ 但 9.4 子集狀壓與 9.6 SOS DP 的轉移不是「加一位」，順序要另外論證——別把這條當成萬用結論。**

### 定理 4（**1799：一次選兩個時，固定「最低未選元素」以避免重複枚舉**）

*設定*：1799 每次操作取出**兩個**還沒用的數 $x,y$，得分 $k\cdot\gcd(x,y)$（$k$ 是第幾次操作）。$n=2m$ 個數，共 $m$ 次操作。

*天真寫法*：$f(\mathit{mask})=\max_{i<j,\ i,j\notin \mathit{mask}}\big(f(\mathit{mask}\cup\{i,j\})+ \ldots\big)$ ⇒ 每個狀態枚舉 $O(n^2)$ 對。

*命題*：**可以固定 $i$ 為 $\mathit{mask}$ 的補集中下標最小的元素，只枚舉 $j$**，答案不變。

*證明*。任一最優方案在狀態 $\mathit{mask}$ 時，接下來的所有操作**必定會在某一步用到那個最小的未選元素 $i_0$**（因為最後所有元素都要被用完）✔。而**各次操作之間的順序只影響「第幾次」這個係數 $k$**——但 $k$ 由 $\mathrm{popcount}$ 決定，**在同一個狀態 $\mathit{mask}$ 下，下一次操作的 $k$ 是固定的** ⇒ 把「用到 $i_0$ 的那次操作」提前到現在，不改變任何一次操作的 $k$，也不改變配對關係 ⇒ **代價完全相同** ✔。故存在一個最優方案，它下一步就配掉 $i_0$ ⇒ 只枚舉含 $i_0$ 的配對已足 ✔。$\square$

**效果**：轉移從 $O(n^2)$ 降到 $O(n)$ ⇒ 總複雜度 $O(n2^n)$ 而非 $O(n^22^n)$ ✔。**$n=14$ 時是 $2.3\times10^5$ vs $3.2\times10^6$。**

> **這個「固定最小未使用元素」的技巧在配對 / 分組型狀壓裡幾乎必用**（9.4 子集狀壓也會再看到一次）。
> **⚠ 對計數型而言它不只是優化，而是正確性的必需品**——不固定的話每個配對方案會被數 2 倍（甚至 $m!$ 倍）✘。**最值型「只是慢」，計數型「會錯」**（7.7 定理 1）。

### 定理 5（**2172：槽位容量 $>1$ 時，複製槽位而不是改用高進位**）

*設定*：2172 有 `numSlots` 個編號槽位，**每個槽位最多放 2 個數**，得分是 $\sum \mathit{nums}[i]\ \&\ \mathit{slot}(i)$。

*兩種建模*：

| 建模 | 狀態 | 大小 |
| --- | --- | --- |
| **三進位**：每個槽記「已放 0/1/2 個」 | $3^{\mathit{numSlots}}$ | $3^9=19683$ |
| **複製槽位**：把每個槽拆成兩個相同編號的虛擬槽，變回「每槽至多 1 個」 | $2^{2\cdot\mathit{numSlots}}$ | $2^{18}=262144$ |

*命題*：兩種建模等價（存在保代價的雙射）。

*證明*。給定一個「每槽至多 2 個」的合法分配，把每個槽內的兩個數任意指派給該槽的兩個虛擬槽 ⇒ 得到「每虛擬槽至多 1 個」的分配，**代價相同**（因為兩個虛擬槽的編號一樣，$\&$ 的結果一樣）✔。反向亦然 ✔。**注意這是「至多 2 對 1」的多對一映射，但因為代價相同，取最優值不受影響** ✔。$\square$

*為什麼推薦複製槽位*：

- **三進位需要自己寫 `mask / pow3[i] % 3` 的取位函式**，且無法用 `__builtin_popcount` ✘；
- **複製槽位可以直接沿用定理 1–3 的全部結論**（包括 $\mathrm{popcount}$ 推位置、mask 遞增即拓撲序）✔；
- 狀態數雖然大 13 倍，但 $2^{18}\cdot n$ 仍然只有 $2\times10^6$ ✔。

> **一般教訓：能把問題化歸成「每個容器至多裝一個」，就不要自創進位制。**
> **多花一點狀態換掉一整類位元操作的錯誤，非常划算。**

### 定理 6（**1879 / 1947 / 1066 / 2850 是同一題：二分圖完美匹配的最優權**）

*命題*：以下四題都可寫成

$$\min_{\sigma}\ \sum_{k=0}^{n-1} C\big[k\big]\big[\sigma(k)\big],\qquad \sigma \text{ 是雙射},$$

其中 $C$ 是一張 $n\times n$（或 $n\times m$，$m\ge n$）的代價表：

| 題 | 左側 | 右側 | $C[k][j]$ |
| --- | --- | --- | --- |
| 1879 | `nums1[k]` | `nums2[j]` | `nums1[k] ^ nums2[j]` |
| 1947 | 學生 $k$ | 導師 $j$ | 相容分（取負求最大） |
| 1066 | 工人 $k$ | 自行車 $j$ | 曼哈頓距離 |
| 2850 | 「缺石頭的格子」第 $k$ 個 | 「多石頭的石頭」第 $j$ 個 | 兩格的曼哈頓距離 |

*正確性*：這正是定理 1 的形式（代價可拆成「位置 × 元素」的和）⇒ 狀壓 DP 直接適用 ✔。

$$f(\mathit{mask}) = \min_{j\in \mathit{mask}} \Big(f(\mathit{mask}\setminus\{j\}) + C\big[\mathrm{popcount}(\mathit{mask})-1\big][j]\Big).$$

*右側比左側多的情形（1066：車比人多）*：令 $\mathit{mask}$ 是**車**的集合，$k=\mathrm{popcount}(\mathit{mask})$ 是已配好的工人數。**答案不是 $f(\text{全集})$，而是 $\min\{f(\mathit{mask}) : \mathrm{popcount}(\mathit{mask})=\#\text{工人}\}$** ✔——**這是最容易寫錯的一行。**

*2850 的前置轉換*：「把多的石頭搬到少的格子」的最小總移動 = 把「超額石頭」逐顆展開成左側清單、把「空缺」展開成右側清單，再做完美匹配 ✔。
**⚠ 這裡用到一個不顯然的前提**：**每顆石頭獨立移動，路徑不互相干擾，且代價可加** ⇒ 總代價 = 各配對的曼哈頓距離和 ✔。（格子數 $\le9$ ⇒ 展開後最多 8 顆超額石頭 ⇒ $2^8$ ✔。）

## 時間與空間複雜度

| 題 | 狀態數 | 單次轉移 | 時間 | 空間 |
| --- | --- | --- | --- | --- |
| 通式（相鄰無關排列） | $2^n$ | $O(n)$ | $O(n\,2^n)$ | $O(2^n)$ |
| 526（$n\le15$） | $2^{15}$ | $O(15)$ | $5\times10^5$ | 128 KB |
| 1879（$n\le14$） | $2^{14}$ | $O(14)$ | $2\times10^5$ | 64 KB |
| 1947（$m\le8$） | $2^8$ | $O(8)$ | $2\times10^3$ | 1 KB |
| 1066（車 $\le10$） | $2^{10}$ | $O(10)$ | $10^4$ | 4 KB |
| 1799（$n\le14$，定理 4） | $2^{14}$ | **$O(n)$** 而非 $O(n^2)$ | $2\times10^5$ | 64 KB |
| 2172（$2\cdot\mathit{slots}\le18$） | $2^{18}$ | $O(n)$ | $\sim5\times10^6$ | 1 MB |
| 2403（$n\le17$） | $2^{17}$ | $O(17)$ | $2\times10^6$ | 512 KB |

**空間就是狀態數乘上單格大小**。$2^{20}$ 的 `int` 表 = 4 MB ✔；`long long` = 8 MB，仍在多數限制之內 ✔。**$n=24$ 時 `int` 表已是 64 MB ⇒ 通常 MLE** ✘。

**三個常數優化**：

1. **`__builtin_popcount` 不是免費的**（雖然通常編譯成單一 `popcnt` 指令）。在最內層迴圈裡反覆呼叫時，**把它提到外層算一次** ✔：

```cpp
for (int mask = 0; mask < full; mask++) {
    if (f[mask] == INF) continue;      // 不可達，剪枝
    int k = __builtin_popcount(mask);  // 提到外面，內層不再算
    for (int j = 0; j < n; j++) {
        if (mask >> j & 1) continue;
        int nxt = mask | (1 << j);
        f[nxt] = min(f[nxt], f[mask] + C[k][j]);
    }
}
```

2. **不可達狀態直接跳過**（`if (f[mask] == INF) continue;`）——**526 這種帶合法性限制的題目，實際可達的狀態往往遠少於 $2^n$** ✔。
3. **只枚舉補集中的位元**：`for (int t = ~mask & full; t; t &= t - 1) { int j = __builtin_ctz(t); ... }` ⇒ 內層迴圈次數從 $n$ 降到「剩餘元素數」✔，**平均省一半**。

**記憶化 vs 遞推**：**本節一律推薦遞推**——定理 3 保證順序天然正確，而遞迴 $2^n$ 次的函式呼叫開銷不小 ✔。（9.4 子集狀壓因為轉移複雜，記憶化才比較有優勢。）

**⚠ `INF` 的選擇**：轉移是 `f[mask] + C[k][j]`，用 `INT_MAX` 會溢位 ⇒ **用 `INT_MAX / 2` 或 `0x3f3f3f3f`**（後者的好處是 `memset(f, 0x3f, sizeof f)` 一行搞定）✔。這是 2.1 定理 3 的同一條規則。

## 與相似技巧的比較

- **與 9.2 排列型狀壓（相鄰相關）**：**唯一的差別是代價項的自變數**（定理 1 的 (ii)）。相鄰相關要多一維「上一個是誰」⇒ 狀態 $O(n2^n)$、時間 $O(n^22^n)$。**先判這一點，再動手。**
- **與 9.3 TSP**：TSP 是 9.2 的特例（相鄰相關 + 起點固定 + 要回到起點）。**本節的題目若把「位置」換成「上一個城市」就變成 TSP。**
- **與 9.4 子集狀壓**：本節每次加**一個**元素，9.4 每次加**一整個子集** ⇒ 轉移從 $O(n)$ 變成「枚舉子集」的 $O(2^{|\text{補集}|})$，總計 $O(3^n)$。**判準：題目是「排順序 / 一對一配對」⇒ 本節；「分組 / 劃分」⇒ 9.4。**
- **與匈牙利演算法 / KM 演算法**：二分圖最優匹配的多項式解法是 $O(n^3)$，**理論上比 $O(n2^n)$ 好**。但：
  - $n\le20$ 時 $n2^n=2\times10^7$，$n^3=8000$——**KM 更快，但難寫十倍**；
  - **狀壓 DP 能輕鬆處理額外限制**（「某些配對非法」「代價依賴已配對數」如 2403），KM 不行 ✔。
  - **判準：$n\le20$ 且有額外限制 ⇒ 狀壓；$n\ge100$ 的純匹配 ⇒ KM。** 競賽 / 面試裡幾乎都是前者。
- **與 7.6 多維 DP**：7.6 定理 6 的分水嶺說「要記住『用過哪些元素的集合』⇒ 進 9 章」。**本節就是那句話的兌現。**
- **與 3 章背包**：0-1 背包也是「每個元素選或不選」，但**它只需要記「總重量」這個摘要**，不必記集合 ⇒ $O(nW)$。**判準：能不能用一個標量摘要掉集合？能 ⇒ 背包；不能（因為代價與「第幾個」或「與誰配對」有關）⇒ 狀壓。**
- **與 9.6 SOS DP**：SOS 處理的是「對每個 mask 求其所有子集的彙總」，是**預處理工具**而非排列模型。**兩者常常搭配使用**（先 SOS 預處理，再狀壓轉移）。

## 例題與分級練習

**延伸閱讀**：[LeetCode 526 優美的排列](https://leetcode.cn/problems/beautiful-arrangement/) 是排列型狀壓 DP 的最小完整範例：位置由 `popcount(mask)` 唯一決定，可省去一維。

## 本節重點速查

- **核心（定理 1）**：**已用元素集合相同的排列前綴可以合併 ⇒ $n!\to2^n$。** 成立條件是代價可寫成 $\sum_k w(\sigma(k),k)$——**每一項只依賴「元素」與「位置」。**
- **三秒判準**：把代價寫成總和，看每項的自變數。**只有 $(\text{元素},\text{位置})$ ⇒ 本節；出現 $(\text{元素},\text{前一個元素})$ ⇒ 9.2。**
- **定理 2**：**位置 $=\mathrm{popcount}(\mathit{mask})$，不必多開一維。** 前提是位置被連續填滿——若允許「跳過某些位置」就推不出來。
- **定理 3**：**所有轉移都讓 mask 的整數值嚴格變大 ⇒ `for mask = 0 .. (1<<n)-1` 就是拓撲序。** 不必煩惱填表順序。（**⚠ 9.4 / 9.6 不適用。**）
- **定理 4（1799）**：配對型只需枚舉「含最低未選元素」的配對。**最值型是優化（$O(n^2)\to O(n)$），計數型是正確性必需（否則重複計數）。**
- **定理 5（2172）**：**槽位容量 $>1$ ⇒ 複製槽位，不要自創三進位。** 多花狀態換掉一整類位元錯誤。
- **定理 6**：**1879 / 1947 / 1066 / 2850 是同一題**——二分圖完美匹配。**右側比左側多時，答案是 $\min\{f(\mathit{mask}):\mathrm{popcount}=\#\text{左側}\}$，不是 $f(\text{全集})$。**
- **實作**：`popcount` 提到外層算；不可達狀態 `continue` 剪枝；用 `t &= t-1` 只枚舉補集位元；`INF` 用 `0x3f3f3f3f` 配 `memset`。
- **規模**：$n\le20$ 放心用（$2\times10^7$）；$n\ge24$ 記憶體就爆了。
