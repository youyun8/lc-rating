## 這個技術解決什麼問題

**把 $n$ 個元素分成若干個「合法群組」，求最少組數／最小總代價／方案數。**

9.1–9.3 的 $\mathit{mask}$ 是「已用元素集合」，一次加**一個**元素；本節一次加**一整組**：

$$f(\mathit{mask}) = \min_{\substack{\mathit{sub}\subseteq \mathit{mask}\\ \mathit{sub}\ \text{合法}}} \Big( f(\mathit{mask}\setminus \mathit{sub}) + \mathrm{cost}(\mathit{sub}) \Big).$$

**這就是 9.2 定理 4 留下的那條分界線**：

> **代價的最小計算單元是「一對相鄰元素」⇒ 9.2（加 $\mathit{last}$ 維，$O(n^22^n)$）；**
> **代價的最小計算單元是「一整組」⇒ 本節（枚舉子集，$O(3^n)$）。**

典型題型：

| 題 | 「一組」是什麼 | $\mathrm{cost}$ | 合法性 |
| --- | --- | --- | --- |
| **1681 最小不兼容性** | 一個大小 $n/k$ 的組 | $\max-\min$ | 組內數值互不相同、大小恰為 $n/k$ |
| **1986 最少工作時間段** | 一個工作時段 | $1$ | 組內時間和 $\le$ `sessionTime` |
| **465 最優帳單平衡** | 一群內部可自行結清的人 | $|\mathit{sub}|-1$ | 組內餘額和為 $0$ |
| **2152 穿過所有點的最少直線** | 一條直線上的點集 | $1$ | 這些點共線 |
| **1723 完成所有工作的最短時間** | 一個工人接的工作集 | — | 目標是 $\min\max$，**要加「第幾個工人」維** |
| **1494 並行課程 II** | 一個學期修的課 | $1$ | $|\mathit{sub}|\le k$ 且前置課都已修 |

**兩件事決定本節的成敗**：

1. **$O(3^n)$ 的子集枚舉慣用法**，以及**為什麼是 $3^n$ 而不是 $4^n$**（定理 1）；
2. **強制讓每組包含「最低位元素」**——對計數型是**正確性的必要條件**，對最值型是常數減半（定理 2）。

**⚠ 一個常見的誤判**：看到 $\mathit{mask}$ 就以為是本節。**先問：$\mathit{mask}$ 的語意是「已用元素的集合」還是「這一層的形狀」？** 1349 的 $\mathit{mask}$ 是「這一列坐了哪些位子」，屬於逐列相容性 DP，**不是子集劃分**（定理 6）。

## 狀態／資料結構定義

### 基本型（不需要額外維度）

$$f(\mathit{mask}) = \text{把 } \mathit{mask} \text{ 裡的元素全部分完組的最小總代價};\qquad f(\varnothing)=0.$$

**預處理**（**必做**，否則複雜度多一個 $n$）：

- `sum[mask]` — 組內數值和，用 lowbit 遞推 $O(2^n)$：`sum[mask] = sum[mask ^ low] + a[ctz(low)]`；
- `cost[mask]` — 這個子集當成「一組」的代價，**不合法就填 $-1$**，$O(2^n\cdot n)$。

### 加維度型

$$f(i,\ \mathit{mask}) = \text{只用前 } i \text{ 個「容器」，服務完 } \mathit{mask} \text{ 的最佳值}.$$

**什麼時候必須加這一維**（定理 5）：**各組的身份／容量不同時**。

| 題 | 需要 $i$ 嗎 | 理由 |
| --- | --- | --- |
| 1681 | ✘ 不需要 | 組數 $=\mathrm{popcount}(\mathit{mask})/(n/k)$，可推導（7.6 定理 6 檢查 ①） |
| 1986 | ✘ 不需要 | 組數就是被最小化的 $f$ 本身 |
| **1723** | ✔ 需要 | 目標是 $\min\max$，$f(w,\mathit{mask})$ 的 $w$ 無法由 $\mathrm{popcount}$ 推出 |
| **1655 分配重複整數** | ✔ 需要 | 第 $i$ 種數值的**供給量不同**，各容器不對等 |

### 子集枚舉慣用法

```cpp
for (int sub = mask; sub; sub = (sub - 1) & mask) { /* 所有非空子集，遞減序 */
}
```

**為什麼對**：`sub - 1` 把最低的 1 借位成 0、其下全變 1；再 `& mask` 投影回 $\mathit{mask}$ 的位元空間 ⇒ 恰好得到**數值上次小的子集** ✔。要含空集就寫成 `for (int t = mask; ; t = (t-1) & mask) { ...; if (!t) break; }` ✔。

## 不變量或正確性證明

### 定理 1（**枚舉所有 mask 的所有子集恰是 $O(3^n)$**）

*命題*：$\displaystyle\sum_{\mathit{mask}\subseteq[n]} 2^{\mathrm{popcount}(\mathit{mask})} = 3^n.$

*證明（雙射）*。左邊在數的是**有序對 $(\mathit{mask},\mathit{sub})$ 且 $\mathit{sub}\subseteq \mathit{mask}$** 的個數。給定這樣一個對，每個元素 $x$ 恰落入三種互斥情形之一：

$$x\notin \mathit{mask};\qquad x\in \mathit{mask}\ \text{且}\ x\in \mathit{sub};\qquad x\in \mathit{mask}\ \text{且}\ x\notin \mathit{sub}.$$

反過來，任一「每個元素三選一」的指派唯一決定一組 $(\mathit{mask},\mathit{sub})$ ⇒ 雙射 ⇒ 個數 $=3^n$ ✔。$\square$

*代數驗證*：$\sum_{k}\binom{n}{k}2^k = (1+2)^n = 3^n$ ✔。

*推論 1.1*：**寫成 `for mask: for sub = 0..mask: if ((sub & mask) == sub)` 是 $O(4^n)$**，$n=16$ 時是 $4\times10^9$ ✘。**一定要用 `(sub-1) & mask` 的慣用法。**

*規模表*：

| $n$ | $3^n$ | 可行性 |
| --- | --- | --- |
| 12 | $5.3\times10^5$ | 輕鬆 ✔ |
| 14 | $4.8\times10^6$ | 輕鬆 ✔ |
| **16** | $4.3\times10^7$ | 可行（**但迴圈內不能再有 $O(n)$**）⚠ |
| 18 | $3.9\times10^8$ | 通常 TLE ✘ |

**這就是為什麼本節題目幾乎都卡在 $n\le16$**，而 9.1–9.3（$O(n^22^n)$）能到 $n\le18$。

### 定理 2（**強制每組包含最低位元素：計數型必要、最值型優化**）

*記號*：$\mathrm{low}(\mathit{mask}) = \mathit{mask}\ \&\ (-\mathit{mask})$。

*命題*：把轉移限制成「$\mathit{sub}\ni \mathrm{low}(\mathit{mask})$」，則

**(a)** 對最值型，$f$ 的值不變，但枚舉量從 $3^n$ 降到 $3^n/2$；
**(b)** 對**計數型**，這是**必要的**——不加此限制會把同一個劃分數 $g!$ 次（$g$ = 組數）。

*證明*。設 $\mathcal{P}=\{S_1,\dots,S_g\}$ 是 $\mathit{mask}$ 的任一合法劃分。

**不漏**：$\mathrm{low}(\mathit{mask})$ 屬於**某一個** $S_t$；把這個 $S_t$ 當作枚舉到的 $\mathit{sub}$，剩下的 $\mathcal{P}\setminus\{S_t\}$ 是 $\mathit{mask}\setminus S_t$ 的合法劃分 ⇒ 該劃分在遞迴中被走到 ✔。

**不重**：由於劃分的各組互斥，$\mathrm{low}(\mathit{mask})$ 只屬於**唯一一個** $S_t$ ⇒ 每個劃分**恰好**對應一條遞迴路徑 ✔。

於是「限制後枚舉到的劃分集合」與「所有合法劃分」之間是**雙射** ⇒ (a) 最小值不變 ✔；(b) 計數不重不漏 ✔。

**不加限制時**：同一個劃分 $\{S_1,\dots,S_g\}$ 會依「先剝哪一組」的 $g!$ 種順序各被走到一次 ⇒ 計數放大 $g!$ 倍 ✘。$\square$

*依賴的前提*：**各組互斥**（是「劃分」不是「覆蓋」）。**若允許重疊，「$\mathrm{low}$ 只屬於唯一一組」就不成立** ⇒ 見定理 3 的另一套處理 ⚠。

*這是 7.7 定理 6 去重框架 ③（正規化）的第三次現身*：7.3 的「第一次出現」、9.2 定理 3 的「排序後只允許最小可用索引」、本定理的「強制含 lowbit」——**都是在每個等價類裡挑一個代表**。

*實作*：

```cpp
int low = mask & -mask, rest = mask ^ low;
for (int t = rest;; t = (t - 1) & rest) {
    int sub = t | low;  // 保證含 low
    /* ... */
    if (!t) break;
}
```

### 定理 3（**「覆蓋」與「劃分」何時等價——以及覆蓋型可以只用 $O(2^n\cdot|\mathcal{C}|)$**）

*設定*：有一族候選集合 $\mathcal{C}$，要用最少個數的候選集合**覆蓋**全體（允許重疊）。

*命題*：若

- **(i) 合法性對子集封閉**：$S\in\mathcal{C}$ 且 $S'\subseteq S$ $\Rightarrow$ $S'\in\mathcal{C}$；
- **(ii) 代價對子集單調不增**：$S'\subseteq S \Rightarrow \mathrm{cost}(S')\le \mathrm{cost}(S)$，

則**最小覆蓋代價 $=$ 最小劃分代價**。

*證明*。**($\le$)** 劃分是覆蓋的特例 ✔。

**($\ge$)** 取一個最優覆蓋 $S_1,\dots,S_g$。令 $S'_t := S_t\setminus(S_1\cup\cdots\cup S_{t-1})$（把重疊部分歸給編號較小者）。則 $\{S'_t\}$ 互斥、聯集不變 ⇒ 是一個劃分（去掉空的）✔；由 (i) 每個 $S'_t$ 仍合法 ✔；由 (ii) $\sum\mathrm{cost}(S'_t)\le\sum\mathrm{cost}(S_t)$ ✔。$\square$

*套用*：

- **2152（最少直線）**：共線集合的子集仍共線 ✔ (i)；$\mathrm{cost}\equiv1$ ✔ (ii) ⇒ **可以用覆蓋型**。
- **1681**：組的大小必須**恰為** $n/k$ ⇒ **(i) 不成立** ✘ ⇒ **必須嚴格劃分**。
- **1986**：時間和 $\le$ `sessionTime` 對子集封閉 ✔；$\mathrm{cost}\equiv1$ ✔ ⇒ 兩種寫法都對，但劃分型比較好寫。

*推論 3.1（覆蓋型的效率優勢）*：覆蓋型可以寫成**前推**轉移

$$f(\mathit{mask}\ |\ S)\ \leftarrow\ f(\mathit{mask}) + \mathrm{cost}(S),\qquad S\in\mathcal{C},$$

複雜度 $O(2^n\cdot|\mathcal{C}|)$。**2152 中 $|\mathcal{C}|=O(n^2)$（每對點決定一條直線）⇒ $O(n^22^n)$，遠優於 $3^n$** ✔。

再配上**「只擴充編號最小的未覆蓋點」**（`low = ctz(~mask)`，僅枚舉含 `low` 的 $S$）⇒ 又快一截，理由與定理 2 完全相同 ✔。

### 定理 4（**465：最少交易數 $=m-$ 最多的零和分組數**）

*設定*：算出每個人的淨餘額，丟掉為 $0$ 的，剩下 $m$ 個人，餘額總和為 $0$。

*命題*：最少交易次數 $=m-g^{*}$，其中 $g^{*}$ 是「把這 $m$ 個人劃分成**組內餘額和為 $0$** 的組」的**最大組數**。

*證明*。

**($\ge$)，即交易數 $\ge m-g^{*}$**：把一組交易看成圖上的邊（每筆交易連接付款人與收款人）。結清後每個人餘額為 $0$ ⇒ **每個連通分量內部的餘額和必為 $0$**（錢不會跨分量流動）✔。設共有 $c$ 個分量、大小 $s_1,\dots,s_c$，則交易數 $\ge\sum(s_j-1)=m-c$（連通分量至少要 $s_j-1$ 條邊）✔。而這 $c$ 個分量構成一個零和劃分 ⇒ $c\le g^{*}$ ⇒ 交易數 $\ge m-c\ge m-g^{*}$ ✔。

**($\le$)**：取一個有 $g^{*}$ 組的零和劃分。組內大小 $s$ 時，**$s-1$ 筆交易一定夠**：任取組內一人 $u$，讓其他每個人都與 $u$ 結算一次（$u$ 收下所有負債、付出所有債權）；因組內和為 $0$，最後 $u$ 恰好歸零 ✔。總計 $\sum(s_j-1)=m-g^{*}$ ✔。$\square$

*依賴的前提*：**交易金額可以任意（不限於原始金額）** ✔，題目允許；**沒有「不能欠陌生人」之類的限制** ✔。

計算 $g^{*}$。令 $f(\mathit{mask})$ 表示「$\mathit{mask}$ 最多能切成幾個零和組」，**只在 $\mathrm{sum}(\mathit{mask})=0$ 時有定義**。轉移取含 lowbit 且零和的 $\mathit{sub}$；因 $\mathrm{sum}(\mathit{mask})=\mathrm{sum}(\mathit{sub})=0\Rightarrow\mathrm{sum}(\mathit{mask}\setminus \mathit{sub})=0$ ⇒ **遞迴永遠落在有定義的狀態上** ✔（這就是本題的不變量）。

### 定理 5（**要不要加「第幾個容器」維——三個判準**）

*命題*：需要額外的 $i$ 維，**當且僅當**下列任一成立：

1. **各容器不對等**（容量／供給／代價函數不同）⇒ 1655（第 $i$ 種數值的庫存不同）、1723（要區分是第幾個工人才能做 $\min\max$）；
2. **目標不是各組代價之和**（例如 $\min\max$）⇒ 1723；
3. **組數受硬性上限而又無法由 $\mathrm{popcount}$ 推出**。

反之，若容器對等且目標是求和／求組數，就**不要加維**：

- **1681**：組大小固定 $n/k$ ⇒ 組數 $=\mathrm{popcount}(\mathit{mask})/(n/k)$，**可由狀態推導** ⇒ 加維純屬浪費（7.6 定理 6 檢查 ①）✔；
- **1986**：組數就是 $f$ 的值本身 ✔。

*1723 的正確轉移*：

$$f(w,\ \mathit{mask}) = \min_{\mathit{sub}\subseteq \mathit{mask}} \max\Big( f(w-1,\ \mathit{mask}\setminus \mathit{sub}),\ \ \mathrm{sum}(\mathit{sub}) \Big),\qquad f(1,\mathit{mask})=\mathrm{sum}(\mathit{mask}).$$

*為什麼 $\max$ 在裡面、$\min$ 在外面*：$w$ 個工人並行 ⇒ 完工時間是**各工人負載的最大值** ✔；我們可以選分法 ⇒ 外層 $\min$ ✔。**（與 8.2 定理 3 的 minimax 形狀相同，但語意是「並行」而非「對手」——別混。）**

*⚠ 1723 也可以「二分答案 + 可行性 DP」*，但**這裡的 DP 版本已經是 $O(k3^n)$，二分反而不划算**；5.3 定理 3 的「min-max ⇒ 二分」是在**沒有好 DP** 時才用的退路。

### 定理 6（**$\mathit{mask}$ 的兩種語意：本節 vs 逐列 DP**）

*命題*：看到位元遮罩，先分辨它是哪一種：

| $\mathit{mask}$ 的語意 | 轉移形狀 | 屬於 | 例子 |
| --- | --- | --- | --- |
| **已用元素的集合**（只增不減） | 剝掉一個合法子集 | **本節 9.4** | 1681、465、1986、1723 |
| 已用元素的集合 + 目前位置 | 加一個元素 | 9.2 / 9.3 | 996、TSP |
| **這一列的形狀**（每列重設） | 與**上一列**的 $\mathit{mask}$ 檢查相容 | **逐列狀壓** | **1349 參加考試的最大學生數** |
| 一條**鋸齒狀**的邊界 | 逐格推進 | 9.5 輪廓線 | 鋪磚類 |

*1349 為什麼不屬於本節*：它的 $f(i,\mathit{mask})$ 中 $\mathit{mask}$ 是**第 $i$ 列坐了哪些位子**，第 $i+1$ 列的 $\mathit{mask}'$ **不必與它互斥**，只要滿足

$$\mathit{mask}'\ \&\ \text{壞位子}=0,\quad \mathit{mask}'\ \&\ (\mathit{mask}'\ll1)=0,\quad \mathit{mask}'\ \&\ (\mathit{mask}\ll1)=0,\quad \mathit{mask}'\ \&\ (\mathit{mask}\gg1)=0.$$

**「元素恰屬一組」這條本節的核心前提在 1349 完全不存在** ⇒ 它是 9.5 的入門題，不是 9.4 ✔。

*1494 的一個重要事實*：「每輪最多做 $k$ 件、有前置限制」的排程（$P|\mathit{prec},p_j=1|C_{\max}$）——

- $k=2$：有多項式演算法（Coffman–Graham）✔；
- 前置關係是**森林**：有多項式演算法（Hu）✔；
- **一般的 $k\ge3$：沒有已知的多項式演算法** ✘。

**所以 1494 把 $n$ 限制在 15——那是在明示狀壓。任何「按深度／按後繼數排序」的貪心都只是啟發式，不要拿來當解。**

```cpp
// ---- 0. 子集枚舉的兩種慣用法 ----
// 非空子集（遞減序）
for (int sub = mask; sub; sub = (sub - 1) & mask) { /* ... */
}
// 含空集
for (int t = mask;; t = (t - 1) & mask) { /* ... */
    if (!t) break;
}
// 強制含 lowbit（定理 2）：計數型必用，最值型省一半
{
    int low = mask & -mask, rest = mask ^ low;
    for (int t = rest;; t = (t - 1) & rest) {
        int sub = t | low;
        /* ... */
        if (!t) break;
    }
}

// ---- 1. 子集劃分 DP 骨架（最小總代價）----
// cost[sub] >= 0 表示 sub 可以當一組；-1 表示不合法
int partitionMinCost(int n, const vector<int>& cost) {
    int FULL = 1 << n;
    const int INF = 0x3f3f3f3f;
    vector<int> f(FULL, INF);
    f[0] = 0;
    for (int mask = 1; mask < FULL; mask++) {
        int low = mask & -mask, rest = mask ^ low;
        for (int t = rest;; t = (t - 1) & rest) {
            int sub = t | low;
            if (cost[sub] >= 0 && f[mask ^ sub] != INF)
                f[mask] = min(f[mask], f[mask ^ sub] + cost[sub]);
            if (!t) break;
        }
    }
    return f[FULL - 1];
}

// ---- 2. LC 1681 最小不兼容性 ----
int minimumIncompatibility(vector<int>& nums, int k) {
    int n = (int)nums.size(), sz = n / k, FULL = 1 << n;
    vector<int> cost(FULL, -1);
    for (int mask = 0; mask < FULL; mask++) {
        if (__builtin_popcount(mask) != sz) continue;
        int mn = 100, mx = 0, seen = 0;
        bool ok = true;
        for (int i = 0; i < n && ok; i++) {
            if (!(mask >> i & 1)) continue;
            if (seen >> nums[i] & 1) {
                ok = false;
                break;
            }  // 組內不可重複
            seen |= 1 << nums[i];
            mn = min(mn, nums[i]);
            mx = max(mx, nums[i]);
        }
        if (ok) cost[mask] = mx - mn;
    }
    const int INF = 0x3f3f3f3f;
    vector<int> f(FULL, INF);
    f[0] = 0;
    for (int mask = 1; mask < FULL; mask++) {
        if (__builtin_popcount(mask) % sz) continue;  // 非整組數必不可達
        int low = mask & -mask, rest = mask ^ low;
        for (int t = rest;; t = (t - 1) & rest) {
            int sub = t | low;
            if (cost[sub] >= 0 && f[mask ^ sub] != INF)
                f[mask] = min(f[mask], f[mask ^ sub] + cost[sub]);
            if (!t) break;
        }
    }
    return f[FULL - 1] == INF ? -1 : f[FULL - 1];
}

// ---- 3. LC 465 最優帳單平衡（定理 4）----
int minTransfers(vector<vector<int>>& transactions) {
    unordered_map<int, int> bal;
    for (auto& t : transactions) {
        bal[t[0]] -= t[2];
        bal[t[1]] += t[2];
    }
    vector<int> a;
    for (auto& [_, v] : bal)
        if (v) a.push_back(v);
    int m = (int)a.size(), FULL = 1 << m;
    if (m == 0) return 0;
    vector<int> sum(FULL, 0), f(FULL, 0);  // f[mask]：最多切成幾個零和組
    for (int mask = 1; mask < FULL; mask++) {
        int low = mask & -mask;
        sum[mask] = sum[mask ^ low] + a[__builtin_ctz(low)];
    }
    for (int mask = 1; mask < FULL; mask++) {
        if (sum[mask] != 0) continue;  // 不變量：只在零和遮罩上遞推
        int low = mask & -mask, rest = mask ^ low;
        for (int t = rest;; t = (t - 1) & rest) {
            int sub = t | low;
            if (sum[sub] == 0) f[mask] = max(f[mask], f[mask ^ sub] + 1);
            if (!t) break;
        }
    }
    return m - f[FULL - 1];
}

// ---- 4. LC 2152 最少直線：覆蓋型前推（推論 3.1）----
int minimumLines(vector<vector<int>>& points) {
    int n = (int)points.size();
    if (n <= 2) return 1;
    vector<int> lines;  // 候選集合族 C
    for (int i = 0; i < n; i++)
        for (int j = i + 1; j < n; j++) {
            int mask = 0;
            for (int k = 0; k < n; k++) {
                long long cross = 1LL * (points[j][0] - points[i][0]) *
                                      (points[k][1] - points[i][1]) -
                                  1LL * (points[j][1] - points[i][1]) *
                                      (points[k][0] - points[i][0]);
                if (cross == 0) mask |= 1 << k;
            }
            lines.push_back(mask);
        }
    int FULL = 1 << n;
    vector<int> f(FULL, INT_MAX);
    f[0] = 0;
    for (int mask = 0; mask + 1 < FULL; mask++) {
        if (f[mask] == INT_MAX) continue;
        int low = __builtin_ctz(~mask);  // 只覆蓋編號最小的未覆蓋點
        for (int L : lines) {
            if (!(L >> low & 1)) continue;
            int nxt = mask | L;
            f[nxt] = min(f[nxt], f[mask] + 1);
        }
    }
    return f[FULL - 1];
}

// ---- 5. LC 1723 完成所有工作的最短時間：加「第幾個工人」維（定理 5）----
int minimumTimeRequired(vector<int>& jobs, int k) {
    int n = (int)jobs.size(), FULL = 1 << n;
    vector<int> sum(FULL, 0);
    for (int mask = 1; mask < FULL; mask++) {
        int low = mask & -mask;
        sum[mask] = sum[mask ^ low] + jobs[__builtin_ctz(low)];
    }
    vector<int> f = sum;  // f[mask]：1 個工人 => 全包
    for (int w = 2; w <= k; w++) {
        vector<int> g(FULL, INT_MAX);
        g[0] = 0;
        for (int mask = 1; mask < FULL; mask++) {
            int low = mask & -mask, rest = mask ^ low;
            for (int t = rest;; t = (t - 1) & rest) {
                int sub = t | low;  // 工人可互換 => 讓最後一人拿 low
                g[mask] = min(g[mask], max(f[mask ^ sub], sum[sub]));
                if (!t) break;
            }
        }
        f = move(g);
    }
    return f[FULL - 1];
}
```

## 時間與空間複雜度

| 模式 | 時間 | 空間 |
| --- | --- | --- |
| **子集劃分（基本型）** | $O(3^n)$ | $O(2^n)$ |
| 強制含 lowbit | $O(3^n/2)$ | $O(2^n)$ |
| **覆蓋型前推**（推論 3.1） | $O(2^n\cdot|\mathcal{C}|)$ | $O(2^n)$ |
| 加容器維（1723、1655） | $O(k\cdot3^n)$ | $O(2^n)$（滾動掉 $k$ 維 ✔） |
| 預處理 `cost[sub]` | $O(2^n\cdot n)$ | $O(2^n)$ |
| 預處理 `sum[sub]`（lowbit 遞推） | $O(2^n)$ | $O(2^n)$ |

**⚠ 最容易寫爆的一行**：把 `cost(sub)` 的計算**放進 $3^n$ 的內層迴圈** ⇒ $O(3^n\cdot n)$，$n=16$ 時 $7\times10^8$ ✘。**一定要先 $O(2^n n)$ 預處理成表。**

**具體題目**：

| 題 | $n$ | 複雜度 |
| --- | --- | --- |
| 1681 | $\le16$ | $O(3^n)$，$4.3\times10^7$ ✔ |
| 465 | $\le12$ 人 | $O(3^m)$，$5\times10^5$ ✔ |
| 1986 | $\le14$ | $O(3^n)$，$4.8\times10^6$ ✔ |
| **2152** | $\le10$ | $O(n^22^n)$，$10^5$ ✔（若用 $3^n$ 也只有 $6\times10^4$，兩者都行） |
| 1723 | $\le12$，$k\le12$ | $O(k3^n)$，$6\times10^6$ ✔ |
| 1494 | $\le15$ | $O(3^n)$，$1.4\times10^7$ ✔ |

**滾動**：加維型的 $i$ 維可以滾動（`f` / `g` 兩層互換）✔——**但不能就地更新**，因為轉移會讀到 $\mathit{mask}$ 的**任意**子集，不是固定偏移（2.1 定理 2：偏移不固定 ⇒ 必須整層替換）。

**常數優化**：

1. **`if (f[mask ^ sub] == INF) continue;`** — 稀疏可達時省很多 ✔。
2. **用 `popcount` 早退**：1681 的 `if (popcount(mask) % sz) continue;` 一行砍掉大部分遮罩 ✔。
3. **把不合法的子集先收集成 vector**，內層只走合法者（1681 中大小 $\ne n/k$ 的佔絕大多數）✔。
4. **`f` 用 `int` 而非 `long long`**：$2^{16}$ 個 int 只有 256 KB，快取友善 ✔。

## 常見錯誤與邊界條件

- **✘ 用 `for (sub = 0; sub <= mask; sub++) if ((sub & mask) == sub)` 枚舉子集。** 這是 $O(4^n)$，$n=16$ 直接 TLE（定理 1 推論 1.1）。
- **✘ 計數型忘記固定 lowbit。** 答案會膨脹 $g!$ 倍（定理 2b）。**最值型忘記只是慢一倍，計數型忘記就是錯的**——這個不對稱很容易記漏。
- **✘ 覆蓋型當成劃分型用在 1681 上。** 組大小必須恰為 $n/k$，合法性對子集不封閉 ⇒ 定理 3 的前提 (i) 破了 ✘。
- **✘ `cost(sub)` 在內層迴圈現算。** 多一個 $O(n)$ ⇒ 超時。
- **✘ 從不可達狀態轉移。** `INF + cost` 溢位 ⇒ 用 `0x3f3f3f3f` 並加 `continue` ✔。
- **✘ `for (sub = mask; sub; sub = (sub-1) & mask)` 漏掉空集。** 若「一組可以是空的」有意義，就要用含空集的寫法 ⚠（多數題目不需要，但 1723 的「工人閒著」要想清楚——模板 5 用 lowbit 版避開了這個問題）。
- **✘ 465 忘記先刪掉餘額為 $0$ 的人。** $m$ 白白變大，$3^m$ 爆炸 ✘；而且答案不受影響（餘額 0 的人不需要任何交易）✔。
- **✘ 465 直接對「原始交易」做 DP。** 要先聚合成**淨餘額**——同兩人之間的多筆交易可以合併 ✔。
- **✘ 1681 沒有處理無解。** 某個數值出現超過 $k$ 次 ⇒ 必有一組重複 ⇒ 回傳 $-1$；模板用 `f[FULL-1] == INF` 統一處理 ✔。
- **✘ 2152 只考慮「由兩點決定的直線」而漏掉 $n\le2$。** $n=1$ 或 $2$ 時沒有點對，`lines` 是空的 ⇒ 要特判回傳 1 ✔。
- **✘ 2152 用浮點斜率判共線。** 精度問題 ⇒ **用整數叉積** ✔。
- **✘ 1494 用貪心。** $k\ge3$ 的前置排程沒有已知多項式解（定理 6）✘。
- **邊界**：$n=0$（空集，答案 0）；$k=1$（只有一組，就是全集）；$k=n$（每個元素自成一組）；所有元素都不合法（回傳 $-1$）。

## 與相似技巧的比較

- **與 9.2／9.3**：**判準就是 9.2 定理 4 那一句——代價的最小計算單元是「一對」還是「一整組」。** 一對 ⇒ 加 $\mathit{last}$，$O(n^22^n)$；一整組 ⇒ 枚舉子集，$O(3^n)$。**1681 正是被 9.2 定理 4 判給本節的那道題。**
- **⚠ 與 9.1 定理 3（mask 遞增即拓撲序）**：**本節仍然滿足**（$\mathit{mask}$ 只增不減，且 $\mathit{mask}\setminus \mathit{sub}<\mathit{mask}$）⇒ `for mask = 0..FULL-1` 依然是合法順序 ✔。**但 9.6 SOS DP 不滿足**，那裡要按位元維度分層。
- **與 9.5 輪廓線**：定理 6 的表就是判準。**$\mathit{mask}$ 是「已用元素集合」⇒ 本節；是「一層的形狀」⇒ 逐列；是「鋸齒邊界」⇒ 9.5。**
- **與 9.6 SOS DP**：本節對每個 $\mathit{mask}$ 枚舉子集是 $O(3^n)$；**若你只需要「所有子集的某個彙總量」（和／最值／計數），SOS DP 只要 $O(n2^n)$** ⇒ 看到 $3^n$ 超時，先問「內層真的需要逐一檢視子集，還是只要一個彙總？」
- **與 3 章背包**：1986（時間和 $\le$ 上限）本質是**裝箱問題**。背包是「一個容器選物品」，裝箱是「多個容器分完所有物品」——**裝箱是 NP-hard，所以只能狀壓**。
- **與 7.7 計數 DP**：定理 2b 就是 7.7 定理 1「計數必須是嚴格劃分」在位元遮罩上的實例；去重手法是 7.7 定理 6 框架 ③（正規化）。
- **與 8.2 區間 DP**：兩者都是「枚舉最後一塊」。差別在**區間 DP 的「一塊」必須連續**（$O(n)$ 種切法），**本節的「一組」可以是任意子集**（$O(2^{|\mathit{mask}|})$ 種）——這就是 $n^3$ 與 $3^n$ 的差距來源。

## 本節重點速查

- **核心式**：$f(\mathit{mask})=\min_{\mathit{sub}\subseteq \mathit{mask},\ \mathit{sub}\ \text{合法}}\big(f(\mathit{mask}\setminus \mathit{sub})+\mathrm{cost}(\mathit{sub})\big)$。
- **枚舉慣用法**：`for (int sub = mask; sub; sub = (sub - 1) & mask)`。**別寫 $O(4^n)$ 的版本。**
- **定理 1**：$\sum_{\mathit{mask}}2^{\mathrm{popcount}}=3^n$，三態雙射證明。$n\le16$ 是實務上限。
- **定理 2**：**強制 $\mathit{sub}\ni\mathrm{low}(\mathit{mask})$。最值型省一半，計數型不加就錯（多算 $g!$ 倍）。**
- **定理 3**：合法性對子集封閉 **且** 代價對子集單調不增 ⇒ 覆蓋 $=$ 劃分 ⇒ 可用 $O(2^n|\mathcal{C}|)$ 前推（2152）。**1681 不滿足 (i)，必須嚴格劃分。**
- **定理 4（465）**：答案 $=m-$（最多零和分組數）。下界用「連通分量內部和為 0 且至少 $s-1$ 條邊」，上界用「組內指定一人統一結算」。**先刪餘額 0 的人。**
- **定理 5**：容器不對等（1655）或目標是 $\min\max$（1723）⇒ 加維；組數可由 $\mathrm{popcount}$ 推出（1681）或就是 $f$ 本身（1986）⇒ 不加維。
- **定理 6**：$\mathit{mask}$ 是「已用元素集合」才是本節；**1349 的 $\mathit{mask}$ 是「這一列的形狀」，屬於逐列 DP（9.5 入門）。**
- **⚠ 效能第一守則**：`cost[sub]` 與 `sum[sub]` 一律 $O(2^n)$／$O(2^nn)$ 預處理，**絕不在 $3^n$ 內層現算**。
- **實作**：`0x3f3f3f3f` + 不可達 `continue`；`popcount` 早退；滾動容器維要整層替換（2.1 定理 2）。
