## 這個技術解決什麼問題

**對每一個 $\mathit{mask}$，都要知道「它所有子集」的某個彙總量（和／最值／計數／存在性）。**

$$F(\mathit{mask}) \;=\; \bigoplus_{\mathit{sub}\subseteq \mathit{mask}} a(\mathit{sub}),\qquad \oplus\in\{+,\ \max,\ \min,\ \text{or},\ \dots\}.$$

**暴力**：對每個 $\mathit{mask}$ 枚舉子集 ⇒ $O(3^n)$（9.4 定理 1）。
**SOS DP（Sum over Subsets，又稱 zeta 變換／高維前綴和）**：$O(n2^n)$。

$n=20$ 時 $3^{20}=3.5\times10^9$ ✘ 對上 $20\cdot2^{20}=2\times10^7$ ✔——**這就是本節存在的全部理由**。

### 一句話直覺：**SOS 就是 $n$ 維前綴和，只是每一維長度都是 2**

二維前綴和你會寫成兩趟：

```cpp
for (int i = 1; i < R; i++)
    for (int j = 0; j < C; j++) s[i][j] += s[i - 1][j];
for (int i = 0; i < R; i++)
    for (int j = 1; j < C; j++) s[i][j] += s[i][j - 1];
```

**一個維度一趟，趟與趟之間有先後**。SOS 一模一樣，只是有 $n$ 個維度、每維只有 $\{0,1\}$ 兩格：

```cpp
for (int i = 0; i < n; i++)
    for (int mask = 0; mask < (1 << n); mask++)
        if (mask >> i & 1) f[mask] += f[mask ^ (1 << i)];
```

**「先 bit 後 mask」這個順序不是風格問題，是正確性問題**（定理 2）。

### 什麼訊號代表該用 SOS

| 訊號 | 例 |
| --- | --- |
| 「對每個 $\mathit{mask}$，統計有多少個 $\mathit{sub}\subseteq \mathit{mask}$ 滿足…」 | 子集計數 |
| 「兩個數**沒有公共位**（$x\ \&\ y=0$），求最佳配對」 | 定理 5 |
| 「所有子集中的最大值／是否存在」 | max-SOS |
| 「按位或等於 $\mathit{mask}$ 的方案數」 | 先算 $\subseteq$ 再反演（定理 3） |
| 想枚舉子集但複雜度逼近 $3^n$，而**內層其實只要一個彙總值** | 定理 4 |

**⚠ 反過來也要會判**：本節題單裡有些題**根本不需要 SOS**（見「與相似技巧的比較」）。**先問「$n$ 有多大」——$n\le16$ 時 $3^n=4\times10^7$ 還過得去，SOS 的價值主要在 $n\ge18$。**

## 狀態／資料結構定義

### 三個基本變換（都是 $O(n2^n)$、原地）

| 名稱 | 定義 | 迴圈 |
| --- | --- | --- |
| **子集和（zeta）** | $F(\mathit{mask})=\sum_{\mathit{sub}\subseteq \mathit{mask}}a(\mathit{sub})$ | `if (mask>>i&1) f[mask] += f[mask^(1<<i)];` |
| **超集和** | $G(\mathit{mask})=\sum_{\mathit{sup}\supseteq \mathit{mask}}a(\mathit{sup})$ | `if (!(mask>>i&1)) g[mask] += g[mask|(1<<i)];` |
| **反演（Möbius）** | 從 $F$ 還原 $a$ | `if (mask>>i&1) f[mask] -= f[mask^(1<<i)];` |

**中間狀態的意義**（這才是真正的「狀態定義」，也是定理 1 的不變量）：

$$f_t(\mathit{mask}) \;=\; \sum_{\substack{\mathit{sub}\subseteq \mathit{mask}\\ \mathit{sub}\ \text{與}\ \mathit{mask}\ \text{在第 } t,t+1,\dots,n-1 \text{ 位相同}}} a(\mathit{sub}).$$

即：**跑完前 $t$ 個位元後，$f_t(\mathit{mask})$ 只在「低 $t$ 位」上允許自由縮小，高位必須與 $\mathit{mask}$ 一致。** $f_0=a$，$f_n=F$ ✔。

### 記憶體

$F$ 與 $a$ 可以是**同一個陣列**（原地變換，定理 2 保證安全）⇒ 空間 $O(2^n)$，不需要 $O(n2^n)$ ✔。

## 不變量或正確性證明

### 定理 1（**SOS 的正確性**）

*命題*：以上述 $f_t$ 為不變量，迴圈

```cpp
for (int i = 0; i < n; i++)
    for (int mask = 0; mask < (1 << n); mask++)
        if (mask >> i & 1) f[mask] += f[mask ^ (1 << i)];
```

在第 $i$ 趟結束後恰好把 $f_i$ 變成 $f_{i+1}$，因此結束時 $f=f_n=F$。

*證明（對 $i$ 歸納）*。

**基底**：$t=0$ 時，「與 $\mathit{mask}$ 在第 $0..n-1$ 位全相同」的 $\mathit{sub}$ 只有 $\mathit{mask}$ 自己 ⇒ $f_0=a$ ✔。

**歸納步**：假設現在陣列是 $f_i$。固定 $\mathit{mask}$，把「$f_{i+1}(\mathit{mask})$ 的求和範圍」依 **$\mathit{sub}$ 的第 $i$ 位**分成兩類（**互斥且窮盡**）：

- **第 $i$ 位與 $\mathit{mask}$ 相同**：這部分恰是 $f_i(\mathit{mask})$ ✔。
- **第 $i$ 位是 $0$ 而 $\mathit{mask}$ 的第 $i$ 位是 $1$**：這要求 $\mathit{mask}$ 的第 $i$ 位為 $1$；此時這些 $\mathit{sub}$ 都是 $\mathit{mask}\setminus\{i\}$ 的子集，且與 $\mathit{mask}\setminus\{i\}$ 在第 $i..n-1$ 位相同 ⇒ 這部分恰是 $f_i(\mathit{mask}\oplus2^i)$ ✔。

若 $\mathit{mask}$ 的第 $i$ 位是 $0$，第二類為空 ⇒ $f_{i+1}(\mathit{mask})=f_i(\mathit{mask})$，程式不動它 ✔；否則 $f_{i+1}(\mathit{mask})=f_i(\mathit{mask})+f_i(\mathit{mask}\oplus2^i)$，正是程式做的事 ✔。$\square$

*依賴的前提*：$\oplus$ **可交換、可結合**（$+$、$\max$、$\min$、`|`、`&` 都可以）✔。**不需要有逆元**——逆元只有反演（定理 3）才需要。

### 定理 2（**兩個順序問題：為什麼原地安全、為什麼不能「先 mask 後 bit」**）

**(a) 原地更新是安全的。**

*證明*。固定第 $i$ 趟。程式**只寫入**第 $i$ 位為 $1$ 的 $\mathit{mask}$；**只讀取** $f[\mathit{mask}]$（同一格，先讀後寫 ✔）與 $f[\mathit{mask}\oplus2^i]$，後者的第 $i$ 位是 $0$ ⇒ **本趟永遠不會被寫入** ✔。於是「本趟被寫的集合」與「本趟被讀的**其他**格」不相交 ⇒ 讀到的一定是 $f_i$ 的值，與 $\mathit{mask}$ 的枚舉順序無關 ✔。$\square$

**所以第 $i$ 趟裡的 `for mask` 可以遞增、遞減、甚至平行——這是 2.1 定理 2 的正面案例：讀寫集不相交時，就地是安全的。**

**(b) 「先 mask 後 bit」對加法是錯的。**

*反例*（$n=2$，$a=(a_{00},a_{01},a_{10},a_{11})$）。錯誤寫法：

```cpp
for (int mask = 0; mask < 4; mask++)
    for (int i = 0; i < 2; i++)
        if (mask >> i & 1) f[mask] += f[mask ^ (1 << i)];
```

- $\mathit{mask}=01$：$f_{01}=a_{01}+a_{00}$ ✔
- $\mathit{mask}=10$：$f_{10}=a_{10}+a_{00}$ ✔
- $\mathit{mask}=11$：先 $i=0$ ⇒ $f_{11}=a_{11}+f_{10}=a_{11}+a_{10}+a_{00}$；再 $i=1$ ⇒ $f_{11}\mathrel{+}=f_{01}=a_{01}+a_{00}$

得 $a_{00}+a_{01}+a_{10}+a_{11}+\boxed{a_{00}}$ ⇒ **$a_{00}$ 被算了兩次** ✘。正確答案是 $a_{00}+a_{01}+a_{10}+a_{11}$。

**根本原因**：「經由 $01$ 到 $11$」與「經由 $10$ 到 $11$」是通往 $00$ 的兩條不同路徑。分層寫法（先 bit）讓每個 $\mathit{sub}$ 到 $\mathit{mask}$ **只有唯一一條「依位元編號遞增地補上缺的位」的路徑** ⇒ 不重不漏 ✔。

**(c) ⚠ 但若 $\oplus$ 冪等（$\max$／$\min$／`|`／`&`／存在性），「先 mask 後 bit」是對的。**

*證明*：對 $\mathit{mask}$ 遞增時，所有 $\mathit{mask}\oplus2^i<\mathit{mask}$ 都已算完 ⇒
$$f(\mathit{mask})=a(\mathit{mask})\ \oplus\ \bigoplus_{i\in \mathit{mask}} f(\mathit{mask}\setminus\{i\}),$$
右邊涵蓋所有真子集（可能重複涵蓋，但**冪等 ⇒ 重複無害**）✔。$\square$

> **這正是 9.1 定理 3 那句警告的精確版本**：
> **「$\mathit{mask}$ 遞增是合法拓撲序」在本節對冪等運算仍成立，對「加法／計數」則會重複計數。**
> **不確定時一律用分層寫法（先 bit 後 mask）——它對兩種情形都對。**

### 定理 3（**反演：zeta 與 Möbius 互為逆變換**）

*命題*：把每一趟的 `+=` 改成 `-=`（順序不變），得到的變換 $\mu$ 滿足 $\mu(\zeta(a))=a$，即

$$a(\mathit{mask}) = \sum_{\mathit{sub}\subseteq \mathit{mask}} (-1)^{|\mathit{mask}|-|\mathit{sub}|}\,F(\mathit{sub}).$$

*證明*。第 $i$ 趟的 zeta 是線性映射：對每一組配對 $(\mathit{mask}\oplus2^i,\ \mathit{mask})$（第 $i$ 位 0/1 的兩格），做 $\begin{pmatrix}1&0\\1&1\end{pmatrix}$；其反矩陣是 $\begin{pmatrix}1&0\\-1&1\end{pmatrix}$，恰是把 `+=` 換成 `-=` ✔。整個 zeta 是 $n$ 個這種映射的複合，逐層取反即得逆 ✔（且**每層都可逆，所以順序照舊即可，不必倒著跑**）。$\square$

*用途（最常見的一條）*：

> **「恰好等於」很難算，「至多／包含於」好算 ⇒ 先算 $\subseteq$ 版，再反演回「恰好」。**

例：已知「按位或**是 $\mathit{mask}$ 的子集**的方案數」$F(\mathit{mask})$，要求「按位或**恰為** $\mathit{mask}$ 的方案數」$a(\mathit{mask})$ ⇒ 對 $F$ 做 Möbius ✔。

*依賴的前提*：**運算要有逆元**（整數加法、模 $p$ 加法 ✔）。**$\max$／$\min$ 沒有逆元 ⇒ 不能反演** ✘。

### 定理 4（**判準：什麼時候 SOS 能取代 9.4 的 $3^n$**）

*命題*：9.4 的子集枚舉迴圈

$$f(\mathit{mask}) = \bigoplus_{\mathit{sub}\subseteq \mathit{mask}} h(\mathit{sub},\ \mathit{mask}\setminus \mathit{sub})$$

能降到 $O(n2^n)$，**當且僅當 $h$ 只依賴 $\mathit{sub}$（或只依賴 $\mathit{mask}\setminus \mathit{sub}$），與另一半無關**。

*證明方向*。若 $h(\mathit{sub},\cdot)=h(\mathit{sub})$，則右邊就是 $a=h$ 的 zeta 變換 ⇒ $O(n2^n)$ ✔。若 $h$ 同時依賴兩半（例如 9.4 的 $f(\mathit{mask}\setminus \mathit{sub})+\mathrm{cost}(\mathit{sub})$，其中 $f$ 本身還在被計算），**兩半耦合**，zeta 無能為力——那需要子集卷積（定理 6）⚠。$\square$

*三秒判準*：

> **「我要的是所有子集的一個彙總值」⇒ SOS，$O(n2^n)$。**
> **「我要對每個子集分別做點事、還要用到補集的 DP 值」⇒ 子集枚舉，$O(3^n)$（或定理 6）。**

### 定理 5（**「無公共位」配對：取補集 + max-SOS**）

*問題型*：給定一組數，求 $x\ \&\ y=0$ 的一對 $(x,y)$ 使 $x\cdot y$（或 $x+y$ 等）最大。

*做法*：設值域為 $[0,2^n)$，`best[mask]` $=$ 「所有出現過且 $\subseteq \mathit{mask}$ 的數之中的最佳者」（用 **max-SOS** 算出）。對每個出現過的 $x$：

$$\text{候選} = x \;\otimes\; \mathit{best}\big[\ \overline{x}\ \big],\qquad \overline{x} = (2^n-1)\oplus x.$$

*正確性*。

**(不漏)** 對任一合法配對 $(x,y)$：$x\ \&\ y=0\iff y\subseteq\overline{x}$ ✔ ⇒ $y$ 在 $\mathit{best}[\overline{x}]$ 的候選集合裡 ⇒ 該配對的值 $\le x\otimes \mathit{best}[\overline{x}]$ ✔。

**(不多)** $\mathit{best}[\overline{x}]$ 取到的 $y$ 必定滿足 $y\subseteq\overline{x}$ ⇒ $x\ \&\ y=0$ ⇒ 是**合法**配對 ✔。

兩邊夾擊 ⇒ 枚舉 $x$ 取最大即為答案 ✔。$\square$

*依賴的前提*：

- **$\otimes$ 對 $y$ 單調遞增**（乘上非負的 $x$、相加，都可以）✔。**若目標不單調（例如求 $|x-y|$ 最小），max-SOS 就不適用** ✘。
- **同一個數用兩次是否合法**要看題意 ⚠：若不能重複用同一個「元素」，而值域裡該值只出現一次，要額外處理（記錄 $\mathit{best}$ 的**前二大**或記錄來源索引）。

*複雜度*：$O(2^n\cdot n)$，$n=20$ 時 $2\times10^7$ ✔。**這是 SOS 最經典的一個應用場景。**

### 定理 6（**子集卷積：$O(3^n)\to O(n^22^n)$，以及它的適用範圍**）

*定義*：$\displaystyle (f*g)(\mathit{mask}) = \sum_{\mathit{sub}\subseteq \mathit{mask}} f(\mathit{sub})\,g(\mathit{mask}\setminus \mathit{sub}).$

*命題*：可在 $O(n^22^n)$ 內對所有 $\mathit{mask}$ 算出 $(f*g)$。

*做法與證明要點*。直接對 $f,g$ 做 zeta 再逐點相乘會得到

$$\zeta(f)\cdot\zeta(g)\ (\mathit{mask}) = \sum_{\mathit{s},\mathit{t}\subseteq \mathit{mask}} f(\mathit{s})g(\mathit{t}),$$

其中 $\mathit{s},\mathit{t}$ **可以相交**，也可以聯集不足 $\mathit{mask}$ ✘。修正的關鍵是**加一維 popcount**：

$$\hat f_k(\mathit{mask}) := \sum_{\substack{\mathit{sub}\subseteq \mathit{mask}\\ |\mathit{sub}|=k}} f(\mathit{sub})\quad(\text{對每個 } k \text{ 各做一次 zeta}).$$

令 $\hat h_k = \sum_{p+q=k}\hat f_p\cdot\hat g_q$（逐點乘），再對每層做 Möbius 得 $h_k$，則

$$(f*g)(\mathit{mask}) = h_{|\mathit{mask}|}(\mathit{mask}).$$

**為什麼取 $k=|\mathit{mask}|$ 這一層就對**：該層裡的貢獻滿足 $\mathit{s}\cup \mathit{t}=\mathit{mask}$ **且** $|\mathit{s}|+|\mathit{t}|=|\mathit{mask}|$ ⇒ 由排容 $|\mathit{s}\cap \mathit{t}|=|\mathit{s}|+|\mathit{t}|-|\mathit{s}\cup \mathit{t}|=0$ ⇒ **$\mathit{s}$ 與 $\mathit{t}$ 必定不交** ✔——**這就是「加 popcount 維」的全部意義：用計數把「不交」這個條件變成一條等式。**

*複雜度*：$n+1$ 層 zeta／Möbius 各 $O(n2^n)$，逐點乘 $O(n^22^n)$ ⇒ 總 $O(n^22^n)$ ✔。

*⚠ 適用範圍（很重要）*：

| 目標 | 能否用子集卷積加速 |
| --- | --- |
| **計數型劃分**（有幾種分組法） | ✔ 可以，$O(n^22^n)$ |
| **最少組數** | ✔ 可以（算「恰好 $k$ 組」的卷積冪，找最小的非零 $k$）⚠ 模運算下要小心「非零」被誤判 |
| **最小總代價劃分**（9.4 的 1681） | ✘ **沒有已知的等價加速**——$(\min,+)$ 不是環，沒有逆元，Möbius 步驟做不了 |

**所以 9.4 的最值型仍然停在 $O(3^n)$，而那正是 9.4 的題目都卡在 $n\le16$ 的原因。**

## C++17 模板

```cpp
// ---- 1. 三個基本變換（原地，O(n·2^n)）----
void subsetSum(vector<long long>& f, int n) {  // zeta：F[m] = Σ_{s⊆m} a[s]
    for (int i = 0; i < n; i++)
        for (int m = 0; m < (1 << n); m++)
            if (m >> i & 1) f[m] += f[m ^ (1 << i)];
}

void supersetSum(vector<long long>& f, int n) {  // G[m] = Σ_{s⊇m} a[s]
    for (int i = 0; i < n; i++)
        for (int m = 0; m < (1 << n); m++)
            if (!(m >> i & 1)) f[m] += f[m | (1 << i)];
}

void mobius(vector<long long>& f, int n) {  // zeta 的逆（定理 3）
    for (int i = 0; i < n; i++)
        for (int m = 0; m < (1 << n); m++)
            if (m >> i & 1) f[m] -= f[m ^ (1 << i)];
}

// ---- 2. max 版 SOS：best[m] = 所有 s⊆m 中 a[s] 的最大值 ----
// max 冪等 => 兩種迴圈順序都對（定理 2c），但分層寫法一律安全
vector<int> subsetMax(const vector<int>& a, int n) {
    vector<int> f = a;  // 不存在的 s 請填 INT_MIN / 0
    for (int i = 0; i < n; i++)
        for (int m = 0; m < (1 << n); m++)
            if (m >> i & 1) f[m] = max(f[m], f[m ^ (1 << i)]);
    return f;
}

// ---- 3. 「無公共位」的最佳配對（定理 5）----
long long bestDisjointPair(const vector<int>& nums, int n) {  // 值域 [0, 2^n)
    int FULL = (1 << n) - 1;
    vector<int> best(1 << n, -1);
    for (int x : nums) best[x] = max(best[x], x);  // 只取最佳代表值
    for (int i = 0; i < n; i++)
        for (int m = 0; m < (1 << n); m++)
            if (m >> i & 1) best[m] = max(best[m], best[m ^ (1 << i)]);
    long long ans = 0;
    for (int x : nums) {
        int y = best[FULL ^ x];  // y ⊆ ~x  <=>  x & y == 0
        if (y >= 0) ans = max(ans, 1LL * x * y);
    }
    return ans;
}

// ---- 4. 「按位或恰為 mask」：先算 ⊆ 版再反演（定理 3）----
// cnt[v] = 值為 v 的元素個數；求「子集的 OR 恰為 m」的子集數
vector<long long> exactOrCount(const vector<int>& cnt, int n) {
    vector<long long> c(cnt.begin(), cnt.end());
    subsetSum(c, n);  // c[m] = 有幾個元素 ⊆ m
    vector<long long> f(1 << n);
    for (int m = 0; m < (1 << n); m++) f[m] = (1LL << c[m]);  // OR ⊆ m 的子集數
    mobius(f, n);                                             // => OR 恰為 m
    return f;
}

// ---- 5. 子集卷積 O(n^2 · 2^n)（定理 6）----
vector<long long> subsetConvolution(const vector<long long>& f,
                                    const vector<long long>& g, int n) {
    int S = 1 << n;
    vector fh(n + 1, vector<long long>(S, 0)), gh = fh, hh = fh;
    for (int m = 0; m < S; m++) {
        fh[__builtin_popcount(m)][m] = f[m];
        gh[__builtin_popcount(m)][m] = g[m];
    }
    for (int k = 0; k <= n; k++) {
        subsetSum(fh[k], n);
        subsetSum(gh[k], n);
    }
    for (int p = 0; p <= n; p++)
        for (int q = 0; p + q <= n; q++)
            for (int m = 0; m < S; m++) hh[p + q][m] += fh[p][m] * gh[q][m];
    for (int k = 0; k <= n; k++) mobius(hh[k], n);
    vector<long long> res(S);
    for (int m = 0; m < S; m++) res[m] = hh[__builtin_popcount(m)][m];
    return res;
}
```

## 時間與空間複雜度

| 操作 | 時間 | 空間 |
| --- | --- | --- |
| **zeta／超集和／Möbius** | $O(n2^n)$ | $O(2^n)$（原地 ✔） |
| 暴力子集枚舉（9.4） | $O(3^n)$ | $O(2^n)$ |
| **無公共位配對**（定理 5） | $O(n2^n + |\mathit{nums}|)$ | $O(2^n)$ |
| **子集卷積**（定理 6） | $O(n^22^n)$ | $O(n2^n)$ ⚠ |

**$n$ 的可行區間**：

| $n$ | $n2^n$（SOS） | $3^n$（枚舉） | $n^22^n$（卷積） |
| --- | --- | --- | --- |
| 16 | $1.0\times10^6$ ✔ | $4.3\times10^7$ ✔ | $1.7\times10^7$ ✔ |
| 18 | $4.7\times10^6$ ✔ | $3.9\times10^8$ ✘ | $8.5\times10^7$ ⚠ |
| **20** | $2.1\times10^7$ ✔ | $3.5\times10^9$ ✘ | $4.2\times10^8$ ✘ |
| 22 | $9.2\times10^7$ ⚠ | ✘ | ✘ |

**這張表就是選型依據**：$n\le16$ 隨便寫；$n=18\sim20$ **只有 SOS 能用**；子集卷積的實用上限大約在 $n=18$。

**⚠ 子集卷積的空間是 $O(n2^n)$**：$n=20$ 時 $21\cdot2^{20}\cdot8\ \text{B}\approx176$ MB $\times3$ 個陣列 ⇒ **必爆** ✘。要嘛降 $n$，要嘛用 `int`／模數並只保留必要層。

**常數優化**：

1. **把外層 `for i` 與內層 `for m` 的順序記牢**——外層必須是位元 ✔。內層對 $m$ 遞增有良好的快取局部性。
2. **只跑到實際用到的位元數 $n$**，不要用固定的 20 ⇒ 常數直接砍 $2^{20-n}$ 倍 ✔。
3. **`f` 用 `int` 而非 `long long`**（若不會溢位）⇒ 快取行裝兩倍資料，實測快 30–50% ✔。
4. **模運算**：用 `if (f[m] >= MOD) f[m] -= MOD;` 取代 `%`；Möbius 的減法要 `if (f[m] < 0) f[m] += MOD;` ✔。

## 常見錯誤與邊界條件

- **✘ 迴圈寫成「先 mask 後 bit」而運算是加法。** 會重複計數（定理 2b 的 $a_{00}$ 反例）。**這是本節第一名的錯誤，而且在小測資上常常剛好對。**
- **✘ 用 $n=20$ 的固定上界跑一個實際只有 $n=10$ 的問題。** 慢 1000 倍 ✘。
- **✘ 超集和的條件寫反。** 子集和是 `if (m >> i & 1) f[m] += f[m ^ (1<<i)]`；超集和是 `if (!(m >> i & 1)) f[m] += f[m | (1<<i)]`。**兩個都要背，別靠推。**
- **✘ 對 $\max$／$\min$ 做 Möbius 反演。** 沒有逆元 ⇒ 無意義 ✘（定理 3 前提）。
- **✘ max-SOS 的初值填 0。** 若數值可以是負數或 0 是合法值，$0$ 會被誤認為「存在一個值為 0 的元素」⇒ 用 `INT_MIN` 或另設 `exists` 陣列 ✔。
- **✘ 定理 5 中把同一個元素用兩次。** 若題目要求兩個**不同**的元素，而某個值只出現一次，就會誤判 ⇒ 記錄前二大或來源索引 ⚠。
- **✘ 模數下用 `f[m] != 0` 判斷「存在方案」。** 真實方案數可能是 $\mathrm{MOD}$ 的倍數 ⇒ 誤判為 0 ✘（定理 6 的「最少組數」用法要特別小心；穩妥做法是換成 max-plus 或用兩個模數）。
- **✘ 子集卷積忘記最後只取 $k=\mathrm{popcount}(\mathit{mask})$ 那一層。** 取錯層等於算了「可相交」的版本 ✘。
- **✘ 值域沒有補滿 $2^n$。** SOS 的陣列長度必須是 $2^n$，缺的位置要填單位元素（$0$／`INT_MIN`）✔。
- **邊界**：$n=0$（只有一個空集，$F(\varnothing)=a(\varnothing)$）；`nums` 為空；所有數都是 0（定理 5 的答案是 0，不是無解）；$\mathit{mask}=0$（子集只有自己）。

## 與相似技巧的比較

- **與 9.4 子集狀壓**：**定理 4 就是判準。** 9.4 是「對每個子集分別做事、還要讀補集的 DP 值」⇒ $3^n$；本節是「只要一個彙總值」⇒ $n2^n$。**看到 $3^n$ 超時，先問：內層真的需要逐一檢視每個子集嗎？**
- **⚠ 與 9.1 定理 3（mask 遞增是拓撲序）**：**本節是那條規則唯一的例外家族。** 精確地說（定理 2c）：**冪等運算仍然可以用 mask 遞增；加法／計數不行。** 分層寫法對兩者都對，所以**養成只寫分層版的習慣**。
- **與 2 章前綴和**：SOS **就是** $n$ 維前綴和，每維長度 2；Möbius 就是差分。**如果你會寫二維前綴和與二維差分，你已經會 SOS 了，只差把「維度」換成「位元」。**
- **與排容原理**：定理 3 的 Möbius 展開 $\sum(-1)^{|\mathit{mask}|-|\mathit{sub}|}F(\mathit{sub})$ **就是**位元版的排容。7.7 定理 6 的去重框架 ④（排容）在這裡有了 $O(n2^n)$ 的通用實作 ✔。
- **與 9.7／直接枚舉**：**本節題單裡有些題其實不需要 SOS**，要誠實判斷：
  - **2044 統計按位或能得到最大值的子集數目**：$n\le16$ ⇒ 直接枚舉 $2^{16}=65536$ 個子集、各算 OR，$O(2^nn)$ 就結束了 ✔。**用 SOS 反而複雜。**
  - **2732 找到矩陣中的好子集**：關鍵是一條**與 SOS 無關**的組合引理（若存在好子集，就存在大小 $\le2$ 的好子集）；有了它，因為 $m\le5$，只要枚舉 32 個列遮罩、找一對 `a & b == 0` 即可 ✔。**這題被歸在狀壓，但用到的不是 SOS。**
  - **判準**：$n\le16$ 且每個子集只需 $O(n)$ 處理 ⇒ 直接枚舉；**$n\ge18$ 或需要「對每個 mask 都給答案」⇒ SOS。**
- **與 11 章優化 DP**：SOS 屬於「換一個**變換**來加速轉移」的家族，和字首和優化（11.1）、矩陣快速冪（11.6）是同一類思想——**把「對很多項求和」變成「對結構做一次變換」。**

## 例題與分級練習

**延伸閱讀**：[LeetCode 3670：SOS DP／高維前綴和講解](https://leetcode.cn/problems/maximum-product-of-two-integers-with-no-common-bits/solutions/3768219/mo-ban-gao-wei-qian-zhui-he-sos-dppython-78fz/)，閱讀時只取狀態與轉移推導；本節實作仍以 C++17 為準。

## 本節重點速查

- **核心**：$F(\mathit{mask})=\bigoplus_{\mathit{sub}\subseteq \mathit{mask}}a(\mathit{sub})$，$O(n2^n)$。**SOS = $n$ 維前綴和，每維長度 2。**
- **唯一要背的迴圈**：`for i: for m: if (m>>i&1) f[m] += f[m^(1<<i)];`——**外層是位元，內層是遮罩。**
- **超集和**：`if (!(m>>i&1)) f[m] += f[m|(1<<i)];`。**Möbius 反演**：同樣順序，`+=` 換成 `-=`。
- **定理 1**：不變量 = 「只在低 $t$ 位允許縮小」，歸納時依 $\mathit{sub}$ 的第 $i$ 位做**互斥窮盡**的二分。
- **定理 2**：**(a)** 原地安全（讀寫集不相交，2.1 定理 2 的正面案例）；**(b)** 「先 mask 後 bit」對加法會重複計數（$n=2$ 反例：$a_{00}$ 算兩次）；**(c) 但對 $\max/\min$ 等冪等運算是對的**——這就是 9.1 定理 3 在本節的精確邊界。
- **定理 3**：zeta 與 Möbius 互逆（$2\times2$ 三角矩陣求逆）。**「恰好」難算就先算「⊆」再反演。** 前提：運算要有逆元，$\max$ 不行。
- **定理 4 判準**：只要彙總 ⇒ SOS $O(n2^n)$；兩半耦合 ⇒ $3^n$ 或子集卷積。
- **定理 5**：$x\ \&\ y=0\iff y\subseteq\overline{x}$ ⇒ max-SOS 後查 $\mathit{best}[\overline{x}]$。**不漏因為補集涵蓋，不多因為子集必不交。** 前提：目標對 $y$ 單調。
- **定理 6**：加 popcount 維 ⇒ $|\mathit{s}|+|\mathit{t}|=|\mathit{s}\cup \mathit{t}|$ 強制不交 ⇒ 子集卷積 $O(n^22^n)$。**只適用於 $(+,\times)$ 環；$(\min,+)$ 的最小總代價劃分沒有等價加速**，所以 9.4 仍是 $3^n$。
- **規模**：$n\le16$ 什麼都行；$n=18\sim20$ 只有 SOS；子集卷積實用上限約 $n=18$（空間 $O(n2^n)$ 是瓶頸）。
- **⚠ 誠實判斷**：2044（$n\le16$ 直接枚舉）與 2732（靠組合引理 + $m\le5$）都**不是** SOS 題。
