## 這個技術解決什麼問題

兩件事：一是在含負權邊的圖上求最短路並偵測負環（SPFA，即佇列優化的 Bellman-Ford）；二是把一組形如 `x_j - x_i <= c` 的不等式轉成圖上的最短路問題，判斷是否有解並求出一組解（差分約束）。

## 辨識題型的訊號

出現負權邊或需要判斷「是否存在矛盾的約束」；題目給的是一堆兩兩之間的差值上下界，問能否同時滿足；或要求最大化／最小化某個變數與另一個變數的差。

## 核心想法與直覺

Bellman-Ford 的本質是反覆鬆弛所有邊直到不再變化。SPFA 的觀察是：只有「距離剛剛變小」的節點才可能讓鄰居再變小，因此用佇列只重試這些節點。

差分約束的橋樑是三角不等式：最短路滿足 `dis[j] <= dis[i] + w(i, j)`，移項成 `dis[j] - dis[i] <= w(i, j)`。這與約束 `x_j - x_i <= c` 形狀完全相同，所以為每條約束連一條 `i -> j`、權為 `c` 的邊，跑出的 `dis` 就是一組合法解。

## 狀態／資料結構定義

`dis[x]` 為目前最短距離上界；`in_queue[x]` 避免同一節點重複排入；`count[x]` 記錄 `x` 被鬆弛入隊的次數，用來偵測負環。

## 不變量或正確性證明

不變量：佇列中包含所有「上一次鬆弛後 `dis` 變小、且尚未用來鬆弛鄰居」的節點。因此當佇列為空時，所有邊都滿足 `dis[y] <= dis[x] + w`，即達到最短路的鬆弛終止條件。

負環偵測：無負環時最短路至多經過 `n - 1` 條邊，故任一節點最多被鬆弛入隊 `n - 1` 次。若某節點入隊次數達到 `n`，代表存在一條邊數不少於 `n` 的更短路徑，必然重複經過某節點，該重複段的權重和為負，即負環。

差分約束的可解性：若約束圖存在負環，沿環把不等式相加得到 `0 <= 負數` 的矛盾，故無解；反之無負環時最短路存在，且由三角不等式知它必滿足每一條約束。

## 逐步演算法

SPFA：起點距離設 0 入隊；取出節點鬆弛其所有出邊；被成功鬆弛且不在佇列中的鄰居入隊，並累加其入隊次數；次數達到 `n` 判定負環。

差分約束：把每條 `x_j - x_i <= c` 建成邊 `i -> j` 權 `c`；加一個虛擬源點向所有變數連權 0 的邊以保證連通；跑 SPFA；無負環則 `dis` 即為一組解。

## C++17 模板

```cpp
// 回傳 false 表示存在負環（差分約束即為無解）。
bool spfa(int n, const vector<vector<pair<int, int>>>& g, int start,
          vector<long long>& dis) {
    dis.assign(n, LLONG_MAX);
    vector<int> in_queue(n, 0), count(n, 0);
    dis[start] = 0;
    queue<int> q;
    q.push(start);
    in_queue[start] = 1;

    while (!q.empty()) {
        const int x = q.front();
        q.pop();
        in_queue[x] = 0;
        for (const auto& [y, w] : g[x]) {
            if (dis[x] == LLONG_MAX) {
                continue;
            }
            if (dis[x] + w < dis[y]) {
                dis[y] = dis[x] + w;
                if (!in_queue[y]) {
                    if (++count[y] >= n) {
                        return false;
                    }  // 負環
                    q.push(y);
                    in_queue[y] = 1;
                }
            }
        }
    }
    return true;
}
```

約束轉換備忘：`x_j - x_i <= c` 連 `i -> j` 權 `c`；`x_j - x_i >= c` 改寫成 `x_i - x_j <= -c`；`x_i == x_j` 則雙向各連權 0 的邊。

## 時間與空間複雜度

SPFA 平均接近 $O(m)$，但最壞為 $O(nm)$，且存在專門的卡 SPFA 資料。空間 $O(n + m)$。邊權非負時務必改用 Dijkstra。

## 常見錯誤與邊界條件

- 在無負權的題目用 SPFA 而被最壞情況卡掉。
- 忘記虛擬源點導致約束圖不連通、部分變數未被約束。
- 不等式方向與邊的方向弄反。
- `dis[x]` 仍為無限大時參與加法造成溢位。
- 求「最大化 `x_t - x_s`」時應以 `<=` 建圖跑最短路，求最小化才轉成最長路。

## 與相似技巧的比較

Dijkstra 更快但不允許負權；樸素 Bellman-Ford 為固定 $O(nm)$，實作簡單且更容易分析，判負環同樣可靠；Johnson 演算法用一次 Bellman-Ford 重賦權後改跑多次 Dijkstra，適合稀疏圖的全源最短路。

## 本節重點速查

- 只有變小的點才需重試
- 入隊次數達 `n` 即負環
- `x_j - x_i <= c` 對應邊 `i -> j` 權 `c`
- 記得加虛擬源點。
