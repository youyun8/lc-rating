## 這個技術解決什麼問題

一次算出所有點對之間的最短路。當題目要反覆詢問任意兩點距離，或需要在最短路矩陣上再做決策時，跑 `n` 次 Dijkstra 不如直接用 Floyd——它只有三層迴圈，且允許負權邊。

## 辨識題型的訊號

節點數很小（通常 `n <= 400` 左右），需要任意兩點的距離；題目允許動態加入新節點；或需要判斷「經過某些中繼點」的可達性與傳遞閉包。

## 核心想法與直覺

按「允許使用哪些中繼點」逐步放寬。先只允許直達，再允許經過節點 0，再允許經過節點 0 和 1……每放行一個新的中繼點 `k`，就檢查所有點對能否藉由 `k` 走得更短。迴圈順序必須是 `k` 在最外層，這是整個演算法的靈魂。

## 狀態／資料結構定義

`f[k][i][j]` 是「只允許以編號小於 `k` 的節點作為中繼」時 `i` 到 `j` 的最短距離。由於第 `k` 層只依賴第 `k-1` 層，可以滾動掉第一維，直接用二維 `f[i][j]` 原地更新。

## 不變量或正確性證明

不變量：外層迴圈跑完第 `k` 輪後，`f[i][j]` 等於「中繼點只取自 `{0, ..., k}`」的最短路長度。

歸納步驟：考慮中繼集合擴充到 `k` 時的最短路。若它不經過 `k`，值與上一輪相同；若經過 `k`，因為最短路不會重複經過同一節點，可把路徑切成 `i -> k` 與 `k -> j` 兩段，兩段的中繼點都只取自 `{0, ..., k-1}`，恰為上一輪的值。取兩者較小即得，故不變量成立。

原地更新的安全性：第 `k` 輪中 `f[i][k]` 與 `f[k][j]` 不會在本輪被改變，因為更新它們需要 `f[k][k]`，而在無負環的前提下 `f[k][k]` 為 0，鬆弛不會生效。因此滾動掉一維不影響正確性。

## 逐步演算法

用鄰邊初始化矩陣，對角線設 0、無邊設無限大；三層迴圈依序枚舉中繼點 `k`、起點 `i`、終點 `j`，用 `f[i][k] + f[k][j]` 嘗試更新 `f[i][j]`；結束後矩陣即為全源最短路。

## C++17 模板

```cpp
// f 為鄰接矩陣：無邊填 kInf，對角線填 0。就地變成全源最短路。
void floyd(vector<vector<int>>& f) {
    const int n = f.size();
    const int kInf = 1e9;
    for (int k = 0; k < n; ++k) {  // 中繼點必須在最外層
        for (int i = 0; i < n; ++i) {
            if (f[i][k] == kInf) {
                continue;
            }  // 剪枝：i 到不了 k
            for (int j = 0; j < n; ++j) {
                if (f[k][j] == kInf) {
                    continue;
                }
                f[i][j] = min(f[i][j], f[i][k] + f[k][j]);
            }
        }
    }
}
```

動態加點（每次加入一個新節點後查詢全源最短路）只需把新節點當作新的中繼點跑一輪，總成本仍是 $O(n^3)$：

```cpp
// 新增節點 k 後：先用 k 的邊更新矩陣，再以 k 為中繼跑一輪
for (int i = 0; i < n; ++i) {
    for (int j = 0; j < n; ++j) {
        f[i][j] = min(f[i][j], f[i][k] + f[k][j]);
    }
}
```

## 時間與空間複雜度

時間固定 $O(n^3)$，空間 $O(n^2)$。`n` 為 400 時約 $6.4 \times 10^7$ 次運算，仍可接受；`n` 上千就不可行。

## 常見錯誤與邊界條件

- 把 `k` 寫在內層（結果錯誤且不易察覺）。
- 初始化時漏掉對角線為 0。
- 重邊時應取最小值而非直接覆蓋。
- 無限大直接相加造成溢位，需先剪枝或把 `kInf` 設得夠小。
- 有負權時仍可用，但若 `f[i][i]` 變成負數就代表存在負環。

## 與相似技巧的比較

跑 `n` 次 Dijkstra 為 $O(nm \log m)$，在稀疏圖上更快但不允許負權；Johnson 演算法結合兩者優點；若只需要可達性而非距離，把 `min/+` 換成 `or/and` 即為傳遞閉包，並可用 bitset 再加速。

## 本節重點速查

- `k` 一定在最外層
- 對角線初始化為 0
- 可原地更新省一維
- `n` 小才用
- 負權可以、負環看對角線。
