## 這個技術解決什麼問題

當我們只關心「`i` 能不能到 `j`」而不關心距離時，Floyd 的內層迴圈變成一連串布林運算。用 `bitset` 把一整列的可達性壓進機器字，內層 `n` 次布林或運算就縮成 `n / 64` 次字運算，常數直接降低約 64 倍。

## 辨識題型的訊號

求傳遞閉包、判斷任意兩點是否連通、統計每個點能到達多少節點、或需要「誰一定排在誰前面」的偏序關係。節點數在 1000 到 3000 之間，$O(n^3)$ 剛好超時而 $O(n^3 / 64)$ 剛好可行。

## 核心想法與直覺

傳遞閉包的遞推是 `reach[i][j] |= reach[i][k] && reach[k][j]`。固定 `i` 與 `k` 後，`reach[i][k]` 是一個常數：若為真，這一整列就是 `reach[i] |= reach[k]`；若為假，什麼都不用做。整列的按位或正是 `bitset` 的原生操作。

## 狀態／資料結構定義

`reach[i]` 是一個 `bitset<N>`，第 `j` 位表示 `i` 是否能到達 `j`。`N` 必須是編譯期常數，取節點數上限。

## 不變量或正確性證明

不變量與 Floyd 完全相同：第 `k` 輪結束後，`reach[i][j]` 為真等價於存在一條由 `i` 到 `j` 且中繼點只取自 `{0, ..., k}` 的路徑。

改寫的等價性：原式對每個 `j` 獨立計算 `reach[i][j] |= reach[i][k] & reach[k][j]`。當 `reach[i][k]` 為假時右側恆為假，整列不變；當它為真時右側化為 `reach[k][j]`，對所有 `j` 同時成立，即整列的按位或。兩種情形都與逐位計算的結果一致，故正確性不受影響——這是純粹的常數優化，不改變演算法本身。

## 逐步演算法

用鄰接關係初始化每個 `reach[i]`，並把自己設為可達；三層結構縮成兩層：枚舉中繼點 `k`，再枚舉起點 `i`，若 `reach[i][k]` 為真就執行 `reach[i] |= reach[k]`；結束後即得傳遞閉包。

## C++17 模板

```cpp
constexpr int kMaxN = 3000;

// 回傳傳遞閉包：reach[i][j] 表示 i 是否能到達 j。
vector<bitset<kMaxN>> transitiveClosure(int n,
                                        const vector<vector<int>>& edges) {
    vector<bitset<kMaxN>> reach(n);
    for (int i = 0; i < n; ++i) {
        reach[i][i] = true;  // 自己到自己
    }
    for (const auto& e : edges) {
        reach[e[0]][e[1]] = true;
    }

    for (int k = 0; k < n; ++k) {  // 中繼點仍在最外層
        for (int i = 0; i < n; ++i) {
            if (reach[i][k]) {
                reach[i] |= reach[k];  // 一次處理 64 個 j
            }
        }
    }
    return reach;
}
```

統計每個節點能到達的數量用 `reach[i].count()`；判斷是否所有點對都有偏序關係（例如「能否排出唯一名次」）則檢查每對 `i < j` 是否至少一個方向可達。

## 時間與空間複雜度

時間 $O(n^3 / w)$，其中 $w$ 為機器字長（通常 64）；`n = 3000` 時約 $4 \times 10^8 / 64$ 次字運算，實務上數十毫秒。空間 $O(n^2 / w)$ 位元，`n = 3000` 約 1.1 MB。

## 常見錯誤與邊界條件

- `bitset` 的大小必須是編譯期常數，不能用執行期的 `n`，開太大會浪費記憶體與時間。
- 忘記把對角線設為真，導致「自己可達自己」的題意被漏掉。
- 仍把 `k` 寫在內層。
- 誤以為這個技巧能套用在帶權最短路上——`min/+` 無法用按位運算表示，只有布林的 `or/and` 可以。

## 與相似技巧的比較

若只需要無向圖的連通性，並查集是 $O(n \alpha(n))$，遠優於本法；若圖是 DAG 且只需部分查詢，可用拓撲序上的 DP 逐點合併 `bitset`，效果相同；本法的適用場合是有向圖、需要完整點對可達矩陣、且 `n` 落在千級。

## 本節重點速查

- 只做可達性才能壓位
- `reach[i] |= reach[k]` 取代內層迴圈
- `k` 仍在最外層
- 對角線要設為真。
