## 這個技術解決什麼問題

找一條把每條邊恰好走一次的路徑（尤拉路徑）或回路（尤拉回路）。注意重點在「走遍所有邊」，而不是走遍所有點——後者是漢米頓路徑，屬於 NP-困難問題。

## 辨識題型的訊號

「重新安排行程」「用完所有機票」「把所有字串首尾相接」；每個元素恰好用一次，而元素本身是「連接兩個狀態的轉移」。多數題目還要求輸出字典序最小的方案。

## 核心想法與直覺

存在性由度數決定。有向圖存在尤拉路徑的條件是：所有邊在同一個連通塊內，且至多一個節點出度比入度多 1（起點）、至多一個節點入度比出度多 1（終點），其餘節點出入度相等。若全部相等則存在尤拉回路。

構造用 Hierholzer 演算法：一路往前走直到卡住（無出邊可用），把卡住的節點壓入答案堆疊，再回退繼續探索其他分支。最後把堆疊反轉就是答案。

## 狀態／資料結構定義

`g[x]` 為 `x` 的出邊列表；用指標或 `multiset` 標記每條邊是否用過。`path` 是後序收集的節點堆疊，最終反轉輸出。

## 不變量或正確性證明

不變量：遞迴在節點 `x` 卡住時，`x` 的所有出邊都已被使用。

正確性：在滿足度數條件的連通圖上，從起點出發沿未用邊行走，只可能卡在終點（其他節點每進入一次就必有一條未用出邊可離開，因為出入度相等）。因此第一次卡住時走出的是一條從起點到終點的路徑，剩餘未用邊構成若干個各自度數平衡的子圖，掛在已走路徑的某些節點上。回退到這些節點時遞迴會繼續走完子圖，並在後序時把子回路接進答案。

後序反轉之所以正確：節點被壓入堆疊的時機是「它再也沒有可用出邊」，所以先壓入的是路徑末端、後壓入的是接近起點的部分，反轉後恰為正向順序，且子回路會被插在正確的接點上。

## 逐步演算法

統計度數並檢查存在性；決定起點（有出度多 1 的節點就用它，否則任選一個有出邊的節點）；從起點遞迴，每次取走一條未用出邊並前進；無邊可走時把自己壓入堆疊；遞迴結束後反轉堆疊。

## C++17 模板

以「重新安排行程」為例，需要字典序最小，故把每個節點的出邊排序後依序取用：

```cpp
class Solution {
public:
    vector<string> findItinerary(vector<vector<string>>& tickets) {
        map<string, multiset<string>> g;
        for (const auto& t : tickets) {
            g[t[0]].insert(t[1]);
        }

        vector<string> path;
        function<void(const string&)> dfs = [&](const string& x) {
            auto& outs = g[x];
            while (!outs.empty()) {
                const string y = *outs.begin();
                outs.erase(outs.begin());  // 取走即刪除，保證每條邊只用一次
                dfs(y);
            }
            path.push_back(x);  // 後序：卡住才記錄
        };

        dfs("JFK");
        reverse(path.begin(), path.end());
        return path;
    }
};
```

節點為整數時改用 `vector<int>` 加一個「已用到第幾條邊」的游標，可省下 `multiset` 的對數成本。

## 時間與空間複雜度

每條邊恰好被取用一次，時間 $O(m)$（用 `multiset` 或排序時為 $O(m \log m)$），空間 $O(n + m)$。

## 常見錯誤與邊界條件

- 寫成前序記錄節點，遇到需要回退的分支就會輸出錯誤順序。
- 忘記刪除已用的邊而無限迴圈。
- 起點選錯（存在尤拉路徑時必須從出度多 1 的節點出發，從別處出發會走不完）。
- 忽略連通性檢查——度數條件滿足但邊分散在多個連通塊時無解。
- 孤立節點不影響判定，只需保證所有「有邊的」節點連通。

## 與相似技巧的比較

漢米頓路徑要走遍所有點，沒有多項式解法，資料小時用位元遮罩 DP；一般 DFS 走遍所有點而非所有邊；中國郵差問題允許重複走邊並求最小總長，需要在尤拉的基礎上做最小權完美匹配。

## 本節重點速查

- 走遍所有邊不是所有點
- 度數決定是否存在
- Hierholzer 後序入堆疊再反轉
- 邊取走就刪。
