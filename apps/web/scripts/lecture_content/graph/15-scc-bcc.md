## 這個技術解決什麼問題

找出有向圖中「互相都能到達」的極大節點群（強連通分量，SCC），或無向圖中刪掉會使圖斷開的關鍵邊與關鍵點（橋與割點，屬於雙連通分量的範疇）。前者用於把有環圖縮成 DAG，後者用於分析網路的脆弱處。

## 辨識題型的訊號

有向圖上要做 DP 但存在環；問「有多少組節點彼此可互相到達」；無向圖問「哪些連線是關鍵連線」「刪掉哪個點會讓網路斷開」。

## 核心想法與直覺

兩者共用同一個框架：DFS 時記錄每個節點的時間戳 `dfn`，並計算 `low`——從該節點的子樹出發、最多用一條非樹邊能回溯到的最小時間戳。`low` 衡量的是「這棵子樹能不能繞回祖先」。

若一條樹邊 `x -> y` 滿足 `low[y] > dfn[x]`，代表 `y` 的子樹完全繞不回 `x` 或更早的節點，這條邊就是橋。有向圖中若 `low[x] == dfn[x]`，代表 `x` 是某個強連通分量在 DFS 樹上的最高點，堆疊中從 `x` 之上的節點構成一個分量。

## 狀態／資料結構定義

`dfn[x]` 為 `x` 的訪問序號（0 表示未訪問）；`low[x]` 為子樹可回溯到的最小 `dfn`；Tarjan 求 SCC 額外用一個堆疊存放尚未歸屬分量的節點，以及 `in_stack[x]` 標記。

## 不變量或正確性證明

不變量：`low[x]` 等於「`x` 的 DFS 子樹中所有節點，經由至多一條回邊（有向圖中為指向堆疊內節點的邊）所能到達的最小 `dfn`」。

橋的判定：若 `low[y] > dfn[x]`，則 `y` 的子樹沒有任何邊通向 `x` 或其祖先，刪除邊 `(x, y)` 後子樹與其餘部分再無連結，故為橋；反之若 `low[y] <= dfn[x]`，存在一條繞路，刪邊後仍連通。

SCC 的判定：`low[x] == dfn[x]` 表示 `x` 的子樹無法回到比 `x` 更早的節點，因此 `x` 是其所在強連通分量中 `dfn` 最小者。堆疊中位於 `x` 之上的節點都能到達 `x` 且被 `x` 到達，故恰好構成一個極大強連通集合。`in_stack` 的檢查不可省略：指向已歸屬其他分量之節點的邊屬於橫叉邊，不能用來更新 `low`。

## 逐步演算法

對每個未訪問節點啟動 DFS；進入時分配 `dfn` 與 `low` 並入堆疊；對樹邊遞迴後用 `low[y]` 更新 `low[x]`，對回邊（`in_stack[y]` 為真）用 `dfn[y]` 更新；離開時若 `low[x] == dfn[x]` 就不斷彈出堆疊直到彈出 `x`，這些節點組成一個 SCC。

## C++17 模板

```cpp
// Tarjan 求強連通分量：comp[x] 為 x 所屬分量編號，回傳分量總數。
int tarjanScc(int n, const vector<vector<int>>& g, vector<int>& comp) {
    vector<int> dfn(n, 0), low(n, 0), in_stack(n, 0), stk;
    comp.assign(n, -1);
    int timer = 0, count = 0;

    function<void(int)> dfs = [&](int x) {
        dfn[x] = low[x] = ++timer;
        stk.push_back(x);
        in_stack[x] = 1;
        for (int y : g[x]) {
            if (!dfn[y]) {
                dfs(y);
                low[x] = min(low[x], low[y]);  // 樹邊：用子樹的 low
            } else if (in_stack[y]) {
                low[x] = min(low[x], dfn[y]);  // 回邊：只用 dfn，且必須在堆疊內
            }
        }
        if (low[x] == dfn[x]) {  // x 是分量的根
            while (true) {
                const int y = stk.back();
                stk.pop_back();
                in_stack[y] = 0;
                comp[y] = count;
                if (y == x) {
                    break;
                }
            }
            ++count;
        }
    };

    for (int i = 0; i < n; ++i) {
        if (!dfn[i]) {
            dfs(i);
        }
    }
    return count;
}
```

無向圖找橋的差異：改用「父邊編號」而非父節點來排除回頭（以正確處理重邊），並在遞迴後判斷 `low[y] > dfn[x]`。

## 時間與空間複雜度

每個節點與每條邊各處理常數次，時間 $O(n + m)$，空間 $O(n + m)$，遞迴深度最差 $O(n)$。

## 常見錯誤與邊界條件

- 更新 `low` 時對回邊誤用 `low[y]` 而非 `dfn[y]`。
- 漏掉 `in_stack` 檢查，把橫叉邊算進來。
- 無向圖找橋時用父節點排除回頭，遇到重邊就會誤判（重邊之間互為退路，不是橋）。
- `dfn` 從 0 開始並同時用 0 當作未訪問標記。
- 縮點後別忘了同一分量內的邊要去除自環。

## 與相似技巧的比較

Kosaraju 用兩次 DFS 求 SCC，較易理解但常數較大；並查集只能處理無向連通性，無法求有向的強連通；求割點的條件是 `low[y] >= dfn[x]`（且根節點需另外看子樹數量），與橋的嚴格不等號差一個等號，這是最容易記混的地方。

## 本節重點速查

- `low` 是子樹能回溯到的最早時間
- 回邊用 `dfn` 不用 `low`
- `low[x] == dfn[x]` 就彈出一個 SCC
- 橋是 `>`、割點是 `>=`。
