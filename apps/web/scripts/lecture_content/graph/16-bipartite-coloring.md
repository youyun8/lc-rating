## 這個技術解決什麼問題

判斷能不能把所有節點分成兩組，使每條邊的兩端都落在不同組。這等價於「用兩種顏色染色且相鄰不同色」，也等價於「圖中不存在奇數長度的環」。

## 辨識題型的訊號

要把人分成兩隊且某些人不能同隊、判斷是否存在矛盾的敵對關係、可能的二分匹配前置檢查；或題目直接說「相鄰元素必須不同」。

## 核心想法與直覺

顏色沒有選擇餘地：一旦某個節點定色，它的所有鄰居就被迫是另一色，再往外一路傳遞下去。因此整個連通塊的染色由起點的顏色唯一決定（至多兩種對稱的方案）。矛盾只會以「某條邊兩端同色」的形式出現。

## 狀態／資料結構定義

`color[x]` 取 `0` 表示未染色、`1` 與 `2` 表示兩種顏色。用 `3 - c` 在兩色之間切換。圖可能不連通，需對每個未染色節點各起一次。

## 不變量或正確性證明

不變量：任一時刻，所有已染色節點之間的邊都滿足兩端異色。

正確性：DFS 從起點出發，節點 `x` 到起點的路徑長度奇偶性決定了它的顏色。若染色過程中遇到邊 `(x, y)` 且 `y` 已染成與 `x` 相同的顏色，表示 `x` 與 `y` 到起點的路徑長度同奇偶，這兩條路徑加上邊 `(x, y)` 構成一個奇數長度的環，而奇環無法二染色，故確實無解。

反之若整個過程沒有衝突，得到的染色本身就是一組合法解。因此演算法既不會漏報也不會誤報，且順帶證明了「二分圖等價於無奇環」。

## 逐步演算法

建無向鄰接表；對每個未染色節點以顏色 1 啟動 DFS；在 DFS 中先染色自己，再檢查每個鄰居：同色即回報失敗，未染色則遞迴染成另一色；全部完成無衝突即為二分圖。

## C++17 模板

```cpp
class Solution {
public:
    // 是二分圖時回傳染色結果（值為 1 或 2）；否則回傳空陣列。
    vector<int> colorBipartite(int n, vector<vector<int>>& edges) {
        vector<vector<int>> g(n);
        for (const auto& e : edges) {
            g[e[0]].push_back(e[1]);
            g[e[1]].push_back(e[0]);
        }

        vector<int> color(n, 0);
        function<bool(int, int)> dfs = [&](int x, int c) -> bool {
            color[x] = c;
            for (int y : g[x]) {
                if (color[y] == c) {
                    return false;
                }  // 同色，出現奇環
                if (color[y] == 0 && !dfs(y, 3 - c)) {
                    return false;
                }
            }
            return true;
        };

        for (int i = 0; i < n; ++i) {  // 圖可能不連通
            if (color[i] == 0 && !dfs(i, 1)) {
                return {};
            }
        }
        return color;
    }
};
```

BFS 版本同樣可行，把顏色隨佇列逐層交替即可，且能避免深遞迴。

## 時間與空間複雜度

每個節點染色一次、每條邊檢查兩次（無向圖各方向一次），時間 $O(n + m)$，空間 $O(n + m)$。

## 常見錯誤與邊界條件

- 只從節點 0 出發而漏掉其他連通塊。
- 用布林值表示顏色卻無法區分「未染色」與「顏色 false」。
- 自環必定使圖非二分（`color[y] == c` 會正確捕捉到）。
- 孤立節點永遠可以染色，不影響結果。
- 重邊無害。

## 與相似技巧的比較

並查集也能判二分圖：把每個節點拆成「自己」與「對立面」兩份，對每條邊合併 `x` 與 `y` 的對立面，若 `x` 與自己的對立面被合併則非二分圖；適合邊逐步加入的動態場景。染色只回答「能不能分兩組」，若要進一步求最大匹配則需匈牙利演算法或網路流。

## 本節重點速查

- 相鄰強制異色
- 衝突即奇環
- `3 - c` 切換顏色
- 記得掃過每個連通塊。
