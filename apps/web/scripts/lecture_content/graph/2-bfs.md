## 這個技術解決什麼問題

在每條邊代價都相同的圖上求「最少幾步」。BFS 依距離由小到大逐層擴展，因此第一次抵達某個節點時走的步數就是最短距離。

## 辨識題型的訊號

題目出現「最少步數」「最短路徑長度」「最少操作次數」，而且每一步的成本都一樣（通常是 1）。若邊有不同權重就要改用 Dijkstra；若權重只有 0 與 1 則用雙端佇列 BFS。

## 核心想法與直覺

把佇列想成一圈一圈往外擴散的水波。佇列中永遠只會同時存在距離為 `d` 與 `d+1` 的節點，於是節點出隊的順序就是距離的非遞減順序。關鍵動作是「入隊時就標記已訪問」，這樣同一個節點不會被排入兩次。

## 狀態／資料結構定義

`dist[x]` 是起點到 `x` 的最短步數，未訪問以 `-1` 表示。`queue` 中存放已確定距離、但尚未展開鄰居的節點。

## 不變量或正確性證明

不變量：佇列中節點的 `dist` 值非遞減，且最大值與最小值相差至多 1。

以歸納法證明第一次到達即最短：假設所有 `dist` 值小於 `d` 的節點都已正確標記。距離為 `d` 的節點 `y` 必有一個距離為 `d-1` 的鄰居 `x`；`x` 會在所有距離 `d` 的節點之前出隊，因此 `y` 在被展開時得到的值恰為 `d`。又因為入隊即標記，`y` 不會再被更大的值覆蓋。

## 逐步演算法

把起點入隊並設 `dist` 為 0；反覆取出隊首，掃描其鄰居；對尚未標記的鄰居設定 `dist` 為目前值加一並入隊；佇列清空即結束。

## C++17 模板

```cpp
vector<int> bfs(int n, const vector<vector<int>>& g, int start) {
    vector<int> dist(n, -1);
    dist[start] = 0;
    queue<int> q;
    q.push(start);

    while (!q.empty()) {
        const int x = q.front();
        q.pop();
        for (int y : g[x]) {
            if (dist[y] == -1) {  // 入隊即標記，避免重複排入
                dist[y] = dist[x] + 1;
                q.push(y);
            }
        }
    }
    return dist;
}
```

需要「一次處理一整層」時（例如記錄層數或每層取最大值）：

```cpp
int steps = 0;
while (!q.empty()) {
    for (int sz = q.size(); sz > 0; --sz) {  // 先取尺寸，凍結本層
        const int x = q.front();
        q.pop();
        // ... 展開 x 的鄰居並入隊
    }
    ++steps;
}
```

## 時間與空間複雜度

每個節點入隊與出隊各一次、每條邊檢查一次，時間 $O(n + m)$；空間 $O(n)$ 存距離與佇列。

## 常見錯誤與邊界條件

- 在出隊時才標記已訪問，導致同一節點被重複入隊、複雜度退化。
- 分層迴圈中直接寫 `i < q.size()` 而沒有先凍結尺寸，使新入隊的節點被算進本層。
- 起點與終點相同時應回傳 0。
- 圖不連通時終點的 `dist` 仍是 `-1`，要當成不可達處理。

## 與相似技巧的比較

DFS 遍歷成本相同但不保證最短；Dijkstra 是 BFS 在帶權圖上的推廣，用優先佇列取代普通佇列；0-1 BFS 用雙端佇列，權 0 的邊放前端、權 1 的邊放後端，同樣維持距離非遞減的不變量。

## 本節重點速查

- 邊權相同才能用
- 入隊即標記
- 第一次到達就是最短
- 要層數就先凍結佇列尺寸。
