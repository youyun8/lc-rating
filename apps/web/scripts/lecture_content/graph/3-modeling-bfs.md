## 這個技術解決什麼問題

題目表面上沒有圖，只有「狀態」與「操作」——字串、棋盤位置、數字、開關組合。把狀態當節點、把一次合法操作當一條邊，最少操作次數就變成無權圖最短路，可以直接用 BFS 解。

## 辨識題型的訊號

問「最少操作幾次能從 A 變成 B」，每次操作的代價相同，而且狀態空間有限可枚舉（字串長度小、棋盤格數少、數字有上界、位元遮罩不超過 $2^{20}$）。

## 核心想法與直覺

建模的重點不是真的把圖建出來，而是想清楚三件事：什麼是狀態、狀態之間怎麼轉移、如何為狀態編號。多數題目不必預先建鄰接表，而是在 BFS 展開時「即時生成」鄰居，這樣可以省下大量記憶體。

## 狀態／資料結構定義

狀態用可雜湊或可編碼的形式表示：字串直接放進 `unordered_set`，網格用 `r * cols + c` 壓成整數，開關組合用位元遮罩。`dist` 改用雜湊表或以編碼為索引的陣列。

## 不變量或正確性證明

只要「每次操作的代價相同」，隱式圖與顯式圖的最短路定義完全一致，BFS 的逐層不變量（佇列中距離非遞減、第一次到達即最短）原封不動成立。正確性的關鍵前提是轉移函式必須完整且對稱於題意——漏掉一種合法操作等於漏掉一條邊，會得到偏大的答案。

## 逐步演算法

定義狀態編碼；把起點狀態入隊；每次取出狀態，套用所有合法操作生成鄰居狀態；過濾掉不合法或已訪問的狀態，設定距離後入隊；抵達目標狀態即回傳距離。

## C++17 模板

以「每次改動一個字元，且中途必須都在字典中」為例：

```cpp
class Solution {
public:
    int ladderLength(string begin, string end, vector<string>& wordList) {
        unordered_set<string> dict(wordList.begin(), wordList.end());
        if (dict.count(end) == 0) {
            return 0;
        }

        unordered_map<string, int> dist{{begin, 1}};
        queue<string> q;
        q.push(begin);

        while (!q.empty()) {
            const string x = q.front();
            q.pop();
            if (x == end) {
                return dist[x];
            }

            for (size_t i = 0; i < x.size(); ++i) {  // 即時生成鄰居
                string next = x;
                for (char c = 'a'; c <= 'z'; ++c) {
                    next[i] = c;
                    if (dict.count(next) && dist.count(next) == 0) {
                        dist[next] = dist[x] + 1;
                        q.push(next);
                    }
                }
            }
        }
        return 0;
    }
};
```

## 時間與空間複雜度

設狀態數為 $S$、每個狀態的轉移數為 $B$，時間 $O(S \cdot B \cdot C)$，其中 $C$ 是一次狀態編碼或比較的成本（字串為長度 $L$）。空間 $O(S \cdot C)$ 用於距離表與佇列。

## 常見錯誤與邊界條件

- 狀態編碼不唯一，使兩個不同狀態被視為同一個。
- 忘記把起點就等於終點的情況特判。
- 生成鄰居時沒有檢查邊界或合法性。
- 狀態數估算錯誤導致記憶體爆掉。
- 把「訪問過的字典字」留在集合中重複展開，應在入隊時就移除或標記。

## 與相似技巧的比較

若不同操作有不同代價，改用 Dijkstra；若代價只有 0 與 1，用 0-1 BFS；若同時從起點與終點擴展可用雙向 BFS，把狀態數從 $B^d$ 降到約 $2 B^{d/2}$；若狀態空間過大而有明確目標距離估計，則走 A\*。

## 本節重點速查

- 先定義狀態，再定義轉移
- 鄰居即時生成不必建圖
- 代價相同才是 BFS，代價不同就是 Dijkstra。
