## 這個技術解決什麼問題

有一批任務彼此存在先後依賴，要排出一個不違反任何依賴的執行順序，或判斷依賴是否互相矛盾（有環）。拓撲排序在有向無環圖上給出這樣的線性序。

## 辨識題型的訊號

出現「先修課程」「編譯順序」「必須在……之前完成」等字眼；輸入是有向邊 `a -> b` 表示 `a` 先於 `b`；問是否可能完成、或要求輸出一個合法順序。

## 核心想法與直覺

想像一條生產線：入度為 0 的節點表示沒有任何前置任務擋著，可以立刻執行。做完一個任務就把它的所有後繼各減去一份依賴，誰的依賴歸零就輪到誰。這就是 Kahn 演算法。

## 狀態／資料結構定義

`indeg[x]` 是節點 `x` 尚未被滿足的前置條件數量；佇列存放目前入度為 0、可立即輸出的節點；`order` 依序收集結果。

## 不變量或正確性證明

不變量：任一時刻，佇列中的節點其所有前驅都已進入 `order`。

因此把佇列中任一節點接到 `order` 尾端都不會違反依賴，輸出序列始終是合法的偏序延伸。

判環的正確性：若最終 `order.size() < n`，表示剩餘節點的入度都不為 0。從任一剩餘節點沿著「尚未滿足的前驅」不斷回溯，因為節點有限，必定重複遇到某個節點，即構成環；反之若圖無環，則任何非空子圖都存在入度為 0 的節點（取拓撲最小者），演算法不會提前停止。

## 逐步演算法

建鄰接表並統計入度；把所有入度為 0 的節點入隊；每次出隊一個節點加入答案，並把其所有後繼的入度減一，減到 0 就入隊；最後比較答案長度與節點數判斷是否有環。

## C++17 模板

```cpp
class Solution {
public:
    // 回傳一個合法拓撲序；若有環則回傳空陣列。
    vector<int> topoSort(int n, vector<vector<int>>& edges) {
        vector<vector<int>> g(n);
        vector<int> indeg(n, 0);
        for (const auto& e : edges) {  // e = {a, b} 表示 a 必須先於 b
            g[e[0]].push_back(e[1]);
            ++indeg[e[1]];
        }

        queue<int> q;
        for (int i = 0; i < n; ++i) {
            if (indeg[i] == 0) {
                q.push(i);
            }
        }

        vector<int> order;
        while (!q.empty()) {
            const int x = q.front();
            q.pop();
            order.push_back(x);
            for (int y : g[x]) {
                if (--indeg[y] == 0) {
                    q.push(y);
                }
            }
        }

        if (static_cast<int>(order.size()) < n) {
            return {};
        }  // 有環
        return order;
    }
};
```

若題目要求字典序最小的拓撲序，把 `queue` 換成 `priority_queue<int, vector<int>, greater<int>>` 即可。

## 時間與空間複雜度

每個節點入隊出隊各一次、每條邊被鬆弛一次，時間 $O(n + m)$；空間 $O(n + m)$。改用優先佇列求字典序最小時為 $O(n \log n + m)$。

## 常見錯誤與邊界條件

- 邊的方向搞反（「修完 a 才能修 b」對應 `a -> b`，入度加在 `b`）。
- 用 `--indeg[y] <= 0` 之類的條件造成重複入隊。
- 忘記檢查 `order.size()` 而漏判環。
- 重邊會讓入度重複計算，若題目允許重邊需先去重或確認題意。
- 孤立節點入度本來就是 0，必須一併入隊。

## 與相似技巧的比較

DFS 後序反轉也能得到拓撲序，且更適合順帶求強連通分量；Kahn 的優勢是天然判環、易於求字典序最小、並且能自然地按層次分批處理（每輪出隊的整層就是同一「深度」的任務）。

## 本節重點速查

- 入度為 0 才可出隊
- 出隊即定序
- `order.size() < n` 就是有環
- 字典序最小改用優先佇列。
