## 這個技術解決什麼問題

在有向無環圖上求最長路、路徑計數、可達集合等需要「先算完前驅才能算自己」的量。拓撲序提供了一個安全的計算順序，讓每個狀態被計算時，它依賴的所有狀態都已經是最終值。

## 辨識題型的訊號

DAG 上求最長／最短路徑、統計從起點到終點的路徑數、求每個節點的最大累積收益、課程安排中求最少學期數。一般的環狀圖沒有這種性質，必須先縮點成 DAG 才能套用。

## 核心想法與直覺

DP 需要無後效性——狀態之間的依賴不能成環。DAG 天生滿足這一點，而拓撲序正是把這個偏序攤平成線性序。於是「按拓撲序遞推」與「記憶化搜尋沿邊遞迴」是同一件事的兩種寫法：前者由前驅推後繼（推式），後者由後繼回頭問前驅（拉式）。

## 狀態／資料結構定義

`f[x]` 是以 `x` 結尾（或以 `x` 為起點）的目標量，例如最長路長度或路徑條數。方向要先定死：若 `f[x]` 定義為「到 `x` 為止」，則沿邊 `x -> y` 更新 `f[y]`。

## 不變量或正確性證明

不變量：當節點 `x` 從佇列出隊時，`f[x]` 已經是最終值。

理由是 `x` 出隊代表 `indeg[x]` 歸零，也就是它的每一個前驅都已出隊並完成過對 `x` 的鬆弛；由歸納假設那些前驅的 `f` 值皆為最終值，故 `f[x]` 已聚合完所有來源。因為圖無環，這個歸納不會循環定義，所以每個 `f[x]` 恰好在被讀取前定型一次。

## 逐步演算法

建圖並統計入度；設定所有起點的初始值；跑 Kahn，出隊節點 `x` 時其 `f[x]` 已定型，用它去鬆弛每個後繼 `y`；後繼入度歸零時入隊；掃描所有 `f` 取答案。

## C++17 模板

DAG 最長路（邊權為 1，等價於最長鏈長度）：

```cpp
class Solution {
public:
    int longestPath(int n, vector<vector<int>>& edges) {
        vector<vector<int>> g(n);
        vector<int> indeg(n, 0);
        for (const auto& e : edges) {
            g[e[0]].push_back(e[1]);
            ++indeg[e[1]];
        }

        vector<int> f(n, 0);  // f[x]：以 x 結尾的最長路徑邊數
        queue<int> q;
        for (int i = 0; i < n; ++i) {
            if (indeg[i] == 0) {
                q.push(i);
            }
        }

        int answer = 0;
        while (!q.empty()) {
            const int x = q.front();
            q.pop();
            answer = max(answer, f[x]);  // 此時 f[x] 已定型
            for (int y : g[x]) {
                f[y] = max(f[y], f[x] + 1);  // 推式鬆弛
                if (--indeg[y] == 0) {
                    q.push(y);
                }
            }
        }
        return answer;
    }
};
```

路徑計數只需把 `max` 換成加法：`f[y] += f[x]`，並把起點的 `f` 設為 1。

## 時間與空間複雜度

每條邊恰好觸發一次鬆弛，時間 $O(n + m)$；空間 $O(n + m)$。記憶化搜尋版本相同，但遞迴深度最差為 $O(n)$。

## 常見錯誤與邊界條件

- 在節點入隊時（而非出隊時）讀取 `f[x]`，此時尚未聚合完前驅。
- 把初始值設錯（計數題起點應為 1，最長路應為 0）。
- 圖有環時 DP 無意義，必須先判環。
- 路徑計數容易溢位，需用 `long long` 或取模。
- 多個起點時別忘了每個入度為 0 的節點都要初始化。

## 與相似技巧的比較

記憶化搜尋不需要顯式求拓撲序，程式更短，但有遞迴深度風險；Kahn 推式版本便於同時判環與分層。若圖有環則需先用 Tarjan 縮點成 DAG 再做同樣的 DP。若邊有實數權且要最短路，DAG 上仍可用本法，且比 Dijkstra 更快、還能處理負權。

## 本節重點速查

- 出隊才定型
- 推式沿邊鬆弛後繼
- 計數起點設 1、最長路設 0
- 有環先縮點。
