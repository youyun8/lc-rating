## 這個技術解決什麼問題

處理「每個節點恰有一條出邊」的圖（內向基環樹森林），例如 `nums[i]` 指向下一個位置、每個人只能指定一位對象。這種圖的形狀非常固定：每個連通塊都是一個環，環上每個點掛著一棵樹。

## 辨識題型的訊號

輸入是長度為 `n` 的陣列 `g`，其中 `g[i]` 是唯一後繼；題目問最長循環長度、能走多遠、誰在環上、或是 `n` 個點 `n` 條邊的無向圖（此時是基環樹森林）。

## 核心想法與直覺

因為出度恆為 1，從任何點一直走下去必然進入一個環（節點有限，先重複的那個點就是入環點）。於是整張圖被拆成兩部分：環上的點與掛在環外的樹枝。多數題目的解法就是先剝掉樹枝、找出環，再分別處理。

剝樹枝的手法就是拓撲排序：入度為 0 的點一定不在環上，把它們層層刪去，剩下入度不為 0 的點恰好構成所有環。

## 狀態／資料結構定義

`g[x]` 是 `x` 的唯一後繼；`indeg[x]` 是入度；`on_cycle[x]` 標記是否留在環上；對每個環另外記錄長度與環上節點順序。

## 不變量或正確性證明

不變量：拓撲剝除過程中，任何被刪除的節點都不可能在環上。

證明：環上每個節點都至少有一個環內前驅，因此其入度在環內貢獻至少為 1，永遠不會降到 0，故不會被刪。反之，若某節點不在任何環上，沿其反向可達的樹枝有限且無環，最終會被逐層剝光。所以剝除後剩下的節點集合恰為所有環的並集。

## 逐步演算法

統計入度；把入度為 0 的節點入隊，出隊時把其後繼入度減一，歸零則入隊（此即剝樹枝）；剩下未被刪除的節點都在環上；從任一環上節點沿 `g` 走一圈即可取得該環的長度與成員；樹枝上的資訊可在剝除時或之後由環反向 DFS 求得。

## C++17 模板

```cpp
class Solution {
public:
    // 回傳最長環的長度（內向基環樹森林）。
    int longestCycle(vector<int>& g) {
        const int n = g.size();
        vector<int> indeg(n, 0);
        for (int x = 0; x < n; ++x) {
            if (g[x] >= 0) {
                ++indeg[g[x]];
            }
        }

        // 一、拓撲剝除所有樹枝
        queue<int> q;
        for (int i = 0; i < n; ++i) {
            if (indeg[i] == 0) {
                q.push(i);
            }
        }
        vector<int> removed(n, 0);
        while (!q.empty()) {
            const int x = q.front();
            q.pop();
            removed[x] = 1;
            const int y = g[x];
            if (y >= 0 && --indeg[y] == 0) {
                q.push(y);
            }
        }

        // 二、剩下的都在環上，逐環量長度
        int answer = -1;
        for (int i = 0; i < n; ++i) {
            if (removed[i]) {
                continue;
            }
            int length = 0;
            for (int x = i; !removed[x]; x = g[x]) {
                removed[x] = 1;  // 邊走邊標記，每個環只量一次
                ++length;
            }
            answer = max(answer, length);
        }
        return answer;
    }
};
```

若只需要「找出某條路徑何時進入環」而不必處理整張圖，也可以用快慢指標（Floyd 判圈）在 $O(1)$ 額外空間內完成。

## 時間與空間複雜度

拓撲剝除與環掃描各自訪問每個節點常數次，時間 $O(n)$、空間 $O(n)$。

## 常見錯誤與邊界條件

- 自環 `g[x] == x` 是長度為 1 的合法環，別漏掉。
- `g[x]` 可能是 `-1` 表示沒有出邊，需特判。
- 量環長時忘了標記造成同一個環被重複計算。
- 把「入度為 0」誤解成「一定是樹根」而忽略整個連通塊可能純粹是一個環（此時沒有任何節點入度為 0，佇列一開始就是空的，這是正確行為）。

## 與相似技巧的比較

一般有向圖找環要用三色 DFS 或 Tarjan；基環樹因為出度為 1，用拓撲剝除即可，更簡單也更快。無向的基環樹（`n` 點 `n` 邊）同樣可用拓撲剝除，只是要把入度為 1 的葉子當作剝除起點。

## 本節重點速查

- 出度恆為 1 必進環
- 入度為 0 者不在環上
- 先拓撲剝樹枝，剩下的就是環
- 自環也算環。
