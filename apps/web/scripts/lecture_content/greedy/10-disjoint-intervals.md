## 這個技術解決什麼問題

從一堆區間中挑出最多個彼此不重疊者，或反過來求「最少刪掉幾個才能讓剩下的不重疊」。這是區間排程的基本題型。

## 狀態／資料結構定義

按**右端點**由小到大排序，維護 `lastEnd` 表示已選最後一個區間的右端點。掃描時只要當前區間的左端點不小於 `lastEnd` 就選入。

## 不變量或正確性證明

不變量：掃描到第 `i` 個區間時，已選集合是「只考慮前 `i` 個區間」中規模最大的不重疊集合之一，且在所有同規模的最優解中，它的最後一個右端點最小。

按右端點排序的正確性（交換論證）：設某最優解的第一個區間為 `X`，而貪心選的是右端點最小的 `G`。因為 `G` 的右端點不大於 `X` 的右端點，把 `X` 換成 `G` 後，後續所有與 `X` 不重疊的區間也必定與 `G` 不重疊——它們的左端點都不小於 `X` 的右端點，也就不小於 `G` 的右端點。故替換後仍是合法解且規模不變。逐一替換即可把最優解轉成貪心解。

這說明「右端點越早結束，留給後面的空間越大」，正是不變量後半段所述的最小性。

反之若按左端點排序則不成立：一個很早開始但很晚結束的長區間會擋掉許多短區間。

「最少刪除數」等於總數減去最多不重疊數，兩者是同一問題的互補說法。

## 逐步演算法

按右端點升序排序；`lastEnd` 初始為負無窮；掃描每個區間，若左端點不小於 `lastEnd` 就選入並更新 `lastEnd`；回傳選中個數（或總數減之）。

## C++17 模板

```cpp
// 最少需刪除多少區間，才能使剩下的互不重疊。
int eraseOverlapIntervals(vector<vector<int>>& intervals) {
    if (intervals.empty()) {
        return 0;
    }
    sort(intervals.begin(), intervals.end(),
         [](const auto& a, const auto& b) { return a[1] < b[1]; });  // 按右端點

    int kept = 0, lastEnd = INT_MIN;
    for (const auto& it : intervals) {
        if (it[0] >= lastEnd) {  // 不重疊就選
            ++kept;
            lastEnd = it[1];
        }
    }
    return intervals.size() - kept;
}
```

## 時間與空間複雜度

排序 $O(n \log n)$ 主導，掃描 $O(n)$，空間 $O(1)$。

## 常見錯誤與邊界條件

- 按左端點排序（本題必須按右端點）。
- 端點相接算不算重疊未確認（`>=` 與 `>` 的差別，題目常說「[1,2] 與 [2,3] 不重疊」）。
- `lastEnd` 初始值不夠小。
- 空陣列未處理。
- 把本題與「區間分組」混淆——後者是要全部保留而分組。

## 與相似技巧的比較

不相交區間按右端點排序取最多；區間分組按左端點排序用堆求最少組數；區間選點與本題對偶，答案相同但意義不同。三者都以區間為輸入卻用不同排序，判準是「要丟掉區間還是全部保留」。

## 本節重點速查

- 按右端點排序
- 不重疊就選
- 早結束留下的空間最大
- 最少刪除等於總數減最多保留。
