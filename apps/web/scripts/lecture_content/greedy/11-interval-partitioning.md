## 這個技術解決什麼問題

把所有區間分成最少的組，使同一組內的區間互不重疊。等價說法是「最少需要幾間會議室」「最多同時有幾個區間重疊」。

## 狀態／資料結構定義

按左端點排序後，用小根堆存放各組當前的結束時間，堆頂是最早結束的那一組。或改用差分／掃描線：把每個區間拆成 `+1` 與 `-1` 兩個事件，掃過去求最大同時值。

## 不變量或正確性證明

不變量：處理完前 `i` 個區間後，堆的大小等於「這 `i` 個區間所需的最少組數」，堆中每個值是對應組別當前的結束時間。

貪心規則是：新區間若能放進「最早結束的那一組」就放，否則開新組。

正確性的下界論證：設某時刻有 `k` 個區間同時重疊，則這 `k` 個區間兩兩重疊，必須分屬 `k` 個不同的組，故答案至少為 `k`；也就是說**最少組數不小於最大重疊數**。

上界則由演算法達成：開新組只發生在「新區間與最早結束的組也重疊」時。既然它與最早結束者重疊，依左端點排序可知它與目前所有組的最後一個區間都重疊（其他組結束得更晚），加上它自己，此刻恰有「當前組數 + 1」個區間同時重疊。因此每次開新組時，組數都等於某個時刻的重疊數，不超過最大重疊數。上下界相符，故貪心最優。

## 逐步演算法

按左端點升序排序；小根堆初始為空；對每個區間，若堆非空且堆頂結束時間不晚於當前左端點，就彈出該組（重用）；把當前右端點入堆；最終堆的大小即為答案。

## C++17 模板

```cpp
// 最少會議室數量。
int minMeetingRooms(vector<vector<int>>& intervals) {
    sort(intervals.begin(), intervals.end(),
         [](const auto& a, const auto& b) { return a[0] < b[0]; });  // 按左端點

    priority_queue<int, vector<int>, greater<int>> ends;  // 小根堆：最早結束
    for (const auto& it : intervals) {
        if (!ends.empty() && ends.top() <= it[0]) {
            ends.pop();
        }  // 重用該組
        ends.push(it[1]);
    }
    return ends.size();
}
```

差分寫法：把所有端點排序後掃描，遇左端點加一、右端點減一，過程中的最大值即答案，同樣 $O(n \log n)$ 但常數更小。

## 時間與空間複雜度

排序 $O(n \log n)$，每個區間各一次堆操作 $O(\log n)$，總計 $O(n \log n)$ 時間、$O(n)$ 空間。

## 常見錯誤與邊界條件

- 按右端點排序（本題必須按左端點）。
- 用大根堆。
- 端點相接是否算重疊未確認（`<=` 與 `<`）。
- 差分寫法中同一時刻的「結束」與「開始」處理順序錯誤，導致相接被誤判為重疊。
- 空輸入回傳 0。

## 與相似技巧的比較

不相交區間是「丟掉一些，保留最多」，本題是「全部保留，分成最少組」，因此排序鍵相反；若只需要最大重疊數而不需知道分組方式，差分掃描線最省事。

## 本節重點速查

- 按左端點排序
- 小根堆放各組結束時間
- 能重用就重用
- 答案等於最大重疊數。
