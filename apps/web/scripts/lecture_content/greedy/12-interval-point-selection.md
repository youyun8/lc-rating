## 這個技術解決什麼問題

在數線上放下最少的點，使每個給定區間內至少有一個點。代表題是「用最少數量的箭引爆氣球」。

## 狀態／資料結構定義

按右端點排序，維護 `lastPoint` 表示上一次放點的位置。掃描時若當前區間的左端點大於 `lastPoint`，表示它尚未被覆蓋，就在它的右端點放一個新點。

## 不變量或正確性證明

不變量：掃描到第 `i` 個區間時，已放的點數是「覆蓋前 `i` 個區間」所需的最小值，且最後一個點的位置在所有同樣點數的方案中最靠右。

把點放在區間右端點的正確性：考慮尚未被覆蓋的區間中右端點最小的那個 `R`。它必須被某個點覆蓋，而任何能覆蓋它的點都不會超過 `R` 的右端點。把該點移到 `R` 的右端點：移動後仍覆蓋 `R`（因為右端點在區間內），且對其他區間而言只可能覆蓋更多——任何原本被該點覆蓋的區間 `I`，其右端點不小於 `R` 的右端點（依排序），而左端點不大於原點位置，故新位置仍落在 `I` 內。

因此存在一個最優解把點放在右端點上，貪心與之一致。這也解釋了不變量後半段的「最靠右」：越靠右的點能覆蓋越多後續區間。

本題與「不相交區間」對偶：最少點數恰等於最多兩兩不相交的區間數——每個互不相交的區間都需要各自的點（下界），而貪心達成該數（上界）。

## 逐步演算法

按右端點升序排序；`lastPoint` 初始為負無窮；掃描每個區間，若其左端點大於 `lastPoint` 就放新點於其右端點並計數；回傳點數。

## C++17 模板

```cpp
// 最少射出幾支箭能引爆所有氣球（區間閉合）。
int findMinArrowShots(vector<vector<int>>& points) {
    if (points.empty()) {
        return 0;
    }
    sort(points.begin(), points.end(),
         [](const auto& a, const auto& b) { return a[1] < b[1]; });  // 按右端點

    int arrows = 0;
    long long lastPoint = LLONG_MIN;
    for (const auto& p : points) {
        if (p[0] > lastPoint) {  // 尚未被覆蓋，放新點
            ++arrows;
            lastPoint = p[1];
        }
    }
    return arrows;
}
```

## 常見錯誤與邊界條件

- 按左端點排序。
- 把點放在左端點（會漏覆蓋後續區間）。
- 區間為閉合時判斷寫成 `>=` 而多放點。
- `lastPoint` 用 `int` 而輸入含 `INT_MIN`/`INT_MAX` 造成溢位（本題常見陷阱，需 `long long`）。
- 空輸入回傳 0。

## 與相似技巧的比較

與不相交區間同樣按右端點排序，兩題答案相同但語意互補；區間覆蓋則是「用區間蓋滿目標範圍」，排序鍵與貪心方向都不同。判準是「要放點、選區間、還是蓋範圍」。

## 本節重點速查

- 按右端點排序
- 點放在右端點上
- 未被覆蓋才放新點
- 注意端點極值溢位。

## 時間與空間複雜度

排序 $O(n \log n)$ 主導，掃描 $O(n)$，空間 $O(1)$。
