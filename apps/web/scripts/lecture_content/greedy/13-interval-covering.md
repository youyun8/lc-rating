## 這個技術解決什麼問題

用最少的區間把一段目標範圍完整蓋滿。代表題是「影片拼接」「跳躍遊戲 II」的區間版本。

## 狀態／資料結構定義

按左端點排序後，維護 `covered`（已完整覆蓋到的位置）與 `farthest`（在不超過 `covered` 起點的所有可用區間中，能延伸到的最遠右端點）。

[45 跳躍遊戲 II](https://leetcode.cn/problems/jump-game-ii) 可直接畫成 BFS 分層式覆蓋。以下文字圖以 `nums = [2,3,1,1,4]` 為例；每個位置 `i` 提供區間 `[i, i + nums[i]]`：

```text
第 0 層：可達下標 [0, 0]，掃描 0 後，下一層最遠到 2
第 1 層：可達下標 [1, 2]，掃描 1、2 後，下一層最遠到 4
第 2 層：可達下標 [3, 4]，已覆蓋終點
```

`covered` 是本層右界，`farthest` 是掃完整層後得到的下一層右界；只有走到 `covered` 才把跳數加一。這個可由螢幕閱讀器直接讀出的層次描述，也避免把「每看一個位置就跳一次」的錯誤直覺帶進程式。

## 不變量或正確性證明

不變量：每輪結束時，`covered` 是「用當前已選區間數」所能覆蓋到的最遠位置。

貪心規則：在所有左端點不超過 `covered` 的區間中，選右端點最遠的那一個。

正確性用歸納：假設已選 `k` 個區間且覆蓋到 `covered`，且這是 `k` 個區間能達到的最遠覆蓋。要再選第 `k+1` 個，它必須與已覆蓋部分相接（左端點不超過 `covered`），否則中間會留下空隙。在所有這類候選中選右端點最大者，得到的新覆蓋位置就是 `k+1` 個區間所能達到的最遠位置——因為任何其他選擇的右端點都不更遠，而覆蓋範圍是單調的。

由此可知，對每個區間數 `k`，貪心都達到了該數目下的最遠覆蓋。因此第一次使覆蓋達到目標終點的 `k`，就是最少所需的區間數；任何更少的區間數都覆蓋不到終點。

這個「每一層取最遠」的結構與 BFS 分層完全同構，也是它與跳躍遊戲 II 等價的原因。

## 逐步演算法

按左端點排序；`covered` 初始為起點；每輪掃過所有左端點不超過 `covered` 的區間求出 `farthest`；若 `farthest` 沒有前進則無解；否則把 `covered` 更新為 `farthest`、計數加一；直到覆蓋終點。

## C++17 模板

```cpp
// 用最少的區間覆蓋 [0, target]；無法覆蓋回傳 -1。
int videoStitching(vector<vector<int>>& clips, int target) {
    sort(clips.begin(), clips.end(),
         [](const auto& a, const auto& b) { return a[0] < b[0]; });

    int count = 0, covered = 0, i = 0;
    const int n = clips.size();

    while (covered < target) {
        int farthest = covered;
        while (i < n && clips[i][0] <= covered) {  // 所有能接上的候選
            farthest = max(farthest, clips[i][1]);
            ++i;
        }
        if (farthest == covered) {
            return -1;
        }  // 卡住了，無解
        covered = farthest;
        ++count;
    }
    return count;
}
```

## 時間與空間複雜度

排序 $O(n \log n)$ 主導；指標 `i` 只前進不回頭，掃描總計 $O(n)$。空間 $O(1)$。

## 常見錯誤與邊界條件

- 內層每輪都從頭掃（會退化成 $O(n^2)$，應讓 `i` 只前進）。
- 漏掉「無法前進即無解」的判斷而死迴圈。
- 目標為 0 時應回傳 0。
- 區間左端點嚴格大於 `covered` 就不能用（相接的定義要看題目是連續還是離散）。
- 覆蓋條件寫成 `<` 而漏掉剛好接上的情形。

## 常見變形

[45 跳躍遊戲 II](https://leetcode.cn/problems/jump-game-ii) 是同一個「逐層擴大覆蓋」模型：掃描目前一跳可達的整層 `[0, end]`，用 `farthest = max(farthest, i + nums[i])` 收集下一層最遠邊界；掃到 `i == end` 才增加一次跳躍並令 `end = farthest`。

以 `nums = [2,3,1,1,4]` 為例，覆蓋層可以用純文字表示：

```text
下標：       0 | 1  2 | 3  4
所在 BFS 層：0 |   1  |   2
覆蓋右界：   0 -> 2  -> 4
```

第一層只掃下標 0，得到下一層右界 2；第二層掃下標 1、2，得到右界 4。每一條分隔線才代表真正多跳一次，所以答案是 2，而不是每更新一次 `farthest` 就加一。

## 與相似技巧的比較

不相交區間與區間選點按右端點排序，本題按左端點——因為這裡要的是「連續延伸」而非「互不干擾」。本題與跳躍遊戲 II 的分層貪心同構；若每個區間有不同成本而要最小化總成本，貪心失效，需改用 DP 或最短路。

## 本節重點速查

- 按左端點排序
- 每層取能接上的最遠右端點
- 指標只前進
- 無法前進即無解。
