## 這個技術解決什麼問題

把一堆可能重疊的區間合併成互不重疊的大區間。它本身是常考題，也是許多區間題的前置處理步驟。

## 狀態／資料結構定義

按左端點排序後，用一個結果陣列，維護其最後一個區間作為「當前正在擴張的合併區間」。

## 不變量或正確性證明

不變量：處理完前 `i` 個區間後，結果陣列中的區間兩兩不重疊、依左端點遞增排列，且它們的並集恰等於前 `i` 個原始區間的並集。

排序後只需與**最後一個**結果區間比較的理由：因為輸入已按左端點升序，當前區間的左端點不小於所有先前區間的左端點。結果陣列中除最後一個以外的區間，其右端點都小於最後一個區間的左端點（否則它們早已被合併），因此當前區間不可能與它們重疊——它的左端點更大。所以只需檢查最後一個。

合併條件是「當前左端點不超過最後一個的右端點」，此時把右端點更新為兩者較大值（注意不能直接取當前區間的右端點，因為當前區間可能被完全包含在內）。並集不變，故不變量維持。

## 逐步演算法

按左端點升序排序；把第一個區間放入結果；對每個後續區間，若與結果最後一個重疊就擴張其右端點，否則追加為新區間。

## C++17 模板

```cpp
vector<vector<int>> merge(vector<vector<int>>& intervals) {
    if (intervals.empty()) {
        return {};
    }
    sort(intervals.begin(), intervals.end(),
         [](const auto& a, const auto& b) { return a[0] < b[0]; });

    vector<vector<int>> result{intervals[0]};
    for (size_t i = 1; i < intervals.size(); ++i) {
        auto& last = result.back();
        if (intervals[i][0] <= last[1]) {
            last[1] =
                max(last[1], intervals[i][1]);  // 可能被完全包含，故取 max
        } else {
            result.push_back(intervals[i]);
        }
    }
    return result;
}
```

## 時間與空間複雜度

排序 $O(n \log n)$ 主導，掃描 $O(n)$，空間為輸出的 $O(n)$。

## 常見錯誤與邊界條件

- 擴張時直接賦值成當前右端點，遇到被包含的區間就把範圍縮小了。
- 相接（`[1,2]` 與 `[2,3]`）是否要合併未確認（`<=` 與 `<` 的差別）。
- 未排序就直接掃描。
- 空輸入未處理。
- 把左右端點寫反。

## 與相似技巧的比較

合併區間求的是並集；若要求交集則改用雙序列雙指標（見滑動視窗題單）；若要動態插入區間並維持有序不重疊，用 `map` 存放區間並二分定位，成本 $O(\log n)$ 每次。差分陣列適合「區間加值」而非「區間合併」。

## 本節重點速查

- 按左端點排序
- 只需比對結果的最後一個
- 擴張要取 `max` 別直接賦值
- 相接是否合併看題意。
