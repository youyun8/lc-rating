## 這個技術解決什麼問題

區間類貪心的綜合與辨析。這類題的成敗幾乎完全取決於「按哪一端排序」，選錯就全盤皆錯，因此本節的重點是建立一張可靠的對照。

## 狀態／資料結構定義

依題型選擇：需要「挑出最多不重疊」或「放最少點」時按右端點排序；需要「全部保留分組」或「連續覆蓋」時按左端點排序；需要同時追蹤多個進行中的區間時再加一個堆。

## 不變量或正確性證明

四種主流題型的貪心規則與各自的正確性依據：

- **不相交區間**（挑最多）：按右端點排序，能選就選。交換論證——右端點越早結束，留給後續的空間越大，替換不會使解變差。
- **區間選點**（放最少點）：按右端點排序，點放右端點。移動論證——任何覆蓋該區間的點都可右移到其右端點，覆蓋範圍只增不減。
- **區間分組**（分最少組）：按左端點排序，堆維護各組結束時間。下界是最大重疊數，上界由「開新組時恰有那麼多區間重疊」達成，兩者相符。
- **區間覆蓋**（蓋滿範圍）：按左端點排序，每層取能接上的最遠右端點。歸納證明每個區間數下的覆蓋位置都是最遠。

判斷順序建議固定為：先問「區間是要被丟棄、被保留分組、還是用來覆蓋別的東西」，答案就決定了排序鍵。前兩者互相對偶（答案相同），後兩者則是完全不同的問題。

## 逐步演算法

辨識題型；依上表選定排序鍵；排序後線性掃描並維護對應的狀態量；必要時加堆。

## C++17 模板

```cpp
// 依題型選擇排序鍵——這是區間貪心唯一需要記牢的決策。
auto byEnd = [](const auto& a, const auto& b) { return a[1] < b[1]; };
auto byStart = [](const auto& a, const auto& b) { return a[0] < b[0]; };
```

| 題型               | 排序鍵 | 貪心規則           | 複雜度        |
| ------------------ | ------ | ------------------ | ------------- |
| 挑最多不重疊       | 右端點 | 不重疊就選         | $O(n \log n)$ |
| 最少刪除數         | 右端點 | 總數減最多保留     | $O(n \log n)$ |
| 最少點覆蓋所有區間 | 右端點 | 點放右端點         | $O(n \log n)$ |
| 最少組數           | 左端點 | 堆重用最早結束的組 | $O(n \log n)$ |
| 最少區間蓋滿範圍   | 左端點 | 每層取最遠         | $O(n \log n)$ |
| 合併重疊區間       | 左端點 | 與結果最後一個比對 | $O(n \log n)$ |

## 時間與空間複雜度

全部由排序主導，皆為 $O(n \log n)$ 時間；空間 $O(1)$ 到 $O(n)$，視是否需要堆或輸出陣列。

## 常見錯誤與邊界條件

- 排序鍵選錯（最常見）。
- 端點相接是否算重疊未確認。
- 端點為 `INT_MIN`/`INT_MAX` 時的溢位。
- 未排序就掃描。
- 空輸入未處理。

## 與相似技巧的比較

若每個區間帶權且要最大化總權重，貪心失效，必須用「按右端點排序 + 二分找前一個不重疊者」的 DP，複雜度 $O(n \log n)$；若要支援動態插入與查詢，改用有序容器或線段樹。

## 本節重點速查

- 先判題型再選排序鍵
- 丟棄與放點按右端點，分組與覆蓋按左端點
- 帶權就得改用 DP。
