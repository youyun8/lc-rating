## 這個技術解決什麼問題

構造或改造迴文串：用給定字元組成最長迴文、判斷能否重排成迴文、求最少改動次數。核心是把「左右對稱」的要求翻譯成字元次數的奇偶條件。

## 狀態／資料結構定義

一張字元次數表。構造答案時分成三部分：左半段、可選的中心字元、右半段（左半段的鏡像）。

## 不變量或正確性證明

判據：一組字元能重排成迴文，當且僅當出現次數為奇數的字元種類數不超過 1。

必要性：迴文中位置 `i` 與 `n-1-i` 的字元相同，故除了長度為奇數時的正中央那一格，其餘字元都成對出現。因此至多一種字元可以有奇數次。

充分性用構造：把每種字元的次數取一半放進左半段，鏡射成右半段，剩下的那個奇數字元（若有）放在正中央。這樣得到的串顯然是迴文，且用完了所有字元。

由此得「最長迴文子序列長度」的公式：把每種字元次數的偶數部分全部計入（$\sum 2\lfloor c_i/2 \rfloor$），若存在任何奇數次字元再加一。

字典序最小的迴文構造：在滿足上述條件的前提下，左半段應由小到大排列，中心取剩下的奇數字元中最小者——因為左半段決定了整體的字典序，而右半段完全由左半段決定，沒有自由度。

## 逐步演算法

統計字元次數；檢查奇數次的種類數是否超過 1；把每種字元的一半依序放入左半段；記錄中心字元；輸出左半段、中心、左半段的反轉。

## C++17 模板

```cpp
// 用給定字元能組成的最長迴文長度。
int longestPalindrome(string s) {
    array<int, 128> count{};
    for (char c : s) {
        ++count[static_cast<unsigned char>(c)];
    }

    int length = 0;
    bool hasOdd = false;
    for (int c : count) {
        length += c / 2 * 2;  // 只取偶數部分
        if (c % 2 == 1) {
            hasOdd = true;
        }
    }
    return length + (hasOdd ? 1 : 0);  // 任一奇數字元可放正中央
}
```

## 常見錯誤與邊界條件

- 允許多於一個奇數次字元。
- `length += c / 2 * 2` 寫成 `c / 2`（漏掉鏡像的另一半）。
- 中心字元加了不只一次。
- 大小寫視為同一字元與否未確認。
- 空字串應回傳 0。

## 與相似技巧的比較

本節處理「可任意重排」的情形，靠次數統計即可；若字元順序固定而要求最少插入或刪除次數使之成為迴文，那是區間 DP（等價於求最長迴文子序列）；若要在字串中找已存在的迴文子串，用中心擴散或 Manacher。

## 本節重點速查

- 奇數次字元至多一種
- 長度取每種次數的偶數部分再加一
- 左半段決定字典序
- 可重排才能用次數判據。

## 時間與空間複雜度

統計字元次數與構造各掃一遍，時間 $O(n)$，空間 $O(\Sigma)$。
