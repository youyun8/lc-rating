## 這個技術解決什麼問題

目標是乘積最大或最小時，貪心規則與加法完全不同，關鍵全在負號與零。代表題是「三個數的最大乘積」「乘積最大子陣列」。

## 狀態／資料結構定義

排序後只需檢查兩端的少數幾個元素；或在掃描時同時維護「到目前為止的最大乘積」與「最小乘積」兩個量。

## 不變量或正確性證明

三個數最大乘積的判據：答案必為「最大的三個數之積」與「最小的兩個數乘以最大的數」兩者中的較大者。

證明：排序後設為 $a_0 \le a_1 \le \cdots \le a_{n-1}$。最大乘積中負因子的個數必為偶數（0 或 2），否則乘積為負，而必定存在非負的選法不劣。

- 若取 0 個負數，應取三個最大的正數，即 $a_{n-1}a_{n-2}a_{n-3}$。
- 若取 2 個負數，為使乘積絕對值最大，應取絕對值最大的兩個負數（即最小的兩個 $a_0, a_1$），再配上最大的正數 $a_{n-1}$。

其餘組合都被這兩者支配，故取兩者較大即可，不需枚舉。

乘積最大子陣列的不變量：掃描到 `i` 時，`maxProd` 與 `minProd` 分別是「以 `i` 結尾的子陣列」中乘積的最大值與最小值。

必須同時維護最小值的理由：遇到負數時，最大與最小會互換角色——一個很小的負數乘上負數會變成很大的正數。若只維護最大值，這個機會就被丟失了。轉移時對 `nums[i]`、`maxProd * nums[i]`、`minProd * nums[i]` 三者取最大與最小即可。

## 逐步演算法

固定個數的乘積題：排序後比較兩端的候選組合。子陣列乘積題：線性掃描，遇負數時交換最大與最小，再用三者取極值更新。

## C++17 模板

```cpp
// 三個數的最大乘積。
int maximumProduct(vector<int>& nums) {
    sort(nums.begin(), nums.end());
    const int n = nums.size();
    return max(nums[n - 1] * nums[n - 2] * nums[n - 3],  // 三個最大
               nums[0] * nums[1] * nums[n - 1]);  // 兩個最小負數配最大
}

// 乘積最大子陣列。
int maxProduct(vector<int>& nums) {
    int answer = nums[0], maxProd = nums[0], minProd = nums[0];
    for (size_t i = 1; i < nums.size(); ++i) {
        const int x = nums[i];
        if (x < 0) {
            swap(maxProd, minProd);
        }  // 負數翻轉角色
        maxProd = max(x, maxProd * x);
        minProd = min(x, minProd * x);
        answer = max(answer, maxProd);
    }
    return answer;
}
```

## 常見錯誤與邊界條件

- 只考慮最大的三個而漏掉兩負一正。
- 交換 `maxProd` 與 `minProd` 的時機寫在更新之後。
- 乘積溢位需 `long long`。
- 含 0 時應允許「從當前元素重新開始」（`max(x, ...)` 已涵蓋）。
- 元素個數不足時未特判。

## 與相似技巧的比較

加法的最大子陣列（Kadane）只需維護最大值；乘法必須同時維護最小值，這是兩者最大的結構差異。若允許選任意個數而非連續子陣列，改成統計負數個數與零的個數後直接構造。

## 本節重點速查

- 負因子個數要湊成偶數
- 三數乘積比較兩種候選
- 子陣列要同時維護最大與最小
- 遇負數先交換。

## 時間與空間複雜度

三數乘積需排序，$O(n \log n)$；乘積最大子陣列為單次掃描 $O(n)$、空間 $O(1)$。
