## 這個技術解決什麼問題

把單一序列的元素兩兩配對，使配對數最多、組數最少、或最大的那一對盡量小。代表題是「救生艇」與「最小化最大配對和」。

## 狀態／資料結構定義

排序後用相向雙指標：`left` 指向最小者、`right` 指向最大者。每輪決定這兩者是否配成一對，並向中間收攏。

## 不變量或正確性證明

不變量：任一時刻，區間 `[left, right]` 之外的元素都已被妥善分組，且已用的組數是「處理完那些元素所需的最小值」。

最小者必須與當前最大者配對的論證（以救生艇為例，每艘船最多兩人且有載重上限）：考慮最重的人 `H`。他必定要上某艘船。若最輕的人 `L` 能與 `H` 同船，那麼在任何最優解中，把 `H` 的同伴（若有）換成 `L` 仍然可行——因為 `L` 是最輕的，替換後載重不增；被換下來的人可以併入 `L` 原本所在的船，或單獨成船，總船數不增。故存在一個最優解讓 `L` 與 `H` 同船。若 `L` 都無法與 `H` 同船，則沒有任何人可以，`H` 只能獨自一艘。

兩種情形都讓我們可以安全地把 `right` 定案並收縮，因此貪心與某個最優解始終保持一致。

## 逐步演算法

排序；`left` 置於開頭、`right` 置於結尾；每輪組數加一並讓 `right` 左移；若 `left` 與 `right` 可同組則 `left` 也右移；直到指標交錯。

## C++17 模板

```cpp
// 每艘船最多兩人、載重上限 limit，求最少船數。
int numRescueBoats(vector<int>& people, int limit) {
    sort(people.begin(), people.end());
    int left = 0, right = people.size() - 1, boats = 0;

    while (left <= right) {
        if (people[left] + people[right] <= limit) {
            ++left;
        }  // 最輕者一起上
        --right;  // 最重者必定上船
        ++boats;
    }
    return boats;
}
```

「最小化最大配對和」則是把最小配最大：排序後 `a[i]` 與 `a[n-1-i]` 成對，取所有配對和的最大值。

## 時間與空間複雜度

排序 $O(n \log n)$，雙指標掃描 $O(n)$，總計 $O(n \log n)$，空間 $O(1)$。

## 常見錯誤與邊界條件

- 迴圈條件寫成 `left < right` 而漏掉最後單獨一人的情形。
- `--right` 放在條件分支內導致最重者未被處理。
- 配對和溢位。
- 每組人數上限不是 2 時本法不適用。
- 空陣列回傳 0。

## 與相似技巧的比較

「最小化最大配對和」用最小配最大（逆序配對），「最大化總和」則用同序配對——兩者都由排序不等式支撐，方向相反。若配對需滿足額外的相容關係，退化成二分圖匹配，需匈牙利演算法或網路流。

## 本節重點速查

- 排序後相向雙指標
- 最重者每輪必定定案
- 最輕者能搭就搭
- `left <= right` 別寫成 `<`。
