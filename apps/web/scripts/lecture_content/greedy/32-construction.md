## 這個技術解決什麼問題

題目不問最大值或方案數，而要你親手造出一個符合規則的具體答案——一個排列、一個字串、一個陣列。代表題是「擺動排序 II」「重構字串」。

## 狀態／資料結構定義

多數構造題先做一次排序或次數統計，再按某個固定的填放順序寫入答案。常用手法是「先放最受限的元素」與「按特定下標順序填入」。

## 不變量或正確性證明

構造題的完整解答有兩部分，缺一不可：

**可行性判定**：先證出一個充要條件，說明什麼時候有解。通常由某個計數論證給出，例如「相鄰不同」要求出現最多的元素次數不超過 $\lceil n/2 \rceil$。

**構造與驗證**：給出具體造法，並證明它在條件成立時必定產生合法答案。

以「擺動排序 II」（要求 $a_0 < a_1 > a_2 < a_3 \cdots$）為例。造法是：排序後把較小的一半**倒序**填入偶數位、較大的一半倒序填入奇數位。

為何要倒序：若正序填入，相等的元素可能落在相鄰的偶奇位上而破壞嚴格不等號。倒序填入時，較小一半中最大的那個被放在最前面的偶數位，較大一半中最大的被放在最前面的奇數位，使得「可能相等」的兩個中位數被推到序列的兩端，距離最遠。

嚴格性的保證：設排序後為 $a_0 \le \cdots \le a_{n-1}$，中位數附近可能有大量相等值。倒序填放後，偶數位 `2i` 放的是較小半段的第 `(m-1-i)` 個，奇數位 `2i+1` 放的是較大半段的第 `(m-1-i)` 個。相鄰位置取自兩個半段中相隔至少 `m/2` 個位置的元素，因此只要「出現最多的元素次數不超過 $\lceil n/2 \rceil$」，它們就不會相等。

## 逐步演算法

先判定有無解；排序或統計次數；決定填放順序（通常先放最受限者）；按順序寫入；最後掃一遍驗證結果真的符合所有規則。

## C++17 模板

```cpp
// 擺動排序 II：a[0] < a[1] > a[2] < a[3] ...
void wiggleSort(vector<int>& nums) {
    vector<int> sorted = nums;
    sort(sorted.begin(), sorted.end());

    const int n = nums.size();
    int small = (n + 1) / 2 - 1, large = n - 1;  // 兩半段各自從尾端取
    for (int i = 0; i < n; ++i) {
        nums[i] = (i % 2 == 0) ? sorted[small--] : sorted[large--];  // 倒序填入
    }
}
```

## 常見錯誤與邊界條件

- 正序填入而在中位數重複時失敗。
- 兩半段的分界算錯（奇數長度時較小半段應多一個）。
- 未先判定可行性就直接構造。
- 構造完沒有驗證。
- `n = 1` 時應直接返回。

## 與相似技巧的比較

構造題與最優化題的關鍵差異是「沒有目標函式可最佳化」，因此交換論證用不上，取而代之的是可行性判定加顯式造法。若找不到直接構造，退而求其次可用貪心逐位填入並在填不下去時回溯，但那通常會超時。

## 本節重點速查

- 先判有無解再造
- 最受限的元素先放
- 擺動排序要倒序填避免中位數相鄰
- 造完務必驗證。

## 時間與空間複雜度

排序或統計次數 $O(n \log n)$ 主導，填放與驗證各 $O(n)$，空間 $O(n)$ 存放答案。
