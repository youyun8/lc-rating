## 這個技術解決什麼問題

計算「一件事分成幾個獨立步驟完成」的總方案數。乘法原理讓我們把一個大計數問題拆成若干互不干擾的小選擇，再把各步的選法數相乘，避免真的枚舉。

## 狀態／資料結構定義

通常不需要資料結構，只要一個累乘的 `long long`（必要時取模）。關鍵是把「步驟」定義清楚：每一步的選法數不可以依賴前面步驟的**具體選擇**，只能依賴步驟本身。

## 不變量或正確性證明

不變量：處理完前 `k` 個步驟後，累積值等於前 `k` 步所有合法組合的個數。

歸納證明：前 0 步只有一種空組合，值為 1。設前 `k` 步有 `N` 種組合，第 `k+1` 步在每種既有組合下都有相同的 `a` 種選法，則新的組合總數為 `N × a`——因為每個舊組合各自延伸出 `a` 個新組合，且不同舊組合延伸出的結果互不相同（前 `k` 步已不同）。

這裡的前提正是「獨立性」：第 `k+1` 步的選法數 `a` 必須與前面選了什麼無關。若會互相影響（例如不可重複選），就必須把可用選項的變化納入，變成 `n × (n-1) × …` 的排列形式，而不是單純的 `n^k`。

與加法原理的分工：互斥的情形之間用加法，連續的步驟之間用乘法。

## 時間與空間複雜度

步驟數為 `k` 時，時間 $O(k)$，空間 $O(1)$。若每步選法數需先統計，成本取決於統計本身。

## C++17 模板

```cpp
constexpr long long kMod = 1'000'000'007;

// 各步驟選法數相乘；choices[i] 為第 i 步的選法數。
long long countWays(const vector<long long>& choices) {
    long long result = 1;
    for (long long c : choices) {
        result = result * (c % kMod) % kMod;
    }
    return result;
}
```

典型應用：長度 `n` 的字串每位有 `m` 種字元，總數為 $m^n$，用快速冪計算；若要求相鄰不同，則第一位 `m` 種、其後每位 `m - 1` 種，總數為 $m (m-1)^{n-1}$。

## 常見錯誤與邊界條件

- 步驟之間其實不獨立卻硬套乘法（例如「不重複選」要用排列數）。
- 把互斥情形也相乘（應該相加）。
- 漏掉某一步只有一種選法時仍要乘 1。
- 累乘溢位需取模。
- 某步選法數為 0 時總數為 0，屬正常結果。

## 與相似技巧的比較

乘法原理是組合計數的地基，排列數、組合數、放球問題都建立在它之上；當步驟之間有重疊或衝突時改用容斥原理；當選擇會形成狀態轉移時改用 DP。

## 本節重點速查

- 步驟獨立才能相乘
- 互斥情形要相加
- 不可重複選要用排列而非乘冪
- 累乘記得取模。
