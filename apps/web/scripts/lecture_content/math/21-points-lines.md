## 這個技術解決什麼問題

處理平面上點與線的關係：三點是否共線、線段是否相交、轉向是順時針還是逆時針、多邊形面積。核心是把幾何翻成整數算術，盡量避開除法與浮點誤差。

## 狀態／資料結構定義

點用 `struct Point { long long x, y; }`。最重要的工具是叉積：對向量 $\vec{u}=(x_1,y_1)$ 與 $\vec{v}=(x_2,y_2)$，

$$\vec{u} \times \vec{v} = x_1 y_2 - x_2 y_1$$

全程用整數即可，不需開根號或除法。

## 不變量或正確性證明

叉積的幾何意義：$\vec{u} \times \vec{v}$ 等於以兩向量為鄰邊的平行四邊形的**有向**面積。

由此得到三條判定，且都不需除法：

- 符號為正表示 $\vec{v}$ 在 $\vec{u}$ 的逆時針側，為負表示順時針側，為零表示共線。
- 三點 `O`、`A`、`B` 共線等價於 $(A-O) \times (B-O) = 0$。
- 三角形面積為 $\frac{1}{2}\left|(A-O)\times(B-O)\right|$；判斷面積大小時可比較兩倍面積，維持整數。

判斷線段 `AB` 與 `CD` 是否跨越（規範相交）：要求 `C`、`D` 落在直線 `AB` 兩側，且 `A`、`B` 落在直線 `CD` 兩側，即

$$\big((B-A)\times(C-A)\big)\cdot\big((B-A)\times(D-A)\big) < 0$$

且對稱式亦成立。嚴格小於零排除了端點共線的退化情形，那些需依題意另行判斷。

## 時間與空間複雜度

單次叉積為 $O(1)$；多邊形面積用鞋帶公式掃過所有頂點，$O(n)$。判斷 `n` 條線段兩兩相交樸素為 $O(n^2)$，需要更快時用掃描線。

## C++17 模板

```cpp
struct Point {
    long long x, y;
};

// 叉積：正為逆時針、負為順時針、零為共線。
long long cross(const Point& o, const Point& a, const Point& b) {
    return (a.x - o.x) * (b.y - o.y) - (a.y - o.y) * (b.x - o.x);
}

// 鞋帶公式：回傳兩倍有向面積，取絕對值再除以 2 即為面積。
long long doubleArea(const vector<Point>& poly) {
    long long sum = 0;
    const int n = poly.size();
    for (int i = 0; i < n; ++i) {
        const Point& p = poly[i];
        const Point& q = poly[(i + 1) % n];  // 首尾相接
        sum += p.x * q.y - q.x * p.y;
    }
    return llabs(sum);
}
```

## 常見錯誤與邊界條件

- 用斜率判斷共線而在垂直線時除以零（改用叉積）。
- 座標相乘溢位，需 `long long` 甚至 `__int128`。
- 面積忘記除以 2 或忘記取絕對值。
- 鞋帶公式漏掉首尾相接那一項。
- 退化情形（重合點、端點接觸）未依題意處理。
- 用浮點比較是否等於 0。

## 與相似技巧的比較

叉積判方向、點積判夾角銳鈍，兩者互補；需要精確判定時一律用整數叉積，只有在必須輸出實際長度或角度時才轉浮點。凸包、極角排序、多邊形內判定全都建立在叉積之上。

## 本節重點速查

- 叉積等於有向面積的兩倍
- 正逆時針、負順時針、零共線
- 全程用整數
- 面積記得取絕對值再除以 2。
