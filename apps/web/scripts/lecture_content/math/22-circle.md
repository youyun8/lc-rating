## 這個技術解決什麼問題

處理圓的判定與計算：點是否在圓內、兩圓是否相交、圓與矩形是否重疊。關鍵是把幾乎所有判斷都化成「距離與半徑的比較」，並用平方比較避開開根號。

## 狀態／資料結構定義

一個圓只需三個數：圓心 `(cx, cy)` 與半徑 `r`。距離一律以平方形式保存，`dx * dx + dy * dy` 與 `r * r` 直接比較，全程留在整數域。

## 不變量或正確性證明

平方比較的正確性：對非負實數 `a`、`b`，$a \le b \iff a^2 \le b^2$，因為平方在非負區間上嚴格遞增。距離與半徑都非負，故比較平方與比較原值等價——這讓我們得以捨棄 `sqrt`，同時消除浮點誤差並保持整數精度。

兩圓關係由圓心距 `d` 與半徑決定：相離為 $d > r_1 + r_2$、外切為等號、相交為 $|r_1 - r_2| < d < r_1 + r_2$、內含為 $d < |r_1 - r_2|$。這些同樣可全部平方後比較，唯一要注意的是 $|r_1 - r_2|$ 要先取絕對值再平方。

圓與軸對齊矩形是否重疊：先把圓心「夾」到矩形範圍內得到最近點 $(\max(x_1,\min(cx,x_2)), \max(y_1,\min(cy,y_2)))$，再判斷該點到圓心的距離是否不超過 `r`。正確性在於矩形是凸集，圓心到矩形的最近點必是逐座標獨立夾取的結果——因為距離平方可分解成 `x` 與 `y` 兩項各自獨立最小化。

## 時間與空間複雜度

所有判定皆為 $O(1)$ 時間與空間。若要處理 `n` 個圓的兩兩關係，樸素為 $O(n^2)$。

## C++17 模板

```cpp
// 點是否在圓內（含邊界）：比平方，不開根號。
bool inCircle(long long px, long long py, long long cx, long long cy,
              long long r) {
    const long long dx = px - cx, dy = py - cy;
    return dx * dx + dy * dy <= r * r;
}

// 圓與軸對齊矩形是否重疊。
bool circleOverlapsRect(long long cx, long long cy, long long r, long long x1,
                        long long y1, long long x2, long long y2) {
    const long long nx = max(x1, min(cx, x2));  // 把圓心夾進矩形
    const long long ny = max(y1, min(cy, y2));
    return inCircle(nx, ny, cx, cy, r);
}
```

## 常見錯誤與邊界條件

- 開根號後用浮點比較而誤判邊界。
- `dx * dx` 在 `int` 下溢位。
- 邊界該算相交還是相離未依題意確認（`<=` 與 `<` 的差別）。
- 兩圓內含時忘記取半徑差的絕對值。
- 半徑為 0 的退化圓。
- 矩形座標未保證 `x1 <= x2`。

## 與相似技巧的比較

軸對齊矩形的重疊判定只需比較四個座標，比圓簡單；一般多邊形與圓的判定要逐邊求點到線段距離。凡是「比較距離大小」的場合都應優先考慮平方比較；只有需要輸出實際距離或面積時才動用浮點。

## 本節重點速查

- 圓只需三個數
- 比平方不開根號
- 圓心夾進矩形求最近點
- 邊界的 `<` 與 `<=` 要看題意。
