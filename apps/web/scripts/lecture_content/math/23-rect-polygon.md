## 這個技術解決什麼問題

處理矩形與多邊形的判定：兩個軸對齊矩形是否重疊、重疊面積多少、四點是否構成正方形、點是否在多邊形內。重點同樣是化成整數座標的比較。

## 狀態／資料結構定義

軸對齊矩形用四個數 `(x1, y1, x2, y2)` 表示左下與右上角，並約定 `x1 <= x2`、`y1 <= y2`。一般多邊形用頂點陣列，按沿邊順序（順時針或逆時針皆可）排列。

## 不變量或正確性證明

矩形重疊的判定可**降維**：兩個軸對齊矩形重疊，當且僅當它們在 `x` 軸上的投影區間重疊，且在 `y` 軸上的投影區間也重疊。

理由是軸對齊矩形恰為兩個區間的笛卡兒積 $[x_1,x_2] \times [y_1,y_2]$，而兩個乘積集合的交集非空等價於各分量交集皆非空。於是二維問題化為兩次一維區間相交判定：區間 $[a_1,a_2]$ 與 $[b_1,b_2]$ 相交等價於 $\max(a_1,b_1) < \min(a_2,b_2)$（若邊界接觸也算重疊則用 $\le$）。

重疊面積同理：$\text{寬} = \max(0, \min(x_2,x_2') - \max(x_1,x_1'))$，高同理，兩者相乘。取 `max(0, ·)` 是為了讓不重疊時自然得到 0。

點在多邊形內用射線法：從該點向任意方向射出一條射線，統計與多邊形邊的交點數，奇數為內、偶數為外。正確性在於每穿過一次邊界就從內外切換一次；實作時需小心射線恰好通過頂點的退化情形，慣例是規定只計「一端嚴格在射線上方、另一端不在」的邊，使每個頂點只被計一次。

## 時間與空間複雜度

矩形判定與面積皆為 $O(1)$。射線法判斷點在多邊形內為 $O(n)$。求 `n` 個矩形的聯集面積需掃描線加線段樹，$O(n \log n)$。

## C++17 模板

```cpp
// 兩個軸對齊矩形的重疊面積（只碰到邊界視為 0）。
long long overlapArea(long long ax1, long long ay1, long long ax2,
                      long long ay2, long long bx1, long long by1,
                      long long bx2, long long by2) {
    const long long w = min(ax2, bx2) - max(ax1, bx1);
    const long long h = min(ay2, by2) - max(ay1, by1);
    return (w > 0 && h > 0) ? w * h : 0;  // 不重疊時為 0
}

// 射線法：點是否在多邊形內。
bool inPolygon(const vector<Point>& poly, long long px, long long py) {
    bool inside = false;
    const int n = poly.size();
    for (int i = 0, j = n - 1; i < n; j = i++) {
        const auto& a = poly[i];
        const auto& b = poly[j];
        if ((a.y > py) == (b.y > py)) {
            continue;
        }  // 不跨越水平線
        const long long cross =
            (b.x - a.x) * (py - a.y) - (b.y - a.y) * (px - a.x);
        if ((cross > 0) == (b.y > a.y)) {
            inside = !inside;
        }
    }
    return inside;
}
```

## 常見錯誤與邊界條件

- 未保證 `x1 <= x2` 就直接比較。
- 邊界接觸該不該算重疊未確認。
- 面積相乘溢位。
- 射線法在頂點與邊上的退化情形處理不一致，導致同一頂點被計兩次。
- 正方形判定只比對邊長而忽略對角線，需同時檢查六個兩兩距離中恰有四個相等的短邊與兩個相等的長對角線。

## 與相似技巧的比較

軸對齊情形一律降維成區間問題，最省事；一般凸多邊形的相交判定用分離軸定理；大量矩形的聯集面積或周長屬於掃描線經典題。點在凸多邊形內可用二分做到 $O(\log n)$，優於一般射線法。

## 本節重點速查

- 軸對齊矩形是兩區間的乘積，逐軸判斷即可
- 重疊寬高取 `max(0, ·)`
- 射線法看交點奇偶
- 頂點退化要一致處理。
