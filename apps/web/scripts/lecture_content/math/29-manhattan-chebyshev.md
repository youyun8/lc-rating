## 這個技術解決什麼問題

處理曼哈頓距離 $|x_1-x_2|+|y_1-y_2|$ 的極值問題。絕對值與兩維耦合讓直接枚舉是 $O(n^2)$；透過座標旋轉把曼哈頓距離轉成切比雪夫距離 $\max(|x_1-x_2|,|y_1-y_2|)$，兩維就解耦了，可以各自獨立求極值。

## 狀態／資料結構定義

旋轉變換為 $(x, y) \mapsto (x+y,\; x-y)$。變換後只需維護新座標各自的最大值與最小值。反向變換為 $(u, v) \mapsto \left(\frac{u+v}{2}, \frac{u-v}{2}\right)$。

## 不變量或正確性證明

核心恆等式：對任意實數 `a`、`b`，

$$|a| + |b| = \max(|a+b|,\; |a-b|)$$

證明：右式的兩個候選皆不超過 $|a|+|b|$（三角不等式）。而當 `a`、`b` 同號時 $|a+b| = |a|+|b|$，異號時 $|a-b| = |a|+|b|$，故最大值恰好取到 $|a|+|b|$。

令 $a = x_1-x_2$、$b = y_1-y_2$，代入後左式是曼哈頓距離，右式是變換後座標 $u = x+y$、$v = x-y$ 的切比雪夫距離。因此**原空間的曼哈頓距離等於變換後空間的切比雪夫距離**。

這個等價帶來實質好處：切比雪夫距離是兩維取 `max`，而「最大化 $\max(A,B)$」可以拆成「分別最大化 $A$ 與 $B$ 再取較大者」。於是求最遠點對只需算 $\max u - \min u$ 與 $\max v - \min v$，各掃一遍即可，複雜度從 $O(n^2)$ 降到 $O(n)$。

## 時間與空間複雜度

變換與掃描各一次，時間 $O(n)$、空間 $O(1)$。相較樸素兩兩比較的 $O(n^2)$，在 $n = 10^5$ 時是決定性的差距。

## C++17 模板

```cpp
// 平面上曼哈頓距離的最大值。
long long maxManhattan(const vector<Point>& pts) {
    long long maxU = LLONG_MIN, minU = LLONG_MAX;
    long long maxV = LLONG_MIN, minV = LLONG_MAX;

    for (const auto& p : pts) {
        const long long u = p.x + p.y;  // 旋轉 45 度
        const long long v = p.x - p.y;
        maxU = max(maxU, u);
        minU = min(minU, u);
        maxV = max(maxV, v);
        minV = min(minV, v);
    }
    return max(maxU - minU, maxV - minV);
}
```

## 常見錯誤與邊界條件

- 把變換方向記反（曼哈頓轉切比雪夫用 $(x+y, x-y)$，反向才是除以 2）。
- 反向變換時忘記除以 2 或遇到奇偶性不合的無效座標。
- 只取 `u` 的極差而漏掉 `v`。
- 求**最小**曼哈頓距離時本法不適用（`max` 拆不開），需改用其他方法。
- 座標相加溢位。

## 與相似技巧的比較

求最遠曼哈頓點對用本變換最漂亮；高維時可推廣成枚舉 $2^{d-1}$ 種符號組合。若要求最近點對，曼哈頓與歐氏一樣需要分治或掃描線。切比雪夫距離本身常出現在「八方向移動」的棋盤題中，那時反而要往回轉成曼哈頓。

## 本節重點速查

- $(x,y) \to (x+y, x-y)$ 把曼哈頓變切比雪夫
- $|a|+|b| = \max(|a+b|,|a-b|)$
- 只求極差
- 最小距離不適用。
