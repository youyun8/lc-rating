## 這個技術解決什麼問題

求兩數的最大公約數。列舉所有公因數是 $O(\min(a,b))$；歐幾里得演算法用取餘不斷縮小問題，降到對數級，是幾乎所有數論題的底層工具。

## 狀態／資料結構定義

只需兩個變數 `a`、`b`。每步以 `(b, a % b)` 取代 `(a, b)`，直到 `b` 為 0，此時 `a` 即為答案。

## 不變量或正確性證明

不變量：`gcd(a, b)` 在每次替換後保持不變。

證明關鍵引理 `gcd(a, b) = gcd(b, a mod b)`：設 `a = qb + r`。若 `d` 同時整除 `a` 與 `b`，則 `r = a - qb` 也被 `d` 整除，故 `d` 是 `(b, r)` 的公因數；反之若 `d` 整除 `b` 與 `r`，則 `a = qb + r` 也被 `d` 整除。兩邊的公因數集合完全相同，最大者自然相等。

終止性：每步的餘數嚴格小於除數，且非負，故必在有限步內降到 0。收斂速度由費波那契數列給出最壞界——連續兩步至少讓較大者減半，因此步數為 $O(\log \min(a,b))$。

邊界 `gcd(a, 0) = a` 正是遞迴出口：任何數都整除 0。

## 時間與空間複雜度

時間 $O(\log \min(a, b))$，迭代版空間 $O(1)$，遞迴版堆疊深度同為對數級。

## C++17 模板

```cpp
long long gcd(long long a, long long b) {
    while (b != 0) {
        const long long r = a % b;
        a = b;
        b = r;
    }
    return a;  // b 為 0 時 a 即答案
}
```

C++17 起標準庫已提供 `std::gcd(a, b)`（`<numeric>`），競賽中可直接使用。多個數的 GCD 由結合律逐個折疊：`gcd(gcd(x, y), z)`。

## 常見錯誤與邊界條件

- 負數輸入時 `%` 在 C++ 中可能得到負餘數，應先取絕對值。
- `gcd(0, 0)` 通常定義為 0，需確認題意。
- 用減法版本（輾轉相減）在兩數相差懸殊時退化成 $O(n)$。
- 把 `gcd` 與 `lcm` 的公式記反。

## 與相似技巧的比較

擴展歐幾里得在求 GCD 的同時給出貝祖係數，可用來解線性同餘方程與求模逆元；若只需判斷互質，算完 GCD 比較是否為 1 即可；區間 GCD 查詢可用線段樹或稀疏表，因為 GCD 滿足結合律與冪等性。

## 本節重點速查

- `gcd(a, b) = gcd(b, a mod b)`
- `b` 為 0 時回傳 `a`
- 步數是對數級
- 負數先取絕對值。
