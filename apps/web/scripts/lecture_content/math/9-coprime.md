## 這個技術解決什麼問題

判斷兩數是否互質（GCD 為 1），以及統計「與 `n` 互質的數有幾個」。互質是模逆元存在、分數最簡、循環群生成的共同前提。

## 狀態／資料結構定義

判斷只需一次 GCD。計數則用歐拉函數 `φ(n)`，由 `n` 的相異質因數決定；區間內所有 `φ` 值可用類似線性篩的方式一次求出。

## 不變量或正確性證明

歐拉函數的乘積公式：

$$\varphi(n) = n \prod_{p \mid n} \left(1 - \frac{1}{p}\right)$$

用容斥證明：`[1, n]` 中與 `n` 不互質的數，就是至少被 `n` 的某個質因數整除的數。被 `p` 整除的有 `n/p` 個，被 `p·q` 整除的有 `n/(pq)` 個，依容斥交替加減，整理後恰為上式的乘積形式。

實作時寫成 `result = result / p * (p - 1)`，先除後乘避免溢位；除法無誤差是因為在處理質因數 `p` 時 `result` 仍含有因數 `p`。

注意公式只看**相異**質因數，指數不影響括號項——因為與 `n` 互質只要求不被任何質因數整除，與該質因數出現幾次無關。

## 時間與空間複雜度

判斷互質為 $O(\log \min(a,b))$。單個 `φ(n)` 需先分解質因數，$O(\sqrt{n})$。求 `[1, n]` 全部 `φ` 值用線性篩，$O(n)$ 時間與空間。

## C++17 模板

```cpp
bool coprime(long long a, long long b) {
    return gcd(a, b) == 1;
}

// 歐拉函數：[1, n] 中與 n 互質的數的個數。
long long phi(long long n) {
    long long result = n;
    for (long long p = 2; p * p <= n; ++p) {
        if (n % p != 0) {
            continue;
        }
        while (n % p == 0) {
            n /= p;
        }  // 只算一次，指數不影響
        result = result / p * (p - 1);  // 先除後乘
    }
    if (n > 1) {
        result = result / n * (n - 1);
    }  // 剩下的大質因數
    return result;
}
```

## 常見錯誤與邊界條件

- 同一個質因數重複套用括號項。
- 忘記迴圈後處理剩下的大質因數。
- 寫成 `result * (p - 1) / p` 而溢位。
- `φ(1) = 1`（1 與自己互質，依定義成立）。
- 把「兩兩互質」誤當成「整體 GCD 為 1」——後者弱得多。

## 與相似技巧的比較

判斷互質直接用 GCD 即可，不必分解；需要大量 `φ` 值時用線性篩批量求。歐拉定理（`a^φ(m) ≡ 1 (mod m)`，需 `a` 與 `m` 互質）可用來求逆元，是費馬小定理在合數模下的推廣。

## 本節重點速查

- 互質即 GCD 為 1
- `φ` 只看相異質因數
- `result / p * (p - 1)` 先除後乘
- 別漏掉最後的大質因數。
