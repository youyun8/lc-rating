## 這個技術解決什麼問題

原地反轉字串或陣列，以及所有以反轉為基礎的變形：只反轉母音、反轉每個單字、旋轉陣列。核心工具是一對從兩端向中間交換的指標。

## 辨識題型的訊號

要求「原地」「不使用額外陣列」地反轉、旋轉或重排；或題目本身就是「反轉單字順序」「輪轉陣列 `k` 步」。

## 核心想法與直覺

反轉的本質是把下標 `i` 與 `n - 1 - i` 的元素互換。用左右兩個指標同時向中間移動，每步交換一次，走到相遇即完成，只需 `n / 2` 次交換且不佔額外空間。

許多看似複雜的重排都能拆成幾次反轉。旋轉陣列是最漂亮的例子：先整體反轉，再分別反轉前 `k` 個與後 `n - k` 個，就得到向右輪轉 `k` 步的結果。

## 狀態／資料結構定義

`left` 從 0 出發、`right` 從 `n - 1` 出發，維持 `left < right`。已完成的部分是兩端各 `left` 個元素。

## 不變量或正確性證明

不變量：任一時刻，區間 `[0, left)` 與 `(right, n-1]` 已經處於最終位置，中間的 `[left, right]` 尚未處理且其內容仍是原始順序。

證明：初始兩端為空，成立。每步交換 `a[left]` 與 `a[right]`——依反轉的定義，原本在 `left` 的元素最終應落在 `n - 1 - left = right` 處，反之亦然，故這一次交換同時讓兩個元素到位。隨後 `left` 加一、`right` 減一，已完成區間各擴大一格，不變量保持。當 `left >= right` 時，未處理區間長度不超過 1；長度為 1 時該元素的目標位置就是自己，無需動作。因此整個陣列完成反轉。

旋轉三次反轉的正確性：設原陣列為 `AB`，其中 `B` 的長度為 `k`。整體反轉得到 `(AB)^R = B^R A^R`；再分別反轉前 `k` 個與其餘部分，得到 `(B^R)^R (A^R)^R = BA`，正是向右輪轉 `k` 步的結果。

## 逐步演算法

`left` 置 0、`right` 置 `n - 1`；當 `left < right` 時交換兩者並各自向中間移動一格；相遇即結束。

## C++17 模板

```cpp
void reverseRange(vector<int>& nums, int left, int right) {
    while (left < right) {
        swap(nums[left], nums[right]);
        ++left;
        --right;
    }
}

// 向右輪轉 k 步：三次反轉，O(n) 時間、O(1) 空間。
void rotate(vector<int>& nums, int k) {
    const int n = nums.size();
    k %= n;  // k 可能大於 n
    reverseRange(nums, 0, n - 1);
    reverseRange(nums, 0, k - 1);
    reverseRange(nums, k, n - 1);
}
```

只反轉母音之類的變形，把指標推進條件改成「跳過不需處理的字元」即可：

```cpp
while (left < right) {
    while (left < right && !isVowel(s[left])) {
        ++left;
    }
    while (left < right && !isVowel(s[right])) {
        --right;
    }
    if (left < right) {
        swap(s[left++], s[right--]);
    }
}
```

## 時間與空間複雜度

交換次數為 $O(n)$，時間 $O(n)$，空間 $O(1)$。三次反轉的旋轉同為 $O(n)$ 時間、$O(1)$ 空間。

## 常見錯誤與邊界條件

- 迴圈條件寫成 `left <= right`，長度為奇數時多做一次無謂的自我交換（無害但多餘），若條件中含副作用則可能出錯。
- 旋轉時忘記 `k %= n` 而越界。
- 跳過字元的內層迴圈缺少 `left < right` 保護。
- 空陣列或單元素應原樣返回。

## 與相似技巧的比較

用額外陣列反轉是 $O(n)$ 空間，題目常明確禁止；旋轉也可以用「循環替換」在 $O(1)$ 空間完成，但需處理最大公因數個環，程式遠比三次反轉複雜且易錯，因此三次反轉是實務首選。

## 本節重點速查

- 兩端交換、向中間收；
- `left < right` 即可；
- 旋轉等於三次反轉；
- 記得 `k %= n`。
