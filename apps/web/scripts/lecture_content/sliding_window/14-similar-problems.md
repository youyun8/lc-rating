## 這個技術解決什麼問題

找出「只要把這一段排好序，整個陣列就有序」的最短連續子陣列。表面上像排序題，實際上用兩次線性掃描配合前綴最大值與後綴最小值即可，不需真的排序。

## 辨識題型的訊號

問「最短的無序連續子陣列」「排序哪一段能讓整體有序」；或需要判斷每個位置「是否已經處於最終有序位置」。

## 核心想法與直覺

一個元素可以留在原地不動，當且僅當它同時滿足兩個條件：不小於它左側所有元素的最大值，且不大於它右側所有元素的最小值。

於是從左往右掃一遍維護前綴最大值，凡是遇到比前綴最大值小的元素，就代表它左邊有更大的數擋著，該位置必須被納入待排序區間——記錄最後一次發生的位置作為右界。對稱地從右往左掃維護後綴最小值，記錄最前一次違規的位置作為左界。

## 狀態／資料結構定義

`right` 是需要排序區間的右界，`left` 是左界。`maxSoFar` 為從左到當前的前綴最大值，`minSoFar` 為從右到當前的後綴最小值。

## 不變量或正確性證明

不變量：正向掃描到位置 `i` 時，`maxSoFar` 等於 `nums[0..i]` 的最大值。

先證必要性：若 `nums[i] < maxSoFar`（其中 `maxSoFar` 由某個 `j < i` 取得），則在最終有序的陣列中 `nums[j]` 必須排在 `nums[i]` 之後，故 `i` 與 `j` 都必須落在待排序區間內，因此區間右界至少為 `i`。取所有這類 `i` 的最大值即為右界的下界。對稱論證給出左界。

再證充分性：設由上述方法得到的區間為 `[left, right]`。對任意 `i < left`，掃描過程未曾違規，表示 `nums[i]` 等於其前綴最大值，即 `nums[i]` 不小於左側所有元素；同時由反向掃描未違規知 `nums[i]` 不大於右側所有元素的最小值。因此 `nums[i]` 已在正確位置。同理 `i > right` 者亦然。故只需排序 `[left, right]` 即可使整體有序，該區間確實是最短的。

## 逐步演算法

正向掃描維護前綴最大值，每遇到小於它的元素就把右界更新為當前下標；反向掃描維護後綴最小值，每遇到大於它的元素就把左界更新為當前下標；若右界從未被更新，代表陣列本已有序，回傳 0。

## C++17 模板

```cpp
class Solution {
public:
    int findUnsortedSubarray(vector<int>& nums) {
        const int n = nums.size();
        int left = -1, right = -1;

        int maxSoFar = INT_MIN;
        for (int i = 0; i < n; ++i) {  // 正向：找右界
            if (nums[i] < maxSoFar) {
                right = i;
            } else {
                maxSoFar = nums[i];
            }
        }

        int minSoFar = INT_MAX;
        for (int i = n - 1; i >= 0; --i) {  // 反向：找左界
            if (nums[i] > minSoFar) {
                left = i;
            } else {
                minSoFar = nums[i];
            }
        }

        return right == -1 ? 0 : right - left + 1;
    }
};
```

## 時間與空間複雜度

兩次線性掃描，時間 $O(n)$，空間 $O(1)$。相較之下「複製一份排序後比對首尾差異」的解法是 $O(n \log n)$ 時間與 $O(n)$ 空間，雖然更直覺但較慢。

## 常見錯誤與邊界條件

- 只掃一個方向就下結論。
- 把 `maxSoFar` 的更新寫在違規判斷之前，導致自身參與比較。
- 已經有序時回傳 1 而非 0。
- `left` 與 `right` 的初始值選用 0 而無法區分「未更新」。
- 含重複元素時判斷應用嚴格不等號（相等不算違規）。

## 與相似技巧的比較

單調堆疊也能解此題——用堆疊找出每個元素應被推到的最左／最右位置，複雜度相同但程式較長；本節的前後綴極值掃描是同向雙指標思路的自然延伸，也是許多「每個位置是否已就位」類問題的通用手法。

## 本節重點速查

- 前綴最大值定右界、後綴最小值定左界；
- 違規判斷要在更新極值之前；
- 已有序回傳 0；
- 兩次掃描即可。
