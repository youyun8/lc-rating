## 這個技術解決什麼問題

兩個指標從同一個位置出發，一個向左、一個向右背向擴散。最典型的用途是以每個位置為中心向外擴張找迴文，以及從某個基準點向兩側尋找最近的滿足條件者。

## 辨識題型的訊號

問最長迴文子串／迴文子串個數；需要「以某點為中心對稱地檢查」；或在有序陣列中找出離某個值最近的 `k` 個元素。

## 核心想法與直覺

迴文的定義本身就是對稱的：`s[i..j]` 是迴文，等價於 `s[i] == s[j]` 且 `s[i+1..j-1]` 是迴文。與其對每個區間獨立驗證，不如反過來——固定對稱中心，兩側同步向外擴張，只要兩端字元相同就繼續，一旦不同就停止。這樣每個中心的擴張成本正比於它產生的迴文長度。

長度為奇數與偶數的迴文中心不同：奇數的中心是一個字元，偶數的中心是兩個字元之間的縫隙。因此 `n` 個字元共有 `2n - 1` 個候選中心。

## 狀態／資料結構定義

`left` 與 `right` 為當前擴張到的邊界。奇數迴文以 `left = right = i` 起始，偶數迴文以 `left = i`、`right = i + 1` 起始。

## 不變量或正確性證明

不變量：擴張過程中，區間 `[left, right]` 始終是迴文。

歸納：起始時區間為單一字元（必為迴文）或兩個相同字元（檢查後才進入）。每次擴張前檢查 `s[left - 1] == s[right + 1]`，成立才把邊界外推；由迴文的遞迴定義，在 `[left, right]` 為迴文且兩側新字元相等的前提下，`[left-1, right+1]` 也是迴文，故不變量保持。

停止即最長：擴張在 `s[left-1] != s[right+1]` 或觸及邊界時停止。此時任何更大的同中心區間都包含這對不相等的字元，不可能是迴文。因此每個中心擴張出的是該中心的最長迴文，遍歷所有 `2n - 1` 個中心即涵蓋所有迴文子串。

## 逐步演算法

枚舉每個可能的中心（含字元中心與縫隙中心）；從中心向兩側擴張，只要邊界合法且兩端字元相等就繼續；記錄擴張所得的最長長度或累加迴文個數。

## C++17 模板

```cpp
class Solution {
public:
    string longestPalindrome(string s) {
        int start = 0, best = 0;

        auto expand = [&](int left, int right) {
            while (left >= 0 && right < static_cast<int>(s.size()) &&
                   s[left] == s[right]) {
                --left;
                ++right;
            }
            // 迴圈結束時 [left+1, right-1] 是迴文
            if (right - left - 1 > best) {
                best = right - left - 1;
                start = left + 1;
            }
        };

        for (int i = 0; i < static_cast<int>(s.size()); ++i) {
            expand(i, i);      // 奇數長度
            expand(i, i + 1);  // 偶數長度
        }
        return s.substr(start, best);
    }
};
```

統計迴文子串個數只需把記錄最值改成每成功擴張一次就累加 1。

## 時間與空間複雜度

共 `2n - 1` 個中心，每個中心最多擴張 $O(n)$ 次，時間 $O(n^2)$，空間 $O(1)$。若需要線性時間，改用 Manacher 演算法。

## 常見錯誤與邊界條件

- 只處理奇數長度而漏掉偶數迴文。
- 迴圈結束後把長度算成 `right - left + 1`（此時邊界已多走一步，正確的是 `right - left - 1`）。
- 起點算成 `left` 而非 `left + 1`。
- 空字串或單字元需回傳自身。
- 擴張時忘記檢查邊界造成越界。

## 與相似技巧的比較

區間 DP 以 `f[i][j]` 表示是否為迴文，同為 $O(n^2)$ 但空間也是 $O(n^2)$；Manacher 用「已知的最右迴文邊界」重用先前結果，達到 $O(n)$；中心擴散的優勢是空間 $O(1)$ 且程式最短，是面試場合的首選。

## 本節重點速查

- 固定中心向外擴；
- 奇偶兩種中心都要試；
- 停止後長度是 `right - left - 1`；
- 起點是 `left + 1`。
