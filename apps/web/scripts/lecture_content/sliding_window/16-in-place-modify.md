## 這個技術解決什麼問題

在不申請額外陣列的前提下改寫原陣列：移除指定元素、去除重複、把零移到末尾、按規則重排。雙指標讓「篩選後的結果」直接覆寫回原陣列的前段。

## 辨識題型的訊號

題目明確要求「原地修改」「空間複雜度 $O(1)$」「回傳新長度而非新陣列」；或描述為「移除」「去重」「移動元素」。

## 核心想法與直覺

沿用快讀慢寫的分工：`fast` 逐一檢視每個元素，`slow` 標記結果區的下一個寫入位置。應保留的元素被搬到 `nums[slow]`，其餘直接跳過。因為 `slow` 永遠不超過 `fast`，覆寫的一定是已讀過的位置。

題目通常只要求前 `slow` 個元素正確，後面的內容不限。若要求「其餘位置補零」（例如移動零），在掃描結束後再補一輪即可。

## 狀態／資料結構定義

`slow` 為寫游標兼結果長度，`fast` 為讀游標，恆有 `slow <= fast`。保留判斷依題意而定：不等於 `val`、與前一個保留值不同、非零等等。

## 不變量或正確性證明

不變量：`[0, slow)` 恰為「前 `fast` 個元素中所有應保留者」，且維持原始相對順序。

歸納步驟：初始兩者為 0，區間為空。檢視 `nums[fast]` 時，若應丟棄則 `slow` 不變，保留集合未增加，不變量成立；若應保留則寫入 `nums[slow]` 後遞增，恰好把它接在結果尾端，順序不變。

覆寫安全性：由 `slow <= fast` 知寫入位置早已被讀取，不會破壞尚未檢視的資料。等號成立時是自我賦值，無副作用。

去重的判斷之所以要比對 `nums[slow - 1]` 而非 `nums[fast - 1]`：前者是已定稿的結果，後者可能是剛被丟棄的重複值，用它比較會在連續三個以上相同時誤判。

## 逐步演算法

`slow` 與 `fast` 歸零；`fast` 掃過全部元素；判斷是否保留，保留則寫入 `nums[slow]` 並遞增；掃完回傳 `slow`；若題目要求填充剩餘位置，再補一輪。

## C++17 模板

有序陣列去重（每個值只保留一個）：

```cpp
int removeDuplicates(vector<int>& nums) {
    int slow = 0;
    for (int fast = 0; fast < static_cast<int>(nums.size()); ++fast) {
        if (slow == 0 || nums[fast] != nums[slow - 1]) {  // 比對已定稿的值
            nums[slow] = nums[fast];
            ++slow;
        }
    }
    return slow;
}
```

移動零（保留非零元素順序，其餘補零）：

```cpp
void moveZeroes(vector<int>& nums) {
    int slow = 0;
    for (int fast = 0; fast < static_cast<int>(nums.size()); ++fast) {
        if (nums[fast] != 0) {
            nums[slow++] = nums[fast];
        }
    }
    while (slow < static_cast<int>(nums.size())) {
        nums[slow++] = 0;
    }
}
```

允許每個值最多保留兩個時，判斷改為與 `nums[slow - 2]` 比較：

```cpp
if (slow < 2 || nums[fast] != nums[slow - 2]) {
    nums[slow++] = nums[fast];
}
```

## 時間與空間複雜度

每個元素讀一次、至多寫一次，時間 $O(n)$，空間 $O(1)$。

## 常見錯誤與邊界條件

- 去重時比對 `nums[fast - 1]` 而非 `nums[slow - 1]`。
- 忘記 `slow == 0` 的起始保護而越界。
- 回傳陣列而非長度。
- 「保留至多 `k` 個」的變形忘記把比較對象改成 `nums[slow - k]`。
- 移動零時用交換而非覆寫也可行，但要避免自我交換帶來的多餘寫入。

## 與相似技巧的比較

用額外陣列篩選再拷回是 $O(n)$ 空間，題目通常禁止；若元素順序無所謂，可以用「首尾交換」把待刪元素換到末尾，寫入次數更少但會打亂順序；快讀慢寫的優勢是保序且邏輯統一。

## 本節重點速查

- 快讀慢寫；
- 比較對象是 `nums[slow - 1]`；
- 回傳的是長度 `slow`；
- 要補零就再掃一輪。
