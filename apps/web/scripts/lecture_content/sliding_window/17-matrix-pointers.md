## 這個技術解決什麼問題

在「每列由左至右遞增、每行由上至下遞增」的矩陣中搜尋目標值或統計符合條件的元素個數。雙指標從一個特殊的角落出發，把 $O(nm)$ 的全掃降到 $O(n + m)$。

## 辨識題型的訊號

矩陣同時具備列有序與行有序的性質；問某個值是否存在、或統計小於／大於某值的元素個數。注意與「整個矩陣攤平後有序」的題目區分——後者可直接二分。

## 核心想法與直覺

關鍵是選對起點。從**右上角**出發時，當前元素是所在列的最大值、同時是所在行的最小值，於是每次比較都能果斷刪掉一整列或一整行：

- 若當前值大於目標，這一列的其餘元素只會更大，整列作廢，向左移一格。
- 若當前值小於目標，這一行的其餘元素只會更小，整行作廢，向下移一格。

左下角同理。左上角與右下角則不行——那裡的元素同時是行列的最小（或最大）值，比較結果無法排除任何一整條。

## 狀態／資料結構定義

`row` 與 `col` 為當前位置，初始為 `(0, m - 1)`（右上角）。尚未排除的搜尋區域是以 `(row, col)` 為右上角的子矩陣，即 `[row, n) × [0, col]`。

## 不變量或正確性證明

不變量：若目標存在於矩陣中，它必定落在以 `(row, col)` 為右上角的子矩陣 `[row, n) × [0, col]` 內。

證明每步排除的安全性：設當前值 `a[row][col] > target`。對該列的任意 `r >= row`，由行遞增知 `a[r][col] >= a[row][col] > target`，故第 `col` 列在剩餘區域中不可能含有目標，令 `col` 減一是安全的。對稱地，若 `a[row][col] < target`，對該行的任意 `c <= col`，由列遞增知 `a[row][c] <= a[row][col] < target`，故第 `row` 行作廢，令 `row` 加一安全。

終止性：每步 `row` 加一或 `col` 減一，兩者合計至多走 `n + m` 步，指標必然走出邊界或找到目標。

## 逐步演算法

從右上角開始；比較當前值與目標，相等即回傳；偏大則左移一格，偏小則下移一格；走出邊界表示不存在。

## C++17 模板

```cpp
class Solution {
public:
    bool searchMatrix(vector<vector<int>>& matrix, int target) {
        if (matrix.empty() || matrix[0].empty()) {
            return false;
        }
        int row = 0, col = matrix[0].size() - 1;  // 從右上角出發

        while (row < static_cast<int>(matrix.size()) && col >= 0) {
            const int value = matrix[row][col];
            if (value == target) {
                return true;
            }
            if (value > target) {
                --col;
            }  // 整列作廢
            else {
                ++row;
            }  // 整行作廢
        }
        return false;
    }
};
```

統計負數個數時，走到某個負數就知道它右側整列皆為負，可一次累加 `matrix[0].size() - col`，同樣是 $O(n + m)$。

## 時間與空間複雜度

每步排除一整行或一整列，時間 $O(n + m)$，空間 $O(1)$。相較之下逐列二分為 $O(n \log m)$，在方陣上兩者接近，但雙指標實作更簡單。

## 常見錯誤與邊界條件

- 從左上角或右下角出發（無法排除，退化成全掃）。
- 邊界條件寫成 `col > 0` 而漏掉第 0 列。
- 未處理空矩陣。
- 把「每列遞增且每行遞增」誤當成「攤平後整體有序」——後者才能直接對整個矩陣二分。

## 與相似技巧的比較

若矩陣攤平後整體有序（每行首元素大於上一行末元素），直接把二維下標映射成一維做二分，時間 $O(\log(nm))$；逐列二分適用於行間無關係的情形；本節的階梯走法只需要「行列各自有序」這個較弱的條件。

## 本節重點速查

- 從右上或左下出發；
- 大了向左、小了向下；
- 每步砍掉一整條；
- $O(n+m)$ 且空間 $O(1)$。
