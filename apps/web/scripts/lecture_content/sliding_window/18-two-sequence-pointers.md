## 這個技術解決什麼問題

兩個序列各配一個指標，依比較結果決定推進哪一邊，在一次線性掃描中完成合併、求交集、對齊或配對。適用於合併有序陣列、兩陣列交集、區間列表的交集、比較含退格的字串。

## 辨識題型的訊號

輸入是兩個序列（通常已排序或本身有序，例如按起點排序的區間）；要輸出兩者的合併、交集、差集，或逐項對齊比較。

## 核心想法與直覺

每一輪只做一個決定：比較兩個指標當前指向的元素，推進「較小的那一個」。因為序列有序，較小的那個元素不可能再與對面尚未檢視的任何元素配對成功（那些都更大），所以可以安全地消耗掉它。

區間問題的變形是：交集由 `max(起點)` 與 `min(終點)` 決定，而推進哪一邊取決於誰先結束——終點較小的那個區間不可能再與後續區間相交。

## 狀態／資料結構定義

`i` 與 `j` 分別是兩個序列的游標。已處理的部分是 `a[0..i)` 與 `b[0..j)`，兩者都只前進不回頭。

## 不變量或正確性證明

不變量：所有尚未產生的答案元素，其來源下標都不小於 `i` 與 `j`。

證明推進的安全性（以求交集為例）：設 `a[i] < b[j]`。因為 `b` 遞增，對任意 `j' >= j` 有 `b[j'] >= b[j] > a[i]`，故 `a[i]` 不可能與 `b` 中任何尚未檢視的元素相等，推進 `i` 不會丟失交集元素。對稱地 `a[i] > b[j]` 時推進 `j` 安全。相等時兩者同時推進並輸出一個結果。

區間交集的正確性：設兩區間為 `A = [a1, a2]`、`B = [b1, b2]`，其交集為 `[max(a1,b1), min(a2,b2)]`，非空當且僅當該下界不超過上界。若 `a2 < b2`，則 `A` 與 `B` 之後的所有區間（起點更大、終點更大）的交集都不會再用到 `A`——因為 `A` 已在 `b2` 之前結束，故推進 `A` 側安全。

終止性：每輪至少一個指標前進，總步數不超過 `|a| + |b|`。

## 逐步演算法

兩個游標歸零；當兩者都未走完時比較當前元素，依規則輸出並推進較小的一側；某一側走完後，視題意決定是否把另一側剩餘部分接上。

## C++17 模板

兩個有序陣列的交集（保留重複次數）：

```cpp
vector<int> intersect(vector<int>& a, vector<int>& b) {
    sort(a.begin(), a.end());
    sort(b.begin(), b.end());
    vector<int> answer;
    size_t i = 0, j = 0;

    while (i < a.size() && j < b.size()) {
        if (a[i] < b[j]) {
            ++i;
        } else if (a[i] > b[j]) {
            ++j;
        } else {
            answer.push_back(a[i]);
            ++i;
            ++j;
        }
    }
    return answer;
}
```

區間列表的交集：

```cpp
while (i < A.size() && j < B.size()) {
    const int low = max(A[i][0], B[j][0]);
    const int high = min(A[i][1], B[j][1]);
    if (low <= high) {
        answer.push_back({low, high});
    }
    if (A[i][1] < B[j][1]) {
        ++i;
    } else {
        ++j;
    }  // 先結束的先退場
}
```

合併有序陣列且要求原地時，從**後往前**寫入可避免覆蓋尚未讀取的資料——這是 `nums1` 有預留空間那類題目的關鍵技巧。

## 時間與空間複雜度

時間 $O(|a| + |b|)$（若需先排序則為 $O(n \log n)$），空間 $O(1)$ 不計輸出。

## 常見錯誤與邊界條件

- 相等時只推進一側造成重複輸出或死迴圈。
- 某一側走完後忘記處理另一側的剩餘元素（合併類題目必須接上）。
- 原地合併時由前往後寫而覆蓋未讀資料。
- 區間題判斷相交寫成 `low < high` 而漏掉單點相交。
- 未排序就直接套用。

## 與相似技巧的比較

雜湊表求交集不需排序、期望 $O(n)$，但無法保持有序輸出，且在需要「按序輸出」或「處理區間」時不適用；相向雙指標處理的是同一個序列的兩端，本節處理的是兩個獨立序列，雖然都叫雙指標但推進規則完全不同。

## 本節重點速查

- 推進較小的一側；
- 相等時兩側同時動；
- 先結束的區間先退場；
- 原地合併要從後往前寫。
