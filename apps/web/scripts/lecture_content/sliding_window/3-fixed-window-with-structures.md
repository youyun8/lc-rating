## 這個技術解決什麼問題

定長視窗裡要查詢的不是總和這種可加可減的量，而是「最接近某值的元素」「第 `k` 小」「有序排名」。這時需要在視窗上掛一個支援插入、刪除與有序查詢的結構。

## 辨識題型的訊號

在長度固定的視窗內問「是否存在兩數之差不超過 `t`」「中位數是多少」「前 `k` 小的和」；或值域很小而可以用計數桶取代有序結構。

## 核心想法與直覺

總和之所以能 $O(1)$ 維護，是因為它對加減封閉。有序性不具這個性質——移除一個元素後無法從舊的排名推出新的排名。因此改用兩類工具：

一是**有序集合**（`multiset`），插入與刪除為 $O(\log k)$，並可用 `lower_bound` 找到最接近的元素。二是**桶／計數陣列**，當值域有限時，把元素映射到桶中，同桶即代表差值必定夠小，相鄰桶再逐一檢查，可做到 $O(1)$ 均攤。

## 狀態／資料結構定義

`window` 為 `multiset<long long>`，內容恰為當前視窗中的元素（含重複）。桶做法則用 `unordered_map<long long, long long>`，鍵為桶編號 `floor(value / (t + 1))`。

## 不變量或正確性證明

不變量：`window` 的內容恆等於區間 `[right - k + 1, right]` 中的所有元素，重複次數一致。

由此可證「存在差值不超過 `t` 的一對」的判定是正確的：對新加入的 `x`，只需在集合中找第一個不小於 `x - t` 的元素 `y`；若 `y` 存在且 `y <= x + t`，即找到一對。反之若不存在這樣的 `y`，則集合中所有元素要嘛小於 `x - t`、要嘛大於 `x + t`，與 `x` 的差都超過 `t`。因為每個元素在加入時都與當時視窗中的全部元素做過這個檢查，任何一對合法組合都會在較晚者加入時被發現，故不漏判。

桶做法的正確性：桶寬取 `t + 1`，同一桶內任兩元素之差至多為 `t`，故同桶命中即可直接回答；差值不超過 `t` 的兩個元素若不同桶，桶編號必定相鄰，因此只需再檢查左右各一個桶。

## 逐步演算法

沿用定長滑窗骨架；加入新元素前先在結構中查詢是否已有滿足條件的元素；把新元素插入結構；視窗超長時刪除最左元素對應的那一份。

## C++17 模板

存在重複元素 III（視窗長 `k`，問是否有兩數之差不超過 `t`）：

```cpp
class Solution {
public:
    bool containsNearbyAlmostDuplicate(vector<int>& nums, int k, int t) {
        if (k <= 0 || t < 0) {
            return false;
        }
        multiset<long long> window;

        for (int i = 0; i < static_cast<int>(nums.size()); ++i) {
            const long long x = nums[i];
            auto it = window.lower_bound(x - t);  // 第一個 >= x - t
            if (it != window.end() && *it <= x + t) {
                return true;
            }

            window.insert(x);
            if (static_cast<int>(window.size()) > k) {
                window.erase(
                    window.find(nums[i - k]));  // 只刪一份，不可用 erase(value)
            }
        }
        return false;
    }
};
```

值域有限時改用桶，均攤 $O(1)$：

```cpp
auto bucketOf = [&](long long v) {
    return v >= 0 ? v / (t + 1) : (v + 1) / (t + 1) - 1;  // 負數要向下取整
};
```

## 時間與空間複雜度

有序集合做法為 $O(n \log k)$ 時間、$O(k)$ 空間；桶做法為 $O(n)$ 均攤時間、$O(k)$ 空間。

## 常見錯誤與邊界條件

- 刪除時用 `window.erase(value)` 一次刪光所有相同值（必須用 `erase(find(value))` 只刪一份）。
- 相減溢位需轉 `long long`。
- `t` 為 0 時桶寬 `t + 1` 為 1，仍正確。
- 負數除法在 C++ 中向零取整，桶編號需特別處理。
- `k <= 0` 應直接回傳 false。

## 與相似技巧的比較

單調佇列在定長視窗上維護最大／最小值只需 $O(1)$ 均攤，遠優於有序集合，但它只能回答極值、無法回答「第 `k` 小」或「最接近」；對頂堆（大根堆加小根堆）適合維護中位數；有序集合最通用但常數最大。依查詢種類選擇，不要一律用 `multiset`。

## 本節重點速查

- 有序性不可加減，要掛結構；
- `erase(find(v))` 只刪一份；
- 桶寬取 `t + 1`；
- 只問極值就改用單調佇列。
