## 這個技術解決什麼問題

這一節收攏幾個不屬於前面任一模式、但各自有代表性的鏈表題型：深拷貝帶隨機指標的鏈（138）、扁平化多層雙向鏈（430）、隨機取樣（382）、以及以鏈為底層的迭代器設計（1265）。

它們的共同處是：**原本的「一趟掃描」不夠用，因為節點之間存在第二種連結關係**（`random` 指標、`child` 指標）或**輸入長度未知**（串流取樣）。解法各自不同，但都圍繞「如何在不能回頭、不能隨機存取的限制下建立節點之間的對應」。

## 狀態／資料結構定義

- 深拷貝（138）：需要一組「原節點 → 新節點」的對應。兩種做法——用 `unordered_map<Node*, Node*>` 明確存，或用**交錯法**把新節點暫時插在原節點之後，讓對應關係隱含在 `cur->next` 裡。
- 扁平化（430）：用堆疊存「待接回的後繼」，或遞迴處理 `child` 後回傳該子鏈的尾。核心狀態是「這一層還沒接回的 `next`」。
- 隨機取樣（382）：狀態只有 `chosen` 與已看過的個數 `i`。
- 迭代器（1265）：狀態是遞迴堆疊或顯式堆疊。

## 不變量或正確性證明

**交錯法深拷貝的不變量。** 分三趟，每趟結束時都有明確的結構性質：

1. 第一趟後，鏈形如 $A \to A' \to B \to B' \to \dots$，即每個原節點 $X$ 之後緊跟其複本 $X'$。此時**「$X$ 的複本」可以 $O(1)$ 取得，就是 `X->next`**——這正是交錯法用結構替代雜湊表的地方。
2. 第二趟設定隨機指標：`X'->random = X->random->next`。正確性直接來自性質 1：`X->random` 是某個原節點 $Y$，而 $Y$ 的複本正是 `Y->next`。必須先完成整個第一趟才能做第二趟，因為 `X->random` 可能指向鏈中任意位置（包括尚未走到的後方），只有全部複本都就位後這個等式才對每個 $X$ 都成立。這是「為什麼不能一趟做完」的實質理由。
3. 第三趟拆鏈，把原鏈與新鏈的 `next` 各自還原。若題目要求不修改輸入，這一趟不可省。

`X->random` 可能為 `nullptr`，此時 `X'->random` 也要是 `nullptr`，不能寫成 `X->random->next` 而解參考空指標。

**扁平化（430）的正確性**用結構歸納：對節點 `cur`，若無 `child` 則直接前進；若有 `child`，遞迴扁平化該子鏈得到一條無 `child` 的雙向鏈及其尾節點 `t`，然後把 `cur->next` 暫存為 `nxt`，接成 `cur -> child... -> t -> nxt`，並清空 `cur->child`。歸納假設保證子鏈已無巢狀，故接回後 `cur` 到 `t` 這段也無巢狀。**必須先存 `nxt` 再改 `cur->next`**，否則後半鏈遺失；且**必須清空 `child`**，否則題目要求的「不再有 child」不成立。雙向鏈還要同步設定 `prev`，漏掉時單向遍歷看似正確、反向遍歷才會出錯。

**蓄水池取樣（382）的正確性。** 演算法：看到第 $i$ 個節點（從 1 起算）時，以機率 $1/i$ 用它取代目前選中的值。宣稱：掃完 $n$ 個節點後，每個節點被選中的機率都是 $1/n$。

歸納證明。$n = 1$ 時必選第一個，機率 1，成立。設對長度 $n-1$ 成立，考慮長度 $n$：第 $n$ 個節點被選中的機率依規則為 $1/n$。對 $j < n$ 的節點，它要留到最後，必須先在前 $n-1$ 步中被選中（歸納假設，機率 $\frac{1}{n-1}$），且第 $n$ 步沒有被取代（機率 $1 - \frac1n = \frac{n-1}{n}$）。兩者獨立，故機率為 $\frac{1}{n-1} \cdot \frac{n-1}{n} = \frac1n$。所有節點機率相同，得證。

這個證明的價值在於它解釋了**為何機率必須恰為 $1/i$ 而非某個固定值**：正是 $\frac{1}{i-1} \cdot \frac{i-1}{i}$ 的伸縮相消讓每一步都把機率重新攤平。也解釋了為何這個方法不需要事先知道 $n$——每一步的規則只用到 $i$。

## C++17 模板

```cpp
// 深拷貝帶隨機指標的鏈（LeetCode 138），交錯法，O(1) 額外空間。
Node* copyRandomList(Node* head) {
    if (!head) {
        return nullptr;
    }

    for (Node* cur = head; cur;
         cur = cur->next->next) {  // 1. 複本插在原節點之後
        Node* copy = new Node(cur->val);
        copy->next = cur->next;
        cur->next = copy;
    }

    for (Node* cur = head; cur;
         cur = cur->next->next) {  // 2. 靠交錯結構設隨機指標
        if (cur->random) {
            cur->next->random = cur->random->next;
        }
    }

    Node dummy;  // 3. 拆開兩條鏈
    Node* tail = &dummy;
    for (Node* cur = head; cur; cur = cur->next) {
        Node* copy = cur->next;
        cur->next = copy->next;  // 還原原鏈
        tail->next = copy;
        tail = copy;
    }
    return dummy.next;
}
```

蓄水池取樣（LeetCode 382）：

```cpp
int getRandom() {
    int chosen = 0, i = 0;
    for (ListNode* cur = head_; cur; cur = cur->next) {
        if (rand() % (++i) == 0) {
            chosen = cur->val;
        }  // 第 i 個以 1/i 取代
    }
    return chosen;
}
```

## 時間與空間複雜度

深拷貝：交錯法三趟各 $O(n)$，總計 $O(n)$ 時間、$O(1)$ 額外空間（不計新節點本身）；雜湊表法同為 $O(n)$ 時間但額外 $O(n)$ 空間，程式碼短很多。

扁平化：每個節點恰被走訪一次，$O(n)$ 時間；遞迴版空間 $O(d)$（$d$ 為巢狀深度，最壞 $O(n)$），堆疊版相同。

蓄水池取樣：每次 `getRandom` 都要走完整條鏈，$O(n)$ 時間、$O(1)$ 空間。若鏈長固定且允許預處理，倒成陣列後可 $O(1)$ 查詢但需 $O(n)$ 空間——蓄水池的優勢在於**長度未知或資料為串流**時仍然可用。

## 常見錯誤與邊界條件

- 深拷貝把三趟合成一趟，導致 `X->random` 指向後方尚未建立複本的節點時取到錯的值。
- `random` 為 `nullptr` 時解參考。
- 第三趟忘記還原原鏈的 `next`（題目通常要求輸入不被破壞）。
- 扁平化忘記清空 `child` 或忘記設定 `prev`。
- 扁平化改 `cur->next` 前沒先存後半鏈。
- 蓄水池用 `rand() % i` 卻從 $i=0$ 起算而除以零。
- 空鏈輸入。

## 與相似技巧的比較

- 交錯法與雜湊表法的取捨很典型：前者 $O(1)$ 空間但要三趟且會暫時破壞輸入結構，後者好寫但吃 $O(n)$ 空間。面試若限定 $O(1)$ 空間，答案就是交錯法。
- 扁平化與二元樹的前序展開（114，見 2.14）是同一個問題的兩種外觀，都是「把巢狀結構壓成單鏈，注意先存後繼再改指標」。
- 蓄水池取樣可推廣到取 $k$ 個：前 $k$ 個直接放入，第 $i > k$ 個以 $k/i$ 的機率替換其中隨機一個，證明方式與上面完全平行。

## 本節重點速查

- 深拷貝用交錯法：插複本、設 random、拆鏈，三趟不能合併。
- 扁平化先存後繼再接子鏈，記得清 `child` 補 `prev`。
- 蓄水池取樣第 $i$ 個以 $1/i$ 取代，$1/i$ 這個值由歸納證明中的伸縮相消決定，不能改。
