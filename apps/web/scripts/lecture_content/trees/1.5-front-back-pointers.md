## 這個技術解決什麼問題

「刪除倒數第 $n$ 個節點」（19）這種需求，直覺做法是先走一趟數長度 $L$，再走一趟到第 $L-n$ 個。兩趟都是 $O(n)$，總體沒變差，但題目常追問「能不能一趟完成」，而且在串流情境下你根本無法回到頭再走第二次。

前後指標的槓桿是：**用兩個相距固定 $k$ 步的指標，把「倒數第 $k$」轉換成「前指標到終點時，後指標所在位置」**。距離差一旦建立就自動維持，不需要知道總長度。

**延伸講解**：[刪除鏈表重複節點【基礎演算法精講 08】](https://www.bilibili.com/video/BV1VP4y1Q71e/)

## 狀態／資料結構定義

- `fast`：前指標，先走 $k$ 步。
- `slow`：後指標，從 `dummy`（而非 `head`）出發——因為刪除需要的是**目標的前驅**，從 dummy 起跑剛好讓 `slow` 停在前驅上，也順帶處理「刪的就是頭節點」。
- 間距 $k$：兩指標之間的邊數，是整個技巧的核心量，必須在迴圈中保持不變。

旋轉串列（61）的變體：先數長度 $L$，把 $k$ 取模成 $k \bmod L$，再用間距 $L - k \bmod L$ 找到新尾。這裡取模是必要的，否則 $k$ 可能遠大於 $L$。

## 不變量或正確性證明

不變量：**建立間距之後，每輪開始時 `fast` 與 `slow` 之間恰隔 $k$ 條邊。**

- 初始化：讓 `fast` 單獨走 $k$ 步，`slow` 不動，間距為 $k$。
- 保持：迴圈本體同時執行 `fast = fast->next` 與 `slow = slow->next`，兩者各前進一步，差值不變。
- 終止：以 `fast == nullptr` 為條件退出時，`fast` 走過的總步數等於串列長度 $L$（從 `head` 起算需 $L$ 步才到 `nullptr`）。因此 `slow` 從 `dummy` 起走了 $L - k$ 步，停在第 $L-k$ 個節點上（`dummy` 記為第 0 個），它的後繼是第 $L-k+1$ 個節點，也就是**倒數第 $k$ 個**。於是 `slow->next` 正是待刪節點，`slow` 是其前驅。

正確性依賴兩個前提。其一，$k \le L$，否則初始那 $k$ 步就會走出串列外而解參考空指標；題目保證 $n \le L$ 時可省略檢查，否則要顯式判斷。其二，退出條件與起跑點必須配套：`slow` 從 `dummy` 起跑、`fast` 從 `head` 起跑並以 `fast == nullptr` 退出，三者搭配才會落在前驅；把 `slow` 改成從 `head` 起跑就會停在待刪節點自己，拿不到前驅。這組偏移量是最常寫錯的地方，建議用 $L = k$（刪頭）與 $k = 1$（刪尾）兩個極端案例各驗一次。

## C++17 模板

```cpp
// 刪除倒數第 n 個節點（LeetCode 19），一趟完成。
ListNode* removeNthFromEnd(ListNode* head, int n) {
    ListNode dummy;
    dummy.next = head;

    ListNode* fast = head;  // 前指標從 head 起跑
    for (int i = 0; i < n; ++i) {
        fast = fast->next;
    }  // 先拉開 n 條邊的間距

    ListNode* slow = &dummy;  // 後指標從 dummy 起跑，才會停在「前驅」
    while (fast) {            // 同步前進，間距恆為 n
        fast = fast->next;
        slow = slow->next;
    }

    slow->next = slow->next->next;  // slow 正是倒數第 n 個的前驅
    return dummy.next;
}
```

## 時間與空間複雜度

`fast` 總共走 $L$ 步、`slow` 走 $L-k$ 步，時間 $O(n)$ 且**只掃一趟**；空間 $O(1)$。與「先數長度再走」的兩趟版相比漸近同階，差別在常數（$L$ 對 $2L$）與能否處理不可重讀的串流輸入。

## 常見錯誤與邊界條件

- `slow` 從 `head` 而非 `dummy` 起跑，結果停在待刪節點本身而拿不到前驅。
- 初始間距多走或少走一步（用刪頭、刪尾兩個極端案例驗證）。
- `n` 大於長度時初始迴圈解參考空指標。
- 刪除頭節點後回傳 `head` 而非 `dummy.next`。
- 旋轉串列忘記 `k %= L` 而白繞很多圈，或 `L` 為 0 時取模除以零。
- 只有一個節點的串列。

## 與相似技巧的比較

- 快慢指標（1.6）是**速度比**不同（一次一步對一次兩步），本節是**固定間距**、速度相同；前者用來找中點與判環，後者用來定位倒數第 $k$。
- 陣列裡「倒數第 $k$」直接用 `a[n-k]`，不需要這個技巧——它存在的唯一理由就是連結串列不能隨機存取。
- 若要同時取得長度與位置，兩趟寫法更直白，程式碼也更難寫錯；一趟版主要是面試要求與串流場景。

## 本節重點速查

- 先讓 `fast` 走 $k$ 步拉開間距，再兩者同步前進；
- `fast` 到 `nullptr` 時 `slow` 就位。
- `slow` 從 `dummy` 起跑才能停在前驅。
- 不變量是「間距恆為 $k$」，偏移量用刪頭與刪尾兩個極端案例校準。
