## 這個技術解決什麼問題

這一節處理樹與鏈之間的相互轉換：把有序鏈建成平衡 BST（109）、把二元樹展平成單鏈（114）、把 BST 轉成有序雙向循環鏈（426）、在每層節點間串上 `next` 指標（116、117）。

它們的共同挑戰是**兩種結構的訪問模式不相容**：樹允許遞迴分治但鏈只能順序前進；鏈無法 $O(1)$ 取中點但樹的分治需要它。解法通常是「找到一個讓兩者對齊的遍歷順序」——多半是中序（對 BST）或前序（對展平）。

## 狀態／資料結構定義

- **109（有序鏈建平衡 BST）**：樸素做法每層用快慢指標找中點（$O(n \log n)$）。更好的做法是**中序模擬**：先數出長度 $n$，然後 `build(l, r)` 依中序順序遞迴——先建左子樹，此時全域游標 `cur` 恰好停在應作為根的節點上，取它的值後把 `cur` 前進，再建右子樹。狀態只有一個全域游標 `cur` 與區間 $[l, r]$。
- **114（展平成前序單鏈）**：用「反前序」（右 → 左 → 根）遍歷，全域 `prev` 記錄上一個處理過的節點，處理當前節點時執行 `node->right = prev; node->left = nullptr; prev = node;`。
- **426（BST 轉雙向循環鏈）**：中序遍歷，`prev` 記錄中序前驅，訪問時互相接上 `prev->right = cur; cur->left = prev;`，最後把頭尾相連。
- **116／117（連接 next 指標）**：116 是完美二元樹，可用 `next` 指標本身當作「當前層的鏈」逐層下推，$O(1)$ 空間；117 是任意二元樹，需用 dummy 加 tail 逐層串接（1.7 的分鏈手法）。

## 不變量或正確性證明

**109 中序模擬的正確性。** 關鍵洞察：由 2.9 的等價性，一棵 BST 的中序序列就是有序序列。反過來，若我們**先決定樹的形狀**（由 `build(l, r)` 的區間切分決定），再按中序順序把有序鏈的值依次填入，得到的必然是一棵 BST。

不變量：**呼叫 `build(l, r)` 時，全域游標 `cur` 恰指向鏈中第 $l$ 個節點（0 起算）；返回時 `cur` 指向第 $r+1$ 個。**

- 基底：$l > r$ 時不消耗任何節點，直接返回，成立。
- 保持：設 `m = (l + r) / 2`。先呼叫 `build(l, m - 1)`，由歸納假設它消耗第 $l$ 到 $m-1$ 個節點，返回時 `cur` 指向第 $m$ 個。此時取 `cur->val` 作為當前子樹的根值，並把 `cur` 前進一格（指向第 $m+1$ 個）。再呼叫 `build(m + 1, r)`，由歸納假設消耗第 $m+1$ 到 $r$ 個，返回時指向第 $r+1$ 個。整段恰消耗 $[l, r]$，不變量維持。
- 由於填入順序嚴格按中序、鏈本身遞增，故中序序列遞增，由 2.9 得結果是 BST。平衡性則由「每次取中點切分」保證，論證同 108。

**這個做法的價值在於把「找中點」從 $O(n)$ 降到 $O(1)$**——形狀由下標算術決定，值由順序游標供給，兩者解耦。這是本節最值得學的一招。

**114 為何用反前序。** 目標是把樹改成一條「按前序排列、全部掛在右指標上」的鏈。若用正前序處理，改動 `node->right` 時會弄丟原本的右子樹（它還沒被處理）。反前序（右 → 左 → 根）則保證：處理到 `node` 時，它的左右子樹都已經被展平並串好，而 `prev` 正指向**前序序列中緊接 `node` 之後的那個節點**。

為什麼 `prev` 恰是前序後繼？反前序的訪問序列是前序序列的完全逆序（前序是「根、左、右」，反前序是「右、左、根」，兩者互為逆序，可用結構歸納證明）。因此在反前序中「上一個被處理的節點」，在前序中就是「下一個節點」。於是 `node->right = prev` 直接接對，`node->left = nullptr` 清掉左指標。

**426 的中序串接**同理：中序序列即有序序列，`prev` 是中序前驅，雙向接上即可。收尾要把最後一個節點與第一個節點相連成環，且**必須在遞迴全部結束後做**，因為在遞迴中無法得知誰是最後一個。

**116 為何能 $O(1)$ 空間。** 完美二元樹中每個節點要嘛有兩個子、要嘛沒有。處理第 $d$ 層時，該層的 `next` 指標已全部串好，於是可以沿著這條鏈走訪本層所有節點，並為第 $d+1$ 層建立連接：`node->left->next = node->right;`（同一父親），`node->right->next = node->next ? node->next->left : nullptr;`（跨父親，靠本層的 `next` 找到右邊的兄弟）。不變量是「處理第 $d+1$ 層時，第 $d$ 層的 `next` 已完整」，歸納即得。**這條論證依賴完美二元樹的性質**：跨父親連接時 `node->next->left` 必定存在。117 中它可能為空，必須逐個往右找第一個有子節點的兄弟，故改用 dummy 加 tail 更穩妥。

## C++17 模板

```cpp
// 有序鏈建平衡 BST（LeetCode 109）：中序模擬，O(n) 時間。
class Solution {
    ListNode* cur_ = nullptr;

    TreeNode* build(int l, int r) {
        if (l > r) {
            return nullptr;
        }
        int m = l + (r - l) / 2;

        TreeNode* left = build(l, m - 1);  // 先建左子樹，cur_ 隨之推進
        TreeNode* root = new TreeNode(cur_->val);  // 此刻 cur_ 恰是本子樹的根
        cur_ = cur_->next;
        root->left = left;
        root->right = build(m + 1, r);  // 再建右子樹
        return root;
    }

public:
    TreeNode* sortedListToBST(ListNode* head) {
        int n = 0;
        for (ListNode* p = head; p; p = p->next) {
            ++n;
        }
        cur_ = head;
        return build(0, n - 1);
    }
};
```

展平二元樹（LeetCode 114）：

```cpp
class Solution {
    TreeNode* prev_ = nullptr;

public:
    void flatten(TreeNode* root) {
        if (!root) {
            return;
        }
        flatten(root->right);  // 反前序：右 -> 左 -> 根
        flatten(root->left);
        root->right = prev_;  // prev_ 正是前序中的後繼
        root->left = nullptr;
        prev_ = root;
    }
};
```

## 時間與空間複雜度

109 中序模擬：數長度 $O(n)$，建樹每個節點 $O(1)$，總計 $O(n)$ 時間、$O(\log n)$ 堆疊。樸素的「每層快慢指標找中點」是 $T(n) = 2T(n/2) + O(n) = O(n \log n)$——差別正是找中點的成本。

114、426：$O(n)$ 時間、$O(h)$ 堆疊。114 有 $O(1)$ 空間的 Morris 式解法（利用左子樹最右節點接上原右子樹），值得一提但較繁瑣。

116：$O(n)$ 時間、$O(1)$ 空間（利用已建好的 `next` 當作層鏈）。117 用 dummy 加 tail 同樣 $O(1)$ 空間。用 BFS 做則是 $O(w)$ 空間。

## 常見錯誤與邊界條件

- 109 用樸素找中點而在大測資超時，或切分時忘記斷開鏈導致無限遞迴。
- 109 的中序模擬中，把 `build(l, m-1)` 的結果先賦給 `root->left` 再取 `cur_`（求值順序不保證，必須先存進區域變數）。
- 114 用正前序而弄丟右子樹。
- 114 忘記把 `left` 設為 `nullptr`。
- 426 忘記最後首尾相連，或在遞迴中途就嘗試連環。
- 117 誤用 116 的解法而在缺子節點處連錯。
- 空輸入。

## 與相似技巧的比較

- 109 與 108（有序陣列建 BST，見 2.10）目標相同，差別只在資料來源能否隨機存取；中序模擬正是為了彌補這個差距。
- 114 與 430（扁平化多層雙向鏈，見 1.11）是同一個「壓平巢狀結構」的問題，都要注意先保存後繼再改指標；114 用反向遍歷繞開了這個問題，430 用堆疊或遞迴回傳尾節點。
- 116／117 的逐層串接與 1.7 的分鏈手法同構，都是 dummy 加 tail。
- 426 與 2.9 的中序法共用「一個 `prev` 變數」的骨架，差別只在做的事情是比較還是接指標。

## 本節重點速查

- 樹與鏈的轉換靠「找到讓兩者對齊的遍歷順序」。
- 109 用**中序模擬**：形狀由下標切分決定、值由順序游標供給，把找中點從 $O(n)$ 降到 $O(1)$。
- 114 用**反前序**（右→左→根），`prev` 恰是前序後繼。
- 426 用中序加 `prev`，最後才連環。
- 116 靠完美樹性質用 `next` 當層鏈達成 $O(1)$ 空間，117 不行，改用 dummy 加 tail。
