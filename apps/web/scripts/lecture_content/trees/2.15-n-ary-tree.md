## 這個技術解決什麼問題

N 叉樹的每個節點有一個子節點串列 `vector<Node*> children`，而非固定的 `left`／`right`。它是二元樹的直接推廣，也是一般樹（3.x）的具體表示。

本節的重點不是新技巧，而是**辨認哪些二元樹的手法能無痛遷移、哪些會失效**。答案很乾脆：所有基於「前序／後序」的技巧照搬即可，把兩次遞迴換成對 `children` 的迴圈；**只有中序遍歷失去意義**——子節點超過兩個時，「根該插在第幾個子樹之後」沒有標準答案。這也連帶讓所有依賴「中序即有序」的 BST 技巧（2.9）在 N 叉樹上無對應。

## 狀態／資料結構定義

- `struct Node { int val; vector<Node*> children; };`
- 前序 DFS：處理自己，再 `for (Node* c : node->children) dfs(c);`
- 後序 DFS：先迴圈遞迴，再處理自己；彙總量用累加或取最值的方式合併所有子節點的回傳值，**初始值必須是該運算的單位元**（求和用 0，求最大值用 `INT_MIN` 或第一個子節點的值）。
- BFS（429）：與 2.13 完全相同，只是入隊時改成迴圈把所有子節點推入。
- 序列化（428）：因為子節點數不固定，序列中必須額外編碼「這個節點有幾個子」或使用括號、哨兵標記。

## 不變量或正確性證明

**遍歷的完備性**與 2.1 的論證同構，只是劃分從「左子樹、右子樹、根」三塊變成「$k$ 棵子樹、根」共 $k+1$ 塊。歸納步驟仍然成立，因為 N 叉樹的關鍵性質未變：**各子樹的節點集合兩兩不交，且與根的並集是整棵子樹**。這條性質是所有樹上遞迴的根基，它與子節點數目無關，這正是二元樹技巧能整批遷移的理由。

**後序彙總的正確性**同樣是結構歸納，合併規則從 `combine(f(L), f(R), v)` 變成 $\text{fold}$：

$$f(v) = g\big(v,\ \bigoplus_{c \in \text{children}(v)} f(c)\big)$$

要求 $\oplus$ 是**可結合的**（結合律），否則對 `children` 的迴圈順序會影響結果。求和、取最大值、取最小值都滿足；「減法」「除法」不滿足，遇到這類彙總要重新設計。這是二元樹版本裡看不出來的隱含條件——只有兩個運算元時結合律不會被觸發。

**N 叉樹直徑的推廣。** 2.6 的「枚舉最高點」分解在 N 叉樹上完全成立（該證明只用到「路徑的最高點唯一」，與分支數無關）。差別在於：以 $v$ 為最高點的最長路徑，是從 $v$ 的所有子節點中取**向下最長鏈的前兩大**相加，而不是簡單的「左 + 右」。

實作上不需要排序：邊迴圈邊維護 `max1 >= max2` 兩個變數即可，$O(k)$ 而非 $O(k \log k)$。更新順序要小心——**必須先用當前子節點的值嘗試更新 `max1`，若被擠下來的舊 `max1` 再成為 `max2`**，寫成兩個獨立的 `if` 會漏掉「新值同時大於兩者」的情形。

**N 叉樹的最大深度（559）**：$h(v) = 1 + \max_{c} h(c)$，葉節點（`children` 為空）的 $\max$ 為空集合，必須特別處理——回傳 1 而非 $1 + (-\infty)$。這正是「單位元選錯」在 N 叉樹上的具體表現：對 `max` 運算，空集合的單位元是 $-\infty$，但這裡的語意是「沒有子節點時深度為 1」，用 0 作為初始值（代表「空子樹高度 0」）才對。

**428 序列化的唯一性。** 二元樹靠固定的兩個位置（含空標記）就能還原；N 叉樹不行，因為讀到一串子節點時不知道何時該停。必須顯式編碼子節點數量，或用配對的括號／終止哨兵界定範圍。這是「N 叉」相對「二元」真正多出來的困難，不是遍歷順序的問題。

## C++17 模板

```cpp
// N 叉樹的最大深度（LeetCode 559）與後序彙總骨架。
int maxDepth(Node* root) {
    if (!root) {
        return 0;
    }  // 單位元：空子樹深度 0
    int best = 0;
    for (Node* c : root->children) {  // 兩次遞迴換成對 children 的迴圈
        best = std::max(best, maxDepth(c));
    }
    return 1 + best;  // children 為空時自然回傳 1
}
```

N 叉樹直徑（取前兩大向下鏈）：

```cpp
class Solution {
    int ans_ = 0;

    int down(Node* node) {  // 從 node 向下的最長鏈（邊數）
        int max1 = 0, max2 = 0;  // 最大與次大，初值 0 代表「不接任何子」
        for (Node* c : node->children) {
            int d = 1 + down(c);
            if (d > max1) {
                max2 = max1;
                max1 = d;
            }  // 擠下來的舊 max1 成為 max2
            else if (d > max2) {
                max2 = d;
            }
        }
        ans_ = std::max(ans_, max1 + max2);  // 以 node 為最高點，可分叉
        return max1;                         // 上傳必須單邊
    }

public:
    int diameter(Node* root) {
        down(root);
        return ans_;
    }
};
```

## 時間與空間複雜度

設節點數為 $n$、總邊數為 $n - 1$。對 `children` 的迴圈總共執行 $\sum_v |\text{children}(v)| = n - 1$ 次，故所有遍歷仍是 $O(n)$ 時間——**不是 $O(nk)$**，因為 $k$ 是每個節點各自的分支數，總和有界。這個「所有分支數之和等於邊數」的觀察在分析樹上演算法時反覆出現，值得記住。

空間 $O(h)$ 遞迴堆疊（DFS）或 $O(w)$ 佇列（BFS）。直徑的前兩大維護是 $O(k)$ 而非 $O(k \log k)$，故不影響總複雜度。

## 常見錯誤與邊界條件

- 後序彙總的初始值選錯（559 用 `INT_MIN` 導致葉節點回傳錯誤，應用 0）。
- 直徑的前兩大更新寫成兩個獨立 `if`，漏掉新值同時大於兩者的情形。
- 上傳時回傳 `max1 + max2`（分叉值）而非 `max1`。
- `children` 中含有 `nullptr`（多數題目保證沒有，但序列化還原時可能產生）。
- 428 序列化未編碼子節點數量而無法還原。
- 空樹。
- 只有根節點（`children` 為空）。

## 與相似技巧的比較

- 與二元樹（2.x）的對應關係如開頭所述：前序、後序、BFS、直徑、樹形 DP 全部照搬；中序與 BST 的一整套技巧沒有對應。
- 與一般樹（3.x）的差別只在表示法：3.x 用鄰接表加父節點編號（因為輸入常是邊集合，且需要避免走回父節點），2.15 用 `children` 指標（父子關係已由結構給定，不會走回頭）。**這個差別導致 3.x 的 DFS 必須傳入 `fa` 參數，本節不需要。**
- 「左子右兄弟」表示法可把 N 叉樹編碼成二元樹（`left` 指第一個子、`right` 指下一個兄弟），此時 N 叉樹的前序等於該二元樹的前序、N 叉樹的後序等於該二元樹的中序——這是一個有趣的對應，偶爾能把 N 叉問題轉成二元問題。
- 589／590（N 叉樹前序／後序遍歷）的迭代版要注意：用堆疊時子節點需**逆序入棧**才能維持由左至右的訪問順序。

## 本節重點速查

- 兩次遞迴換成對 `children` 的迴圈，其餘照搬二元樹；
- **只有中序與 BST 那一套沒有對應**。
- 後序彙總要求運算可結合，且單位元要與「無子節點」的語意一致。
- 直徑取前兩大向下鏈，更新時記得把被擠下的舊最大值降為次大。
- 總複雜度仍是 $O(n)$，因為所有分支數之和等於邊數。
