## 這個技術解決什麼問題

這一節收攏幾類不屬於前面單一模式的二元樹題：序列化與反序列化（297）、BST 迭代器（173）、完全二元樹的節點計數（222）、樹的垂直遍歷（314）、以及排列序號類的組合題（60）。

它們各自的槓桿不同，但有一個共同主題值得先點出：**當樹具有額外的結構性保證（完全二元樹、BST）時，樸素的 $O(n)$ 遍歷往往可以被壓到 $O(\log^2 n)$ 或 $O(h)$**。看到「完全」「滿」「搜尋樹」這些字眼，就該問「這個保證能省下什麼」。

## 狀態／資料結構定義

- **297 序列化**：選一種遍歷（通常前序），並**顯式輸出空節點標記**（如 `#`）。還原時用一個游標依同樣順序消耗 token。狀態是「輸入串流的當前位置」。
- **173 BST 迭代器**：用堆疊存「當前節點的祖先鏈中，右子樹尚未處理的節點」——與 2.1 迭代中序的堆疊語意完全相同。建構時把根的左鏈全部壓入；`next()` 彈出棧頂、輸出、再把其右子的左鏈壓入。
- **222 完全二元樹計數**：狀態是當前子樹的根與其「左鏈深度」`hl` 與「右鏈深度」`hr`（沿最左／最右一路走到底的深度）。
- **314 垂直遍歷**：給每個節點一個座標 $(col, row)$，根為 $(0,0)$，左子 $(col-1, row+1)$、右子 $(col+1, row+1)$；用 `map<int, vector<pair<int,int>>>` 按 `col` 分組。

## 不變量或正確性證明

**297 為何加上空節點標記就足以還原。** 2.10 已說明單一種遍歷無法唯一確定樹，根本原因是「單子節點的左右歸屬不明」。加上空標記後，前序序列變成對**擴充二元樹**（每個空位補一個外部節點）的前序遍歷，而擴充二元樹中每個內部節點都恰有兩個子節點。

還原的正確性用歸納：讀到一個 token，若是 `#` 則回傳 `nullptr`（消耗一個 token）；否則建立節點，遞迴建左子樹、再遞迴建右子樹。**不變量是「每次呼叫 `deserialize()` 恰好消耗完整描述一棵子樹的那段 token，並回傳其根」**。基底是 `#`（消耗 1 個）。歸納步驟中，左子樹的遞迴消耗完自己那段後，游標恰好停在右子樹描述的開頭——這正是前序序列的定義所保證的。故整個過程無歧義。

這解釋了 2.10 提到的「需要兩種序列的根本原因是空節點資訊遺失」：補回這個資訊，一種序列就夠了。

**222 完全二元樹計數的複雜度論證。** 完全二元樹的定義是「除最後一層外都填滿，且最後一層節點靠左連續」。演算法：對當前子樹，計算最左鏈深度 `hl` 與最右鏈深度 `hr`。

- 若 `hl == hr`，這棵子樹是**滿二元樹**，節點數為 $2^{hl} - 1$，$O(1)$ 得出。要說明這個推論成立：完全二元樹中若最左路徑與最右路徑等長，表示最後一層已填滿（否則最右鏈會短一層），故是滿的。
- 否則遞迴計算 `1 + count(left) + count(right)`。

複雜度的關鍵論證：**在完全二元樹中，任一節點的左右兩棵子樹中，至少有一棵是滿的**。理由：最後一層的節點靠左連續，所以「缺口」只出現在一條從根往下的路徑上；不在這條路徑上的子樹要嘛全滿、要嘛全空。因此遞迴每層只會有**一個**分支真正展開，另一個 $O(1)$ 解決。遞迴深度 $O(\log n)$，每層計算 `hl`、`hr` 各需 $O(\log n)$，總計 $O(\log^2 n)$——遠優於樸素遍歷的 $O(n)$。

**173 迭代器的攤還分析。** 單次 `next()` 最壞需要壓入一整條左鏈，$O(h)$。但每個節點在整個迭代過程中**恰被壓入一次、彈出一次**，故 $n$ 次 `next()` 的總成本是 $O(n)$，**攤還 $O(1)$**。空間 $O(h)$，這正是題目要求「不能預先把所有值倒進陣列」的原因——後者是 $O(n)$ 空間。

**314 垂直遍歷的排序規則。** 同一列（相同 `col`）內，先按 `row` 由小到大；`row` 也相同時，題目通常要求按值排序（987）或按輸入順序（314）。若用 BFS 產生節點，同一 `(col, row)` 的節點天然按由左至右的順序出現，可省去一次排序——這是選 BFS 而非 DFS 的實質理由。

## C++17 模板

```cpp
// 序列化與反序列化（LeetCode 297）：前序 + 空節點標記。
class Codec {
public:
    std::string serialize(TreeNode* root) {
        if (!root) {
            return "#,";
        }  // 空節點也要輸出
        return std::to_string(root->val) + "," + serialize(root->left) +
               serialize(root->right);
    }

    TreeNode* deserialize(const std::string& data) {
        size_t pos = 0;
        return build(data, pos);
    }

private:
    TreeNode* build(const std::string& s, size_t& pos) {  // pos 是共享游標
        size_t comma = s.find(',', pos);
        std::string token = s.substr(pos, comma - pos);
        pos = comma + 1;

        if (token == "#") {
            return nullptr;
        }
        TreeNode* node = new TreeNode(std::stoi(token));
        node->left = build(s, pos);  // 前序保證游標順序正確
        node->right = build(s, pos);
        return node;
    }
};
```

完全二元樹計數（LeetCode 222），$O(\log^2 n)$：

```cpp
int countNodes(TreeNode* root) {
    if (!root) {
        return 0;
    }

    int hl = 0, hr = 0;
    for (TreeNode* p = root; p; p = p->left) {
        ++hl;
    }  // 最左鏈深度
    for (TreeNode* p = root; p; p = p->right) {
        ++hr;
    }  // 最右鏈深度

    if (hl == hr) {
        return (1 << hl) - 1;
    }  // 滿樹，O(1) 算出
    return 1 + countNodes(root->left) + countNodes(root->right);
}
```

## 時間與空間複雜度

297：序列化與反序列化各 $O(n)$ 時間，序列長度 $O(n)$。遞迴 $O(h)$ 堆疊。

173：建構 $O(h)$，`next()` 與 `hasNext()` 攤還 $O(1)$（最壞單次 $O(h)$），空間 $O(h)$。

222：$O(\log^2 n)$ 時間、$O(\log n)$ 堆疊，依據上面的「每層只有一個分支展開」論證。

314／987：$O(n \log n)$ 時間（排序或 `map` 的開銷），$O(n)$ 空間。

## 常見錯誤與邊界條件

- 297 用 `int` 解析而節點值為負或超出範圍。
- 297 的游標未以引用傳遞，各層各自從頭讀。
- 297 序列化格式的分隔符與節點值衝突。
- 222 直接用 $O(n)$ 遍歷（能過但沒抓到題目給「完全二元樹」的用意）。
- 222 的 `1 << hl` 在 `hl` 較大時溢位（用 `1LL`）。
- 173 在建構時就把所有值倒進陣列（違反空間要求）。
- 314 忘記處理同一格多個節點的次序規則。
- 空樹在各題的回傳約定。

## 與相似技巧的比較

- 297 與 2.10 的「兩種序列建樹」互為對照：前者補上空節點資訊所以一種序列就夠，後者靠第二種序列提供切分點。428（N 叉樹序列化）則需編碼子節點數量，見 2.15。
- 173 的堆疊與 2.1 迭代中序完全相同，只是把「一次跑完」拆成「每次吐一個」；這種把遞迴改寫成可暫停的迭代器，是「顯式堆疊」最有價值的用途。
- 222 的「利用結構保證省下遍歷」與 BST 的 $O(h)$ 查找同屬一類思路：額外的結構保證換取複雜度。
- 60（排列序號）其實與樹的關係是概念性的——它在「排列的決策樹」上直接定位第 $k$ 個葉節點，靠的是「以某個數字開頭的排列恰有 $(n-1)!$ 個」這條計數性質，一路除法定位而不必真的建樹。這是「用計數代替搜尋」的典型，與 4.x 的回溯形成對比。

## 本節重點速查

- 看到「完全二元樹」「BST」這類結構保證，先問能省下什麼——222 靠「至少一棵子樹是滿的」把 $O(n)$ 壓到 $O(\log^2 n)$。
- 297 補上空節點標記後單一種前序即可唯一還原，反序列化的游標必須跨遞迴共享。
- 173 用堆疊實作可暫停的中序，攤還 $O(1)$、空間 $O(h)$。
