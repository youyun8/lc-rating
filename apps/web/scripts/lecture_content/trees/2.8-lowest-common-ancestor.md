## 這個技術解決什麼問題

最近公共祖先（LCA）是「同時是 $p$ 與 $q$ 的祖先，且深度最大的那個節點」。它是樹上距離、路徑查詢的基石：$p$ 到 $q$ 的路徑必經 LCA，距離為 $d(p) + d(q) - 2d(\text{LCA})$。

樸素做法是求出根到 $p$、根到 $q$ 的兩條路徑，再找最後一個公共節點，需要 $O(h)$ 空間存路徑。二元樹的遞迴解法把它壓成一次後序遍歷、$O(1)$ 額外空間（不計堆疊），而且程式碼只有幾行——代價是那幾行的正確性並不顯然，值得仔細論證。

## 狀態／資料結構定義

遞迴函式 `lca(node, p, q)` 的回傳值語意必須precise，這是理解本節的全部關鍵：

> **若以 `node` 為根的子樹中同時含有 $p$ 與 $q$，回傳它們的 LCA；若只含其中一個，回傳那一個；若都不含，回傳 `nullptr`。**

注意這是一個**三合一**的語意，而不是「回傳 LCA」。正因為它把「找到了一個」與「找到了答案」用同一個回傳值編碼，程式碼才能這麼短。

BST 版本（235）的狀態更簡單：只需當前節點，靠值的大小關係決定往哪走。

## 不變量或正確性證明

**先證回傳值語意（結構歸納）。** 設遞迴依 `l = lca(node->left)`、`r = lca(node->right)` 展開。

- 基底：`node == nullptr` 回傳 `nullptr`，符合「都不含」。
- `node` 是 $p$ 或 $q$ 時直接回傳 `node`。要說明這不會漏掉「另一個在 `node` 的子樹裡」的情形：若 $q$ 在 $p$ 的子樹中，則 LCA 就是 $p$ 本身，回傳 `node`（$=p$）正確。若 $q$ 不在其中，則此子樹只含 $p$，依語意也該回傳 $p$。兩種情形都對，故可以提前返回、不必再往下找。**這一步依賴「$p$ 與 $q$ 都確實存在於樹中」的前提**；若某個節點可能不存在，這個提前返回會給出錯誤答案（回傳 $p$ 卻宣稱是 LCA），必須改成完整遍歷並額外回報是否兩者都找到。
- 遞迴情形：由歸納假設，`l`、`r` 各自符合語意。
  - `l` 與 `r` 皆非空：表示左子樹含其中一個、右子樹含另一個（各自不可能同時含兩個，否則另一邊就會是空）。故 `node` 同時是兩者的祖先，且沒有更深的公共祖先——任何更深的節點只會落在單側，不可能同時是兩者的祖先。回傳 `node` 正確。
  - 恰一非空：整棵子樹中只在該側找到東西。若該側回傳的是 LCA（兩者都在該側），向上傳遞不改變答案；若該側只含一個，則本子樹也只含一個。兩種情形都該回傳那個非空值，與語意一致。
  - 皆空：本子樹不含 $p$ 也不含 $q$，回傳 `nullptr`。
- 對根呼叫時，由於兩者都在樹中，落入「皆非空」或「node 自己是其中一個」的情形，回傳的必是真正的 LCA。

上面「恰一非空」的分支之所以能不加區分地向上傳遞，正是三合一語意的價值：呼叫者不需要知道那個非空值到底是「LCA」還是「其中一個」，因為兩種情形下的正確動作相同。

**BST 版（235）的正確性。** 利用 BST 性質：若 $p$、$q$ 的值都小於 `node->val`，兩者必在左子樹（BST 定義），故 LCA 也在左子樹，可以直接往左走而不必搜右邊；都大則往右；否則（一小一大，或其中之一等於 `node->val`）當前節點就是分歧點，即 LCA。這裡的推論「兩者都在左子樹 ⟹ LCA 在左子樹」成立，是因為 LCA 必是兩者的公共祖先，而左子樹外的節點若是兩者祖先則 `node` 更近或相等——嚴格說，`node` 是公共祖先但深度較小，故 LCA 必在左子樹內。這使複雜度從 $O(n)$ 降到 $O(h)$。

## C++17 模板

```cpp
// 二元樹的 LCA（LeetCode 236）。前提：p 與 q 都存在於樹中。
TreeNode* lowestCommonAncestor(TreeNode* root, TreeNode* p, TreeNode* q) {
    if (!root || root == p || root == q) {
        return root;
    }  // 找到一個就上傳

    TreeNode* l = lowestCommonAncestor(root->left, p, q);
    TreeNode* r = lowestCommonAncestor(root->right, p, q);

    if (l && r) {
        return root;
    }  // 分居兩側，當前節點即 LCA
    return l ? l : r;  // 只有一側有，原樣上傳
}
```

BST 版（LeetCode 235），$O(h)$：

```cpp
TreeNode* lowestCommonAncestorBST(TreeNode* root, TreeNode* p, TreeNode* q) {
    while (root) {
        if (p->val < root->val && q->val < root->val) {
            root = root->left;
        } else if (p->val > root->val && q->val > root->val) {
            root = root->right;
        } else {
            return root;
        }  // 分歧點（含其中之一等於 root）即 LCA
    }
    return nullptr;
}
```

## 時間與空間複雜度

二元樹版：最壞需訪問每個節點一次，$O(n)$ 時間、$O(h)$ 堆疊空間。有提前返回，實際常更快，但最壞界不變。

BST 版：每步下降一層，$O(h)$ 時間；迭代寫法 $O(1)$ 空間。平衡時 $h = O(\log n)$。

若要**多次查詢**，$O(n)$ 每次就太慢，應改用倍增（3.8）預處理 $O(n \log n)$、查詢 $O(\log n)$，或歐拉序加稀疏表達成 $O(n \log n)$ 預處理、$O(1)$ 查詢。單次查詢用本節，多次查詢用 3.8——這是選擇的分水嶺。

## 常見錯誤與邊界條件

- 假設 $p$、$q$ 必定存在卻用在可能不存在的題目上（1644 明確要求處理不存在的情形，必須改成統計找到幾個）。
- 比較節點時用 `->val` 而樹中有重複值（應比指標）。
- `l && r` 的分支寫成 `l || r`。
- BST 版忘記「其中之一等於 `node->val`」也算分歧點而繼續下降，越過真正的 LCA。
- 1650 給的是帶父指標的節點，此時應改用「兩指標走完自己換走對方」的技巧（與 160 相交串列同構），不要套本節模板。
- $p == q$ 的情形（LCA 是自己）。
- 空樹。

## 與相似技巧的比較

- 1650（帶父指標）等價於兩條「向上到根」的鏈求交點，用 160 的雙指標換軌法 $O(h)$ 時間、$O(1)$ 空間，比本節更簡單——**有父指標時不要用遞迴版**。
- 1123（最深葉節點的 LCA）需要同時回傳深度與 LCA，是狀態擴充的例子：回傳 `pair<深度, 節點>`，深度較大的一側直接上傳，相等時當前節點即答案。
- 倍增 LCA（3.8）處理多次查詢；Tarjan 離線 LCA 用並查集可做到近線性，但只能離線。
- 236 的三合一語意與 2.3 一般的後序彙總同構，只是彙總的是「指標」而非數值。

## 本節重點速查

- 回傳值是**三合一語意**：同時含兩者回傳 LCA、只含一個回傳那一個、都不含回傳空。
- 左右都非空則自己是 LCA，否則原樣上傳。
- 提前返回依賴「$p$、$q$ 都存在」這個前提。
- BST 版靠值的大小關係一路下降到分歧點，$O(h)$。
- 多次查詢改用倍增（3.8）。
