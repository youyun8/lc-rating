## 這個技術解決什麼問題

一類題目要統計**所有點對之間的路徑**是否滿足某條件：長度恰為 $K$、權重和在某範圍、異或為 0……路徑共有 $\binom{n}{2}$ 條，逐條檢查是 $O(n^2)$。

點分治的槓桿是一個劃分：**任一條路徑，要嘛經過選定的中心點 $c$，要嘛完全落在移除 $c$ 後的某個連通塊內。** 前者可以用「兩段半路徑配對」在 $O(\text{塊大小})$ 或 $O(\text{塊大小} \log)$ 內一次算完，後者遞迴處理。若每次都選**重心**當中心，遞迴深度只有 $O(\log n)$，總計 $O(n \log n)$ 到 $O(n \log^2 n)$。

## 狀態／資料結構定義

- `sz[u]`：當前連通塊中以 $u$ 為根的子樹大小（每層重算，因為塊在變）。
- `done[u]`：$u$ 是否已被選為某層的重心並「封住」。所有遍歷都必須跳過 `done` 的點——這是「當前連通塊」的唯一定義方式。
- **重心**：使「移除它後最大連通塊的大小」最小的點。等價刻畫：所有塊的大小都 $\le \lfloor N/2 \rfloor$（$N$ 為當前塊的節點數）。
- 每層從重心 $c$ 出發 DFS，收集每個點的「半路徑量」`dist[x]`（到 $c$ 的距離／權重和／異或值）。
- 統計函式 `calc(起點, 初始量)`：把從某點出發收集到的半路徑兩兩配對，回傳滿足條件的配對數。

## 不變量或正確性證明

**引理一（重心存在，且最大塊 $\le \lfloor N/2 \rfloor$）。**

設 $c$ 是使 $f(u) = \max_{\text{塊}} |\text{塊}|$ 最小的點。反證：若 $f(c) > N/2$，設達到最大的塊是經由鄰居 $v$ 的那一塊 $B$，$|B| > N/2$。考慮改選 $v$：移除 $v$ 後，「往 $c$ 方向」的那一塊大小是 $N - |B| < N/2$；其餘各塊都是 $B$ 的真子集去掉 $v$ 後的部分，大小 $\le |B| - 1$。故 $f(v) \le \max(N - |B|,\ |B| - 1) < f(c)$（因為 $|B| > N/2 > N - |B|$，且 $|B| - 1 < |B| = f(c)$）。與 $c$ 的最小性矛盾。故 $f(c) \le \lfloor N/2 \rfloor$。$\square$

**引理二（遞迴深度 $O(\log n)$）。** 由引理一，每往下遞迴一層，連通塊大小至少減半。從 $n$ 減半到 1 最多 $\log_2 n$ 層。

進一步，**每一層所有連通塊的節點總數 $\le n$**（它們互不相交），所以若每層對每塊做 $O(\text{塊大小})$ 的工作，每層總計 $O(n)$，全部 $O(n \log n)$。**這個「每層總和有界」的觀察，而不是「每塊很小」，才是複雜度的真正來源。**

**引理三（不重不漏）：每條路徑恰好在一層、被恰好一個重心統計一次。**

設路徑 $P = (a, b)$。在最上層，$a, b$ 都在同一個連通塊中（整棵樹）。歸納地假設在某層 $a, b$ 同屬當前塊 $T$，塊的重心為 $c$：

- 若 $c$ 在 $P$ 上（含 $c = a$ 或 $c = b$），這一層就統計到它。
- 若 $c$ 不在 $P$ 上，則 $P$ 上所有點都不是 $c$，故移除 $c$ 後 $a$ 與 $b$ 仍由 $P$ 連通，落在**同一個**新塊中，遞迴時繼續。

因為塊嚴格變小，遞迴必定終止，而終止時塊只剩一個點，此時 $a = b = c$，路徑退化。故每條路徑在「第一次遇到 $c \in P$」的那一層被統計，且該層只有一個重心，統計恰一次。$\square$

這條引理是點分治不重不漏的全部依據。它只用到「移除不在路徑上的點不會斷開該路徑」——樹上路徑唯一，這在圖上不成立，所以點分治是樹專屬技巧。

**容斥的正確性。** 從 $c$ 出發 DFS 得到所有點的 `dist`（含 $c$ 自己，`dist = 0`）。把這些值兩兩配對得到的「$\text{dist}[x] + \text{dist}[y]$ 滿足條件」的對數，包含了兩類：

- $x, y$ 在 $c$ 的不同子樹（或其一為 $c$）：$x \to c \to y$ 確實是一條簡單路徑，長度就是 $\text{dist}[x] + \text{dist}[y]$。**應該算**。
- $x, y$ 在 $c$ 的**同一棵**子樹：$x \to c \to y$ 不是簡單路徑（會重複走 $c$ 到分岔點那一段），真實距離比 $\text{dist}[x] + \text{dist}[y]$ 小。**不該算**。

因此扣掉每棵子樹內部的配對數即可。實作上是對每個子節點 $v$，以 $v$ 為起點、初始量為邊權 $w(c,v)$ 再算一次 `calc`——這樣算出的正是「同一棵子樹內、且用 $\text{dist}$ 相加的錯誤配對數」，減去它就對了。

**注意容斥的初始量必須是 $w(c,v)$ 而不是 0**，否則扣掉的量與加進去的量不是同一批（前者用的是到 $v$ 的距離，後者用的是到 $c$ 的距離），會多扣或少扣。

## C++17 模板

```cpp
// 點分治骨架：統計滿足條件的路徑數，O(n log n) ~ O(n log^2 n)。
class CentroidDecomposition {
    std::vector<std::vector<std::pair<int, int>>> g_;  // {鄰居, 邊權}
    std::vector<int> sz_;
    std::vector<bool> done_;      // 已被選為重心 → 封住
    std::vector<long long> buf_;  // 收集半路徑量
    long long ans_ = 0;
    long long kLimit_ = 0;  // 題目給的門檻，視題目而定

    void getSize(int u, int fa) {  // done_ 的點視為不存在
        sz_[u] = 1;
        for (auto [v, w] : g_[u]) {
            if (v == fa || done_[v]) {
                continue;
            }
            getSize(v, u);
            sz_[u] += sz_[v];
        }
    }

    int findCentroid(int u, int fa, int total) {
        for (auto [v, w] : g_[u]) {
            if (v == fa || done_[v]) {
                continue;
            }
            if (sz_[v] > total / 2) {
                return findCentroid(v, u, total);
            }  // 往大塊走
        }
        return u;  // 所有塊都 <= total/2
    }

    void collect(int u, int fa, long long d) {
        buf_.push_back(d);
        for (auto [v, w] : g_[u]) {
            if (v == fa || done_[v]) {
                continue;
            }
            collect(v, u, d + w);
        }
    }

    long long calc(int u, int fa, long long init) {  // 兩兩配對，視題目實作
        buf_.clear();
        collect(u, fa, init);
        std::sort(buf_.begin(), buf_.end());
        long long res = 0;
        // 例：統計 buf_[i] + buf_[j] <= K 的對數（雙指標）
        for (int i = 0, j = buf_.size() - 1; i < j;) {
            if (buf_[i] + buf_[j] <= kLimit_) {
                res += j - i;
                ++i;
            } else {
                --j;
            }
        }
        return res;
    }

    void solve(int entry) {
        getSize(entry, -1);
        int c = findCentroid(entry, -1, sz_[entry]);
        done_[c] = true;  // 先封住，之後的遍歷會自動繞開

        ans_ += calc(c, -1, 0);  // 所有半路徑兩兩配對
        for (auto [v, w] : g_[c]) {
            if (done_[v]) {
                continue;
            }
            ans_ -= calc(v, c, w);  // 容斥：初始量必須是 w
        }

        for (auto [v, w] : g_[c]) {
            if (!done_[v]) {
                solve(v);
            }  // 對每個新塊遞迴
        }
    }
};
```

## 時間與空間複雜度

層數 $O(\log n)$（引理二）；每層所有塊的節點總數 $\le n$。

- 若 `calc` 是 $O(m)$（例如用桶計數統計「距離恰為 $K$」），總計 $O(n \log n)$。
- 若 `calc` 需要排序或雙指標前先排序，是 $O(m \log m)$，總計 $O(n \log^2 n)$。

`getSize` 與 `findCentroid` 每層合計 $O(n)$，不影響階數。

空間：鄰接表 $O(n)$、`sz`/`done` $O(n)$、`buf` $O(n)$、遞迴堆疊 $O(\log n)$ 層 $\times$ 單層 DFS 深度 $O(n)$ 最壞——**堆疊深度仍可能是 $O(n)$**（單層的 DFS 走的是原樹的鏈），鏈狀樹上要留意。

## 常見錯誤與邊界條件

- 遍歷時忘記檢查 `done_`（會跨到已封住的塊，路徑被重複統計）。
- `done_[c] = true` 設定的時機在容斥之後（此時 `calc` 會走過 $c$，把它算成普通點）。
- 容斥時初始量給 0 而非邊權 $w(c,v)$（扣錯量）。
- `findCentroid` 的判斷寫成 `sz_[v] >= total / 2`（邊界差一，可能無限遞迴）。
- `getSize` 每層都要重算，沿用上一層的值會全錯。
- 忘記路徑「一端是重心」的情形（`collect` 從 $c$ 出發、`dist = 0` 已涵蓋，但若把 $c$ 排除就會漏）。
- 單點路徑是否計入要看題目定義。
- 帶權時用 `int` 累加溢位。
- 每層 `buf_` 忘記清空。

## 與相似技巧的比較

- 與 2.6／3.5 的「枚舉最高點」：兩者都是「每條路徑有唯一的代表點」這個劃分思路。差別在於枚舉最高點是**固定根之後由樹結構決定代表點**，只能處理「代表點處可 $O(1)$ 合併」的問題（最長鏈相加）；點分治**自己選代表點**並允許在代表點處做 $O(m \log m)$ 的配對統計，因此能處理「恰為 $K$」「不超過 $K$」這類需要查表配對的條件。**問法是「最長／最大」通常用枚舉最高點，問法是「有幾條」通常用點分治。**
- 與 3.10 的樹上滑動視窗：後者只處理「由上往下」的鏈，本節處理任意點對的路徑。
- 與 3.11 的 DSU on tree：DSU on tree 答的是「每棵子樹一個答案」，點分治答的是「全樹的路徑統計總量」。輸出形狀不同。
- 與 3.9 的虛樹：虛樹是壓縮點集，點分治是分解結構，兩者可以疊加使用（在虛樹上跑點分治），但那已超出本節。
- 若題目在分治過程中還要支援修改，就要用**動態點分治（點分樹）**，即把每層重心的父子關係建成一棵深度 $O(\log n)$ 的輔助樹。那是本節的自然延伸。

## 本節重點速查

- 劃分：路徑要嘛經過重心，要嘛整條落在移除重心後的某一塊——**不重不漏**（引理三，依賴樹上路徑唯一）。
- 選重心保證每塊 $\le \lfloor N/2 \rfloor$，故只有 $O(\log n)$ 層，而**每層節點總數 $\le n$** 才是複雜度的來源。
- 統計用容斥：全部配對減去同子樹內部配對，且**容斥的初始量必須是邊權 $w(c,v)$**。
- 所有遍歷都要跳過 `done_`。
