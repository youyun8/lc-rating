## 這個技術解決什麼問題

一般樹的直徑：最遠的兩個節點之間的距離（1245、2246 的變體、3313）。它是很多題目的核心量——「最少幾輪能傳遍全樹」「樹的中心在哪」都要先求直徑。

有兩套 $O(n)$ 解法，各有適用範圍，選錯會出錯：

- **DFS 枚舉最高點**（同 2.6）：對每個節點取其子樹方向的前兩長鏈相加。**對任意邊權都成立，包括負權。**
- **兩次 BFS/DFS**：從任意點出發找最遠點 $u$，再從 $u$ 出發找最遠點 $v$，$u$–$v$ 即直徑。**只在非負邊權（含無權）時成立。**

**延伸講解**：[樹形 DP：樹的直徑【基礎演算法精講 23】](https://www.bilibili.com/video/BV17o4y187h1/)

## 狀態／資料結構定義

**方法一（枚舉最高點）：**
- `down(u, fa)` 回傳從 $u$ 向下的最長鏈長度（邊數或權重和）。
- 迴圈中維護 `max1 >= max2` 兩個變數（不必排序），代表所有子節點方向中最長與次長的鏈。
- 全域 `ans = max(ans, max1 + max2)`；回傳 `max1`（**單邊**）。
- 初始 `max1 = max2 = 0`，代表「不往任何子節點延伸」，這對無權樹正確；帶負權時要允許取更小的值，見下。

**方法二（兩次 BFS）：**
- 第一趟從節點 0 出發，記錄距離陣列，取距離最大者為 $u$。
- 第二趟從 $u$ 出發，最大距離即直徑，對應節點為 $v$。
- 用 BFS（無權）或 DFS/Dijkstra（帶權）皆可。

## 不變量或正確性證明

**方法一**的正確性與 2.6 完全相同：每條路徑有唯一最高點，故枚舉最高點不重不漏；以 $u$ 為最高點的最長路徑是其各子節點方向的前兩長鏈之和（各方向獨立，因為子樹不相交）。這套論證只用到「路徑最高點唯一」與「子樹不相交」，**與邊權正負無關**，所以它是通用的。

**方法二的正確性論證（且看清它的前提）。** 宣稱：從任意節點 $s$ 出發的最遠點 $u$，必定是某條直徑的一個端點。

證明。設 $(a, b)$ 是一條直徑。分兩種情形。

情形一：$s$ 在 $a$–$b$ 路徑上。此時 $d(a,b) = d(a,s) + d(s,b)$。設 $u$ 是離 $s$ 最遠的點，不失一般性設 $d(s,a) \ge d(s,b)$。因 $u$ 最遠，$d(s,u) \ge d(s,a)$。設 $m$ 是 $s$–$u$ 與 $s$–$b$ 兩條路徑的分歧點，則
$$d(u,b) = d(s,u) + d(s,b) - 2\,d(s,m).$$
若 $m = s$（兩條路徑一離開 $s$ 就分開），則 $d(u,b) = d(s,u) + d(s,b) \ge d(s,a) + d(s,b) = d(a,b)$，故 $(u,b)$ 也是直徑。若 $m \ne s$，表示 $u$ 與 $b$ 同側，那就改與 $a$ 配對：$s$–$u$ 與 $s$–$a$ 必定在 $s$ 就分歧（因為 $a$、$b$ 分居 $s$ 兩側），同樣得 $d(u,a) \ge d(a,b)$。兩種情形都找到一條不短於直徑的路徑，而直徑已是最大，故等號成立。

情形二：$s$ 不在 $a$–$b$ 路徑上。設 $s$ 到該路徑的接入點為 $t$。若 $u$ 到 $a$–$b$ 路徑的接入點也在路徑上，類似地可證 $d(u,a)$ 或 $d(u,b)$ 達到直徑長度。反之若 $d(s,u) > d(s,t) + \max(d(t,a), d(t,b))$，則把 $a$（或 $b$）換成 $u$ 會得到比 $d(a,b)$ 更長的路徑，矛盾。

**這個證明的每一步都用到「距離非負」——具體來說，用到「路徑的一段不會比整條長」這個單調性。** 若邊權可為負，$d(s,u)$ 最大不再蘊含 $u$ 是好的端點：一條含大量負權邊的長路徑可能距離很小，而真正的直徑端點反而在第一趟中沒被選中。此時方法二直接失效，必須用方法一。

**方法一在負權下的調整**：`max1`、`max2` 的初值不能是 0（那等於「可以選擇不延伸」，隱含了「不延伸不會更差」的非負假設）。若題目定義路徑必須至少含一條邊，初值應設為 $-\infty$ 並小心處理葉節點。若定義允許單點路徑（長度 0），初值 0 才對。**先問清楚題目對「路徑」的定義**。

## C++17 模板

```cpp
// 樹的直徑（方法一：枚舉最高點）。對任意邊權都正確。
class Solution {
    std::vector<std::vector<std::pair<int, int>>> g_;  // {鄰居, 邊權}
    long long ans_ = 0;

    long long down(int u, int fa) {  // 從 u 向下的最長鏈
        long long max1 = 0,
                  max2 = 0;  // 最大與次大（非負邊權時初值 0 代表不延伸）
        for (auto [v, w] : g_[u]) {
            if (v == fa) {
                continue;
            }
            long long d = down(v, u) + w;
            if (d > max1) {
                max2 = max1;
                max1 = d;
            }  // 舊 max1 降為 max2
            else if (d > max2) {
                max2 = d;
            }
        }
        ans_ = std::max(ans_, max1 + max2);  // 以 u 為最高點，可分叉
        return max1;                         // 上傳單邊
    }

public:
    long long diameter(int n, const std::vector<std::vector<int>>& edges) {
        g_.assign(n, {});
        for (const auto& e : edges) {
            g_[e[0]].push_back({e[1], 1});
            g_[e[1]].push_back({e[0], 1});
        }
        down(0, -1);
        return ans_;
    }
};
```

方法二（無權樹，兩次 BFS）：跑一次 BFS 取最遠點 `u`，從 `u` 再跑一次 BFS，最大距離即直徑。程式碼更短，但只適用非負邊權。

## 時間與空間複雜度

方法一：一次 DFS，$O(n)$ 時間；維護前兩大是 $O(\deg u)$ 而非排序的 $O(\deg u \log \deg u)$，總計仍是 $O(n)$。空間 $O(n)$ 鄰接表加 $O(h)$ 堆疊。

方法二：兩次遍歷各 $O(n)$，總計 $O(n)$。用 BFS 時空間 $O(n)$ 且**不會爆堆疊**——這是它在深度極大的鏈狀樹上的實際優勢。

兩者同階，選擇依據是：**邊權可能為負就必須用方法一；否則方法二程式碼更短、且 BFS 版沒有堆疊風險。**

## 常見錯誤與邊界條件

- 在可能有負權的題目上使用兩次 BFS（最常見的錯誤，測資弱時還會過）。
- 方法一的回傳值寫成 `max1 + max2`（分叉值不是合法的向上延伸鏈）。
- 前兩大的更新寫成兩個獨立 `if`，漏掉新值同時大於兩者的情形。
- 混淆直徑的「邊數」與「節點數」（相差 1）。
- 帶權時用 `int` 累加而溢位。
- `max1`／`max2` 初值與題目對路徑定義（是否允許單點）不一致。
- $n = 1$ 時直徑為 0。
- 忘記 `v == fa`。

## 與相似技巧的比較

- 與 2.6 的二元樹直徑：分解思路完全相同，差別只在「左右兩個」變成「所有子節點取前兩大」。
- 2246（相鄰字元不同的最長路徑）、687（最長同值路徑）都是同一骨架，只是 `down` 的定義加上「只在字元不同時才延伸」的條件。
- 3313（樹中最遠節點）若要對**每個節點**求最遠距離，那是換根 DP（3.4）的最值類問題，需維護向下最長與次長、以及向上最長；也可用「答案必是到直徑兩端點之一的距離」這條性質繞開——後者的正確性同樣依賴非負邊權。
- 樹的中心（最小化到最遠點的距離）位於直徑的中點，這是直徑的直接推論，常用於 1245 的變體。

## 本節重點速查

- 兩套解法：**枚舉最高點（取前兩長鏈相加）對任意邊權都對；
- 兩次 BFS 只在非負邊權下成立**，因為它的證明用到「路徑的一段不會比整條長」。
- 回傳值必須是單邊 `max1`，全域答案才用 `max1 + max2`。
- 前兩大的更新要記得把被擠下的舊最大降為次大。
