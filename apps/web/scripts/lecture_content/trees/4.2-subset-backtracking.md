## 這個技術解決什麼問題

「把所有子集列出來」是回溯最基本的形狀，也是 39、78、1239、2597、1601 這一大類題的共同骨架：每個元素獨立地「選或不選」，答案是所有選法。

它與 4.1 的差別在於**方案長度不固定**——子集可以是空集，也可以是全集。這帶來兩個結構性問題：答案該在哪裡收集？如何保證每個子集只被生成一次？本節給出兩種標準視角（選／不選、枚舉下一個選誰），並說明它們各自的不變量與適用場合。

**延伸講解**：[回溯算法套路①子集型回溯【基礎演算法精講 14】](https://www.bilibili.com/video/BV1mG4y1A7Gu/)

## 狀態／資料結構定義

**視角一：選或不選（輸入的角度）**

- `dfs(i)`：決定第 $i$ 個元素選不選。
- 遞迴樹是一棵**滿二元樹**，深度恰為 $n$，每個節點兩個分支。
- 葉節點（$i = n$）與子集一一對應，答案只在葉節點收集。

**視角二：枚舉下一個選誰（答案的角度）**

- `dfs(start)`：`path` 已經是一個合法子集，接下來只能從下標 $\ge \text{start}$ 的元素中挑「下一個要加入的」。
- 遞迴樹的分支數逐層遞減（$n - \text{start}$ 個選項），深度至多 $n$。
- **每個節點都是一個合法子集**，答案在每個節點收集，包括根節點（空集）。

兩種視角都用同一個 `path` 與 pop/push 配對。差別只在「遞迴樹長什麼樣」與「答案在哪裡收集」。

## 不變量或正確性證明

**視角一的雙射。** 一條根到葉的路徑是一個長度 $n$ 的二元決策序列 $(d_0, \dots, d_{n-1})$，$d_i \in \{\text{選}, \text{不選}\}$。這與 $\{0,1\}^n$ 一一對應，而 $\{0,1\}^n$ 與 $\{0,\dots,n-1\}$ 的子集族一一對應（特徵向量）。故葉節點與子集一一對應，共 $2^n$ 個，**不重不漏是雙射的直接後果**，不需要任何額外論證。

**視角二的雙射。** 每個子集 $S$ 有唯一的**遞增下標表示** $i_1 < i_2 < \cdots < i_m$。視角二的遞迴恰好枚舉所有遞增下標序列：`dfs(start)` 的迴圈取 $j \ge \text{start}$，然後遞迴 `dfs(j + 1)`——下一個選的下標嚴格大於 $j$。因此根到任一節點的路徑對應一個嚴格遞增序列，且每個遞增序列對應唯一一條路徑。故節點與子集一一對應。

**這條論證點名了一個必須遵守的細節：遞迴時傳的是 `j + 1`，不是 `start + 1`，也不是 `i + 1`。**

- 傳 `start + 1`：下一層仍可選到 $j$ 以外但小於 $j$ 的下標，遞增性被破壞，同一個子集會以多種順序被生成（重複）。
- 傳 `j`（不加一）：允許重複選同一個元素——這在 39（組合總和，元素可重複使用）中**正是想要的**。39 與 78 的唯一差別就是這裡加不加一。把這一點看清楚，兩題就是同一份程式碼。

**答案收集位置的推導，而不是記憶。** 問「什麼樣的 `path` 是一個完整方案」：

- 視角一：只有在所有元素都表態之後 `path` 才確定，故在 $i = n$ 收集。
- 視角二：`path` 在任何時刻都已經是一個合法子集（它就是已選元素的集合），故在**每個節點**收集。

若在視角二只在葉節點收集，會漏掉所有非極大的子集；若在視角一每個節點都收集，會把同一個子集收集多次（前綴相同的中途狀態）。**兩種錯誤都源自沒有先回答「什麼是完整方案」。**

**剪枝的合法性。** 加剪枝時要證明「被剪掉的分支確實不含任何答案」，這是必要條件而非充分條件的檢查。例如 39（組合總和，正整數、和為 `target`）中，若當前和已超過 `target`，由於所有元素為正，繼續往下只會更大，故該分支必無解——**這一步用到「元素全為正」這個前提**。若允許負數，剪枝立刻失效，這也是 39 明確要求正整數的原因。

2597（美麗子集：任兩元素差不等於 $k$）的剪枝則要在加入前檢查 `cnt[x - k]` 與 `cnt[x + k]` 是否為 0，並在回溯時遞減——這是「用計數器維護可行性」的標準做法，計數器的增減必須與 push/pop 同樣嚴格配對。

## C++17 模板

```cpp
// 子集（LeetCode 78）：兩種視角，任選一種。
class Solution {
    std::vector<int> nums_, path_;
    std::vector<std::vector<int>> ans_;

    // 視角一：選或不選。深度固定 n，只在葉節點收集。
    void pickOrNot(int i) {
        if (i == static_cast<int>(nums_.size())) {
            ans_.push_back(path_);
            return;
        }
        pickOrNot(i + 1);           // 不選 nums_[i]
        path_.push_back(nums_[i]);  // 選 nums_[i]
        pickOrNot(i + 1);
        path_.pop_back();
    }

    // 視角二：枚舉下一個選誰。每個節點都是一個合法子集，都要收集。
    void pickNext(int start) {
        ans_.push_back(path_);  // 包含根節點的空集
        for (int j = start; j < static_cast<int>(nums_.size()); ++j) {
            path_.push_back(nums_[j]);
            pickNext(j + 1);  // j + 1：保證下標嚴格遞增
            path_.pop_back();
        }
    }

public:
    std::vector<std::vector<int>> subsets(std::vector<int>& nums) {
        nums_ = nums;
        pickNext(0);
        return ans_;
    }
};
```

## 時間與空間複雜度

視角一的遞迴樹有 $2^{n+1} - 1$ 個節點，$2^n$ 個葉節點；每個葉節點複製一份長度至多 $n$ 的 `path`。時間 $O(n \cdot 2^n)$。

視角二的節點數恰為 $2^n$（與子集一一對應），每個節點複製一次 `path`。時間同樣 $O(n \cdot 2^n)$。**兩者同階**，選擇依據是哪一種的剪枝比較好寫：

- 條件與「某個元素選不選」直接掛鉤（1863 求所有子集異或和）→ 視角一。
- 條件與「已選集合」有關且需要提早中止（39 的和超過 target、2597 的差值衝突）→ 視角二，因為每個節點都是完整狀態，容易判斷。

空間：`path` 與遞迴堆疊 $O(n)$，不計輸出。

$n$ 的規模上限：$2^n$ 在 $n = 20$ 時約 $10^6$，$n = 25$ 時約 $3\times10^7$。**看到 $n \le 20$ 幾乎就是在暗示指數枚舉**；$n$ 到 40 左右則要考慮 4.8 的折半列舉。

## 常見錯誤與邊界條件

- 視角二漏掉在節點處收集（只收葉節點，答案少一大半）。
- 視角二傳 `start + 1` 或 `i + 1` 而非 `j + 1`（產生重複）。
- 39 這種可重複選的題誤傳 `j + 1`（漏解）。
- 視角一在每個節點收集（重複）。
- 剪枝條件未驗證「被剪的分支確實無解」（例如有負數時仍用「和超過就剪」）。
- 輔助計數器的增減沒有與 push/pop 配對。
- 空集是否算合法子集要看題目。
- `path` 存的是值還是下標要一致。
- 輸入含重複元素時本節的雙射失效，須用 4.6 的去重規則。

## 與相似技巧的比較

- 與 4.4 的組合型：組合是「固定大小的子集」，骨架相同，多一個「長度到了就收集並回傳」的終止條件與長度剪枝。
- 與 4.5 的排列型：子集不在乎順序（用 `start` 保證下標遞增），排列在乎順序（每層都要從全部未使用的元素中挑）。**`start` 這個參數在不在，就是子集與排列的全部差別。**
- 與位元枚舉（`for (int mask = 0; mask < (1 << n); ++mask)`）：兩者同階且位元版更短、常數更小。**能用位元枚舉就用位元枚舉**；回溯的優勢在於可以剪枝（位元枚舉沒得剪），以及元素可重複選、方案長度無上界（39）這類位元表示不了的情形。
- 與 4.8 的折半列舉：當 $n$ 大到 $2^n$ 不可行但 $2^{n/2}$ 可行時（$n \approx 40$），把子集枚舉拆成兩半。前提是目標函數可分解。
- 與狀壓 DP：同樣是 $2^n$ 個狀態，但 DP 會**合併**到達同一狀態的不同路徑（只留最佳值），子集枚舉則要全部列出。要「所有方案」用回溯，要「最佳值」優先考慮狀壓 DP。

## 本節重點速查

- 兩種視角：**選／不選**（滿二元樹、深度 $n$、只在葉收集）與**枚舉下一個選誰**（每個節點都是合法子集、都要收集）。
- 後者的關鍵是遞迴傳 **`j + 1`** 以保證下標嚴格遞增，這正是不重不漏的雙射依據；
- 傳 `j`（不加一）就變成「元素可重複使用」的 39。
- 答案收集的位置由「什麼是完整方案」推導，不靠記憶。
- 剪枝必須先證明被剪的分支無解（39 用到「元素全為正」）。
- $n \le 20$ 是指數枚舉的訊號。
